# 本科生进实验室：怎么找导师、怎么开始

> 一句话概括：进实验室的门槛比你想的低，难的是知道该找谁、第一句话说什么。

**适用人群**：大二、大三想积累科研经历的学生；准备保研但简历上空空的人；不确定自己适不适合读研、想先试试的人。

> **核查日期**：2026-11-05
>
> 本文是经验与方法类内容，不涉及政策规定与金额。所有【经验】标注的内容来自本科生科研的普遍实践，不指向任何具体学校或个人。各校的本科生科研训练项目名称、申请时间不同，以本校教务处或学院通知为准。

---

## 一、为什么值得去（和不值得去）

先说清楚收益，避免盲目投入。

| 收益 | 说明 |
| --- | --- |
| **判断自己适不适合读研** | 这是最被低估的收益。在实验室待三个月，比想三年更能回答「我能不能忍受这种生活」 |
| **保研/申请的实质材料** | 面试官问的是「你做过什么」，不是「你成绩多好」 |
| **技能** | 文献检索、实验操作、数据处理、学术写作，这些在课堂学不到 |
| **推荐信** | 需要一个真正了解你的老师，而了解只能靠共事 |
| **信息** | 导师、方向、行业内部情况，这些信息在实验室里自然流通 |

| 成本 | 说明 |
| --- | --- |
| 时间 | 每周固定投入，会挤占课程复习与社团时间 |
| 收益不确定 | 可能前三个月一直在打杂 |
| 可能遇到不合适的组 | 方向不对、管理风格不合、承诺不兑现 |

**判断标准**：如果你的目的是「想清楚要不要走学术」或「保研要有东西可讲」，收益远大于成本。如果只是「简历上想多一行」，不如去做一段实习。【经验】

## 二、找谁：三条路径，按成功率排序

| 路径 | 做法 | 成功率 |
| --- | --- | --- |
| **① 上过课的老师** | 你在他课上表现过、问过问题，他记得你 | 最高 |
| **② 学院官网的研究方向页** | 逐个看老师的研究方向、近三年论文，挑 3—5 位匹配的 | 中 |
| **③ 学长学姐推荐** | 已经在组里的学长帮你引荐 | 高，但需要有这个关系 |

**最有效的是第一条。** 一个记得你脸的老师，比十个陌生邮箱有用得多。所以如果你已经大三了还没和任何老师说过话，先从这学期的课开始：坐在前排、课后问一个真问题、下次再问一个。

**看官网时看什么**：
- 研究方向页（不是职称列表）
- 近三年发表的论文题目（判断他现在在做什么，而不是十年前做什么）
- 课题组是否有主页，有没有列出本科生参与情况

## 三、邮件怎么写（本篇最实用的部分）

一封合格的邮件只有 5 句话，200 字以内。老师每天收几十封邮件，长的会被跳过。

### 模板

```
主题：本科生科研申请咨询 —— 姓名 / 专业 / 年级

X 老师您好：

我是 XX 学院 XX 专业 20XX 级本科生 XXX。我上过您的《XX 课程》，
对其中 XX 部分很感兴趣（或：我读了您 20XX 年关于 XX 的论文，
对 XX 这一点有疑问）。

我想申请加入您的课题组学习，每周可投入 X 小时，可持续 X 个学期。
我的情况：绩点 X（专业排名 X/X），掌握 XX 技能（编程语言/实验技术/软件），
读过 XX 方向的 X 篇文献。

如果方便，我能否在您办公时间去拜访 10 分钟？

此致
XXX
学号 / 手机 / 邮箱
```

### 五个必须做到的点

| 要点 | 为什么 |
| --- | --- |
| 主题写清身份 | 老师靠主题决定要不要点开 |
| 提到具体课程或具体论文 | 证明你不是群发 |
| 写清可投入时间 | 老师最关心你来了能不能干活 |
| 给出技能清单 | 让老师判断你能上手什么 |
| 请求一次短会面，不要请求「加入」 | 降低对方的决策成本 |

### 三个不要做

- **不要群发同一封邮件给多位老师**（尤其不要抄送）。老师们互相认识。
- **不要写「我对科研有浓厚兴趣」**——这句话零信息量，人人都在写。
- **不要在邮件里承诺「我什么都能干、时间很多」**。承诺过多，进组后做不到，信任一次就没了。

**如果两周没回复**：可以礼貌跟进一次（同一邮件线程内回复，不要新开一封）。仍无回复就换下一位，不要连发三封。没回复通常意味着没名额或没兴趣，不是你不够好。【经验】

## 四、第一次见面谈什么

见面 10 分钟，你要问清五件事。这些问题问出来，老师会觉得你是认真的。

| 该问的 | 为什么问 |
| --- | --- |
| 组里现在有什么本科生能参与的工作 | 判断你是真有事做，还是只是旁听 |
| 每周需要投入多少时间、什么时段 | 避免和课程冲突，也避免期待错位 |
| 有没有补助或劳务费 | 有当然好；没有也正常，但要提前知道 |
| 本科生能不能参与论文署名 | 直接问不礼貌，可以问「以往本科生参与的工作一般怎么署名」 |
| 前三个月大概做什么 | 判断「打杂期」有多长 |

**不该问的**：什么时候能发论文、能不能保证保研加分、能不能不来只挂名。这三个问题会直接结束对话。

**见面后当天发一封感谢邮件**，一句话即可。这个动作成本极低，但很少有人做。

## 五、进组后的现实：打杂期是正常的

不要被「打杂」两个字劝退，也不要美化它。

| 阶段 | 通常做什么 | 持续多久 |
| --- | --- | --- |
| 第 1—2 个月 | 读文献、学操作规范、洗瓶子/整理数据/跑基线 | 视组而定【经验】 |
| 第 3—6 个月 | 在师兄师姐的课题里承担一小块 | 视你的投入 |
| 半年后 | 可能独立负责一个小问题 | 不保证 |

**从打杂到参与，靠的是两件事**：
1. **可靠**。答应的事按时完成，做不了提前说。这一条比聪明重要。
2. **主动问**。不要等分配任务。每周组会后问一句「这块我可以试试吗」。

**如果三个月后仍然完全在打杂、且看不到变化**，可以主动谈一次，说明你想承担更多。谈完仍无改善，退出是合理选择，不是失败。

【待核实】各课题组的实际做法差异极大：「打杂期」长度、本科生参与论文署名的惯例、是否发放补助，都没有统一标准，取决于导师与学科。本文给的是常见情况，不是规则。

---

## 六、怎么退出

进实验室不是签合同，退出不需要仪式感，但需要体面。

1. **提前两周说**，不要突然消失
2. **把手上的事交接清楚**：数据、代码、文献笔记整理好
3. **说明原因**：课程压力、方向不合、时间冲突，实话即可
4. **保持关系**：这位老师可能仍是你未来的推荐人

**不要做的**：不打招呼就不再出现。学术圈很小，同一个学院更小。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 只有成绩顶尖的人才能进实验室 | 多数导师欢迎本科生，主要看你是否可靠、能否投入时间 |
| 大一太早，大四太晚 | 大二下到大三上是性价比最高的窗口；大四进组主要价值是毕设 |
| 必须先把专业课学完 | 多数技能是进组后学的；基础课够用即可 |
| 老师都很忙，不会理本科生 | 忙是真的，但需要人手的组并不少；一封具体邮件成本很低 |
| 进组就能发论文 | 本科生署名取决于实际贡献，不能承诺，也不该以此为目的 |
| 打杂就是被剥削 | 打杂期是学习操作规范的过程；但长期只打杂且无改变，可以退出 |
| 换组会得罪人 | 提前说明、交接清楚，换组是正常流动 |

## 可执行清单

### 准备（1—2 周）

- [ ] 列出 3—5 位目标导师，读他们的研究方向页与近两年论文题目
- [ ] 挑一位，读他 1 篇论文的摘要与结论（不需要读懂全部）
- [ ] 整理自己的技能清单：会什么软件、什么实验技术、什么编程语言
- [ ] 算清每周能稳定投入多少小时（诚实一点）

### 联系

- [ ] 按第三节模板写邮件，控制在 200 字内
- [ ] 从「上过课的老师」开始投，成功率最高
- [ ] 两周无回复，同线程跟进一次；再无回复换人

### 见面

- [ ] 带上成绩单和一句话的自我介绍
- [ ] 问清第四节那五个问题
- [ ] 当天发感谢邮件

### 进组后

- [ ] 第一个月：读完组里 3 篇代表作，学会基本操作规范
- [ ] 每月主动汇报一次进展（哪怕只有一页）
- [ ] 三个月后评估：有没有事做、有没有成长、时间是否承受得住
- [ ] 决定继续或体面退出

## 一句话记住

**导师不缺聪明学生，缺的是「答应了就能做到」的本科生——所以邮件里别夸自己，只说清你能投入多少、做过什么。**
