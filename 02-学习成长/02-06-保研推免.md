# 保研（推免）：资格怎么拿、夏令营与预推免

> 一句话概括：拿到推免资格只是入场券，能不能入学取决于接下来三个月的三场考核。

**适用人群**：大二、大三成绩位于专业前列、想走推免的学生；刚拿到推免资格、正在准备夏令营与预推免的大三学生；家长。

> **政策适用范围**
> - 主要依据：教育部《推荐优秀应届本科毕业生免试攻读研究生工作管理办法》（教学〔2006〕14 号及后续年度通知）；「全国推荐优秀应届本科毕业生免试攻读研究生信息公开暨管理服务系统」（简称推免服务系统）年度公告；各校推免实施办法
> - 全国统一 / 地方执行：**推免制度、系统流程、时间框架全国统一；推免名额分配、成绩计算办法、加分细则由各校规定，名额总数由教育部按校下达**
> - 核查日期：2026-11-05
> - 已知变化：年度通知的报名与系统开放时间每年微调，**必须查当年公告**

## 一、先把「推免」这件事拆开

很多人把「保研」当成一件事，其实是**三段独立的关卡**，任何一段断了都白搭：

| 阶段 | 谁说了算 | 失败后果 |
| --- | --- | --- |
| ① 拿到**推免资格** | 你的本科学校 | 没有资格，后面全部无关 |
| ② 通过**目标院校考核**（夏令营 / 预推免 / 九推） | 目标院校 | 有资格但没人要，只能放弃或等补录 |
| ③ 在**推免服务系统**完成填报与确认 | 系统 + 双方 | 系统操作超时，前面的努力作废 |

【法规】推免资格由本科学校按教育部下达的名额、依据本校办法遴选产生；接收由招生单位通过推免服务系统完成。

**关键认知**：推免名额是**下达到学校的**，不是下达到你个人的。你在本校内部先要排进名额范围，才谈得上申请外校。

## 二、推免资格怎么来

| 环节 | 说明 |
| --- | --- |
| **名额来源** | 教育部按学校层次、学科、往年情况等下达推免名额总数，学校再分配到各学院/专业【法规】 |
| **遴选依据** | 以学业成绩为主，可包含科研、竞赛、社会工作等加分项，**具体算法由本校办法规定** |
| **排名基础** | 多数学校用前三年（或前五学期）加权平均成绩排名【经验】 |
| **公示要求** | 推免办法、名额分配、拟推免名单须在校内公示【法规】 |
| **一票否决项** | 通常包括：有未解除的纪律处分、有不及格课程未通过、学术不端记录、体测/学分不达标 |

**这是最容易忽略的一点**：推免资格的竞争发生在**校内**，而且只算到你提交申请那一刻为止的成绩。大三下学期的成绩很多人以为不算，实际各校口径不同，有的算到大三下，有的只到前五学期。——去查本校推免办法里的「成绩计算截止时间」这一句。

另外注意：**获得推免资格后通常不得再报名参加全国统考**。这不是「多一条路」，是二选一。多数学校有此规定，写在推免办法里。

## 三、完整时间线（刚性，按此倒推）

| 时间 | 要做什么 | 关键风险 |
| --- | --- | --- |
| 大二全年 | 保住绩点排名；进实验室或参加学科竞赛 | 排名一旦掉出范围，后面无法补 |
| 大三上 | 确定 3—5 所目标院校与方向；整理科研经历 | 目标定太晚，材料来不及准备 |
| 大三下 3—5 月 | 准备材料：成绩单、排名证明、推荐信、个人陈述、英语成绩 | 推荐信要提前 2—3 周找老师，临时要没人写 |
| 大三下 5—6 月 | **夏令营投递**（多数院校在此时段开放报名） | 只投一两所，风险集中 |
| 大三暑假 7—8 月 | 参加夏令营（笔试、面试、参观实验室） | 拿到「优秀营员」不等于录取，还要走系统 |
| 大四 9 月上中旬 | **预推免**（部分院校在系统开放前组织） | 名额有限，先到先得的情况存在 |
| 9 月下旬 | **推免服务系统开放**：填报志愿、接收并确认复试/待录取通知 | **确认有时限，超时视为放弃** |
| 9 月底—10 月中 | 补录、九推（系统内仍有名额的院校） | 好学校基本已满 |

系统开放的具体日期每年由教育部公告，**不是固定的某一天**。以当年推免服务系统公告和本校研究生院通知为准。所有「往年是几月几号」的说法都可能失效。

## 四、材料准备清单

| 材料 | 注意点 |
| --- | --- |
| **成绩单** | 需教务处盖章；提前一周办，别卡截止日 |
| **专业排名证明** | 要写清「排名 X / 总人数 Y」和计算口径（是否含加分） |
| **推荐信** | 通常 2 封；找真正了解你的任课老师或导师，不要只找头衔大的 |
| **个人陈述** | 讲清三件事：做过什么、想研究什么、为什么是这所学校这个导师 |
| **科研/竞赛证明** | 论文（含在投）、专利、竞赛证书；在投论文要如实标注状态 |
| **英语成绩** | 四六级、雅思托福；部分院校有硬性门槛 |
| **其他** | 学生证、身份证、申请表、部分院校要求体检表 |

**别做的一件事**：不要伪造或夸大科研经历。夏令营面试会追问细节，一问就露；且一旦被记入诚信记录，影响面远超一次申请。【经验】

## 五、夏令营与预推免的区别

| 维度 | 夏令营 | 预推免 |
| --- | --- | --- |
| 时间 | 大三暑假 | 大四 9 月，系统开放前后 |
| 形式 | 通常 2—5 天，含宣讲、笔试、面试、实验室参观 | 通常 1 天，以考核为主 |
| 名额 | 各院校自主，规模较大 | 多为夏令营未招满的剩余名额 |
| 竞争 | 全国学生集中投递，头部院校极卷 | 部分学生已被夏令营锁定，竞争相对小 |
| 结果 | 「优秀营员」等，多数仍需在系统内走流程 | 可能直接给待录取 |

**策略上的实话**：夏令营是主战场，预推免是补位。只准备预推免，等于等别人挑剩下的名额。【经验】

## 六、系统操作：最容易前功尽弃的一步

推免服务系统的操作有几个不可逆的时点：

1. **填报志愿**：**可同时填报 3 个平行志愿，不分主次（顺序）**。提交后**短时间内（通常 48 小时）不能修改**，这段时间招生单位会下载信息并决定是否让你复试
2. **接收复试通知**：院校发出后，你需在系统内确认，**超时未确认视为放弃**
3. **接收待录取通知**：这是最终环节。**一旦确认接受，通常不能再接受其他单位的待录取**，需要原单位同意才能解除【待核实：解除的具体条件以系统规则与对方单位意见为准】
4. **时间窗很窄**：待录取确认的时限常以小时计，不是以天计

> 【官方】全国推荐免试攻读研究生信息公开暨管理服务系统（推免服务系统）操作规则：可同时填报 3 个平行志愿，不分主次。
>
> 每年系统开放时间与部分细则由教育部当年公告确定，填报志愿数上限与锁定时长如有调整，以当年系统公告为准。

**为什么「48 小时不能改」很关键**：很多人以为填完可以随时换，结果填了 3 个冲的学校，锁定期内没有保底院校发复试通知，就错过了整个批次。**3 个志愿要按「冲—稳—保」的梯度填，不要全填冲刺档。**

**所以有两个动作必须提前做**：
- 系统开放期间保持手机畅通、每天多次登录
- 提前想清楚：如果 A 校和 B 校同时给待录取，你要哪一个。**到时候没有时间犹豫**

## 七、没拿到资格 / 没被录取怎么办

| 情况 | 处理 |
| --- | --- |
| 差一点没进名额 | 关注是否有放弃名额后的顺延；同时立刻转向考研，多数专业课内容可复用 |
| 拿了资格但夏令营全拒 | 主攻预推免与九推；扩大目标院校范围，包括本校 |
| 系统内确认后想反悔 | 需与已确认单位协商解除，**不是单方面能做的**，风险很高 |
| 明确不想读研 | 直接投入秋招；推免资格不影响就业 |

**给一个不制造焦虑的判断**：推免失败的成本是「失去一次免试机会」，不是「失去读研机会」。统考仍然开放，且你在准备推免过程中复习的专业课与英语，直接可用于统考。【经验】

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 有推免资格就等于有学上 | 资格只是入场券，还要通过目标院校考核并在系统中被录取 |
| 拿到优秀营员就稳了 | 多数院校仍要求走系统流程，且部分「优秀营员」不具约束力 |
| 推免系统可以慢慢填 | 待录取确认时限常以小时计，超时视为放弃 |
| 可以先接受 A 校再等 B 校 | 确认待录取后通常不可单方面更改 |
| 排名只看成绩 | 多数学校有科研、竞赛加分，加分细则影响很大 |
| 大三下成绩不重要 | 各校计算截止时间不同，有的包含大三下 |
| 保研失败就完了 | 统考、就业都还开着；推免复习的内容可直接复用 |
| 名额是全校统一排名 | 名额通常按学院/专业分配，跨专业比较无意义 |

## 可执行清单

### 大二—大三上

- [ ] 找到本校《推免工作实施办法》，重点看三处：成绩计算口径、加分项、一票否决条件
- [ ] 确认自己的排名，算出还差多少
- [ ] 进一个实验室或参加一项学科竞赛（加分项也是面试谈资）
- [ ] 把英语成绩考到目标院校的门槛之上

### 大三下

- [ ] 列出 5—8 所目标院校，分冲/稳/保三档
- [ ] 提前 3 周找 2 位老师写推荐信
- [ ] 办成绩单与排名证明（预留一周）
- [ ] 按各校截止日建一张投递表，逐项打勾

### 暑假—9 月

- [ ] 参加夏令营，记录每所学校的考核形式与老师反馈
- [ ] 系统开放前，把个人材料整理成一份 PDF 随时可发
- [ ] 系统开放期间每天多次登录，手机不静音

### 结果出来后

- [ ] 若未获资格，48 小时内切换到统考或秋招，不要空等
- [ ] 若已确认待录取，停止其他申请，专心完成本科毕业要求

## 一句话记住

**推免是三段式：校内抢名额、校外过考核、系统抢确认——三段都有硬时限，任何一段拖一天都可能归零。**
