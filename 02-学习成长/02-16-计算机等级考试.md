# 计算机等级考试：考哪一级、谁真的看这个证

> 一句话概括：这个证对多数人不是硬门槛，但考公、进国企、部分学校的学位要求会用到它。

**适用人群**：非计算机专业想证明基础能力的人；准备考公考编的人；被学校要求考的人。

> **核查日期**：2026-11-05
>
> ⏳ 易过时：报名费各省不同；部分学校的学位挂钩政策在调整。

---

## 一、先判断你要不要考

| 你的情况 | 建议 |
| --- | --- |
| 学校把 NCRE 二级和学位挂钩 | **必须考**，先查本校规定 |
| 目标是考公/事业单位/国企 | 部分岗位要求，值得考 |
| 计算机相关专业 | 意义不大，有更硬的替代（项目、竞赛） |
| 想证明会用办公软件 | 二级 MS Office 可考虑，但招聘方更看重实际操作 |
| 纯为简历好看 | 性价比一般 |

**第一件事：查本校有没有学位挂钩。** 这是唯一可能构成「必须考」的理由。

---

## 二、考什么

全国计算机等级考试（NCRE）分四级。

| 级别 | 定位 | 常见科目 |
| --- | --- | --- |
| **一级** | 基础操作 | 计算机基础及 MS Office 应用、WPS Office 等 |
| **二级** | 程序设计/办公高级应用 | MS Office 高级应用、C、Python、Java、Access 等 |
| **三级** | 工程师预备 | 网络技术、数据库技术、信息安全技术等 |
| **四级** | 工程师级 | 网络工程师、数据库工程师、信息安全工程师等 |

### 2.1 最常考的是二级

原因：

- 多数学校的学位挂钩要求是「二级」
- 二级 MS Office 对非计算机专业最友好
- 二级的编程科目（C/Python/Java）可用于证明编程基础

### 2.2 二级选哪个科目

| 科目 | 适合谁 |
| --- | --- |
| MS Office 高级应用 | 非计算机专业，日常办公需求 |
| Python | 想入门编程、做数据分析 |
| C 语言 | 理工科，部分学校教学语言 |
| Access 数据库 | 需要处理数据、考公相关岗位 |

**注意**：二级各科目**难度差异明显**，MS Office 相对容易，编程科目需要真练。

## 三、报名

| 项目 | 说明 |
| --- | --- |
| 考试时间 | 每年多次（通常 3 月、9 月为主，部分省份增加场次） |
| 报名时间 | 考前约 1–2 个月，**以本省教育考试院公告为准** |
| 报名费 | **各省不同**，常见区间在百元左右/科目【待核实】 |
| 报名方式 | 全国计算机等级考试报名系统或本省指定渠道 |

> 【官方】各省教育考试院 NCRE 报名公告
>
> 具体报名费与考试场次以本省当年公告为准。

## 四、谁真的看这个证

| 场景 | 是否真的看 |
| --- | --- |
| 公务员/事业单位部分岗位 | **看**，招聘公告会写明「需 NCRE 二级」 |
| 国企、银行部分岗位 | 部分看 |
| 学校学位/毕业要求 | **部分学校看**，必须查本校规定 |
| 互联网公司技术岗 | **基本不看**，看项目与算法 |
| 一般企业文职 | 参考价值有限 |

**结论**：它的价值集中在**体制内**方向。如果目标是互联网技术岗，投入产出比不高。

---

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「计算机二级是硬通货」 | 只在部分场景有用，互联网公司不看 |
| 「级别越高越好」 | 四级难度大、认可场景更窄，多数人不需要 |
| 「考了二级就会编程」 | 考试通过 ≠ 会写项目 |
| 「报名费全国统一」 | 各省不同 |
| 「一年只有两次」 | 多数省份 3 月、9 月，部分省份增加场次 |
| 「非计算机专业考编程科目更好」 | 除非真需要，MS Office 更省力 |

## 六、可执行清单

### 决定考之前

- [ ] 查本校学位/毕业是否要求 NCRE
- [ ] 查目标岗位（考公/国企）是否要求
- [ ] 如果两者都不要求，考虑是否值得投入

### 报名

- [ ] 查本省当次报名时间与费用
- [ ] 选定科目（非计算机专业优先 MS Office）

### 备考

- [ ] 编程科目需要实际上机练习，不能只看书
- [ ] MS Office 要熟悉具体版本的操作题

---

## 七、一句话记住

**先查本校学位要不要它、目标岗位要不要它。两个都不要，就别花这个时间。**
