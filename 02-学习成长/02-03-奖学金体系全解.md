# 奖学金体系全解

> 一句话概括：奖学金不是「成绩好自然有」，是分类型、分渠道、要申请的。

**适用人群**：全体在校生，尤其大一新生。

> **政策适用范围**
> - 主要依据：《普通高等学校国家奖学金管理办法》《普通高等学校国家励志奖学金管理办法》；全国学生资助管理中心公告
> - 全国统一：国奖、励志奖学金的设立与基本条件全国统一
> - 地方执行：**金额、名额、评审细则按当年通知与各校办法执行**
> - 核查日期：2026-11-05
> - ⏳ 易过时：金额与名额每年可能调整

---

## 一、奖学金分四层

| 层次 | 名称 | 设立方 |
| --- | --- | --- |
| 国家级 | 国家奖学金、国家励志奖学金 | 中央财政 |
| 省级 | 省级奖学金 | 省级财政 |
| 校级 | 一/二/三等奖学金 | 学校 |
| 社会捐赠 | 企业、校友奖学金 | 捐赠方 |
| 单项 | 科研、竞赛、文体、志愿 | 学校或捐赠方 |

---

## 二、国奖 vs 励志奖学金（最容易混淆）

| 项目 | 国家奖学金 | 国家励志奖学金 |
| --- | --- | --- |
| 看什么 | 成绩 + 综合表现 | **家庭经济困难 + 成绩优秀** |
| 是否需要困难认定 | **不需要** | **必须** |
| 能否同时获得 | **不能**（互斥） | **不能** |
| **奖励标准** | **每生每年 10000 元** | **每生每年 6000 元** |
| **名额** | 全国每年奖励 **12 万名** | 按当年下达 |

【官方】深圳市教育局《高校本专科学生资助政策简介（国家资助部分）》，2026-09-07

**注意一个变化**：从 2024 年起，本专科生国家奖学金名额由每年 6 万名增加到 **12 万名**，奖励标准由每生每年 8000 元提高到 **10000 元**；国家励志奖学金由每生每年 5000 元提高到 **6000 元**。

**如果你看到「国奖 8000 元」「励志 5000 元」的说法，那是 2024 年之前的旧标准。**

**两个关键点**：
1. **励志奖学金必须先完成家庭经济困难认定**
2. **两者互斥**，同一学年只能拿一个。但**励志奖学金和国家助学金可以同时获得**。

## 三、除了成绩还看什么

| 维度 | 说明 |
| --- | --- |
| 学业成绩 | 通常是基础门槛（如排名前 X%） |
| 综合测评 | 很多学校有综合测评体系（含德育、体育、社会实践） |
| 竞赛获奖 | 学科竞赛、创新创业 |
| 科研 | 论文、专利、项目 |
| 社会工作 | 学生干部、志愿服务 |

**查本校的《综合测评办法》**——它决定了奖学金评定的实际权重。

---

## 四、评审流程与时间

| 时间 | 阶段 |
| --- | --- |
| 每学年秋季（9–11 月） | 集中评审 |
| 学生申请 | 提交申请表与材料 |
| 班级/学院评议 | 综合测评排名 |
| 学校评审与公示 | 公示期通常 5 个工作日 |
| 发放 | 通常学期内到账 |

⚠️ **大部分奖学金需要主动申请。不申请就没有。**

---

## 五、申请材料怎么准备

| 材料 | 说明 |
| --- | --- |
| 申请表 | 学校统一模板 |
| 成绩单 | 教务系统打印 |
| 获奖证明 | 竞赛、荣誉证书复印件 |
| 科研成果 | 论文首页、专利证书 |
| 困难认定结果 | 申请励志奖学金必需 |
| 个人陈述 | 部分奖学金需要 |

---

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「成绩第一就一定有」 | 还要看综合测评、材料完整性 |
| 「不申请也会给」 | 多数需要主动申请 |
| 「国奖和励志可以同时拿」 | 互斥 |
| 「奖学金要交税」 | 按现行规定，奖学金通常免征个人所得税（具体以税务规定为准） |
| 「大三大四再申请」 | 每年都可申请，越早积累越好 |

## 七、可执行清单

### 每学年初

- [ ] 查本年度的奖学金通知（学院官网/公众号）
- [ ] 确认申请截止时间
- [ ] 对照条件，看自己符合哪几项

### 申请时

- [ ] 备齐材料（成绩单、获奖证明、科研成果）
- [ ] 申请励志奖学金的，先确认困难认定已完成
- [ ] 注意不要同时申请互斥的奖项

### 长期

- [ ] 保留所有获奖证书和证明材料
- [ ] 关注本校综合测评办法的计分规则

## 八、一句话记住

**奖学金要申请，国奖和励志互斥，励志必须先做困难认定。**
