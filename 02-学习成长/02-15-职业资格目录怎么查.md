# 职业资格目录怎么查、怎么识别山寨证书

> 一句话概括：判断一张证书有没有用，只需要做一件事——去《国家职业资格目录》里搜它的名字。

**适用人群**：所有被培训机构推销过证书的人；不确定某张证是否被国家认可的人。

> **政策与法律适用范围**
> - 主要依据：人力资源社会保障部《国家职业资格目录》
> - 全国统一：目录由人社部统一发布，全国适用
> - 核查日期：2026-11-05
> - 已知变化：目录经过多次调整，部分职业资格已取消

---

## 一、一句话方法

**打开人社部《国家职业资格目录》，搜你要考的那张证的名字。**

- 搜到了 → 是国家认可的正式职业资格
- 搜不到 → **不是国家职业资格**，它的「权威性」是培训机构自己说的

**这是唯一可靠的方法。**

---

## 二、职业资格分两类

| 类型 | 意思 | 举例 |
| --- | --- | --- |
| **准入类** | 没有证就不能干这行 | 教师资格、法律职业资格、医师资格 |
| **水平评价类** | 证明水平高低，不是硬门槛 | 部分工程技术类、技能人员类 |

**判断含金量最直接的标准**：是不是准入类。

准入类的证，没有就真干不了那个活；水平评价类的证，有更好，但没有也能干。

> 【官方】人力资源社会保障部《国家职业资格目录》（分专业技术人员和技能人员两类）
>
> 【待核实】目录会调整，以人社部公布的最新版本为准。

## 三、三步识别山寨证书

### 第一步：查目录

人社部官网 → 搜「国家职业资格目录」→ 看有没有这个职业。

### 第二步：查发证机构

| 情况 | 判断 |
| --- | --- |
| 发证机构是政府部门或其授权机构 | 正常 |
| 发证机构是「XX 协会」「XX 学会」「XX 研究院」 | **多数不是职业资格** |
| 发证机构听起来像国际组织 | **高度警惕** |

### 第三步：看推销话术

以下是**高危信号**：

| 话术 | 为什么危险 |
| --- | --- |
| 「包过」「保过」 | 正规考试不可能包过 |
| 「交钱就发证」 | 这不是职业资格 |
| 「国家承认、全国通用」 | 只有目录内的才这么说 |
| 「国际认证」「全球通用」 | 多数是营销话术 |
| 「最后一批，政策要收紧」 | 制造紧迫感 |
| 「不考就没机会了」 | 同上 |

---

## 四、常见的「看起来权威但不是职业资格」的证

**注意**：不是所有证书都没用，而是它们**不是国家职业资格**，含金量取决于行业认可度，不能按「国家认证」宣传。

| 类型 | 说明 |
| --- | --- |
| 各类「XX 师」「XX 管理师」培训证书 | 多为培训机构的培训证明 |
| 「国际 XX 认证」 | 发证方多为境外机构，国内无对应资格 |
| 「XX 人才库入库证书」 | 不是资格 |
| 部分行业技能证书 | 行业内有认可，但不是国家职业资格 |

**判断标准回到第一条**：目录里搜不到，就不是。

---

## 五、考证前先问四个问题

| 问题 | 怎么查 |
| --- | --- |
| 它是不是准入类？ | 查目录，看是否「准入」 |
| 目标岗位真的要它吗？ | 看招聘公告的硬性要求 |
| 发证机构是谁？ | 查机构性质 |
| 培训机构的通过率承诺可信吗？ | 不可信，没有任何正规考试能保证通过 |

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「证越多越好」 | 加分型的证性价比低 |
| 「有证书就有工作」 | 准入类才有硬门槛作用 |
| 「国际认证更值钱」 | 多数在国内没有对应资格 |
| 「培训机构说国家认可」 | 以目录为准，不信宣传 |
| 「考了总没坏处」 | 花钱花时间，机会成本真实存在 |

## 七、可执行清单

### 决定考任何证之前

- [ ] 在人社部官网搜《国家职业资格目录》，确认这个职业在不在
- [ ] 确认它是准入类还是水平评价类
- [ ] 找到 3 个目标岗位的招聘公告，看有没有硬性要求

### 遇到推销时

- [ ] 听到「包过」「交钱包发」→ 直接排除
- [ ] 听到「国际认证」→ 查国内有无对应资格
- [ ] 查发证机构是否为政府部门或授权机构

### 已经报了名

- [ ] 保留宣传材料与合同（若发现虚假宣传可投诉）
- [ ] 向当地人社部门咨询该证书性质

---

## 八、一句话记住

**目录里搜不到，就不是国家职业资格。培训机构的宣传不算证据。**
