# 四六级：报名、刷分、成绩怎么用

> 一句话概括：四六级不是「考过就行」——刷分规则、成绩有效期、哪些学校有学位挂钩，比考试本身更影响你怎么安排。

**适用人群**：大一至大四学生；准备刷分的人；不确定自己学校有无学位挂钩的人。

> **核查日期**：2026-11-05
>
> ⏳ 易过时：报名费各省不同且逐年调整；部分高校的学位挂钩政策在陆续取消。

---

## 一、先搞清三件事

| 问题 | 答案 | 影响 |
| --- | --- | --- |
| 我们学校把四级和学位挂钩吗 | **各校不同，且在陆续取消** | 决定你是否必须考 |
| 能考几次 | 在校期间**每年两次**（6 月、12 月） | 决定刷分空间 |
| 成绩记录哪一次 | 多数学校**记录最高分**，部分记录全部 | 影响刷分策略 |

**第一件事必须先查本校学生手册或教务处公告。** 网上「四级不过没学位」的说法在不少学校已经不成立，但仍有学校保留。

---

## 二、报名

### 2.1 谁能报

| 类型 | 通常要求 |
| --- | --- |
| 四级（CET-4） | 全日制在校生，多数学校要求修完相应课程 |
| 六级（CET-6） | **四级达到一定分数**（各校线不同，常见 425 分） |

**注意**：部分学校不允许大一新生报考四级（要求先修完大学英语课程），报名前查本校通知。

### 2.2 报名费

**各省差异极大**，这是最容易被误导的地方：

| 地区 | 四级笔试 | 六级笔试 |
| --- | --- | --- |
| 北京 | 15 元 | 17 元 |
| 上海 | 每人每科次 25 元 | 同左 |
| 部分省份 | 可达 30–50 元 | 略高于四级 |

> 【官方】各省教育考试院年度报名通知
>
> 上表仅为举例，2025 年各省收费标准请以本省教育考试院当年公告为准。口语考试（CET-SET）通常另行收费。

**为什么差这么多**：报名费由各省级考试机构按当地物价核定，没有全国统一标准。

### 2.3 报名时间

每年两次，通常在**3 月和 9 月**前后，具体以本校教务处通知为准。

**错过无法补报**，且部分学校名额有限、先到先得。

## 三、刷分：要不要刷、怎么刷

### 3.1 先判断有没有必要

| 你的情况 | 建议 |
| --- | --- |
| 已过 425 分，不考研不出国 | **不必刷**，够用 |
| 想保研，目标院校有六级分数线 | 查目标院校要求，按线刷 |
| 想进外企/部分岗位卡六级 | 查招聘公告的具体分数要求 |
| 本校记录最高分 | 刷分无风险，可试 |
| 本校记录全部成绩 | 刷分有风险，低分会留在成绩单上 |

**关键**：**先查本校的成绩记载规则**，再决定要不要刷。这一条比什么都重要。

### 3.2 成绩有效期

四六级成绩**长期有效**，没有「两年过期」的说法。

但要注意：部分用人单位或院校会要求「近 X 年内」的成绩，那是**对方的要求**，不是成绩本身过期。

---

## 四、成绩怎么用

| 场景 | 常见要求 |
| --- | --- |
| 毕业/学位 | 部分学校有挂钩，多数已取消【待核实：查本校规定】 |
| 保研 | 部分院校要求六级达到一定分数 |
| 考研 | 多数不要求，但复试可能参考 |
| 求职 | 部分岗位写「六级 425 分以上」 |
| 公务员 | 少数岗位有要求 |

---

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「四级不过就没学位」 | 多数学校已取消挂钩，但仍有保留的，必须查本校 |
| 「成绩两年过期」 | 长期有效，过期是对方单位的要求 |
| 「刷分一定没坏处」 | 记录全部成绩的学校，低分会留下来 |
| 「六级必须先过四级」 | 是，多数学校要求四级达线才能报六级 |
| 「报名费全国统一」 | 各省自行核定，差异可达数倍 |
| 「大四还能随便考」 | 部分学校限制毕业年级报考，查通知 |

## 六、可执行清单

### 大一

- [ ] 查本校四级报考资格（是否限制新生）
- [ ] 查本校学位是否与四级挂钩
- [ ] 查本校成绩记载规则（最高分 / 全部）

### 备考

- [ ] 确认报名时间，别错过（一年两次）
- [ ] 确认报名费与缴费方式

### 决定刷分前

- [ ] 查目标院校/岗位的具体分数要求
- [ ] **确认本校记录最高分还是全部成绩**

---

## 七、一句话记住

**先查本校三件事：能不能报、学位挂不挂钩、成绩记最高还是记全部。这三条决定了你要不要刷分。**
