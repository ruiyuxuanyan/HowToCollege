# 绩点怎么算、怎么影响保研出国求职

> 一句话概括：绩点是大学的硬通货，但算法、权重和用途各校都不一样。

**适用人群**：全体在校生，尤其大一大二。

> **政策适用范围**
> - 全国统一：无全国统一绩点算法
> - 地方/学校执行：**绩点公式、挂科后果、学位授予条件全部由各校规定**
> - 核查日期：2026-11-07

---

## 一、绩点怎么算（通用原理）

核心是**学分加权**：

```
绩点 = Σ(单科绩点 × 该科学分) ÷ Σ学分
```

也就是说，**学分高的课对绩点影响大**。

### 百分制 → 绩点的常见换算（各校不同）

| 百分制 | 常见 4.0 制 | 常见 5.0 制 |
| --- | --- | --- |
| 90–100 | 4.0 | 4.0–5.0 |
| 80–89 | 3.0–3.9 | 3.0–3.9 |
| 70–79 | 2.0–2.9 | 2.0–2.9 |
| 60–69 | 1.0–1.9 | 1.0–1.9 |
| <60 | 0 | 0 |

⚠️ **上表只是示意。各校换算表差异很大**，有的学校 85 分就是 4.0，有的要 90 分。**查本校学生手册。**

---

## 二、绩点的四个用途

| 用途 | 影响方式 | 重要程度 |
| --- | --- | --- |
| **保研（推免）** | 通常是最核心指标，按加权成绩排名 | 极高 |
| 出国申请 | 换算成 GPA，部分学校看专业课 GPA | 高 |
| 求职（校招） | 部分企业设门槛（如 GPA 3.0 以上） | 中 |
| 校内评优 | 奖学金、荣誉称号的评选基础 | 中高 |

**注意**：不同用途看的可能是**不同的绩点**（总绩点 vs 专业课绩点 vs 最近两学年绩点）。查具体要求。

---

## 三、挂科的连锁后果（重点）

挂科不只是「补考过了就行」。

| 后果 | 说明 |
| --- | --- |
| 绩点下降 | 挂科通常记 0 分，严重拉低平均 |
| 补考/重修占时间 | 可能与其他课冲突 |
| **影响保研资格** | 多数学校规定有挂科记录即失去推免资格 |
| 影响奖学金 | 当年评定受影响 |
| **可能影响学位** | 部分学校有「挂科超过 X 门不授学位」的规定 |

⚠️ **「挂科超过 X 门不授学位」这类条款各校不同**，必须查本校学籍管理规定。

---

## 四、绩点低怎么办

如果你已经大二大三，绩点不理想：

| 路径 | 做法 |
| --- | --- |
| **后期拉分** | 后面学期选给分好的课，重点提升（但要看学校是否允许刷分） |
| **专业课绩点** | 部分出国申请看专业课 GPA，可单独提升 |
| **其他维度补** | 科研、竞赛、实习、作品集 |
| **调整目标** | 如果保研无望，转向考研或就业 |

**现实提醒**：保研通常看前五或前六学期，大一大二落下就很难追。**尽早查清本校的推免计算方式。**

---

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「跨校绩点可以比较」 | 算法不同，不能直接比 |
| 「绩点不重要」 | 对保研是决定性的 |
| 「重修一定能刷高」 | 部分学校限制刷分，或成绩单保留原分 |
| 「挂科补考过了没影响」 | 保研资格、学位可能仍受影响 |
| 「选修课随便上」 | 选修课也算进加权绩点 |

## 六、可执行清单

### 大一就要做

- [ ] 查本校**绩点计算公式**（学生手册）
- [ ] 查本校**挂科后果**（补考/重修如何记分）
- [ ] 查本校**学位授予条件**（有无挂科门数限制）
- [ ] 查本校**推免办法**（绩点计算范围、是否含选修课）

### 每学期

- [ ] 期末后核对成绩
- [ ] 有疑问的成绩及时申请复核

### 如果要保研

- [ ] 大一就开始维护绩点
- [ ] 关注是否有挂科记录
