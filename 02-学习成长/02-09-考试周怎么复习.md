# 考试周怎么复习

> 一句话概括：复习方法有实证研究支撑，不是玄学——但有效的方法往往感觉更难受。

**适用人群**：正在准备期末、感觉「看了很多遍还是记不住」的大学生；习惯考前通宵突击的人；想找一套能重复使用的方法而不是一次性技巧的人。

> **核查日期**：2026-11-07

## 一、一个反直觉的起点：感觉学会了 ≠ 学会了

认知心理学里有一个稳定的现象：**让你感觉流畅的学习方式，往往让你忘得更快**。

反复阅读一段材料，第二遍会明显更快、更顺——这种「流畅感」被误当成「掌握了」。而真正能提升长期记忆的，是那些**当下更费劲、感觉更差**的方法。

Bjork 把这类方法称为「合意困难」（desirable difficulties）：短期表现变差，长期保持变好。【经验】这一框架在认知心理学中被广泛采用。

**所以第一个判断标准是**：如果一个复习方法让你很舒服，它大概率低效；如果你在自测时频繁答错、很挫败，那可能正在有效学习。

## 二、三个有研究支持的方法

### 2.1 主动回忆（retrieval practice）：最有效的一条

**做什么**：合上书，凭记忆写出/说出内容，然后再对照检查。而不是一遍遍重读。

**证据**：Roediger 与 Karpicke 的实验让被试学习短文，一组反复阅读，一组读一遍后反复自测。**在 5 分钟后的测验中，反复阅读组表现更好；但在一周后的测验中，自测组显著优于反复阅读组。**【实证】Roediger & Karpicke, 2006, *Psychological Science*。

Karpicke 与 Blunt 后来比较了「提取练习」与「概念图式精细加工」，发现提取练习在后续测验中表现更好，且被试**自己预测**的效果排序与实际相反。【实证】Karpicke & Blunt, 2011, *Science*。

**怎么用在考试周**：

| 低效做法 | 换成 |
| --- | --- |
| 把笔记再读一遍 | 合上笔记，在白纸上默写这一章的框架 |
| 看老师给的例题和答案 | 遮住答案自己解，解完再对照 |
| 反复看 PPT | 把每页标题变成一个问题，自问自答 |
| 划重点 | 把划过的重点变成填空题自测 |

**关键**：自测之后一定要**核对答案**。只测不核对，错误会被固化。

### 2.2 分散练习（spacing）：不要一次学完

**做什么**：把同样的总时长拆成多次，中间隔开。而不是考前一晚连学 6 小时。

**证据**：Cepeda 等人对大量分散练习实验做了定量综述（meta 分析），结论是**分散练习在言语回忆任务上稳定优于集中练习**，且最佳间隔与需要保持的时间长度有关——保持期越长，间隔应越长。【实证】Cepeda et al., 2006, *Psychological Bulletin*。

**怎么用在考试周**：

| 考试时间 | 建议节奏 |
| --- | --- |
| 距考试 2 周以上 | 同一门课每周 2—3 次，每次 1 小时，而不是攒到周末 |
| 距考试 1 周 | 每门课至少接触 4 次，间隔 1—2 天 |
| 距考试 3 天 | 仍要分次：今天、明天、考前各一次 |
| 考前一夜 | 只做轻量回顾与自测，不通宵学新内容 |

**注意**：分散练习的前提是**总量不变**。把 6 小时拆成 3 次 2 小时，不是变成 3 次 6 小时。

### 2.3 交错练习（interleaving）：混合不同题型

**做什么**：把不同类型的题目混在一起练，而不是一次只练一种题型。

**证据**：Rohrer 与 Taylor 让被试练习数学题，一组按题型分块练习（AAA-BBB-CCC），一组交错练习（ABC-ABC）。**交错组在后续测验中表现更好**，尽管练习过程中错误更多、感觉更差。【实证】Rohrer & Taylor, 2007, *Instructional Science*。

**怎么用在考试周**：
- 不要把「第一章的题全做完再做第二章」，改成每章抽几题混着做
- 数学、物理、会计这类需要「判断这是哪类问题」的科目，交错练习收益最大
- 纯记忆类科目（名词解释、法条）收益较小，仍是分散 + 自测为主

## 三、三个没有证据支持的方法

### 3.1 划重点与重读

Dunlosky 等人系统评估了十种常用学习技巧，**重读（rereading）与划重点（highlighting）被评为「效用低」**，而练习性测试（practice testing）与分散练习被评为「效用高」。【实证】Dunlosky et al., 2013, *Psychological Science in the Public Interest*。

划重点的问题在于：它让你在**识别**层面产生熟悉感，但考试要求的是**提取**。看着划过的句子觉得「这个我知道」，合上书却写不出来。

**替代方案**：划完之后，把划过的地方变成问题，自测。

### 3.2 「学习风格」：视觉型 / 听觉型 / 动觉型

这是流传最广、也最没有证据的说法之一。

Pashler 等人系统检视了学习风格的研究，结论是：**几乎没有严格设计的实验支持「按学生的学习风格匹配教学方式能提升学习效果」这一「匹配假说」（meshing hypothesis）**。他们指出，支持该假说的证据来自使用不当的研究设计。【实证】Pashler, McDaniel, Rohrer & Bjork, 2008, *Psychological Science in the Public Interest*。

**实际意义**：不要因为「我是视觉型」就只看图不看文字，也不要相信卖课机构用这套话术衍生的「专属学习方案」。真正有效的是**不管什么风格，都用自测和分散**。

### 3.3 通宵突击

通宵的直接问题不是「伤身体」这种笼统说法，而是三件具体的事：

1. **睡眠参与记忆巩固**。学习后睡眠不足会削弱长期保持。【实证】这是记忆研究中较一致的结论（见参考资料中 Bjork 的研究综述）。
2. **次日的提取能力下降**。考场上需要的是在工作记忆里调取信息，睡眠剥夺会直接影响这一过程。
3. **考前突击只能支撑到第二天**。如果你后面还有三门考试，第一门透支的代价会转移到后面。

**如果已经欠了很多**：宁可睡 4 小时再起来看，也不要熬到天亮直接进考场。【经验】

## 四、考试周的实际排期

用倒推法，不要用「今天想复习哪门」。

### 步骤

1. **列出所有考试**：科目、日期、时间、地点、形式（开卷/闭卷/论文/机考）
2. **给每门课估工作量**：不是「几章」，而是「几小时能过一遍 + 几小时自测」
3. **按考试日期倒排**：越早考的越早开始，但**不要把所有时间给第一门**
4. **每天固定留 1 小时给「后面的科目」**，防止第一门吃掉全部时间
5. **每门课至少安排 3 次接触**（对应分散练习）

### 示例表格（自行填写）

| 科目 | 考试日 | 需投入 | 第 1 次 | 第 2 次 | 第 3 次 | 自测安排 |
| --- | --- | --- | --- | --- | --- | --- |
| 科目 A | 周一 | 8h | 周三 | 周五 | 周日 | 周日整套模拟 |
| 科目 B | 周四 | 6h | 周四 | 周六 | 周二 | 周二自测 |

**一个反直觉的建议**：把**最难/最没把握**的科目放在每天精力最好的时段，而不是放在最后。人在考试周后期会疲惫，那时候啃硬骨头效率最低。

## 五、往年卷怎么用

往年卷是有效的工具，但有两个边界。

**边界一：学校是否允许。** 部分学校/学院明确禁止传播往年试题，或只在课程平台提供。**用之前确认来源合法**——如果是老师上传到课程平台的，可以用；如果是通过非公开渠道拿到的，风险在你身上。【待核实】各校规定不同，见本校考试管理办法。

**边界二：怎么用。** 押题式背答案风险很高：

| 用法 | 效果 |
| --- | --- |
| 背往年答案 | 题型一变就失效；且易被认定违规 |
| 限时整套模拟 | **最有效**：同时练提取、时间分配、题型判断 |
| 分析考点分布 | 有效：看哪几章反复出现，但不等于只学那几章 |
| 只看不做 | 低效，等同于重读 |

**建议**：把往年卷当**模拟考试**用——关书、限时、写完再批改。这样一份卷子相当于一次高质量的主动回忆训练。

## 六、考场上

| 情况 | 做法 |
| --- | --- |
| 拿到卷子先做什么 | 花 2 分钟通览全卷，标出「会/不会/不确定」 |
| 时间分配 | 按分值分配，不按题号顺序硬啃 |
| 卡住的题 | 超过预定时间 1.5 倍就跳过，做记号，回头再攻 |
| 先易后难 | 先拿稳的分，建立节奏，也为后面的题留出心理空间 |
| 主观题 | 先列要点再展开，阅卷看的是要点命中 |
| 最后 10 分钟 | 检查姓名学号、答题卡填涂、有没有漏题 |

**【经验】** 关于「第一直觉要不要改」：研究结论并不统一，不建议作为策略。真正可靠的是**只在能找到明确理由时才改**，不要因为「感觉不对」就改。

## 七、作弊的代价

这一节不写方法，只写后果，因为后果与复习方法完全不成比例。

学术不端的认定与处分见 02-10。这里只说一句：**考试作弊在很多学校是记过以上处分，可能影响学位授予、保研资格与档案记录，且可追溯。** 用一次考试的分数去换这些，任何计算都不成立。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 看得遍数越多记得越牢 | 重读被评为低效用；自测的长期效果显著更好 |
| 划重点就等于复习 | 划重点只产生熟悉感，不产生提取能力 |
| 我是视觉型，只看图 | 「学习风格匹配」缺乏实证支持 |
| 通宵一晚能顶一周 | 睡眠剥夺削弱记忆巩固与次日提取，且透支后续科目 |
| 分散练习就是拖时间 | 总量不变、拆成多次，效率更高 |
| 往年卷背答案最保险 | 题型一变即失效，且有违规风险；当模拟卷用才有效 |
| 自测错太多说明没学好 | 恰恰说明在有效学习；错题要核对后重测 |
| 考前一晚该学新章节 | 该做轻量回顾与自测，新内容来不及巩固 |

## 可执行清单

### 考前 2 周

- [ ] 列出全部考试的时间、形式、范围
- [ ] 给每门课估算投入小时数
- [ ] 排出「每门课至少 3 次接触」的时间表
- [ ] 把最难科目排进每天精力最好的时段

### 每天

- [ ] 先自测昨天学的内容（10 分钟），再看新内容
- [ ] 学完一节，合上书默写框架
- [ ] 划过的重点当天转成问题
- [ ] 睡前用 5 分钟回忆当天三个要点

### 考前 3 天

- [ ] 做一套限时模拟（往年卷或自编题）
- [ ] 批改后只复习错的部分，不重看全部
- [ ] 停止学习新章节
- [ ] 保证睡眠，不熬到凌晨

### 考场

- [ ] 带齐证件与文具，提前确认考场
- [ ] 通览全卷，标出难题
- [ ] 按分值分配时间，卡住的先跳过
- [ ] 最后 10 分钟检查填涂与漏题

## 一句话记住

**合上书能写出来的，才是你会的——所以复习的核心动作是自测，不是重读；而自测必须分散到多天，不能攒到考前一夜。**
