# 辅修与双学位：值不值得、学历怎么认定

> 一句话概括：辅修证、双学位、第二学士学位是三件不同的事，别被招生话术混为一谈。

**适用人群**：想跨专业学习但不想/不能转专业的大一、大二学生；正在被机构推销「双学位项目」的人；想靠第二学位换专业方向的人。

> **政策适用范围**
> - 主要依据：国务院学位委员会《学士学位授权与授予管理办法》（学位〔2019〕20 号）；教育部办公厅《关于在普通高校继续开展第二学士学位教育的通知》（教高厅〔2020〕9 号）；各校辅修/双学位实施办法
> - 全国统一 / 地方执行：**学位授予的类别与证书形式由国家规定，开设专业、学分要求、收费标准由各校自行规定**
> - 核查日期：2026-11-05
> - 已知变化：学位〔2019〕20 号规范了「辅修学士学位」「双学士学位」的名称与证书形式，各校已按此调整

---

## 一、先分清三个概念（本篇最重要的一节）

这三个词在日常口语里被混用，但**在法律和学历认定上完全不同**。分不清，就会花钱买到一个自己以为很有用的东西。

| 维度 | 辅修专业 | 双学士学位 | 第二学士学位 |
| --- | --- | --- | --- |
| **是什么** | 在主修专业之外修读另一专业的课程 | 同时修读两个跨学科门类的本科专业 | 本科毕业后再读两年的独立学位教育 |
| **招生方式** | 校内报名，通常看绩点 | 校内选拔或高考招生（部分高校） | 独立招生，需报名审核/考试 |
| **学分要求** | 通常 25—40 学分左右 | 需完成两个专业的全部培养要求 | 按第二学士学位专业培养方案，学制 2 年 |
| **拿到什么** | 辅修证书（非学位） | 一本学位证书，注明授予两个学士学位 | 第二学士学位证书（独立证书） |
| **学信网能否查到** | 一般可查辅修记录，但不是学历 | 可查 | 可查，属完整学历 |
| **社会认定** | 作为能力证明，不是学历 | 本科层次的双学位 | 按本科后教育层次认定，部分单位按研究生同等待遇 |

【法规】学位〔2019〕20 号明确了「辅修学士学位」与「双学士学位」的规范：辅修学士学位在主修学士学位证书中予以注明，**不单独发放学位证书**；双学士学位只发放一本学位证书，所授两个学位在证书中予以注明。

**这句话的实际含义**：辅修不会让你多一张学位证。它证明你系统学过，但不改变你的学历层次。

## 二、第二学士学位是另一回事

第二学士学位不是「辅修的升级版」，它是**独立的教育形式**。

【法规】教高厅〔2020〕9 号重启并规范了第二学士学位教育，核心要点：

| 要点 | 内容 |
| --- | --- |
| 性质 | 大学本科后教育，属于本科层次，全日制脱产学习，学制 2 年 |
| 招生对象 | 当年普通高校本科毕业并获得学士学位的应届毕业生；以及近三年本科毕业、获学士学位、目前未就业的往届生 |
| 专业限制 | 通常要求报考与原本科专业**分属不同学科门类**，或属同一门类但不同专业类 |
| 毕业 | 完成培养方案、通过论文答辩，颁发第二学士学位证书 |
| 招生方式 | 高校自主招生，公布招生简章，一般有考核 |

**为什么它值得单独看**：如果你本科专业彻底不合适、又不想考研，第二学士学位是**唯一能在两年内拿到另一个完整本科学历**的路径。【法规】

但要注意限制：**必须已经本科毕业**才有资格报，在校生不能边读边报。

## 三、时间与经济成本

这是决定「值不值」的核心，先算账再谈价值。

| 成本项 | 辅修 | 双学士学位 | 第二学士学位 |
| --- | --- | --- | --- |
| 额外时间 | 周末/晚上上课，或与主修课程并行 | 通常需延长或高密度排课 | 全日制 2 年 |
| 额外学分 | 25—40 学分区间 | 两个专业的全部要求 | 按第二学位培养方案 |
| 费用 | 按学分收费，各校标准不同【待核实】 | 同左 | 按第二学士学位专业学费标准【待核实】 |
| **机会成本** | 挤占实习、竞赛、考研复习时间 | 同上，且更重 | 放弃两年工作收入与工作经验 |
| 能否同时考研 | 可以，但备考时间被压缩 | 较难 | 不能，脱产在读 |

**费用一定要问清三件事**：按学分还是按学年收费、挂科是否重交学费、中途退出能否退费。这三条各校规定不同，且往往写在报名须知的小字里。【待核实】

## 四、什么情况下值得读

| 情况 | 判断 | 理由 |
| --- | --- | --- |
| 目标岗位**硬性要求**某专业背景（如部分财务、法律、计算机岗位） | 值得 | 学历/专业是筛选门槛，跨不过去连面试都没有 |
| 想跨专业考研，需要先补基础 | 值得（选辅修） | 有成绩单能证明你学过，复试时是实打实的优势 |
| 考公岗位限专业，你的专业不在目录里 | 值得，但要先查 | 先确认目标岗位是否认可辅修/第二学位（见下节） |
| 只是想「多学点东西」 | 不值得 | 慕课、旁听、自学都能达到，不用付学分费 |
| 主修专业已经吃力 | 不值得 | 本专业绩点是保研、求职的硬指标，先保住它 |
| 大四才想起来 | 多半来不及 | 学分要求通常无法在一年内完成 |

---

## 五、最有价值的一个判断：先查「用途是否被承认」

辅修和第二学位不是万能通行证。真正决定价值的，是你想用它做什么，**以及那个场景认不认**。

| 用途 | 是否承认 | 怎么确认 |
| --- | --- | --- |
| 考研复试 | 一般认，作为学习能力证明 | 看目标院校招生简章，多数不禁止 |
| 考公/事业编岗位「专业要求」 | **不一定**，多数以主修专业（学历证书上的专业）为准 | 查当年招考公告的「专业目录」说明，或打招录单位电话 |
| 企业校招简历筛选 | 认，作为加分项 | 无统一标准，看岗位 JD |
| 教师资格、法考等执业资格报考 | 看报考条件，通常要求「相应学历」 | 查该项考试的官方报考公告 |
| 出国申请 | 认，但需成绩单与证书 | 目标院校 admission 要求，需翻译公证 |

【待核实】**考公这一条尤其要提前查。** 多数公务员招考的「专业」以学历证书载明的专业为准，辅修专业通常不能用于报考限专业的岗位；第二学士学位因为是独立学历，认定情况又不同。各省、各年份口径可能变化，**务必以当年招考公告为准，并直接向招录单位确认**。

## 六、报名流程与时间

通用流程（各校不同，以本校教务处/院系通知为准）：

1. **关注通知**：多数学校在大一下或大二上组织辅修报名，教务处官网发布
2. **确认资格**：通常要求主修专业已修课程无不及格、绩点达到一定水平
3. **提交申请**：填表、选专业、缴费
4. **开课**：多在周末或晚间，与主修课程并行
5. **修满学分**：完成全部课程与考核
6. **申请证书**：毕业时统一办理，辅修信息记入主修学位证书或单独发辅修证书

**关键提醒**：辅修的课程如果和主修冲突，通常不能免修、不能替代主修学分。**辅修学分不计入主修毕业学分要求**，这是两套账。

## 七、被机构推销时怎么判断

市面上有大量打着「双学位」「国际学位」旗号的付费项目，和校内的辅修完全不是一回事。

| 信号 | 判断 |
| --- | --- |
| 说「不用考试，交钱就能读」 | 不是正规学历教育 |
| 说「学信网可查」但给不出证书样本 | 要求看往届学员的学信网截图与证书编号 |
| 发证机构是「XX 协会」「XX 研究院」 | 不是学位授予单位，学位只能由高校授予【法规】 |
| 承诺「等同研究生待遇」 | 需要明确依据，口头承诺无效 |
| 说「名额只剩最后 3 个」 | 营销话术，正规招生有明确报名期 |

【法规】学位只能由经批准有权授予学位的高等学校和科学研究机构授予。**任何非高校机构发的「学位」，都不能作为学历使用。**

判断方法：拿到机构名称后，去**中国学位与研究生教育信息网（学位网）**或**学信网**查该机构是否在学位授予单位名单内；查不到，就直接放弃。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 辅修能拿到第二个学位证 | 辅修学士学位在主修学位证书中注明，**不单独发证**【法规】 |
| 双学位等于两个学历 | 双学士学位只发一本证书，注明两个学位，学历层次仍是本科 |
| 辅修证能当学历用 | 辅修是学习经历证明，不是学历；考公限专业岗位多数不认 |
| 第二学士学位可以边读本科边报 | 必须已本科毕业并获学士学位才具备报考资格 |
| 辅修可以替代主修的挂科 | 两套学分账，通常不能互抵 |
| 多一个证总没坏处 | 有成本：学分费、时间、挤占实习与备考，本专业绩点下滑的代价更大 |
| 国际双学位项目都不可信 | 经教育部审批的中外合作办学项目是正规的，**关键是在教育部涉外监管信息网能查到** |

## 可执行清单

### 决定前

- [ ] 明确用途：考研 / 考公 / 求职 / 纯兴趣（决定要不要花这笔钱）
- [ ] 如果是考公，先查近两年目标岗位的「专业目录」说明
- [ ] 算清额外学分与费用，问清退费与补考规则
- [ ] 评估本专业绩点是否还有余力（本专业绩点优先级更高）

### 报名时

- [ ] 索要本校《辅修/双学位实施办法》原文，而不是听宣讲
- [ ] 确认证书记载形式（单独发证 / 在主修证上注明 / 只在学信网有辅修记录）
- [ ] 确认开课时间是否与主修课程冲突

### 就读期间

- [ ] 每学期核对已修辅修学分，避免毕业前才发现差学分
- [ ] 若影响主修成绩，及时止损退出，不要硬撑

### 如果是机构项目

- [ ] 在学信网 / 学位网 / 教育部涉外监管信息网查发证机构
- [ ] 要求看往届学员的真实证书编号
- [ ] 任何「包过」「包认证」的承诺，一律视为虚假宣传

## 一句话记住

**辅修是「学过」，双学士是「一本证上写两个学位」，第二学士学位才是「另一个学历」——先想清你要哪个，再交钱。**
