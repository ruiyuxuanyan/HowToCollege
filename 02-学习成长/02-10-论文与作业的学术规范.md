# 论文与作业的学术规范

> 一句话概括：抄袭的判定比大多数人以为的宽，AI 的边界比大多数人以为的窄。

**适用人群**：全体在校生；写课程论文、毕业论文的人。

> **政策适用范围**
> - 主要依据：《高等学校预防与处理学术不端行为办法》（教育部令第 40 号）；《中华人民共和国学位法》
> - 全国统一：学术不端的认定与处理程序有全国性规范
> - 地方执行：**各校的学术规范细则、AI 使用规定不同且仍在变化**
> - 核查日期：2026-11-07

---

## 一、什么算学术不端

| 类型 | 具体表现 |
| --- | --- |
| **抄袭** | 直接复制；**改写但不标注出处**；翻译后使用 |
| 伪造 | 编造数据、实验结果 |
| 篡改 | 修改数据使结论符合预期 |
| 不当署名 | 未参与者署名；代写代投 |
| 一稿多投 | 同一成果投多个期刊 |
| **代写代做** | 请人代写论文、代做毕设 |
| AI 相关 | 见第四节 |

### 最容易踩的一条：改写不标注

**很多人以为「换个说法就不算抄」，这是错的。**

用自己的话重述他人观点，**仍然需要标注出处**。不标注 = 抄袭。

---

## 二、正确引用怎么做

| 方式 | 做法 |
| --- | --- |
| **直接引用** | 加引号 + 标注出处（含页码，视格式要求） |
| **转述（改写）** | 用自己话重述 + **标注出处** |
| 参考文献 | 按学校/期刊要求的格式列出 |

**记住**：引用不是「承认自己不行」，是学术写作的基本礼貌与规范。

---

## 三、AI 工具的使用边界（当前最需要讲清）

### 3.1 各校规定的三种典型态度

| 态度 | 典型要求 |
| --- | --- |
| **禁止** | 任何 AI 生成内容不得用于作业/论文 |
| **允许但需申报** | 可以使用，但必须声明使用了什么、用在哪 |
| **允许但有范围限制** | 允许辅助理解、检查语法，不允许生成正文 |

⚠️ **各校规定不同，且仍在快速变化。必须以本校最新规定为准。**

### 3.2 风险分级

| 用法 | 风险 |
| --- | --- |
| 整段生成直接提交 | **极高** |
| 生成后改写但不申报 | 高（视学校规定） |
| **伪造参考文献**（AI 编造不存在的文献） | **极高**，可能构成学术不端 |
| 辅助理解概念 | 低 |
| 检查语法、翻译 | 低（但仍需看学校是否要求申报） |

### 3.3 AI 会编造引用——这是学生最容易踩的坑

大语言模型会生成**看起来格式正确、实际不存在**的文献（作者、期刊、DOI 都可能是编的）。

**如果你把 AI 生成的参考文献直接放进论文，可能被认定为「伪造参考文献」。**

**做法**：AI 给的每一条文献，都要自己去数据库验证是否真实存在。

## 四、学位撤销：可追溯

《中华人民共和国学位法》与相关规定明确，学位授予后，如发现存在学术不端等情形，**可以撤销已授予的学位**。

**这意味着**：不是「毕业了就没事了」。论文抽检、后续举报都可能导致追溯。

---

## 五、被认定学术不端后的处理

| 阶段 | 内容 |
| --- | --- |
| 调查 | 学校学术委员会/相关部门调查 |
| 告知 | 告知你的事实、理由、依据 |
| **陈述申辩** | 你有权说明情况 |
| 处理决定 | 警告、记过、取消学位等 |
| 申诉 | 可按学校程序申诉 |

**「陈述申辩」是你的权利**，不要放弃。

---

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「改几个字就不算抄」 | 改写不标注仍属抄袭 |
| 「AI 写的查不出来」 | AI 检测工具在进步；且引用造假明显 |
| 「本科论文没人看」 | 抽检存在，学位可被撤销 |
| 「引用太多显得没水平」 | 引用规范是加分项 |
| 「毕设代做不会被发现」 | 答辩追问、查重、抽检都可能发现 |

---

## 七、可执行清单（提交前自查）

- [ ] 所有引用都有出处标注
- [ ] 改写的段落也标了出处
- [ ] 参考文献逐条核实过真实性（不是 AI 编的）
- [ ] 使用了 AI 的，按学校规定申报
- [ ] 查重通过（重复率在学校要求范围内）
- [ ] 没有虚构数据
- [ ] 署名符合规范

---

## 八、一句话记住

**引用就标出处，改写也要标。AI 给的文献必须自己核实——它经常编造。**
