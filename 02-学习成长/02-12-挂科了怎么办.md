# 挂科了怎么办

> 一句话概括：挂科不是世界末日，但它是一串连锁反应的起点，而且有些链条一断就接不回来。

**适用人群**：刚挂科的人、担心要挂的人、以及想把挂科后果算清楚的人。

> **政策适用范围**
> - 主要依据：《普通高等学校学生管理规定》（教育部令第 41 号）第十八条、第三十二条、第三十三条
> - 全国统一：成绩记载要**如实标注**补考重修；毕业与结业的条件
> - 各校自定：补考怎么记分、重修是否覆盖、能否刷分、挂几门不授学位
> - 核查日期：2026-11-05

---

## 一、先看全国统一的这条：补考成绩必须标注

很多人以为「补考过了就和没挂一样」。看条文：

> 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第十八条：学校应当健全学生学业成绩和学籍档案管理制度，真实、完整地记载、出具学生学业成绩，**对通过补考、重修获得的成绩，应当予以标注**。

**这是全国性的硬规定，不是某校特色。** 也就是说，你的成绩单上凡是补考、重修得来的分数，都会带标记。想「洗白」成一次性通过，制度上就不允许。

但要注意区分两件事：

| 事项 | 谁定 |
| --- | --- |
| **是否标注**补考/重修 | 全国统一，**必须标注** |
| 标注成什么样（记 60 分？记实际分？覆盖原分？） | **各校自定** |

所以「补考过了绩点会不会回升」没有统一答案，必须查本校《成绩管理办法》。

---

## 二、挂科的四种后果，按严重度排

| 后果 | 严重程度 | 能否补救 |
| --- | --- | --- |
| 补考/重修占用时间 | 低 | — |
| 绩点下降 | 中 | 部分可（看学校是否允许刷分） |
| 影响当年奖学金、评优 | 中 | 当年不行，次年可 |
| **失去保研（推免）资格** | 高 | **通常不能** |
| **可能影响学位授予** | 极高 | 看本校规定 |

**真正要命的是后两条。** 前三条是「难受」，后两条是「关上一扇门」。

---

## 三、补考 vs 重修：差别比你想的大

| 项目 | 补考 | 重修 |
| --- | --- | --- |
| 时间 | 通常下学期初 | 下一学年跟班重上，或单独开班 |
| 机会成本 | 低（占用假期或开学初） | 高（占一学期课时，可能冲突） |
| 成绩记载 | 多数记 60 分或标注「补考」 | **各校不同**：有的覆盖原分，有的取高分，有的与原分并存 |
| 是否影响绩点 | 通常按补考成绩计入 | 视学校规定 |
| 对保研的影响 | 有挂科记录即可能失去资格 | 同上，且重修记录也在 |

⚠️ **补考和重修的具体规则，各校差异极大**，必须查本校《学籍管理规定》和《成绩管理办法》。这两份文件通常在学校教务处网站「规章制度」栏目，关键词搜「补考」「重修」「成绩」。

---

## 四、学分不够会不会延毕：会，而且这是最实际的风险

《普通高等学校学生管理规定》第三十二条写的是「在**学校规定学习年限内**，修完教育教学计划规定内容，成绩合格，达到学校毕业要求的，学校应当准予毕业」。

反过来读：没修完、没合格，就不能毕业。

第三十三条给了另一条出路：

> 【法规】学生在学校规定学习年限内，修完教育教学计划规定内容，但未达到学校毕业要求的，学校可以准予**结业**，发给**结业证书**。结业后是否可以补考、重修或者补作毕业设计、论文、答辩，以及是否颁发毕业证书、学位证书，由学校规定。

**「结业」和「毕业」差一个字，待遇差很多**：结业证不是毕业证，考研、考公、落户、入职背调都可能卡住。而且结业后能不能换发毕业证，**由学校规定**——有的学校给一次机会，有的不给。

**预防的方法只有一个**：每学期对着培养方案核对已修学分，别到最后一学期才发现缺。

## 五、缓考：一个被低估的正当程序

因病因事无法参加考试，可以申请**缓考**，而不是硬着头皮缺考。

| 情况 | 处理 |
| --- | --- |
| 生病（有医院证明） | 申请缓考 |
| 直系亲属重大变故 | 申请缓考 |
| 无故缺考 | 通常按零分计，且可能记违纪 |

**缓考优于缺考，性质完全不同**：缓考是保留正常考试机会（按正常考试成绩记载），缺考往往直接算挂，甚至按旷考处理。

> 【经验】缓考必须**考前**申请。考完再补申请，绝大多数学校不受理——这是最容易踩的坑。

## 六、挂科对五条出路的具体影响

| 你的打算 | 挂科的影响 | 能否补救 |
| --- | --- | --- |
| **保研（推免）** | 多数学校规定有挂科记录即失去推免资格 | **通常不能**，查本校推免办法 |
| **考研** | 不影响报考资格，复试可能被问 | 可解释，影响有限 |
| **就业** | 部分企业看成绩单，多数不深究 | 可补 |
| **出国** | 影响 GPA，部分学校看关键课成绩 | 后期拉分可部分弥补 |
| **拿学位** | 部分学校有「挂科门数/学分超限不授学位」规定 | 查本校学位授予细则 |

**最关键的一句**：如果你还想保研，**挂科这条几乎就是终局**。这也是为什么大一大二不能松——保研看的是前三年，而挂科记录一旦产生就抹不掉（因为第十八条要求如实标注）。

## 七、罕见但存在：作弊的后果比挂科重得多

同一部规章第十八条还有一段：

> 学生严重违反考核纪律或者作弊的，该课程考核成绩记为**无效**，并应视其违纪或者作弊情节，给予相应的**纪律处分**。给予警告、严重警告、记过及留校察看处分的，经教育表现较好，可以对该课程给予补考或者重修机会。

注意两点：

1. **成绩「无效」不等于「不及格」**——是记录作废，性质更严重。
2. **处分后仍可能获得补考/重修机会**，前提是「经教育表现较好」。这句话给了挽救空间，但不保证。

**结论**：宁可挂科，不要作弊。挂科是学业问题，作弊是诚信问题，后者会进档案。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「补考过了就没事了」 | 41 号令要求**如实标注**补考/重修，成绩单上看得出来 |
| 「重修一定能刷高绩点」 | 部分学校限制刷分，或取首次成绩 |
| 「挂科不影响保研」 | 多数学校有挂科即失去推免资格 |
| 「缺考和缓考差不多」 | 完全不同，缓考是正当程序，缺考按零分 |
| 「挂一门无所谓」 | 看本校学位授予细则，有的按门数或学分级联 |
| 「结业证和毕业证差不多」 | 差很多，考研考公落户入职都可能卡 |
| 「考完还能补申请缓考」 | 绝大多数学校要求**考前**申请 |

## 九、可执行清单

### 刚挂科（一周内）

- [ ] 查本校《学籍管理规定》《成绩管理办法》里的补考/重修条款
- [ ] 确认成绩怎么记（补考记 60 还是实际分？重修覆盖还是并存？）
- [ ] 在系统里报名补考或重修，**注意截止日期**
- [ ] 如果打算保研，立刻确认挂科是否已使你失去资格

### 本学期

- [ ] 对着培养方案核一遍已修学分与剩余要求
- [ ] 把剩余课程的考试时间记进日历
- [ ] 有任何不能应考的苗头，**考前**申请缓考

### 长期

- [ ] 查本校学位授予细则里「挂科门数/学分」的阈值
- [ ] 若已影响保研，把精力转到考研或就业，别两头空

---

## 十、一句话记住

**先查规则（补考怎么记分、重修是否覆盖、挂几门不授学位），再决定怎么补。成绩单上补考重修必须标注，这一点全国统一，抹不掉。**

## 参考资料

1. 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第十八条：成绩应真实完整记载，**补考、重修获得的成绩应当予以标注**；作弊成绩记无效并给予纪律处分 [教育部原文](http://www.moe.gov.cn/srcsite/A02/s5911/moe_621/201702/t20170216_296385.html)
2. 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第三十二条：修完规定内容、成绩合格、达到毕业要求的准予毕业
3. 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第三十三条：未达毕业要求可准予**结业**、发结业证书；结业后能否补考重修换发毕业证**由学校规定**
4. 【官方】各高校《学籍管理规定》《成绩管理办法》《学位授予工作细则》（**各校不同**，是本文多数具体规则的真正依据）
5. 【官方】各高校《推荐优秀应届本科毕业生免试攻读研究生工作办法》（保研是否受挂科影响，以此为准）
