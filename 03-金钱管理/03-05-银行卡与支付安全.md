# 银行卡与支付安全：一人多卡清理、帮人过账的法律风险

> 一句话概括：你以为只是「帮个忙」，法律看到的是「为犯罪提供支付结算帮助」。

**适用人群**：所有持有银行卡、微信/支付宝账户的大学生；曾被要求「帮忙收个款」「借张卡走账」的人。

> **本文性质**
>
> 本文是法律与用卡信息整理，**不构成法律意见**。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国反电信网络诈骗法》第三十一条、第三十八条；《中华人民共和国刑法》第二百八十七条之二；中国人民银行「断卡」行动惩戒规定
> - 全国统一：法律条文全国统一；银行的具体风控规则各行不同
> - 核查日期：2026-11-05
>
> ⏳ 易过时：各银行的账户分类规则、限额、开卡要求经常调整。

> **与「帮信罪」一文的分工**：本文讲**日常用卡场景**（哪些请求要拒绝、怎么清理账户）；罪名的构成要件与量刑请看「「帮信罪」离大学生有多近」一文，本文不重复。

## 一、这四种请求，一个都不要答应

先说结论，后面的内容都是解释为什么。

| 请求 | 常见说辞 | 真实用途 |
| --- | --- | --- |
| 借你的卡收一笔钱，马上转走 | 「我卡限额了」「我在外地不方便」 | 你的卡成了赃款中转站 |
| 租/买你的卡 | 「一天 300」「一张卡 500」 | 诈骗团伙需要大量干净的实名账户 |
| 借你的收款码 | 「帮我收一下，给你提成」 | 收款码绑定你的实名，钱进了你的账 |
| 用你身份证注册公司/开对公账户 | 「什么都不用管，给你 2000」 | 对公账户额度高、监管松，是诈骗首选工具 |

**判断标准只有一条**：正常的事，不需要借用别人的身份。凡是需要你出借实名信息的「帮忙」，本质上都是在把风险转移到你身上。

## 二、法律怎么规定的

### 2.1 明确禁止出借

> 第三十一条　任何单位和个人不得非法买卖、出租、出借电话卡、物联网卡、电信线路、短信端口、银行账户、支付账户、互联网账号等，不得提供实名核验帮助；不得假冒他人身份或者虚构代理关系开立上述卡、账户、账号等。
>
> 【法规】《中华人民共和国反电信网络诈骗法》第三十一条，2022 年 9 月 2 日通过

注意这里的范围比很多人想的宽：**不只是银行卡**，还包括电话卡、支付账户（微信支付、支付宝）、互联网账号。

### 2.2 不构成犯罪也会被罚

> 第三十八条　组织、策划、实施、参与电信网络诈骗活动或者为电信网络诈骗活动提供帮助，构成犯罪的，依法追究刑事责任。
>
> 前款行为尚不构成犯罪的，由公安机关处十日以上十五日以下拘留；没收违法所得，处违法所得一倍以上十倍以下罚款，没有违法所得或者违法所得不足一万元的，**处十万元以下罚款**。
>
> 【法规】同上，第三十八条

**十万元以下罚款。** 对比一下：卖一张卡可能赚 300 元。这个比例关系需要说清楚——很多学生以为「最多把赚的钱退回去」，实际罚则是按上限十万元设计的。

### 2.3 构成犯罪的情形

提供支付结算帮助，达到司法解释规定的门槛即可能构成帮助信息网络犯罪活动罪。门槛包括：**为三个以上对象提供帮助**，或**支付结算金额二十万元以上**，或**违法所得一万元以上**。

具体条文与认定标准见「「帮信罪」离大学生有多近」一文第四节，此处不重复。

## 三、5 年金融惩戒意味着什么

即使不被刑事追究，也可能被列入惩戒名单。

> 银行和支付机构对经设区的市级及以上公安机关认定的出租、出借、出售、购买银行账户（含银行卡）或者支付账户的单位和个人及相关组织者……**5 年内暂停其银行账户非柜面业务、支付账户所有业务，并不得为相关个人新开立账户**。
>
> 【官方】中国人民银行安徽省分行《开展「断卡」行动，抵制买卖账户》，2020-12-25

把「非柜面业务全部暂停」翻译成日常场景：

| 平时怎么做 | 惩戒后怎么做 |
| --- | --- |
| 手机银行转账 | 只能去柜台排队 |
| 微信/支付宝付款 | 不能用 |
| 点外卖、打车、网购 | 大部分不能用 |
| 交学费 | 必须去柜台 |
| 收工资 | 只能收现金或柜台取 |
| 办新卡 | 不允许 |

**这一条对生活的影响，往往比很多人想象的大得多。** 而它不需要经过法院判决，公安机关认定后即可实施。

《反电信网络诈骗法》第三十一条第二款同时规定，对认定和措施有异议的**可以提出申诉**，相应主管部门应当建立申诉渠道、信用修复和救济制度。

## 四、一人多卡：为什么要清理，怎么清理

### 4.1 为什么要清理

- 不用的卡可能被遗忘，一旦被冒用你也不知道
- 长期不动的「睡眠账户」更容易被利用
- 部分银行对持卡数量有上限要求
- 账户数量越多，被冒用的概率越高

### 4.2 怎么查自己名下有多少卡

| 查什么 | 渠道 | 说明 |
| --- | --- | --- |
| 名下电话卡数量 | 工信部「一证通查」 | 官方服务，可查名下有几张手机卡 |
| 名下银行账户 | 各银行 App / 柜台 | 部分银行支持「一键查卡」类服务 |
| 是否被注册为公司法人/股东 | 国家企业信用信息公示系统 `www.gsxt.gov.cn` | 输入自己姓名查询 |
| 个人信用报告 | 中国人民银行征信中心 | 可查异常查询记录和贷款记录 |

### 4.3 清理动作

1. **注销长期不用的卡**：本人带身份证到柜台办理
2. **注销不用的电话卡**：运营商营业厅办理
3. **关闭小额免密支付**：在支付平台设置里关掉
4. **关闭境外交易**（如无需求）：部分银行 App 可自助设置
5. **检查「睡眠账户」**：长期无交易的账户，联系银行确认状态

## 五、日常用卡的六个习惯

| 习惯 | 为什么 |
| --- | --- |
| 密码不用生日、手机号、身份证后六位 | 这些信息一旦泄露，等于没有密码 |
| 不同平台用不同密码 | 一处泄露不至于全线沦陷 |
| 开启交易提醒 | 异常交易能第一时间发现 |
| 不把卡号、CVV、有效期发给任何人 | 有这三样就能盗刷（尤其境外网站） |
| 不把身份证照片存在手机里 | 手机丢失即全套信息泄露 |
| 公共 WiFi 下不登录网银 | 存在被劫持风险 |

## 六、已经借出去了，怎么办

按顺序处理：

1. **立即挂失或冻结**涉事银行卡、支付账户
2. **保存所有记录**（聊天记录、转账截图、对方身份信息）——**不要删除**
3. **查名下账户**，确认有没有其他被冒用的卡
4. **咨询律师**，再决定是否主动向公安机关说明
5. **告诉家人**

关于第 4 步为什么不能自己决定：主动说明在量刑上是法定从轻情节，但具体怎么说明、说什么、什么时机，属于法律策略问题。各地检察机关的从宽标准也不一致。这部分不能照搬网上的说法。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「我卡里没钱，没关系」 | 关键不是余额，是流经这张卡的**涉案资金流水** |
| 「借一下就还，不算出借」 | 一次性借用也属于「出借」 |
| 「我只是帮忙，没收钱」 | 《反电信网络诈骗法》禁止的是行为本身，不以获利为前提 |
| 「微信收款码不是银行账户」 | 支付账户明确在法条列举范围内 |
| 「不用了放着也不影响」 | 睡眠账户被冒用的风险更高 |

## 八、可执行清单

### 本周完成

- [ ] 用「一证通查」查名下电话卡数量
- [ ] 查国家企业信用信息公示系统，确认自己不是某公司的法人/股东
- [ ] 拉一份个人征信报告
- [ ] 注销不用的银行卡和电话卡
- [ ] 关闭不必要的小额免密支付

### 长期保持

- [ ] 银行卡、支付账户、身份证**不外借**
- [ ] 收到「借卡走账」类请求时，直接拒绝，不解释
- [ ] 每年自查一次名下账户

### 面对请求时的标准回答

> 「我的卡和账号不外借。」

不需要解释理由。真要好的朋友，不会因为这句话跟你翻脸。
