# 校园里的「代理」和「分销」：看起来赚钱，实际在做什么

> 一句话概括：赚零花钱和替人背法律责任，有时候是同一件事。

**适用人群**：被同学或学长邀请「做代理赚零花钱」的学生；正在参与某个「分销」「团队」的人；想赚生活费但分不清正规推广与拉人头的人。

> **本文性质**
>
> 本文是法律与风险信息整理，**不构成法律意见**。是否构成传销由市场监管部门与司法机关认定，个人判断仅供参考。
>
> **政策与法律适用范围**
> - 主要依据：《禁止传销条例》（国务院令第 444 号，2005 年 11 月 1 日施行）第七条；《中华人民共和国刑法》第二百二十四条之一（组织、领导传销活动罪）；最高人民法院、最高人民检察院、公安部《关于办理组织领导传销活动刑事案件适用法律若干问题的意见》（2013 年）
> - 全国统一 / 地方执行：**传销的认定标准与刑事责任全国统一**

## 一、先把三类「校园代理」分开

不是所有代理都是骗局。混淆会让判断失准。

| 类型 | 典型形式 | 你的收益来源 | 风险 |
| --- | --- | --- | --- |
| **① 正规品牌推广** | 帮某品牌在校内做地推、发传单、拉新注册 | **按工作量拿固定报酬或提成** | 低。但要注意别替品牌做虚假宣传 |
| **② 层层分销** | 「发展 3 个下线就能升级，下线再发展下线」 | **来自下线的加入费或业绩** | 极高，可能构成传销 |
| **③ 拉人头骗局** | 「先交一笔入会费成为会员，拉人返利」 | **纯粹来自新加入者的钱** | 就是传销或诈骗 |

**分界线只有一条**：**你的钱是「卖东西/做服务」赚来的，还是「拉人加入」赚来的。**

前者是劳动或经营收入，后者是传销的核心特征。

## 二、《禁止传销条例》第七条的三种情形

这是判定传销最权威的依据，逐条对照。

【法规】《禁止传销条例》第七条：下列行为，属于传销行为：

> （一）组织者或者经营者通过发展人员，要求被发展人员发展其他人员加入，对发展的人员以其**直接或者间接滚动发展的人员数量**为依据计算和给付报酬（包括物质奖励和其他经济利益，下同），牟取非法利益的；
>
> （二）组织者或者经营者通过发展人员，要求被发展人员**交纳费用或者以认购商品等方式变相交纳费用**，取得加入或者发展其他人员加入的资格，牟取非法利益的；
>
> （三）组织者或者经营者通过发展人员，要求被发展人员发展其他人员加入，形成**上下线关系**，并以下线的**销售业绩**为依据计算和给付上线报酬，牟取非法利益的。

### 拆成你能用的判断表

| 情形 | 关键动作 | 对应的话术 |
| --- | --- | --- |
| **（一）拉人头计酬** | 报酬按**你拉了多少人**算（含间接） | 「你拉的人再拉人，你也有份」 |
| **（二）收取入门费** | 要交钱或买货才能获得**加入资格** | 「先交代理费/保证金/拿一批货」 |
| **（三）团队计酬** | 上下线关系 + 按**下线业绩**给上线提成 | 「下级卖出去的，上级抽成」 |

**三条中任意一条成立即可认定为传销**，不需要三条全占。【法规】

**注意第（三）条的措辞是「销售业绩」而不是「人员数量」**——这是它与正常多层次销售的关键区别。但实践中，如果所谓「销售业绩」主要来自下线囤货而非真实终端消费，仍可能被认定为传销。具体认定由执法机关判断。

## 三、六个高危信号（命中两个就该退）

| # | 信号 | 说明 |
| --- | --- | --- |
| 1 | **要先交钱** | 代理费、保证金、培训费、系统使用费——交钱才能开始，收益来自拉人 |
| 2 | **要先囤货** | 让你以「代理价」买一批货压在手里，卖不掉自己承担 |
| 3 | **收益主要来自发展下线** | 而不是零售给真实消费者 |
| 4 | **要求用你的身份证注册** | 注册公司、开对公账户、办电话卡、办银行卡 |
| 5 | **强调「团队」「层级」「升级」** | 有明确的上下线结构与晋级制度 |
| 6 | **劝你拉同学、室友、家人** | 熟人网络是最容易被消耗的资源，也是最难修复的 |

**第 4 条最危险**：一旦你的身份证被用于注册主体，法律上的责任人是**你**。这不是「帮个忙」，这是把自己变成了责任承担者。详见 03-06。

## 四、法律后果：不只是「不赚钱」

### 4.1 行政处罚

【法规】《禁止传销条例》对传销行为规定了责令停止、没收非法财物与违法所得、罚款等处罚；对为传销提供经营场所、培训场所、货源、保管、仓储等条件的，也有相应处罚规定。

**这意味着**：即使你只是「参与」而非组织者，投入的钱通常也难以追回（属非法财物/违法所得范畴），且可能面临调查。

### 4.2 刑事：组织、领导传销活动罪

【法规】《刑法》第二百二十四条之一规定了组织、领导传销活动罪。根据两高一部 2013 年《关于办理组织领导传销活动刑事案件适用法律若干问题的意见》，**组织、领导的传销活动人员在三十人以上且层级在三级以上**的，对组织者、领导者应追究刑事责任。

**注意两个关键词**：

| 关键词 | 含义 |
| --- | --- |
| **组织者、领导者** | 不只是「老板」。在传销活动中承担宣传、培训、协调等职责的，可能被认定为组织者、领导者 |
| **三十人以上、三级以上** | 这是追究刑事责任的人数与层级标准 |

【法规】**所以「我只是个小代理」不必然是安全位置。** 如果你负责在校园里宣讲、培训新人、管理一个小团队，可能被认定在这个范围内。具体认定由司法机关判断。

### 4.3 学术与学业后果

| 后果 | 说明 |
| --- | --- |
| 纪律处分 | 参与传销通常违反校规，可能受处分 |
| 影响评优与保研 | 处分记录会影响资格 |
| 影响档案与就业 | 部分处分记入档案 |

### 4.4 民事：你的名义注册的东西归你负责

如果被要求用你的身份证注册了公司、办了卡：

| 你名下有什么 | 风险 |
| --- | --- |
| 公司（法定代表人/股东） | 公司债务、税务问题、被列入失信名单 |
| 对公账户 | 可能被用于洗钱，涉刑（见 03-06） |
| 电话卡/银行卡 | 可能构成帮信罪（见 03-06） |
| 网络贷款 | 债务在你名下，且上征信 |

## 五、正规推广长什么样

作为对照，正规的校园品牌推广有这些特征：

| 特征 | 说明 |
| --- | --- |
| **不收费** | 不需要交代理费、保证金、培训费 |
| **不囤货** | 不要求你先进货 |
| **按工作量计酬** | 按时薪、按单量、按有效注册数，有明确结算方式 |
| **有主体、有合同** | 对方是真实企业，能提供营业执照与书面协议 |
| **有发票或正规结算记录** | 通过公司账户结算，不是私人转账 |
| **不要求你拉人加入** | 你的任务是推广产品，不是招募下线 |
| **不与「升级」「团队」挂钩** | 没有层级制度 |

**一个简单的测试**：问对方「如果我不拉任何人，只做推广，能不能拿到钱？」——如果答案是否定的，那这份「工作」的实质就是拉人头。

## 六、已经在里面了怎么办

| 阶段 | 动作 |
| --- | --- |
| **刚被邀请，还没交钱** | 停止，不要交任何费用；保留聊天记录 |
| **已经交了钱** | 停止继续投入；**不要为了回本去拉人**（这是最危险的一步）；保留所有转账记录、聊天记录、宣传材料 |
| **已经被要求用身份证注册** | 立即查名下主体（见下）；不要再提供任何证件 |
| **已经拉了同学** | 主动告知他们实情并止损；这比继续瞒着更能减少伤害 |
| **怀疑涉嫌传销** | 向市场监管部门（12315）举报；涉刑的向公安机关报案 |

**自查名下被注册了什么**：

| 查什么 | 怎么查 |
| --- | --- |
| 名下公司/个体工商户 | 国家企业信用信息公示系统 |
| 名下电话卡数量 | 各运营商官方渠道的「一证通查」类服务 |
| 名下银行账户 | 人民银行征信报告、各银行客服 |
| 名下网贷 | 个人信用报告 |

【官方】上述查询渠道均为官方渠道。发现异常注册应尽快申请注销并向公安机关说明情况。

## 七、为什么学生是重点目标

不是因为你贪心，是因为三个客观条件：

1. **有熟人网络**——同学、室友、社团，是最容易撬动的信任关系
2. **有身份可用**——刚满 18 岁、证件干净，在灰产链条里有价值
3. **缺钱且缺判断经验**——「赚点零花钱」的门槛很低，而识别传销需要法律知识

**一个诚实的提醒**：被拉进去的人多数不是想骗人，是想赚生活费。**这不改变后果，但改变了应对方式**——不必自责，要立刻止损，并且不要把责任转嫁给拉你进来的人（他可能也是受害者）。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 有真实产品就不是传销 | 关键看计酬方式是否按拉人头/入门费/团队业绩，而不是有没有商品 |
| 我只是小代理，不会有责任 | 承担宣传、培训、协调职责的可能被认定为组织者、领导者 |
| 交了钱要拉人才能回本 | 这正是设计目的；继续拉人会把你也变成加害方 |
| 同学介绍的不会坑我 | 介绍人往往也是受害者，他未必知道实情 |
| 用我身份证注册，我不参与就没事 | 法律上的责任人在你，债务与违法风险都指向你 |
| 退出就能拿回钱 | 投入的钱通常难以追回 |
| 只是发发朋友圈，不算参与 | 参与宣传推广可能构成违法行为的组成部分 |

## 可执行清单

### 被邀请时（决定之前）

- [ ] 问清：要不要先交钱、要不要先囤货
- [ ] 问清：我的收入是按销量还是按拉来的人数
- [ ] 问清：有没有上下线层级、升级制度
- [ ] 做「不拉人测试」：只做推广不招人，能不能拿到钱
- [ ] 核对对方企业：国家企业信用信息公示系统查营业执照
- [ ] 只要命中第三节两条以上高危信号，直接拒绝

### 已经在做

- [ ] 立刻停止拉新人
- [ ] 保留全部证据：转账记录、聊天记录、宣传材料、层级图
- [ ] 查名下公司、电话卡、银行账户、网贷
- [ ] 告知被自己拉进来的人实情
- [ ] 向市场监管部门（12315）或公安机关报案

### 长期

- [ ] 任何要求提供身份证、银行卡、手机卡、学信网信息的「兼职」，一律拒绝
- [ ] 记住一句话：先交钱的兼职，收益来自后面交钱的人
