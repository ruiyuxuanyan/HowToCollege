# 学费代偿与基层就业补偿：去哪些地方工作能免学费

> 一句话概括：国家替你还学费是真的，但服务年限、地区目录和申请时限卡得很死。

**适用人群**：家庭经济困难、靠贷款读完大学的学生；打算毕业后去基层、去部队、去中西部地区工作的人；公费师范生、定向医学生及其家长。

> **政策适用范围**
> - 主要依据：财政部、教育部、总参谋部《应征入伍服义务兵役高等学校学生学费补偿国家助学贷款代偿及退役复学后学费资助暂行办法》（财教〔2013〕43 号）；财政部、教育部《高等学校毕业生学费和国家助学贷款代偿暂行办法》（财教〔2009〕15 号）；教育部等《教育部直属师范大学师范生公费教育实施办法》；各省基层就业学费补偿实施细则
> - 全国统一 / 地方执行：**中央部属高校毕业生的代偿政策全国统一执行；地方高校的补偿范围、金额上限、基层地区目录由各省确定**
> - 核查日期：2026-11-05
> - 已知变化：中央高校基层就业代偿的年度申请通知每年发布，**金额上限与基层地区目录可能调整**

---

## 一、这其实是四件不同的事

很多人把「国家替我还学费」当成一项政策，实际上有四套并行的制度，适用对象完全不同。**搞错一套，就白准备了。**

| 政策 | 谁能享受 | 你付出什么 | 性质 |
| --- | --- | --- | --- |
| **① 应征入伍学费补偿/贷款代偿** | 在校生或毕业生应征入伍服义务兵役 | 服役 | 补偿学费或代偿贷款 |
| **② 退役复学后学费资助** | 入伍前在校、退役后复学 | 已服役 | 资助后续学费 |
| **③ 基层就业学费补偿/贷款代偿** | 毕业后到中西部、艰苦边远地区基层单位就业 | 服务满一定年限 | 补偿学费或代偿贷款 |
| **④ 公费师范生 / 定向生** | 招生时即确定 | 履约任教/服务 | 免学费 + 补助，违约要退 |

【法规】①② 依据财教〔2013〕43 号；③ 依据财教〔2009〕15 号及各省细则；④ 依据公费师范生与定向就业招生相关规定。

**先分清楚你属于哪种，再往下看。** 下面的内容按这四类分别展开。

---

## 二、应征入伍：补偿与代偿

### 2.1 谁能享受

【法规】财教〔2013〕43 号规定，对应征入伍服义务兵役的高校学生，在入伍时对其在校期间缴纳的学费实行一次性补偿，或对其获得的国家助学贷款实行代偿。

| 对象 | 说明 |
| --- | --- |
| 在校生入伍 | 补偿已缴学费，或代偿已借贷款 |
| 毕业生入伍 | 同上 |
| 退役复学 | 退役后复学，资助其剩余学年的学费 |
| 退役后考入高校 | 按相关规定享受学费资助 |

### 2.2 补偿/代偿的额度

**每学年补偿或代偿的金额有上限，由财政部、教育部规定，并按年度调整。**

**能查到的原始依据（可自行核对）**：

> 【法规】《高等学校毕业生学费和国家助学贷款代偿暂行办法》（财教〔2009〕15 号）**第七条**：
> 「每个高校毕业生每学年代偿学费和国家助学贷款的金额**最高不超过 6000 元**。毕业生在校学习期间每年实际缴纳的学费或获得的国家助学贷款低于 6000 元的，按照实际缴纳的学费或获得的国家助学贷款金额实行代偿。毕业生在校学习期间每年实际缴纳的学费或获得的国家助学贷款高于 6000 元的，按照每年 6000 元的金额实行代偿。」
> 同条还规定：本科、专科（高职）、研究生和第二学士学位毕业生代偿年限，分别按国家规定的相应学制计算。
> 第八条：采取**分年度代偿**，毕业后每年代偿总额的 1/3，3 年代偿完毕。
> —— [教育部官网原文](https://hudong.moe.gov.cn/jyb_xxgk/moe_1777/moe_1779/tnull_46550.html)

**这是 2009 年的原始标准，不是现行标准。** 此后财政部、教育部按年度发布通知调整过多次（学费标准本身也涨了），**现行上限以你毕业当年的通知为准**。

**查法（按可靠性排序）**：
1. 本校学生资助管理中心 —— 最准，直接按本校口径
2. 全国学生资助管理中心官网 —— 看当年文件
3. 学校武装部/征兵工作站（入伍相关事务由这里对接）

**注意两个「取低」**：
- 上限按「每学年实际缴纳学费」与「国家规定上限」**两者取低**。学费高于上限的只补到上限；低于上限的按实际学费补。
- 代偿的学费**优先用于偿还国家助学贷款本息**（财教〔2009〕15 号第二条）——所以有贷款的人，钱不一定到手，可能直接被划去还贷。

### 2.3 申请流程（关键：有时限）

| 步骤 | 做什么 |
| --- | --- |
| 1 | 入伍前/入伍时，向学校学生资助管理中心提出申请 |
| 2 | 填写《应征入伍服兵役高等学校学生国家教育资助申请表》 |
| 3 | 提交入伍通知书复印件等材料 |
| 4 | 学校审核、上报 |
| 5 | 资金拨付（通常逐级下拨，周期较长） |

**最容易出错的地方**：**入伍当年必须申请，过期通常不予补办。** 【经验】不要等退役后再办。在校生入伍前，务必先到资助中心问清材料清单和时间点。

## 三、基层就业补偿/代偿

### 3.1 三个必须同时满足的条件

【法规】财教〔2009〕15 号的框架是三个条件同时成立：

| 条件 | 说明 |
| --- | --- |
| **① 就业地区** | 到中西部地区、艰苦边远地区**县以下（不含县级）**基层单位就业【待核实具体地区目录】 |
| **② 服务年限** | **服务期在 3 年以上（含 3 年）** |
| **③ 单位性质** | 基层单位（如乡镇机关、农村中小学、基层农技推广站等），具体范围按文件规定 |

【官方】基层就业学费补偿国家助学贷款代偿政策的基本条件为：中央部属高校应届毕业生自愿到中西部地区、艰苦边远地区和老工业基地县以下基层单位就业、**服务期在 3 年以上（含 3 年）**的，其学费由国家补偿，或代偿国家助学贷款。

**「3 年以上（含 3 年）」这一条是硬的**：差一天没满 3 年，就不符合条件，或需按规定退还已发放资金。

**最容易误解的是第 ① 条**：「基层」不等于「小城市」，也不等于「老家县城」。多数政策的表述是**县以下**，即乡镇及以下。县城里的单位通常不符合。

### 3.2 「中西部地区」和「艰苦边远地区」怎么认定

这两个概念不是自己判断的：

| 概念 | 依据 |
| --- | --- |
| 中西部地区 | 按国家区域划分；具体范围见文件附件或年度通知 |
| 艰苦边远地区 | 按国家规定的地区类别目录 |

**不要凭感觉判断。** 你所在的地方算不算，看**当年通知附的地区目录**。查不到就打学校学生就业指导中心或资助中心的电话问。

### 3.3 申请时间（最狠的一条）

基层就业代偿的申请**通常在毕业当年办理**，由学校统一组织上报。

| 时间 | 动作 |
| --- | --- |
| 毕业前（春季） | 关注学校就业中心/资助中心通知 |
| 毕业当年 | 提交申请材料，学校审核上报 |
| 之后 | 服务满年限后，按程序核销/确认 |

**关键提醒**：**这不是「先工作三年再申请」，是「毕业时就申请，服务满后核销」。** 顺序搞反，就彻底没机会了。【经验】

### 3.4 地方高校的差异

**中央部属高校与地方高校的政策不同。** 地方高校的补偿范围、金额上限、是否覆盖本省特定地区，由**各省自行规定**，有些省份的实施范围比中央政策更宽，有些更窄。

查法：
- 省教育厅官网搜「基层就业 学费补偿」
- 省学生资助管理中心
- 本校就业指导中心

## 四、公费师范生与定向生：另一套逻辑

这类不是「毕业后申请补偿」，而是**入学时就签了协议**。

| 项目 | 内容 |
| --- | --- |
| 享受什么 | 免学费、免住宿费，发放生活补助（标准按政策） |
| 义务 | 毕业后按协议到指定地区/学校任教或服务，服务期通常为 6 年（以协议约定为准） |
| 违约后果 | 退还已享受的免费教育费用，缴纳违约金，记入诚信档案【待核实具体标准】 |
| 能否考研 | 一般需按协议约定，部分允许在职攻读 |

【法规】公费师范生依据《教育部直属师范大学师范生公费教育实施办法》；定向医学生依据相应的定向就业招生与培养规定。

**这类协议的法律性质是合同。** 签之前必须读懂违约条款，因为它是真的会被执行的。【经验】

## 五、四类政策对比

| 维度 | 入伍补偿 | 基层就业代偿 | 公费师范生/定向生 | 退役复学资助 |
| --- | --- | --- | --- | --- |
| 决定时点 | 入伍时 | 毕业时申请 | 高考填志愿时 | 退役复学时 |
| 服务要求 | 服义务兵役 | 基层服务满规定年限 | 按协议服务 | 无额外要求 |
| 金额 | 按学年上限 | 按学年上限 | 免学费+补助 | 按学年上限 |
| 地区限制 | 无 | **有，且很严** | 有（协议指定） | 无 |
| 违约后果 | 中途退役可能影响资格 | 未满服务期通常需退还 | 退费+违约金+诚信记录 | 无 |
| 申请窗口 | 入伍当年 | 毕业当年 | 入学时 | 复学当年 |

## 六、最容易踩的五个坑

| 坑 | 后果 | 怎么避免 |
| --- | --- | --- |
| 以为「县城」也算基层 | 不符合条件，白等服务三年 | 查当年通知的地区目录，问就业中心 |
| 毕业时没申请，想着以后补 | 过期不补，彻底失去资格 | 毕业当年主动问，别等通知 |
| 入伍时没办，等退役再办 | 通常不予补办 | 入伍前先去资助中心 |
| 没看公费师范生的违约条款 | 违约要退全部费用+违约金 | 签协议前逐条读，尤其是违约金计算方式 |
| 把「贷款代偿」当成「贷款不用还」 | 代偿是有限额的，超出部分仍要还 | 确认代偿额度上限与你实际贷款额的差额 |

**最后一条要展开说**：代偿的通常是「国家助学贷款」的本息，且有**金额上限**。如果你的贷款总额超过代偿上限，超出部分仍需自己偿还。

按财教〔2009〕15 号第七条的原始表述，是「**每学年**最高不超过某个数」——**注意是每学年，不是总共**。所以总额上限 ≈ 每学年上限 × 学制年数（四年制本科 = 4 倍）。这是很多人算错的地方：以为一年 6000 就只有 6000。

再加上第八条的分年度代偿（每年 1/3，三年发完），实际到手节奏是：**毕业 3 年内分 3 次拿到总额，而不是一次性。**

【待核实】现行每学年上限的具体数字，因财政部、教育部历年调整，本文不写入。请以你毕业当年本校资助中心的通知为准。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 去任何一个基层单位都能免学费 | 必须同时满足地区、单位性质、服务年限三个条件，且地区目录由文件规定 |
| 服务满三年后可以再申请 | 申请在毕业当年，服务期满后是「核销」不是「申请」 |
| 县城工作就算基层 | 多数政策表述为「县以下」，县城通常不算 |
| 补偿金额等于我交的全部学费 | 有每学年上限，超出部分不补 |
| 贷款代偿等于贷款全免 | 代偿有额度上限，超出部分自理 |
| 公费师范生违约只是退钱 | 还可能涉及违约金与诚信记录 |
| 地方高校和部属高校政策一样 | 地方高校按本省细则执行，范围和金额可能不同 |
| 入伍后再补办补偿手续 | 通常须在入伍当年办理 |

## 可执行清单

### 如果你打算入伍

- [ ] 入伍前到学校武装部/征兵工作站与学生资助管理中心各问一次
- [ ] 领《应征入伍服兵役高等学校学生国家教育资助申请表》
- [ ] 保留入伍通知书原件与复印件
- [ ] 确认补偿方式：补偿已缴学费 还是 代偿贷款（二选一，问清哪个更划算）

### 如果你打算去基层就业

- [ ] 毕业当年春季，到就业指导中心问「今年基层就业代偿的通知什么时候发」
- [ ] 查当年通知附的**地区目录**，确认你要去的地方在不在里面
- [ ] 确认单位性质是否符合（乡镇机关、农村学校、基层站所等）
- [ ] 记下服务年限要求，签就业协议时确认起止时间
- [ ] 保留劳动合同、社保记录、单位证明——核销时要用

### 如果你是公费师范生/定向生

- [ ] 找出入学时签的协议原件
- [ ] 逐条读违约条款：违约金怎么算、什么情况算违约
- [ ] 确认服务地区范围与年限
- [ ] 确认能否在职读研及条件

### 通用

- [ ] 所有材料扫描存档（入伍通知书、合同、缴费凭证、贷款合同）
- [ ] 每一步都留下书面或邮件记录

---

## 一句话记住

**代偿不是「工作三年后去申请」，是「毕业当年就申请、服务满后再核销」——顺序反了，一分钱都拿不到。**
