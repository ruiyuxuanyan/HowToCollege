# 助学金与勤工助学：能拿多少、怎么申请

> 一句话概括：一个是免费给的钱，一个是用时间换的钱，两条路都能走且不冲突。

**适用人群**：已通过家庭经济困难认定、但不知道还能申请什么的学生；想找校内兼职但担心影响学习的人；家长。

> **政策适用范围**
> - 主要依据：《普通高等学校国家助学金管理办法》（财教〔2007〕92 号）；教育部、财政部《高等学校勤工助学管理办法》（教财〔2018〕12 号）；全国学生资助管理中心年度工作通知
> - 全国统一 / 地方执行：**制度框架与管理办法全国统一；分档标准、发放金额、校内岗位设置与时薪由各省、各校确定**
> - 核查日期：2026-11-05
> - 已知变化：助学金分档与金额按年度调整；勤工助学时薪由各校在不低于当地最低工资相关要求的前提下确定

---

## 一、先分清三条「资助线」

这三个概念最容易被混为一谈，但它们**性质完全不同**：

| 项目 | 性质 | 要不要还 | 前置条件 | 你付出什么 |
| --- | --- | --- | --- | --- |
| **国家助学金** | **无偿资助** | **不还** | 家庭经济困难认定 | 无（不是劳动报酬） |
| **勤工助学** | **劳动报酬** | 不还（本来就是工资） | 多数学校要求困难认定，部分岗位不限 | 时间与劳动 |
| **国家助学贷款** | **借款** | **要还**（在校期间国家贴息） | 困难认定或信用审核 | 毕业后还本付息 |

【法规】国家助学金是无偿资助，用于资助家庭经济困难学生的生活费用开支；勤工助学是学生在学校组织下利用课余时间参加劳动并取得报酬。

**最关键的区别在最后一行**：助学金是你**不需要做事就能拿到**的钱，勤工助学是你**做了事才拿到**的钱。所以：
- 不要因为「拿了助学金不好意思」而去打工替代——两者可以同时有
- 也不要把勤工助学理解为「另一种助学金」——它是正经的雇佣关系，有工作量要求

## 二、国家助学金

### 2.1 谁能拿

必须**先完成家庭经济困难认定**（见 01-10）。认定是资格门槛，助学金是资金发放。

【法规】国家助学金的资助对象是家庭经济困难的全日制本专科在校学生。

### 2.2 分档

多数学校分 2—3 档，通常与困难认定的档次对应（特别困难 / 困难 / 一般困难）。**档次决定金额**。

**国家助学金的国家层面标准**：平均资助标准为每生每年 **3700 元**，具体标准由高校在每生每年 **2500—5000 元**范围内自主确定，可以分为 2—3 档。

【官方】深圳市教育局《高校本专科学生资助政策简介（国家资助部分）》，2026-09-07

**注意这是「平均标准」**：实际拿到多少，取决于你所在学校的分档和你的困难认定档次。所以你查到「3700 元」不等于你就能拿 3700 元。

### 2.3 发放方式

| 方式 | 说明 |
| --- | --- |
| **按学期发放** | 最常见：秋季、春季各发一次 |
| **按月发放** | 部分学校按月打入银行卡 |
| **一次性发放** | 少数学校按学年一次发 |

发放通常打入**学生本人银行卡**（多为学校统一办理的资助卡或指定银行账户）。**不要让别人代收**，这既有风险也不合规。【经验】

### 2.4 在哪里查真实金额

按顺序试：

1. **本校学生资助管理中心网站**——通常有「政策文件」或「资助标准」栏目
2. **本校《学生资助管理办法》**——里面会写各档金额
3. **辅导员或学院学生工作办公室**——直接问最快
4. **全国学生资助管理中心官网**——查国家层面的政策依据
5. **录取通知书随附的资助政策说明**——新生可先看这个

## 三、勤工助学

### 3.1 它有专门的国家管理办法

这一点值得强调：勤工助学不是「学校随便给的零活」，它有部门规章级别的依据。

【法规】教育部、财政部《高等学校勤工助学管理办法》（教财〔2018〕12 号）规定了勤工助学的组织管理、岗位设置、酬金标准与时间限制。

其中的核心要求包括：

| 要求 | 内容 |
| --- | --- |
| **不得影响学业** | 勤工助学应安排在课余时间，不得影响学生正常学习 |
| **有时间上限** | **原则上每周不超过 8 小时（含），每月不超过 40 小时（含）** |
| **酬金标准** | 由学校按当地相关规定确定，不得低于一定水平【待核实：具体时薪各校不同】 |
| **岗位以校内为主** | 以校内岗位为主，校外勤工助学须经学校组织并保障权益 |
| **不得安排有害工种** | 不得组织学生参加有毒有害、危险的生产作业 |

**这条对你的实际意义**：如果你被安排的工作明显超出合理时长、影响上课，或岗位存在安全风险，**这是有规章可依的**——可以向学校学生资助管理中心或勤工助学管理部门反映，而不是只能忍着。

### 3.2 常见岗位类型

| 类型 | 内容 | 特点 |
| --- | --- | --- |
| **图书馆** | 上书、整理、值班 | 相对安静，可兼顾看书 |
| **实验室/机房** | 设备维护、协助管理 | 与专业相关，可能积累技能 |
| **行政助理** | 学院办公室文书、数据整理 | 能接触老师，了解流程 |
| **助教/助研** | 批改作业、协助课程 | 与学业结合最紧 |
| **校园服务** | 食堂、宿舍管理协助、迎新 | 时间灵活，体力为主 |
| **宣传/新媒体** | 拍照、写稿、运营 | 可积累作品 |

【经验】**助教/助研和实验室岗位的隐性价值最高**——除了工资，还能拿到推荐信、科研经历、对课程的深度理解。选岗位时不要只看时薪。

### 3.3 怎么申请

通用流程（各校不同）：

1. 关注**学生资助管理中心**或**学工部**发布的岗位招聘通知（多在学期初）
2. 提交申请（通常需填写岗位申请表，部分需困难认定证明）
3. 用人部门面试或直接分配
4. 签订勤工助学协议（明确岗位、时长、酬金）
5. 按月考核、按月发放

**时间点很重要**：岗位多在**每学期开学初**集中放出，晚了就没了。开学第一周去看通知。

### 3.4 工资怎么发、会不会拖欠

【法规】勤工助学酬金由学校按规定标准支付，通常按月结算，打入学生银行卡。

如果出现拖欠或克扣：
1. 先与用人部门核对工作量记录
2. 向学校勤工助学管理部门（通常在学生资助管理中心或学工部）反映
3. 保留岗位协议、考勤记录、沟通记录

**注意**：校内勤工助学的争议处理走学校内部渠道，不适用《劳动合同法》的劳动争议程序（因为不构成劳动关系，详见 04-01）。这一点在维权时容易搞错。

## 四、能不能同时拿

| 组合 | 能否同时 | 说明 |
| --- | --- | --- |
| 国家助学金 + 勤工助学 | **可以** | 一个是无偿资助，一个是劳动报酬，性质不同 |
| 国家助学金 + 国家助学贷款 | **可以** | 助学金不用还，贷款要还，互不冲突 |
| 国家助学金 + 国家励志奖学金 | **可以**（需符合各自条件） | 励志奖学金要求困难认定 + 成绩优秀 |
| 国家奖学金 + 国家励志奖学金 | **不可以** | 二者互斥（见 02-03） |
| 勤工助学 + 校外兼职 | 可以，但要注意总时长 | 别让打工挤掉上课时间 |

【待核实】同一学年内各项资助的具体叠加规则，各校在实施细则中可能有额外限制（例如某些学校规定获得大额奖学金后不再发放助学金）。**申请前问一句「我这个情况还能不能同时拿」，比事后发现重复领取要退钱好。**

## 五、几个容易出问题的地方

| 情况 | 处理 |
| --- | --- |
| **重复领取** | 如实申报已获得的资助；重复领取通常要退回，且可能影响后续申请资格 |
| **不实申报** | 取消资格、追回资金、视情节给予纪律处分（见 01-10） |
| **助学金被要求「请客」** | 没有这种义务；被同学施压可向辅导员反映 |
| **被要求公开家庭情况** | 公示一般只公示姓名与档次，不应公示家庭细节（见 01-10 第四节） |
| **勤工助学影响上课** | 有规章依据可拒绝超时安排 |
| **毕业时还有未结的酬金** | 离校前核对并结清，保留协议 |

## 六、隐私：你有权利要求

【法规】学生资助工作应保护学生隐私与尊严。实际操作中：

| 不该发生 | 可以怎么做 |
| --- | --- |
| 班会上公开讲述家庭困难 | 向学院学生工作办公室或资助中心反映 |
| 公示家庭收入、疾病细节 | 公示内容应限于姓名与档次 |
| 同学评议时讨论你家具体情况 | 评议应聚焦是否符合标准 |
| 因领取助学金被贴标签 | 这是制度设计，不是施舍 |

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 助学金要还 | 无偿资助，不需要偿还 |
| 拿了助学金就不能做勤工助学 | 可以同时，性质不同 |
| 勤工助学工资低，不如去校外 | 校内安全、时间可控、可能有隐性收益（推荐信、经历） |
| 勤工助学不算正式工作，被克扣只能忍 | 有《高等学校勤工助学管理办法》可依，可向资助中心反映 |
| 助学金一次申请管四年 | 通常每学年重新认定与申请 |
| 家里不算特别困难就不申请 | 认定分档，中间档也有资助 |
| 领助学金是丢人的事 | 这是国家制度，不是个人施舍 |
| 勤工助学可以随便请假 | 是雇佣关系，有考勤与考核要求 |

## 可执行清单

### 开学初（第一周）

- [ ] 确认自己是否已完成本学年的家庭经济困难认定（未完成先去办，见 01-10）
- [ ] 到学生资助管理中心网站查助学金的分档标准与申请截止时间
- [ ] 查勤工助学岗位招聘通知，列出 3 个想申请的岗位
- [ ] 优先考虑助教/助研/实验室岗位（隐性收益更高）

### 申请时

- [ ] 如实填写已获得的其他资助，避免重复领取
- [ ] 勤工助学签订岗位协议，写清岗位、时长、酬金标准
- [ ] 确认发放方式与时间（按学期还是按月）

### 在读期间

- [ ] 每月核对勤工助学酬金是否到账
- [ ] 保留考勤记录与沟通记录
- [ ] 若工作明显影响上课，向资助中心反映
- [ ] 每学年重新申请认定与助学金

### 毕业前

- [ ] 结清未发的勤工助学酬金
- [ ] 确认所有资助款项无遗留问题
