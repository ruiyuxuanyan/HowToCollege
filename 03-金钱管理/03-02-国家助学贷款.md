# 国家助学贷款：生源地 vs 校园地、额度、贴息、还款

> 一句话概括：这是国家给的、在校期间利息全部由财政承担的低息贷款，符合条件不借是吃亏。

**适用人群**：家庭经济困难的在校本专科生、研究生；正在纠结「要不要申请」或「利息高不高」的学生和家长。

> **政策适用范围**
> - 主要依据：财政部、教育部、中国人民银行、金融监管总局《关于调整完善国家助学贷款有关政策的通知》（财教〔2024〕188 号），2024 年 10 月 31 日
> - 全国统一 / 地方执行：**额度、利率、贴息规则全国统一**；经办银行与具体办理流程由各省/各校确定
> - 核查日期：2026-11-05
> - 已知变化：2024 年秋季学期起额度上调、利率下调

---

## 一、先纠正三个最常见的误解

在讲细节之前，这三件事必须先说清，因为它们直接影响你要不要申请。

| 误解 | 实际情况 |
| --- | --- |
| 「助学贷款利息很高，还不如找亲戚借」 | **在校期间利息全部由财政承担**，你一分钱利息都不用付 |
| 「家里不是特别穷就不能办」 | 这是**信用贷款**，以借款人信誉作为还款保证，「家庭经济困难学生有需要就能申请」 |
| 「借了会留下不良记录，影响以后买房」 | **按时还款不会**。只有逾期才会进征信 |

**第一条是关键。** 很多人因为「怕欠钱」而放弃，但他们不知道在校期间是不付利息的——这相当于一笔免息的周转资金。

---

## 二、额度：现在能借多少

这是最新、也最容易被过时信息误导的部分。

> 自 **2024 年秋季学期**起，全日制普通本专科学生（含第二学士学位、高职学生、预科生）每人每年申请贷款额度由不超过 16000 元提高至**不超过 20000 元**；全日制研究生每人每年申请贷款额度由不超过 20000 元提高至**不超过 25000 元**。
>
> 学生申请的国家助学贷款优先用于支付在校期间**学费和住宿费**，超出部分用于弥补**日常生活费**。
>
> 【法规】《关于调整完善国家助学贷款有关政策的通知》（财教〔2024〕188 号）第一条

整理成表：

| 学历层次 | 每年最高额度 |
| --- | --- |
| 本专科生（含第二学士学位、高职、预科生） | **20000 元** |
| 研究生 | **25000 元** |

**两个重要细节**：

1. **用途不只学费**：优先交学费住宿费，**超出的部分可以用来当生活费**
2. **不是只能借这么多，是不超过这么多**：你可以按实际需要少借

## 三、利率：到底多少

> 国家助学贷款利率由同期同档次贷款市场报价利率（**LPR）减 60 个基点**，调整为同期同档次 **LPR 减 70 个基点**。
>
> 对此前已签订的参考 LPR 的浮动利率国家助学贷款合同，承办银行可与贷款学生协商，将原合同利率调整为同期同档次 LPR 减 70 个基点。
>
> 【法规】财教〔2024〕188 号 第二条

通俗解释：

- 利率 = 当期 LPR − 0.7%
- 这是**明显低于普通商业贷款**的水平
- 已经签了旧合同（LPR−0.6%）的，可以申请调整到 LPR−0.7%

> **注意**：LPR 每月公布一次，会浮动。文中无法给出一个固定利率数字，请以贷款合同和银行当年公告为准。

## 四、贴息：在校期间谁付利息

这是助学贷款最核心的优惠。教育部在 2025 年的新闻发布会上明确说明：

> 贷款偿还上，学生在校期间**本金无需偿还，利息全部由财政承担**。
>
> 【官方】教育部新闻发布会，介绍国家助学贷款等学生资助工作情况

具体规则：

| 阶段 | 本金 | 利息 |
| --- | --- | --- |
| **在校期间** | 不需还 | **财政全额承担** |
| 毕业后（宽限期内） | 按政策 | 开始由本人承担 |
| 宽限期后 | 需偿还 | 本人承担 |

**所以「在校期间」这四个字很关键。** 你读书的这几年，这笔钱是零成本使用的。

## 五、生源地贷款 vs 校园地贷款

国家助学贷款有两种，目前以生源地为主：

> 国家助学贷款已经形成了**生源地为主体、校园地为补充**的发展模式。
>
> 【官方】教育部新闻发布会

### 5.1 对比

| 项目 | 生源地信用助学贷款 | 校园地国家助学贷款 |
| --- | --- | --- |
| 办理地点 | **户籍所在地**县级学生资助管理中心 / 经办银行 | 就读学校 |
| 办理时间 | 通常在**暑假**（新生入学前或入学后不久） | 入学后，学校统一组织 |
| 频率 | **每年办一次** | 通常一次签约，分年发放 |
| 共同借款人 | 通常需要（家长或其他符合条件的亲属） | 一般不需要 |
| 经办机构 | 各地不同（如国家开发银行等） | 学校合作银行 |
| 覆盖率 | 主体 | 补充 |

### 5.2 该选哪个

**首选生源地贷款**，原因：

1. 是当前的主体模式，覆盖最广
2. 暑假就能办好，开学直接走「绿色通道」，不用先垫钱
3. 每年办理，额度可按当年实际需要调整

**校园地贷款适合**：生源地无法办理、或已入学才发现需要的学生。

### 5.3 两者能不能同时借

**不能重复申请同一学年的额度。** 无论哪种形式，一年内的贷款总额受第二条的额度上限约束。

> **借款学生同一学年内不能同时申请生源地信用助学贷款和校园地国家助学贷款。**
>
> 【官方】深圳市教育局《高校本专科学生资助政策简介（国家资助部分）》，2026-09-07

所以只能二选一。选哪个见上一节的对比。

## 六、申请条件

【官方】综合教育部与各校公开说明，通常要求：

| 条件 | 说明 |
| --- | --- |
| 学籍 | 全日制普通本专科生、研究生（含第二学士学位、高职、预科生） |
| 家庭经济状况 | 家庭经济困难（通常需完成**困难认定**） |
| 信用 | 信用贷款，无需抵押担保，但需信用良好 |
| 学籍状态 | 在校、正常在读 |

**关键前置动作**：多数学校要求先完成**家庭经济困难认定**。这一项没做，后面的资助都拿不到。详见「家庭经济困难认定」一文。

---

## 七、办理流程（生源地贷款为例）

以下是通用步骤，**具体以你户籍所在县的学生资助管理中心公告为准**：

1. **查公告**：搜索「XX 县/区 生源地信用助学贷款 2026」，找当年办理通知
2. **线上预申请**：多数地区需先在指定系统（如国家开发银行学生在线服务系统）注册、填表、打印
3. **准备材料**（常见）：身份证、户口簿、录取通知书或在读证明、共同借款人身份证、困难认定相关材料
4. **现场办理**：学生本人和共同借款人一起到县级资助中心签约
5. **回执确认**：把回执交给学校，学校录入系统确认
6. **放款**：学费住宿费直接划到学校，超出部分打到你的账户

**办理时间**：通常在 7–9 月，各地不同。**错过要等明年。**

## 八、还款

| 阶段 | 说明 |
| --- | --- |
| 在校期间 | 只计息不还本，利息财政承担 |
| 毕业后宽限期 | 只还息不还本（宽限期年数按合同约定） |
| 宽限期后 | 按合同分期偿还本息 |
| 提前还款 | 通常可以，具体流程问经办银行 |

> 宽限期年数、最长还款期限**按合同约定**，各地各经办银行不同。请以你的贷款合同为准。

### 逾期后果

| 后果 | 说明 |
| --- | --- |
| 进入征信 | 逾期记录进入个人信用报告 |
| 影响后续贷款 | 房贷、车贷等可能受影响 |
| 影响就业 | 部分单位会查征信 |
| 罚息 | 按合同约定加收 |

**按时还款就没事。** 这一条要说清，避免有人因为「怕影响征信」而不敢借。

## 九、还有更划算的：贷款代偿

如果毕业后去特定地区、特定岗位工作，或者去服兵役，可以申请**学费补偿或助学贷款代偿**——相当于国家替你还。

财教〔2024〕188 号明确：

> 国家助学贷款额度调整后，**服兵役**高等学校学生学费补偿、用于学费的国家助学贷款代偿和学费减免标准以及**基层就业**学费补偿、用于学费的国家助学贷款代偿标准，相应调整为本专科学生每人每年最高不超过 20000 元、研究生每人每年最高不超过 25000 元。
>
> 【法规】财教〔2024〕188 号 第一条

即：

| 路径 | 标准 |
| --- | --- |
| 服义务兵役 | 本专科 ≤2 万/年，研究生 ≤2.5 万/年 |
| 基层就业 | 同上 |

**这意味着**：如果你打算去基层或参军，这笔贷款可能最终由国家替你还掉。

具体条件与申请流程见「学费代偿与基层就业补偿」一文（03-07）。

## 十、常见误区

| 误区 | 实际 |
| --- | --- |
| 「助学贷款利息很高」 | 在校期间利息**全部由财政承担**，你零成本用钱 |
| 「只有特别穷才能办」 | 是信用贷款，「家庭经济困难学生有需要就能申请」 |
| 「只能交学费」 | 优先交学费住宿费，**超出部分可当生活费** |
| 「借了影响买房」 | 按时还款不影响；只有逾期才影响 |
| 「毕业后马上要还一大笔」 | 有宽限期，且可分期 |
| 「网上说能借 8000」 | 那是旧标准。2024 年秋季起本专科 2 万、研究生 2.5 万 |
| 「找中介能包办」 | 办理**不收费**，收费代办一律是骗局 |

## 十一、可执行清单

### 决定要不要借之前

- [ ] 算一下：学费 + 住宿费 + 生活费大概多少
- [ ] 确认自己是否已完成**家庭经济困难认定**
- [ ] 查户籍所在县当年的生源地贷款公告

### 办理（暑假）

- [ ] 线上预申请、打印表格
- [ ] 准备材料：身份证、户口簿、录取通知书/在读证明、共同借款人材料
- [ ] 和共同借款人一起去县级资助中心
- [ ] 拿到回执后**及时交给学校**

### 入学后

- [ ] 确认贷款已到账、学费已抵扣
- [ ] 记住还款起始时间
- [ ] 保存好合同

### 毕业后

- [ ] 按时还款，避免逾期
- [ ] 如果去了基层或参军，申请代偿

## 十二、一句话记住

**这是国家给你的、在校期间零利息的一笔钱。** 明明需要却不申请，损失的是自己。
