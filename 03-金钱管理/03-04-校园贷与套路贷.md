# 校园贷与「套路贷」：如何识别、已经借了怎么办

> 一句话概括：借的时候觉得只是几千块，还的时候发现要还的是好几年。

**适用人群**：正在被推销「低息快速放款」的学生；已经借了网贷、正在以贷养贷的人；被催收威胁、不敢告诉家里的人；想帮同学判断的人。

> **本文性质**
>
> 本文是法律与风险信息整理，**不构成法律意见**。具体个案请咨询执业律师，或拨打 12348 法律援助热线。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国民法典》合同编第十二章「借款合同」；最高人民法院《关于审理民间借贷案件适用法律若干问题的规定》（2020 年修正）；最高人民法院、最高人民检察院、公安部、司法部《关于办理「套路贷」刑事案件若干问题的意见》（2019 年）；原银保监会等五部门《关于进一步规范大学生互联网消费贷款监督管理工作的通知》（银保监办发〔2021〕27 号）
> - 全国统一 / 地方执行：**刑事认定与民间借贷利率规则全国统一；具体案件的定性由司法机关判断**
> - 核查日期：2026-11-05
> - 已知变化：民间借贷利率的司法保护上限已由固定比例改为挂钩 LPR 的浮动机制，**旧资料里的「24%、36%」表述已不适用**
>
> ⏳ 易过时：利率上限随 LPR 变动；监管文件持续更新。

## 一、先分清三种东西（混在一起就会判断错）

「校园贷」不是一种产品，是三类性质完全不同的东西被叫成同一个名字：

| 类型 | 本质 | 法律性质 | 该怎么处理 |
| --- | --- | --- | --- |
| **① 持牌机构的合规贷款** | 银行、消费金融公司依法发放 | 民事借贷关系 | 按合同还款，可协商 |
| **② 违规向学生发放的网贷** | 违反监管规定开展的大学生互联网消费贷款 | 民事关系 + 行政违规 | 合同不因此当然无效，但可主张违规事实 |
| **③ 「套路贷」** | **以借贷为名实施诈骗** | **刑事案件** | **立即报警**，不是民事纠纷 |

**第 ③ 类是最关键的**：「套路贷」不是「利息高一点的贷款」，它的目的从一开始就不是收回本息，而是**非法占有你的财产**。所以对它**不存在「协商还款」这条路**——你越还，对方越有动力继续。

---

## 二、「套路贷」的五个识别特征

【法规】两高两部《关于办理「套路贷」刑事案件若干问题的意见》（2019 年）明确了「套路贷」的界定：以非法占有为目的，假借民间借贷之名，诱使或迫使被害人签订「借贷」或变相「借贷」「抵押」「担保」等相关协议，通过虚增借贷金额、恶意制造违约、肆意认定违约、毁匿还款证据等方式形成虚假债权债务，并借助诉讼、仲裁或者采用暴力、威胁以及其他手段非法占有被害人财物的违法犯罪活动。

拆成你能用的判断清单：

| 特征 | 具体表现 |
| --- | --- |
| **① 虚增金额** | 合同写借 1 万，实际到手 8 千（「砍头息」）；或以「保证金」「服务费」「行规」名义预先扣除 |
| **② 制造虚假流水** | 让你先收一笔大额转账，再让你把差额转回去——**银行流水显示你借了很多，实际没拿到** |
| **③ 恶意制造违约** | 到期时故意让你联系不上、系统故障、账户变更，让你「被动违约」 |
| **④ 肆意认定违约** | 合同里埋着极易触发的违约条款，一旦触发，违约金滚成新本金 |
| **⑤ 软硬兼施索债** | 电话轰炸、爆通讯录、上门、恐吓、虚假诉讼 |

**只要出现 ①②③④ 中的任意一条，就不是正常借贷。** 【经验】

再补三个「话术前兆」：

- 「先签个空白合同，金额回头填」
- 「配合走个流水，显得额度高，对你没影响」
- 「借新还旧，先把这个平了，利息我们帮你算」

## 三、识别高危借款产品的清单

不管对方叫什么名字，命中下面任何一条就要停下来：

| 信号 | 为什么危险 |
| --- | --- |
| **不看还款能力、当天放款** | 合规机构必然评估还款能力；不评估说明它靠违约金赚钱 |
| **要求提供通讯录权限** | 这是为爆通讯录催收准备的，正常借贷不需要 |
| **要求提供身份证照片/手持身份证/裸照** | 用于威胁；裸照类还涉及敲诈勒索等更重罪名 |
| **要求提供学信网截图、校园卡** | 明确锁定学生身份 |
| **合同金额 ≠ 实际到手金额** | 砍头息，见上节特征 ① |
| **利率用「日息」「手续费」表达，不给年化** | 掩盖真实成本 |
| **违约金条款畸高** | 违约金的真实目的是滚债务 |
| **要求你签多份合同、签给不同主体** | 制造多个债权人，便于轮番索债 |
| **催收威胁「告诉你爸妈/学校/发群里」** | 这本身可能构成违法催收 |

**一个自查动作**：把「到手金额」和「总共要还的钱」算出来，除以到手金额，再按实际期限折算成年化。多数高危产品的真实年化高到你自己都不敢签。

## 四、法律边界：哪些钱可以不还

这一节最需要精确，也最容易被人误传。

### 4.1 民间借贷的利率上限

【法规】最高人民法院《关于审理民间借贷案件适用法律若干问题的规定》（2020 年修正）确立了以 **LPR 为基准的浮动上限**：出借人请求借款人按照合同约定利率支付利息的，人民法院应予支持，但**双方约定的利率超过合同成立时一年期贷款市场报价利率（LPR）四倍的除外**。

**必须说清的三点**：

1. 这是**民间借贷**的规则。银行、消费金融公司等**持牌金融机构**的金融借款，适用金融审判的相关规则，不直接套用四倍 LPR。【待核实】具体适用规则需依个案与现行司法解释判断。
2. **LPR 每月公布、会变动**，所以上限不是一个固定数字。**不要相信任何写死「超过 X% 不用还」的说法**，包括本文。
3. 超过上限的部分，法院不予支持——但这**不等于「整笔不用还」**。本金和上限内的利息仍然要还。

### 4.2 哪些条款本身可能无效

| 条款 | 情况 |
| --- | --- |
| 砍头息（预先扣除利息） | 【法规】《民法典》第六百七十条：借款的利息不得预先在本金中扣除。预先扣除的，应当按照实际借款数额返还借款并计算利息 |
| 畸高违约金 | 可请求法院调整 |
| 「服务费」「咨询费」「管理费」变相计息 | 通常被合并计算为利息，受利率上限约束 |
| 要求以裸照、通讯录作担保 | 不具合法效力，且相关行为可能构成犯罪 |

### 4.3 一个必须纠正的说法

网上常见「套路贷不用还」——**这句话不准确**。准确的说法是：

- 「套路贷」是刑事案件，**首要动作是报警**
- 虚增的部分、违法部分不受保护
- 但**你实际收到的本金**，在民事上仍可能需要返还——具体由司法机关认定

**所以：不要自行判断「这笔不用还」，也不要自行「不还了等着」**。正确路径是报警，让司法机关认定债权性质。

## 五、已经借了怎么办（按情况分路径）

### 情况 A：持牌机构的正常贷款，但还不上

| 步骤 | 做什么 |
| --- | --- |
| 1 | **不要借新还旧**——这是唯一会把小事变大事的动作 |
| 2 | 主动联系机构，申请**延期、展期或分期**（正规机构有这些通道，越早谈越好） |
| 3 | 书面确认协商结果，保留记录 |
| 4 | 如果确实无力偿还，如实告诉家人——**这是止损，不是丢人** |
| 5 | 逾期已发生：查征信报告，确认记录是否准确；对错误记录可提出异议 |

### 情况 B：怀疑是「套路贷」

| 步骤 | 做什么 |
| --- | --- |
| 1 | **立即停止还款**（尤其是「平账」「走流水」类要求） |
| 2 | **保全证据**：合同、转账记录、聊天记录、通话录音、催收短信、APP 截图 |
| 3 | **报警**（110 或到派出所），说明「疑似套路贷」，提交证据 |
| 4 | 同步告知家人与辅导员——催收会联系他们，让他们有准备 |
| 5 | 遭遇虚假诉讼时，向法院提交报警回执与证据 |
| 6 | 咨询法律援助（12348）或律师 |

**证据清单（现在就存）**：

- [ ] 借款合同/协议全文（含电子合同截图、APP 页面）
- [ ] 所有转账记录（银行流水、支付平台账单）
- [ ] 与对方的全部聊天记录（不要删）
- [ ] 通话录音（合法取得，用于证明威胁内容）
- [ ] 催收短信、电话记录、来电号码
- [ ] APP 名称、下载渠道、公司名称

### 情况 C：被威胁、被爆通讯录

| 行为 | 定性 |
| --- | --- |
| 爆通讯录、群发欠款信息 | 侵犯隐私与名誉，可报警 |
| 威胁人身安全 | 可能构成寻衅滋事、敲诈勒索等，报警 |
| 冒充公检法、发「逮捕通知」 | 典型诈骗，报警 |
| 上门滋扰 | 报警，不要单独应对 |
| 要求以裸照抵债 | 可能构成敲诈勒索、传播淫秽物品等，**立即报警** |

**不要做的事**：不要因为害怕而继续转账，不要私下和催收「谈条件」给钱，不要删证据。

## 六、预防：四个具体动作

| 动作 | 说明 |
| --- | --- |
| **关掉「先用后付」「分期」的默认开通** | 很多平台默认开通，是借款的第一步 |
| **手机不授权通讯录给借贷类 App** | 一次授权，长期暴露 |
| **不看「日息」看「年化」** | 让对方给出年化综合成本，给不出的直接放弃 |
| **先用「24 小时规则」** | 任何超过一定金额的借款，隔 24 小时再决定；绝大多数冲动借贷熬不过一天 |

以及最重要的一条：**生活费的缺口不要用借贷补。** 缺钱的正确解法是困难认定（01-10）、助学金与勤工助学（03-03）、临时困难补助，不是贷款。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 借一点点，很快能还上 | 「很快还上」是最常见的开始，也是最少实现的结局 |
| 不还就没事 | 持牌机构会上征信；套路贷则可能演变为诉讼或暴力催收 |
| 告诉家里就完了 | 隐瞒才是真的完了；越早说，能选的方案越多 |
| 套路贷完全不用还 | 违法部分不受保护，但实际收到的本金在民事上仍可能需返还，由司法机关认定 |
| 只要年化不超过 36% 就合法 | 该表述已过时；现行规则是四倍 LPR 的浮动上限，且 LPR 会变 |
| 催收打电话就还一点稳住 | 还一点不解决债务，只延长纠缠；套路贷中还会被当作「认账」证据 |
| 借钱是个人隐私，不必让学校知道 | 被爆通讯录时学校迟早会知道；主动说明能获得帮助 |
| 报警没用，警察不管经济纠纷 | 套路贷是刑事案件，不是经济纠纷；报警要说清「疑似诈骗」而非「借钱不还」 |

## 可执行清单

### 借之前

- [ ] 算出真实年化（到手金额 vs 总还款额 vs 期限）
- [ ] 确认放款方是持牌机构还是不明来源
- [ ] 检查合同：金额是否等于到手金额，有无砍头息
- [ ] 检查有无要求通讯录、身份证照片、裸照、学信网截图
- [ ] 过 24 小时再决定

### 已经借了

- [ ] 立刻停止借新还旧
- [ ] 按第五节的证据清单存好所有材料
- [ ] 判断属于 A/B/C 哪种情况，走对应路径
- [ ] 主动告知家人（越早越好）
- [ ] 涉及套路贷 → 报警；涉及催收威胁 → 报警

### 止损后的修复

- [ ] 查一次个人信用报告，核对记录
- [ ] 制定还款计划（只还合法部分，通过正规渠道）
- [ ] 需要时申请法律援助（12348）
- [ ] 把这次的触发原因写下来（消费缺口 / 被骗 / 赌 / 社交压力），针对原因解决

## 一句话记住

**正常的贷款怕你不还，套路贷怕你还——所以一旦发现「怎么还都还不完」，那不是你不够努力，那是刑事案件，去报警。**
