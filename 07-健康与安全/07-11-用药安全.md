# 用药安全：常备药、抗生素、止痛药

> 一句话概括：最常见的用药事故不是吃错药，是把同名成分吃了两遍。

**适用人群**：自己买药吃的学生；宿舍备着感冒药的人；感冒时「多吃几种好得快」的人；长期靠止痛药、褪黑素的人。

> **本文性质**
>
> 本文是用药常识整理，**不能替代医生或药师的指导**。用药前请阅读说明书；有基础疾病、正在服用其他药物、或为孕妇/哺乳期，**必须咨询医生或药师**。

> **政策适用范围**
> - 主要依据：《中华人民共和国药品管理法》；国家药品监督管理局药品说明书与标签管理规定；《处方药与非处方药分类管理办法》
> - 全国统一：**药品管理、处方药/非处方药分类、说明书规范全国统一**
> - 核查日期：2026-11-05
>
> ⏳ 易过时：具体药品的说明书内容、部分药品的分类调整。

## 一、最危险的一件事：对乙酰氨基酚过量

**这是本文最重要的内容。** 每年都有因为"感冒药吃多了"导致肝损伤的案例，而原因几乎都是同一个：**不知不觉重复服用了同一种成分。**

### 1.1 为什么容易重复

**多数复方感冒药都含对乙酰氨基酚**（也叫扑热息痛、醋氨酚）。

| 你同时吃了 | 结果 |
| --- | --- |
| 两种感冒药（如"感冒灵"+"白加黑"） | 对乙酰氨基酚叠加，可能超量 |
| 感冒药 + 退烧药（如"泰诺"+"对乙酰氨基酚片"） | 同上 |
| 感冒药 + 某些止痛药 | 同上 |
| 中西药复方制剂（部分中成药含西药成分） | **最容易被忽略** |

**关键认识**：这些药的名字看起来完全不同，但**有效成分是同一个**。

### 1.2 后果

| 后果 | 说明 |
| --- | --- |
| **肝损伤** | 对乙酰氨基酚过量是药物性肝损伤的常见原因 |
| 严重可致肝衰竭 | 需要住院治疗，极端情况危及生命 |
| **早期症状不明显** | 可能只是恶心、乏力，容易被忽略 |

### 1.3 怎么做

| 做法 | 说明 |
| --- | --- |
| **吃任何感冒药前，看成分表** | 找「对乙酰氨基酚」这个成分 |
| **只吃一种复方感冒药** | 不要"两种一起吃好得快" |
| **不要再叠加单一成分退烧药** | 如果已吃含对乙酰氨基酚的感冒药 |
| 不超说明书剂量 | 不要"多吃一片好得快" |
| 不饮酒 | 酒精会增加肝损伤风险 |

> 【经验】「对乙酰氨基酚过量伤肝、多种感冒药同吃会超量」是药学领域的通行认识。**具体剂量、每日上限按说明书执行，本文不给数字**——不同制剂含量差异大，个体情况（肝功能、饮酒、体重）也影响判断。

### 1.4 已经吃多了怎么办

| 情况 | 做法 |
| --- | --- |
| 刚吃下、意识清醒 | **立即就医或打 120**，说明吃了什么、多少 |
| 已经过了几小时，出现恶心、乏力、右上腹不适 | **立即就医** |
| 不确定吃了多少 | 带着药盒去医院 |

**不要等出现症状再处理。** 对乙酰氨基酚过量的早期可能没有明显症状，但肝损伤已经在发生。

## 二、抗生素：四个必须知道的点

### 2.1 抗生素不能治感冒

| 事实 | 说明 |
| --- | --- |
| **普通感冒多数是病毒引起的** | 抗生素只对细菌有效 |
| **吃抗生素不会让感冒好得更快** | 反而增加副作用和耐药风险 |
| 流感也是病毒 | 同上 |

**那什么时候需要抗生素？** 由医生判断。比如确诊的细菌性扁桃体炎、细菌性肺炎、尿路感染等。

### 2.2 抗生素是处方药

应当经医生诊断后使用，**不要自行在药店购买服用**（部分药店可能违规销售）。

### 2.3 要用就足疗程

| 错误做法 | 后果 |
| --- | --- |
| 「好点了就停」 | 细菌未被完全清除，容易复发 |
| 「剩下几片留着下次吃」 | 剂量不足，且可能不对症 |
| 「自己减量」 | 同上 |

**具体疗程由医生确定，本文不给天数。**

### 2.4 抗生素不是「消炎药」

| 概念 | 说明 |
| --- | --- |
| **抗生素** | 针对**细菌** |
| **抗炎药**（如布洛芬） | 减轻炎症反应，不杀细菌 |
| 日常说的「消炎」 | 混用了这两个概念 |

这就是为什么"嗓子发炎就吃阿莫西林"是错的——多数咽炎是病毒性的。

## 三、止痛药：布洛芬 vs 对乙酰氨基酚

这两种是最常见的非处方止痛退烧药，很多人不知道它们的区别。

| | 对乙酰氨基酚 | 布洛芬 |
| --- | --- | --- |
| **退烧** | 有 | 有 |
| **止痛** | 有 | 有 |
| **抗炎** | **无** | **有** |
| **对胃的刺激** | 较小 | **较大** |
| **主要风险** | **过量伤肝** | **伤胃、可能影响肾** |
| **适用提醒** | 不饮酒；不与其他含同成分的药叠加 | 胃病、肾病者慎用；饭后服用可减轻胃刺激；不与其他非甾体抗炎药同用 |

### 3.1 五条实用原则

| 原则 | 说明 |
| --- | --- |
| **不要同时吃两种** | 不会叠加效果，只会叠加副作用 |
| 不要超过说明书剂量和频次 | —— |
| **不要长期自行服用** | 疼痛持续不缓解，应查明原因 |
| 胃不好的人优先考虑对乙酰氨基酚 | 但仍需注意肝的问题 |
| 服药期间不饮酒 | 尤其对乙酰氨基酚 |

### 3.2 关于「止痛药上瘾」

常见的非处方止痛药（对乙酰氨基酚、布洛芬）**不属于成瘾性药物**，正常按说明书使用不会成瘾。

但要注意另一件事：**长期靠止痛药掩盖症状，可能延误诊断**。头痛、腹痛持续不缓解，应该查原因，而不是加量吃药。

> 【经验】以上为常见非处方止痛药的通行认识。**具体选用、剂量、禁忌，按说明书并由医生或药师判断。** 有胃溃疡、肾功能不全、哮喘、正在服用抗凝药等情况，用药前必须咨询。

## 四、宿舍常备药：怎么备，备什么

### 4.1 建议清单（原则性）

| 类别 | 用途 | 注意 |
| --- | --- | --- |
| 退烧止痛（对乙酰氨基酚 **或** 布洛芬，二选一） | 发热、头痛、牙痛 | **不要两种都备**，避免叠加 |
| 口服补液盐 | 腹泻、呕吐后补水 | 优于单纯喝水 |
| 复方感冒药（一种即可） | 缓解感冒症状 | **看成分，避免与退烧药叠加** |
| 抗过敏药 | 过敏性鼻炎、荨麻疹 | 部分会引起嗜睡 |
| 外用：碘伏、创可贴、无菌纱布 | 小伤口 | 碘伏优于酒精（刺激性小） |
| 体温计 | —— | —— |
| 个人处方药 | 慢性病 | 按医嘱，注意有效期 |

### 4.2 备药的三条原则

| 原则 | 说明 |
| --- | --- |
| **少而精** | 备太多容易过期，也容易吃错 |
| **保留原包装和说明书** | 拆散分装后就看不出成分和有效期了 |
| **定期清理** | 每学期检查一次有效期；过期药按有害垃圾处理，不要吃 |

### 4.3 关于「室友的药能不能吃」

**不建议。** 原因：

- 可能是处方药，适应症不符
- 可能有你不知道的禁忌（对方有胃病、过敏史）
- 剂量可能不适合你

**急用时可以借，但要看清成分和有效期，并确认自己不对该成分过敏。**

## 五、几个容易踩的坑

### 5.1 抗生素 + 酒精

部分抗生素（尤其某些头孢类）与酒精同用可能引起严重反应。

| 做法 | 说明 |
| --- | --- |
| 用药期间不饮酒 | —— |
| 停药后也要等一段时间 | **具体间隔按药品说明书与医生指导，本文不给天数** |
| 注意「隐形酒精」 | 藿香正气水、部分漱口水、酒心巧克力 |

### 5.2 嗜睡类药物

| 药物类型 | 影响 |
| --- | --- |
| 含抗组胺成分的感冒药 | 嗜睡、反应变慢 |
| 部分抗过敏药（第一代） | 明显嗜睡 |
| 部分止咳药 | 可能嗜睡 |

**服药后不要开车、骑车、操作机械。** 也不要在这时候去参加需要集中注意力的活动。

### 5.3 中西药同服

部分中成药含西药成分（如某些"感冒灵"含对乙酰氨基酚）。**同时服用中成药和西药，可能造成成分重复。**

**做法**：看成分表，或咨询药师。

### 5.4 保健品不是药

| 看批准文号 | 是什么 |
| --- | --- |
| **国药准字** | 药品 |
| **国食健字**（或保健食品标志） | 保健食品 |
| SC 编号 | 食品 |

**保健食品不能宣称治疗作用。** 如果某个"保健品"声称能治病，要么是虚假宣传，要么是违法。

### 5.5 网购药品

| 注意 | 说明 |
| --- | --- |
| 在正规平台、有资质的药店购买 | 处方药需凭处方 |
| 警惕"特效药""祖传秘方" | 成分不明，可能是假药 |
| 海外代购药 | 成分、剂量可能与国内不同，且无中文说明书 |

## 六、褪黑素不是安眠药

这一节单独说，因为它的误解最普遍。

| 事实 | 说明 |
| --- | --- |
| 褪黑素是**调节昼夜节律**的物质 | 不是镇静催眠药 |
| 它**不是**治疗失眠的药物 | 对入睡困难可能有些帮助，但对失眠的整体治疗不是一线方案 |
| 更适合的场景 | 倒时差、倒班等**节律紊乱** |
| 长期失眠 | **应就医**。一线方案是认知行为治疗（CBT-I），不是自己买褪黑素长期吃 |

> 【经验】「褪黑素不是安眠药」是睡眠医学领域的通行认识。**具体是否适合使用、用多久，由医生判断。** 睡眠调整的非药物方法见 07-04。

### 6.1 为什么不建议自己长期吃

| 原因 | 说明 |
| --- | --- |
| 掩盖真正的问题 | 失眠可能是情绪问题、呼吸问题、药物副作用 |
| 长期安全性数据有限 | 尤其长期大剂量 |
| 可能影响自身分泌节律 | 需专业判断 |
| 买到的不一定是药 | 市售产品按保健食品管理，剂量与纯度差异大 |

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「感冒多吃几种药好得快」 | 可能导致对乙酰氨基酚过量伤肝，**这是最常见的用药事故** |
| 「抗生素能消炎」 | 抗生素只针对细菌；多数感冒是病毒 |
| 「症状好了就停药」 | 抗生素需足疗程 |
| 「止痛药多吃点更有效」 | 增加副作用，不增加效果 |
| 「两种止痛药一起吃效果更好」 | 不会叠加效果，只会叠加副作用 |
| 「中药没有副作用」 | 中成药也可能含西药成分，也有不良反应 |
| 「保健品能治病」 | 不能，保健食品不得宣称治疗作用 |
| 「褪黑素是天然安眠药」 | 不是安眠药，是节律调节剂 |
| 「别人吃着有效的我也能吃」 | 处方药需医生指导；个体差异大 |
| 「过期药只是效果差点」 | 可能失效，也可能产生有害物质，不要吃 |
| 「症状压下去就好了」 | 掩盖症状可能延误诊断 |

## 八、可执行清单

### 买药前

- [ ] 看**成分表**（尤其找「对乙酰氨基酚」）
- [ ] 看**批准文号**（药品是「国药准字」）
- [ ] 处方药凭处方购买，不自行购买抗生素
- [ ] 看有效期
- [ ] 不买来源不明的"特效药"

### 吃药时

- [ ] 按说明书剂量，不自行加量
- [ ] **不叠加含同一成分的多种药**
- [ ] 抗生素足疗程，不自行停药
- [ ] 服药期间不饮酒（尤其对乙酰氨基酚、头孢类）
- [ ] 服嗜睡类药物后不开车、不骑车
- [ ] 不同时吃两种止痛药

### 宿舍备药

- [ ] 对乙酰氨基酚 **或** 布洛芬，只备一种
- [ ] 感冒药只备一种，且知道它含什么成分
- [ ] 保留原包装和说明书
- [ ] 每学期清理一次过期药
- [ ] 口服补液盐备一盒（腹泻时有用）

### 特殊情况（必须就医或咨询药师）

- [ ] 服药后出现皮疹、呼吸困难 → **立即就医**
- [ ] 怀疑吃多了 → **立即就医，带药盒**
- [ ] 长期失眠 → 就医，不长期吃褪黑素
- [ ] 疼痛持续不缓解 → 查明原因，不加量吃药
- [ ] 正在服用其他药物或保健品 → 咨询药师（可能相互作用）
- [ ] 有胃病、肾病、肝病、哮喘 → 用药前必须咨询

## 九、一句话记住

**感冒药只吃一种（对乙酰氨基酚吃过量会伤肝），抗生素不治感冒，吃头孢别喝酒，褪黑素不是安眠药。**
