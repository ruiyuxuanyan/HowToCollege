# 性健康与避孕：正规渠道与常见误解

> 一句话概括：避孕套是唯一能同时防怀孕和防病的方法，这一点没有替代品。

**适用人群**：有或可能有性行为的在校生；想弄清避孕方法的人；想去做检查但不知道去哪、怕被评判的人；帮朋友找信息的人。

> **本文性质**
>
> 本文是健康信息整理，**不构成医疗建议**。所有避孕方法的选择、处方药的使用、检查与治疗，**必须由医生评估**。
>
> 本文**不评判任何人**：不评判是否发生性行为、不评判和谁、不评判几次。只提供正确的信息和正规的渠道。

> **政策适用范围**
> - 主要依据：《中华人民共和国基本医疗卫生与健康促进法》；《中华人民共和国人口与计划生育法》；《中华人民共和国传染病防治法》；《中华人民共和国疫苗管理法》
> - 全国统一 / 地方执行：**制度框架全国统一；免费避孕药具发放点、青少年友好门诊的设置由各地执行**
> - 核查日期：2026-11-05
>
> ⏳ 易过时：免费药具发放点的位置与方式、各医院的服务设置、HPV 疫苗的适用年龄与预约方式。

## 一、这一篇只做三件事

网络上这个话题的信息充满错误和羞耻感。本文只做三件事：

| 做 | 不做 |
| --- | --- |
| 说清各种避孕方法的效果与局限 | 说教、评判、制造羞耻 |
| 告诉你正规渠道在哪 | 推荐具体品牌或产品 |
| 说清什么情况必须就医 | 给具体的用药方案或剂量 |

**一个前提**：知情是保护自己的前提。信息越模糊，风险越高。

## 二、避孕方法对比

### 2.1 核心对照表

| 方法 | 避孕效果 | 防性病 | 使用要点 |
| --- | --- | --- | --- |
| **男用避孕套** | 正确使用时效果好 | **能** | **唯一能同时防性病的方法** |
| **女用避孕套** | 效果较好 | 部分能 | 使用不如男用套普遍 |
| **短效口服避孕药** | 规律服用时效果好 | **不能** | **处方药**，需每天固定时间服用 |
| **宫内节育器（IUD）** | 效果好、长效 | **不能** | 需医生放置；未生育者也可使用（由医生评估） |
| **皮下埋植** | 效果好、长效 | **不能** | 需医生操作 |
| **避孕针** | 效果好 | **不能** | 需按周期注射 |
| **紧急避孕药** | **效果有限，越晚越差** | **不能** | **只作补救，非常规方法** |
| **体外排精** | **效果差** | **不能** | 失败率高，不推荐 |
| **安全期/日历法** | **效果差** | **不能** | 月经不规律时基本不可靠 |

> 【经验】上表为避孕方法的通行分类与相对效果，**未给出任何具体有效率数字**——不同研究口径、"完美使用"与"典型使用"的结果差异很大，写固定数字容易误导。

### 2.2 必须记住的一条

**只有避孕套能防性传播疾病**（包括 HIV、梅毒、淋病、衣原体、HPV 等）。

其他所有方法（口服药、IUD、埋植、避孕针）**都只防怀孕，不防病**。

> **如果你有多个性伴侣，或不确定对方的状况，避孕套不是"可选项"，是"必须项"。**
>
> **即使使用了其他避孕方法，仍应使用避孕套防病。**

### 2.3 关于"双重保护"

通行的建议是：**激素类避孕（如短效口服药）+ 避孕套**。

| 层次 | 提供什么 |
| --- | --- |
| 激素类 | 高避孕效果 |
| 避孕套 | 防病保护 |
| 两者叠加 | 容错率更高（一种失效时另一种仍在） |

## 三、紧急避孕药：只作补救

### 3.1 三个必须知道的点

| 点 | 说明 |
| --- | --- |
| **① 越早越好** | 效果随时间下降。**具体时间窗按药品说明书与医生/药师指导**，本文不给数字 |
| **② 效果有限** | 不是"吃了就一定没事"，明显低于常规避孕方法 |
| **③ 不能当常规方法** | 激素剂量高，频繁使用会扰乱月经周期 |

### 3.2 常见误解

| 误解 | 实际 |
| --- | --- |
| 「事后吃药就万无一失」 | 效果有限，且越晚越差 |
| 「可以经常吃」 | 不能。这是补救措施，不是避孕方案 |
| 「吃了就不会怀孕了」 | 仍可能怀孕。月经推迟需要检测 |
| 「紧急避孕药会导致不孕」 | 没有证据支持"一次使用导致不孕"；但频繁使用会扰乱周期【经验】 |
| 「紧急避孕药能防病」 | **不能** |
| 「紧急避孕药是堕胎药」 | 作用机制不同，不是同一回事 |

### 3.3 服药后要注意

- 如果下次月经**明显推迟**，应做妊娠检测
- 出现严重腹痛、异常出血 → 就医
- 服药后如再次发生性行为，仍需避孕（药物不提供持续保护）

> 【经验】以上为紧急避孕药的通行认识。**具体用法、时间窗、禁忌症必须按说明书并由医生或药师指导。**

## 四、正规渠道：去哪问、去哪看

### 4.1 渠道对照

| 需求 | 去哪 | 说明 |
| --- | --- | --- |
| 避孕咨询、开药 | 校医院、社区卫生服务中心、妇幼保健院 | 短效口服药需处方 |
| 性传播疾病检测 | 疾控中心（CDC）、三甲医院皮肤性病科 | 疾控通常有免费或低价检测 |
| **HIV 检测** | 疾控中心 | 通常提供免费、匿名检测【待核实】当地具体安排 |
| HPV 疫苗 | 社区卫生服务中心、部分医院 | 需预约，见 07-10 |
| 意外怀孕 | **正规医院妇产科** | 不要自行处理 |
| 与性相关的焦虑/关系困扰 | 校心理咨询中心 | 免费，有保密原则（见 06-07） |

### 4.2 免费避孕药具

国家有免费避孕药具发放政策。发放点通常设在社区卫生服务中心、部分高校校医院、部分城市设有自助发放机。

> 【待核实】本校与所在城市的发放点位置、领取方式不同。可咨询校医院、社区卫生服务中心，或当地卫生健康部门。

### 4.3 关于隐私

| 担心 | 实际情况 |
| --- | --- |
| 「去看妇科会被同学知道」 | 就医记录属于医疗隐私，医院有保密义务 |
| 「校医院会不会告诉辅导员」 | 一般不会；医疗信息受隐私保护【待核实】具体规定 |
| 「检查会被记录在档案里」 | 就医记录独立保存，一般不进入学籍档案 |

**如果担心隐私**，可以选择校外医院，用身份证挂号即可（多数医院不需要其他证明）。

### 4.4 网络信息的可靠性

| 来源 | 可靠性 |
| --- | --- |
| 国家卫生健康委、疾控中心官方发布 | 高 |
| 正规医院官方科普、专业学会指南 | 高 |
| 健康类 App、自媒体 | **差异极大，需交叉验证** |
| 论坛、匿名社区 | **低，常有错误信息与恐吓内容** |

**判断方法**：如果一篇文章在制造恐惧、推销产品、或给出"绝对"的结论，就要警惕。

## 五、警惕非法机构

### 5.1 常见形式

| 形式 | 风险 |
| --- | --- |
| **"无痛人流"小广告**（厕所、电线杆、网络弹窗） | 可能无资质、设备简陋、术后无保障 |
| **"包治性病""一针见效"** | 虚假宣传，可能延误治疗 |
| **网络售卖的"特效药"** | 成分不明，可能是假药 |
| **"免费检查"后推销治疗** | 典型的诱导消费模式 |
| **私人诊所无证行医** | 安全无保障 |

### 5.2 怎么识别正规机构

| 看什么 | 正规 |
| --- | --- |
| 机构资质 | 有《医疗机构执业许可证》，可在当地卫生健康部门官网查询 |
| 人员 | 医生有执业资格，可查询 |
| 收费 | 明码标价，有正规票据 |
| 宣传 | 不做"绝对治愈""无痛无风险"这类承诺 |

### 5.3 一条底线

**任何涉及"手术""治疗"的事情，去正规医院。** 便宜和方便，不值得用健康去换。

## 六、几个必须说清的事实

### 6.1 关于"第一次"

| 说法 | 实际 |
| --- | --- |
| 「第一次不会怀孕」 | **错误**。只要有性行为就可能怀孕 |
| 「第一次一定出血」 | **不一定**。不出血是正常的 |
| 「可以用是否出血判断是不是处女」 | **没有科学依据**。这是流传很广的错误观念 |

### 6.2 关于性传播疾病

| 事实 | 说明 |
| --- | --- |
| 很多性病**早期没有症状** | 无症状不等于没感染 |
| 有性行为的人**应定期检测** | 尤其有多个性伴侣或更换伴侣时 |
| 检测通常**保密** | 疾控中心与医院有保密义务 |
| 多数性病**可以治疗** | 关键是早期发现、正规治疗 |
| 拖延治疗**可能造成长期后果** | 如影响生育能力 |

> 【经验】以上为性健康领域通行认识。**具体检测项目、频率、治疗由医生根据情况决定。**

### 6.3 关于同意

这一条不在医学范畴，但必须写：

| 原则 | 说明 |
| --- | --- |
| **同意必须是明确的** | 沉默、不反抗、没有说"不"，**都不等于同意** |
| **同意可以随时撤回** | 任何时候说停，就必须停 |
| **同意不能推定** | 以前同意过，不代表这次同意 |
| **醉酒、昏迷状态下无法给出有效同意** | 此时发生性行为可能构成犯罪 |
| **可以拒绝任何不愿意的性行为** | 包括在关系中的 |

涉及强迫、胁迫、趁人醉酒的情况，见 **06-02**。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「体外排精很安全」 | 失败率高，且不防病 |
| 「安全期可以不用套」 | 月经不规律时基本不可靠 |
| 「洗一洗就没事」 | 不能避孕，也不能防病 |
| 「吃了紧急避孕药就没事」 | 效果有限，越晚越差，不能常规使用 |
| 「只有女生需要负责避孕」 | 避孕是双方的事；避孕套由男方使用，但双方都应知情 |
| 「用了其他避孕方法就不用套」 | 其他方法不防病，仍需用套 |
| 「没有症状就是没病」 | 很多性病早期无症状 |
| 「去检查很丢人」 | 检查是对自己负责，医务人员有保密义务 |
| 「只有乱交才会得性病」 | 单一伴侣也可能（对方感染） |
| 「HPV 疫苗打了就不用筛查」 | 仍需按医生建议定期筛查 |
| 「小广告上的"无痛"更便宜方便」 | 可能无资质，风险远大于省钱 |

## 八、可执行清单

### 知情准备（在发生性行为之前）

- [ ] 了解至少两种避孕方法的效果与局限
- [ ] 明确：**只有避孕套能防病**
- [ ] 知道紧急避孕药是补救，不是方案
- [ ] 和对方明确谈过避孕方式（不要默认）
- [ ] 知道"同意"必须是明确的、可随时撤回的

### 物资与使用

- [ ] 避孕套（检查有效期，不用过期的）
- [ ] 知道正确用法：**开封不撕破、挤出前端空气、全程使用**
- [ ] 不用油性润滑剂配合乳胶避孕套（会破坏乳胶）
- [ ] 一次只用一个（同时用两个更容易破）

### 需要就医的情况

- [ ] 月经明显推迟 → 做妊娠检测
- [ ] 异常阴道出血、严重腹痛 → 就医
- [ ] 生殖器溃疡、异常分泌物、皮疹 → 就医
- [ ] 有多个性伴侣或更换伴侣 → 定期检测
- [ ] 担心暴露于 HIV → **尽快就医**（越早越好，具体由医生判断）

### 查清渠道（现在就做）

- [ ] 本校校医院是否有妇科/全科门诊、门诊时间
- [ ] 最近的综合医院妇科位置
- [ ] 当地疾控中心的检测与咨询方式
- [ ] 社区卫生服务中心的位置（免费药具）

### 如果遇到强迫或侵害

- [ ] 见 **06-02**（性骚扰的处理与取证）
- [ ] 见 **07-03**（心理危机求助）
- [ ] 保留证据，尽快就医
