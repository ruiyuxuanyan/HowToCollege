# 宿舍与实验室安全：用电、消防、化学试剂

> 一句话概括：火灾和化学品事故的后果，比违规处分的后果严重得多。

**适用人群**：住校生；进实验室的理工科、医科学生；在宿舍用大功率电器的人；参加实验课、跟导师做项目的人。

> **本文性质**
>
> 本文是安全信息整理，**不能替代专业培训与应急处置指导**。涉及化学品具体处置时，**以 SDS（化学品安全技术说明书）和实验室安全规程为准**。

> **政策适用范围**
> - 主要依据：《中华人民共和国消防法》；《高等学校实验室安全规范》（教育行政部门相关文件）；《中华人民共和国安全生产法》
> - 全国统一 / 地方执行：**法律框架全国统一；各校宿舍管理规定、实验室安全制度由学校制定**
> - 核查日期：2026-11-05
>
> ⏳ 易过时：各校违规电器的具体清单、处分标准。

## 一、宿舍用电：最危险的不是电器，是电池

### 1.1 风险排序

| 风险 | 危险程度 | 说明 |
| --- | --- | --- |
| **电动车电池带回宿舍充电** | **最高** | 锂电池热失控起火极快，烟气有毒 |
| 大功率电器（热得快、电热锅、取暖器） | 高 | 超负荷、干烧 |
| 插排串接、过载 | 中高 | 一个插排接多个大功率设备 |
| 私拉电线 | 中高 | 线路老化、接触不良 |
| 充电器长期插着 | 中 | 劣质充电器有起火风险 |
| 充电宝过夜充电 | 中 | 劣质产品风险更高 |

**关于第一项必须说清楚**：

锂电池起火和普通火灾不同——它不需要外部氧气，会自行剧烈燃烧，且可能复燃。**一旦在室内起火，逃生窗口极短，烟气剧毒。**

> 【官方】近年来多地消防部门与应急管理部门反复提示：不得将电动自行车（或其电池）停放在建筑门厅、楼梯间、走道及室内充电。**具体规定以本校与当地消防要求为准**【待核实】。

**这一条不是"注意一下"级别的建议，是"绝对不要"级别的。**

### 1.2 宿舍用电的具体做法

| 做法 | 说明 |
| --- | --- |
| 使用学校允许的电器 | 违规电器的清单见本校《学生手册》 |
| 一个插排不串接另一个插排 | 串联会放大过载风险 |
| 大功率设备不与其他设备共用插排 | —— |
| 离开宿舍时拔掉充电器 | 尤其充电宝、电动车电池 |
| 不买无 3C 认证的充电器、插排 | 便宜但有风险 |
| 不私拉电线、不从别的宿舍接电 | —— |
| 电线不压在床垫下、不被重物压 | 避免绝缘破损 |

## 二、火灾：先判断，再行动

### 2.1 关键判断：扑救还是撤离

| 情况 | 做法 |
| --- | --- |
| **初期小火**（如垃圾桶起火、锅里起火），火势未蔓延，你能安全接近 | 可用灭火器扑救，**同时确保身后有退路** |
| **火势已蔓延、有浓烟、看不清路** | **立刻撤离，不要救火，不要拿东西** |
| **门把手发烫** | **不要开门**（门外可能是火），堵住门缝，从窗口呼救 |
| **楼道有浓烟** | 不要盲目冲出去，判断能否从其他通道撤离 |

**一句话原则**：**你只有一次判断机会，选"撤"永远不算错。**

### 2.2 记住：致命的主要是烟

火灾死亡多数不是烧死，而是**吸入有毒烟气**。

| 做法 | 说明 |
| --- | --- |
| 低姿前进 | 烟往上走，贴近地面空气相对好 |
| 湿毛巾捂口鼻 | **只能短暂缓解，不能过滤有毒气体**，不要指望它 |
| 关闭身后的门 | 减缓火势与烟气蔓延 |
| 不要乘电梯 | 断电会困住你，且电梯井是烟囱 |

### 2.3 逃生要点

| 做 | 不做 |
| --- | --- |
| 走**楼梯** | 不乘电梯 |
| 到安全地点后打 **119** | 不返回取物 |
| 如果被困，到窗口/阳台呼救，关门堵缝 | 不跳楼（低楼层也容易重伤） |
| 用湿布堵门缝，往门上泼水 | 不躲进卫生间等无窗空间（除无奈） |

### 2.4 灭火器怎么用

记住四个字：**提、拔、握、压**。

| 步骤 | 动作 |
| --- | --- |
| **提** | 提起灭火器 |
| **拔** | 拔掉保险销 |
| **握** | 握住喷管，**对准火焰根部** |
| **压** | 压下压把 |

**要点**：对准**根部**，不是对着火苗。站在上风口。

> 【待核实】各校宿舍楼配备的灭火器类型（干粉、二氧化碳等）不同，使用方法略有差异，以现场标识和培训为准。

## 三、实验室安全

### 3.1 三段式风险认识

| 阶段 | 主要风险 |
| --- | --- |
| **进入前** | 不知道有什么危险（没看标识、没读 SDS） |
| **操作中** | 溅出、吸入、起火、爆炸 |
| **事故后** | 不知道冲洗多久、不知道带什么信息给医生 |

### 3.2 常见危险标识

| 标识类型 | 含义 | 典型物质 |
| --- | --- | --- |
| 腐蚀性 | 强酸强碱，损伤皮肤与眼睛 | 盐酸、氢氧化钠 |
| 易燃 | 易挥发、易点燃 | 乙醇、乙醚、丙酮 |
| 有毒 | 吸入/接触有害 | 多种有机溶剂 |
| 氧化性 | 助燃，与可燃物接触可能起火 | 高锰酸钾、过氧化氢 |
| 生物危害 | 微生物、血液样本 | 培养基、临床样本 |
| 高压/低温 | 气瓶、液氮 | —— |

### 3.3 个人防护

| 装备 | 什么时候必须 |
| --- | --- |
| **护目镜** | 几乎所有化学操作（**眼睛损伤不可逆**） |
| **手套** | 接触任何试剂；注意手套材质要与试剂匹配 |
| **实验服** | 全程（防溅、防污染便服） |
| 通风橱 | 挥发性、有毒、有刺激性气味的试剂 |
| 口罩/防毒面具 | 按试剂要求 |

**核心原则**：**不要凭感觉判断"这个不危险"。先看标签，再看 SDS。**

### 3.4 化学品溅到身体：先冲，再送

| 情况 | 做法 |
| --- | --- |
| **溅到皮肤** | **立即用大量流动水冲洗**；同时脱去被污染的衣物 |
| **溅到眼睛** | **立即用洗眼器大量冲洗**（撑开眼睑，翻转眼睑冲洗），同时呼救；冲洗后立刻就医 |
| **吸入气体/蒸气** | 迅速转移到通风处；严重时就医 |
| **误服** | **不要自行催吐**（腐蚀性物质催吐会造成二次损伤），立即就医并带上试剂标签/SDS |

**关于冲洗时长**：通行原则是"充分、大量、持续"，**具体时长按 SDS 和实验室规程执行，本文不给数字**。

> 【经验】「先冲洗、再就医、带上试剂信息」是化学品伤害处置的通行原则。**具体冲洗时长、中和剂使用与否，必须按 SDS 与实验室规程执行——不要自行使用中和剂。**

### 3.5 事故后要带的三样东西

| 带上 | 为什么 |
| --- | --- |
| **试剂的 SDS/标签** | 医生需要知道是什么物质 |
| 事故经过 | 接触方式、时间、浓度 |
| 现场照片 | 便于判断 |

## 四、其他实验室常见风险

| 风险 | 说明 | 做法 |
| --- | --- | --- |
| **气瓶** | 高压、可能倾倒 | 固定牢靠，不擅自移动 |
| **液氮/干冰** | 极低温，密闭空间会置换氧气 | 通风，戴低温防护手套 |
| **离心机** | 不平衡会剧烈震动 | 严格配平 |
| **加热设备** | 无人看管起火 | 不长时间无人值守 |
| **玻璃器皿** | 破损、划伤 | 检查有无裂纹 |
| **独自实验** | 出事无人施救 | 避免深夜独自做危险操作 |
| **废弃物** | 混倒可能反应 | 按分类投放 |

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「小火自己能灭」 | 火势蔓延以秒计。判断不清就撤 |
| 「电梯更快」 | 火灾时电梯是死亡陷阱，且会断电 |
| 「湿毛巾能防毒烟」 | 只能短暂缓解，不能过滤有毒气体 |
| 「少量试剂不用护目镜」 | 事故往往发生在"少量"时；眼损伤不可逆 |
| 「电池带回宿舍充一下没事」 | 这是宿舍火灾的主要成因之一，且起火极快 |
| 「化学溅到冲一下就行」 | 需要充分、大量、持续冲洗，具体按 SDS |
| 「误服了催吐就好」 | 腐蚀性物质催吐会造成二次损伤，**不要催吐** |
| 「中和剂可以自己配」 | 中和反应放热，可能加重损伤，**不要自行使用** |
| 「违规电器最多没收」 | 引发火灾可能涉及处分、赔偿，甚至刑事责任 |
| 「实验做熟了就不用防护」 | 熟练带来的麻痹是事故主因 |

## 六、可执行清单

### 宿舍

- [ ] 查本校违规电器清单（《学生手册》）
- [ ] **不在宿舍给电动车电池充电**（最重要的一条）
- [ ] 插排不串接，不接多个大功率设备
- [ ] 离开时拔掉充电器、充电宝
- [ ] 不买无 3C 认证的电器与插排
- [ ] 知道最近的灭火器位置
- [ ] 知道两条疏散路线（不要只记一条）
- [ ] 知道宿舍楼的安全出口在哪

### 实验室（第一次进之前）

- [ ] 参加实验室安全培训并通过考核
- [ ] 知道洗眼器、紧急淋浴、灭火器、急救箱的位置
- [ ] 知道紧急疏散路线与集合点
- [ ] 学会查 SDS
- [ ] 确认护目镜、手套、实验服齐全

### 每次实验

- [ ] 看清所有试剂标签
- [ ] 护目镜、手套、实验服到位
- [ ] 挥发性试剂在通风橱操作
- [ ] 不独自做危险操作
- [ ] 废弃物按分类投放

### 出事时

- [ ] 火：判断不清就撤，走楼梯，打 119
- [ ] 化学品溅到：大量流水冲洗，就医，**带标签/SDS**
- [ ] 眼睛溅到：洗眼器冲洗，同时呼救
- [ ] 吸入气体：转移到通风处，严重时就医

**核查说明**：

**化学品处置做了保守处理**：未给出任何冲洗时长的具体分钟数、未给出中和剂配方、未给出不同试剂的具体处置差异，全部指向 SDS 与实验室安全规程，并明确写了「不要自行使用中和剂」。这是刻意的处理——不同化学品（酸、碱、有机溶剂、氧化剂）的处置方式不同，给出统一数字会造成误导。
