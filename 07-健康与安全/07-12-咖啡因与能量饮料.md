# 熬夜、咖啡因与能量饮料：剂量与风险

> 一句话概括：咖啡因是剂量问题，不是习惯问题——而中国的饮料包装上，偏偏不强制标这个剂量。

**适用人群**：每天靠咖啡、浓茶、奶茶、能量饮料提神的人；下午喝了就睡不着的人；考试周靠能量饮料硬撑的人。

> **核查日期**：2026-11-05
> ⏳ 易过时：饮品含量随配方、杯型、门店变化，本文给的是**公开可查的参考值**，不是产品承诺。看标签永远优先于看文章。

---

## 一、先给数字，不给「较高/中等」

大部分文章写到「咖啡因含量较高」就停了，这没有任何用。下面是可查的参考值：

| 饮品 | 常见规格 | 咖啡因含量（参考） | 折算每 100ml |
| --- | --- | --- | --- |
| 美式咖啡 | 355 ml | 约 **145 mg** | 约 41 mg |
| 拿铁咖啡 | 335 ml | 约 **75 mg** | 约 22 mg |
| 某品牌奶茶 | 470 ml | 约 **135 mg** | 约 27 mg |
| 红牛（经典款） | 250 ml | 约 **50 mg** | 约 20 mg |
| 一罐可乐 | 330 ml | 通常 30–40 mg 量级 | 较低 |

> 【官方】上述数值引自新华网 2024-05-30 报道中援引的公开标注数据与行业通例。

**这张表能推翻两个流行说法：**

| 流行说法 | 实际 |
| --- | --- |
| 「一杯奶茶 ≈ 8 罐红牛」 | **极端个例，不是常态**。按上表，470ml 奶茶（135mg）约相当于 2.7 罐红牛（50mg），不是 8 罐 |
| 「奶茶没有咖啡因」 | 有，而且一杯奶茶 ≈ 一杯拿铁，**接近美式的量** |

**但真正危险的不是这几种，是「差异极大」的那些**：现制茶饮的咖啡因含量取决于茶叶品种、投茶量、闷泡时间，同样叫「茉莉奶绿」，不同品牌能差好几倍。

## 二、安全摄入量：有明确数字

> 【官方】国家食品安全风险评估中心 2021 年发布《中国居民膳食咖啡因摄入水平及其风险评估》，建议**成年人每天摄入的咖啡因量不超过 400 mg**。

细分人群：

| 人群 | 参考限量 |
| --- | --- |
| 健康成年人 | **≤ 400 mg/天** |
| 18 岁以下未成年人 | **2.5 mg/kg 体重/天** |
| 孕妇、哺乳期 | 需更严格限制，遵医嘱 |
| 有心脏问题、焦虑倾向者 | 应更低或避免 |

**2.5 mg/kg 换算一下**（这是很多文章算错的地方）：

| 体重 | 每日上限 |
| --- | --- |
| 40 kg | 100 mg |
| 50 kg | 125 mg |
| 60 kg | 150 mg |

也就是说，**一个 50 kg 的 18 岁以下学生，一天一杯美式（145mg）就已经超了**。这不是危言耸听，是 2.5 mg/kg 直接算出来的。

> 【官方】该报告的另一个结论值得记住：我国成年人咖啡因摄入贡献率最高的依次是**茶叶、茶饮料、奶茶、咖啡**——也就是说，很多人以为自己「不喝咖啡所以没事」，实际咖啡因主要来自茶。

## 三、过量是什么感觉：身体会先告诉你

| 症状 | 说明 |
| --- | --- |
| 心悸、心跳加快 | 最常见，也是最该停的信号 |
| 手抖、坐立不安 | 剂量偏高的典型表现 |
| 焦虑、烦躁 | 咖啡因会放大焦虑 |
| 失眠 | 尤其下午之后摄入 |
| 胃部不适、反酸 | 刺激胃酸分泌 |
| 头痛（停用时） | 戒断反应，不是「上火」 |

**严重过量**（罕见但真实存在）：心律失常、抽搐。**与酒精混用时风险显著升高。**

> 【官方】中国人大网刊载的讨论提到：摄入大剂量咖啡因会引发「咖啡因中毒」，**摄入 10 克以上可致命**。10 克 = 10000 mg，相当于约 70 杯美式——日常喝达不到，但**咖啡因片/粉剂**是另一回事，那是真正会出人命的形态。

---

## 四、能量饮料：问题不只是咖啡因

| 成分 | 问题 |
| --- | --- |
| 咖啡因 | 含量常偏高，且常与瓜拉纳（天然咖啡因来源）叠加 |
| **糖** | 一罐可能含 25–50 g 糖，接近每日建议上限 |
| 牛磺酸、瓜拉纳等 | 与咖啡因协同，总效应难预估 |
| **与酒精混用** | 掩盖醉意 → 喝更多 → 心血管风险与急性酒精中毒风险上升 |

**最危险的做法：能量饮料兑酒。** 咖啡因让你「感觉清醒」，但血液酒精浓度一点没降，判断力和反应速度仍然受损——你会误以为自己能开车。

---

## 五、中国的一个特殊问题：包装上不强制标咖啡因

这是本文最该记住的一条实用信息。

| 国家/地区 | 咖啡因标注 |
| --- | --- |
| 中国 | **营养标签强制标示的是能量、蛋白质、脂肪、碳水、钠**，咖啡因不在其中，通常**不标注** |
| 美国 | 常规食品不强制，但膳食补充剂需标 |
| 欧盟 | 高咖啡因饮料（>150 mg/L）须标注「高咖啡因含量」及含量 |
| 澳新 | 含咖啡因饮料有标注与配方限制 |

**后果**：在国内买一瓶饮料，你很可能**无法从包装知道它含多少咖啡因**。所以：

- 别指望看标签判断剂量，**只能靠品牌公开信息 + 自己的身体反应**
- 首次尝试某个能量饮料/浓茶饮时，**先喝一半**
- 出现心悸立刻停，不要「再喝点压一压」

> 【经验】这是国内消费者相对吃亏的地方。同样的产品在欧盟要标含量，在国内不标——不是产品不同，是标签制度不同。

## 六、咖啡因不能替代睡眠

**机制很关键：咖啡因是阻断「困意信号」（腺苷受体），不是消除疲劳。**

| 你以为 | 实际 |
| --- | --- |
| 「喝了就清醒了」 | 只是暂时感觉不到困，**认知能力仍受损** |
| 「熬夜 + 咖啡 = 高效」 | 记忆巩固、判断力、反应速度仍然下降 |
| 「喝了能开车」 | 疲劳驾驶的风险不因咖啡因而消失 |

**长期靠咖啡因撑过睡眠不足，是在透支。** 咖啡因的半衰期约 5 小时，个体差异可达 2–10 小时——下午 3 点喝的那杯，半夜体内可能还剩四分之一。

---

## 七、依赖与戒断

| 现象 | 说明 |
| --- | --- |
| 耐受 | 同样剂量效果变弱，需要更多 |
| 戒断 | 突然停会出现头痛、疲倦、注意力下降、易怒 |
| 戒断持续时间 | 通常数天，多数人 1 周内缓解 |

**减量建议**：每 3–5 天减少约四分之一，不要突然断。突然停最容易在第二天头痛到放弃。

---

## 八、特殊人群要更谨慎

| 人群 | 注意 |
| --- | --- |
| 18 岁以下 | 按 **2.5 mg/kg** 算，很容易超 |
| 孕期、哺乳期 | 需严格限制，遵医嘱 |
| 有心脏问题（心律失常等） | 应限制或避免 |
| 焦虑倾向、惊恐发作史 | 咖啡因会显著加重 |
| 胃病（胃炎、反流、溃疡） | 刺激胃酸，浓咖啡尤甚 |
| 服药期间 | 部分药物（如某些抗生素、支气管扩张剂、口服避孕药）会影响咖啡因代谢 |

---

## 九、常见误区

| 误区 | 实际 |
| --- | --- |
| 「奶茶没有咖啡因」 | 一杯奶茶 ≈ 一杯拿铁，接近美式的量 |
| 「1 杯奶茶 = 8 罐红牛」 | 极端个例；按公开数据约 2.7 罐 |
| 「能量饮料比咖啡健康」 | 糖高、成分复杂，还常与酒精一起被误用 |
| 「我习惯了，所以没事」 | 耐受 ≠ 无害，剂量效应依然存在 |
| 「喝了咖啡就能熬夜学习」 | 认知能力仍受损，只是感觉不到困 |
| 「咖啡因能解酒」 | 不能，只是让人误以为清醒 |
| 「看标签就知道含量」 | 中国营养标签**不强制标咖啡因** |

## 十、可执行清单

- [ ] 算一下自己的上限：成人 400 mg/天，未满 18 岁按 **2.5 mg/kg × 体重**
- [ ] 下午 2 点后不再摄入（半衰期长，个体差异大）
- [ ] 首次喝某款能量饮料/浓茶饮，**先喝一半**观察
- [ ] **绝不把能量饮料和酒混着喝**
- [ ] 出现心悸、手抖，当天就停，别加大剂量
- [ ] 有心脏问题、焦虑倾向、胃病 → 限制或避免
- [ ] 想戒咖啡 → 每 3–5 天减四分之一，别突然停
- [ ] 考试周靠咖啡因硬撑前，先算一下自己当天已经喝了多少

---

## 十一、一句话记住

**成人 400 mg、未成年 2.5 mg/kg 是硬数字；一杯奶茶就接近一杯美式的量；能量饮料别兑酒，包装上还不标含量——所以只能靠算和靠身体的信号。**
