# 传染病与疫苗：结核、乙肝、HPV、流感

> 一句话概括：宿舍是传染病的高密度场所，疫苗是所有健康投入里最划算的一种。

**适用人群**：全体在校生，尤其住校生；新生（入学体检相关）；咳嗽超过两周没好的人；不清楚自己打过哪些疫苗的人。

> **本文性质**
>
> 本文是健康信息整理，**不能替代专业医疗诊断**。出现症状请就医；是否接种某种疫苗、能否接种，请咨询医生或接种点。

> **政策适用范围**
> - 主要依据：《中华人民共和国传染病防治法》；《中华人民共和国疫苗管理法》；国家免疫规划疫苗儿童免疫程序；教育行政部门与卫生健康部门关于学校结核病防控的规定
> - 全国统一 / 地方执行：**法定传染病报告制度、免疫规划框架全国统一；非免疫规划疫苗（如 HPV、流感）的供应、价格、预约方式各地不同**
> - 核查日期：2026-11-05
>
> ⏳ 易过时：疫苗的适用年龄与剂次（按产品说明书）、各地预约渠道与价格。

## 一、校园为什么是传染病的高发场所

| 因素 | 说明 |
| --- | --- |
| **居住密集** | 宿舍多人同住，呼吸道传染病容易传播 |
| **通风不足** | 冬夏开窗少，空气不流通 |
| **共处时间长** | 教室、食堂、图书馆 |
| **共用餐具/水杯** | 部分消化道传染病 |
| **作息不规律** | 免疫力下降 |
| **集体活动多** | 军训、体测、聚会 |

这不是危言耸听，是结构性的。**理解这一点，就能理解为什么"咳嗽两周要查"不是过度紧张。**

---

## 二、校园常见传染病

| 疾病 | 传播途径 | 关键症状 | 要点 |
| --- | --- | --- | --- |
| **肺结核** | 呼吸道飞沫 | **咳嗽咳痰两周以上**、午后低热、盗汗、消瘦 | **法定报告传染病**，见第三节 |
| **流感** | 飞沫、接触 | 高热、全身酸痛、乏力 | 每年可接种疫苗 |
| **诺如病毒** | 粪口、接触、呕吐物气溶胶 | 呕吐、腹泻 | 冬季高发，洗手最关键 |
| **水痘** | 飞沫、直接接触 | 皮疹（分批出现）、发热 | 有疫苗 |
| **乙肝** | 血液、性、母婴 | 多数无症状 | **有疫苗**，见第五节 |
| **HPV 感染** | 性接触为主 | 多数无症状 | **有疫苗**，见 07-09 |
| **艾滋病（HIV）** | 性、血液、母婴 | 早期常无症状 | 无疫苗，可检测、可治疗 |
| **新冠病毒感染** | 飞沫、接触 | 发热、咳嗽、乏力 | 按当地政策 |

## 三、肺结核：最需要警惕的一项

### 3.1 为什么单独说它

宿舍环境对结核传播特别"友好"：**密集、通风差、共处时间长**。高校出现聚集性疫情的情况并不少见。

> 【官方】国家卫生计生委办公厅、教育部办公厅《学校结核病防控工作规范（2017 版）》（**国卫办疾控发〔2017〕22 号**），2017 年 6 月 26 日印发。该规范对新生入学体检中的结核病检查、疫情报告、休学与复学管理等作出了要求。
>
> 该规范 2017 年发布，此后是否有修订或替代文件，请以国家卫生健康委、教育部现行公告为准。

### 3.2 关键信号

| 信号 | 说明 |
| --- | --- |
| **咳嗽、咳痰持续两周以上** | **最重要的警示信号** |
| 痰中带血 | 需要立即检查 |
| 午后低热 | 下午体温略高 |
| 夜间盗汗 | 睡醒发现衣服湿了 |
| 乏力、食欲下降 | 非特异，但常见 |
| 体重下降 | 不明原因 |

### 3.3 该做什么

| 情况 | 做法 |
| --- | --- |
| 咳嗽两周以上 | **立即到校医院或结核病定点医院检查** |
| 接触过确诊患者 | 主动告知医生，按安排筛查 |
| 确诊 | 按医嘱**规范治疗、足疗程** |

### 3.4 三个必须说清的点

| 点 | 说明 |
| --- | --- |
| **能治好** | 规范治疗可以治愈，但**必须足疗程**，不能自行停药 |
| **是法定报告传染病** | 医疗机构发现后须依法报告，这不是"告状" |
| **传染期需要休学治疗** | 各校规定不同，具体按规定执行 |

### 3.5 关于隐瞒

隐瞒的代价是双向的：

- **对自己**：延误治疗，病情加重，可能产生耐药（治疗更难、更久）
- **对他人**：在不知情的情况下传播给室友、同学

**"怕被歧视"是真实的顾虑，但隐瞒通常让结果更糟。** 多数学校对患病学生的处理以治疗和学业安排为主，而不是惩罚。

## 四、疫苗：哪些值得打

### 4.1 免疫规划疫苗 vs 非免疫规划疫苗

| 类别 | 特点 | 例子 |
| --- | --- | --- |
| **免疫规划疫苗** | 政府免费提供，按程序接种 | 乙肝疫苗（儿童剂次）、卡介苗、麻疹类疫苗 |
| **非免疫规划疫苗** | 自愿、自费 | HPV 疫苗、流感疫苗、水痘疫苗、部分成人乙肝疫苗 |

> 各疫苗在各地的具体收费与免费范围不同，以当地接种点与卫生健康部门公布为准。

### 4.2 大学生值得考虑的疫苗

| 疫苗 | 推荐程度 | 说明 |
| --- | --- | --- |
| **乙肝疫苗** | **强烈推荐**（如未接种或抗体不足） | 见第五节 |
| **HPV 疫苗** | **推荐** | 见 07-09 |
| **流感疫苗** | 推荐（每年） | 每年毒株不同，需每年接种 |
| **水痘疫苗** | 未患过且未接种者推荐 | 成人感染水痘症状通常更重 |
| 新冠疫苗 | 按当地政策 | 见当地通知 |

### 4.3 关于"打了疫苗是不是就不会得"

**不是。** 疫苗的作用是**显著降低风险**，不是绝对保护。

| 正确理解 | 错误理解 |
| --- | --- |
| 降低感染风险 | 打了就不会得 |
| 降低重症风险 | 打了就不用防护 |
| 部分疫苗可降低传播 | 打了就可以随便接触患者 |

**但这个"降低"的价值很大**——尤其对重症的防护。

## 五、乙肝：三个常见误解

### 5.1 乙肝不会通过日常接触传播

这是最需要澄清的一点。**乙肝通过血液、性接触、母婴传播**，不通过：

- 一起吃饭
- 共用餐具（除非有血液污染）
- 握手、拥抱
- 咳嗽、打喷嚏
- 共用厕所

**所以：室友是乙肝病毒携带者，不需要隔离、不需要换宿舍、不需要特殊对待。**

### 5.2 大学生该做什么

| 情况 | 做法 |
| --- | --- |
| 不确定是否接种过 | 查接种记录；可做乙肝五项检查看抗体情况 |
| 未接种 | 按程序接种（通常三针） |
| 已接种但抗体不足 | 咨询医生是否需要加强 |
| 已感染 | 定期复查，按医嘱管理，不饮酒 |

> 是否需要检测抗体、是否需要加强接种，由医生根据检查结果判断。本文不给具体方案。

### 5.3 关于入学体检

多数高校入学体检包含肝功能或乙肝相关检查。**具体的检查项目与结果处理，以本校规定为准**【待核实】。

需要注意的是：**乙肝病毒携带者在入学、就业方面的权益受法律保护**，不应因携带状态受到歧视。

## 六、得了传染病要不要告诉学校

| 情况 | 处理 |
| --- | --- |
| **法定报告传染病**（如肺结核等） | 医疗机构依法报告；**个人也应配合**，不要隐瞒 |
| 需要停课治疗的 | 需向学校请假说明 |
| 普通感冒、腹泻 | 视情况，严重时请假 |
| 需要隔离的（如水痘、诺如） | 按医嘱隔离，避免扩散 |

### 6.1 为什么"报告"不等于"公开"

很多人担心"报告了全校都知道"。实际流程通常是：

- 医疗机构向疾控部门报告（法定要求）
- 疾控与学校相关部门对接，**知情范围限于必要人员**
- 不会公开你的姓名给同学

> 各校的具体知情范围与处理流程不同，以本校规定为准。

### 6.2 一条底线

**不要隐瞒需要隔离的传染病。** 这不是为了惩罚你，是为了保护同学，也保护你不被延误治疗。

## 七、日常防护：最有效的几条

| 做法 | 为什么有效 | 成本 |
| --- | --- | --- |
| **开窗通风** | 稀释室内病原体浓度，对呼吸道传染病最有效 | 零 |
| **勤洗手** | 对诺如、流感、接触传播都有效 | 零 |
| 不共用餐具、水杯 | 减少唾液、血液传播风险 | 零 |
| 咳嗽、打喷嚏遮掩口鼻 | 减少飞沫扩散 | 零 |
| **生病时不硬撑上课** | 保护别人，也让自己恢复更快 | 零 |
| 口罩（流行期、就医时） | 减少飞沫传播 | 低 |
| 睡眠与饮食规律 | 免疫力的基础（见 07-04、07-05） | 零 |

**注意**：通风是被严重低估的一项。宿舍每天开窗，比很多"增强免疫力的产品"有用。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「结核已经很少见了」 | 校园仍有聚集性疫情，不能忽视 |
| 「咳嗽两周是感冒没好」 | 需要排查结核 |
| 「乙肝会通过一起吃饭传染」 | 日常接触不传播（血液/性/母婴） |
| 「室友是乙肝携带者要换宿舍」 | 不需要。日常接触不传播 |
| 「打了疫苗就百分百不得」 | 降低风险，不是绝对 |
| 「流感疫苗打一次管一辈子」 | 每年需重新接种 |
| 「得了传染病会被歧视，不能说」 | 隐瞒会延误治疗并传染他人；报告不等于公开 |
| 「抗生素能治流感」 | 流感是病毒，抗生素无效（见 07-11） |
| 「没症状就是没感染」 | 很多传染病早期无症状 |
| 「抽烟喝酒跟这个没关系」 | 吸烟损害呼吸道，是结核等疾病的危险因素 |

## 九、可执行清单

### 入学时

- [ ] 完成入学体检（含胸片等结核相关检查）
- [ ] 查自己的疫苗接种记录（乙肝、水痘、HPV）
- [ ] 不确定乙肝抗体情况 → 咨询校医院是否需要检查

### 平时

- [ ] 宿舍每天开窗通风
- [ ] 勤洗手（饭前、便后、外出回来）
- [ ] 不共用餐具、水杯、毛巾
- [ ] 咳嗽、打喷嚏遮掩口鼻
- [ ] 保持睡眠与饮食规律（见 07-04、07-05）

### 出现症状

- [ ] **咳嗽两周以上 → 立即就诊**（这是最重要的一条）
- [ ] 痰中带血 → 立即就诊
- [ ] 持续发热、盗汗、体重下降 → 就诊
- [ ] 确诊传染病 → 按医嘱治疗，配合报告，不隐瞒

### 预防

- [ ] 确认乙肝疫苗接种情况，未接种的补种
- [ ] 适龄接种 HPV 疫苗（见 07-09）
- [ ] 每年可考虑接种流感疫苗
- [ ] 未患过水痘且未接种的，咨询是否接种

### 减少传播

- [ ] 生病时不硬撑上课
- [ ] 需要隔离时按规定执行
- [ ] 告知密切接触的室友，让他们注意观察

## 十、一句话记住

**咳嗽两周以上必须查结核——这一条能救你自己，也能保护你室友。疫苗能打的都打，尤其乙肝和 HPV。**
