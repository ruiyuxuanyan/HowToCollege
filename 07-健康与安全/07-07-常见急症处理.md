# 常见急症处理：晕倒、心脏骤停、窒息、过敏、烫伤、中暑、癫痫、溺水

> 一句话概括：现场那几分钟做对的事，比之后做多少事都重要。

**适用人群**：全体在校生。尤其是住宿舍、上体育课、军训、进实验室、参加社团活动的人——你可能会遇到，也可能被遇到的人指望。

> **本文性质**
>
> 本文为急救知识整理，**不能替代专业医疗救治**。任何紧急情况请立即拨打 **120**。
>
> ⚠️ **关于具体参数的说明**：本文**不写**心肺复苏的按压深度、频率、通气比例，也不写各类治疗时间窗的具体数字。这些参数以**现行急救指南**为准，会随指南更新而变化，写死数字的风险大于收益。
>
> **本文只写两件事：① 看到什么要立刻打 120；② 在现场做什么、绝对不做什么。**
>
> 强烈建议参加一次红十字会的急救培训，并考取急救证书——**动手练过一次，比读十篇文章有用**。

> **政策适用范围**
> - 主要依据：中国红十字会急救培训体系公开教材；国家卫生健康委急救科普；《中华人民共和国民法典》第一百八十四条（自愿实施紧急救助免责）
> - 全国统一：**急救原则全国通行；具体操作参数以现行急救指南为准**
> - 核查日期：2026-11-05
>
> ⏳ 易过时：急救指南按版本更新，操作参数请以最新版为准。

## 一、先记住：什么情况立刻打 120

这是全文最重要的一张表。**其他都可以忘，这张表要记住。**

| 情况 | 说明 |
| --- | --- |
| **没有反应 + 没有正常呼吸** | 心脏骤停，**立刻 120 + 开始按压** |
| **胸痛**（压榨样、伴出汗、放射到肩/下颌） | 可能是心梗 |
| **严重呼吸困难**（喘不上气、不能平躺、嘴唇发紫） | —— |
| **意识不清、叫不醒、答非所问** | —— |
| **抽搐**（首次发作，或持续不缓解） | —— |
| **大量出血**（止不住） | —— |
| **突然口角歪斜、一侧肢体无力、说话不清** | 卒中征象 |
| **严重过敏**（全身皮疹 + 呼吸困难/喉头发紧/头晕） | 过敏性休克 |
| **高热 + 意识改变 + 皮肤干热** | 热射病 |
| **头部受伤后呕吐、嗜睡、意识改变** | —— |
| **误服药物/化学品、疑似一氧化碳中毒** | —— |
| **溺水** | 无论看起来是否清醒 |

**一个原则：如果你在犹豫「要不要打 120」，就打。**

### 1.1 打 120 要说清的四件事

| 要素 | 例子 |
| --- | --- |
| **地点** | 「XX 大学 XX 校区 X 号宿舍楼 412 室」，说清校区、楼栋、房间；说不清就让别人去路口接 |
| **发生了什么** | 「有人晕倒，没有呼吸」「有人被烫伤」 |
| **人数与状态** | 「一个人，现在没有意识」 |
| **你的电话** | 保持畅通，不要挂断，等对方先挂 |

**不要先挂电话。** 调度员会指导你做处置。

## 二、通用第一步：判断与呼救

任何急症，先做三件事，顺序不能反。

| 顺序 | 动作 | 具体 |
| --- | --- | --- |
| **① 看反应** | 拍肩、大声呼喊 | 「你怎么了？能听见吗？」 |
| **② 看呼吸** | 观察胸廓有无起伏 | 同时看面色、听有无呼吸声 |
| **③ 呼救** | 打 120，同时让人去取 AED | **指定具体的人**：「穿蓝衣服的同学，你去拿 AED」 |

### 2.1 为什么「指定具体的人」很重要

对着人群喊「快打 120」，常常没有人打——这叫责任分散。

正确做法：**指着某一个人说**「你，打 120」「你，去拿 AED」。被指名的人行动率会显著提高。

### 2.2 AED 是什么

自动体外除颤器。校园里通常放在体育场馆、宿舍楼大厅、教学楼一层、校医院。

**它会自己判断要不要电击，你只需要按语音提示操作。** 不敢用是最大的问题——AED 设计得让普通人也能用。

## 三、心脏骤停

**识别核心：没有反应 + 没有正常呼吸（或只有濒死样喘息）。**

| 做什么 | 说明 |
| --- | --- |
| 立刻打 120，同时开始胸外按压 | 不要等救护车 |
| 让人取 AED | 指定具体的人 |
| **胸外按压** | 双手交叠，掌根置于胸部中央（两乳头连线中点附近），手臂伸直，垂直向下按压 |
| **按压的深度、频率、是否通气** | **按现行急救指南执行**，本文不给数字 |
| **AED 到达后** | 开机，按语音提示贴片、离开患者、按提示电击 |
| **不要停** | 持续到专业救援到达，或患者恢复反应 |

### 3.1 三个必须知道的要点

1. **按压位置是胸部中央**（不是左侧胸口，也不是腹部）
2. **手臂要伸直，用上半身重量压**，不是只用手臂力气
3. **让胸廓充分回弹**，压下去和松开来同等重要

### 3.2 常见错误

| 错误 | 后果 |
| --- | --- |
| 先送医院 | 失去最关键的几分钟 |
| 反复摸脉搏、反复判断 | 浪费时间 |
| 按压太浅、太快或太慢 | 效果差（具体标准按指南） |
| 怕压断肋骨而不敢用力 | 有效按压优先于顾虑 |
| AED 到了不敢用 | 设备会自己判断，按提示做即可 |

> 【经验】以上为急救培训中的通行要点。**具体参数（深度、频率、通气比例）请以现行急救指南与培训内容为准，本文刻意不写数字。**

## 四、窒息（气道异物梗阻）

### 4.1 先分清两种情况

| 情况 | 表现 | 怎么做 |
| --- | --- | --- |
| **能咳嗽、能说话、能发声** | 气道部分梗阻 | **鼓励用力咳嗽**，不要拍背、不要干预 |
| **不能说话、不能咳嗽、不能呼吸、面色发紫、双手抓喉** | 完全梗阻 | **立即腹部冲击（海姆立克法）** |

**这个区分是本节的核心。** 能咳嗽说明还有气流，此时拍背可能让异物掉得更深。

### 4.2 腹部冲击（海姆立克法）

| 步骤 | 做法 |
| --- | --- |
| ① | 站到其身后，一腿前插在其两腿之间（防其倒下） |
| ② | 一手握拳，拳眼置于**肚脐上方、胸骨下方** |
| ③ | 另一手包住拳头，**快速向内、向上冲击** |
| ④ | 重复，直到异物排出或患者失去反应 |
| ⑤ | **如果患者失去反应 → 按心脏骤停处理，打 120** |

### 4.3 特殊情况

| 对象 | 做法 |
| --- | --- |
| **孕妇、明显肥胖者** | 改为**胸部冲击**（手置于胸骨下半段），不用腹部冲击 |
| **婴儿（1 岁以下）** | **背部拍击 + 胸部按压**，**不用**腹部冲击 |
| **独自一人** | 用自己的拳头自我冲击；或压在上腹部（椅背、桌沿等硬物） |
| **患者已昏迷** | 按心脏骤停处理，开始心肺复苏 |

### 4.4 绝对不要做

- **不要用手指盲目去掏**（看不到就别掏，可能把异物推得更深）
- **能咳嗽时不要拍背、不要冲击**
- 不要给患者喝水「冲下去」

## 五、晕倒（晕厥）

### 5.1 现场处置

| 步骤 | 做法 |
| --- | --- |
| ① | 让其平躺，**抬高双腿**（有助于血液回流） |
| ② | 松开衣领、腰带，保持通风 |
| ③ | 观察意识与呼吸 |
| ④ | 通常数十秒到几分钟内会恢复 |
| ⑤ | **如果几分钟内不恢复，或没有正常呼吸 → 按心脏骤停处理，打 120** |

### 5.2 恢复后

- 不要立刻让他站起来（容易再次晕倒）
- 先坐起，适应后再站
- 询问有没有摔到头（**头部外伤后呕吐、嗜睡 → 急诊**）
- 首次晕倒、反复晕倒、伴胸痛/心悸 → 建议就医

### 5.3 不要做的事

| 不要 | 为什么 |
| --- | --- |
| 掐人中 | 没有证据支持，且可能造成皮肤损伤 |
| 灌水、喂药 | 意识不清时容易呛入气道 |
| 扶着坐起来或站着 | 可能再次晕倒摔伤 |
| 往脸上泼冷水 | 无必要，且可能加重刺激 |

## 六、严重过敏（过敏性休克）

### 6.1 识别

**核心组合：皮肤症状 + 呼吸/循环症状。**

| 类别 | 表现 |
| --- | --- |
| 皮肤 | 全身荨麻疹、瘙痒、面部/嘴唇/眼睑肿胀 |
| 呼吸 | 喉头发紧、声音嘶哑、喘不上气、吞咽困难 |
| 循环 | 头晕、面色苍白、心慌、意识模糊 |
| 消化 | 恶心、呕吐、腹痛 |

**只要出现呼吸困难或头晕，就是紧急情况。**

### 6.2 处置

| 步骤 | 做法 |
| --- | --- |
| ① | **立即打 120** |
| ② | 平躺，**抬高下肢**（保持脑供血）；如果呼吸困难明显，可取坐位 |
| ③ | **如有肾上腺素自动注射笔**，按说明注射大腿外侧（**这是过敏性休克的首选药物**） |
| ④ | 移除可疑过敏原（如蜂刺要刮除，不要用手挤） |
| ⑤ | 不要让其站立或走动 |
| ⑥ | 观察呼吸，无呼吸则按心脏骤停处理 |

### 6.3 重要提醒

**有严重过敏史的人应该随身携带肾上腺素自动注射笔，并让室友知道放在哪、怎么用。**

抗组胺药（如氯雷他定）只能缓解皮肤症状，**不能替代肾上腺素处理严重过敏**。

> 【经验】肾上腺素为过敏性休克的首选急救药物，这是急救领域的通行认识。**具体用药与剂量由医生或药品说明书确定，本文不给剂量。**

## 七、烫伤与烧伤

### 7.1 记住五个字：冲、脱、泡、盖、送

| 步骤 | 做法 | 注意 |
| --- | --- | --- |
| **冲** | 用**流动冷水**冲洗伤处 | 不要用冰、不要用冰水 |
| **脱** | 小心去除伤处衣物、饰品 | **粘在伤口上的不要硬撕** |
| **泡** | 继续用冷水浸泡降温 | 大面积烫伤不要长时间浸泡（会失温） |
| **盖** | 用干净纱布或清洁布覆盖 | 不要用棉花、纸巾 |
| **送** | 严重时就医 | 见 7.3 |

### 7.2 绝对不要做

| 不要 | 为什么 |
| --- | --- |
| 涂牙膏、酱油、香油、面酱 | 增加感染风险，且妨碍医生判断伤情 |
| 涂紫药水、红药水 | 影响观察创面 |
| 挑破水泡 | 增加感染 |
| 直接敷冰块 | 可能造成冻伤，加重损伤 |
| 用棉花、纸巾覆盖 | 纤维粘在创面上 |
| 大面积烫伤后长时间冷水浸泡 | 可能引起体温过低 |

### 7.3 什么情况必须就医

| 情况 | 说明 |
| --- | --- |
| 面积较大 | 具体面积判断由医生评估 |
| 面部、手、足、会阴、关节部位 | 这些部位影响功能与外观 |
| 深度较深（皮肤发白、焦黑、无痛感） | **无痛感反而更严重**（神经受损） |
| 电烧伤、化学烧伤 | 内部损伤可能比表面重 |
| 吸入烟雾（咳嗽、声音嘶哑、面部烧伤） | **可能气道损伤，急诊** |
| 老人、婴幼儿、有基础病者 | 风险更高 |
| 疼痛剧烈或持续加重 | —— |

> 【经验】以上为烫伤急救的通行原则。**具体冲洗时长、面积分级、深度判断由专业医疗评估，本文不给数字。**

## 八、中暑与热射病

### 8.1 分级

| 分级 | 表现 | 处置 |
| --- | --- | --- |
| **先兆中暑** | 头晕、口渴、多汗、乏力、注意力不集中 | 移到阴凉处、补水、休息 |
| **轻症中暑** | 上述症状加重，体温升高、面色潮红或苍白、恶心 | 降温、补水、密切观察 |
| **热射病（重症）** | **高热 + 意识改变（谵妄、抽搐、昏迷）+ 皮肤干热无汗** | **立即打 120 + 现场积极降温，这是会致命的** |

### 8.2 热射病的现场处置

| 步骤 | 做法 |
| --- | --- |
| ① | **立即打 120** |
| ② | 迅速移到阴凉通风处 |
| ③ | **积极降温**：解开衣物、冷水擦拭全身、风扇吹、冰袋置于颈部/腋下/腹股沟 |
| ④ | 不要给意识不清的人喂水 |
| ⑤ | 持续降温直到救援到达 |

**关键认识**：热射病是**急症**，不是「中暑严重一点」。**核心是快速降温 + 立刻送医。**

### 8.3 高发场景

| 场景 | 说明 |
| --- | --- |
| **军训** | 高温 + 长时间户外 + 迷彩服不透气（见 01-06） |
| **体测** | 突然高强度运动 |
| **夏季户外运动** | 尤其午后 |
| **密闭高温环境** | 车内、不通风的房间 |

### 8.4 预防

- 提前补水，不要等渴了才喝
- 高温天降低运动强度、避开午后
- 穿透气衣物
- 注意同伴状态（**自己中暑时往往判断力下降**）

## 九、癫痫发作

### 9.1 该做什么

| 做什么 | 说明 |
| --- | --- |
| **移开周围硬物** | 防止撞伤 |
| **保护头部** | 垫软物（衣服、包） |
| **让其侧卧**（发作停止后） | 防止呕吐物误吸 |
| **记录发作时间** | 医生会问「持续了多久」 |
| **疏散围观人群** | 保持通风，也保护患者尊严 |
| **发作超过数分钟、或连续发作、或首次发作** | **打 120** |

### 9.2 绝对不要做

| 不要 | 为什么 |
| --- | --- |
| **往嘴里塞任何东西**（勺子、毛巾、手指） | 可能损伤牙齿、堵塞气道，甚至咬断手指 |
| **按压肢体、强行制止抽搐** | 可能造成骨折或关节损伤 |
| 掐人中 | 无证据支持 |
| 发作后立刻喂水喂药 | 意识未完全恢复时易呛入 |
| 围成一圈看 | 影响通风，也伤害患者 |

**关于「会不会咬断舌头」**：这是流传很广的误解。舌咬伤可能发生，但**塞东西造成的伤害通常更严重**。绝对不要往嘴里塞东西。

## 十、溺水

### 10.1 最重要的一条

**不要贸然下水救人。**

不会水上救援的人下水，很可能成为第二个溺水者。

### 10.2 正确顺序

| 顺序 | 做法 |
| --- | --- |
| ① | **大声呼救**，让人拨打 120/110 |
| ② | **岸上救援优先**：伸（长杆、树枝、毛巾）、抛（救生圈、空水桶、绳子） |
| ③ | 只有**受过水上救援训练**的人才下水，且要带浮具 |
| ④ | 救上岸后：**无反应无呼吸 → 按心脏骤停处理，立即心肺复苏** |

### 10.3 救上岸后

| 情况 | 做法 |
| --- | --- |
| 无反应、无正常呼吸 | 立即心肺复苏，打 120 |
| 有呼吸但意识不清 | 侧卧位，保暖，等救援 |
| 看起来正常 | **仍建议就医**——溺水后可能出现迟发性的呼吸问题 |

**不要做**：不要试图「控水」（倒挂、压腹部排水）——这会延误心肺复苏，且可能引起呕吐误吸。

## 十一、一氧化碳中毒

宿舍、出租屋、冬季洗澡是高发场景。

| 识别 | 说明 |
| --- | --- |
| 多人同时出现头痛、头晕、恶心 | **这是一个强提示**（一氧化碳无色无味） |
| 口唇呈樱桃红色 | 部分患者出现 |
| 意识模糊、昏迷 | 严重 |

| 处置 | 做法 |
| --- | --- |
| ① | **立即开窗通风**，关闭气源 |
| ② | 把患者移到通风处（**施救者自己也要注意，不要长时间停留在高浓度环境**） |
| ③ | **打 120** |
| ④ | 无呼吸则按心脏骤停处理 |

## 十二、常见误区汇总

| 错误做法 | 为什么错 | 正确做法 |
| --- | --- | --- |
| 心脏骤停先送医院 | 失去最关键的现场时间 | 现场按压 + AED，同时打 120 |
| 烫伤涂牙膏/酱油 | 增加感染、妨碍判断 | 冲冷水、盖干净纱布 |
| 烫伤直接敷冰块 | 可能冻伤 | 用流动冷水 |
| 癫痫发作往嘴里塞东西 | 损伤牙齿、堵塞气道 | 移开硬物、侧卧、记录时间 |
| 晕倒掐人中、灌水 | 无效，可能呛入 | 平躺抬腿、观察呼吸 |
| 溺水直接跳下去救 | 可能双双遇险 | 岸上救援、呼救 |
| 溺水后「控水」 | 延误复苏，可能误吸 | 直接按心肺复苏处理 |
| 窒息还能咳嗽时拍背 | 可能使异物掉得更深 | 鼓励咳嗽，完全梗阻才冲击 |
| 用手指掏异物 | 可能推得更深 | 看不见不要掏 |
| 中暑只是「热一点」 | 热射病可致命 | 高热 + 意识改变 = 立刻 120 |
| 对人群喊「快打 120」 | 责任分散，可能没人打 | 指定具体的人 |
| 不敢用 AED | 设备会自己判断 | 开机按语音提示操作 |
