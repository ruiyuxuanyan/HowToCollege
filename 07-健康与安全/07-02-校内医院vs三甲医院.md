# 校内医院 vs 三甲医院：什么时候去哪个

> 一句话概括：不是所有病都要去三甲，但有几类症状千万别在校医院排队。

**适用人群**：刚入学、不熟悉就医流程的学生；生病时不知道该挂哪个科的人；担心看病贵、担心报销麻烦的人。

> **本文性质**
>
> 本文是就医路径与政策信息整理，**不能替代专业医疗建议**。文中的「必须去急诊」清单是就医指征提示，不是诊断标准。出现急症请直接拨打 120。

> **政策适用范围**
> - 主要依据：《国家发展改革委办公厅等关于进一步提高高校学生医疗保障质量的通知》（发改办就业〔2024〕1096 号）；《医疗机构管理条例》；各统筹地区医保政策
> - 全国统一 / 地方执行：**转诊与报销的制度框架全国统一，首诊点设置、转诊要求、报销比例由各统筹地区与学校具体规定**
> - 核查日期：2026-11-05
>
> ⏳ 易过时：本校转诊规定、报销比例每年可能调整。

## 一、两种机构的定位完全不同

先理解它们各自「该干什么」，判断就有依据了。

| | 校医院（校内医疗机构） | 三甲医院 |
| --- | --- | --- |
| **定位** | 首诊、常见病、慢病管理、公共卫生 | 疑难重症、专科诊疗 |
| **优势** | 近、便宜、能开转诊单、不用排长队 | 设备齐全、专科细分、能处理复杂情况 |
| **劣势** | 设备有限、专科不全、夜间能力有限 | 贵、远、排队久 |
| **能做什么** | 感冒发烧、轻微外伤、开常见药、体检、开转诊 | 所有科室，含急诊、手术、影像、专科检查 |
| **不能做什么** | 复杂检查、专科手术、多数急重症 | —— |

**一句话**：校医院管「日常」，三甲管「复杂和危急」。

## 二、什么时候去校医院

| 情况 | 说明 |
| --- | --- |
| 感冒、低热、咽痛、咳嗽（无呼吸困难） | 常见病，校医院完全能处理 |
| 轻微外伤（擦伤、小面积烫伤、扭伤） | 清创、包扎、换药 |
| 需要开常用药 | 慢性病续方、常用药 |
| 腹泻、轻微肠胃不适 | 无脱水、无剧烈腹痛 |
| 皮肤问题（皮疹、瘙痒） | 初诊，必要时转诊 |
| 需要开**转诊单** | 想报销，通常要先经校医院转诊 |
| 常规体检、疫苗接种 | 校医院承担公共卫生职能 |
| 心理咨询初诊 | 多数校医院可初筛（见 06-07） |

### 2.1 校医院的一个重要功能：开转诊单

很多人不知道这一点，直接跑去三甲，结果报销比例变低。

> 【官方】发改办就业〔2024〕1096 号要求：应将自愿申请且符合条件的高校内设医疗卫生机构纳入医保定点范围，方便学生就近就医，推动各高校简化报销流程，落实医保直接结算。

多数统筹地区实行**基层首诊、逐级转诊**：未经转诊直接去高级别医院，报销比例可能降低，甚至不予报销。

**具体规则各统筹地区不同**【待核实】：查学校所在市的医保政策，或问校医院医保办。

## 三、必须直接去急诊的情况（本篇最重要）

**以下情况不要在校医院排队，不要去门诊挂号，直接去急诊，必要时打 120。**

| 类别 | 具体表现 |
| --- | --- |
| **胸痛** | 胸口压榨样疼痛、闷痛，尤其伴出汗、放射到左肩/下颌 |
| **呼吸困难** | 喘不上气、不能平躺、口唇发紫 |
| **剧烈腹痛** | 突然发生的剧烈腹痛，按下去更痛、腹部发硬 |
| **意识改变** | 昏迷、叫不醒、答非所问、突然糊涂 |
| **大量出血** | 呕血、咯血、便血、外伤出血止不住 |
| **高热伴皮疹** | 高热 + 全身皮疹，尤其伴精神差 |
| **头部外伤后呕吐** | 撞到头后出现呕吐、嗜睡、意识不清 |
| **卒中征象** | 突然口角歪斜、一侧肢体无力、说话不清、看不清 |
| **严重过敏** | 全身荨麻疹 + 呼吸困难/喉头发紧/头晕 |
| **抽搐** | 首次发作，或发作持续不缓解 |
| **严重脱水** | 腹泻呕吐后极度口渴、尿少、站立时头晕 |
| **中毒** | 误服药物、化学品、CO 中毒 |

### 3.1 关于卒中：FAST 原则

| 字母 | 含义 | 具体 |
| --- | --- | --- |
| **F**（Face） | 面部 | 让他笑一下，看口角是否歪斜 |
| **A**（Arms） | 手臂 | 让他双臂平举，看是否有一侧无力下垂 |
| **S**（Speech） | 言语 | 让他说一句完整的话，看是否含糊、说不清 |
| **T**（Time） | 时间 | **记下发病时间，立刻打 120** |

> 【经验】FAST 是国际通用的卒中快速识别方法。**发病时间对治疗决策很关键**，一定要记下来告诉医生。具体治疗时间窗由医生判断，本文不给数字。

### 3.2 一个原则：宁可白跑

急诊分诊的原则是「宁可我判断错了，也不要漏掉」。

**如果你在犹豫「要不要去急诊」，答案通常是「去」。** 白跑一趟的代价，远低于延误的代价。

## 四、夜间和周末怎么办

这是最容易出问题的时段。

| 情况 | 建议 |
| --- | --- |
| 校医院夜间关门 | 确认本校是否有夜间值班/急诊；多数校医院夜间只处理简单情况 |
| 需要夜间就医 | 直接去就近三甲医院急诊，不要等第二天 |
| 周五晚上发病 | **不要拖到周一**，周末门诊大多停诊，只能走急诊 |
| 假期在校 | 先确认校医院是否开放，再决定去留 |

**一个实用做法**：入学第一周，查清楚三件事并存进手机——

1. 校医院位置、电话、门诊时间
2. 最近的三甲医院（打车多久）
3. 学校所在地的急救电话（120）

## 五、转诊与报销的关系

### 5.1 常见模式

| 模式 | 说明 |
| --- | --- |
| **基层首诊** | 先到校医院/社区医院，需要时开转诊单 |
| **转诊优惠** | 有转诊单，报销比例更高 |
| **未转诊惩罚** | 直接去高级别医院，报销比例降低 |
| **急诊例外** | 急诊通常不受转诊限制（生命优先） |

> 上述模式的适用范围、比例差异由各统筹地区规定，必须查学校所在市当年的医保政策。

### 5.2 急诊一般不受转诊限制

原因很简单：急救不能等转诊单。

但**事后可能需要补手续**（如住院后回参保地报销）。建议：

- 保留所有急诊病历、发票、费用清单
- 事后咨询校医院医保办或学校医保经办点

### 5.3 异地就医

寒暑假在家、实习在外地生病，需要**异地就医备案**（详见 07-01）。不备案可能降低报销比例，或无法直接结算。

## 六、怎么选科室

挂错科白跑一趟很常见。给一张速查表：

| 症状 | 挂什么科 |
| --- | --- |
| 发热、咳嗽、咽痛 | 呼吸内科 / 全科 / 校医院内科 |
| 腹痛、腹泻、呕吐 | 消化内科（剧烈腹痛→急诊） |
| 胸闷、心悸 | 心血管内科（胸痛→急诊） |
| 头痛、头晕 | 神经内科 |
| 皮疹、瘙痒 | 皮肤科 |
| 眼睛红、痛、视力下降 | 眼科（**眼外伤、突然失明→急诊**） |
| 耳痛、听力下降 | 耳鼻喉科 |
| 牙痛、牙龈出血 | 口腔科 |
| 扭伤、骨折可能 | 骨科（**明显畸形、不能动→急诊**） |
| 尿频尿痛、下腹痛 | 泌尿外科 / 妇科（按性别与症状） |
| 情绪问题、失眠 | 精神科 / 心理科（见 06-07） |
| 不确定 | **全科医学科 / 校医院**，让医生分诊 |

## 七、看病的实际流程

### 7.1 去校医院

1. 带**学生证/校园卡**（多数校医院需要）
2. 挂号（部分学校免挂号费）
3. 就诊
4. 缴费（医保直接结算的话自付部分很低）
5. 取药
6. 如需转诊，请医生开**转诊单**

### 7.2 去三甲医院

1. **提前预约**（多数医院支持线上预约，现场挂号可能没号）
2. 带身份证、医保卡/医保电子凭证、学生证
3. 到院取号、就诊
4. 医生开检查 → 缴费 → 检查 → 回诊
5. 保留所有票据

**第一次去大医院的建议**：

- 提前查好科室和医生出诊时间
- 早上去（很多检查下午不做，或结果当天出不来）
- 带上之前的病历和检查结果
- 一个人去的话，把流程记在手机里

### 7.3 要说清楚的三件事

医生时间紧，说重点：

1. **哪里不舒服，多久了**
2. **有没有加重/缓解的因素**（吃什么、做什么会好或坏）
3. **吃过什么药，有没有过敏**

不要从「我上周……」开始讲完整故事。先说结论。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「校医院什么都看不了」 | 常见病完全能处理，且能开转诊单、报销比例高 |
| 「直接去三甲更保险」 | 可能降低报销比例；且三甲排队久，小病反而更折腾 |
| 「晚上不舒服，等明天再说」 | 有些症状（胸痛、卒中征象）等一晚就是错过时机 |
| 「急诊很贵，能不去就不去」 | 急诊挂号费不高，真正的成本是延误 |
| 「发烧就要去大医院」 | 多数发热校医院能处理；关键看有没有危险信号（见第三节） |
| 「没有转诊单也能报销」 | 多数地区能报，但比例可能降低，甚至不予报销 |
| 「医保卡没带就白去了」 | 多数地区支持医保电子凭证，但仍建议带实体卡 |
| 「校医院开的药不管用」 | 校医院受药品目录限制，部分药需转诊后在大医院开 |

## 九、可执行清单

### 入学第一周

- [ ] 存校医院地址、电话、门诊时间
- [ ] 查最近的三甲医院（打车时间）
- [ ] 确认本校夜间/周末的就医安排
- [ ] 激活医保电子凭证
- [ ] 了解本校转诊规定（问辅导员或校医院医保办）

### 生病时先自问

- [ ] 有没有第三节清单里的任何一项？→ **有，直接去急诊或打 120**
- [ ] 症状轻微、能走能说？→ 校医院
- [ ] 症状持续超过一周不缓解？→ 校医院初诊，必要时转诊
- [ ] 不确定？→ 先去校医院，让医生判断

### 去大医院前

- [ ] 线上预约（不要指望现场有号）
- [ ] 带身份证 + 医保凭证 + 学生证
- [ ] 带上既往病历和检查结果
- [ ] 记下症状开始时间（尤其神经系统症状）

### 看完病

- [ ] 保留所有票据、病历、检查报告
- [ ] 需要报销的，确认材料和时限
- [ ] 异地就医的，办备案（见 07-01）

## 十、一句话记住

**小病去校医院，能省时间也能省钱；但胸痛、喘不上气、意识不清、说话不利索——不要排队，直接去急诊或打 120。**
