# 心理危机求助

> 一句话概括：出现不想活下去的念头时，立刻打电话，不要独处，不要等。

**适用人群**：正在经历强烈痛苦的在校生；担心身边室友或朋友的人；不知道该不该去心理咨询的人。

> **本文性质**
>
> 本文是求助信息整理，**不能替代专业诊断和治疗**。紧急情况请立刻拨打 120 或 110。
>
> **信息适用范围**
> - 主要依据：国家卫生健康委《关于应用"12356"全国统一心理援助热线电话号码的通知》（国卫医政函〔2024〕259 号）
> - 全国统一：12356 是全国统一号码；各校心理咨询中心设置情况不同
> - 核查日期：2026-11-05
>
> ⏳ 易过时：热线覆盖情况、学校心理咨询中心的预约方式可能变化。

## 一、如果你现在就有危险

**请先做这件事，再往下读：**

| 情况 | 立刻做 |
| --- | --- |
| 已经伤害了自己 | 拨打 **120** |
| 正在计划伤害自己 | 拨打 **120** 或 **110** |
| 有强烈念头但还没行动 | 拨打 **12356**，并告诉身边任何一个人 |
| 身边有人正在实施 | 拨打 **120**，不要让对方独处 |

### 三个号码

- **12356**：全国统一心理援助热线（国家卫生健康委设立）
- **120**：急救
- **110**：报警

**如果你不知道说什么**，就说这句话就够了：

> 「我现在状态很不好，我需要人陪我说说话。」

对方受过训练，知道怎么接下去。

## 二、12356 是什么

很多人不知道这个号码，但它是国家层面统一设立的。

> 为健全社会心理服务体系，向人民群众提供更加优质便捷的心理健康服务，我委协调工业和信息化部设置"12356"作为全国统一心理援助热线电话号码。
>
> 【官方】国家卫生健康委《关于应用"12356"全国统一心理援助热线电话号码的通知》（国卫医政函〔2024〕259 号），2024 年 12 月 6 日

文件里的几个关键要求：

| 要求 | 内容 |
| --- | --- |
| 开通时间 | 确保 **2025 年 5 月 1 日 0 时前**实现拨打 12356 接通 |
| 覆盖范围 | 原则上**每个设区的市至少开通 1 条**心理援助热线 |
| 坐席数量 | 每条热线至少设置 **2 个坐席** |
| 服务时长 | 每日提供**不少于 18 小时**心理援助服务 |
| 服务内容 | 心理健康教育、心理咨询、心理疏导、**心理危机干预** |
| 过渡期 | 各地设置一定过渡期，原有号码和 12356 均可接通 |

> 【官方】同上文件第一、二、三、四条

**注意最后一条**：如果你所在的学校或城市之前宣传过另一个热线号码，在过渡期内它可能仍然可用。但**12356 是应该记住的那个**。

### 关于拨打 12356 的几个实际问题

- **要钱吗**：不需要，公益服务
- **会不会被记录**：这是热线咨询服务，不是就医记录
- **说了会不会传出去**：热线有保密要求，但涉及生命危险时会启动应急联动（见下文第四节）
- **不知道说什么**：直接说「我最近状态很不好」就可以
- **白天打还是晚上打**：有 18 小时服务时间，具体时段各地不同

## 三、怎么判断自己或身边的人已经到了需要求助的程度

不是「心情不好」就需要危机干预，但下面这些信号需要认真对待。

### 3.1 需要立刻求助的信号（不要等）

- 有**具体的自杀计划**（时间、方式、地点）
- 开始**处理身后事**（交代遗言、送掉贵重物品、写告别信）
- 情绪从极度低落**突然变得平静**（这是需要高度警惕的信号，有时意味着已经做了决定）
- 出现了自伤行为
- 反复说「活着没意思」「不想拖累别人」「我是负担」

### 3.2 需要尽快求助的信号（本周内）

- 持续两周以上失眠、厌食或暴食
- 无法上课、无法完成基本生活事务
- 强烈的无望感、觉得自己毫无价值
- 回避所有社交，完全孤立
- 酒精或其他物质使用明显增加

### 3.3 需要注意但不必恐慌

- 失恋、考试失利后的短期情绪低落
- 适应新环境时的焦虑
- 阶段性的人际冲突

这些是正常的生活反应，**大部分会自行缓解**。但如果持续超过两周且影响功能，就进入了 3.2 的范围。

## 四、校内的资源

### 4.1 心理咨询中心

多数高校设有心理咨询中心，有几个特点需要知道：

| 问题 | 通常情况 |
| --- | --- |
| 收费吗 | 多数对在校生**免费** |
| 保密吗 | 有保密原则，但有法定例外（见下） |
| 会被记入档案吗 | 一般不会。咨询记录独立保存 |
| 怎么预约 | 学校官网/公众号/辅导员转介 |
| 次数有限制吗 | 部分学校限定每学期次数，用完可申请或转介 |

> 【经验】以上为多数学校的通行做法，**各校具体规定不同**，以本校心理咨询中心的说明为准。

### 4.2 保密原则的例外

这一点必须说清，因为它影响很多人是否愿意去：

咨询师在以下情况会突破保密：

1. **你有伤害自己的风险**
2. **你有伤害他人的风险**
3. 涉及未成年人受侵害
4. 法律法规规定的其他情形

**关键理解**：突破保密的目的通常是**保护你**（比如联系辅导员、联系家人、建议就医），而不是「告状」。这个区别很重要——很多人因为怕「被告诉辅导员」而不去咨询，结果错过了本该获得的帮助。

### 4.3 辅导员

辅导员通常**不是专业心理人员**，但可以是第一道联系人。找辅导员的现实作用是：

- 帮你请假、协调学业
- 帮你联系心理咨询中心
- 在紧急情况下联系家长

如果你需要的是专业心理帮助，**直接去心理咨询中心更合适**。

## 五、作为朋友或室友，你能做什么

这一节可能是全文最有用的部分——很多人不是自己出事，而是身边人出事。

### 5.1 五件该做的事

| 做法 | 说明 |
| --- | --- |
| **认真听，不评判** | 不说「想开点」「这有什么大不了的」「别人比你惨多了」 |
| **直接问** | 问「你有没有想过自杀」，见下文 5.2 |
| **不让他独处** | 尤其在他表达了明确念头之后 |
| **陪他就医或打电话** | 陪着打 12356，或者陪他去心理咨询中心 |
| **移除危险物品** | 药品、刀具等，暂时收起来 |

### 5.2 关于「直接问」这件事

很多人不敢问，怕「问了反而提醒他」。这是一个广泛存在的误解。

**实际情况是**：直接询问不会诱发自杀念头，反而是让对方感到被理解、愿意开口的重要一步。这是自杀预防领域的共识。

可以这样问：

> 「你最近是不是很难受？有没有想过不想活了？」

问的时候要注意：

- 语气平静，不要惊慌
- 问完给对方时间回答，不要急着安慰
- 如果对方说有，**不要承诺保密**

### 5.3 一件必须做的事：不要承诺「不告诉别人」

如果对方说「你别告诉任何人」，而他有明确的自杀计划，**生命安全优先于承诺**。

正确做法：

> 「我很重视你信任我。但如果你有危险，我不能假装不知道——我得确保你安全，这一点我不能答应你。」

然后联系辅导员、家人，或陪他去医院。

### 5.4 你自己的状态也很重要

陪伴一个有危机的人会很消耗。如果感到力不从心：

- 不要独自承担，把情况告诉辅导员
- 你自己也可以打 12356 咨询「怎么帮助朋友」
- 不要因为「没救回来」而自责——你不是专业人员，你已经做了能做的

## 六、去医院看什么科

如果情况持续、影响功能，需要就医。

| 就诊科室 | 适合情况 |
| --- | --- |
| **精神科 / 精神心理科** | 有明确症状：持续情绪低落、失眠、焦虑发作、自伤念头 |
| 心理科 / 临床心理科 | 情绪困扰、需要心理治疗 |
| 心理咨询门诊 | 轻度困扰、发展性问题 |

**关于挂号的实际建议**：

- 综合医院的精神科/心理科通常要提前预约，号源紧张
- 学生医保可以报销（详见「医保怎么用」一文）
- 部分学校的校医院可以转诊到合作医院
- 首次就诊建议上午去（有些检查需要空腹或耗时较长）

**如果被建议住院，不要恐慌。** 精神科住院有自愿原则和法定例外情形，可以了解清楚再决定。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「去看心理医生等于承认自己有病」 | 心理咨询处理的是困扰，不等于精神疾病 |
| 「去咨询会被记入档案，影响就业」 | 一般不会。咨询记录独立、保密 |
| 「问了会不会提醒他自杀」 | 不会。直接询问是有效的预防手段 |
| 「他只是在说说而已」 | 所有关于自杀的表达都应当认真对待 |
| 「忍一忍就过去了」 | 有些会过去，但有些不会。区别在于是否影响功能、持续多久 |
| 「12356 是精神病才打的」 | 它是心理健康服务热线，任何人都可以打 |
