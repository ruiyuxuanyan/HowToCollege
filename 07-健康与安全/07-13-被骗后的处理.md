# 被骗后的心理与财务双重处理

> 一句话概括：被骗不是你的错，但止损的每一步都要走对。

**适用人群**：遭遇电信网络诈骗、兼职诈骗、校园贷诈骗的学生。

> **核查日期**：2026-11-05

---

## 一、立即做（转账后 30 分钟内）

**这是决定能否追回损失的关键窗口。**

| 顺序 | 动作 | 怎么做 |
| --- | --- | --- |
| 1 | **打 110 报警** | 直接说「我被诈骗了，刚转账」 |
| 2 | **联系银行/支付平台申请止付** | 打客服电话，说明情况 |
| 3 | 保留全部证据 | 截图、录屏，**不要删** |

**为什么这么快**：资金一旦被层层转出，追回难度成倍增加。警方与银行有快速止付机制，但依赖时效。

---

## 二、24 小时内

| 动作 | 说明 |
| --- | --- |
| 到派出所做笔录 | 带上手机、转账凭证 |
| 整理证据 | 聊天记录（带时间的截图）、转账记录、对方账号/二维码/网址 |
| 联系发卡银行 | 说明涉案，确认账户状态 |
| 检查其他账户 | 如果泄露了密码、验证码，立刻改 |

**证据清单**：
- 对方的账号、电话、微信/QQ 号
- 转账凭证（银行流水、支付记录）
- 全部聊天记录（**不要删除任何一条**）
- 对方发来的链接、App 安装包

---

## 三、一周内

| 动作 | 说明 |
| --- | --- |
| 跟进案件 | 拿**受案回执**，记下办案民警联系方式 |
| 查征信 | 如涉及贷款，确认有没有被冒名贷款 |
| 通知家人 | 见下文第五节 |

---

## 四、金融层面的处理

| 情况 | 处理 |
| --- | --- |
| 银行卡被盗刷 | 挂失、报警、向银行申请核查 |
| 被冒名贷款 | 报警 + 向征信机构提异议 + 联系贷款机构 |
| 征信出现异常记录 | 向中国人民银行征信中心提出异议申请 |
| 被诱导签了贷款合同（培训贷） | 报警 + 主张合同无效/撤销（需律师协助） |

---

## 五、心理层面：这一节常被忽略

**被骗后的羞耻感和自责，会让人选择隐瞒，而隐瞒会让损失扩大。**

### 5.1 常见的心理反应

| 反应 | 说明 |
| --- | --- |
| 强烈的自责（「我怎么这么蠢」） | 诈骗是专业化的，不是智商问题 |
| 羞耻，不想告诉任何人 | 这正是骗子希望你做的 |
| 失眠、焦虑、反复回想 | 正常的应激反应 |
| 想自己追回损失 | **这是最危险的想法**，见第七节 |

### 5.2 该做什么

- **告诉家人或朋友**：即使会被说几句，也比独自扛着好
- 如果出现持续失眠、无法上课、有自伤念头 → 立即求助（见 07-03）
- 记住：**被骗的人是受害者，不是犯错的人**

---

## 六、警惕「追款服务」——二次诈骗

**这是最需要强调的一条。**

被骗后，你会收到各种「能帮你追回钱」的信息：

| 话术 | 真相 |
| --- | --- |
| 「我们是专业追款团队，先付定金」 | 二次诈骗 |
| 「我们是黑客，能黑进对方账户」 | 二次诈骗 |
| 「加这个 QQ，有内部渠道」 | 二次诈骗 |
| 「网警在线，点这个链接登记」 | 假冒网警 |

**原则：除公安机关外，任何人声称能帮你追回被骗资金，都是骗子。**

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「金额太小，警察不管」 | 仍应报案，累计案件有助侦破 |
| 「报警也没用」 | 止付机制有效，越早越有可能追回 |
| 「太丢人了，不想说」 | 隐瞒导致损失扩大 |
| 「网上有人能追回」 | 二次诈骗 |
| 「删掉聊天记录免得被看到」 | **绝对不要删**，那是证据 |

- [ ] 打 110

- [ ] 到派出所做笔录，拿受案回执
- [ ] 整理完整证据清单
- [ ] 修改可能泄露的密码

- [ ] 查征信（有无被冒名贷款）
- [ ] 告诉家人
- [ ] 跟进案件

### 心理

- [ ] 允许自己难过，但不要独自承担
- 心理危机求助（07-03）
- [ ] **绝不联系任何「追款服务」**

## 九、一句话记住

**先报警止付，再保留证据。别删记录，别信追款。**
