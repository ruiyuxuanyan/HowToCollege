# 国家助学贷款：在校期间利息是财政全额承担的，不借才是吃亏

**三个最常见的误解，先纠正掉：**

| 误解 | 实际 |
| --- | --- |
| 「助学贷款利息很高，不如找亲戚借」 | **在校期间利息全部由财政承担**，你一分钱不用付 |
| 「家里不是特别穷就不能办」 | 这是**信用贷款**，不用抵押担保，家庭经济困难有需要就能申请 |
| 「借了会留不良记录，影响买房」 | **按时还款不会**。只有逾期才进征信 |

第一条是关键。很多人因为「怕欠钱」放弃，但不知道读书这几年是零成本的——相当于一笔免息周转资金。

## 现在能借多少（2024 年秋季学期起）

网上大量攻略还停在老标准，这里更新一下：

> 全日制普通本专科学生（含第二学士学位、高职学生、预科生）每人每年申请贷款额度由不超过 16000 元提高至**不超过 20000 元**；全日制研究生由不超过 20000 元提高至**不超过 25000 元**。
>
> ——《关于调整完善国家助学贷款有关政策的通知》（财教〔2024〕188 号）第一条

| 学历层次 | 每年最高额度 |
| --- | --- |
| 本专科生（含第二学士学位、高职、预科生） | **20000 元** |
| 研究生 | **25000 元** |

两个细节：

1. **用途不只学费**。优先交学费和住宿费，**超出部分可以当生活费**
2. **不是必须借满**。可以按实际需要少借

## 利率

> 国家助学贷款利率由同期同档次 LPR 减 60 个基点，调整为同期同档次 **LPR 减 70 个基点**。

也就是说，利率 = 当期 LPR − 0.7%。明显低于普通商业贷款。

已经签了旧合同（LPR−0.6%）的，可以跟承办银行协商调整到 LPR−0.7%。

注意 LPR 每月公布、会浮动，具体数字要看你的合同和银行当年公告。

## 生源地 vs 校园地，选哪个

目前是「**生源地为主体、校园地为补充**」。

| 项目 | 生源地 | 校园地 |
| --- | --- | --- |
| 办理地点 | 户籍所在地县级学生资助管理中心 / 经办银行 | 就读学校 |
| 办理时间 | 通常暑假 | 入学后，学校统一组织 |
| 频率 | 每年办一次 | 一次签约，分年发放 |
| 共同借款人 | 通常需要（家长或亲属） | 一般不需要 |

**首选生源地**，三个理由：

1. 是当前主体模式，覆盖最广
2. 暑假就能办好，开学直接走「绿色通道」，不用先垫钱
3. 每年办理，额度可按当年实际需要调整

**校园地适合**：生源地办不了、或者入学后才发现需要的学生。

**两者不能同时借**：同一学年内不能同时申请生源地贷款和校园地贷款，只能二选一。

## 一个前置条件容易被忽略

申请通常需要先完成**家庭经济困难认定**，这个认定一般在学校的学生工作部门或资助中心办，是另一套流程。

所以时间上要倒推：先做困难认定 → 再申请贷款。开学才想起来往往赶不上。
