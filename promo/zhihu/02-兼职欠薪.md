# 兼职被拖欠工资，劳动监察基本不会管你——那该怎么办

**先说一个多数攻略不会告诉你的前提：在校生课余兼职，和对方是「劳务关系」，不是「劳动关系」。这意味着劳动监察和劳动仲裁都不受理你的案子。**

我见过太多人拿着打工记录跑去劳动监察，被告知「你这不算劳动关系，我们管不了」，然后就卡在这一步，觉得没辙了。

其实路是有的，只是要走对。

## 先证明四件事

打官司也好、协商也好，你手里得有东西。以下四件事必须能证明：

| 要证明什么 | 用什么证明 |
| --- | --- |
| 存在用工关系 | 聊天记录、排班表、工作群、工牌照片 |
| 约定了报酬 | 微信谈价记录、语音（可录音）、书面协议 |
| 你确实干了活 | 打卡截图、交付的成果、工作照片 |
| 对方没给钱 | 催讨记录、对方的承诺与推脱 |

**证据怎么存：**
- 截图要带时间（微信聊天记录截图会显示时间，别用手动裁切的）
- 不要清空聊天记录
- 重要语音转文字或录屏
- 工作成果备份到自己设备上

## 第一步不是投诉，是留下书面催讨

用微信或短信，**不要只打电话**——电话留不下证据。

话术大概是：「X 月 X 日到 X 月 X 日的工资共 X 元，请于 X 日前支付。」

对方回「过几天给」「下周一定」，这些都是好证据——它证明对方承认欠你钱，只是没付。

给对方一个明确期限，比如 7 天。到期不付就往下走。

## 三条路，按实际效果排序

**路径一：投诉（大概率不受理，但值得试一次）**

| 部门 | 管什么 | 你这种情况 |
| --- | --- | --- |
| 劳动监察 | 劳动关系争议 | 通常不受理 |
| 12315 | 消费纠纷 | 一般不适用 |
| 12345 | 综合政务 | 可反映，但会转办 |

如果金额较大、或者对方是正规公司，投诉有时能促成对方主动协商解决。即使不受理，**把书面答复留着**。

**路径二：法院起诉（主要路径）**

这是真正能拿到钱的路。

- **怎么立案**：微信小程序「人民法院在线服务」可以在线提交，不用跑法院
- **去哪个法院**：被告住所地，或者合同履行地（你干活的地方）
- **要准备什么**：起诉状（写清事实、金额、请求）、证据、双方身份信息、诉讼费
- **小额诉讼程序**：一审终审、审理快（通常一两个月）、诉讼费低。标的额上限各省不同，要查当地规定

**诉讼时效是三年**（《民法典》第一百八十八条），从你知道或应当知道权利受损时起算。三年听着长，但证据会随时间消失，别拖。

**路径三：检察支持起诉**

检察机关可以对弱势群体提起的民事诉讼「支持起诉」——协助调查取证、出具支持起诉意见书。

学生是否属于适用范围，**各地检察机关不一样**，需要向当地检察院民事检察部门咨询。实践中已有学生兼职欠薪获支持起诉的案例。

## 一个容易踩的坑

如果你实际上不是「课余兼职」，而是全职上班、按时打卡考勤、按月领固定工资——那你可能**构成劳动关系**，这时候就该走劳动仲裁，而不是上面这套。

判断标准不是对方怎么称呼你，而是实际用工形态。这一点搞错了，路就走反了。
