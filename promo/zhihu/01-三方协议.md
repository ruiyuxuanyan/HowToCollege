# 三方协议的违约金，签之前必须搞清楚的一件事

**结论先说：三方协议可以约定违约金，而且这个违约金是有效的。它和劳动合同完全是两回事。**

很多人以为「只有劳动合同才能约定违约金，所以三方里的违约金是吓唬人的」——这个理解是反的。

## 三方协议不是劳动合同

| 项目 | 三方协议 | 劳动合同 |
| --- | --- | --- |
| 签约主体 | 学生 + 单位 + 学校 | 劳动者 + 单位 |
| 法律性质 | **民事协议** | **劳动合同** |
| 适用法律 | 《民法典》 | 《劳动合同法》 |
| 违约金 | **可以约定** | 只有两种法定情形能约定 |
| 签订时间 | 毕业前 | 入职后一个月内 |

《劳动合同法》第二十五条写得很清楚：除「服务期」和「竞业限制」这两种情形外，用人单位不得与劳动者约定由劳动者承担违约金。

但这条管的是**劳动合同**。三方协议受《民法典》调整，属于普通民事合同，双方爱怎么约定怎么约定。

**所以那份三方上写的「违约金 X 元」，不是废纸。**

## 违约金一般多少钱

实践中从几千块到一个月工资不等。法律没有上限，但如果金额高得离谱，可以请求法院调低（《民法典》第五百八十五条，约定违约金过分高于造成的损失，可以请求适当减少）。

但说实话，为了几千块去打官司的人很少。**更实际的做法是签之前就想清楚：如果将来我要毁约，这个数我认不认。**

## 想毁约，按这个顺序走

1. **先翻协议，看违约金条款**——多少、什么条件触发、升学参军能不能免
2. **找原单位协商**——说明真实原因，请求减免。态度诚恳往往有用，很多 HR 见多了
3. **拿到书面解除证明或同意函**——一定要书面的
4. **向学校申请新的三方**——多数学校要求先有原单位解约函
5. 再和新单位签

## 三件千万不要做的事

- **不要直接消失。** 有些单位会记录，影响后续背调。
- **不要伪造解约函。** 这是伪造文件，性质就变了。
- **不要以为没签劳动合同就没事。** 三方是独立生效的协议，和劳动合同没关系。

## 签之前必须确认的六件事

- [ ] 违约金金额是多少，什么情况触发
- [ ] 有没有「服务期」约定（几年内不能离职）
- [ ] 岗位、工作地点、薪资是否与面试时一致
- [ ] 单位是否真的能接收档案和户口
- [ ] **备注栏有没有附加条款**（很多人只看正文，附加条件常写在这里）
- [ ] 升学、参军等特殊情况能否免责

最后一条尤其容易翻车。有些单位在备注栏加「须在 X 年内取得 XX 证书，否则视为违约」这种条件，正文里完全看不到。

## 几个常见误解

| 说法 | 实际 |
| --- | --- |
| 「三方就是劳动合同」 | 不是。入职后还要另外签劳动合同，三方不能替代 |
| 「签了不去也没事」 | 可能要付违约金 |
| 「违约金不合法」 | 三方是民事协议，违约金有效 |
| 「学校会帮我兜底」 | 学校只是见证方，不承担你的违约责任 |
| 「毁约影响征信」 | 通常不影响，但可能影响你们学校后续的招聘名额 |
