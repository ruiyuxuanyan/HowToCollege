# 新生入学防骗：假冒辅导员、助学金诈骗、校园贷

> 一句话概括：开学第一个月，骗子比你更熟悉流程——把他们的剧本拆开给你看。

**适用人群**：大一新生、准大学生、新生家长。

> **政策适用范围**
> - 主要依据：公安部、国家反诈中心公开发布的诈骗类型提示；《反电信网络诈骗法》
> - 全国统一：诈骗类型与法律定性全国一致
> - 核查日期：2026-11-05
> - ⏳ 易过时：具体话术每年更新，本文讲结构不讲逐字脚本

---

## 一、为什么新生是重点目标

| 原因 | 说明 |
| --- | --- |
| 信息差最大 | 不熟悉学校流程，分不清谁是真老师 |
| 手里有钱 | 学费、生活费刚到账 |
| 社交圈刚建立 | 急于融入，容易被「学长」拉进群 |
| 不敢质疑权威 | 对方自称老师、辅导员就不敢多问 |

## 二、五类高发骗局：话术 → 破绽 → 正确动作

### 2.1 假冒辅导员 / 学长加群收费

**常见剧本**：
> 「我是你们班的辅导员，加一下这个群，把资料费/班费/军训服装费交一下，统一购买。」

**破绽在哪**：
- 学校收费**走官方缴费平台**，不会在群里发个人收款码
- 真辅导员不会私下加学生微信收钱
- 「群」是谁建的？是不是从官方渠道拿到的？

**正确动作**：
- 通过**学校官网、录取通知书上的电话**核实
- 官方班级群通常由学校统一建立并公布
- 任何要你扫码付款的「通知」，先假设是假的

### 2.2 助学金 / 奖学金诈骗

**常见剧本**：
> 「你符合助学金条件，需要先交 200 元手续费/保证金才能发放。」

**破绽在哪**：
- **助学金、奖学金从不需要先交任何费用**
- 官方发放会直接打到你的银行卡，不需要「激活费」

**正确动作**：
- 记住一句话：**凡是先要钱的「发钱」，都是诈骗**
- 资助事宜只通过学校学生资助管理中心办理

### 2.3 校园贷 / 培训贷

**常见剧本**：
> 「零门槛、当天放款、不用抵押，学生也能借。」

**破绽在哪**：
- 监管已明令禁止向在校学生开展网贷业务
- 「不看还款能力」本身就是最大的风险信号

**正确动作**：见「校园贷与套路贷」一文

### 2.4 兼职刷单

**常见剧本**：
> 「招聘打字员/刷单员，日结 200–500，先做一单试试。」

**破绽在哪**：
- 第一单真的会返钱（建立信任），后面要求你垫付大额
- 刷单本身违法

**正确动作**：见「兼职、实习的常见骗局」一文

### 2.5 冒充公检法

**常见剧本**：
> 「你涉嫌洗钱/你的身份被冒用，需要配合调查，把钱转到安全账户。」

**破绽在哪**：
- **公检法从不会电话办案、不会要求转账**
- 「安全账户」是不存在的东西

**正确动作**：
- 直接挂断
- 打 110 核实（用你自己的电话打，不用对方给的号码）

## 三、三条通用识别原则

| 原则 | 具体做法 |
| --- | --- |
| **① 官方渠道核实** | 不信对方提供的电话/网址，自己从官网找 |
| **② 不转账、不扫码** | 任何要求付款的「通知」，先停 |
| **③ 不透露验证码** | 验证码等于密码，给谁都不行 |

**最有用的一句**：不管对方说自己是谁，**挂掉，用你自己查到的官方电话打回去核实**。

## 四、已经被骗了怎么办

**黄金时间是转账后最初几十分钟。**

| 时间 | 动作 |
| --- | --- |
| 立刻 | 打 110 报警；联系银行/支付平台申请止付 |
| 当天 | 保留全部证据：转账凭证、聊天记录、对方账号 |
| 当天 | 告诉家人（可能有人能帮你止损） |
| 之后 | 警惕「追款服务」——那是二次诈骗 |

详见「被骗后的心理与财务双重处理」一文。

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「学长不会骗我」 | 骗子最常冒充学长 |
| 「就几百块，算了」 | 几百块也要报警，且可能是连环骗的第一步 |
| 「不转会被处分」 | 没有任何学校会因你不转账而处分你 |
| 「对方知道我名字，应该是真的」 | 你的信息可能已泄露 |
| 「网上找人追款能要回来」 | 这是二次诈骗的高发区 |

## 六、可执行清单

### 存好三个号码

- [ ] **110**（报警）
- [ ] **学校官方电话**（从录取通知书或官网拿，不是别人给的）
- [ ] **12381**（工信部反诈预警，可查可疑号码）

### 报到前

- [ ] 只从**录取通知书、学校官网**获取信息
- [ ] 不加入来源不明的「新生群」
- [ ] 记住：所有缴费走官方平台

### 遇到可疑情况

- [ ] 挂断 / 不回
- [ ] 用自己查到的官方电话核实
- [ ] 告诉家长或辅导员

---

## 七、一句话记住

**凡是让你先付钱、先扫码、先给验证码的，先假设是诈骗，再去核实。**
