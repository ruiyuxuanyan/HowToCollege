# 报到要带什么：录取通知书到宿舍的第一周清单

> 一句话概括：把「带什么去学校」从一堆焦虑清单，变成一张分优先级的打勾表。

**适用人群**：准大学生、大一新生、新生家长。

> **核查日期**：2026-11-05

> ⚠️ **最重要的一句**：各校报到流程不同，**录取通知书里的《新生须知》才是唯一权威清单**。本文的通用清单只作参考。

---

## 一、三档分类

不要把所有东西都从家里背过去。

| 档次 | 含义 | 举例 |
| --- | --- | --- |
| **必须随身** | 丢了就办不成事，不能托运 | 录取通知书、身份证、档案、证件照 |
| 建议带 | 到校立刻要用 | 换洗衣物、常用药、充电器 |
| **到校再买** | 快递或当地超市更省力 | 被褥、脸盆、衣架、洗漱用品 |

**核心原则**：能买的不要背。快递寄到学校比自己扛两千公里轻松。

---

## 二、必须随身（丢了很麻烦）

| 物品 | 用途 | 丢了怎么办 |
| --- | --- | --- |
| **录取通知书** | 报到凭证 | 立即联系学校招生办，可补办证明 |
| **身份证**（原件+复印件） | 办卡、住宿、体检 | 到校后可就近办临时身份证 |
| 户口迁移证（如迁户口） | 办户口 | 联系原籍派出所补办 |
| 党团组织关系材料 | 转接 | 线上系统可补，详见 01-05 |
| **证件照**（一寸、二寸各若干） | 学生证、社团、各种表格 | 到校可拍 |
| 银行卡（学校指定） | 缴学费、发奖学金 | 到校办 |
| 家庭经济困难材料（如需要） | 绿色通道、困难认定 | 可后补，见 01-02、01-10 |

**复印件建议**：身份证正反面印 5 份，户口本首页+本人页印 3 份。

---

## 三、建议带（到校第一天就用得上）

- 换洗衣物（一周量即可，其余可后寄）
- 常用药（感冒药、肠胃药、创可贴、个人处方药）
- 手机充电器、充电宝
- 一双舒适的鞋（军训会用到）
- 少量现金（几百元，有些地方还不能扫码）
- 雨伞

---

## 四、到校再买（别背）

| 物品 | 为什么 |
| --- | --- |
| 被褥、枕头 | 占空间，学校通常会统一采购或附近有卖 |
| 脸盆、水桶、衣架 | 超市、快递都方便 |
| 洗漱用品 | 同上 |
| 台灯、插排 | 学校可能对电器有功率限制，先看清规定 |
| 床上用品 | 部分学校统一发放，别重复买 |

**做法**：出发前查一下学校是否统一采购床上用品（《新生须知》里会写），避免买重复。

---

## 五、报到当天的实际流程

多数学校大同小异：

| 步骤 | 做什么 |
| --- | --- |
| 1 | 到站（火车站/机场）→ 找学校的接站车（多数学校有） |
| 2 | 到报到点 → 核验证件、交录取通知书 |
| 3 | 缴费（或走绿色通道） |
| 4 | 领宿舍钥匙、校园卡 |
| 5 | 到宿舍安顿 |
| 6 | 后续：体检、领教材、开班会 |

---

## 六、读懂《新生须知》

录取通知书里那几页纸，请认真看完。重点找：

- [ ] 报到时间与地点（有些专业在不同校区！）
- [ ] 缴费方式与截止时间
- [ ] 是否统一采购床上用品
- [ ] 户口迁移怎么办
- [ ] 档案转递要求
- [ ] 党团组织关系转接方式
- [ ] 绿色通道的办理点与材料

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「被子脸盆都要从家背」 | 快递或当地买更省力 |
| 「要带户口本原件」 | 多数只需复印件，看新生须知 |
| 「录取通知书丢了就不能报到」 | 可联系招生办补办证明 |
| 「所有专业都在主校区」 | 部分学校分校区，务必确认 |
| 「带越多越安心」 | 越少越轻松，缺什么都能买 |

---

## 八、可执行清单

### 出发前

- [ ] 通读《新生须知》，标出关键时间点
- [ ] 确认报到地点在哪个校区
- [ ] 准备证件材料（按第二节表格）
- [ ] 身份证复印件各 5 份
- [ ] 证件照一寸二寸各 10 张

### 打包

- [ ] 必须随身类放随身包（不托运）
- [ ] 大件行李走快递到校
- [ ] 少量现金

### 报到当天

- [ ] 找接站车
- [ ] 核验证件
- [ ] 缴费或走绿色通道
- [ ] 领钥匙入住

---

## 九、一句话记住

**证件随身、大件快递、缺的现买。走之前把《新生须知》读完。**
