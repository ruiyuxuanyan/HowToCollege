# 家庭经济困难认定

> 一句话概括：这是拿助学金、助学贷款、勤工助学的第一道门，符合条件的很多人不知道自己符合。

**适用人群**：家庭经济有困难但不确定该不该申请的在校生；新生及家长。

> **政策适用范围**
> - 主要依据：教育部、财政部关于家庭经济困难学生认定的相关规定；各校学生资助管理中心实施办法
> - 全国统一：认定制度全国统一要求建立
> - 地方执行：**认定标准、分档名称、材料清单各省各校不同**
> - 核查日期：2026-11-05

---

## 一、认定能带来什么

**困难认定本身不给钱，但它是几乎所有资助的前置条件。**

| 资助项目 | 是否需要困难认定 |
| --- | --- |
| 国家助学金 | **需要** |
| 国家励志奖学金 | **需要** |
| 国家助学贷款 | 通常需要 |
| 勤工助学 | 多数学校需要 |
| 绿色通道 | 需要（可后补） |
| 学费减免 | 需要 |
| 临时困难补助 | 需要 |

**没有认定 = 拿不到上述任何一项。**

---

## 二、认定标准是什么

**没有全国统一的分数线。** 认定看的是综合情况：

| 考量因素 | 具体内容 |
| --- | --- |
| 家庭收入 | 家庭人均收入水平 |
| 家庭人口与赡养负担 | 供养人数、老人、病人 |
| 特殊身份 | 低保、特困供养、建档立卡、残疾、孤儿 |
| 突发变故 | 重大疾病、灾害、意外事故 |
| 其他 | 单亲、多子女在读等 |

### 分档

多数学校分 2–3 档，常见为：

| 档次 | 通常对应 |
| --- | --- |
| 特别困难 | 低保、特困、建档立卡、孤儿、残疾等 |
| 困难 | 家庭收入明显偏低 |
| 一般困难 | 有一定经济压力 |

**档次影响能拿多少钱**，所以如实填写很重要。

---

## 三、怎么申请

### 3.1 时间

通常在**每学年开学初**集中办理。新生入学时随入学手续办。

### 3.2 流程（通用）

| 步骤 | 做什么 |
| --- | --- |
| 1 | 填写《家庭经济困难学生认定申请表》（通常在录取通知书材料或学校资助中心网站） |
| 2 | 准备证明材料（低保证、残疾证、医疗诊断书等，如有） |
| 3 | 提交给辅导员或班级认定小组 |
| 4 | 班级评议 + 学院审核 |
| 5 | 学校学生资助管理中心审批 |
| 6 | 结果反馈 |

### 3.3 每年都要重新认定

**认定不是一次性的。** 每学年通常需要重新申请认定，因为家庭情况会变化。

---

## 四、隐私保护：你有权利要求

这一点很多人不知道，但它很重要。

**困难认定过程中，你的家庭具体困难细节不应被公开评议、公示。**

| 不该发生 | 可以怎么做 |
| --- | --- |
| 让你在班会上公开讲述家庭困难 | 可向学校学生资助管理中心反映 |
| 公示你的家庭收入、疾病等细节 | 公示一般只公示姓名与档次 |
| 同学评议时讨论你家的具体情况 | 评议应聚焦于是否符合标准 |

如果你遇到上述情况，可以向**学校学生资助管理中心**或**学院学生工作办公室**反映。

---

## 五、不实申报的后果

**必须如实填写。**

| 后果 | 说明 |
| --- | --- |
| 取消认定资格 | 当年及后续 |
| 追回已发放资金 | 已拿的助学金要退 |
| 纪律处分 | 视情节 |
| 影响信用 | 部分学校记入诚信档案 |

**但「如实」不等于「往惨里写」**：符合条件就申请，不符合就不要勉强。

---

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「我家不算特别穷，不用申请」 | 认定分档，中间档也有资助 |
| 「申请了会被同学看不起」 | 隐私受保护，且这是制度设计 |
| 「认定一次管四年」 | 通常每学年重新认定 |
| 「材料不齐就办不了」 | 可先提交，后补材料 |
| 「认定等于拿钱」 | 认定只是资格，还要单独申请各项资助 |
| 「港澳台/留学生不适用」 | 政策对象是全日制本专科生与研究生，具体以本校办法为准 |

## 七、可执行清单

### 入学前/开学初

- [ ] 找到《家庭经济困难学生认定申请表》（录取通知书材料里或学校资助中心网站）
- [ ] 准备证明材料：低保证、残疾证、医疗诊断书、灾害证明等（有就提供）
- [ ] 查本校的分档标准与申请截止时间

### 提交后

- [ ] 跟进审核进度
- [ ] 认定通过后，**立刻**申请助学金、助学贷款、勤工助学
- [ ] 记住下一年要重新申请

### 遇到问题

- [ ] 认定过程被过度公开 → 向资助中心反映
- [ ] 不确定自己是否符合 → 直接问辅导员或资助中心

---

## 八、一句话记住

**认定本身不给钱，但不做认定，后面所有资助都拿不到。**

符合条件就申请，这是制度，不是求人。
