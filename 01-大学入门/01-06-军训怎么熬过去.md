# 军训怎么熬过去：身体、物资、请假与免训

> 一句话概括：军训不是考验意志，是考验你会不会照顾自己。

**适用人群**：大一新生。

> **核查日期**：2026-11-07

---

## 一、军训通常是什么样

- 时长：多数学校 2–4 周
- 内容：队列训练、军姿、正步、拉歌、内务
- 强度：以站立和行走为主，日晒时间长

**风险点不在强度，而在**：中暑、脱水、晒伤、脚磨破、睡眠不足。

---

## 二、物资清单

| 类别 | 必需品 | 好用 | 不必买 |
| --- | --- | --- | --- |
| 防晒 | 防晒霜（SPF50+）、帽子 | 冰袖、防晒喷雾 | 高价防晒衣 |
| 补水 | 大水杯（1L 以上） | 电解质冲剂 | 功能饮料（糖多） |
| 脚部 | 软底运动鞋、棉袜（多双） | 防磨贴、鞋垫 | — |
| 其他 | 毛巾、纸巾 | 清凉油、湿巾 | 各种「军训神器」 |

**最实用的三样**：防晒霜、大水杯、备用袜子。

---

## 三、身体照顾

| 问题 | 怎么做 |
| --- | --- |
| 晒伤 | 提前涂防晒，每 2 小时补涂；晒后用芦荟胶 |
| 脱水 | 少量多次喝水，别等渴了才喝 |
| 脚磨破 | 提前贴防磨贴，换干爽袜子 |
| 肌肉酸痛 | 晚上拉伸，热水泡脚 |
| 睡眠不足 | 保证 7 小时，比什么都重要 |

---

## 四、必须停下来的信号（重要）

出现以下情况**立即报告教官**，不要硬扛：

| 信号 | 可能的危险 |
| --- | --- |
| 头晕、恶心、大量出汗后突然不出汗 | **中暑先兆** |
| 皮肤发烫、意识模糊 | **热射病前兆**（会死人） |
| 心慌、胸闷、眼前发黑 | 心血管反应 |
| **酱油色尿** | **横纹肌溶解**，必须立即就医 |
| 剧烈腹痛、呕吐不止 | 多种可能，需就医 |

**热射病是最危险的**：高热 + 意识改变 + 无汗，必须立刻送医，同时物理降温。

## 五、请假与免训

### 5.1 什么情况可以申请

| 情况 | 通常处理 |
| --- | --- |
| 心脏病、哮喘等慢性病 | 可申请免训或见习 |
| 骨折恢复期、近期手术 | 可申请免训或缓训 |
| 女性生理期严重不适 | 可申请当日休息 |
| 发热、急性病 | 请假 |
| 其他医学原因 | 凭医院证明申请 |

### 5.2 怎么申请

| 步骤 | 做什么 |
| --- | --- |
| 1 | 到校医院或正规医院就诊，取得**诊断证明** |
| 2 | 向辅导员提交免训/缓训申请 |
| 3 | 由军训团/武装部审批 |
| 4 | 获批后按安排执行（可能是「见习」而非完全休息） |

### 5.3 免训不等于不用参加

多数学校的处理是**见习**：不参加体力训练，但要到场、做后勤或记录。具体看学校规定。

**这不是丢人的事。** 有医学理由就该申请，硬扛出事才是真的麻烦。

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「硬扛才是锻炼」 | 中暑和横纹肌溶解是真实风险 |
| 「喝藿香正气水能防中暑」 | 不能预防，只能缓解轻微不适 |
| 「出汗多就该少喝水」 | 错，出汗多更要补水补电解质 |
| 「申请免训会被看不起」 | 医学理由正当，没人有资格评价 |
| 「晕倒了才需要报告」 | 有先兆信号就该报告 |

## 七、可执行清单

### 军训前

- [ ] 买防晒霜（SPF50+）、1L 以上水杯
- [ ] 准备 3–5 双棉袜
- [ ] 有慢性病的，提前办好医学证明
- [ ] 确认学校的请假流程

### 每天

- [ ] 提前 20 分钟涂防晒
- [ ] 带足水，加电解质
- [ ] 训练中不适立即报告
- [ ] 晚上拉伸、泡脚
- [ ] 保证睡眠

### 出现危险信号

- [ ] 立即停止训练
- [ ] 报告教官
- [ ] 严重时打 120

## 八、一句话记住

**防晒、补水、别硬扛。有医学理由就请假，这不丢人。**
