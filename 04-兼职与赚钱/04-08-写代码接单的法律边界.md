# 写代码接单的法律边界：四种会让你坐牢的活

> 一句话概括：技术水平不是免责理由，接一单外挂可能比偷一台电脑判得更重。

**适用人群**：会写代码、正在或准备接私活的学生；在群里看到「高价求开发」的人；已经写过程序但不确定它是否合法的人。

> **本文性质**
>
> 本文是法律信息整理，**不构成法律意见**。具体个案请咨询执业律师。法条的适用与量刑由司法机关裁量。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国刑法》第二百一十七条、第二百五十三条之一、第二百八十五条、第二百八十六条、第二百八十七条；《中华人民共和国网络安全法》；两高相关司法解释
> - 全国统一：刑法与司法解释在全国范围内统一适用
> - 核查日期：2026-11-05
> - 已知变化：本文所述法条目前有效；具体入罪门槛以司法解释与法院裁判为准

## 一、先建立一个基本认知

**「我只是写代码，不知道他拿去干什么」——这句话在法律上不是免罪符。**

三个原因：

1. 刑法中有多个罪名**不要求你参与下游犯罪**，只要你的行为本身符合构成要件
2. 部分罪名允许**推定明知**（交易价格异常、使用隐蔽手段、对方明确要求规避监管等）
3. **违法所得**是量刑依据，不是"我只是个打工的"就能免责

下面四类是最容易踩到的。

## 二、外挂：刑法第二百八十五条

### 2.1 法条

《刑法》第二百八十五条涉及非法侵入计算机信息系统、非法获取计算机信息系统数据、非法控制计算机信息系统，以及**提供侵入、非法控制计算机信息系统的程序、工具**。

其中第三款是关键：

> 提供专门用于侵入、非法控制计算机信息系统的程序、工具，或者明知他人实施侵入、非法控制计算机信息系统的违法犯罪行为而为其提供程序、工具，情节严重的，依照前款的规定处罚。
>
> 【法规】《中华人民共和国刑法》第二百八十五条第三款

### 2.2 为什么外挂会落到这一条

游戏外挂的典型实现方式是：读取或修改游戏客户端内存、拦截通信数据、绕过检测机制、向服务器发送伪造请求。这些行为在司法实践中常被认定为"侵入"或"非法控制"计算机信息系统，或属于专门用于该目的的程序工具。

**注意**：不要求你入侵了服务器。**提供工具**本身就是处罚对象。

### 2.3 现实中的常见说法

| 对方的话术 | 实际风险 |
| --- | --- |
| 「就是个小工具，玩家自己用」 | 「专门用于侵入」的工具，提供即可能构罪 |
| 「你只负责写，出去的事我负责」 | 你是提供者，正是本条针对的对象 |
| 「别人都在做，没事」 | 别人没被抓不等于合法 |
| 「做完删掉代码就行」 | 交付行为已完成，且聊天记录、转账记录都是证据 |
| 「按次收钱，一次几百」 | 违法所得累计计算，次数多即可能达到"情节严重" |

### 2.4 还有别的罪名可能同时成立

外挂案件常出现罪名竞合，除 285 条外还可能涉及：

- **侵犯著作权罪**（第 217 条）：修改、复制游戏代码
- **破坏计算机信息系统罪**（第 286 条）：造成系统不能正常运行
- **非法经营罪**（第 225 条）：未经许可经营需许可的业务

**最终按处罚较重的规定定罪处罚。**

## 三、破解：刑法第二百一十七条

### 3.1 法条

> 以营利为目的，有下列侵犯著作权或者与著作权有关的权利的情形之一，违法所得数额较大或者有其他严重情节的，处三年以下有期徒刑，并处或者单处罚金；违法所得数额巨大或者有其他特别严重情节的，处三年以上十年以下有期徒刑，并处罚金：
>
> （一）未经著作权人许可，复制发行、通过信息网络向公众传播其文字作品、音乐、美术、视听作品、计算机软件及法律、行政法规规定的其他作品的；
> ……
>
> 【法规】《中华人民共和国刑法》第二百一十七条（2020 年《刑法修正案（十一）》修改）

### 3.2 关键要素

| 要素 | 说明 |
| --- | --- |
| **以营利为目的** | 免费分享通常不构成本罪（但可能承担民事赔偿） |
| **未经许可** | 破解正版软件、去除授权验证、制作注册机 |
| **复制发行/信息网络传播** | 出售破解版、发布到网盘、做成"绿色版"分发 |

### 3.3 学生最容易踩的形态

| 形态 | 风险 |
| --- | --- |
| 做某软件的"破解补丁"卖钱 | 直接符合构成要件 |
| 写"注册机"生成序列号 | 同上 |
| 破解网课/教辅平台后分享 | 可能构成，且平台常主动报案 |
| 帮人"去除软件试用限制"收费 | 同上 |
| 汉化组/资源站收费会员 | 可能构成 |

**特别注意**：`以营利为目的` 不要求你直接卖软件。**通过破解内容引流、卖广告、卖会员、卖教程**，都可能被认定为营利目的。

## 四、爬取非公开数据：第二百五十三条之一 / 第二百八十五条

这一类最容易被低估，因为"写爬虫"在很多人眼里是基础技能。

### 4.1 两个可能的罪名

| 罪名 | 法条 | 适用情形 |
| --- | --- | --- |
| **侵犯公民个人信息罪** | 第 253 条之一 | 爬取的是**个人信息**（姓名、身份证号、手机号、住址、行踪等） |
| **非法获取计算机信息系统数据罪** | 第 285 条第二款 | 爬取的是**计算机信息系统中的数据**，且采用技术手段突破防护 |

### 4.2 分界线在哪

| 情形 | 通常不构成犯罪 | 高风险 |
| --- | --- | --- |
| 数据性质 | 公开可访问的网页信息 | 需要登录才能看的、非公开的 |
| 是否突破防护 | 遵守 robots 协议、正常访问 | 绕过验证码、破解加密、伪造 token、侵入后台接口 |
| 数据内容 | 商品价格、公开评论 | **个人信息**、企业内部数据 |
| 规模与后果 | 少量、个人研究 | 大规模、造成系统异常、被转卖 |

**最危险的两个组合**：

1. **爬个人信息 + 转卖/提供给别人** → 侵犯公民个人信息罪的高危区
2. **绕过技术防护 + 大量爬取** → 非法获取计算机信息系统数据罪

### 4.3 常见的接单陷阱

| 需求描述 | 真实情况 |
| --- | --- |
| 「帮我爬一下这个网站的用户数据」 | 个人信息，重罪 |
| 「要能绕过登录/验证码」 | 突破技术防护 |
| 「爬某平台商家联系方式」 | 可能包含个人信息 |
| 「破解这个 App 的接口，批量查手机号」 | 双重高危 |
| 「爬完发我一份，给你 500」 | 你已经是数据获取者 |

**一句话判断**：如果对方要求你"绕过"任何东西（登录、验证码、加密、频率限制），停下来查清楚再动手。

## 五、DDoS 与压力测试：第二百八十六条

### 5.1 法条

> 违反国家规定，对计算机信息系统功能进行删除、修改、增加、干扰，造成计算机信息系统不能正常运行，后果严重的，处五年以下有期徒刑或者拘役；后果特别严重的，处五年以上有期徒刑。
>
> 【法规】《中华人民共和国刑法》第二百八十六条第一款

### 5.2 「压力测试」不是挡箭牌

| 说法 | 实际情况 |
| --- | --- |
| 「我们在做压力测试」 | **没有对方书面授权就是攻击** |
| 「客户让我打的」 | 客户无权授权攻击第三方系统 |
| 「只打了几分钟」 | 造成服务中断即可能"后果严重" |
| 「只是发请求，不算破坏」 | "干扰"本身就在条文里 |
| 「用别人的机器打，查不到我」 | 控制他人计算机本身另构成犯罪（第 285 条第二款） |

### 5.3 合法的压力测试长什么样

真正合规的性能测试必须满足：

1. **有目标系统所有者的书面授权**（明确测试时间、范围、方式）
2. **在约定时间窗口内进行**
3. **不使用被入侵的第三方设备**（"肉鸡"）
4. 有应急停止机制

任何一条不满足，性质就从"测试"变成"攻击"。

## 六、还有一条常被忽略的法律

### 6.1 《网络安全法》的行政责任

即使未达到刑事门槛，也可能面临行政处罚。

> 任何个人和组织不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等危害网络安全的活动；不得提供专门用于从事侵入网络、干扰网络正常功能及防护措施、窃取网络数据等危害网络安全活动的程序、工具……
>
> 【法规】《中华人民共和国网络安全法》第二十七条

行政处罚可能包括：警告、罚款、拘留、没收违法所得。

### 6.2 学校的处分

即使司法机关不追究，学校也可能依据校规给予处分，影响毕业与档案（见「违规用电用火的后果」中关于处分后果的说明——处分入档的逻辑同样适用）。

## 七、接单前的自查方法

### 7.1 五问法

对每一单，问自己五个问题：

| 问题 | 危险答案 |
| --- | --- |
| 1. 这个程序需要"绕过"什么吗？ | 需要绕过登录/验证码/加密/检测 |
| 2. 需求方为什么不自己做？ | 因为他不会，或者他知道有风险 |
| 3. 报酬是否明显高于工作量？ | 是（异常高价是推定明知的信号） |
| 4. 需求方是否要求保密、要求删记录、要求用虚拟货币收款？ | 是，三个都是危险信号 |
| 5. 如果这件事被写在报纸上，我能接受吗？ | 不能 |

**任何一问触发危险答案，就不要接。**

### 7.2 危险需求的共同特征

- 需求描述含糊，不愿说明用途
- 明确要求"不要问"
- 要求用境外聊天软件、虚拟货币结算
- 报酬远高于市场价
- 要求你删除聊天记录
- 要求以他人身份交付

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「我只是写代码，不参与运营就没事」 | 提供工具本身可能就是处罚对象 |
| 「免费分享不违法」 | 不构成犯罪，但民事侵权责任仍在 |
| 「爬虫是基础技能，不会有问题」 | 爬个人信息、突破防护可能构罪 |
| 「客户授权的压力测试就合法」 | 客户无权授权攻击第三方 |
| 「金额小就没事」 | 违法所得累计计算，次数比单次金额更关键 |
| 「删掉代码就查不到」 | 转账记录、聊天记录、服务器日志都是证据 |
| 「我不知道对方拿去干什么」 | 法律允许推定明知 |

## 可执行清单

### 接单前

- [ ] 用五问法过一遍
- [ ] 要求对方书面说明用途与授权情况
- [ ] 判断是否需要"绕过"任何技术防护
- [ ] 查一下需求方是否在招"外挂""破解""爬数据"类需求

### 已经接了怎么办

- [ ] 立即停止交付
- [ ] 不要删除已有记录（删除可能被视为毁灭证据）
- [ ] 咨询律师
- [ ] 如已被约谈，如实说明，不要编造

### 长期习惯

- [ ] 只接能说清正当用途的活
- [ ] 不接需要绕过的活
- [ ] 不用虚拟货币结算
- [ ] 保留所有交付前的需求沟通
