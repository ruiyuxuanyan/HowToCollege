# 大学生兼职要不要交税：预扣了 20% 还能退回来

> 一句话概括：你被扣的税大概率能退，但前提是你知道每年 3-6 月要办汇算。

**适用人群**：接过兼职并被扣过税的学生；在平台接单收到"税前/税后"报价的人；担心"交税会不会影响家里"的人。

> **本文性质**
>
> 本文是税务信息整理，**不构成税务意见**。具体申报请以主管税务机关的解答为准。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国个人所得税法》（2018 年修正）及其实施条例；国家税务总局关于个人所得税综合所得汇算清缴的公告；劳务报酬所得预扣预缴相关规定
> - 全国统一：个人所得税制度在全国范围内统一适用
> - 核查日期：2026-11-05
> - 已知变化：基本减除费用标准、税率表、专项附加扣除标准以现行税法为准；汇算清缴的具体办理规则每年由国家税务总局公告明确
>

## 一、先回答最关心的问题

**要不要交？**

| 你的情况 | 要不要交税 |
| --- | --- |
| 校内勤工助学，收入很低 | 通常不达起征点，不用交 |
| 校外兼职，对方代扣了税 | 已被预扣，年度汇算时可能退回 |
| 平台接单，显示"税后到手" | 平台已代扣代缴 |
| 兼职收入全年很少，没被扣过 | 可能本来就不用交 |
| 年收入较高的自由职业 | 需要依法申报纳税 |

**核心认知**：**兼职收入属于应税所得，但有起征点和扣除项。绝大多数学生兼职收入根本达不到需要实际负担税款的水平。**

---

## 二、你的兼职收入属于哪一类

个人所得税把所得分为九类。学生兼职务必分清前两类：

| 所得类型 | 典型情形 | 计税方式 |
| --- | --- | --- |
| **劳务报酬所得** | 家教、接单、兼职讲课、设计、翻译 | 按次预扣，年度并入综合所得 |
| **工资薪金所得** | 有劳动关系的固定工作 | 按月预扣，年度并入综合所得 |
| **经营所得** | 办了营业执照的个体户 | 按年计算 |
| **稿酬所得** | 写稿、出书 | 按次预扣，有减征优惠 |
| **特许权使用费所得** | 专利、著作许可 | 按次预扣 |

**绝大多数学生兼职是「劳务报酬所得」。** 本文主要讲这一类。

### 2.1 为什么分类重要

因为**预扣率不同**，而且只有"综合所得"（工资薪金、劳务报酬、稿酬、特许权使用费）才在年度汇算时合并计算。

---

## 三、劳务报酬的预扣预缴

### 3.1 机制

支付方（公司、平台、个人雇主）在付钱给你时，负有**代扣代缴**义务。

预扣的计算方式是：

```
预扣税额 = (每次收入 − 费用扣除) × 预扣率 − 速算扣除数
```

其中：

- 每次收入不超过一定金额时，费用扣除按固定金额计算
- 超过该金额时，费用扣除按收入的一定比例计算
- 预扣率按收入档次分三档：**20%、30%、40%**

### 3.2 关键点：预扣 ≠ 最终税负

这是本文最重要的一句话。

**预扣是按"单次收入"算的，而实际税负是按"全年综合所得"算的。**

| 情形 | 预扣 | 年度汇算 |
| --- | --- | --- |
| 单次收了 5000 元 | 按 20% 档预扣 | 全年收入可能远低于起征点 → **全额退** |
| 一年做了 3 次，每次 3000 元 | 每次预扣 | 合并后可能不用交 → **退** |
| 全年兼职收入较高 | 预扣 | 按综合所得税率表计算，多退少补 |

### 3.3 具体的费用扣除与税率

**这些数字每年可能调整，且需配合当年的基本减除费用标准计算。本文不写具体金额。**

查询渠道：

| 查什么 | 去哪查 |
| --- | --- |
| 劳务报酬预扣率表、费用扣除规则 | 国家税务总局官网「政策文件」栏目 |
| 综合所得税率表 | 同上 |
| 基本减除费用标准 | 个人所得税法第六条（现行标准以法律文本为准） |
| 专项附加扣除标准 | 国务院相关文件 + 个税 App |

**不要按记忆或网上传的数字报税。** 个税 App 会自动计算，你只需确认数据。【待核实：各档金额与税率，请以国家税务总局现行公告及个税 App 显示为准】

## 四、年度汇算清缴：退钱的环节

### 4.1 什么是汇算清缴

把全年的综合所得合并，重新计算应纳税额，与已预扣的税额比较：

- 预扣多了 → **退税**
- 预扣少了 → **补税**

### 4.2 什么时候办

**每年 3 月 1 日至 6 月 30 日**，办理上一年度的汇算清缴。

### 4.3 学生为什么常常能退税

| 原因 | 说明 |
| --- | --- |
| 年收入低于基本减除费用标准 | 全年合并后可能完全不用交 |
| 预扣率高于实际适用税率 | 按次预扣 20%，全年综合税率可能很低 |
| 基本减除费用没被用掉 | 你平时没有单位按月代扣，这笔扣除额度空着 |
| 专项附加扣除没填报 | 继续教育、住房租金、赡养老人等 |
| 有符合条件但未申报的公益捐赠 | 可按规定扣除 |

**结论：只要这一年被预扣过个税，就应该去办汇算。大概率能退。**

### 4.4 怎么办理

| 渠道 | 说明 |
| --- | --- |
| **个人所得税 App** | 最方便，国家税务总局官方 |
| 自然人电子税务局（网页版） | 功能更全 |
| 办税服务厅 | 现场办理 |

**操作步骤**：

1. 下载并实名注册「个人所得税」App
2. 进入「收入纳税明细查询」，核对每笔收入与已缴税额
3. 填报「专项附加扣除」
4. 进入「综合所得年度汇算」，选择"使用已申报数据填报"
5. 系统自动计算应退/应补税额
6. 申请退税，绑定本人 I 类银行卡（需通过实名验证）
7. 等待审核，通常数日至数周

### 4.5 要不要补税

如果汇算结果是补税，也有免于办理的情形（比如补税金额很小，或全年收入未超过一定标准）。**具体条件每年由国家税务总局公告规定。**【待核实：免于办理汇算的金额条件，请查当年国家税务总局公告】

## 五、几个高频疑问

### 5.1 「我是学生，没有工作，也要报税吗？」

要看你有没有应税收入。**有没有工作不是判断标准，有没有应税所得才是。**

如果你全年只有很少的兼职收入，很可能不用交税，也可能不需要办理汇算。但只要有预扣，办一次汇算就可能拿回钱。

### 5.2 「兼职交税会不会影响家里的低保/助学金？」

**这是最常见的担心。**

- **纳税记录本身**不等于家庭收入认定。家庭经济困难认定看的是家庭收入和财产状况（见「家庭经济困难认定」01-10）
- 但你本人有较多收入，在部分认定中可能被计入家庭收入
- **具体认定口径由各校与地方民政部门掌握**

**建议**：如果家里有低保或你在申请助学金，先问辅导员或学生资助中心，说明你的兼职收入情况，确认是否影响认定。**不要因为怕影响就逃税**——逃税的后果更严重。【待核实：各校家庭经济困难认定中"学生本人收入"的计算口径，请咨询本校学生资助管理中心】

### 5.3 「平台说'税后 800'，是被扣了多少？」

说明平台按劳务报酬预扣了税。具体扣多少取决于当次收入金额与预扣规则。可以在个税 App 查到这笔申报记录。

**建议**：所有平台接单，都去 App 核对一遍收入明细。既能确认对方真的申报了（关系到你的纳税记录），也能确认金额对不对。

### 5.4 「对方没给我申报怎么办？」

如果个税 App 查不到某笔收入：

1. 说明支付方可能未依法代扣代缴
2. 你的纳税记录会缺失这部分收入
3. 可向主管税务机关反映（12366 纳税服务热线）

**不要配合对方"不申报少收点"的方案**——这会给你留下风险。

### 5.5 「能不能不交？」

**不能。** 依法纳税是义务。但对学生而言，实际负担通常很低甚至为零，走正规流程反而能退税。

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「学生不用交税」 | 学生身份不免税，看收入是否达起征点 |
| 「被扣了 20% 就没了」 | 年度汇算大概率能退 |
| 「收入低就不用管」 | 有预扣就应该去办汇算，能退钱 |
| 「不申报就查不到」 | 支付方有代扣代缴义务，数据会上传 |
| 「平台说税后就是税后」 | 去 App 核对申报记录 |
| 「交税会影响助学金」 | 纳税记录≠家庭收入认定，但需确认本校口径 |
| 「退税很麻烦」 | 个税 App 几分钟能办完 |
