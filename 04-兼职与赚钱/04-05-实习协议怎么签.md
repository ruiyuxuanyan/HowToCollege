# 实习协议怎么签：实习协议 ≠ 劳动合同

> 一句话概括：签错一份纸，可能丢掉应届生身份、赔掉违约金、还拿不到工伤保障。

**适用人群**：拿到实习 offer 准备签字的学生；被公司要求签「实习协议」「三方协议」「劳务协议」但不知道区别的人；实习期被要求交违约金的人。

> **本文性质**
>
> 本文是法律信息整理，**不构成法律意见**。具体争议请咨询执业律师或当地劳动人事争议仲裁机构。
>
> **政策与法律适用范围**
> - 主要依据：《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》（劳部发〔1995〕309 号）第十二条；《中华人民共和国民法典》合同编；《职业学校学生实习管理规定》（教职成〔2021〕4 号，适用于职业学校学生）
> - 全国统一 / 地方执行：实习关系的法律定性由《民法典》与司法实践确定；具体实习管理要求由教育部及各省教育行政部门、各校规定
> - 核查日期：2026-11-05
> - 已知变化：实习关系的司法认定仍在演变，2025 年已出现认定在校生构成劳动关系的判决
>
> ⏳ 易过时：各校实习管理办法、学分认定规则每年可能调整。

## 一、先分清四种「纸」

这是本文最核心的一节。很多纠纷源于签错了类型。

| 文件 | 谁和谁签 | 法律性质 | 什么时候签 |
| --- | --- | --- | --- |
| **实习协议** | 学生 ↔ 实习单位 | 民事合同（通常是劳务/服务性质） | 入职实习前 |
| **三方协议**（就业协议书） | 学生 ↔ 学校 ↔ 用人单位 | 预约性质的民事协议，**不是劳动合同** | 毕业前确定就业去向时 |
| **劳动合同** | 劳动者 ↔ 用人单位 | 劳动关系，受《劳动合同法》调整 | 正式入职（毕业后） |
| **劳务协议/兼职协议** | 个人 ↔ 单位 | 劳务关系 | 短期、项目制 |

### 1.1 实习协议不是劳动合同

判断标准是实质而非名称，但通常：

- 实习生**没有**劳动关系（依据劳部发〔1995〕309 号第 12 条的基本逻辑）
- 因此**不适用**最低工资、加班费、经济补偿金、工伤保险等劳动法保护
- 实习期间受伤，一般**不能认定工伤**，走人身损害赔偿（详见「实习/兼职期间的伤害」一文）

**但是**——这条不是绝对的。2025 年已有判决认定，在校生以**就业为目的**、接受单位考勤管理、按月领薪的，构成**事实劳动关系**。判断要素见「大学生兼职的法律身份」（04-01）第四节的对照表。

### 1.2 三方协议不是劳动合同

三方协议常被误解为"工作合同"。它实际上是：

- 一份**预约合同**：约定毕业后双方签订劳动合同
- 主要作用是**学校统计就业率**、**约束双方不随意反悔**
- 三方协议里通常有**违约金条款**，这是它和劳动合同最大的差别之一

**关键提醒**：签了三方不等于有了工作，也不等于有了劳动关系。毕业后仍要签劳动合同。

## 二、实习协议必须写清的六件事

签字前逐条对照。缺哪条，当场问。

### 2.1 实习期限与起止日期

- 明确开始日、结束日
- 是否可续、续期条件
- 每周实习天数、每日时长

很多学校的实习要求有最低周数（用于学分认定），**先查本校实习管理办法**，别签了才发现不满足学分要求。【待核实：各校实习学分认定规则，请查本校教务处/院系通知】

### 2.2 实习内容与岗位

| 要写清 | 为什么 |
| --- | --- |
| 岗位名称 | 防止被安排去干无关的杂活 |
| 具体工作内容 | 同上 |
| 指导/带教安排 | 部分学校要求有企业导师 |

"打杂"式实习不仅学不到东西，还可能不满足学校对实习内容的要求。

### 2.3 实习补贴

- 金额、发放周期、发放方式
- 是否含餐补/交通补/住宿
- 请假、缺勤如何扣减

**注意**：实习补贴**不受最低工资约束**（因为不是劳动关系）。但**低于当地最低工资的实习补贴在道德上可疑、在部分地方规定中也可能不被允许**——部分省市对职业院校学生实习报酬有明确要求，普通本科实习则主要靠学校规定与企业自律。【待核实：部分省市对实习生报酬有专门规定，需按所在地核查】

### 2.4 工作时间与安全

- 每日/每周最长工作时间
- 是否加班、加班是否另有补偿
- 工作场所的安全条件
- 是否购买**实习责任保险**或**意外伤害保险**

**这一条最重要。** 实习生不享受工伤保险，一旦出事只能走人身损害赔偿。要求单位购买商业意外险，是你唯一低成本的兜底。【经验】

### 2.5 保密与知识产权

| 条款 | 要看什么 |
| --- | --- |
| 保密范围 | 是否宽到把"公司一切信息"都算进去 |
| 保密期限 | 离职后几年 |
| 成果归属 | 你做的成果归谁？**实习期间的作品通常约定归公司**，这是行业惯例，但范围要清楚 |
| 是否限制你今后就业 | 见下节竞业条款 |

### 2.6 解除与违约责任

- 提前多久通知可以结束实习
- 提前离岗是否要赔违约金
- 单位提前终止是否需要补偿

**行业惯例**：实习协议中的"违约金"条款如果明显不对等（只约束学生、不约束单位），在诉讼中可能不被支持。但**不要在签字时赌这一点**，能谈就谈掉。【经验】

## 三、竞业限制：实习生也可能被套住

竞业限制的本意是保护商业秘密，但有些公司把它写进实习协议，用来阻止实习生毕业后去竞争对手。

### 3.1 法律上怎么看

《劳动合同法》对**劳动关系**下的竞业限制作了明确规定：限于高级管理人员、高级技术人员和其他负有保密义务的人员，且**必须支付经济补偿**。

实习生不是劳动者，实习协议里的竞业条款走《民法典》，**约束力取决于条款是否显失公平**。

### 3.2 签字前的三个问题

| 问题 | 危险信号 |
| --- | --- |
| 竞业范围有多宽？ | "任何同行业公司"——过宽，可能无效，但会给你添麻烦 |
| 期限多长？ | 超过 2 年要警惕 |
| 有没有补偿？ | **没有补偿的竞业条款，签字后对你是纯负担** |

**建议做法**：要求删除竞业条款，或至少限定"不得利用实习期间接触的具体商业秘密"，并约定补偿。谈不下来就评估风险再签。【经验】

## 四、签字前必须核实的公司信息

| 核实什么 | 怎么查 |
| --- | --- |
| 公司是否真实存在 | 国家企业信用信息公示系统（gsxt.gov.cn） |
| 是否被列入经营异常/严重违法 | 同上 |
| 是否有大量劳动争议诉讼 | 中国裁判文书网检索公司名 |
| 招聘信息与面试说的一致吗 | 对比岗位描述与实际安排 |
| 办公地点是否与注册地一致 | 异常要问清 |

**特别警惕**：以"实习"名义招人，实际是培训贷（要求你贷款买课程）、刷单、拉人头。这类见「兼职、实习的常见骗局」（04-03）。

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「实习协议和劳动合同差不多」 | 完全不同，实习不适用劳动法保护 |
| 「签了三方就有工作了」 | 三方只是预约，毕业后还要签劳动合同 |
| 「实习期受伤能算工伤」 | 一般不能，走人身损害赔偿 |
| 「实习补贴不能低于最低工资」 | 法律上无此强制要求（劳动关系才有） |
| 「协议上的违约金必须赔」 | 显失公平的条款可能不被支持，但别赌 |
| 「竞业条款实习生签了也没事」 | 通过《民法典》仍可能产生约束 |
| 「口头说好实习 3 个月就行」 | 学校学分认定往往需要书面证明 |

- [ ] 保留实习协议原件或清晰照片
- [ ] 保留排班/考勤/工作成果记录

- [ ] 索要**实习证明**（学校学分认定需要）
- [ ] 确认补贴已结清
- [ ] 确认没有未了结的保密/竞业义务争议
