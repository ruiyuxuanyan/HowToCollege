# 大学生兼职的法律身份：为什么不构成劳动关系

> 一句话概括：这条 1995 年的规定决定了你被欠薪时该找谁，但它不是一刀切——2025 年已有判决认定在校生构成劳动关系。

**适用人群**：正在做或准备做兼职的大学生；被欠薪后不知道去哪个部门的人；签了「兼职协议」但实际全职上班的人。

> **本文性质**
>
> 本文是法律信息整理，**不构成法律意见**。具体纠纷请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》（劳部发〔1995〕309 号）第十二条；《中华人民共和国民法典》合同编
> - 全国统一：309 号文是全国性规范性文件；个案认定由法院裁量
> - 核查日期：2026-11-05
> - 已知变化：**司法实践正在变化**，2025 年已有在校生被认定存在劳动关系的判例（见第四节）

## 一、那条关键规定

几乎所有「大学生兼职不受劳动法保护」的说法，都来自同一句话：

> 12. 在校生利用业余时间勤工助学，不视为就业，未建立劳动关系，可以不签订劳动合同。
>
> 【法规】《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》（劳部发〔1995〕309 号）第 12 条

这句话写于 1995 年 8 月，**至今仍然有效**。它的立法背景是当年的勤工助学制度——学校组织的、利用课余时间的、补助性质的劳动。

### 请注意这句话里的三个限定词

| 限定词 | 含义 | 如果你是这种情况…… |
| --- | --- | --- |
| **在校生** | 尚未毕业，学籍在校 | 已毕业 → 不适用 |
| **利用业余时间** | 课余、假期，不是全职 | 每天 8 小时、做五休二 → 可能不适用 |
| **勤工助学** | 补助性质，不是就业 | 以就业为目的应聘 → 可能不适用 |

**这三个限定词是本文最重要的部分。** 很多网上的说法把「在校生兼职一律不是劳动关系」当成铁律，这是对条文的误读。

## 二、如果确实不构成劳动关系，意味着什么

先讲通常情况。绝大多数「课余打零工」的情形，实践中确实被认定为**劳务关系**。

那么，「劳务关系」和「劳动关系」的差别在哪：

| 项目 | 劳动关系 | 劳务关系（你的情况） |
| --- | --- | --- |
| 适用法律 | 《劳动法》《劳动合同法》 | 《民法典》合同编 |
| 最低工资 | 适用 | **不直接适用**（但可参照） |
| 加班费 | 有法定标准 | 无强制标准，按约定 |
| 社保 | 用人单位必须缴 | 无此义务 |
| 工伤认定 | 可以申请 | **不可以**，走人身损害赔偿 |
| 经济补偿金 | 有（N/N+1/2N） | 无 |
| **被欠薪走哪** | **劳动仲裁** | **法院起诉** |
| 劳动监察管不管 | 管 | **通常不管** |

### 最关键的一行：被欠薪走哪

这是学生最容易搞错的地方。真实情况是：

- 你去**劳动监察**投诉，对方可能告诉你「不属于受理范围」
- 你去**劳动仲裁**，可能收到**不予受理通知书**

这不是推诿，是因为这两条路都只处理**劳动关系**争议。

现实案例：

> 在校大学生果某于 2021 年 7 月到北京某网络公司担任兼职讲师，按小时计收课时费。公司拖欠其 8 月、9 月工资共计 14095 元。果某申请劳动仲裁，**该仲裁委作出不予受理通知书**。果某不服诉至法院。法院经审理认为，果某为在校学生，根据其所做工作性质及报酬发放模式，双方应为**劳务关系，并非劳动关系**。
>
> 【经验】光明网《【光明云说法】在校大学生兼职能否确认劳动关系？》，2023-08-07

**这就是为什么「去劳动局投诉」这个建议在兼职场景下常常行不通。**

## 三、那靠什么保护自己

答案是 **《民法典》**，具体是合同编。

关键点：**口头合同也有效。**

《民法典》第四百六十九条规定，当事人订立合同，可以采用书面形式、口头形式或者其他形式。你接活时的微信聊天、谈好的价钱、做完的交付，都构成事实上的劳务合同关系。

所以举证的重点是**证明存在约定和已履行**：

| 要证明什么 | 用什么证明 |
| --- | --- |
| 存在用工关系 | 聊天记录、排班表、工牌照片、工作群 |
| 约定了报酬 | 微信谈价记录、口头约定的录音 |
| 你确实干了活 | 打卡记录、交付的成果、工作照片 |
| 对方没给钱 | 催讨记录 |

有这些，就可以走**法院起诉**。金额小的可以走小额诉讼程序。

详细的操作步骤见「兼职被拖欠工资怎么办」一文，本文不展开。

## 四、重要：这条规定不是一刀切

这一节是本文最需要更新的认知。

### 4.1 2025 年的一个新判决

> 2024 年 3 月，即将毕业的大学生徐某表明了其在校身份后，入职某物业服务公司任职咖啡师，双方签订**兼职协议**，约定兼职时间为 1 年、试用期 3 个月，工作时间为 8 小时制排班轮休、做五休二……
>
> 法院审理后认为，徐某入职时已满 22 周岁，具备与用工单位建立劳动关系的行为能力和责任能力，且**应聘时明确表达了就业意愿**。公司知晓徐某是尚未毕业的应届生，经过面试等招聘程序后选择聘用……工作期间对徐某进行考勤打卡、请假报批等管理，并支付劳动报酬，双方已形成**人身隶属和经济隶属关系**。因此，双方之间存在**事实劳动关系**。
>
> 【经验】平安浙江网《在校大学生签"兼职协议"，为何被认定存在劳动关系？》，2025-08-05

判决结果：公司需支付违法解除劳动关系赔偿金、超出法定试用期赔偿金等共计 12550 元。**二审维持原判。**

### 4.2 法官给出的判断标准

这个判决的说理部分，比结论更重要：

> 《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》第十二条规定："在校生利用业余时间勤工助学，不视为就业，未建立劳动关系，可以不签订劳动合同"。但**现行法律并未将在校学生完全排除在劳动法适用主体之外**，上述规定主要指向"业余时间""勤工助学"等情形，**不适用于本案在校学生以就业为目的提供劳动的情形**。
>
> 双方之间是否构成劳动关系，应以"**人身隶属关系 + 经济隶属关系**"作为认定标准。
>
> 若在校生接受、遵循用人单位的规章制度、人事管理、岗位安排，并接受用人单位支付的经济报酬，双方以建立长期稳定的劳动关系为目的，则实际上建立了劳动关系。若在校生以勤工俭学、课程实践为目的，不求取劳动报酬或者通过短期、不定期劳务获得一定勤工俭学性质的报酬，则不应认定双方建立了劳动关系。
>
> 【经验】同上

### 4.3 整理成判断表

| 特征 | 偏向劳务关系（勤工助学） | 偏向劳动关系（就业） |
| --- | --- | --- |
| 目的 | 补贴生活费、课程实践 | 以就业为目的，明确表达就业意愿 |
| 时间 | 课余、周末、假期 | 每天 8 小时、固定排班 |
| 管理 | 松散，只看结果 | 考勤打卡、请假报批、遵守规章制度 |
| 期限 | 短期、不定期 | 约定了较长期限（如 1 年） |
| 报酬 | 按次、按小时结算 | 按月发放固定工资 |
| 岗位 | 临时性、辅助性 | 公司正常业务岗位 |

**注意：这不是法律条文，是法院说理的归纳，只能作为参考，不能代替个案判断。**

### 4.4 对你的实际意义

- 如果你只是课余打零工 → 大概率是劳务关系，维权走法院
- 如果你签了「兼职协议」但实际是全职上班、打卡考勤、按月发工资 → **可能构成劳动关系**，可以先尝试劳动仲裁
- 如果仲裁不受理 → 不代表你就没戏，可以继续向法院起诉主张劳动关系

**关键动作：保留考勤记录、排班表、工资发放记录。** 这些是判断「人身隶属和经济隶属」的核心证据。

## 五、实习又是另一回事

「实习」和「兼职」在法律上不是同一个概念，但处理逻辑相似——**取决于实质而非名称**。

| 情形 | 常见认定 |
| --- | --- |
| 学校统一组织的教学实习 | 通常不构成劳动关系 |
| 学生自行找的暑期实习 | 通常为劳务关系 |
| 毕业前的「实习」实际是全职工作 | **可能构成劳动关系**（同第四节） |
| 毕业后入职（试用期） | 构成劳动关系 |

判断标准和第四节的表一样：看**是否有管理与被管理关系、是否按月付酬、是否以就业为目的**。

## 六、五种责任关系的区分（别搞混）

| 关系 | 典型场景 | 受伤了怎么办 | 欠薪找谁 |
| --- | --- | --- | --- |
| **劳动关系** | 毕业后正式工作 | 工伤认定 | 劳动仲裁 |
| **劳务关系** | 课余兼职、短期零工 | 人身损害赔偿 | 法院起诉 |
| **实习关系** | 学校组织/自行实习 | 视实质而定 | 视实质而定 |
| **勤工助学** | 校内岗位 | 学校规定 + 人身损害赔偿 | 校内渠道 |
| **承揽关系** | 接单做设计、写代码 | 自己负责 | 法院起诉 |

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「大学生打工不受法律保护」 | 错。《民法典》保护你，只是路径不同 |
| 「没签合同就没法维权」 | 错。口头合同有效，聊天记录就能证明 |
| 「去劳动局投诉就行了」 | 劳务关系争议，劳动监察和仲裁**可能都不受理** |
| 「在校生一律不是劳动关系」 | 错。2025 年已有判决认定构成劳动关系 |
| 「签了『兼职协议』就一定是劳务关系」 | 错。看实质，不看名称 |
| 「实习算工伤」 | 通常不算，走人身损害赔偿 |

## 八、可执行清单

### 接活前

- [ ] 问清是「兼职」还是「实习」，有没有书面协议
- [ ] 确认报酬标准、结算周期、发放时间
- [ ] 保留对方身份信息（公司名、联系人、联系方式）
- [ ] 判断一下：是全职上班打卡，还是课余打零工？（影响维权路径）

### 干活期间

- [ ] 每天留一点记录：排班表、打卡截图、工作成果
- [ ] 保存所有聊天记录（**不要清空**）
- [ ] 如果对方按月发工资、要求打卡 → 保留这些证据，将来可能主张劳动关系

### 被欠薪后

- [ ] 先把证据整理成时间线
- [ ] 判断关系性质，选择路径（仲裁 or 起诉）
- [ ] 仲裁不予受理的，保留《不予受理通知书》——**这是起诉时的重要材料**

## 九、一句话记住

**「大学生兼职不是劳动关系」这句话只对了一半。**

对的那一半：课余打零工，你走不了劳动仲裁，要去法院起诉。
错的那一半：如果你实际是全职上班、接受管理、按月领薪，法院可能认定你就是劳动者。
