# 兼职被拖欠工资怎么办

> 一句话概括：不能走劳动仲裁，那就走对的那条路——从留证到起诉的完整路径。

**适用人群**：兼职、实习、打零工被欠薪的大学生。

> **政策适用范围**
> - 主要依据：《民法典》合同编；《民事诉讼法》小额诉讼程序；最高人民检察院关于支持起诉的规定
> - 全国统一：诉讼时效、小额诉讼制度全国统一
> - 地方执行：小额诉讼的标的额上限各省不同
> - 核查日期：2026-11-05

> **前提**：本文假定你与对方是**劳务关系**（在校生课余兼职的常见情形）。如果你实际是全职上班、打卡考勤、按月领薪，可能构成劳动关系，此时应先尝试劳动仲裁。详见「大学生兼职的法律身份」一文。

---

## 一、第一步不是投诉，是留证

**很多人吃亏在证据不全。**

### 1.1 要证明的四件事

| 要证明什么 | 用什么证明 |
| --- | --- |
| **存在用工关系** | 聊天记录、排班表、工作群、工牌照片 |
| **约定了报酬** | 微信谈价记录、语音（可录音）、书面协议 |
| **你确实干了活** | 打卡截图、交付的成果、工作照片 |
| **对方没给钱** | 催讨记录、对方的承诺与推脱 |

### 1.2 证据怎么保存

- **截图要带时间**（微信聊天记录截图会显示时间）
- **不要清空聊天记录**
- 重要的语音消息转成文字或录屏
- 工作成果（文件、照片）备份到自己的设备

---

## 二、先协商（成本最低）

### 2.1 怎么谈

| 做法 | 说明 |
| --- | --- |
| 书面沟通 | 用微信/短信，**不要只打电话**（电话难留证） |
| 明确金额与期限 | 「X 月 X 日到 X 月 X 日的工资共 X 元，请于 X 日前支付」 |
| 保留对方承认的表述 | 对方说「过几天给」也是证据 |
| 不要撕破脸 | 保留协商余地，但记录要留 |

### 2.2 协商期限

给对方一个明确期限（如 7 天），到期不付就走下一步。

---

## 三、路径一：投诉（注意可能不受理）

| 部门 | 管什么 | 你这种情况 |
| --- | --- | --- |
| 劳动监察 | 劳动关系争议 | **通常不受理**（劳务关系不在范围） |
| 12315 | 消费纠纷 | 一般不适用 |
| 12345 | 综合政务 | 可反映，但会转办 |

**为什么会不受理**：劳动监察和劳动仲裁处理的是**劳动关系**争议。在校生课余兼职属于劳务关系。

**但可以试一次**：如果金额较大或对方是公司，投诉有时能促成协商解决。即使不受理，也保留书面答复。

---

## 四、路径二：法院起诉（主要路径）

### 4.1 起诉需要什么

| 材料 | 说明 |
| --- | --- |
| 起诉状 | 写明事实、金额、请求 |
| 证据 | 第一部分整理的那些 |
| 双方身份信息 | 你的身份证；对方的姓名/公司名、地址、联系方式 |
| 诉讼费 | 小额诉讼费用较低 |

### 4.2 怎么起诉

| 方式 | 说明 |
| --- | --- |
| **网上立案** | 人民法院在线服务（微信小程序/网页），可在线提交 |
| 现场立案 | 到被告住所地或合同履行地法院 |

**管辖法院**：一般到**被告住所地**或**合同履行地**（你干活的地方）法院。

### 4.3 小额诉讼程序

**适合小额纠纷。**

| 特点 | 说明 |
| --- | --- |
| 一审终审 | 判决后不能上诉（对你是好事，快） |
| 审理快 | 通常一两个月内 |
| 诉讼费低 | 按标的额比例，金额小则很低 |
| 标的额上限 | **各省不同**，需查当地规定 |

### 4.4 诉讼时效

《民法典》第一百八十八条：

> 向人民法院请求保护民事权利的诉讼时效期间为**三年**。

**从你知道或应当知道权利受损时起算**，通常是约定的付款日之后。

**别拖。** 三年看着长，但证据会随时间消失。

---

## 五、路径三：检察支持起诉

检察机关可以对弱势群体提起的民事诉讼**支持起诉**。

| 项目 | 说明 |
| --- | --- |
| 适用对象 | 农民工、未成年人、残疾人等弱势群体（学生是否适用各地不同） |
| 怎么申请 | 向当地检察院民事检察部门咨询 |
| 效果 | 检察院可协助调查取证、出具支持起诉意见书 |

**实践中已有学生兼职欠薪获支持起诉的案例。** 但**各地检察机关的适用条件不同**，需要具体咨询。

---

## 六、时间轴：什么时候做什么

| 时间 | 动作 |
| --- | --- |
| **当天** | 整理证据，截图保存全部聊天记录 |
| **1–3 天** | 书面催讨，给定明确期限 |
| **7 天后** | 仍不付 → 考虑投诉（可选） |
| **2 周内** | 准备起诉材料，网上立案 |
| **立案后** | 等待开庭，准备陈述 |

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「去劳动局投诉就行」 | 劳务关系，劳动监察通常不受理 |
| 「没签合同就没法维权」 | 口头合同有效，聊天记录能证明 |
| 「金额太小，法院不会管」 | 小额诉讼就是为小额纠纷设计的 |
| 「拖一拖没关系」 | 诉讼时效三年，且证据会消失 |
| 「网上找『追款』能要回来」 | 大概率是二次诈骗 |

## 八、可执行清单

### 被欠薪当天

- [ ] 截图保存全部聊天记录（带时间）
- [ ] 整理工作证据（打卡、成果、工作照）
- [ ] 记录对方身份信息（公司名、联系人、电话）

### 一周内

- [ ] 发一条明确的催讨消息，写明金额与期限
- [ ] 对方回复也要保存

### 两周内

- [ ] 如仍不付，准备起诉
- [ ] 写起诉状（网上有模板，写清事实与请求）
- [ ] 通过「人民法院在线服务」提交立案

### 注意事项

- [ ] 不要删除任何记录
- [ ] 不要相信「网上追款」
- [ ] 金额大的话，考虑咨询律师

---

## 九、一句话记住

**留证 → 催讨 → 起诉。不要去找劳动仲裁，那扇门对劳务关系是关着的。**
