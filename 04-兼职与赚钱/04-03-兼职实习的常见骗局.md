# 兼职、实习的常见骗局

> 一句话概括：所有要你先交钱的兼职，都是骗局。

**适用人群**：正在找兼职、准备实习的大学生。

> **核查日期**：2026-11-07
> ⏳ 易过时：具体话术会更新，本文讲结构。

---

## 一、判断标准只有一条

**先交钱 = 骗局。**

不管名义是什么——押金、服装费、体检费、培训费、保证金、材料费、工牌费——只要在工作之前要你掏钱，就是骗局。

**正规工作的特征**：不收费、不押证件、按约定付你钱。

---

## 二、六类高发骗局

### 2.1 押金 / 服装费 / 体检费

**话术**：「先交 300 押金，离职退还。」「工作服 200，统一的。」

**问题**：交了就不退了。或者说「你没做满 X 个月，押金不退」——这本身就是违法的（用人单位不得收取押金）。

**识别**：任何入职前收费。

### 2.2 培训贷（最危险）

这是后果最严重的一类。

**完整剧本**：

| 步骤 | 对方做什么 |
| --- | --- |
| 1 | 招聘网站发布「高薪岗位」，面试很容易通过 |
| 2 | 告诉你「技能不达标，需要先培训」 |
| 3 | 培训费「可以分期」，让你签一份分期合同 |
| 4 | **那份合同其实是贷款合同** |
| 5 | 培训结束后，工作没了 |
| 6 | 你背上几千到几万的贷款 |

**识别关键点**：**任何要求你在入职前签「分期」「贷款」「金融服务」合同的，立刻停止。**

**已经签了怎么办**：
- 立即保留全部合同和聊天记录
- 报警（涉嫌诈骗）
- 向 12315、金融监管部门投诉
- 主张合同无效或撤销（需律师协助）

### 2.3 刷单返利

**话术**：「帮店铺刷单，一单返 5–20 元，日结。」

**真相**：
- 前几单真的返钱（建立信任）
- 然后要求你**垫付大额**，「完成后一起返」
- 垫付后就联系不上了
- **刷单本身也是违法的**

**识别**：任何要求你「先垫付、后返还」的。

### 2.4 打字员 / 录入员

**话术**：「在家打字，千字 30 元，时间自由。」

**真相**：这类岗位在互联网时代已基本不存在（OCR 技术比人便宜）。多数是骗取「会员费」「资料费」。

**判断**：如果对方主要收入来自收你的费，而不是给你的活，就是骗局。

### 2.5 假中介收费

**话术**：「交 200 元介绍费，包你找到工作。」

**问题**：收费后给你几个联系方式，然后不了了之。

**识别**：正规人力资源服务机构收费需明示且受监管；「包找工作」的承诺基本不可信。

### 2.6 「高薪」境外招聘

**话术**：「东南亚某国，月薪 2 万，包吃住，无需经验。」

**真相**：可能是电信诈骗园区。**这是人身安全问题，不只是钱的问题。**

**识别**：境外 + 高薪 + 无门槛 + 催你尽快出境 = 极高风险。

详见「兼职与求职中的人身安全」一文。

## 三、正规兼职的特征

| 特征 | 说明 |
| --- | --- |
| 不收费 | 任何环节都不向你要钱 |
| 不押证件 | 身份证原件不出借、不抵押 |
| 有明确的用工主体 | 能查到公司信息 |
| 按约定结算 | 有明确的报酬标准和支付时间 |
| 不承诺「轻松高薪」 | 正常工作的报酬是合理的 |

---

## 四、找兼职时该问的问题

面试或沟通时，主动问这几个：

- [ ] 需要交任何费用吗？（押金、服装、培训、体检）
- [ ] 报酬怎么算、什么时候发？
- [ ] 需要签什么文件？（特别留意「分期」「贷款」「金融服务」字样）
- [ ] 工作地点在哪？
- [ ] 公司叫什么？（回去查工商信息）

**对方的反应也是信息**：闪烁其词、催你快点决定、说「别人都交了」——都是危险信号。

---

## 五、已经上当了怎么办

| 情况 | 动作 |
| --- | --- |
| 交了押金/费用 | 保留凭证，要求退还；不给就报警或 12315 |
| 签了培训贷 | 保留合同，报警，向金融监管部门投诉 |
| 被要求垫付刷单 | 立即停止，保留记录，报警 |
| 被骗到境外 | 立即联系家人、报警、联系使领馆 |

**共同的第一步：保留所有证据（聊天记录、转账凭证、合同）。**

---

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「同学介绍的不会坑我」 | 同学可能也是被骗的，甚至是被利用来拉人 |
| 「就交几百块，试试」 | 交钱就是进入骗局的第一步 |
| 「签个分期没什么」 | 那可能就是几万元的贷款 |
| 「刷单只是灰色地带」 | 刷单本身违法 |
| 「高薪为什么不试试」 | 无门槛的高薪，代价通常在别处 |

---

## 七、可执行清单

### 找兼职前

- [ ] 记住：**不交任何费用**
- [ ] 不押身份证原件
- [ ] 查一下公司名（国家企业信用信息公示系统）

### 沟通时

- [ ] 问清报酬与支付方式
- [ ] 看清要签的每份文件
- [ ] 拒绝任何「分期」「贷款」类合同

### 工作期间

- [ ] 保留聊天记录、排班、工作成果
- [ ] 记录工作时间

### 被骗后

- [ ] 保留全部证据
- [ ] 报警（110）
- [ ] 消费类投诉 12315

---

## 八、一句话记住

**要你先交钱的，都是骗局；让你签分期的，最危险。**
