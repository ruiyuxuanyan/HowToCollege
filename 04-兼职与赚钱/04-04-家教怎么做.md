# 家教怎么做：怎么找、怎么定价、怎么保护自己

> 一句话概括：把自己当成一门生意来经营，同时把安全放在收款之前。

**适用人群**：第一次做家教、正在带学生但没签过协议、或者遇到过家长拖欠课时费的大学生。特别是要去陌生小区、家长家里上课的女生。

> **核查日期**：2026-11-07

---

## 一、渠道选择：哪些能找到活，哪些别碰

家教信息不外乎三个来源：学校官方、熟人介绍、平台和群里。三类的风险差别很大。

| 渠道 | 典型形式 | 靠谱程度 | 主要风险 |
| --- | --- | --- | --- |
| 校内勤工助学中心 | 学校登记的家教岗位 | 高 | 岗位少，需要排队 |
| 学校家教社团/家教部 | 学生组织的中介 | 中高 | 抽取管理费，需看清比例 |
| 老师、学长学姐介绍 | 熟人带单 | 中高 | 出问题难以维权，靠人情 |
| 小区公告栏、家长微信群 | 家长直招 | 中 | 无法核实身份 |
| 家教中介公司 | 收押金/信息费 | 低 | **大量骗局集中在这一类** |

**一个基本判断**：任何要你先交钱（信息费、押金、培训费、"建档费"）的中介，默认都是骗局。正规中介从课时费里抽成，不需要你先付钱。【经验】

### 找活的正确顺序

1. 先问学校勤工助学中心有没有家教岗位（见「校内勤工助学」一文）
2. 问本院系辅导员、学生会学长学姐有没有在带课、能不能介绍
3. 上面都没有，再考虑本地家长群、社区公告栏
4. 中介最后考虑，且必须先确认不收费

## 二、人身安全：这一节比赚钱重要

家教是大学生兼职里**唯一需要单独去陌生人家中、单独与成年人相处数小时**的工作。这一节没有例外条款。

### 2.1 首次见面：必须选公共场所

| 做法 | 说明 |
| --- | --- |
| 首次见面约在咖啡店、快餐店、图书馆、小区门口 | 不要直接上门 |
| 不要去偏僻的地方、不要在夜间首次见面 | — |
| 不要去酒店、出租屋、KTV 等场所 | 无论对方用什么理由 |
| 试讲也尽量安排在公共空间或家长在场的客厅 | — |

**如果对方拒绝在公共场合首次见面，这一单直接放弃。** 正常的家长不会介意。【经验】

### 2.2 告知行程：让别人知道你在哪

出门前做三件事：

- 告诉至少一个室友或朋友：去哪个小区、几号楼、大概几点回
- 把家长的联系方式和位置共享给这个人
- 约定一个「到点没回就打电话」的时间

上课期间手机保持开机，静音但能震动。

### 2.3 上课地点的红线

| 情形 | 处理 |
| --- | --- |
| 家中只有你和成年男性家长 | 要求客厅上课，房门打开；做不到就换时间或放弃 |
| 家长要求"单独辅导""关上门更专心" | 拒绝 |
| 家长频繁请你吃饭、送礼物、提出私下见面 | 明确划界，必要时终止 |
| 上课地点是出租屋、酒店房间 | 不去 |

### 2.4 遇到越界怎么办

1. **当场离开**，不需要解释，不需要"给面子"
2. 保留聊天记录，不要删除
3. 告知朋友/室友，必要时告知辅导员
4. 涉及猥亵、性骚扰的，报警（110），不要先跟对方"协商"

学校一般设有学生求助渠道（辅导员、心理咨询中心、保卫处）。这类事件的处置学校有经验，不要自己扛。【经验】

## 三、定价：怎么算出一个不吃亏的价格

### 3.1 先算你的成本

很多人的定价错误在于**只算了课上的时间**。

```
真实时薪 = 本次收入 ÷ (上课时间 + 备课时间 + 通勤时间)
```

举例（数字仅为算法示意，不是市场价）：

- 一次课 2 小时，收费 200 元
- 备课 40 分钟，往返通勤 60 分钟
- 真实时薪 = 200 ÷ (2 + 0.67 + 1) ≈ 5.4 小时 → 约 37 元/小时

如果这个数字低于你所在城市的最低小时工资水平，这单基本不值得做。最低工资标准各地不同，查当地人社部门公布的标准。【待核实：各地最低工资标准，请查所在市人社局公告】

### 3.2 影响价格的因素

| 因素 | 影响方向 |
| --- | --- |
| 年级（小学/初中/高中） | 越高越贵 |
| 科目（数学物理 vs 副科） | 主科更贵 |
| 是否毕业班 | 毕业班溢价明显 |
| 距离（通勤时间） | 超过 40 分钟要加价或放弃 |
| 是否一对一 vs 小班 | 一对一单价高，小班总收入高 |
| 你是否有竞赛/名校背景 | 有溢价 |
| 是否需要你出教案、出题 | 加价 |

### 3.3 三条定价原则

1. **不要低于当地最低小时工资**，否则不如去做别的
2. **一次课不要低于 1.5 小时**，否则通勤占比过高
3. **报价时说清"含备课"或"不含备课"**，避免后期扯皮

## 四、防被白嫖：把口头约定变成书面

家教最常见的纠纷不是被骗钱，是**干了活拿不到钱**、**被要求无限加课**。

### 4.1 第一次沟通就要锁定的事

用微信文字确认，不要只打电话：

- 上课时间（每周几次、每次多长、具体时段）
- 课时费标准、按次结还是按月结
- 结算时间（比如"每次课后当场转账"或"每月 5 日前结上月"）
- 上课地点
- 谁负责教材/资料
- 请假规则（提前多久说、临时取消算不算课时）

### 4.2 结算方式：按次结最安全

| 方式 | 风险 |
| --- | --- |
| 每次课后当场结 | **最低**，推荐 |
| 每周结一次 | 低 |
| 每月结一次 | 中，需先建立信任 |
| 学期末一次结 | **高**，不推荐 |

如果家长坚持月结，第一次合作可以接受，但不要超过"一个月"的账期。

### 4.3 试讲和免费课

- 可以免费试讲一次（30 分钟到 1 小时），但**只一次**
- 试讲后对方不回复，就是没成，不要追
- 不要接受"先免费带两周看看效果"

### 4.4 被拖欠怎么办

1. 微信礼貌催一次，留下记录
2. 明确告知"未结清前暂停上课"
3. 金额较大的，整理证据（聊天记录、排班、上课记录）后走法院起诉
4. 家教属于劳务关系，**劳动监察和劳动仲裁通常不受理**，详见「大学生兼职的法律身份」一文

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「家长人很好，不用谈钱的事」 | 谈钱是专业，不是不信任 |
| 「第一次上门去家里更显得有诚意」 | 首次必须在公共场所 |
| 「中介收点信息费正常」 | 正规中介从课时费抽成，不收前置费用 |
| 「课时费按市场价就行」 | 要按你的真实时薪算，含通勤 |
| 「口头说好就行」 | 微信文字确认同样是证据，但必须先有 |
| 「家长让我单独进房间辅导」 | 拒绝，客厅上课、门敞开 |
| 「被骚扰了先跟家长沟通」 | 先离开现场，再报警/告知学校 |

## 可执行清单

### 接单前

- [ ] 确认渠道来源，排除任何"先交钱"的中介
- [ ] 用真实时薪公式算一遍，判断值不值得
- [ ] 微信确认课时费、时间、结算方式、地点
- [ ] 把位置和家长联系方式发给一位朋友

### 首次见面

- [ ] 约在公共场所
- [ ] 白天、交通方便的地方
- [ ] 不去酒店、出租屋
- [ ] 试讲只免费一次

### 每次上课

- [ ] 上课地点在客厅或公共区域，门不关
- [ ] 手机开机
- [ ] 课后当场确认课时、当场收款（或按约定周期）
- [ ] 保留聊天记录

### 出现异常

- [ ] 越界言行 → 立即离开
- [ ] 拖欠 → 催一次后暂停上课
- [ ] 骚扰/威胁 → 报警，同时告知辅导员

---

## 一句话记住

**家教赚钱的前提是安全回家；定价的前提是算上通勤和备课。**
