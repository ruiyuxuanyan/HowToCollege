# 06 人际与情感 · 逐篇写作大纲

> 分类定位：欺凌、性骚扰、师生边界、网暴、恋爱中的钱。
> 适用人群：全体在校生。
> 核查日期：2026-11-04。

## 分类级判断

这个分类**最容易写错**，因为它是「情感」主题，但本项目的定位是**规则与路径**，不是心灵抚慰。

取舍原则：

| 写 | 不写 |
| --- | --- |
| 欺凌的法律定性与取证方法 | 「怎么和室友搞好关系」 |
| 性骚扰的举报渠道与证据保留 | 「如何走出情感创伤」 |
| 恋爱期间转账的法律定性 | 「怎么谈恋爱」 |
| 网暴的证据固定与投诉路径 | 「如何优雅地回怼」 |

**核心原则：情感类话题只写「出问题时怎么办」，不写「怎么经营」。**

原因：前者有客观答案（找谁、怎么取证、走什么程序），后者没有，写了就是鸡汤。

本分类的高危篇目：**06-01 欺凌、06-02 性骚扰、06-09 网暴**。这三篇涉及人身安全与法律，必须写实。

## 06-01 室友矛盾升级到欺凌：什么算、怎么取证、找谁

**一句话定位**：忍让换不来和平，证据和渠道才能。

**核心结论**
1. 欺凌的本质是**力量不对等下的重复伤害**，不是「闹矛盾」
2. **取证是第一步**（记录、截图、证人），没有证据的举报往往无果
3. 渠道有三级：**辅导员 → 学院 → 学校学生工作部门**，逐级走并留痕

**结构骨架**
1. 一句话定位
2. **怎么区分「矛盾」和「欺凌」**（本篇核心，给判断标准）
   - 力量不对等（人数、体型、话语权、经济）
   - 重复性（不是一次冲突）
   - 故意的伤害意图
   - 对方无法有效反抗
3. 欺凌的常见形式（表格：形式 / 例子 / 是否为欺凌）
   - 言语（嘲笑、起侮辱性外号、散布谣言）
   - 关系（孤立、排挤、拉帮结派）
   - 财物（故意损坏、藏东西）
   - 网络（群里嘲笑、P 图传播）
   - 肢体
4. **取证方法**（本篇最实用）
   - 保留聊天记录、截图带时间
   - 记录每次事件（时间、地点、在场人、说了什么）
   - 找愿意作证的同学
   - 身体伤害及时就医并留存病历
   - 录音的合法性边界
5. 举报路径（三级渠道 + 每一步要留什么）
6. 如果学校处理不力怎么办（向上级教育部门反映、12345）
7. 什么情况该报警（涉及殴打、侮辱、传播隐私）
8. 心理支持（校心理咨询中心 → 07-03）
9. 常见误区
   - 「忍忍就毕业了」
   - 「告老师会被报复」（可要求保密与保护）
10. 风险提醒
11. 可执行清单（取证清单 + 举报话术）
12. 参考资料 + 核查日期

**必须查证的资料**
- 《未成年人学校保护规定》（不适用大学生，但可参考框架）
- 教育部关于校园欺凌治理的文件（**注意：主要针对中小学，高校适用性需说明**）
- 《治安管理处罚法》关于殴打、侮辱、威胁的条款
- 《民法典》人格权编

**已确认与待核实**
- ⚠️ **校园欺凌的专门规定主要针对中小学**，高校通常按学生管理规定与治安法规处理，这个差异必须写清
- ✅ 治安处罚与民事责任的路径是明确的

## 06-02 遇到性骚扰怎么办

**一句话定位**：第一件事是保留证据，第二件事是找到会受理你的人。

2. 渠道不止一个：**学校、公安、妇联、12338**，可并行
3. 学校有**法定的防治义务**（《妇女权益保障法》相关条款），不作为可向上级反映

**结构骨架**

5. **举报渠道**（表格：渠道 / 适用情形 / 特点）
   - 学校（学工部、纪检、师德监督）

## 06-04 恋爱期间的大额转账与礼物：分手后能不能要回

**一句话定位**：给钱时的性质，决定了分手后能不能要回来。

**核心结论**
1. 三种性质，后果完全不同：**赠与**（要不回）、**借贷**（能要回）、**彩礼**（有条件返还）
2. 判断标准看**当时的约定与场景**（备注、聊天记录、金额、特殊日期）
3. 「520」「1314」这类特殊金额+特殊日期，通常认定为**赠与**

**结构骨架**
1. 一句话定位
2. 三种法律性质（本篇核心表格）
   - 一般赠与（日常消费、节日红包、礼物）→ 不可撤销
   - 附条件赠与（以结婚为目的）→ 条件不成立可要求返还
   - 借贷 → 有约定可要求返还
3. **法官怎么判断**（给判断要素清单）
   - 金额大小（是否超出日常消费）
   - 支付场景（节日、生日、纪念日 vs 普通日子）
   - 备注内容（「借」「还」vs「爱你」）
   - 双方经济能力
   - 是否有借条/聊天记录
4. 彩礼的返还规则（《民法典》婚姻家庭编司法解释的三种情形）
5. 怎么保护自己（转账备注、大额留借条）
6. 已经发生纠纷怎么办（协商 → 起诉）
7. 常见误区
   - 「送给我的就是我的」（大额可能被认定附条件）
   - 「有聊天记录就能要回」（要看内容）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《民法典》第六百五十七条（赠与合同）、第六百六十三条（法定撤销）
- 最高人民法院关于适用《民法典》婚姻家庭编的解释（一）第五条（彩礼返还）

**已确认与待核实**
- ✅ 彩礼返还的三种情形有明确司法解释
- ⚠️ 个案判断依赖具体证据，文中必须声明「仅作一般性说明，不构成法律意见」

## 06-09 网络暴力与隐私泄露：被挂人、被造谣怎么办

**一句话定位**：网暴的处理有明确顺序，做错顺序会让伤害放大。

**核心结论**
1. 第一动作是**取证**（截图带时间、保存链接、录屏），不是回骂
2. 平台投诉能快速下架，**法律途径能追责**，两者配合使用
3. 造谣、侮辱、传播隐私可能构成**治安违法甚至刑事犯罪**

**结构骨架**
1. 一句话定位
2. 常见形式（挂人、造谣、P 图、人肉搜索、群嘲）
3. **取证清单**（本篇核心）
   - 截图要带时间、URL、账号信息
   - 录屏保留完整上下文
   - 保存原始链接
   - 记录传播量（转发、阅读、评论数）——影响定性与赔偿
4. 平台投诉（各平台入口、投诉话术、加速处理的方法）
5. 法律途径（分档）
   - 民事：名誉权、隐私权（《民法典》人格权编）
   - 治安：《治安管理处罚法》第四十二条
   - 刑事：侮辱罪、诽谤罪（**多为自诉案件，需注意举证**）
6. 人肉搜索的特殊风险（可能涉及侵犯公民个人信息罪）
7. 心理防护（暂时关闭评论、告知身边人、求助 → 07-03）
8. 常见误区
   - 「回骂回去就扯平了」（可能让自己也违法）
   - 「删了就没事了」（要先取证）
9. 风险提醒
10. 可执行清单（时间轴：1 小时内 / 24 小时内 / 一周内）
11. 参考资料 + 核查日期

## 06-10 校园表白墙、群聊与匿名社区的风险

**一句话定位**：匿名不等于无责，你发的每一条都可能被截图。

**核心结论**
1. 匿名平台**不保护你**——平台有后台数据，司法调取可得
2. 在公开群或墙上发布他人信息，可能构成**侵犯隐私/名誉**
3. 表白的「浪漫」和骚扰的「边界」在于**对方是否愿意**

**结构骨架**
1. 一句话定位
2. 常见风险场景（表白墙挂人、群内人身攻击、匿名爆料）
3. 法律边界（隐私权、名誉权、个人信息保护）
4. 「表白」什么时候变成骚扰（判断标准：对方明确拒绝后仍持续）
5. 自己发过不当内容怎么办（删除、道歉、防止扩散）
6. 被别人挂了怎么办 → 06-09
