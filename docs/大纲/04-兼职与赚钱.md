# 04 兼职与赚钱 · 逐篇写作大纲

> 分类定位：兼职的法律身份、被欠薪怎么维权、实习协议怎么签。
> 适用人群：想兼职、正在兼职、准备实习的学生。
> 核查日期：2026-11-04。

## 分类级判断

这个分类有一个**贯穿全类的核心事实**，所有篇目都建立在它之上：

> **在校生利用业余时间勤工助学，不视为就业，未建立劳动关系。**
> 【法规】《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》（劳部发〔1995〕309 号）第十二条

这一条决定了本分类的**全部维权路径**：

| 因为是劳务关系而非劳动关系 | 后果 |
| --- | --- |
| 不适用《劳动合同法》 | 没有经济补偿金、没有双倍工资、没有工伤认定 |
| 劳动仲裁通常不予受理 | 不能走劳动仲裁这条快车道 |
| 劳动监察通常不管 | 投诉到劳动监察，可能被告知不属于受理范围 |
| 适用《民法典》合同编 | 要走**民事诉讼**，或申请检察机关支持起诉 |
| 可以主张劳务报酬 | 有微信记录、工作照片就能证明口头劳务合同 |

**这就是为什么这个分类必须先写 04-01。** 如果读者不知道这一点，后面所有维权建议都会指向错误的部门。

## 04-01 大学生兼职的法律身份：为什么不构成劳动关系

**一句话定位**：搞不清这一点，你维权的方向从一开始就是错的。

**核心结论**
1. 【法规】劳部发〔1995〕309 号第十二条：在校生利用业余时间勤工助学，不视为就业，未建立劳动关系
2. 不构成劳动关系 ≠ 没有法律保护——**《民法典》仍然保护你**，可主张劳务报酬
3. 因此维权路径是：**民事诉讼 / 检察支持起诉**，不是劳动仲裁

**结构骨架**
1. 一句话定位 + 适用人群
2. 法条原文（必须原文引用，附文号）
3. 为什么会有这条规定（历史背景：勤工助学的定位是助学，不是就业）
4. **这条规定的实际后果**（本篇核心表格）
   - 没有劳动合同
   - 不适用最低工资标准（但可参考）
   - 没有工伤认定（受伤走人身损害赔偿）
   - 劳动仲裁不受理
   - 劳动监察不受理
5. 那靠什么保护自己？→ 《民法典》合同编（口头合同也有效）
6. 例外情形（**重要**）：毕业后、或以就业为目的的实习、或实际上完全符合劳动关系特征的情形，可能被认定为劳动关系（需谨慎表述，说明以司法实践为准）
7. 常见误区
   - 「没合同就没法维权」（错，口头劳务合同有效）
   - 「去劳动局投诉就行」（可能不受理）
   - 「大学生打工不受法律保护」（错）
8. 风险提醒
9. 可执行清单（接活前要做的事）
10. 参考资料 + 核查日期

**必须查证的资料**
- 劳部发〔1995〕309 号原文（第十二条）
- 《民法典》合同编关于合同订立与违约责任的规定
- 检察机关支持起诉的实践（如最高检发布的案例）

**已确认与待核实**
- ✅ 309 号文第十二条现行有效
- ⚠️ 「实习是否构成劳动关系」的司法认定存在个案差异，需谨慎表述

**与其他篇的交叉**

- 实习协议 → 04-05

## 04-02 兼职被拖欠工资怎么办

**一句话定位**：不能走劳动仲裁，那就走对的那条路——从留证到起诉的完整路径。

**核心结论**
1. 第一步不是投诉，是**固定证据**（微信记录、工作照片、考勤、转账记录）
2. 劳动监察和劳动仲裁**可能都不受理**，正确路径是**法院起诉**（小额诉讼）
3. 金额不大也能走：**小额诉讼程序**成本低、周期短；还可申请检察机关支持起诉

**结构骨架**
1. 一句话定位
2. 先判断：你属于哪种关系（劳动关系 / 劳务关系）→ 决定走哪条路
3. **证据清单**（本篇核心，最实用部分）
   - 证明存在用工关系：聊天记录、排班表、工作照片、工牌
   - 证明约定报酬：口头约定的录音、微信谈价记录
   - 证明已提供劳动：打卡记录、交付成果
   - 证明未支付：催讨记录
4. 路径一：协商（先礼后兵，保留记录）
5. 路径二：投诉（找对部门：市场监管 12315 / 劳动监察，说明可能不受理）
6. 路径三：**法院起诉**（分步讲）
   - 起诉需要什么材料
   - 诉讼费（小额诉讼费用低）
   - 网上立案（人民法院在线服务）
   - 小额诉讼程序的特点
7. 路径四：检察支持起诉（适用于农民工、学生等弱势群体，需核实适用条件）
8. 时效（诉讼时效期间，需引用《民法典》条款）
9. 常见误区
10. 可执行清单（时间轴：当天做什么、一周内做什么、一个月内做什么）
11. 参考资料 + 核查日期

**必须查证的资料**
- 《民事诉讼法》关于小额诉讼程序的规定
- 《民法典》诉讼时效条款（第一百八十八条，三年）
- 检察机关支持起诉的法律依据与实践
- 人民法院在线服务平台的立案流程

**已确认与待核实**
- ✅ 诉讼时效一般为三年（《民法典》）
- ⚠️ 小额诉讼适用金额上限由各省规定，需注明
- ⚠️ 支持起诉的具体条件各地检察机关不同

**与其他篇的交叉**
- 04-01 法律身份（前提）
- 08-12 报警流程（不同路径，注意区分）

## 04-03 兼职、实习的常见骗局

**一句话定位**：所有要你先交钱的兼职，都是骗局。

**核心结论**
1. **先交钱（押金、培训费、服装费、保证金）的一律是骗局**
2. 「培训贷」是最危险的变种：以招聘为名让你签贷款合同，背上几万元债务
3. 「刷单」本身违法，参与刷单可能构成违法甚至犯罪

**结构骨架**
1. 一句话定位
2. 六类高发骗局，逐个拆（表格 + 每个的识别点）
   - 押金/服装费/体检费
   - **培训贷**（重点，最危险）
   - 刷单返利
   - 打字员/录入员（几乎全假）
   - 假中介收费
   - 「高薪」境外招聘（涉及人身安全 → 09-08）
3. **培训贷的完整剧本**（单列一节）
   - 话术：先承诺高薪岗位 → 说要先培训 → 培训费可「分期」→ 实际是贷款
   - 后果：背上贷款，工作没有
   - 怎么识别：任何要求你签贷款/分期合同的「入职」，立刻停止
4. 正规兼职的特征（列表：不收费、不押证件、按约定结算）
5. 已经签了培训贷怎么办（保留证据、报警、向监管部门投诉、主张合同撤销）
6. 常见误区
7. 风险提醒
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 市场监管总局关于招聘欺诈的提示（如有）
- 关于「培训贷」的监管文件或消费警示

**与其他篇的交叉**
- 兼职法律身份 → 04-01
- 校园贷 → 03-04
- 境外高薪招聘 → 09-08

## 04-04 家教怎么做：怎么找、怎么定价、怎么防被白嫖

**一句话定位**：家教是学生最容易上手的兼职，也是纠纷最多的。

**核心结论**
1. 找家教的渠道分三种：**平台/中介**（抽成）、**熟人介绍**（最稳）、**自行发布**（需防骗）
2. 定价参考当地行情，**不要低价接单养成坏习惯**
3. 最大的风险不是被欠薪，是**人身安全**（尤其去陌生人家）

**结构骨架**
1. 一句话定位
2. 渠道对比（表格：渠道 / 优点 / 风险 / 抽成）
3. 定价方法（怎么查当地行情、怎么谈）
4. **安全边界**（本篇重点）
   - 首次见面选公共场所或家长在场
   - 告知朋友你的行程
   - 不去偏僻地点、不接受单独留宿
5. 第一次上课要谈清的事（课时费、结算周期、请假规则、试讲是否收费）
6. 怎么防被白嫖（先结后上、按次结算、试讲收费）
7. 家教被欠薪怎么办 → 04-02
8. 常见误区
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 经验性内容，标【经验】
- 如涉及「在职教师有偿补课」的规定，需说明学生家教不适用但政策背景可提

## 04-05 实习协议怎么签

**一句话定位**：实习协议不是走过场，签之前有五件事必须问清。

**核心结论**
1. 实习通常签**实习协议**（不是劳动合同），但内容仍然有约束力
2. 五件事必须写明：**实习期限、工作时间、补贴标准与发放、保密义务、能否转正**
3. **违约金条款要特别看**——不合理的违约金可以谈

**结构骨架**
1. 一句话定位
2. 实习协议 vs 劳动合同的区别（表格）
3. **签之前必须确认的五件事**（本篇核心）
   - 期限（起止日期、能否提前结束）
   - 工作时间（是否 996、加班怎么算）
   - 补贴（金额、发放时间、是否含餐补交通）
   - 保密与竞业（是否限制离职后从业）
   - 转正（有没有留用名额、评定标准）
4. 违约金条款（什么情况合理、什么情况可以谈）
5. 实习期间受伤怎么办（不构成工伤，走人身损害赔偿 → 08-05）
6. 实习证明怎么开（离职时一定要）
7. 常见误区
   - 「实习协议不重要」
   - 「签了保密协议就不能写进简历」（一般不影响）
8. 风险提醒
9. 可执行清单（签约前核对表）
10. 参考资料 + 核查日期

**必须查证的资料**
- 《民法典》合同编关于格式条款的规定
- 关于实习学生权益的规范性文件（如有）

**已确认与待核实**
- ✅ 实习关系通常按劳务关系处理
- ⚠️ 职业学校学生实习有专门规定，普通高校实习无统一法规，需说明

## 04-07 远程兼职与自由职业：收钱、报税、合法性

**一句话定位**：线上接活看似自由，收钱和报税这两件事最容易出问题。

**核心结论**
1. 收入要**依法纳税**（劳务报酬所得），平台代扣或次年汇算清缴
2. 境外平台收款涉及**外汇管理规定**，需了解合规渠道
3. 远程工作的最大风险是**被骗且难以维权**（对方在外地甚至境外）

**结构骨架**
1. 一句话定位
2. 常见形态（设计、翻译、编程、写作、剪辑）
3. 平台选择（国内 vs 境外平台的差异）
4. **收款方式与合规**（本篇核心）
   - 国内：平台代收、个人转账
   - 境外：外汇额度、合规收汇渠道
5. 报税（劳务报酬的计税方式、年度汇算清缴）
6. 合同与交付（怎么约定里程碑付款）
7. 被骗了怎么办（跨地域维权的现实难度）
8. 常见误区
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**

## 04-08 写代码接单的法律边界

**一句话定位**：同样是写代码，有些能赚钱，有些能进去。

**核心结论**
1. **外挂、破解、爬取非公开数据、DDoS** 均有刑事风险
2. 风险不取决于你觉得「只是技术」，取决于**行为的法律定性**
3. 接单前必须问清：数据来源是否合法、用途是否合法、对方是谁

**结构骨架**
1. 一句话定位
2. 有刑事风险的六类活儿（表格：行为 / 可能触犯的罪名 / 法条）

   - 爬虫抓取非公开数据（侵犯公民个人信息罪 / 非法获取计算机信息系统数据罪）
   - 抢票、刷单脚本（可能构成破坏计算机信息系统罪）
   - DDoS（破坏计算机信息系统罪）

5. 合法的接单方向（正常业务系统、开源贡献、教学）
6. 常见误区
7. 风险提醒
8. 可执行清单
9. 参考资料 + 核查日期

## 04-10 大学生兼职要不要交税

**一句话定位**：要交，但多数情况下你交多了，可以退回来。

**核心结论**
1. 兼职收入属于**劳务报酬所得**，达到起征点需缴税
2. 支付方通常**预扣预缴**，预扣率可能高于实际税负
3. 次年办**综合所得年度汇算**，多缴的可以退

**结构骨架**
1. 一句话定位
2. 兼职收入的税务性质（劳务报酬 vs 工资薪金）
3. 预扣预缴怎么算（给公式，标注以现行规定为准）
4. **为什么你多半交多了**（预扣率 vs 综合所得税率）
5. 年度汇算清缴怎么退税（个人所得税 App、时间窗口）
6. 什么情况不用交（收入低于起征点）
7. 常见误区（「学生不用交税」「不申报也没事」）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
