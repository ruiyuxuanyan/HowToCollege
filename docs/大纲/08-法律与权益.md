## 08-01 大学生最常踩的法律红线总览

**一句话定位**：一篇文章看完全部高危行为，你的「不知道」比「故意」代价更大。

**核心结论**
1. 大学生的法律风险集中在四类：**帮信、网络言论、财产侵占、打架冲突**
2. 很多行为的共同特征是「**以为只是小事**」——法律不看你以为什么
3. 一旦涉刑，后果是**刑事记录 + 学业中断 + 就业受限**，且长期不可逆

**结构骨架**
1. 一句话定位（总纲篇）
2. 风险全景图（表格：行为 / 可能触犯的罪名/条款 / 后果等级）——**本篇核心**
   按四类分组，每类 3–5 条，全部给出法条指向
3. 为什么学生容易踩（信息差、从众、被利用、轻视后果）
4. **三条通用自保原则**
   - 不用自己的身份替别人办事（卡、账号、公司）
   - 不传播不确定的信息（尤其涉政、涉他人隐私）
   - 不参与「来钱太容易」的事
5. 每条红线展开一行的说明 + 指向详细篇目
6. 涉事后怎么办（停止、保留证据、找律师、主动说明）
7. 常见误区（汇总）
8. 风险提醒
9. 可执行清单（红线清单，可打印）
10. 参考资料 + 核查日期

**必须查证的资料**
- 《刑法》相关条款（帮信罪 287 之二、侮辱诽谤 246、侵犯公民个人信息 253 之一、盗窃 264、寻衅滋事 293、故意伤害 234 等）
- 相关司法解释
- 公开的学生涉案通报（用于说明现状，需标来源）

## 08-02 帮人「代收款」「过账」：帮信罪的认定

**一句话定位**：这一篇与 03-06 互为补充——03-06 讲罪名构成，这篇讲具体场景里的判断。

2. 判断的关键不是「你知不知道」，而是**客观情形是否足以推定你应当知道**

## 08-03 打架与寻衅滋事：从口角到刑事的距离

**一句话定位**：一拳的代价可能是三年。

**核心结论**
1. 故意伤害的**轻伤**就构成犯罪（不是「流血才算」）
2. 寻衅滋事罪的认定比多数人以为的宽（随意殴打、追逐拦截、强拿硬要、起哄闹事）
3. 「对方先动手」不等于免责——**防卫有严格限度**

**结构骨架**
1. 一句话定位
2. 打架的三种法律后果（表格：伤情 / 后果 / 依据）
   - 轻微伤 → 治安处罚（拘留、罚款）
   - 轻伤 → 故意伤害罪（刑事）
   - 重伤/死亡 → 更重
3. **伤情鉴定怎么分**（轻微伤 / 轻伤一二度 / 重伤），说明「轻伤」在法律上并不轻
4. 寻衅滋事罪的四种行为类型（引用《刑法》第二百九十三条）
5. **正当防卫的限度**（什么算防卫、什么算互殴、什么是防卫过当）
6. 校园常见触发场景（篮球场冲突、酒桌、宿舍矛盾、路见不平）
7. 动手后的处理（立即停止、就医、报警、不要私了了事）
8. 常见误区
   - 「打回去算正当防卫」
   - 「没打伤就没事」
   - 「赔钱私了就不追究」（刑事责任不能私了）
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《刑法》第二百三十四条（故意伤害）、第二百九十三条（寻衅滋事）
- 《人体损伤程度鉴定标准》
- 《治安管理处罚法》第四十三条
- 正当防卫的相关司法解释（两高一部关于依法适用正当防卫制度的指导意见）

## 08-04 网络言论的边界：造谣、辱骂、转发境外内容

**一句话定位**：转发也算，且「我只是看看」和「我传播了」是完全不同的法律后果。

**核心结论**
1. **造谣、诽谤、侮辱**都可能担责，民事、行政、刑事三个层次
2. **转发同样构成传播**，法律上不看你是不是原创
3. 涉及特定内容的传播有额外风险（需准确表述，不给规避建议）

**结构骨架**
1. 一句话定位
2. 三类行为，三种后果（表格：行为 / 民事 / 行政 / 刑事）
   - 诽谤（捏造事实）
   - 侮辱（辱骂、羞辱）
   - 造谣（编造并散布虚假信息）
3. **「转发」的法律定位**（本篇核心）
   - 转发即传播
   - 转发者的责任边界（是否明知、是否造成后果）
4. 诽谤罪的特殊性（**多为自诉案件**，「严重危害社会秩序和国家利益」才公诉）
5. 编造、故意传播虚假信息罪（《刑法》第二百九十一条之一）
6. 校园场景（群里骂人、挂人、传谣）
7. 自己的言论被追责怎么办
8. 常见误区
   - 「我只是转发」
   - 「删了就没事了」
   - 「网上说话没人管」
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《刑法》第二百四十六条、第二百九十一条之一
- 《治安管理处罚法》第二十五条
- 《民法典》人格权编（名誉权）
- 两高关于网络诽谤的司法解释（转发次数、浏览量的入罪标准）

## 08-05 实习/兼职期间的伤害：算不算工伤、怎么索赔

**一句话定位**：不算工伤，不等于没得赔——只是路不一样。

**核心结论**
1. **在校生兼职/实习通常不构成劳动关系**，所以**不走工伤认定**
2. 走的是**人身损害赔偿**（《民法典》侵权责任编），按过错划分责任
3. 学校、实习单位、学生本人的责任比例，看**谁有过错**

**结构骨架**
1. 一句话定位
2. 先定性：三种身份决定三条路（表格）
   - 在校生兼职/实习（劳务关系）→ 人身损害赔偿
   - 已建立劳动关系的（毕业后）→ 工伤
   - 学校组织的实习（可能有校方责任）
3. **人身损害赔偿怎么算**（医疗费、误工费、护理费、残疾赔偿金等）
4. 责任怎么划分（实习单位的安全保障义务、学校的教育管理责任、学生的自身过错）
5. 索赔步骤（就医留证 → 协商 → 起诉）
6. 学校组织的实习出事，学校有没有责任（教育管理职责）
7. 常见误区
   - 「不是工伤就没人管」
   - 「签了免责协议就白受伤」（格式条款可能无效）
8. 风险提醒
9. 可执行清单（受伤后立刻要做的事）
10. 参考资料 + 核查日期

**必须查证的资料**
- 《民法典》侵权责任编（第一千一百七十九条人身损害赔偿范围）
- 《工伤保险条例》（说明不适用范围）
- 学生实习相关规定

## 08-06 被学校处分了怎么办：申诉、听证、能否撤销

**一句话定位**：处分有法定程序，程序不合法就是你的机会。

**核心结论**
1. 学校作出处分必须**告知事实、理由、依据**，并**告知申诉权利**
2. 学生有**申诉权**，校内申诉委员会是必经程序
3. 程序违法（未告知、未听取陈述、未送达）是申诉的**有效理由**

**结构骨架**
1. 一句话定位
2. 处分的种类（警告 → 严重警告 → 记过 → 留校察看 → 开除学籍）
3. **处分必须走的程序**（本篇核心，判断学校是否违规的依据）
   - 调查取证
   - 告知拟处分事实、理由、依据
   - **听取学生陈述和申辩**（这是关键权利）
   - 作出决定并送达
   - 告知申诉途径和期限
4. 申诉流程
   - 校内申诉（学生申诉处理委员会），有**时限**（通常收到决定后若干日内）
   - 向上级教育行政部门申诉
5. **申诉书怎么写**（给结构：事实、程序问题、依据、请求）
6. 什么情况下申诉容易成功（程序违法、事实认定错误、依据不当、处分畸重）
7. 开除学籍的特殊性（影响最大，且**必须经校长办公会或校长授权的专门会议研究决定**）
8. 常见误区
   - 「申诉没用」
   - 「错过期限」（**时限是硬性的**）
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《普通高等学校学生管理规定》（教育部令第 41 号，**必须核实是否为现行版本**）
- 本校学生违纪处分规定与申诉办法

**已确认与待核实**

- ⚠️ 申诉时限各校规定不同

## 08-07 学籍问题：休学、退学、转学、开除

**一句话定位**：这些操作都不可逆或代价很大，做之前要知道后果。

**核心结论**
1. **休学**可逆（有期限），**退学**不可逆
2. 退学后想再读书，只能重新参加高考或走成人教育
3. 开除学籍是处分，与主动退学性质完全不同（影响档案）

**结构骨架**
1. 一句话定位
2. 四种状态的对比（表格：性质 / 可逆性 / 学籍处理 / 对档案影响）

   - 保留学籍
   - 退学（主动）
   - 开除学籍（处分）
3. 休学的条件与流程（病休、创业、参军、其他）
4. 退学的后果（学历、再入学途径、档案去向）
5. 转学的现实（高校转学限制极严，需说明条件）
6. 因学业原因被退学（学分不达标、超最长学习年限）
7. 常见误区
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

## 08-09 校园里的「担保」：帮同学贷款、做担保人

**一句话定位**：签字的那一刻，你就把自己的财产押上去了。

**核心结论**
1. 担保人**不是见证人**——对方还不上，你要还
2. 连带责任保证下，债权人可以**直接找你**，不必先找借款人
3. 学生做担保的金额往往超出承受能力

**结构骨架**
1. 一句话定位
2. 担保的两种类型（一般保证 vs 连带责任保证）——**差别巨大**
3. 担保人要承担什么（代为清偿、可能被起诉、影响征信）
4. 校园常见场景（帮同学网贷担保、帮亲戚担保、签字见证被当成担保）
5. **怎么区分「见证人」和「担保人」**（看合同里有没有「保证」字样、有没有担保条款）
6. 已经签了怎么办（能否撤销、如何追偿）
7. 常见误区
   - 「只是签个字」
   - 「他不还我也不用还」（错）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**

## 08-10 合同基本常识：签字前该看哪几条

**一句话定位**：不用懂法律，但要会找那几个要命的条款。

**核心结论**
1. 签字前必看五处：**金额、期限、违约责任、解除条件、争议解决**
2. **格式条款**（对方预先拟定的）中排除你主要权利的，可能无效
3. 口头约定也有效，但**举证极难**，所以一定要落纸

**结构骨架**
1. 一句话定位
2. 合同成立的要素（当事人、标的、数量、质量、价款、履行期限、违约责任、争议解决）
3. **签字前必看的五处**（本篇核心，给检查清单）
   - 金额与支付方式（有无隐藏费用）
   - 期限（起止、续期、自动续费）
   - 违约责任（违约金比例是否畸高）
   - 解除条件（能不能退、怎么退）
   - 争议解决（去哪起诉、仲裁还是诉讼）
4. **格式条款的陷阱**（《民法典》第四百九十六条、四百九十七条）
5. 违约金的上限（过分高于损失的可以请求调整）
6. 「定金」与「订金」的区别（**一字之差，效力完全不同**）
7. 签字前的通用动作（拍照留存、要求给副本、不要签空白合同）
8. 常见误区
9. 可执行清单（签前五问）
10. 参考资料 + 核查日期

**必须查证的资料**
- 《民法典》合同编总则（第四百六十九条起）
- 格式条款条款（第四百九十六、四百九十七条）
- 定金条款（第五百八十六条起）

## 08-11 被偷拍、被偷窥、宿舍被翻：隐私权保护

**一句话定位**：隐私被侵犯时，取证的方式决定了你能不能追责。

**核心结论**
1. 偷拍、偷窥、私自翻查他人财物，可能同时构成**治安违法与民事侵权**
2. 传播偷拍内容可能构成**刑事犯罪**（传播淫秽物品、侵犯公民个人信息）
3. **先取证再声张**——很多人吃亏在打草惊蛇

**结构骨架**
1. 一句话定位
2. 常见形式（宿舍偷拍、浴室偷拍、翻查手机/柜子、传播私密影像）
3. 法律后果分三层（民事/治安/刑事，表格）
4. **取证方法**（本篇核心）
   - 保留原始设备与内容
   - 记录时间地点
   - 不要自行删改
   - 立即报警（涉及偷拍设备，警方可固定证据）
5. 校内处理路径（保卫处、学工部）
6. 传播私密影像的特别提醒（可能构成传播淫秽物品罪；被传播者如何应对）
7. 常见误区
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《民法典》第一千零三十二条、一千零三十三条（隐私权）
- 《治安管理处罚法》第四十二条
- 《刑法》关于传播淫秽物品、侵犯公民个人信息的规定

**与其他篇的交叉**
- 性骚扰 → 06-02
- 网暴 → 06-09

## 08-12 报警之后会发生什么

**一句话定位**：报警不是「报完就完了」，你还需要知道流程和你的权利。

**核心结论**
1. 报警后**有权索取受案回执**，这是后续跟进的凭据
2. 不予立案的，可以**申请复议、向检察院申请立案监督**
3. 民事纠纷报警，警方可能引导走诉讼——这不等于不管

**结构骨架**
1. 一句话定位
2. 报警的方式（110、到派出所、短信报警 12110）
3. 报警后警方做什么（受案 → 审查 → 立案/不立案）
4. **受案回执**（本篇核心：一定要要，怎么要）
5. 不予立案怎么办
   - 要求出具《不予立案通知书》
   - 申请复议
   - 向检察院申请立案监督
6. 什么算刑事案件、什么算治安案件、什么算民事纠纷
7. 报警的注意事项（如实陈述、不要夸大、保留证据）
8. 常见误区
   - 「报警没用」
   - 「金额小不管」
   - 「报了警就一定能破案」
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《刑事诉讼法》关于立案的规定（第一百一十条起）
- 《公安机关办理刑事案件程序规定》
- 《治安管理处罚法》

**与其他篇的交叉**
- 被骗后处理 → 07-13
- 欠薪维权 → 04-02（**路径不同，注意区分**）

## 08-13 消费维权：网购、培训、美容、健身卡退费

**一句话定位**：大多数消费纠纷不用打官司，走对渠道就能解决。

**核心结论**
1. **12315** 是最有效的第一站（市场监管部门）
2. 网购有**七天无理由退货**（法定，但有限制品类）
3. 预付卡（健身、美容、培训）跑路，可**集体维权**

**结构骨架**
1. 一句话定位
2. **维权渠道阶梯**（本篇核心，按成本从低到高）
   - 与商家协商
   - 平台投诉（电商平台）
   - 12315（市场监管）
   - 消协调解
   - 诉讼（小额诉讼）
3. 网购的特殊规则（七天无理由、限定的例外品类、拆封是否影响）
4. 预付卡的风险与维权（跑路、转让、退费）
5. 培训贷的维权 → 04-03
6. 证据怎么准备（订单、聊天记录、发票、实物照片）
7. 常见误区
   - 「金额小就算了」
   - 「没有发票就没法维权」（有其他证据也行）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《消费者权益保护法》（七天无理由条款、第二十五条）
- 《消费者权益保护法实施条例》（需核实是否已施行）
- 单用途商业预付卡管理办法

**与其他篇的交叉**

- 健身房 → 07-06

## 08-14 顺手牵羊与盗窃：多少金额会构成犯罪

**一句话定位**：「就拿一次」也可能变成刑事记录。

**核心结论**
1. 盗窃罪的入罪有**数额标准**（各地不同，通常千元至三千元起）
2. 但**多次盗窃、入户盗窃、扒窃**不受数额限制——拿一次小的也可能构成犯罪
3. 校园内的「拿错」「借用不还」在实践中仍可能被认定为盗窃

**结构骨架**
1. 一句话定位
2. 盗窃罪的构成与数额标准
   - 「数额较大」的地方标准（各省不同）
   - **不受数额限制的情形**（多次、入户、扒窃、携带凶器）——本篇核心
3. 校园常见场景（拿室友东西、偷外卖、图书馆顺走、宿舍楼内顺手拿）
4. 「偷外卖」的法律定性（金额小但可能构成多次盗窃）
5. 治安处罚 vs 刑事处罚的分界
6. 被偷了怎么办（报警、取证 → 08-12）
7. 被指控了怎么办（不要自认、找证据、必要时找律师）
8. 常见误区
   - 「金额小不算偷」
   - 「还回去就没事了」（可能已既遂）
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《刑法》第二百六十四条（盗窃罪）
- 两高关于办理盗窃刑事案件的司法解释
- 各省关于盗窃数额标准的規定

- 08-12 报警
