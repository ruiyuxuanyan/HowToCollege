# 10 毕业与社会生活 · 逐篇写作大纲

> 分类定位：档案、户口、劳动合同、五险一金、租房、个税——成年后的第一课。
> 适用人群：应届毕业生、毕业 2 年内的社会新人。
> 核查日期：2026-11-04。

## 分类级判断

这个分类有两个特点：

1. **信息普遍过时**——报到证取消、社保政策调整、个税规则变化，网上大量内容停留在几年前
2. **后果延迟爆发**——档案问题可能十年后才炸，社保断缴影响买房落户

已核实的关键变化：

> **报到证已取消**，就业报到证不再签发。这意味着「去报到证上写的单位报到」「凭报到证迁户口」这些老流程全部失效，毕业手续相应调整。

本分类的写作纪律：

| 纪律 | 说明 |
| --- | --- |
| **不写旧流程** | 报到证相关的老流程必须剔除，写当前做法 |
| **分清「应届」与「社会人」** | 很多规则在毕业那一刻切换 |
| **金额与比例查当年度** | 社保比例、个税起征点、公积金比例 |
| **说明地区差异** | 社保、公积金、落户全是地方政策 |

## 10-01 毕业手续清单

**一句话定位**：报到证取消后，毕业手续变了——按这张清单走，别漏。

**核心结论**
1. **报到证已取消**，不再签发，传统「凭报到证报到」的流程已失效
2. 毕业时要处理四件事：**档案、户口、党团组织关系、就业手续**
3. 每一项的**去向取决于你的选择**（就业/升学/待业/出国）

**结构骨架**
1. 一句话定位
2. **先按去向分类**（本篇核心表格：去向 / 档案去哪 / 户口怎么办 / 组织关系怎么转）
   - 签了工作（单位有档案保管权 / 无保管权）
   - 升学（本校 / 外校）
   - 待业（回原籍 / 保留在学校）
   - 出国
   - 灵活就业/自由职业
3. 办理时间线（毕业前 1–2 个月要做什么）
4. **报到证取消后的变化**（单列一节，说明新旧流程差异，避免读者被旧攻略误导）
5. 各类材料的交接方式
6. 常见误区
   - 「档案不重要」（→ 10-02）
   - 「学校会自动帮我处理好」
   - 按网上旧攻略去办报到证
7. 风险提醒
8. 可执行清单（按去向分支的打勾表）
9. 参考资料 + 核查日期

**必须查证的资料**
- 教育部关于取消就业报到证的文件（**必须找到文号与生效时间**）
- 本校就业指导中心的毕业手续说明
- 各地人社部门的接收政策

**已确认与待核实**
- ✅ 报到证已取消（有官方来源）
- ⚠️ 取消后的**具体替代流程仍在磨合**，各地各校做法可能不同，必须说明
- ⚠️ 档案接收单位信息各校不同

**与其他篇的交叉**
- 档案 → 10-02
- 应届生身份 → 09-06
- 三方协议 → 09-01

**政策适用性声明必须包含**
- 依据文件（含文号、生效日期）
- 全国统一 / 地方执行
- 核查日期
- 已知变化：报到证取消

## 10-02 档案在哪、有什么用、丢了怎么补

**一句话定位**：这份你看不见的纸质材料，会在十年后决定你能不能考公、退休算几年工龄。

**核心结论**
1. 档案**不能自己保管**（个人保管的档案可能不被接收）
2. 档案影响：**考公政审、职称评定、退休工龄认定、部分落户**
3. 档案丢了可以补，但**极其麻烦**，要回原学校、原单位逐一补材料

**结构骨架**
1. 一句话定位
2. 档案里有什么（学籍材料、成绩单、党团材料、奖惩记录、报到手续）
3. **档案应该在哪**（表格：身份 / 档案存放地）
   - 在校生 → 学校
   - 国企/机关/事业单位 → 单位
   - 民企/外企 → 单位所在地人才市场 或 户籍地人才市场
   - 待业 → 户籍地人才市场/公共就业服务机构
4. **绝对不能做的三件事**（本篇核心）
   - 自己拿着（会成为「死档」，可能不被接收）
   - 自己拆封（**拆封即失效**）
   - 长期不管（多年后可能找不到）
5. 怎么查档案在哪
6. 档案转递流程（机要通道，不能快递）
7. **档案丢了怎么补**（分步：回学校补学籍材料、回原单位补工作材料、重新建档）
8. 常见误区
   - 「档案没用」
   - 「放自己手里更安全」
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《流动人员人事档案管理服务规定》（人社部）
- 《企业职工档案管理工作规定》
- 各地人才服务中心的接收要求

**已确认与待核实**
- ✅ 档案不得个人保管、不得拆封（通行规则）
- ⚠️ 「死档」的具体处理各地不同

**与其他篇的交叉**
- 毕业手续 → 10-01
- 考公 → 09-12

## 10-03 劳动合同怎么签：必备条款、试用期、违约金

**一句话定位**：这是你作为劳动者最重要的一份文件，签之前逐条看。

**核心结论**
1. 劳动合同有**九项法定必备条款**，缺项可以要求补
2. **试用期上限与合同期限挂钩**（详见 09-11）
3. 除「服务期」和「竞业限制」两种情形外，**不得约定由劳动者承担的违约金**

**结构骨架**
1. 一句话定位
2. **法定必备条款**（九项，逐条说明怎么看）
   - 用人单位信息
   - 劳动者信息
   - 合同期限
   - 工作内容与地点
   - 工作时间与休息休假
   - 劳动报酬
   - 社会保险
   - 劳动保护与职业危害防护
   - 法律规定的其他事项
3. **必须警惕的条款**（本篇核心，逐条拆）
   - 「自愿放弃社保」（**无效**）
   - 「加班不付加班费」
   - 「服从公司任何调岗」（可能被滥用）
   - 「离职需公司批准」
   - 高额违约金（除两种法定情形无效）
   - 空白合同
4. 合同期限类型（固定期限、无固定期限、以完成一定工作任务为期限）
5. 不签书面合同的法律后果（**双倍工资**）
6. 合同到期不续签的补偿
7. 常见误区
8. 风险提醒
9. 可执行清单（签约前 10 问）
10. 参考资料 + 核查日期

**必须查证的资料**
- 《劳动合同法》第十七条（必备条款）、第十九条（试用期）、第二十二条至二十五条（违约金）、第八十二条（双倍工资）
- 《社会保险法》

**与其他篇的交叉**
- 试用期 → 09-11（**边界：09-11 专讲试用期，本篇讲合同整体**）
- 被辞退 → 10-06
- 五险一金 → 10-04

## 10-04 五险一金是什么：缴费比例、个人账户、断缴后果

**一句话定位**：工资条上扣掉的那一大块，其实大部分进了你自己的账户。

**核心结论**
1. 五险：养老、医疗、失业、工伤、生育（**工伤和生育个人不缴**）
2. 缴费**由单位和个人共同承担**，比例各地不同
3. **断缴影响**：医保立即受影响，买房落户看连续年限

**结构骨架**
1. 一句话定位
2. 五险一金总览（表格：项目 / 单位缴 / 个人缴 / 用途 / 断缴影响）
   - 养老保险
   - 医疗保险
   - 失业保险
   - 工伤保险（个人不缴）
   - 生育保险（个人不缴，多数地区已并入医保）
   - 住房公积金
3. **哪些进个人账户**（养老个人账户、医保个人账户、公积金全额）
4. **断缴的后果**（本篇核心）
   - 医保：断缴后待遇受影响（各地规定不同）
   - 养老：累计计算，短期断缴影响有限
   - 买房/落户：**看连续缴纳年限**，断一次可能清零
   - 公积金贷款：需连续缴存
5. 缴费比例（说明各地不同，给查询路径）
6. 怎么查自己的缴费记录（国家社会保险公共服务平台）
7. 常见误区
   - 「不缴社保多拿现金更划算」（失去医疗/养老/购房资格）
   - 「试用期不用缴」（必须缴）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《社会保险法》
- 各地社保缴费比例与基数（当年公告）
- 公积金管理条例

**已确认与待核实**
- ⚠️ **缴费比例各地差异大，且每年调整基数**，不得写死数字，写「以当地公告为准」
- ⚠️ 生育保险已多数并入医保，需核实表述
- ⚠️ 医保断缴后的待遇恢复规则各地不同

**与其他篇的交叉**
- 断缴影响 → 10-08
- 灵活就业 → 10-09
- 个税 → 10-07

## 10-05 第一次租房：渠道、合同陷阱、押金、水电过户

**一句话定位**：毕业后第一次独立租房，坑比学校附近多得多。

**核心结论**
1. 毕业后租房没有「学校兜底」，**合同与押金风险全靠自己**
2. 「押一付三」「年付打折」都要谨慎，**付款周期越短越安全**
3. 入住当天**拍全屋照片 + 记录水电表读数**，这是退押金的唯一凭据

**结构骨架**
1. 一句话定位
2. 与学生租房的差异（→ 05-06，本篇不重复基础内容，聚焦毕业后场景）
3. 找房渠道（中介、房东直租、长租公寓、合租）
4. **签合同前的核查**（产权、二房东、是否可办居住登记）
5. 合同必备条款（租期、租金、押金、维修责任、提前解约、转租）
6. **入住当天的存证**（清单）
7. 水电燃气过户/开户
8. 退租与押金（怎么要回、被无理扣押怎么办）
9. 常见纠纷（房东提前收房、押金不退、二房东跑路、房屋被抵押）
10. 常见误区
11. 风险提醒
12. 可执行清单
13. 参考资料 + 核查日期

**必须查证的资料**
- 《民法典》租赁合同章
- 《商品房屋租赁管理办法》
- 居住证/居住登记办理条件（各地不同）

**与其他篇的交叉**

- 押金纠纷 → 08-13

## 10-06 被辞退怎么办：N、N+1、2N 的区别与取证

**一句话定位**：公司说「你明天不用来了」，你该拿多少钱，法律写得很清楚。

**核心结论**
1. **N** = 经济补偿（按工作年限，每满一年一个月工资）
2. **N+1** = 经济补偿 + 代通知金（未提前 30 天通知）
3. **2N** = 违法解除的赔偿金（公司没有合法理由就辞退你）

**结构骨架**
1. 一句话定位
2. 三种情形对应三种补偿（本篇核心表格）
   - 协商一致解除 / 无过失性辞退 → N 或 N+1
   - 经济性裁员 → N
   - **违法解除** → 2N
3. **N 怎么算**（工作年限折算、月工资基数、上限）
4. 什么情况公司可以不给补偿（严重违纪等过失性辞退）
5. **取证**（本篇最实用）
   - 书面解除通知（一定要书面！）
   - 考勤记录、工资条、劳动合同
   - 不要签「自愿离职申请」
6. 维权路径（劳动仲裁 → 诉讼）
7. 常见误区
   - 「被辞退很丢人，赶紧走」（可能放弃补偿）
   - 「签了离职申请还能反悔」（很难）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《劳动合同法》第四十六条（补偿情形）、第四十七条（计算标准）、第四十八条（违法解除）、第八十七条（2N）

**与其他篇的交叉**
- 劳动合同 → 10-03
- 试用期辞退 → 09-11

## 10-07 个税：起征点、专项附加扣除、退税

**一句话定位**：每年 3–6 月有一笔钱可以退，多数人不知道自己符合条件。

**核心结论**
1. 综合所得有**基本减除费用标准**（起征点），且有**专项附加扣除**
2. 租房、继续教育、赡养老人等**都可以抵扣**
3. **年度汇算清缴**（次年 3–6 月）多退少补，多数人能退税

**结构骨架**
1. 一句话定位
2. 个税基本规则（起征点、税率表、累计预扣）
3. **专项附加扣除**（本篇核心，逐项说明条件与标准）
   - 子女教育
   - 继续教育（**职业资格证书也可扣**）
   - 大病医疗
   - 住房贷款利息
   - **住房租金**（租房的人最容易漏）
   - 赡养老人
   - 3 岁以下婴幼儿照护
4. 怎么填报（个人所得税 App）
5. 年度汇算清缴（时间、流程、什么情况能退）
6. 常见误区
   - 「工资低就不用管」
   - 「租房不能抵扣」（可以）
7. 可执行清单
8. 参考资料 + 核查日期

**必须查证的资料**
- 《个人所得税法》及实施条例
- 专项附加扣除暂行办法（**标准近年有上调，需查最新**）

**已确认与待核实**
- ⚠️ **各项扣除标准近年多次调整**（如婴幼儿照护、子女教育、赡养老人标准上调），必须查最新文件
- ⚠️ 起征点与税率表需核对现行版本

**与其他篇的交叉**
- 兼职报税 → 04-10
- 租房 → 10-05

## 10-08 社保断缴的影响

**一句话定位**：断一个月可能没事，断在关键节点上代价很大。

**核心结论**
1. **医保断缴**影响最直接（待遇暂停或降低，各地规则不同）
2. **买房、落户、车牌摇号**看的是**连续缴纳年限**，断一次可能重新计算
3. 养老是累计计算，短期断缴影响有限，但长期断缴影响退休待遇

**结构骨架**
1. 一句话定位
2. 断缴对各险种的影响（表格：险种 / 断缴后果 / 能否补缴）
3. **最要命的三种场景**（本篇核心）
   - 准备买房（连续年限清零）
   - 准备落户（积分或年限要求）
   - 医保待遇期内生病
4. 补缴的规则（单位原因 vs 个人原因，能否补、补了算不算连续）
5. 换工作期间怎么不断缴（三种方案）
6. 常见误区
7. 可执行清单
8. 参考资料 + 核查日期

**必须查证的资料**
- 各地社保政策（差异极大）
- 《社会保险法》

**与其他篇的交叉**
- 五险一金 → 10-04
- 灵活就业 → 10-09

## 10-09 灵活就业与自由职业：社保自己怎么交

**一句话定位**：没有单位，社保不会自动没有——但要自己去办。

**核心结论**
1. 灵活就业人员可以**以个人身份参加职工养老和医疗保险**
2. 也可以选择**参加城乡居民社保**（缴费低、待遇低）
3. 参保地通常要求**户籍地或居住证所在地**

**结构骨架**
1. 一句话定位
2. 两种参保方式对比（表格：方式 / 缴费 / 待遇 / 适合谁）
   - 职工社保（个人身份）
   - 城乡居民社保
3. 缴费基数与比例（各地不同）
4. 参保地限制（户籍地 / 居住证）
5. 怎么办理（线上/线下）
6. 与「挂靠代缴」的区别（**挂靠有法律风险，需提醒**）
7. 常见误区
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 《社会保险法》关于灵活就业人员参保的规定
- 各地灵活就业参保办法

## 10-10 第一份工作的城市选择

**一句话定位**：这不是「哪个城市好」，是「哪个城市的约束条件适合你」。

**核心结论**
1. 关键变量：**落户难度、房价收入比、行业集中度、离家距离**
2. 应届生落户有**政策窗口**（部分城市对应届生放宽），过期不再
3. 第一份工作的城市**不必是终身的**，但换城市有成本

**结构骨架**
1. 一句话定位
2. 四个决策变量（表格：变量 / 怎么查 / 影响什么）
3. 应届生落户的政策窗口（说明各城市不同，给查询路径）

## 10-11 入职体检与背景调查

**一句话定位**：体检和背调都有边界，不是公司想查什么就查什么。

**核心结论**
1. 入职体检**不得包含乙肝项目**（有明确规定）
2. 体检结果属于**个人隐私**，公司只能在必要范围内知悉
3. 背景调查需**本人授权**

**结构骨架**
1. 一句话定位
2. 入职体检的常规项目与禁止项目（**乙肝五项禁止检查**）
3. 体检不合格会怎样（依岗位而定，需说明岗位相关性）
4. 背景调查的合法边界（需授权、查什么、不能查什么）
5. 个人信息保护（《个人信息保护法》相关）
6. 遭遇就业歧视怎么办 → 09-05

## 10-12 职场新人常见错误

**一句话定位**：有些错误会跟着你很久，早一点知道能省很多事。

**核心结论**
1. 最常见的三类错误：**越权承诺、越级汇报、口头代替书面**
2. 职场里**「留痕」是自我保护的基础**（邮件、聊天记录）
3. 不签劳动合同、不缴社保、口头承诺，都是高危

**结构骨架**
1. 一句话定位
2. 沟通类错误（越级、越权承诺、不汇报）
3. **留痕意识**（本篇核心，给具体做法）
   - 重要事项发邮件确认
   - 口头决定后补一条消息
   - 保留工作成果与交接记录
4. 权益类错误（不签合同、不缴社保、接受口头承诺）
5. 边界类错误（帮同事背锅、做超出职责的事、过度加班）
6. 离职时的注意事项（交接、离职证明、社保转移）
7. 常见误区
8. 可执行清单
9. 参考资料 + 核查日期

**与其他篇的交叉**
- 劳动合同 → 10-03
- 被辞退 → 10-06
