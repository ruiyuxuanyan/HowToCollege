## 11-01 账号安全：二次验证、密码管理

**一句话定位**：你的账号安全水平，取决于最弱的那个环节。

**核心结论**
1. **密码复用是最大的风险**——一个站泄露，全部沦陷
2. **二次验证（2FA）是投入产出比最高的措施**
3. 短信验证码**不是最强的 2FA**（可被 SIM 劫持），但比没有强得多

**结构骨架**
1. 一句话定位
2. 三类账号的分级（表格：等级 / 例子 / 保护要求）
   - 核心（银行、支付、微信、主要邮箱）
   - 重要（学校系统、常用社交）
   - 一般
3. **密码管理**（本篇核心）
   - 为什么不能复用
   - 密码管理器怎么用（原理，不推具体产品）
   - 什么算强密码
4. **二次验证**（2FA 方式对比表）
   - 短信验证码（最弱）
   - 认证器 App（TOTP，推荐）
   - 硬件密钥（最强）
   - 生物识别
5. 邮箱是「总钥匙」（找回密码都走邮箱，要重点保护）
6. 常见误区
   - 「我的密码很复杂」（复用才是问题）
   - 「我不值得被攻击」
7. 可执行清单（本周就能做的 5 件事）
8. 参考资料 + 核查日期

## 11-02 手机丢了、号被盗了：第一步做什么

**一句话定位**：按顺序操作，能把损失控制在最小。

**核心结论**
1. **第一件事是挂失 SIM 卡**（旧手机收到验证码，等于账号全丢）
2. 顺序：**挂失手机号 → 冻结支付 → 改密码 → 报警**
3. 提前准备（记住关键账号、开启查找设备）能把损失降到最低

**结构骨架**
1. 一句话定位
2. **手机丢失的 30 分钟操作清单**（本篇核心，按顺序）
   - 打运营商客服挂失/补卡（**最优先**）
   - 冻结支付（微信、支付宝、银行）
   - 用其他设备登录并改密码
   - 开启「查找我的设备」远程锁定/擦除
   - 报警（被盗抢的情况）
3. **手机号被盗用/被补卡**怎么办（SIM 交换攻击）
4. 事前准备（本篇高价值）
   - 记下关键账号与客服电话
   - 开启设备查找
   - 不要在手机里存身份证照片
5. 常见误区
   - 「先报警再挂失」（挂失更急）
   - 「手机有锁屏密码就安全」（SIM 卡能取出）
6. 可执行清单（含电话清单）
7. 参考资料 + 核查日期

**与其他篇的交叉**
- 账号安全 → 11-01
- 个人信息 → 11-03

**写作提醒**：本篇的核心价值在**顺序**。顺序错了损失会翻倍。

## 11-03 个人信息泄露的排查与止损

**一句话定位"**：你不知道的地方，可能已经用你的名字办了好几张卡。

**核心结论**
1. **定期自查名下电话卡、银行卡**，是发现身份被冒用的有效方法
2. 名下多出的卡可能被用于**诈骗、洗钱**（→ 03-06 帮信罪）
3. 发现异常立即**注销 + 报警 + 保留证据**

**结构骨架**
1. 一句话定位
2. 信息泄露的常见来源（注册、快递、扫码、App 权限、内部泄露）
3. **自查方法**（本篇核心，最重要）
   - 查名下电话卡（运营商「一证通查」）
   - 查名下银行卡与账户
   - 查征信报告（央行征信中心，每年免费次数）
   - 查是否被注册为公司法人/股东（国家企业信用信息公示系统）
4. 发现异常怎么办
   - 注销多余卡
   - 报警（身份被冒用）
   - 向征信机构提出异议
5. 日常防护（App 权限、快递单处理、不随意填身份证号）
6. 常见误区
7. 可执行清单（每年做一次的自查表）
8. 参考资料 + 核查日期

**必须查证的资料**
- 工信部「一证通查」服务（电话卡查询）
- 中国人民银行征信中心查询方式（每年免费次数规定）
- 国家企业信用信息公示系统

**与其他篇的交叉**
- 帮信罪 → 03-06
- 银行卡 → 03-05
- 求职信息 → 09-10

## 11-04 校园网、VPN 与「翻墙」的法律风险

**一句话定位**：技术可行，法律有边界，这个边界必须知道。

**核心结论**
1. 未经批准**自建或使用非法定信道进行国际联网**，违反《计算机信息网络国际联网管理暂行规定》
2. 处罚形式包括**警告、罚款**，情节严重可能涉及其他责任
3. 校园网的使用另有校规约束（如禁止分享账号、禁止搭建服务）

**结构骨架**
1. 一句话定位
2. 校园网的合规使用（账号共享、限速、流量、违规后果）
3. 国际联网的管理规定（引用《计算机信息网络国际联网管理暂行规定》第六条等）
4. **风险的实际范围**（客观陈述法律规定与常见处理方式，不夸大、不鼓励）
5. 学校网络管理办法（各校不同）
6. 常见误区
7. 风险提醒
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 《计算机信息网络国际联网管理暂行规定》（**需核实是否为现行有效版本**）
- 《网络安全法》相关条款
- 本校网络使用管理办法

**写作提醒**：本篇只做**客观法律陈述**，不提供任何操作指引，也不做道德评判。写法上保持中性、就事论事。

## 11-05 AI 工具怎么用：作业、论文、编程的边界

**一句话定位**：AI 不是不能用，是要知道在什么场合用会出事。

**核心结论**
1. **各校对 AI 使用的规定不同且仍在变化**，必须以本校最新规定为准
2. 风险最高的三种用法：**整段生成提交、伪造引用、代写论文/毕设**
3. 相对安全的用法：**辅助理解、检查语法、生成提纲后自己重写**

**结构骨架**
1. 一句话定位
2. 学校规定的三种典型态度（表格：态度 / 典型要求 / 风险）
   - 禁止使用
   - 允许但需申报
   - 允许但有范围限制
3. **风险分级**（本篇核心表格：用法 / 风险 / 说明）
   - 整段生成直接提交 → 极高
   - 生成后改写但不申报 → 高（视学校规定）
   - 伪造参考文献 → 极高（可能构成学术不端）
   - 辅助理解概念 → 低
   - 检查语法/翻译 → 低（但需申报，视规定）
   - 生成代码后自己理解并重写 → 中
4. **AI 会编造引用**（幻觉问题）——这是学生最容易踩的坑
5. 怎么正确使用（给方法：把 AI 当检索起点和检查工具，不当作者）
6. 被判定违规的后果
7. 常见误区
8. 可执行清单（使用前自查）
9. 参考资料 + 核查日期

**必须查证的资料**
- 本校关于 AI 使用的规定（**必须查本校，各校差异大**）
- 教育部关于学术规范的现行文件
- 关于大模型幻觉的公开研究（说明引用不可信的依据）

**与其他篇的交叉**
- 学术规范 → 02-10
- AI 代写 → 11-11

## 11-06 云盘、笔记、备份：不丢数据的最小方案

**一句话定位**：丢一次论文你就知道备份值多少钱。

**核心结论**
1. 备份的铁律是**3-2-1**：3 份副本、2 种介质、1 份异地
2. 对学生的**最小可行方案**：本地 + 云盘 + 定期导出
3. **同步 ≠ 备份**（误删会同步删除）

**结构骨架**
1. 一句话定位
2. 为什么学生会丢数据（硬盘坏、误删、账号被盗、毕业清号）
3. **3-2-1 原则**（本篇核心）
4. 学生的实操方案（表格：数据类型 / 备份方式 / 频率）
   - 论文与作业
   - 照片
   - 代码
   - 密码与重要账号信息
5. **同步与备份的区别**（很多人以为开了同步就安全）
6. 毕业时的数据迁移（学校账号会注销）
7. 常见误区
8. 可执行清单
9. 参考资料 + 核查日期

## 11-07 网盘资源与盗版：下载、分享、存储的边界

**一句话定位**：自己看和传播出去，法律后果差很多。

**核心结论**
1. **个人下载观看**与**传播分享**的法律风险不同
2. **分享**（发链接、建群传资源）风险显著高于自己看
3. 以营利为目的的传播风险最高（可能构成刑事）

**结构骨架**
1. 一句话定位
2. 行为的风险分级（表格：行为 / 风险 / 说明）
   - 自己下载观看
   - 存储在自己网盘
   - 分享链接给同学
   - 建群大规模分享
   - 挂广告/收费
3. 著作权法的相关规则（合理使用的边界）
4. **学校网络与校园网的额外风险**（校规、流量监测）
5. 被投诉/被通知怎么办（删除、停止传播）
6. 常见误区
7. 风险提醒
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 《著作权法》第二十四条（合理使用）
- 《刑法》第二百一十七条（侵犯著作权罪）
- 本校网络使用规定

**与其他篇的交叉**
- 著作权 → 08-08（**边界：08-08 讲著作权法理，本篇讲具体场景中的风险分级**）

## 11-08 换手机号前必须做的事

**一句话定位**：旧号一注销，绑在它上面的账号就再也找不回来了。

**核心结论**
1. 换号前必须**逐项解绑/改绑**（银行、支付、社交、学校系统）
2. 旧号不要立即注销，**保留一段时间**（接收验证码）
3. 有些账号只能通过手机号找回，一旦丢失极难恢复

**结构骨架**
1. 一句话定位
2. **改绑清单**（本篇核心，按重要性排序）
   - 银行与支付
   - 微信/QQ 等主要社交
   - 学校系统（教务、邮箱、图书馆）
   - 常用 App
   - 快递、外卖、购物
3. 旧号的处理（保留期、注销流程、二次放号风险）
4. 二次放号的坑（新号主可能收到你的验证码）
5. 常见误区
6. 可执行清单（改绑核对表）
7. 参考资料 + 核查日期

**与其他篇的交叉**

- 手机丢失 → 11-02

**核心结论**
1. 工具的作用被高估，**方法比工具重要**

## 11-10 二手平台交易：闲鱼的骗局与维权

**一句话定位**：二手交易的风险不在商品，在付款方式。

**核心结论**
1. **绝不脱离平台交易**（要求加微信、私下转账的都是骗局）
2. 买家骗局：**假付款截图、到手刀、恶意退款**
3. 卖家骗局：**货不对板、调包、到手后申请仅退款**

**结构骨架**
1. 一句话定位
2. 常见骗局（表格：角色 / 骗局 / 识别点）
   - 买家视角（假链接、假客服、假付款）
   - 卖家视角（到手刀、调包、恶意退款）
3. **交易安全原则**（本篇核心）
   - 全程平台内沟通与付款
   - 不点陌生链接
   - 发货前拍视频留证
   - 面交选公共场所
4. 骗局发生后怎么办（平台申诉、报警、12315）
5. 买卖大件（电脑、手机）的额外注意（验机、IMEI 核对）
6. 常见误区
7. 可执行清单
8. 参考资料 + 核查日期

**与其他篇的交叉**
- 买大件 → 03-09
- 消费维权 → 08-13

## 11-11 「AI 代写」「代做毕设」的风险与后果

**一句话定位**：花几百块买的东西，可能让你拿不到学位。

**核心结论**
1. 代写代做属于**学术不端**，后果可能是**取消学位、撤销学位**（可追溯）
2. 代写方可能反过来**敲诈**（掌握你的把柄）
3. 论文抽检、AI 检测、答辩追问都能发现

**结构骨架**
1. 一句话定位
2. 代写的实际风险（本篇核心）
   - 学校认定后取消学位
   - **已授予的学位可被撤销**（可追溯）
   - 被代写方敲诈
   - 涉及保密的论文可能泄露
3. 被发现的几种方式（查重、AI 检测、答辩、抽检）
4. 已经用了怎么办（主动说明的后果）
5. 常见误区
6. 风险提醒
7. 可执行清单
8. 参考资料 + 核查日期

**必须查证的资料**
- 《学位法》关于撤销学位的规定（**需核实现行条款**）
- 《高等学校预防与处理学术不端行为办法》
- 教育部关于学位论文抽检的规定
