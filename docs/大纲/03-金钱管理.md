# 03 金钱管理 · 逐篇写作大纲

> 分类定位：助学贷款、医保报销、校园贷识别，以及最危险的帮信罪。
> 适用人群：全体在校生，经济困难学生优先。
> 核查日期：2026-11-04。

## 分类级判断

这个分类是本项目**风险最高、价值也最高**的一类。原因：

- 涉及金额大（学费、贷款、被骗的钱）
- 后果不可逆（征信污点、刑事记录）
- 学生最不了解（金融和法律双重信息差）

本分类的写作纪律比其他分类更严：

| 要求 | 说明 |
| --- | --- |
| 每个金额必须有来源 | 贷款额度、报销比例、缴费标准，一律查当年度文件 |
| 涉及刑事的必须给法条 | 帮信罪、诈骗罪的构成要件引用《刑法》条款 |
| 不给「操作建议」只给「正确路径」 | 例如不教怎么「洗白征信」，只教怎么报警和申诉 |
| 明确区分「民事」和「刑事」 | 很多学生不知道自己做的事已经跨过刑事线 |

**特别提醒**：03-05 和 03-06 是本项目全部 128 篇里最需要认真写的两篇。它们可能导致读者少坐几年牢。

## 03-01 一个月生活费怎么分配

**一句话定位**：理财的起点不是投资，是知道钱去哪了。

**核心结论**
1. 第一个月唯一要做的事是**记账**，不是省钱
2. 生活费的三分法：固定开销（吃饭/交通/话费）、弹性开销（社交/娱乐）、应急储备
3. **先存应急金，再谈消费**——哪怕每月只存 100 元

**结构骨架**
1. 一句话定位
2. 为什么第一个月不省钱只记账（建立基线）
3. 生活费结构拆解（表格：类别 / 占比参考 / 可压缩空间）
4. 三分法怎么分（给具体比例区间，说明因人而异）
5. **应急金为什么重要**（手机坏了、生病、突然要回家）
6. 记账怎么做（工具不重要，坚持重要；给最简方案）
7. 常见误区
   - 「记账太麻烦」
   - 「我钱少不用管」
   - 把「花呗额度」当收入
8. 风险提醒：不要用借贷产品填补消费缺口 → 详见 03-04
9. 可执行清单（第一个月的 4 个动作）
10. 参考资料 + 核查日期

**必须查证的资料**
- 经验性内容，标注【经验】
- 消费信贷产品的利率披露（如需引用）

**与其他篇的交叉**
- 校园贷 → 03-04
- 银行卡安全 → 03-05

## 03-02 国家助学贷款：生源地 vs 校园地、额度、贴息、还款

**一句话定位**：这是国家给的、利息在校期间由国家出的低息贷款，符合条件不借是吃亏。

**核心结论**
1. **在校期间利息全部由国家贴息**，学生不付利息——这是最关键也最常被误解的一点
2. 分两种：**生源地信用助学贷款**（在户籍地办，主流）和**校园地国家助学贷款**
3. 还款有宽限期，毕业后才开始还本，且利率为同期同档次 LPR 减一定基点

**结构骨架**
1. 一句话定位 + 适用人群
2. **两种贷款的区别**（本篇核心表格）
   - 生源地贷款：办理地点（户籍地县级学生资助管理中心/银行）、时间（暑假）、额度、共同借款人
   - 校园地贷款：办理地点（学校）、时间（入学后）、经办银行
   - 二者的额度是否可叠加（**明确写清，此处易错，需核实**）
3. 额度与利率（必须查当年度文件，给文号）
4. **贴息规则**（单列一节）
   - 在校期间：国家贴息
   - 毕业后：开始计息
   - 继续深造（读研）能否继续贴息
5. 还款规则
   - 还本宽限期（毕业后若干年内只还息不还本）
   - 还款期限（最长多少年）
   - 提前还款
6. 办理流程（生源地贷款的分步指南）
7. 违约后果（**进征信、影响后续贷款**）
8. 常见误区
   - 「贷款要还很多利息」（在校期间不付息）
   - 「家里不算特别困难就不能办」
   - 「办贷款影响以后买房」（按时还款不影响征信，需准确表述）
9. 风险提醒：**警惕「助学贷款代办」中介**，办理不收费
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**（来源要求最高）
- 《关于调整完善国家助学贷款有关政策的通知》（找最新文号与额度）
- 全国学生资助管理中心关于生源地助学贷款的说明
- 国家开发银行生源地助学贷款办理指南

**已确认与待核实**
- ✅ 在校期间国家贴息，是既有政策
- ⚠️ **额度近年多次上调，必须查当年度文件，严禁沿用旧数字**
- ⚠️ 生源地与校园地额度能否叠加**需核实**，勿凭印象写
- ⚠️ 共同借款人条件各银行/地区有差异

**与其他篇的交叉**
- 困难认定 → 01-10（前置）
- 绿色通道 → 01-02（先报到后办贷款也可）
- 征信 → 03-04

**政策适用性声明必须包含**
- 依据文件（含文号）
- 全国统一 / 地方执行：**制度全国统一，经办银行与流程地方执行**
- 核查日期

## 03-03 助学金与勤工助学：能拿多少、怎么申请、有没有副作用

**一句话定位**：不用还的钱和用时间换的钱，两条路都别错过。

**核心结论**
1. 国家助学金是**无偿资助**，不需要偿还，按困难认定档次发放
2. 勤工助学是**校内岗位**，按小时计酬，有时间上限（保障学业）
3. 两者**可以同时拿**，与助学贷款也不冲突

**结构骨架**
1. 一句话定位
2. 三条资助线对比（表格：名称 / 性质 / 要不要还 / 前置条件）
   - 国家助学金（无偿）
   - 勤工助学（劳动报酬）
   - 助学贷款（需偿还）
3. 国家助学金
   - 分档（一般分 2–3 档）
   - 谁能拿（需困难认定）
   - 发放方式与时间
   - 金额（查当年度文件）
4. 勤工助学
   - 岗位类型（图书馆、实验室、行政助理、助教）
   - 计酬标准（**有国家规定的时薪下限参考，需核实**）
   - 时间限制（每周不超过多少小时，需查规定）
   - 怎么申请（学工部/资助中心）
5. 两者能否叠加（可以）
6. 常见误区
   - 「拿助学金会被同学知道」（隐私保护要求）
   - 「勤工助学工资很低不值得」（在校内、安全、有保障）
7. 风险提醒
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 《普通高等学校国家助学金管理办法》
- 《高等学校勤工助学管理办法》（教育部/财政部，找文号与时薪规定）

**已确认与待核实**
- ✅ 助学金无偿、勤工助学有国家层面管理办法
- ⚠️ 金额、分档、时薪标准需查当年度文件与本校细则

**与其他篇的交叉**
- 困难认定 → 01-10
- 兼职（校外） → 04-01（校外兼职不构成劳动关系，校内勤工助学是另一回事）

## 03-04 校园贷与「套路贷」：如何识别、已经借了怎么办

**一句话定位**：借的时候觉得只是几千块，还的时候发现是一辈子的事。

**核心结论**
1. **任何面向在校学生、无需抵押、快速放款的「校园贷」都是高危产品**，监管已明令禁止相关业务
2. 「套路贷」本质是诈骗：通过砍头息、虚增债务、恶意制造违约让债务滚雪球
3. 已经借了不要躲——**越躲越糟**，正确做法是保留证据 + 报警 + 告知家人

**结构骨架**
1. 一句话定位（高危篇目）
2. 校园贷的几种形态（表格：形态 / 特征 / 风险点）
   - 传统校园网贷
   - 培训贷（报名先贷款）
   - 医美贷 / 分期
   - 套路贷（本质是诈骗）
   - 裸贷（涉及敲诈勒索、传播淫秽物品）
3. **识别特征清单**（本篇最实用）
   - 不看还款能力、当天放款
   - 砍头息（借 1 万到手 8 千）
   - 要求提供通讯录、裸照、身份证照片
   - 合同金额与实际到手不符
   - 违约金条款畸高
4. **已经借了怎么办**（分情况给路径）
   - 正规持牌机构的贷款：协商还款、申请展期
   - 套路贷：立即报警（这是刑事案件，不是民事纠纷）
   - 被威胁催收：报警、保留证据、不还违法部分
5. 法律定性：超过法定利率上限的部分不受保护（需引用现行司法解释的利率规定）
6. 暴力催收的应对（报警、举报至监管部门）
7. 常见误区
   - 「借一点点很快还上」
   - 「不还就没事」（会影响征信，或招致催收）
   - 「告诉家里就完了」（隐瞒才是真的完了）
8. 风险提醒：**不要借新还旧**
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 银保监会等关于禁止校园贷业务的通知（找文号）
- 最高人民法院关于民间借贷利率的司法解释（现行版本）
- 《刑法》中诈骗罪、敲诈勒索罪相关条款

**已确认与待核实**
- ✅ 监管明令禁止向在校学生开展网贷业务（需核实具体文件与文号）
- ⚠️ **借贷利率司法保护上限的规定有调整**，必须查现行有效版本
- ⚠️ 催收行为的合法性边界需引用相关规定

**与其他篇的交叉**
- 征信 → 03-05
- 被骗后处理 → 07-13
- 培训贷 → 04-03

## 03-05 银行卡与支付安全：一人多卡清理、帮人过账的法律风险

**一句话定位**：把银行卡借给别人用一次，可能就是刑事案件的起点。

**核心结论**
1. **出借、出售、出租银行卡/支付账户**，可能构成帮助信息网络犯罪活动罪或掩饰、隐瞒犯罪所得罪
2. 即使不知情，只要客观上为犯罪提供了支付帮助，也可能被追究
3. 「断卡行动」下，涉案账户会被**惩戒**（五年内不能开新卡、不能使用非柜面业务）

**结构骨架**
1. 一句话定位（高危篇目）
2. 常见场景（这些事你可能真遇到过）
   - 同学说「帮我收个款，马上转走」
   - 网上「高价收卡」「租卡刷流水」
   - 兼职「代收款赚佣金」
   - 亲戚借你的卡过账
3. **法律后果**（本篇核心，分三层讲）
   - 刑事：帮信罪（《刑法》第二百八十七条之二）的构成与量刑
   - 刑事：掩饰、隐瞒犯罪所得罪（情节更重时）
   - 行政/金融：断卡惩戒（五年内限制开卡与非柜面业务）
4. 「不知情」能不能免责（讲清主观明知的推定规则）
5. 一人多卡怎么清理（查名下账户的方法）
6. 日常用卡安全（密码、免密支付、境外交易开关）
7. 常见误区
   - 「我只是借一下，又没诈骗」
   - 「我不知道是赃款」
   - 「卡里没钱就没事」
8. 风险提醒：**已经出借了怎么办**（立即挂失、报警、保留聊天记录）
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《中华人民共和国刑法》第二百八十七条之二（帮信罪）
- 两高关于帮信罪的司法解释
- 断卡行动相关部委通知
- 中国人民银行关于账户分类管理的规定

**已确认与待核实**
- ✅ 帮信罪已入刑，且学生群体涉案比例较高（引用时需给出处）
- ⚠️ 司法解释对「明知」的认定有具体标准，需引用原文
- ⚠️ 惩戒措施的具体年限与范围需查最新规定

**与其他篇的交叉**
- 03-06 帮信罪（**两篇高度关联，03-05 讲场景与用卡安全，03-06 专讲罪名构成，需明确边界避免重复**）
- 个人信息泄露 → 11-03

**边界划分**

## 03-06 「帮信罪」离大学生有多近

**一句话定位**：这是当前大学生最容易在完全无感的情况下触犯的罪名。

**核心结论**
1. 帮信罪（帮助信息网络犯罪活动罪）**不要求你参与诈骗**，提供支付、通讯、技术支持即可构成
2. 学生涉案的典型形态：卖卡、跑分、代收款、提供账号
3. 判定关键在于**「明知」的推定**——不是你说不知道就没事

**结构骨架**
1. 一句话定位（全项目最高危篇目）
2. 法条原文与构成要件（引用《刑法》第二百八十七条之二）
   - 明知他人利用信息网络实施犯罪
   - 提供技术支持 / 广告推广 / 支付结算等帮助
   - 情节严重
3. 「明知」怎么认定（司法解释列举的情形，逐条讲清）
4. 学生的五种典型涉案形态（每种给「怎么做」和「后果」）
   - 出售/出租银行卡、电话卡
   - 跑分（帮人代收款、转账赚佣金）
   - 提供微信/支付宝账号
   - 帮忙注册公司、开对公账户
   - 提供技术支持（开发外挂、搭建平台）
5. 「情节严重」的标准（司法解释的具体门槛，如支付结算金额、流水金额）
6. 量刑与后果（刑事处罚 + 惩戒 + 对学业和就业的影响）
7. **真实案例的写法**（不编案例！引用公开裁判文书或官方通报，标明来源）
8. 常见误区（逐条破除）
9. 已经涉案怎么办（立即停止、保留证据、主动投案、聘请律师）
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《中华人民共和国刑法》第二百八十七条之二
- 《最高人民法院、最高人民检察院关于办理非法利用信息网络、帮助信息网络犯罪活动等刑事案件适用法律若干问题的解释》（找文号）
- 公开的裁判文书或检察机关发布的学生涉案通报（用于案例）

**已确认与待核实**
- ✅ 帮信罪的法条与司法解释存在且现行有效
- ⚠️ **「情节严重」的具体金额门槛必须查司法解释原文**，不可凭印象
- ❌ **绝对不编造案例**。若找不到可引用的公开案例，就只讲构成要件与形态，不写故事

## 03-07 学费代偿与基层就业补偿

2. 都有**服务年限要求**（通常 3 年以上）和**地区/岗位限定**
3. 申请有严格时限，**过期不补**

**结构骨架**

5. 公费师范生 / 定向医学生（履约义务与违约后果）
6. 申请流程与材料
7. 常见误区（「随便找个基层工作就行」）
8. 风险提醒：违约要退还并可能付违约金
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**

- 基层就业代偿的具体实施办法

## 03-08 学生票、交通优惠、青年旅社

**一句话定位**：你手里那张学生证，能省的钱比你以为的多。

**核心结论**
1. 学生票优惠有**次数和区间限制**（每学年 4 次，家庭至学校区间）
2. 优惠资质需要**每学年核验**，否则买不了
3. 除了交通，还有景区、博物馆、影院的优惠

**结构骨架**
1. 一句话定位

## 03-09 第一次买大件（电脑、手机、相机）

**一句话定位**：大学四年最贵的一次消费决策，别让它在开学第一周匆忙做完。

**核心结论**
1. **先定需求再定预算**，不要反过来
2. 开学季是价格高点（不是低点），促销话术最多
3. 售后和保修比参数更重要（尤其电脑）

4. **电脑**（本篇重点）

   - 轻薄本 vs 游戏本 vs 台式
   - 保修与售后（校园维修点、上门服务）

## 03-10 校园里的「代理」和「分销」

**一句话定位**：看起来是赚零花钱，实际可能是替别人背风险。

**核心结论**
1. 校园代理常见三类：**正规品牌推广**、**层层发展下线的分销**、**本质是诈骗的拉人头**
2. 涉及「先囤货」「先交保证金」「发展下线」的，**风险极高**
3. 以自己的名义替别人签约或收款，法律责任在你身上

**结构骨架**
1. 一句话定位
2. 三类校园代理的辨别（表格：类型 / 特征 / 风险）
3. 正规推广的特征（有品牌背书、不收费、不囤货）
4. **高危信号**（本篇核心清单）
   - 要求先交代理费/保证金
   - 要求囤货
   - 收益主要来自发展下线
   - 要求用自己身份证注册
5. 「分销」的法律边界（是否构成传销的判定）
6. 以自己的名义替人办卡、注册公司的后果
7. 常见误区（「同学介绍的不会坑我」）
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 《禁止传销条例》
- 传销与直销的区分（市场监管总局说明）

**与其他篇的交叉**
- 兼职骗局 → 04-03
- 帮信罪 → 03-06

## 03-11 医保怎么用：报销流程、门诊住院、异地就医备案

**一句话定位**：制度看 07-01，这篇讲真到了医院该怎么走完流程。

**核心结论**
1. **先备案、再就医**，异地就医不备案报销比例会大幅降低
2. 门诊和住院的报销规则不同，**起付线和封顶线是两回事**
3. 校医院通常是首诊点，转诊规则要提前了解

**结构骨架**
1. 一句话定位（明确本篇是「操作篇」，制度看 07-01）
2. 报销的基本逻辑（起付线 → 报销比例 → 封顶线，用图示讲清）
3. **门诊怎么报**（校医院首诊、转诊、直接结算）
4. **住院怎么报**（入院登记、出院结算、需要什么材料）
5. **异地就医备案**（本篇重点）
   - 什么情况需要备案（寒暑假回家、实习地就医、转诊）
   - 怎么备案（国家医保服务平台 App、当地医保局）
   - 不备案的后果
6. 自费项目和自付部分的区别
7. 报销材料清单
8. 常见误区
   - 「有医保就不用花钱」
   - 「先看病后补备案也行」
   - 「异地就医和本地一样报」
9. 风险提醒：**保留所有票据和病历**
10. 可执行清单（就医前/就医时/就医后）
11. 参考资料 + 核查日期

**必须查证的资料**
- 国家医保局关于异地就医直接结算的规定
- 本校参保地医保政策（报销比例、起付线）

**已确认与待核实**
- ✅ 异地就医需备案，不备案降低报销比例（通行规则）
- ⚠️ **具体比例、起付线各统筹地区不同**，必须写明「以参保地政策为准」

**与其他篇的交叉**
- 制度篇 → 07-01（**本篇不重复讲参保和缴费**）
- 就医选择 → 07-02

## 03-12 一卡通/校园卡丢了、被盗刷、余额怎么退

**一句话定位**：丢卡不可怕，可怕的是不知道先干什么。

**核心结论**
1. 第一动作是**挂失**（线上最快），不是找卡

3. 毕业时卡内余额有退费流程，别忘了

**结构骨架**
1. 一句话定位
2. 卡丢了的三步：挂失 → 补办 → 转移余额
3. 挂失渠道（App、自助机、卡务中心）
4. 被盗刷怎么办（查消费记录、报卡务中心、必要时报警）
5. 补办流程与费用
6. 毕业退费（余额、押金、热水卡）
7. 常见误区
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 本校卡务中心说明（各校不同）

**与其他篇的交叉**
- 无强关联
