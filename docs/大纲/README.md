> 本目录存放 12 个分类的逐篇写作大纲。核查日期：2026-11-04。
>
> **怎么用**：动笔前先看对应分类的大纲文件，确认每篇要讲什么、讲到哪里为止、和哪篇有交叉。大纲定稿后再写正文，避免写到一半发现和别的篇目重复。

## 一、写作顺序

你指定的顺序是按分类号推进，从 01 到 12。这与 `docs/04-首批20篇写作顺序.md` 的「风险优先」排序不同，两者不冲突：

| 用途 | 依据 |
| --- | --- |
| **实际动笔顺序** | 01 → 12 逐分类推进（你指定的） |
| **首批 20 篇的高价值清单** | `docs/04-首批20篇写作顺序.md`（法律、医保、三方协议等） |

按分类推进时，如果某个分类里恰好有 P0 篇目，优先写那几篇，写完再补同分类的 P1、P2。

## 四、每份大纲包含什么

为了让每篇都能直接照着写，大纲里每篇给出：

1. **一句话定位**：这篇解决什么问题，一句话
2. **核心结论**：读者看完必须记住的 2–3 条
3. **结构骨架**：这篇分几节，每节写什么
4. **必须查证的资料**：动笔前要先去找的官方来源（写清去哪个网站找）
5. **已确认与待核实**：写作时哪些能直接用、哪些必须重新核
6. **与其他篇的交叉**：和哪几篇会重叠，边界怎么划
7. **可执行清单**：这篇最终要产出的清单长什么样

## 四、全局写作纪律

写任何一个分类前，先记住这几条（详见 `docs/03-内容质量审核标准.md`）：

- **不编数字**：所有金额、比例、期限必须有来源，否则写「以当地/本校实际为准」
- **不混层级**：全国规定、省级规定、学校规定，是三层不同的东西，必须说清是哪一层
- **不把经验当结论**：个人经历标【经验】，不写成「都是这样」
- **政策必须带文号**：找不到文号就标【待核实】，不假装核实过
- **每篇结尾写「最后核查日期」**
