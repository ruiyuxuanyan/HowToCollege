# 09 求职与就业 · 逐篇写作大纲

> 分类定位：三方协议、应届生身份、校招骗局、试用期——从校招到入职。
> 适用人群：大三、大四、应届毕业生。
> 核查日期：2026-11-04。

## 分类级判断

这个分类的核心矛盾是：**每年政策都在变，但网上的经验帖停在几年前**。

两个最关键的事实（本研究阶段已核实）：

1. **应届生身份的认定正在放宽**：多省份已将认定范围从「毕业当年」拓展至「离校 2 年内未就业」，并取消社保缴纳等门槛，但**各省口径不一**
2. **报到证已取消**：这直接改写了毕业手续流程，网上大量流程文已过时

所以本分类的写作纪律：

| 纪律 | 说明 |
| --- | --- |
| **必须查当年度政策** | 应届生认定、报到证、三方协议的规定每年可能调整 |
| **必须声明地域差异** | 应届生身份认定**按省份不同**，不能写「全国统一」 |
| **区分「劳动法」与「校招惯例」** | 三方协议是民事协议，不是劳动合同 |
| **不写「求职技巧」** | 那是另一个赛道，本项目只写规则与风险 |

## 09-01 三方协议是什么

**一句话定位**：它是一份有违约金的民事协议，不是劳动合同，也不是「意向书」。

**核心结论**
1. 三方协议是**毕业生、学校、用人单位**三方的就业协议，属于**民事协议**（不是劳动合同）
2. **违约金条款是真实的**，签了毁约要付钱
3. 三方协议**不能替代劳动合同**，入职后还要签劳动合同

**结构骨架**
1. 一句话定位
2. 三方协议到底是什么（三方是谁、性质、用途）
3. **与劳动合同的区别**（本篇核心表格）
   - 签约主体
   - 法律性质（民事协议 vs 劳动合同）
   - 违约金（三方可以有，劳动合同除两种情形外不得约定）
   - 签订时间
   - 效力
4. 违约金条款（常见金额、什么情况要赔、能不能谈）
5. 签约流程（学校就业系统、纸质三方、网签）
6. **毁约怎么办**（本篇最实用）
   - 与单位协商解除
   - 支付违约金
   - 学校重新发放新三方的流程
7. 三方协议与「两方协议」、offer letter 的区别
8. 常见误区
   - 「三方就是劳动合同」
   - 「签了不去也没事」
   - 「学校会帮我兜底」
9. 风险提醒
10. 可执行清单（签约前核对表）
11. 参考资料 + 核查日期

**必须查证的资料**
- 《普通高等学校毕业生就业工作暂行规定》（如有）
- 教育部关于高校毕业生就业协议的规定
- 《劳动合同法》第二十五条（违约金限制）

**已确认与待核实**
- ✅ 三方协议为民事协议，违约金有效
- ⚠️ 各校发放/补发三方的流程不同
- ⚠️ 部分地区已推行网签，需核实

**与其他篇的交叉**
- 应届生身份 → 09-06
- 劳动合同 → 10-03、09-11
- 毕业手续 → 10-01

## 09-02 秋招春招时间线与准备

**一句话定位**：校招是有窗口的，错过时间点，再优秀也进不去。

**核心结论**
1. 秋招（9–11 月）是主战场，春招（次年 3–5 月）是补录
2. 互联网/金融等行业**提前批在 6–8 月**就开始
3. 时间线每年略有浮动，**以目标企业官方公告为准**

**结构骨架**
1. 一句话定位
2. 校招全年时间线（表格：时间 / 阶段 / 该做什么）
3. 秋招 vs 春招的差异（岗位数量、竞争强度、心态）
4. 提前批（暑期实习转正、提前批招聘）
5. 准备清单（简历、作品集、笔试、面试）
6. 多条线并行的策略（考公、考研、求职如何不互相拖累）
7. 常见误区
8. 可执行清单（倒推时间表）
9. 参考资料 + 核查日期

**与其他篇的交叉**
- 简历 → 09-09
- 考研抉择 → 02-07

**写作提醒**：时间线每年变化，本篇标 **⏳ 易过时**，且必须写「以企业官方公告为准」，不写死具体日期。

## 09-03 校招常见骗局：内推收费、培训贷、假 offer

**一句话定位**：求职季是骗子的丰收季，因为他们知道你现在最急。

**核心结论**
1. **正规内推不收费**，收费内推一律是骗局或无效服务
2. **任何要求先交钱的「入职」都是骗局**（培训费、体检费、服装费、押金）
3. 假 offer 的常见目的：套取个人信息、骗取「保证金」、拉人做违法业务

**结构骨架**
1. 一句话定位
2. 六类校招骗局（表格：类型 / 话术 / 识别点）
   - 收费内推
   - 培训贷（入职前先培训）
   - 假 offer（套信息、收保证金）
   - 假实习（免费劳动力）
   - 挂靠/代缴社保
   - 境外高薪（→ 09-08）
3. **正规招聘的特征**（本篇核心清单）
   - 不收费
   - 有明确的公司主体（可查工商信息）
   - 面试流程完整
   - offer 有正式抬头与联系方式
4. 怎么核实一家公司（国家企业信用信息公示系统）
5. 个人信息保护（身份证、学历、银行卡什么时候才该给）
6. 已经上当了怎么办
7. 常见误区
8. 风险提醒
9. 可执行清单
10. 参考资料 + 核查日期

**与其他篇的交叉**
- 兼职骗局 → 04-03
- 境外招聘 → 09-08
- 个人信息 → 09-10

## 09-04 实习转正与背景调查：简历能不能美化

**一句话定位**：美化到「编造」的程度，代价可能是 offer 作废。

**核心结论**
1. 背景调查主要查：**学历、工作经历、离职原因、有无竞业限制**
2. **虚构学历、虚构工作经历**是最高危的两项，一旦查出通常直接取消录用
3. 适度包装（措辞、突出成果）与编造（造假）是两回事

**结构骨架**
1. 一句话定位
2. 实习转正的关键因素
3. 背景调查查什么（表格：项目 / 怎么查 / 造假后果）
4. **什么算美化、什么算造假**（本篇核心，给判断标准）
5. 学历造假的具体后果（学历认证可查、可能涉及欺诈）
6. 已被查出怎么办
7. 常见误区
8. 风险提醒
9. 可执行清单

## 09-05 面试中的劳动法问题：能不能问婚育

**一句话定位**：有些问题不该问，被问了你可以不答。

**核心结论**
1. 招聘中**不得以性别为由拒绝录用或提高标准**（《妇女权益保障法》）
2. 询问婚育状况在实践中普遍存在，但**不得作为录用条件**
3. 遇到歧视性提问，可以拒绝回答并保留证据

**结构骨架**
1. 一句话定位
2. 不该问的问题类型（婚育、民族、宗教信仰、健康状况与岗位无关部分）
3. 法律依据（《劳动法》《就业促进法》《妇女权益保障法》）
4. **被问了怎么应对**（本篇核心：给话术与策略）
5. 遭遇就业歧视怎么维权（投诉、诉讼）
6. 背景调查与体检的合法边界
7. 常见误区
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 《就业促进法》第三条、第二十七条等
- 《妇女权益保障法》关于就业歧视的条款（**2022 年修订后有强化，需核实条款**）

## 09-06 应届生身份到底怎么算

**一句话定位**：这个身份值一个考公资格、一次校招机会，而它的定义正在变化。

**核心结论**
1. 国家层面：**择业期为二年**，择业期内未落实工作单位的，可按应届毕业生对待
2. **多省份已放宽**：认定范围从「毕业当年」拓展至「离校 2 年内未就业」，并取消社保缴纳等门槛
3. **各省口径不一**，报考前必须查目标省份当年的公告

**结构骨架**
1. 一句话定位（本篇是高危易错篇）
2. 什么是应届生（两个层次：当年应届 vs 择业期内）
3. **国家规定的框架**
   - 择业期二年
   - 「未落实工作单位」的判定（户口、档案、组织关系保留情况）
4. **各省的放宽政策**（本篇核心，必须给具体说明）
   - 认定范围拓展至离校 2 年内
   - 取消社保缴纳等门槛
   - 但**各省不同，且逐年调整**
5. **什么会「弄丢」应届生身份**（签三方并入职、缴纳社保、档案转出）——需谨慎表述，说明各地判定不同
6. 不同用途的认定不同（考公 vs 校招 vs 落户）
7. 怎么查自己的身份（查目标省份公告、问学校就业中心）
8. 常见误区
   - 「交了社保就不是应届生」（**部分地区已取消这一限制**）
   - 「毕业一年就不是了」（择业期二年）
9. 风险提醒
10. 可执行清单（自查步骤）
11. 参考资料 + 核查日期

**必须查证的资料**（本篇来源要求最高）
- 国家公务员局年度考试录用公告中的应届生界定
- 各省人社厅/组织部关于应届生身份的公告
- 教育部关于做好毕业生就业工作的通知

**已确认与待核实**
- ✅ 国家规定择业期为二年；多省已将认定放宽至离校 2 年内未就业，并取消社保门槛（有官方来源，见下）
- ⚠️ **各省口径差异极大且逐年调整，不得写「全国统一」**
- ⚠️ 「社保是否影响应届生身份」**在不同用途下答案不同**，必须分场景说明

**与其他篇的交叉**
- 三方协议 → 09-01
- 毕业手续 → 10-01
- 社保 → 10-04

**政策适用性声明必须包含**
- 依据文件（国家层面 + 省级层面分开列）
- 全国统一 / 地方执行：**框架统一，认定口径地方执行**
- 核查日期
- 已知变化：注明「多省正在放宽」

## 09-07 选调生、三支一扶、西部计划

**一句话定位**：这些项目的门槛、待遇、出路，和你听说的可能不一样。

**核心结论**
1. 三者性质不同：**选调生是公务员**，三支一扶/西部计划是**服务项目**（服务期满有政策优惠）
2. 都有**服务年限**要求，且违约有后果
3. 报考条件各年各省不同，**以当年公告为准**

**结构骨架**
1. 一句话定位
2. 三者的定位对比（表格：项目 / 性质 / 服务期 / 待遇 / 期满出路）
3. 选调生（报考条件、党员/学生干部要求、笔试面试）
4. 三支一扶（支教支农支医扶贫）
5. 西部计划
6. 服务期满的政策优惠（考研加分、定向招录、学费代偿 → 03-07）
7. 违约后果
8. 常见误区
9. 可执行清单
10. 参考资料 + 核查日期

**必须查证的资料**
- 各省选调生公告（每年不同）
- 三支一扶、西部计划的年度实施方案

**与其他篇的交叉**
- 学费代偿 → 03-07
- 应届生身份 → 09-06

## 09-08 兼职与求职中的人身安全：传销、境外高薪招聘

**一句话定位**：有些「工作机会」的真实目的是把你带走。

**核心结论**
1. **「境外高薪、包吃住、无需经验」是典型诈骗特征**，可能是电信诈骗园区
2. 传销的判定特征是**交纳入门费 + 拉人头 + 层级计酬**
3. 一旦被控制，**保持冷静、寻找机会求助、记住位置信息**

**结构骨架**
1. 一句话定位（高危篇目）
2. **境外高薪招聘的骗局链条**（本篇核心）
   - 话术特征
   - 常见目的地
   - 出境后的真实处境
   - 为什么难以脱身
3. 传销的识别（三特征：《禁止传销条例》）
4. 招聘中的其他危险信号（要求独自赴外地、不告知公司地址、面试地点在民宅）
5. **如何保护自己**（出行前告知家人行程、保留公司信息、随时共享位置）
6. 已经被控制了怎么办（记住地标、寻找求助机会、配合但不放弃）
7. 家人发现失联怎么办（报警、使领馆）
8. 常见误区
9. 风险提醒
10. 可执行清单
11. 参考资料 + 核查日期

**必须查证的资料**
- 《禁止传销条例》
- 外交部/公安部关于境外高薪招聘诈骗的提醒
- 12308 领事保护热线（→ 如有出国篇）

**与其他篇的交叉**
- 兼职骗局 → 04-03
- 校招骗局 → 09-03
- 家教安全 → 04-04

**写作提醒**：本篇涉及人身安全，措辞要严肃但不渲染恐怖。重点放在「识别」和「预防」，不做猎奇叙述。

## 09-09 简历与作品集：没有实习经历怎么写

**一句话定位**：没有实习不代表没有内容，关键是会不会把做过的事讲成能力。

**核心结论**
1. 简历的核心是**匹配度**，不是经历数量
2. 没有实习时，**课程项目、竞赛、自学成果、开源贡献**都可以写
3. **不要编造经历**（背景调查会查 → 09-04）

**结构骨架**
1. 一句话定位
2. 简历的基本结构（一页、模块顺序）
3. **没有实习怎么写**（本篇核心，给具体替代素材）
   - 课程项目（怎么写才不像作业）
   - 竞赛
   - 自学项目/开源
   - 学生工作（要写成果不写头衔）
4. 怎么把经历写成「能力证据」（给 STAR 式改写示例）
5. 量化成果的写法
6. 常见问题（GPA 低要不要写、证书要不要列）
7. 常见误区
8. 可执行清单（简历自查表）
9. 参考资料 + 核查日期

## 09-10 求职时的个人信息保护

**一句话定位**：简历投出去之前，先想清楚哪些信息不该给。

**核心结论**
1. 简历阶段**不需要**身份证号、银行卡号、家庭详细住址
2. 这些信息在**正式入职、签合同、办社保**时才需要
3. 信息泄露可能导致**被冒名办卡、被用于诈骗**

**结构骨架**
1. 一句话定位
2. 信息提供的三个阶段（表格：阶段 / 该给什么 / 不该给什么）
   - 投简历
   - 面试
   - 入职
3. **哪些是高风险信息**（身份证号、银行卡、人脸、学历证书原件）
4. 常见索要场景与判断（背景调查要身份证、入职要银行卡、体检要病史）
5. 信息泄露后的止损 → 11-03
6. 常见误区
7. 可执行清单

## 09-11 试用期与劳动合同：签之前必须确认的 8 件事

**一句话定位**：签合同前的十分钟，决定你未来一年的处境。

**核心结论**
1. **试用期有法定上限**（按合同期限分档），超出部分无效
2. 试用期工资**不得低于**本单位相同岗位最低档工资或合同约定工资的 80%，且不低于当地最低工资
3. **除两种法定情形外，用人单位不得与劳动者约定违约金**

**结构骨架**
1. 一句话定位
2. **签前必须确认的 8 件事**（本篇核心清单）
   - 合同期限与试用期是否匹配
   - 试用期工资是否合规
   - 工作内容与地点
   - 工时制度（标准/综合/不定时）
   - 社保是否缴纳、何时开始
   - 违约金条款是否存在（除服务期、竞业限制外无效）
   - 工资构成与发放日
   - 是否有「自愿放弃社保」条款（无效）
3. **试用期的法定上限**（表格：合同期限 / 试用期上限）
4. 试用期能不能随便辞退（不能，需证明不符合录用条件）
5. 不签书面合同的后果（双倍工资）
6. 常见误区
7. 风险提醒
8. 可执行清单
9. 参考资料 + 核查日期

**必须查证的资料**
- 《劳动合同法》第十九条（试用期期限）、第二十条（试用期工资）、第二十五条（违约金限制）、第八十二条（双倍工资）

**与其他篇的交叉**
- 劳动合同详解 → 10-03（**边界：09-11 聚焦试用期，10-03 讲合同全貌**）
- 三方协议 → 09-01

## 09-12 考研 vs 考公 vs 就业

**一句话定位**：三条路的时间成本不同，混着准备的代价最高。

**核心结论**
1. 三者的**准备周期、考试时间、失败后的退路**完全不同
2. 考公与考研的时间高度重叠（都在年底），**几乎无法同时全力准备**
3. 决策应基于**目标岗位的硬性要求**，不是「哪个更稳」

**结构骨架**
1. 一句话定位
2. 三条路的完整对照（表格：准备周期 / 考试时间 / 成本 / 失败后）
3. 时间冲突分析（考公国考 11–12 月，考研 12 月，秋招 9–11 月）
4. 可以并行的组合（哪些能兼、哪些不能）
5. 怎么根据目标岗位倒推（查招聘公告的学历/身份要求）
6. 常见误区
7. 可执行清单（决策表）
8. 参考资料 + 核查日期

**与其他篇的交叉**
- 考研还是就业 → 02-07（**边界：02-07 面向在校生的方向选择，09-12 面向大四的具体安排与时间冲突**）
- 应届生身份 → 09-06
