# 首批 20 篇写作顺序

> 本文是第一阶段规划文档之一。核查日期：2026-11-04。

## 一、排序逻辑

首批 20 篇不按分类顺序写，按**下面四个条件依次筛选**：

1. **能不能立刻救人一命或一笔钱**：法律、健康、诈骗类优先
2. **是否每个学生都会遇到**：覆盖面 5 分的优先
3. **网上能不能查到正确答案**：越查不到越优先（这是本项目的核心价值）
4. **能不能为其他文章打地基**：比如「大学生医保」会成为多篇文章的引用源

排除项：

- 需要调研本校具体规定的（如「选课怎么选」），先跳过——这类内容无法通用
- 时效性太强、明年就变的（如「秋招时间线」），放后面
- 纯兴趣向、低风险的（如「假期留校」），放后面

## 三、为什么不是先写「大学入门」

一个自然的疑问：既然是大学生指南，为什么不从入学写起？

三个理由：

1. **入学类内容供给充分**：报到清单、军训、宿舍关系，各校新生手册和网上文章已经很多，本项目做不出明显增量
2. **风险不对等**：忘了带东西可以补，签错合同、卖掉银行卡、借钱不还，代价完全不同
3. **建立信任需要硬内容**：项目初期最需要的是「这篇文章真的帮到我了」，而不是「这篇写得很全面」

入学类内容放在第四梯队，且只挑「有制度性盲区」的两篇（绿色通道、防骗）。

## 四、首批完成后的验收

20 篇写完后，检查三件事：

| 检查项 | 标准 |
| --- | --- |
| 是否真的可执行 | 每篇至少有一个读者能立刻照做的动作清单 |
| 来源是否站得住 | 每篇的【法规】【官方】来源全部可访问，政策有文号 |
| 是否形成引用网络 | 至少 5 篇被其他文章引用，避免每篇都自成孤岛 |

如果 20 篇里超过 3 篇出现「查不到权威来源、只能标待核实」的情况，说明这个选题需要重新界定范围，而不是硬写。
