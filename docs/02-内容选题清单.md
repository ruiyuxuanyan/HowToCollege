## 一、编号与优先级说明

### 编号规则

`分类号-序号`，如 `03-07` 表示第 3 类「金钱管理」的第 7 篇。

### 评分维度（1–5 分）

| 缩写 | 维度 | 5 分意味着 |
| --- | --- | --- |
| 覆 | 覆盖面 | 几乎每个大学生都会遇到 |
| 损 | 损失量级 | 踩坑代价是钱、法律后果或健康安全 |
| 难 | 信息可得性（越难查分越高） | 网上基本查不到，或查到的多是错的 |
| 稳 | 时效稳定性（越不容易过时分越高） | 五年内不会变 |
| 值 | 综合价值 | 四项加权后的结论 |

### 优先级

- **P0**：必须最先写。高频 + 高损失 + 难查
- **P1**：第二批。价值明确但紧迫性稍低
- **P2**：补充完善。有价值但覆盖面或损失量级较低
