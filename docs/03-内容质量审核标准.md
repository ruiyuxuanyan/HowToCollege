# 内容质量审核标准

> 本文是第一阶段规划文档之一。核查日期：2026-11-04。
>
> 这份标准的作用是把「写得好」变成可勾选的动作。每篇指南提交前，必须逐条过一遍，不通过的不得合并。

## 一、来源规范

### 1.1 三级来源标记

每个关键结论后必须标注来源类型。这不是可选项，是硬性要求。

| 标记 | 定义 | 可接受的例子 | 不可接受的例子 |
| --- | --- | --- | --- |
| 【法规】 | 法律、行政法规、部门规章、司法解释原文 | 《中华人民共和国劳动合同法》第十九条 | 「根据劳动法规定」（不给条款号） |
| 【官方】 | 政府部门、高校、公共服务平台发布的政策与办事指南 | 教育部官网、《人力资源社会保障部关于……的通知》（人社部发〔20XX〕X号） | 转载政策的商业网站 |
| 【经验】 | 个人经历、社区讨论、非官方整理 | 知乎高赞回答、贴吧帖、学生访谈记录 | 把经验写成无条件结论 |
| 【待核实】 | 有说法但无可靠来源，或来源互相冲突 | 「各校口径不一，需咨询本校教务处」 | 编一个看起来合理的来源 |

**判定规则：**

- 一条结论如果找不到【法规】或【官方】来源，就必须标【经验】或【待核实】
- 标注【经验】的内容，不得使用「所有学校都」「一般都是」「肯定」这类绝对表述
- 标注【待核实】的内容，必须写明「如何自行核实」的具体方法（打哪个电话、查哪个网站）

### 1.2 优先来源清单

按可信度排序，优先用上面的：

1. 法律法规原文（全国人大网、国务院政策文件库、司法部）
2. 中央部委官网（教育部、人社部、市场监管总局、国家医保局、公安部）
3. 中国政府网 `www.gov.cn`
4. 省级政府部门官网、政务服务网
5. 高校官网（教务处、学工部、就业指导中心、财务处）
6. 公共服务平台（国家医保服务平台、国家企业信用信息公示系统、12333）
7. 学术论文与权威研究报告（仅健康类、心理类需要）
8. 可信赖的专业机构（三甲医院、正规律所、行业协会）

**明确不采信：** 内容农场、无署名营销号、收费求职中介的推广页面、AI 生成的二手解读。

### 1.3 链接与时间

- 每个【法规】【官方】来源必须给**可访问的原始链接**
- 链接旁标明：**发布/更新日期 + 核查日期**
- 优先给**稳定的官方地址**，不给会失效的临时跳转
- 政策类内容必须写明文号（如「人社部发〔2024〕X号」），文号是政策唯一可靠的身份证
- 找不到文号的，标注【待核实】，并说明为什么找不到

## 二、内容真实性检查

### 2.1 五条禁令

任何一条触碰，直接打回重写：

| 禁令 | 说明 | 反例 |
| --- | --- | --- |
| 禁止编造数据 | 不给不出处的数字 | 「90% 的大学生都遇到过」（无来源） |
| 禁止编造政策 | 不虚构不存在的补贴、流程、规定 | 凭空写一个不存在的申请渠道 |
| 禁止编造案例 | 不虚构「某同学」「某校学生」当论据 | 「我一个朋友就被骗了 2 万」 |
| 禁止伪造文献 | 不编标题、作者、DOI、文号 | 编一个看起来很正规的文件名 |
| 禁止以偏概全 | 不把个别学校/地区规定写成全国统一 | 「全国高校都要求……」（实际各校不同） |

### 2.2 数字的使用

- 有出处的数字，标明出处和统计年份
- 范围类数字写清口径（如「按 2025 年度标准」）
- 换算类数字（如「每月约合 X 元」）必须给出算式或原始数值
- **宁可写「约」「视地区而定」，也不要给一个看起来精确但无来源的数字**

### 2.3 个人经验的正确用法

个人经验不是不能用，但用法有严格限制：

✅ 正确用法：

> 【经验】有学生反馈，部分学校在报到当天才通知体检，容易与体检机构的工作时间冲突。建议提前向辅导员确认体检安排。
>
> 【待核实】以上为个别学校的情况，请以本校通知为准。

❌ 错误用法：

> 大学报到当天会要求体检，一定要注意时间。
> （把个别情况写成普遍事实）

## 三、文章结构检查

### 3.1 必需元素

每篇文章至少包含：

- [ ] **一句话概括**：30 字内说清这篇解决什么问题
- [ ] **适用人群**：谁需要看（不要写「所有人」）
- [ ] **具体场景**：这个问题真实发生在什么时候、什么情况下
- [ ] **解决方案**：可执行的方法，不是原则口号
- [ ] **操作步骤**：怎么一步步做（涉及办事流程的必须有）
- [ ] **成本说明**：要花多少钱、多少时间、多少精力
- [ ] **常见误区**：学生通常会怎么想错
- [ ] **参考资料**：带链接和日期
- [ ] **最后核查日期**

### 3.2 可选元素（按主题决定）

- 风险提醒（涉及钱、法律、安全时**必须**有）
- 实用清单（可复制执行的清单）
- 表格对比（多个选项做选择时）
- 地区差异说明（政策类**必须**有）

### 3.3 政策类文章附加要求

标题或开头必须有一个「政策适用性声明」块：

```
> **政策适用范围**
> - 依据文件：《XXX》（文号）
> - 全国统一 / 地方执行：地方执行，以各省/各校实际为准
> - 核查日期：2026-11-04
> - 已知变化：XXX 政策 2027 年起调整
```

## 四、写作风格检查

| 要求 | 说明 |
| --- | --- |
| 自然中文 | 不写「综上所述」「值得注意的是」这类论文腔套话 |
| 动词开头 | 条目标题尽量以动作开头，让读者知道要做什么 |
| 不制造焦虑 | 不写「再不注意就完了」「99% 的人都不知道」这类标题党句式 |
| 不灌水 | 不为了凑长度重复表达同一件事 |
| 具体优于抽象 | 不写「要合理规划财务」，写「每月 1 号先把 X 元转到单独账户」 |
| 承认不确定 | 不知道就写不知道，写清怎么去确认 |
| 可被搜索 | 文中包含读者会搜的关键词（如「助学贷款 还款 流程」） |

### 禁止的表达

以下表达一律不得出现：

- 「作为一个 AI 助手」「根据我的训练数据」
- 「据不完全统计」（不给来源的托词）
- 「有关部门」（要么写具体部门名，要么标待核实）
- 「大多数人认为」（无来源的民意）
- 「专家表示」（不署名就是没有专家）

## 五、审核流程

每篇指南需经过四道检查：

```
草稿完成
   ↓
① 自查（作者用本标准的清单逐项打勾）
   ↓
② 事实核查（另一个人或另一轮检查，只查来源是否真实可访问）
   ↓
③ 内容审核（是否解决了问题、是否有重复、是否有缺失）
   ↓
④ 合并（更新 CHANGELOG，登记核查日期）
```

### 5.1 事实核查的具体动作

核查不是"再看一遍"，而是逐条验证：

1. 打开每个链接，确认能访问
2. 确认链接内容**确实支持**文中那句结论（不是沾边就算）
3. 确认政策的**文号、发布机构、生效日期**三项都对得上
4. 确认文中没有把「征求意见稿」当「正式文件」用
5. 确认数字与原文一致（不是记忆里的数字）
6. 如果链接失效，要么找替代来源，要么降级为【待核实】

### 5.2 通过标准

- **必需项**全部齐全
- **禁令**零触碰
- **事实核查**零失败
- 无未标注来源的绝对化结论

任何一项不满足，不得合并。

## 六、定期复查

| 内容类型 | 复查周期 | 触发条件 |
| --- | --- | --- |
| 政策类（补贴、报销、办事流程） | 每学年 | 新学年开始、政策文件更新 |
| 法律类（合同、维权、责任） | 每 2 年 | 相关法律修订 |
| 金额类（学费、贷款额度、报销比例） | 每年 | 标准调整 |
| 生活技巧、心理类 | 每 3 年 | 内容明显过时 |
| 数字生活类（App、平台操作） | 每年 | 界面大改、服务下线 |

复查结果记录在 `CHANGELOG.md`，格式：`[复查] 文件名 - 结论（无变化 / 已更新 X 处）`。
