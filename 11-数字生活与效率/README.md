## 分类说明

本分类处理「数字生活与效率」相关的问题。判断一个选题是否属于这里，看它的核心矛盾是不是落在这个范围内。

**交叉情况的处理**：

- 涉及钱但又涉及法律的（如帮信罪、校园贷），正文写在法律类或金钱类，另一处只放索引，**不重复写两遍**
- 涉及健康的政策类内容（如医保报销），制度部分写在 07，操作流程写在 03，两篇互相链接
- 涉及求职的法律问题（如三方协议），主体写在 09，劳动合同的通用条款写在 10

## 怎么贡献这个分类

1. 在 [选题清单](../docs/02-内容选题清单.md) 里找到对应的编号

3. 按 [CONTRIBUTING.md](../CONTRIBUTING.md) 的模板写
4. 文件名格式：`{编号}-{短标题}.md`，例如 `11-01-示例标题.md`
