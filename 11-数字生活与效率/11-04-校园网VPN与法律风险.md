# 校园网、VPN 与国际联网的法律边界

> 一句话概括：技术可行不等于合规，这条边界需要了解。

**适用人群**：使用校园网的学生；接触过 VPN 工具或听说过「翻墙」的人。

> **政策适用范围**
> - 主要依据：《计算机信息网络国际联网管理暂行规定》（国务院 1996 年发布，1997 年修正）、《中华人民共和国网络安全法》（2016 年通过）
> - 全国统一：国际联网应当使用国家公用电信网提供的国际出入口信道；未经批准不得自行建立或使用其他信道
> - 地方执行：校园网使用管理由各校自行规定
> - 核查日期：2026-11-05

## 一、校园网是什么、受什么约束

校园网由学校建设和管理，属于学校提供的网络服务。使用它意味着同时接受两层约束：

| 约束层级 | 来源 | 典型内容 |
| --- | --- | --- |
| 法律层面 | 国家法律法规 | 网络安全、信息内容、国际联网信道管理 |
| 校规层面 | 学校网络使用管理办法、学生管理规定 | 账号实名与不得转借、不得搭建服务、流量与带宽规则、违规处理 |

**校规不是「没有法律效力」的**。学生与学校之间存在教育管理关系，违反校规可能带来纪律处分，这独立于是否违法。

---

## 二、关于国际联网信道的规定

### 2.1 《计算机信息网络国际联网管理暂行规定》

这是与「国际联网」直接相关的最主要行政法规。

**第六条** 的内容大意是：计算机信息网络直接进行国际联网，必须使用邮电部国家公用电信网提供的国际出入口信道。任何单位和个人不得自行建立或者使用其他信道进行国际联网。

**第十四条** 规定了违反上述规定的处理：由公安机关责令停止联网，给予警告，可以并处一万五千元以下的罚款；有违法所得的，没收违法所得。

> **说明**：上述罚款额度是条文原文所载，本文如实引用。但具体适用、裁量以及是否并处其他责任，取决于个案事实与执法机关判断，本文不对任何具体情形作结论。

### 2.2 《网络安全法》

《网络安全法》确立了网络运营与网络使用的基本义务框架，包括网络实名制、网络日志留存、不得从事危害网络安全的活动等。在涉及国际联网的场景中，它是与上述行政法规共同构成规范体系的上一层法律。

**需要说明的是**：本文只陈述《网络安全法》确立的制度框架（网络实名制、网络安全义务、禁止危害网络安全的活动），不引用具体条款序号。该类法律的条文可能经修正而调整，引用前请核对国家法律法规数据库中的现行有效文本。

### 2.3 关于「VPN」这个词的区分

这一点很容易混淆，必须分清：

| 情形 | 性质 |
| --- | --- |
| 企业/机构经批准建立的专用网络，用于内部业务通信 | 有相应审批与合规安排 |
| 学校为师生提供的、用于访问校内学术资源（如数据库、校内系统）的远程访问服务 | 属于校园网服务的延伸，按学校规定使用 |
| 未经批准自行搭建或使用信道进行国际联网 | 属于上述规定所规范的情形 |

**本文讨论的是第三类。** 前两类是合法的、常见的技术安排，与本文主题不同。很多学校提供的「校外访问图书馆数据库」的 VPN，属于第二类，按学校的说明使用即可。

## 三、后果的类型

不做个案预测，只列可能的类型：

| 类型 | 说明 |
| --- | --- |
| 行政处罚 | 依据《计算机信息网络国际联网管理暂行规定》第十四条，可能被责令停止联网、警告、罚款 |
| 校纪处分 | 依本校学生管理规定与网络管理办法，可能涉及警告直至更重的处分 |
| 网络安全事件牵连 | 使用的工具本身可能带来恶意代码、账号被窃、流量被监听等风险 |
| 关联其他责任 | 若在使用中涉及传播违法信息、侵犯他人权益等行为，可能另有法律责任 |

**关于工具本身的风险**（这一条与技术合规无关，是纯粹的安全问题）：

- 免费或来源不明的工具，可能内置恶意程序或窃取账号密码
- 流量经过第三方服务器，可能被记录、篡改
- 支付环节可能泄露银行卡信息
- 部分工具本身就是诈骗载体

这些风险对任何人成立，与是否合规无关。

## 四、校园网的合规使用

这一节是本文最实用的部分——多数人的实际问题不是国际联网，而是日常用网踩了校规。

| 常见行为 | 通常的校规态度 |
| --- | --- |
| 把校园网账号借给校外人员 | 普遍禁止。账号实名到人，他人行为会追溯到账号持有人 |
| 在宿舍搭建路由器/热点共享 | 各校规定不同，很多学校要求报备或禁止【待核实】 |
| 在校园网内搭建对外服务（网站、代理、下载站） | 普遍禁止，需审批 |
| 大量下载/P2P 上传 | 可能触发流量管理，被限速或断网 |
| 在校园网内传播违法或侵权内容 | 违反法律与校规，后果最重 |
| 使用他人账号上网 | 违反实名制要求，双方都可能被处理 |

**关键一点**：校园网账号是实名的。**用你的账号产生的所有流量，记录都指向你。** 无论实际操作的是谁。

所以「借给同学用一下」这件事，风险不在「借」，在「别人拿它做了什么，记录算你的」。

## 五、怎么查本校与本地规定

这是本文能给出的最有用的动作。

| 查什么 | 在哪查 |
| --- | --- |
| 本校网络使用管理办法 | 学校官网「信息化建设」「网络信息中心」栏目；学生手册 |
| 学生违纪处分规定 | 学生手册、学生工作部门官网 |
| 网络安全与信息内容的相关校规 | 同上 |
| 国际联网管理的现行规定 | 国家法律法规数据库（官方） |
| 具体个案的法律咨询 | 执业律师；学校法律援助机构（如有） |

**不要依赖**：网上的经验帖、论坛回答、所谓「内部消息」。这类内容大量过时或臆造，且不适用于你的学校和你的具体情况。

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「技术上能做，就是允许的」 | 技术可行性与合法性是两个判断，不互推 |
| 「我只是看看，不算违法」 | 上述规定规范的是「建立或使用信道」这一行为本身，不以内容为唯一要件 |
| 「学校提供的 VPN 也属于这一类」 | 不是。用于访问校内学术资源的远程访问服务属校园网服务延伸，按学校说明使用 |
| 「换个工具就查不到」 | 本文不讨论规避问题。需要知道的是：不合规就是不合规 |
| 「罚多少钱是固定的」 | 条文规定了上限，具体裁量依个案；本文不作预测 |
| 「大家都在用，所以没事」 | 普遍性不改变合规判断，也不改变个人承担后果的事实 |
| 「借账号给朋友只是帮忙」 | 校园网实名到人，他人行为的记录指向账号持有人 |
| 「用免费工具只是省钱」 | 免费工具的安全风险独立存在：窃密、劫持、诈骗 |

## 七、可执行清单

### 现在就能做

- [ ] 找到本校《网络使用管理办法》与学生手册中相关章节，读一遍
- [ ] 确认自己的校园网账号没有借给他人使用
- [ ] 确认自己没有在校园网内搭建对外提供服务
- [ ] 学校提供校外访问学术资源的服务，按学校说明使用，不另寻途径
- [ ] 检查自己设备上是否安装了来源不明的网络工具，卸载并改密码

### 遇到不确定的情况

- [ ] 问学校网络信息中心，而不是问论坛
- [ ] 涉及法律判断的，咨询执业律师
- [ ] 不以「别人都这样」作为判断依据

## 八、一句话记住
