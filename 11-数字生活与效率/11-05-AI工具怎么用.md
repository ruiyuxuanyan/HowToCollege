# AI 工具怎么用：作业、论文、编程的边界

> 一句话概括：AI 不是不能用，是要知道在什么场合用会出事。

**适用人群**：用 AI 写作业、写论文、写代码的学生；担心被判定学术不端的人。

> **核查日期**：2026-11-07
> ⏳ 易过时：各校 AI 使用规定仍在快速调整，本文只讲判断框架与风险分级，不写任何学校的具体条款。

---

## 一、先接受一个前提：没有全国统一答案

AI 使用的规定，**主要来自两个层面，都不统一**：

| 层面 | 谁定的 | 状态 |
| --- | --- | --- |
| 课程层面 | 任课教师 | 同一所学校不同课程可能完全不同 |
| 学校层面 | 教务处、研究生院、学术委员会 | 各校差异大，且仍在频繁修订 |
| 学术规范层面 | 教育部关于学术不端的规章 | 提供原则，但未对「AI 生成」逐项规定 |

**这意味着**：任何告诉你「AI 作业可以用」或「绝对不能用」的文章（包括本文）都不能替代你本校的现行规定。

**所以第一件事是**：查本校教务处/研究生院官网关于 AI 使用的规定，以及**每门课的课程大纲**——很多老师会在大纲里写明该课程的 AI 政策。

---

## 二、各校的三种典型态度

不做点名，只讲三种已经出现的模式。

| 态度 | 典型表述 | 对学生的影响 |
| --- | --- | --- |
| **① 禁止使用** | 课程/论文不得使用生成式 AI 工具，生成内容视为非本人完成 | 任何使用都可能构成违规，即使只是润色 |
| **② 允许但需申报** | 可以使用，但须在文中或提交时说明用途、工具、范围 | 用了不申报，本身就是违规——即使内容合格 |
| **③ 允许但有范围限制** | 允许用于某些环节（如查资料、改语法），禁止用于其他环节（如生成正文、生成数据） | 需要判断你用的环节是否在允许范围内 |

**第②种最容易踩坑**：很多学生的注意力都在「我写得够不够好」，却忽略了「该申报没申报」。在实行申报制的学校，**未申报使用 AI 本身就是一条独立的违规事由**，与生成质量无关。

---

## 三、风险分级

这张表是本文的核心工具。把自己的用法对上去，判断你处在哪一档。

| 用法 | 风险 | 说明 |
| --- | --- | --- |
| 整段生成，直接提交 | **极高** | 若学校禁止或要求申报，几乎必然构成违规 |
| 生成后改写，但不申报 | **高** | 改写不等于原创；实行申报制的学校，未申报即违规 |
| 让 AI 生成参考文献/引用 | **极高** | AI 会编造不存在文献，这是学术不端中最难辩解的一类 |
| 让 AI 代写论文/毕设 | **极高** | 见 11-11，可能被撤销学位 |
| 生成实验数据或结果 | **极高** | 编造数据属于最严重的学术不端之一 |
| 生成代码，自己理解后重写 | 中 | 视课程规定；编程课普遍对 AI 辅助态度更宽松，但需确认 |
| 让它解释概念、梳理知识框架 | 低 | 属于学习辅助，通常不涉及提交内容 |
| 让它检查语法、翻译、润色 | 低～中 | 若学校要求申报，仍须申报；部分学校视润色为需声明的辅助 |
| 让它出提纲，你自己写全文 | 低～中 | 提纲通常不构成提交内容，但须确认课程规定 |
| 当检索起点，再去查原始来源 | 低 | **推荐的用法**，前提是核实原始来源 |

**一句话判断标准**：**AI 的输出是否直接进入了你要提交的东西？** 越直接、占比越大、越难看出你做了什么，风险越高。

## 四、AI 会编造引用：学生最容易踩的坑

这一节单独讲，因为它最隐蔽、后果最重。

### 4.1 什么是「幻觉」

大语言模型的工作方式是**预测下一个最可能的词**，不是检索数据库。它的目标是生成「看起来像真的」文本，而不是「是真的」文本。

后果：

| 表现 | 具体样子 |
| --- | --- |
| 编造文献 | 作者名、期刊名、年份、卷期、页码全都有，格式完全正确，但文章不存在 |
| 编造法条 | 条款号、内容都像模像样，实际编号对不上 |
| 编造数据 | 给出统计数字与来源，来源无法查证 |
| 错配作者与观点 | 文献真实存在，但内容与转述的不符 |
| 张冠李戴的引文 | 引号里的话确实像某人的风格，但从未说过 |

**最危险的地方**：这些编造的东西**格式完全正确**。你不去逐一核对，根本看不出来。

### 4.2 为什么它会这样

模型没有「查证」这一步。它并不知道自己在编，输出时也没有任何不确定性提示。有时它会自信地说「该文献刊于某期刊第 X 期」，语气与说真话时完全相同。

部分工具会联网检索并给出链接，这能降低但不能消除风险——链接可能失效、可能指向无关内容、可能被摘要误导。

### 4.3 怎么办

| 规则 | 说明 |
| --- | --- |
| **AI 给的任何引用，都必须逐条核实原文** | 在数据库里搜到、打开、读到，才算存在 |
| 不用 AI 直接生成参考文献列表 | 参考文献必须来自你自己读过的文献 |
| 不用 AI 转述你没读过的文献 | 二手转述最容易错配观点 |
| 把 AI 当「检索的起点」而非「结果的来源」 | 让它给你关键词和方向，然后自己去数据库查 |

**核实成本**：一条一条查，比自己写还慢。这恰恰说明——**让 AI 生成文献，是纯粹的负收益**。

## 五、怎么用才相对安全

不写「禁止使用」，写「怎么用不容易出事」。

| 做法 | 为什么安全 |
| --- | --- |
| 当检索起点：问它「这个领域有哪些经典问题/关键词」 | 你自己去数据库验证，输出不进入提交内容 |
| 当解释工具：让它用不同方式讲一个概念 | 理解是自己的，提交的仍是自己的表述 |
| 当检查工具：让它指出逻辑跳跃、表述不清 | 你判断是否采纳，改的是自己的文字 |
| 当反方：让它质疑你的论点 | 帮你发现漏洞，不替你写 |
| 当翻译/语法辅助（且按校规申报） | 不改变你的观点与结构 |

**核心心法**：**把 AI 放在「你和他讨论」的位置，不放在「他替你做」的位置。**

一个实用的自检问题：**如果老师当面问你「这段为什么这么写」，你能讲出来吗？** 讲不出来，就是有问题的用法。

## 六、被判定违规的后果

不做个案预测，只列可能的类型。

| 类型 | 说明 |
| --- | --- |
| 课程层面 | 该次作业/论文成绩作废、课程不及格、重修 |
| 学校层面 | 依《高等学校预防与处理学术不端行为办法》等规定，可能给予警告直至开除学籍的处分 |
| 学位层面 | 涉及学位论文的，可能影响学位授予；已授予的学位在特定情形下可被撤销（→ 11-11） |
| 记录影响 | 处分记录可能影响评优、保研、政审、部分就业环节 |
| 追溯性 | 学位论文抽检可在毕业后进行，不因毕业而终结 |

**注意「追溯」这一点**：很多人以为「交上去就过去了」。实际上，本科/硕士毕业论文抽检制度使得毕业后仍可能被抽查；一旦查出，处理的是**已授予的学位**。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「学校没说就是允许」 | 多数学校的原则是「未明确允许即需谨慎」，且很多课在大纲里单独规定 |
| 「我改写了就不算 AI 生成」 | 改写不改变来源；实行申报制的学校，未申报即违规 |
| 「查重能过就没问题」 | 查重比对的是文本相似度，AI 生成的内容是「原创」的，查重根本查不出 |
| 「AI 检测工具能证明我清白」 | AI 检测本身误判率高，既不能作为免罪证据，也不该是唯一判定依据 |
| 「参考文献是 AI 给的，应该没错」 | AI 编造引用是常态，必须逐条核实原文 |
| 「只用来润色，不算使用」 | 多数要求申报的学校把润色也纳入需声明范围，看本校规定 |
| 「大家都在用」 | 普遍性不改变认定，且处分是按个案处理的 |
| 「毕业了就没事了」 | 学位论文抽检可在毕业后进行 |

## 八、可执行清单

### 每次用之前

- [ ] 查这门课的课程大纲/教师说明，确认该课的 AI 政策
- [ ] 查本校教务处/研究生院关于生成式 AI 的现行规定
- [ ] 判断你的用法落在第几档风险（对照第三节表格）
- [ ] 如果学校要求申报，确认申报的格式与提交位置

### 用的时候

- [ ] 不让 AI 输出直接进入提交内容
- [ ] 不让 AI 生成参考文献或数据
- [ ] 保存你的原始稿与修改过程（万一被质疑，这是证据）
- [ ] 记住每一条来自 AI 的线索，事后逐条查原文

### 提交前

- [ ] 逐条核实参考文献：能在数据库里找到、能打开、内容与转述一致
- [ ] 检查是否有未申报的 AI 使用
- [ ] 自查：能否当面讲清每一段的思路来源

### 长期

- [ ] 每学期开学查一次本校 AI 规定有无更新
- [ ] 保留自己各版本的草稿

## 九、一句话记住

**判断标准只有一条：AI 的输出有没有直接进入你提交的东西；另外，AI 给的参考文献一律当假的处理，逐条去数据库核实。**
