# 手机丢了、号被盗了：第一步做什么

> 一句话概括：顺序错了，损失会翻倍。第一件事不是报警，是挂失手机号。

**适用人群**：手机丢失、被盗、被抢的人；怀疑手机号被补卡的人。

> **核查日期**：2026-11-07
> ⏳ 易过时：各运营商、支付平台的挂失流程会调整

---

## 一、为什么第一件事是挂失手机号

**关键事实：你的手机号能收到所有验证码。**

如果你只是锁了手机，但手机号还在用：
- 别人可以取出 SIM 卡插到其他手机
- 收到验证码 → 重置你的微信、支付宝、银行密码
- **短信验证码是最后一道防线，而它就在那张卡里**

所以顺序是：**先断掉验证码，再处理其他。**

---

## 二、手机丢失：30 分钟操作清单

### 按顺序做

| 顺序 | 动作 | 怎么做 |
| --- | --- | --- |
| **1** | **挂失/补办手机号** | 打运营商客服；或用其他设备登录运营商 App |
| **2** | 冻结支付账户 | 微信/支付宝的客服电话或安全中心 |
| **3** | 冻结银行账户 | 银行客服电话或 App |
| **4** | 远程锁定/擦除 | 「查找我的 iPhone」/「查找设备」（安卓） |
| **5** | 改关键账号密码 | 用其他设备登录，改微信、邮箱、社交 |
| **6** | 报警 | 被盗抢的情况；拿到受案回执 |
| **7** | 通知家人朋友 | 防止有人冒充你借钱 |

### 运营商客服

| 运营商 | 客服 |
| --- | --- |
| 中国移动 | 10086 |
| 中国联通 | 10010 |
| 中国电信 | 10000 |

**打电话说什么**：「我的手机丢了，需要紧急挂失/停机。」准备好身份证号。

## 三、如果手机号被冒名补卡

这是更严重的情况——「SIM 交换攻击」。攻击者拿到你的身份信息，冒充你去营业厅补办你的号。

**症状**：
- 手机突然没信号，显示无服务
- 收到「您的 SIM 卡已更换」类短信
- 亲友说你打电话借钱

**怎么办**：

1. **立刻联系运营商**，说明被冒名补卡，要求恢复并冻结
2. **立刻冻结支付和银行账户**
3. **报警**，这属于刑事案件
4. 向运营商要求提供补卡记录（谁、何时、在哪个营业厅）

---

## 四、事前准备（现在就能做）

这一段是本文最有价值的部分——**出事前准备好，能把损失降到最低。**

| 准备 | 为什么 |
| --- | --- |
| 给手机设置锁屏密码 + SIM 卡 PIN 码 | SIM 卡 PIN 码能让别人无法用你的卡 |
| 开启「查找我的设备」 | 能远程定位、锁定、擦除 |
| 记下关键客服电话 | 出事时手忙脚乱找不到 |
| 不在手机相册存身份证照片 | 手机丢失 = 身份信息泄露 |
| 开启二次验证（认证器 App，非短信） | 短信验证可被劫持，认证器不会 |
| 记下几个关键账号 | 主邮箱、微信、支付宝 |

### SIM 卡 PIN 码怎么开

在手机设置里找「SIM 卡锁」或「SIM 卡 PIN」，设置一个 4–8 位 PIN。

**注意**：连续输错会锁卡，需要用 PUK 码解锁（PUK 在办卡时的卡片上，或打客服查）。

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「先报警，警察会处理」 | 挂失更急，验证码风险是分钟级的 |
| 「手机有锁屏密码就安全」 | SIM 卡能取出插到别的手机 |
| 「我马上就能找回手机」 | 按最坏情况处理 |
| 「改了微信密码就行」 | 主邮箱、银行、其他社交都要改 |
| 「不用那么紧张」 | SIM 卡被用于验证码，能造成实际资金损失 |

- [ ] 1. 打运营商客服挂失
- [ ] 2. 冻结微信、支付宝
- [ ] 3. 冻结银行账户
- [ ] 4. 远程锁定/擦除
- [ ] 5. 改关键账号密码
- [ ] 6. 报警（被盗抢）
- [ ] 7. 通知家人朋友

## 七、一句话记住

**先断验证码（挂失手机号），再断钱（冻结支付），最后才是报警和改密码。**
