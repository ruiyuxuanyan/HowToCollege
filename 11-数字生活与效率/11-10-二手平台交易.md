# 二手平台交易：骗局与维权

> 一句话概括：二手交易的风险不在商品，在付款方式。

**适用人群**：在二手平台买卖手机、电脑、教材、票券的学生。

> **核查日期**：2026-11-07
> ⏳ 易过时：各平台规则与申诉入口会调整，本文只写交易原则与识别方法。

---

## 一、唯一需要记住的原则

**绝不脱离平台交易。**

这一条覆盖了绝大多数骗局，因为几乎所有骗局的实现方式，都是把你从有担保的流程里带到无担保的流程里。

| 在平台内 | 在平台外 |
| --- | --- |
| 有交易记录 | 只有聊天截图 |
| 有担保流程（确认收货才放款） | 直接转账，钱一到账就没了 |
| 有平台介入与申诉 | 无可申诉对象 |
| 有实名与评价约束 | 对方可能就此消失 |

**凡是说要「加个微信方便聊」「平台有手续费，直接转给我省点」「让你朋友代付」的，一律按骗局处理。**

真正的买家/卖家不会介意在平台内完成交易。介意的人，通常有理由介意留下记录。

## 二、买家视角的骗局

| 骗局 | 怎么发生 | 识别点 |
| --- | --- | --- |
| **假付款截图** | 对方发一张「已转账」的截图，催你发货 | 平台内的到账记录才是真的；只要平台没显示已付款就是没付 |
| **假链接/假客服** | 发一个「付款页面」链接，实际是钓鱼或收款页 | 不点任何聊天里发来的链接；所有操作在官方 App 内完成 |
| **引导线下转账** | 说平台风控、让你直接转给他 | 一律拒绝，本身就是识别信号 |
| **到手刀（到手砍价）** | 收到货后以各种瑕疵为由要求部分退款 | 发货前全程录像，保留商品状态证据 |
| **恶意退款/仅退款** | 收货后申请「仅退款不退货」 | 平台内申诉，提交发货凭证与沟通记录 |
| **调包退货** | 申请退货，退回来的是别的东西 | 签收退货时当面验货并录像 |
| **货不对板** | 描述与实物不符 | 要求提供实拍图、序列号、购买凭证 |

**关于「假链接」最关键的一点**：任何不在官方 App 内的页面，都不算数。付款只有一个正确的入口，就是你自己的 App。

## 三、卖家视角的骗局

| 骗局 | 怎么发生 | 识别点 |
| --- | --- | --- |
| **假客服** | 有人冒充平台客服，说你的账户异常，要求你操作 | 平台不会通过聊天要你的密码、验证码、转账 |
| **要求你先付「保证金」** | 说买家已付款，你需要先交保证金才能收款 | 正规平台不会这样操作 |
| **引导到第三方支付** | 说平台限额，让你加微信转账 | 拒绝，这就是识别点 |
| **二维码诈骗** | 让你扫一个「收款码」 | 扫别人的码通常是付款不是收款 |
| **余额/账户被套走** | 让你登录某个页面「确认收款」 | 不登录非官方页面 |
| **寄出后失联买家** | 你发了货，对方不确认收货、也不回应 | 平台有自动确认期，但仍要保留发货凭证 |
| **恶意投诉** | 恶意举报你售假，导致账号受限 | 保留购买凭证、发票、实拍图 |

**卖家的核心防线**：**发货前留证。**

## 四、交易安全的具体做法

### 4.1 全程在平台内

| 环节 | 做法 |
| --- | --- |
| 沟通 | 只在平台聊天里聊，不迁到其他工具 |
| 付款 | 只用平台内置的支付流程 |
| 物流 | 用平台提供的寄件方式（有轨迹记录） |
| 售后 | 在平台内发起，不在聊天里私下解决 |

**为什么强调「不迁出聊天」**：平台只采信平台内的聊天记录作为证据。你把沟通迁到别处，等于主动放弃了最重要的证据。

### 4.2 发货前必须留的证据

| 证据 | 怎么做 |
| --- | --- |
| 商品外观与功能视频 | 一次拍完：开机 → 展示外观 → 展示功能 → 展示序列号/IMEI → 装盒 |
| 序列号/IMEI 特写 | 与商品页描述一致，且能唯一识别 |
| 打包过程视频 | 从商品入箱到封箱，一气呵成不剪辑 |
| 快递单号 | 与包裹合影 |
| 聊天记录 | 已确认的商品状态与承诺 |

**这段视频的作用**：对方「到手刀」或声称「收到的是砖头」时，这是你唯一的反证。

### 4.3 面交的注意事项

| 原则 | 说明 |
| --- | --- |
| 选**公共场所** | 地铁站、商场、学校门口、有监控的地方；不去对方住处、不去偏僻地点 |
| **白天** | 避免夜间单独见面 |
| **带同伴** | 尤其是卖高价值物品 |
| **当面验货/验机** | 买家当场检查，确认后再确认收货 |
| **当场完成平台流程** | 不当场收现金了事，走平台确认收货 |
| **不透露过多个人信息** | 不告诉对方你的宿舍号、课表 |

**面交的核心风险不是商品，是人。** 人身安全优先于交易本身。

### 4.4 大件（手机、电脑）额外注意

| 检查项 | 怎么查 |
| --- | --- |
| IMEI / 序列号 | 手机拨号界面可查 IMEI；与包装、系统内信息核对是否一致 |
| 是否被锁 | 检查是否有账号锁、激活锁、企业锁 |
| 是否被报失/盗抢 | 有的平台或官方渠道可查状态；来路不明的低价机风险极高 |
| 电池健康 | 系统设置里可看（部分机型） |
| 维修史 | 看螺丝、屏幕边缘、是否有拆机痕迹 |
| 配件是否原装 | 充电器、数据线的做工 |
| 发票/购买凭证 | 有凭证的机子维权更容易 |

**低价是最大的信号**。「九成新，价格只有市场一半，急出」——要么有问题，要么是骗局的开场。

## 五、出问题后怎么办

| 情形 | 顺序 |
| --- | --- |
| 已付款未收到货 | 平台内申请退款 → 平台介入 → 保留聊天与付款记录 |
| 收到货与描述严重不符 | 平台内发起退货退款 → 提交开箱视频与商品对比图 |
| 对方私下骗走钱 | **报警**（这已不是平台纠纷，是诈骗）→ 同时向平台举报 |
| 卖家拒不处理 | 平台客服介入 → 消费者投诉渠道 |
| 涉嫌诈骗金额较大 | 报警，准备好转账记录、聊天记录、对方账号信息 |

**关键区分**：

- 在平台内交易的纠纷 → 走平台流程
- 被引导到平台外转账的 → 这是**诈骗**，直接报警，平台帮不了你

**关于 12315**：它是市场监管部门的投诉举报渠道，主要处理消费纠纷。二手个人之间的交易是否适用、以及平台责任如何认定，要看具体情况——先走平台流程，必要时再向 12315 或当地市场监管部门咨询。

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「他发了转账截图，应该到账了」 | 截图可伪造，只看平台内的到账状态 |
| 「加个微信聊更方便」 | 迁出平台=失去证据与担保，这是骗局的第一步 |
| 「平台抽成太高，私下转账省点」 | 省下的手续费远小于被骗的损失 |
| 「面交最安全」 | 面交避免了商品纠纷，但引入了人身安全风险，必须选公共场所 |
| 「对方信誉分很高，应该没问题」 | 账号可以买卖，高信誉账号也可能是骗局工具 |
| 「东西便宜是因为急用钱」 | 也可能是赃物或有暗病，低价本身是风险信号 |
| 「金额小，懒得追究」 | 骗子靠的就是这个。小额也报案，累计起来才会被重视 |
| 「平台客服主动联系我，应该是真的」 | 平台不会通过聊天要密码、验证码或让你转账 |

## 七、可执行清单

### 每次交易前

- [ ] 确认全程在平台内完成（沟通、付款、物流、售后）
- [ ] 拒绝任何「加微信/私下转账/扫码付款」的提议
- [ ] 不点聊天里发来的任何链接
- [ ] 核对对方账号的注册时间、评价、历史交易

### 作为卖家发货前

- [ ] 拍一段完整视频：外观 → 功能 → 序列号 → 装盒 → 封箱
- [ ] 序列号/IMEI 特写拍照
- [ ] 保存平台内确认商品状态的聊天记录
- [ ] 用平台提供的物流方式寄出

### 作为买家收货时

- [ ] 当着快递员或录像开箱
- [ ] 核对序列号与描述一致
- [ ] 功能当场测试
- [ ] 确认无误后再在平台确认收货

### 面交时

- [ ] 选公共场所、白天、有监控
- [ ] 带同伴
- [ ] 当面验货
- [ ] 当场走完平台流程，不收现金了事
- [ ] 不透露宿舍号、课表等个人信息

### 出问题后

- [ ] 平台内申诉，附完整证据
- [ ] 被引导到平台外转账的，直接报警
- [ ] 保留所有聊天记录与转账凭证

## 八、一句话记住

**绝不脱离平台：不加微信、不私下转账、不点陌生链接；卖家发货前全程录像，买家收货时当面验货，面交只在公共场所。**
