# 「AI 代写」「代做毕设」的风险与后果

> 一句话概括：花几百块买的东西，可能让你拿不到学位。

**适用人群**：动过找代写念头的人；已经找过、正在焦虑的人；被代写方联系过的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国学位法》（2024 年通过，2025 年 1 月 1 日施行）、《高等学校预防与处理学术不端行为办法》（教育部令第 40 号）
> - 全国统一：代写、买卖学位论文属于学术不端的认定原则；已授予学位可被撤销
> - 地方执行：具体认定程序与处分档次由各校学术委员会依本校规定处理
> - 核查日期：2026-11-05

---

## 一、性质：这不是「买个方便」

先把这个行为定性清楚，因为它不属于「稍微违规」。

| 常见说法 | 实际性质 |
| --- | --- |
| 「找人帮忙写」 | 代写 |
| 「买的模板改一改」 | 买卖 + 抄袭 |
| 「AI 生成的不算别人写的」 | 由他人（或工具）代完成，本人未实质参与 |
| 「只是润色和排版」 | 视程度而定，若实质内容非本人完成，仍属不端 |

《高等学校预防与处理学术不端行为办法》列举的学术不端行为中，包括**买卖、代写论文**。这不是道德评价，是规章明文列举的认定类型。

**所以它的问题不在于「被发现的风险有多大」，而在于它本身就是被明确定为不端的行为。**

---

## 二、可能的后果

### 2.1 在校阶段

| 后果 | 说明 |
| --- | --- |
| 论文/毕设成绩作废 | 需重新完成 |
| 延期毕业 | 错过答辩与派遣时间，影响就业 |
| 纪律处分 | 依《高等学校预防与处理学术不端行为办法》，可给予相应处分，情节严重的可至开除学籍 |
| 记录进入档案 | 处分材料可能影响升学、政审、部分就业环节 |
| 学位不授予 | 未达到学术要求，不授予学位 |

### 2.2 已毕业之后

这一节最需要强调，因为多数人以为「毕业就结束了」。

| 情形 | 说明 |
| --- | --- |
| **学位可被撤销** | 《学位法》规定，学位获得者存在学位论文抄袭、剽窃、伪造、数据造假、代写、买卖等学术不端情形的，可依法撤销学位 |
| **撤销不受毕业时间限制** | 撤销学位针对的是「获得学位时」的瑕疵，不因时间流逝而失效 |
| 学历记录受影响 | 学位被撤销后，相关记录随之变更 |
| 职业影响 | 已凭该学位取得的资格、职称、录用可能被重新审视 |

**「可追溯」是这件事最不像「一次考试作弊」的地方。** 考试作弊处理的是当次成绩；学位论文的瑕疵，动摇的是整个学位。

### 2.3 与「抽检」的关系

学位论文抽检制度使得毕业后仍可能被抽查：

| 层级 | 说明 |
| --- | --- |
| 博士、硕士学位论文抽检 | 有专门的抽检办法，抽检结果与学位授予质量挂钩 |
| 本科毕业论文（设计）抽检 | 教育部有专门的抽检办法（试行），抽检发现问题会反馈并处理 |

**注意**：抽检是**随机**的。你没法预测自己会不会被抽到，只能假设可能会。

## 三、怎么会被发现

不要以为「写得像自己写的就查不出来」。

| 发现方式 | 原理 |
| --- | --- |
| **查重** | 比对文本相似度。代写的论文如果本身抄了，查重会暴露 |
| **答辩追问** | 老师问「这个模型为什么选这个参数」「这组数据怎么来的」，答不上来就露了 |
| **写作风格突变** | 与本人平时的作业、课程论文风格差异明显 |
| **AI 生成痕迹** | 表述空洞、结构模板化、引用可疑（→ 11-05） |
| **引用核查** | 参考文献不存在、页码对不上、作者与观点错配 |
| **数据无法复现** | 要求提供原始数据、代码、实验记录时无法提供 |
| **抽检** | 随机抽查，毕业后也可能发生 |
| **代写方暴露** | 代写方被查、被同行举报，客户名单可能外泄 |
| **同学/知情者举报** | 这类举报在实际处理中占相当比例 |

**最关键的一条是答辩追问**。论文可以买，理解买不到。老师问三层，就分得清作者是谁。

---

## 四、代写方的风险：反向敲诈

这是最少被提及、但发生率不低的一项。

| 风险 | 机制 |
| --- | --- |
| **敲诈勒索** | 对方掌握「你买过论文」的证据（聊天记录、转账记录、原始稿件），以此要钱 |
| **二次收费** | 交稿后要求付「查重费」「修改费」「保密费」 |
| **论文被二次售卖** | 同一篇论文卖给多个人，你们互相撞车 |
| **论文被公开发布** | 出现在网上，你的查重直接爆表 |
| **信息泄露** | 你的身份、学校、导师、联系方式被掌握 |
| **被举报** | 部分代写方在纠纷后直接向学校举报 |

**这里有一个结构性陷阱**：你付钱买的是一个「不能声张」的东西。**不能声张的交易，无法通过正常途径维权。** 对方要加价，你不能报警说「我买论文被骗了」。

这个陷阱不是偶然，它是这类交易能够持续存在的条件。

## 五、已经用了怎么办

不评判，只说可选的做法与各自的代价。

| 选择 | 代价 | 说明 |
| --- | --- | --- |
| **主动向导师/学院说明，重做** | 可能受处分，但通常从轻 | 主动说明在认定中一般被视为配合态度 |
| 继续隐瞒，指望不被发现 | 风险持续存在，且可能叠加敲诈 | 抽检、答辩、举报任一环节都可能引爆 |
| 补足实质工作 | 时间成本高 | 真正读懂、重写、补数据，把论文变成自己的 |
| 被敲诈时妥协付钱 | 无底洞 | 付一次就会有第二次 |
| 被敲诈时报警 | 需要面对自己也有问题 | 敲诈是犯罪，但你的行为也会被处理 |

**最务实的一条**：如果论文里你自己都讲不清的部分占比很大，**越早重做，代价越小**。毕业前重做的成本，远低于毕业后被撤销学位。

**关于「主动说明会不会更惨」**：这取决于学校规定与具体情节，无法一概而论。但可以确定的是——**被动发现时，你没有陈述的机会。**

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「查重过了就没事」 | 查重只查文本相似度，代写论文是「原创」的，查重查不出 |
| 「答辩随便应付就行」 | 答辩追问是最有效的识别方式，三层问题就能看出作者是谁 |
| 「毕业了就安全了」 | 学位论文抽检可在毕业后进行；学位可依法撤销 |
| 「撤销学位有时效」 | 撤销针对的是获得学位时的瑕疵，不因时间流逝失效 |
| 「代写方不会敲诈我」 | 你无法维权的交易，天然适合被敲诈 |
| 「AI 写的算我自己写的」 | 若本人未实质参与，仍属代写性质；各校规定不同（→ 11-05） |
| 「只买一部分，不算代写」 | 核心内容非本人完成，同样可能被认定 |
| 「大家都这样」 | 普遍性不改变认定，且处分按个案处理 |

## 七、可执行清单

### 现在（还没做）

- [ ] 把「代写」从选项里划掉，它不是一个有风险的选择，是一个被明文认定的不端行为
- [ ] 遇到写不出来的部分，找导师、找同学、找写作中心，而不是找代写
- [ ] 时间不够就申请延期，延期比撤销学位便宜得多
- [ ] 需要工具辅助时，先读本校 AI 使用规定（→ 11-05）

### 已经在进行中

- [ ] 停止付款，保存所有聊天与转账记录
- [ ] 评估论文中自己讲不清的部分占比
- [ ] 找导师沟通重做的可行路径
- [ ] 被敲诈时不要继续付钱，考虑报警并同时准备向学校说明

### 已经交付、已毕业

- [ ] 重新读一遍自己的论文，标出讲不清的部分
- [ ] 保存原始数据与代码（万一被要求提供）
- [ ] 若收到敲诈，保留证据，不要私下转账
- [ ] 涉及学位的重大风险，咨询执业律师

---

## 八、一句话记住

**代写不是「有风险的选择」，而是被规章明文列为学术不端的行为；学位可被撤销且不受毕业时间限制，而买来的论文在答辩追问下撑不过三层。**
