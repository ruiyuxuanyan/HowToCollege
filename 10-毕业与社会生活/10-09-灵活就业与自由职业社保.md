# 灵活就业与自由职业：社保自己怎么交

> 一句话概括：没有单位，社保不会自动消失，但必须自己去办。

**适用人群**：自由职业者、自媒体、外卖骑手、待业过渡期的人、毕业没签单位的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国社会保险法》（2010 年通过，2018 年修正）第十条、第二十三条
> - 全国统一：灵活就业人员可以参加职工基本养老保险和职工基本医疗保险，费用由个人承担
> - 地方执行：参保地限制、缴费基数档次、缴费比例、办理渠道、户籍与居住证要求，**全部由地方规定**
> - 核查日期：2026-11-07

---

## 一、先搞清一个前提：你交的是哪一套

中国的社会保险有两套并行制度，很多人搞混，导致以为「我自己交社保」只有一种选择。

| | 职工社会保险 | 城乡居民社会保险 |
| --- | --- | --- |
| 面向谁 | 有工作单位的人；**灵活就业人员可以个人身份参加** | 未参加职工社保的城乡居民 |
| 谁出钱 | 单位 + 个人（在职）；个人全额（灵活就业） | 个人缴费 + 政府补贴 |
| 缴费水平 | 高 | 低 |
| 待遇水平 | 高 | 低 |
| 缴费年限 | 职工养老累计满十五年可按月领取 | 按年缴费，规则不同 |
| 与购房/落户资格 | 多数城市只认职工社保 | 通常不认 |

**关键判断**：如果你未来可能在一个限购城市买房、落户、摇号，那么基本只有「职工社保」这条路有意义。城乡居民社保缴得便宜，但换不来这些资格。

---

## 二、两种方式对比

以个人身份参保，实际可选的组合是这两种：

| 对比项 | ① 以个人身份参加**职工**养老 + 医疗 | ② 参加**城乡居民**养老 + 医疗 |
| --- | --- | --- |
| 缴费负担 | 明显更重（全部自己承担，且按当地社平工资的一定比例） | 轻（按年缴，档次可选） |
| 医保报销水平 | 较高，有个人账户（部分地区） | 较低，多数无个人账户 |
| 养老金水平 | 较高，与缴费年限、基数挂钩 | 较低，以基础养老金为主 |
| 缴费年限算不算「连续缴纳」 | 通常算【待核实，各城市规则不同】 | 一般不算 |
| 适合谁 | 长期自由职业、要保购房落户资格、要更好医保 | 收入很低、短期过渡、已确定不回职工体系 |
| 参保地限制 | 户籍地或居住证所在地【待核实】 | 户籍地为主【待核实】 |

**中间选项**：部分地区允许灵活就业人员只参加职工养老保险、不参加职工医保（或反之），或参加职工养老 + 城乡居民医保。这些组合各地政策不同，需要问当地经办机构。

---

## 三、参保地：你能在哪里交

这是最容易卡住的一步，也是最多人踩坑的地方。

| 你的情况 | 一般能在哪参保 |
| --- | --- |
| 本地户籍 | 户籍所在地 |
| 外地户籍、持有当地居住证 | 居住证所在地，多数地区支持【待核实】 |
| 外地户籍、无居住证 | 通常只能在户籍地 |
| 在户籍地以外长期工作 | 先办居住证，再按居住证所在地参保 |

**这意味着什么**：如果你在北京、上海、深圳这类城市自由职业但没有当地户籍，能否在当地以灵活就业身份缴职工社保，取决于当地是否放开居住证参保。这一点各城市差异很大，且近年有放宽趋势——但**必须查当年当地政策**。

**怎么查**：
1. 当地人社局官网，搜「灵活就业人员参保」
2. 当地政务服务网 / 政务 App 的社保办事指南
3. 拨打 **12333**
4. 直接去街道（乡镇）社保经办窗口问

## 四、缴费基数怎么定

职工社保的缴费基数一般与**当地上年度全口径城镇单位就业人员平均工资**挂钩，在规定的上下限之间由本人选择档次。

| 要点 | 说明 |
| --- | --- |
| 不是随便填一个数 | 有上下限，各地每年公布 |
| 档次可选 | 选得高，缴得多，将来养老金也多 |
| 每年可能调整 | 基数上下限随社平工资变化 |
| 具体比例各地不同 | 养老、医疗的费率由地方规定，本文不写数字 |

**选档次的思路**：不是越高越好，也不是越低越省。如果目的是**保住购房/落户的连续资格**，按最低档缴通常就能满足「有缴纳记录」的要求（但要看当地是否对基数有要求）。如果目的是**养老待遇**，长期看选高一点更划算。

## 五、怎么办理

流程结构大体是「先登记、再选档、后缴费」，具体入口各地不同。

| 步骤 | 做什么 | 在哪做 |
| --- | --- | --- |
| 1 | 办理**灵活就业登记**（部分地区需要） | 街道/社区就业服务窗口、政务 App |
| 2 | 办理**社保参保登记** | 社保经办机构、政务 App、人社局网上服务大厅 |
| 3 | 选择**缴费基数档次** | 同上 |
| 4 | 签订**代扣协议**或按月/按年自行缴费 | 税务部门渠道（多数地区社保费已由税务征收） |
| 5 | 定期核对**缴费记录** | 国家社会保险公共服务平台 |

**注意两点**：

1. 社保费征收职责在多数地区已划转税务部门，缴费入口可能不在人社局而在税务/政务 App 里，找不到不要以为不能办。
2. 很多地区**不允许事后补缴**灵活就业期间的断缴月份，只能往后缴。所以别拖。

## 六、「挂靠代缴」的法律风险

这一节必须说清楚，因为它在网上被包装成「解决方案」。

**什么是挂靠代缴**：找一家公司（中介或朋友的公司），以该公司员工的名义申报缴纳社保，实际上你不上班、不发工资，费用全部你自己出，可能还要给中介服务费。

**问题在哪**：

| 风险 | 说明 |
| --- | --- |
| **虚构劳动关系** | 社保缴纳以真实劳动关系为基础。没有劳动关系而申报参保，属于不实申报 |
| 缴费记录可能被认定无效 | 一旦被核查，相关缴费记录可能被清退，钱不一定能全退 |
| 可能被追缴或处罚 | 骗取社保待遇情节严重的，可能涉及法律责任【待核实具体条款适用】 |
| 挂靠公司自身风险传导给你 | 公司欠费、被列为异常、注销，你的记录跟着出问题 |
| 个人信息与资金风险 | 你要把身份证、银行卡信息交给中介 |
| 影响未来待遇核定 | 记录被清退后，年限缺口要在退休前补，代价更大 |

《社会保险法》第八十八条规定，以欺诈、伪造证明材料或者其他手段骗取社会保险待遇的，由社会保险行政部门责令退回骗取的社会保险金，处骗取金额二倍以上五倍以下的罚款。

**注意区分**：挂靠代缴与「人力资源服务机构受单位委托、为**真实用工**人员代办参保」不是一回事。前者没有真实劳动关系，后者有。中介说「我们这是正规代缴」，要问的是：**我在这家公司有真实的劳动关系吗？** 如果没有，那就是挂靠。

**结论**：挂靠省下来的麻烦，会在你最需要用到那段记录的时候还回来。宁可缴城乡居民社保过渡，也不要挂靠。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「没单位就不能交社保了」 | 可以，以灵活就业人员身份参加职工养老和医疗 |
| 「灵活就业社保和单位缴的不一样，年限不算」 | 都是职工社保，缴费年限可以累计接续（具体接续规则按当地） |
| 「城乡居民社保和职工社保可以随时互转、待遇一样」 | 是两套制度，有衔接规则但不是等价互换，待遇差距明显 |
| 「找公司挂靠代缴最省事」 | 虚构劳动关系，记录可能被清退，还有被处罚的风险 |
| 「先不交，等以后有钱了一次性补」 | 多数地区不允许灵活就业人员补缴过往月份 |
| 「在外地自由职业只能回老家交」 | 很多地区凭居住证可以就地参保，需查当地当年政策 |
| 「缴最低档最划算」 | 如果只为保资格，可能够用；如果为养老，长期看高档次更有利 |
| 「社保交满十五年就可以停了」 | 十五年是领取门槛；断缴后医保待遇和连续年限仍会受影响 |

## 八、可执行清单

### 决定参保方式之前

- [ ] 明确目的：是保购房/落户资格，还是保医疗与养老待遇
- [ ] 查当地当年政策：灵活就业人员参保的户籍/居住证要求
- [ ] 查缴费基数上下限与可选档次
- [ ] 打 12333 确认「我这种情况能不能在当地参保」

### 办理时

- [ ] 需要的话先办居住证
- [ ] 完成灵活就业登记与社保参保登记
- [ ] 选定缴费档次并签代扣协议
- [ ] 确认缴费入口（人社局还是税务/政务平台）
- [ ] 首次缴费后一个月内查记录，确认到账

### 长期

- [ ] 每年核对一次缴费记录，防止漏缴
- [ ] 收入变化时重新评估档次
- [ ] 未来重新就业时，办理社保关系接续（新单位续缴即可，年限累计）
- [ ] 跨城市流动时办理社保转移接续

### 绝对不要做

- [ ] 不与任何机构签订「挂靠代缴」协议
- [ ] 不把身份证、银行卡交由中介「代办」

## 九、一句话记住

**没单位就以灵活就业人员身份自己缴职工社保，能保年限也能保资格；缴不起就选城乡居民社保过渡，但绝不要挂靠代缴。**
