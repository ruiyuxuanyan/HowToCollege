# 个税：起征点、专项附加扣除、退税

> 一句话概括：每年 3–6 月做一次年度汇算，多数第一年工作的人都能退一笔钱。

**适用人群**：第一次拿工资、第一次看到「个人所得税」扣款的人；有房租、有老人要养、在读在职学位的人；听说「能退税」但不知道从哪下手的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国个人所得税法》（2018 年 8 月 31 日第七次修正，2019 年 1 月 1 日起施行）；《中华人民共和国个人所得税法实施条例》（国务院令第 707 号）；《个人所得税专项附加扣除暂行办法》（国发〔2018〕41 号）；国家税务总局关于办理个人所得税综合所得汇算清缴的年度公告
> - 全国统一：**税制框架、扣除项目设置、汇算清缴规则全国统一**
> - 地方执行：无需地方执行——个税为中央税，全国统一征收
> - 核查日期：2026-11-07
> - 已知变化：**专项附加扣除的部分标准近年经过上调**；汇算清缴的具体办理要求见国家税务总局年度公告

> ⚠️ **本文不写具体扣除金额。** 原因：专项附加扣除的部分标准近年经过上调，且今后仍可能调整。**请以「个人所得税」App 中显示的现行标准为准**，或查国家税务总局公布的最新口径。本文讲的是**有哪些项目、怎么用、怎么退**。

> ⏳ 易过时：各项扣除的具体标准、汇算清缴的办理要求。

## 一、先搞清一件事：你的税是怎么算的

工资薪金的个税不是「超过某个数就全部按一个税率交」，而是**先减掉一堆东西，再对剩下的部分按超额累进税率计算**。

计算顺序（综合所得）：

```
收入
 − 基本减除费用（俗称「起征点」，按年计算）
 − 专项扣除（三险一金的个人缴费部分）
 − 专项附加扣除（子女教育、房租、赡养老人等）
 − 依法确定的其他扣除（如商业健康险、个人养老金等）
 ─────────────────────────
 = 应纳税所得额
 → 按超额累进税率计算应纳税额
 → 减去已预扣预缴的税额
 = 应退或应补
```

**关键理解三点**：

| 概念 | 含义 |
| --- | --- |
| **基本减除费用** | 俗称「起征点」。注意：它是**按年**计算的，不是「月薪超过某个数才开始交」那么简单 |
| **专项扣除** | 就是你的**社保和公积金个人缴费部分**——这部分不交税 |
| **专项附加扣除** | 国家给特定支出的额外扣除，**这是大多数人退税的来源** |

**这就是为什么「专项附加扣除」值得花十分钟填一下**：每填一项，应纳税所得额就少一块。

【法规】《个人所得税法》第六条规定，居民个人综合所得，以每一纳税年度收入额减除费用六万元以及专项扣除、专项附加扣除和依法确定的其他扣除后的余额，为应纳税所得额。

> 说明：上述条文中的「六万元」为《个人所得税法》第六条的法定表述。**本文不展开其他具体金额与税率级距**，请在个人所得税 App 或国家税务总局官网查看现行完整标准。

## 二、专项附加扣除：七项，逐项说明

这是本文的核心。七项扣除的**适用条件**比金额更重要——很多人明明符合条件却没填。

### 2.1 子女教育

| 项目 | 内容 |
| --- | --- |
| 适用条件 | 子女年满 3 岁至全日制学历教育阶段（含学前教育、义务教育、高中阶段、高等教育） |
| 扣除方式 | 父母可选择一方扣除，或双方各扣一半 |
| 常见漏填 | 子女已满 3 岁但还没上幼儿园的，**也可以扣**（学前教育阶段） |

### 2.2 继续教育

| 类型 | 条件 |
| --- | --- |
| 学历（学位）继续教育 | 在职读本科、硕士、博士等 |
| 职业资格继续教育 | 取得技能人员职业资格证书或专业技术人员职业资格证书的**当年** |

**注意**：学历继续教育按**月**扣除（有最长扣除期限），职业资格继续教育是**取得证书当年一次性**扣除。两者规则不同，别混。

**这条对大学生很实用**：专升本、在职研究生、考取职业资格证书，都可能适用。

### 2.3 大病医疗

| 项目 | 内容 |
| --- | --- |
| 适用条件 | 一个纳税年度内，医保目录范围内的**个人自付部分**累计超过规定起点金额 |
| 扣除主体 | 本人、配偶、未成年子女发生的医药费用支出 |
| 办理时点 | **通常在年度汇算清缴时填**（不能在平时预扣时扣） |
| 数据来源 | 可通过「国家医保服务平台」App 查询年度医疗费用自付金额 |

**这是最容易漏的一项**：平时扣不了，只能在汇算时补，很多人根本不知道自己符合条件。**如果家里当年有大额医疗支出，汇算时一定要查一下。**

### 2.4 住房贷款利息

| 项目 | 内容 |
| --- | --- |
| 适用条件 | **首套住房**贷款利息支出，在**实际发生贷款利息的年度**扣除 |
| 扣除方式 | 夫妻双方可选择一方扣除 |
| 期限 | 有最长扣除期限（按年计） |
| 注意 | 只能享受**一次**首套住房贷款利息扣除 |

**关键点**：只限**首套**。二套房不适用。是否是「首套」按当地住房贷款政策认定。

### 2.5 住房租金（毕业后最常用的一项）

| 项目 | 内容 |
| --- | --- |
| 适用条件 | 在**主要工作城市**没有自有住房而发生的住房租金支出 |
| 扣除主体 | **签订租赁合同的承租人** |
| 与房贷的关系 | **住房贷款利息与住房租金，二者只能享受其一**（同一纳税年度内） |
| 城市档次 | 按城市规模分档，不同档次标准不同（具体分档与标准见现行规定） |
| 所需信息 | 租赁房屋地址、租赁合同、出租方信息（单位名称或个人姓名及身份证号） |

**这一项是刚毕业的人最容易忽略的**，因为：

1. 很多人以为「公司包住」或「住亲戚家」才不能扣，实际上**只要你在工作城市无自有住房且实际支付租金**就符合条件
2. 需要出租方信息，租房时没记房东身份证号的，现在就得补
3. 与房贷利息**二选一**，有房贷的人要比较哪项更划算

**注意**：合同和实际居住要能对得上。税务机关可能要求提供租赁合同等资料备查。

### 2.6 赡养老人

| 项目 | 内容 |
| --- | --- |
| 适用条件 | 赡养**年满 60 岁**的父母，以及子女均已去世的年满 60 岁的祖父母、外祖父母 |
| 扣除方式 | 独生子女与非独生子女规则不同（非独生子女需与兄弟姐妹分摊） |
| 常见误解 | **赡养配偶的父母（岳父母/公婆）不属于本项扣除范围** |

**这一条的关键是「60 岁」这个门槛**，不到年龄不能扣。

### 2.7 3 岁以下婴幼儿照护

| 项目 | 内容 |
| --- | --- |
| 适用条件 | 照护 **3 岁以下**婴幼儿的纳税人 |
| 扣除方式 | 父母可选择一方扣除，或双方各扣一半 |
| 与子女教育的关系 | **3 岁前用这一项，3 岁后用「子女教育」**，无缝衔接 |

### 2.8 七项速查表

| 扣除项目 | 谁能扣 | 常见漏填原因 |
| --- | --- | --- |
| 子女教育 | 有 3 岁以上子女在学的父母 | 以为没上学就不能扣 |
| 继续教育 | 在职读学位、当年取得职业资格证 | 不知道在职学历也能扣 |
| 大病医疗 | 当年有大额医疗自付支出 | 只能汇算时填，平时看不到 |
| 住房贷款利息 | 首套房贷 | 以为要银行开证明才行 |
| 住房租金 | 工作城市无房、实际租房 | 不知道需要出租方信息 |
| 赡养老人 | 赡养 60 岁以上父母 | 误以为配偶父母也算 |
| 3 岁以下婴幼儿照护 | 有 3 岁以下孩子 | 与「子女教育」搞混 |

## 三、为什么会有退税

**退税不是「天上掉钱」，是你多交了。**

| 多交的原因 | 说明 |
| --- | --- |
| 专项附加扣除没及时填 | 平时按未扣除的金额预扣，汇算时补扣 → 产生退税 |
| 中间换过工作 | 两家公司各自按较低税率预扣，合并后适用更高税率 → 可能**补税**（也可能是退税） |
| 年中才开始工作 | 之前月份没收入，年度合并后适用较低税率 → 退税 |
| 有劳务报酬、稿酬等 | 预扣率通常高于综合所得税率 → 退税 |
| 年中符合了新条件 | 如满 60 岁的父母、新出生的孩子、新签的租房合同 |
| 有公益慈善捐赠 | 符合条件的捐赠可扣除 |

**结论**：**第一年工作、年中入职、有房租或赡养老人支出的，大概率能退。**

反过来也要注意：**换过工作的人有时需要补税**，别以为汇算一定是退税。

## 四、年度汇算清缴：3–6 月做的事

### 4.1 什么时候办

**每年 3 月 1 日至 6 月 30 日**办理上一年度的综合所得汇算清缴。

【法规】《个人所得税法》第十一条规定，居民个人取得综合所得，需要办理汇算清缴的，应当在取得所得的次年三月一日至六月三十日内办理。

### 4.2 谁需要办

| 情形 | 是否需要办 |
| --- | --- |
| 需要退税 | 建议办（不办就拿不到） |
| 需要补税且超过规定金额 | **必须办** |
| 收入单一、已足额预扣、无扣除可补 | 可以不办 |
| 符合国务院规定免于汇算的情形 | 可以不办 |

**免于办理汇算的具体条件（现行规定）**：

| 条件 | 说明 |
| --- | --- |
| **年度综合所得收入不超过 12 万元，且需要补税** | 可以免于办理 |
| **年度汇算需补税金额不超过 400 元** | 可以免于办理 |
| 已预缴税额与应纳税额一致 | 不需要办 |
| 符合条件但不申请退税 | 可以不办 |

【官方】国家税务总局关于办理个人所得税综合所得汇算清缴事项的年度公告

**注意两点的区别**：

- **「不超过 12 万元」的前提是你需要补税**。如果你不用补税反而能退税，那还是建议去办——退税是权利，不办就拿不到钱。
- **这两个数字（12 万、400 元）近年保持稳定，但仍以当年公告为准。**

> 上述标准由国家税务总局年度公告规定，理论上可能调整；办理前请核对当年公告。

### 4.3 怎么办理（三种渠道）

| 渠道 | 说明 |
| --- | --- |
| **「个人所得税」App**（最常用） | 实名注册 → 首页「综合所得年度汇算」→ 按提示操作 |
| 自然人电子税务局（网页端） | 功能与 App 基本一致 |
| 办税服务厅 | 现场办理 |

**推荐用 App**，因为专项附加扣除的填报、修改、查询都在同一个地方，数据是打通的。

### 4.4 办理时的一个关键选择

系统会给出「我需要申报表预填服务」的选项。**建议用预填**——系统已经把你的工资、已缴税额填好了，你只需要核对并补充扣除项。

**必做的一步**：在提交前，**逐项检查专项附加扣除是否都填了**。这就是退税的来源。

## 五、现在就能做的准备

退税不难，难在**信息不全**。提前把这些准备好：

| 要办的事 | 需要准备 |
| --- | --- |
| 住房租金扣除 | 租赁合同、房屋地址、出租方姓名与身份证号（或单位名称与统一社会信用代码） |
| 赡养老人扣除 | 父母的身份信息、出生日期（确认是否满 60 岁） |
| 子女教育 / 婴幼儿照护 | 子女身份信息、就读学校信息 |
| 继续教育 | 学历教育：入学时间；职业资格：证书编号与发证日期 |
| 大病医疗 | 通过国家医保服务平台 App 查年度自付金额 |
| 住房贷款利息 | 贷款合同编号、首次还款日期、房屋信息 |

**现在就做的一件事**：打开「个人所得税」App，把专项附加扣除**现在填上**。填了之后，当年后续月份就能按扣除后的金额预扣，**不用等到第二年汇算才退**——这等于提前拿到钱。

## 六、几个容易出错的地方

| 情形 | 注意 |
| --- | --- |
| **房贷利息和房租同时填** | 同一纳税年度内只能享受其一，重复填报会被系统提示或后续核查 |
| **赡养配偶父母** | 不属于「赡养老人」扣除范围 |
| **房租扣除填了非工作城市** | 应为**主要工作城市**的租金 |
| **子女教育父母双方都按全额填报** | 应约定一方扣除或双方各扣一半，合计不得超过规定比例 |
| **继续教育混淆两种类型** | 学历继续教育按月扣；职业资格是取得当年一次性扣 |
| **换工作后忘记更新扣除信息** | 扣除信息与扣缴单位绑定，换单位后需确认 |
| **以为不申报也没事** | 应补税未申报的，可能产生滞纳金并影响纳税信用 |

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「月薪没超过起征点就不用管个税」 | 起征点按**年**计算，且还有多项扣除；年中入职、有扣除的仍可能退税 |
| 「退税是额外补贴」 | 是你平时多交的部分退回，不是白给的钱 |
| 「专项附加扣除要提供发票」 | 多数项目**不需要发票**，但需留存合同、证书等资料备查 |
| 「房租和房贷可以同时扣」 | 同一纳税年度**只能选其一** |
| 「住亲戚家不能扣房租」 | 关键看是否在主要工作城市**无自有住房且实际支付租金** |
| 「父母没到 60 岁也能扣赡养老人」 | 必须年满 60 岁 |
| 「3 岁以下不能扣」 | 有「3 岁以下婴幼儿照护」专项扣除 |
| 「公司包住就不用管」 | 若你实际支付租金且符合条件，仍需自行判断；建议咨询 12366 |
| 「汇算一定要补税」 | 多数第一年工作的人是退税；换过工作的人有可能补税 |

## 可执行清单

**入职当月**

- [ ] 下载「个人所得税」App，完成实名注册
- [ ] 在 App 里填报所有符合条件的专项附加扣除
- [ ] 确认公司已把你加入扣缴申报（可问 HR）
- [ ] 保存好租房合同、证书、贷款合同等资料

**每年 3 月前**

- [ ] 检查上一年度的专项附加扣除是否都填了
- [ ] 有新增情况（结婚、生子、父母满 60 岁、新签租房合同、取得证书）的，补填
- [ ] 有大额医疗支出的，到国家医保服务平台查自付金额

**每年 3–6 月**

- [ ] 打开个税 App，进入「综合所得年度汇算」
- [ ] 使用预填服务
- [ ] **逐项核对专项附加扣除**
- [ ] 核对收入与已缴税额
- [ ] 确认是退税还是补税
- [ ] 退税：绑定本人银行卡并提交
- [ ] 补税：在期限内缴纳，不要拖

**全年**

- [ ] 保留租房合同、贷款合同、证书、医疗票据等资料（税务可能要求备查）

## 一句话记住

**个税 = 收入减去「三险一金 + 七项专项附加扣除」后再算；每年 3–6 月用个税 App 汇算一次，多数刚工作的人能退一笔——现在就把扣除填上，比等到明年退更划算。**
