# 被辞退怎么办：N、N+1、2N 的区别与取证

> 一句话概括：N 是正常离职补偿，N+1 是「没提前通知」，2N 是「违法辞退」——拿哪个取决于公司怎么辞你。

**适用人群**：被通知「明天不用来了」的人；被 HR 劝「主动离职」的人；想提前搞清楚自己有什么权利的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国劳动合同法》（2012 年 12 月 28 日修正）第三十九条、第四十条、第四十一条、第四十六条、第四十七条、第四十八条、第八十七条、第八十九条；《中华人民共和国劳动合同法实施条例》第二十七条
> - 全国统一：**补偿标准、计算方式、2N 规则全国统一**
> - 地方执行：社保缴费基数上下限、仲裁受理流程、最低工资标准由地方规定
> - 核查日期：2026-11-05
> - 已知变化：现行条文自 2012 年修正后未再修订

> ⚠️ **本文最重要的一条**：**不要签「自愿离职申请」。** 签了，N 和 2N 都可能拿不到。见第五节。

---

## 一、先分清三种情形，才谈得上算钱

「N」不是一个笼统的补偿，它的法律名称是**经济补偿**。你能拿多少，取决于公司是**怎么**解除合同的。

| 情形 | 法律依据 | 补偿 | 通俗说法 |
| --- | --- | --- | --- |
| **过失性辞退**（你有过错） | 第三十九条 | **无补偿** | 「0」 |
| **无过失性辞退**（非你的过错） | 第四十条 | **N 或 N+1** | 「N+1」的来历 |
| **经济性裁员** | 第四十一条 | **N** | 裁员 |
| **协商一致解除**（公司提出） | 第三十六、四十六条 | **N** | 「和平分手」也要给 N |
| **合同到期不续签**（公司不续） | 第四十四条、第四十六条 | **N** | 常被漏掉 |
| **违法解除** | 第四十八、八十七条 | **2N** | 「公司乱来」 |

### 1.1 一张判断流程图（用文字表达）

```
公司要你走
  ├─ 说你有严重违纪/严重失职/试用期不符合录用条件（第39条）
  │    → 无补偿。但公司必须举证，举证不足就是违法解除 → 2N
  ├─ 说你不能胜任/医疗期满/客观情况重大变化（第40条）
  │    → N+1（未提前30日书面通知）或 N（提前30日书面通知）
  ├─ 公司裁员（第41条，需符合法定条件和程序）
  │    → N
  └─ 没有法定理由，就是想让你走
       → 违法解除 → 2N（或要求继续履行合同）
```

## 二、N 怎么算

### 2.1 法条原文（第四十七条）

> 经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。
>
> 劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付，向其支付经济补偿的年限最高不超过十二年。
>
> 本条所称月工资是指劳动者在劳动合同解除或者终止前十二个月的平均工资。
>
> 【法规】《中华人民共和国劳动合同法》第四十七条

### 2.2 拆成两个变量

**N = 工作年限 × 月工资**

**① 工作年限怎么数**

| 你在本单位工作了 | 算作 |
| --- | --- |
| 满 6 个月不满 1 年 | **1 年** |
| 不满 6 个月 | **0.5 年**（半个月工资） |
| 满 1 年 | 按 1 年算，余数按上面两条处理 |

**举例**（示例仅演示算法，非真实案例）：

- 工作 2 年 8 个月 → 3 年 → N = 3 个月工资
- 工作 1 年 3 个月 → 1 年 + 3 个月（不满 6 个月）→ N = 1.5 个月工资
- 工作 7 个月 → 1 年 → N = 1 个月工资

**注意**：「本单位」指当前这家公司。前一家公司的工作年限不带过来（除非属法定承继情形，如公司合并分立）。

**② 月工资怎么算**

- 是**解除或终止前十二个月的平均工资**
- 是**应得工资**（税前），不是到手工资
- 依据《劳动合同法实施条例》第二十七条，包括计时工资或者计件工资以及奖金、津贴和补贴等货币性收入

> 【法规】《劳动合同法实施条例》第二十七条：劳动合同法第四十七条规定的经济补偿的月工资按照劳动者应得工资计算，包括计时工资或者计件工资以及奖金、津贴和补贴等货币性收入。劳动者在劳动合同解除或者终止前12个月的平均工资低于当地最低工资标准的，按照当地最低工资标准计算。劳动者工作不满12个月的，按照实际工作的月数计算平均工资。

**这一条很关键**：很多人只按「基本工资」算，其实**奖金、津贴、补贴都要算进去**。年终奖是否计入，实务中有争议，通常按实际发放期间分摊考虑【待核实】具体认定以当地仲裁/法院口径为准。

**③ 高收入者的封顶规则**（第四十七条第二款）

月工资高于当地上年度职工月平均工资三倍的：

- 计算基数**按三倍封顶**
- 补偿年限**最高 12 年**

【待核实】「当地上年度职工月平均工资」的具体数值由各直辖市、设区的市级人民政府公布，各地不同且逐年更新，本文不写数字。

## 三、+1 是什么，什么时候有

**「+1」不是补偿，是「代通知金」。**

《劳动合同法》第四十条：

> 有下列情形之一的，用人单位提前三十日以书面形式通知劳动者本人或者额外支付劳动者一个月工资后，可以解除劳动合同：
>
> （一）劳动者患病或者非因工负伤，在规定的医疗期满后不能从事原工作，也不能从事由用人单位另行安排的工作的；
> （二）劳动者不能胜任工作，经过培训或者调整工作岗位，仍不能胜任工作的；
> （三）劳动合同订立时所依据的客观情况发生重大变化，致使劳动合同无法履行，经用人单位与劳动者协商，未能就变更劳动合同内容达成协议的。
>
> 【法规】《劳动合同法》第四十条

### 3.1 关键理解

| 公司做法 | 你拿 |
| --- | --- |
| 提前 30 日**书面**通知你 | N（没有 +1） |
| 不提前通知，让你马上走 | N + 1 |

**所以「+1」是「买这 30 天」的钱**，不是额外福利。而且它只适用于**第四十条的三种情形**。

**常见的误用**：公司以「你不能胜任」为由辞退，却说「给你 N，没有 +1，因为我们提前通知了」。你要确认：**通知是不是书面的？是不是真的提前了 30 日？**

> **注意**：这里的「一个月工资」通常指**上一个月的工资标准**，与 N 的计算基数（前 12 个月平均）不完全相同【待核实】实务中对代通知金基数的认定存在地区差异，以当地仲裁口径为准。

## 四、2N：违法解除

### 4.1 法条

> 用人单位违反本法规定解除或者终止劳动合同，劳动者要求继续履行劳动合同的，用人单位应当继续履行；劳动者不要求继续履行劳动合同或者劳动合同已经不能继续履行的，用人单位应当依照本法第八十七条规定支付赔偿金。
>
> 【法规】《劳动合同法》第四十八条

> 用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。
>
> 【法规】《劳动合同法》第八十七条

### 4.2 2N 的两种救济，你可以选

| 你的选择 | 结果 |
| --- | --- |
| 要求**继续履行**合同 | 公司应继续履行，并补发争议期间的工资 |
| 不要求继续履行（或已无法履行） | 公司支付**2N 赔偿金** |

**这是你的选择权，不是公司的。** 实践中如果你已经找到新工作，通常选 2N 更实际。

### 4.3 什么算「违法解除」

| 情形 | 为什么违法 |
| --- | --- |
| 没有法定理由就辞退 | 不符合第三十九、四十、四十一条任一情形 |
| 以「不能胜任」辞退但没培训/没调岗 | 第四十条第（二）项要求先培训或调岗 |
| 以「严重违纪」辞退但拿不出证据 | 举证责任在公司 |
| 辞退孕期、产期、哺乳期女职工 | 第四十二条明确禁止（除非符合第三十九条情形） |
| 辞退在规定医疗期内的员工 | 第四十二条禁止 |
| 辞退患职业病或因工负伤丧失劳动能力者 | 第四十二条禁止 |
| 未通知工会就单方解除 | 第四十三条要求事先通知工会 |
| 程序不合法（如裁员未走法定程序） | 第四十一条有明确程序要求 |

【法规】《劳动合同法》第四十二条列举了用人单位不得依照第四十条、第四十一条解除劳动合同的情形，包括：从事接触职业病危害作业的劳动者未进行离岗前职业健康检查，或者疑似职业病病人在诊断或者医学观察期间的；在本单位患职业病或者因工负伤并被确认丧失或者部分丧失劳动能力的；患病或者非因工负伤，在规定的医疗期内的；女职工在孕期、产期、哺乳期的；在本单位连续工作满十五年，且距法定退休年龄不足五年的；法律、行政法规规定的其他情形。

## 五、取证：这一节决定你能不能拿到钱

**说句实话：劳动仲裁里输的人，多数不是没道理，是没证据。**

### 5.1 最重要的一条：要书面解除通知

| 公司让你签的东西 | 能不能签 |
| --- | --- |
| **《解除劳动合同通知书》**（写明解除理由、日期） | **要，且要原件或拍照留存** |
| **《自愿离职申请》/《辞职申请书》** | **绝不签** |
| 《协商解除协议》（写明补偿金额） | 看清补偿金额与支付时间再签；金额未谈妥不签 |
| 《离职交接单》 | 可以签，但**不要在上面写「个人原因离职」** |

### 5.2 为什么「自愿离职申请」是陷阱

法律后果非常直接：

| 你签的文件 | 法律效果 |
| --- | --- |
| 自愿离职申请 | 视为**你主动辞职** → 无经济补偿（N=0），无 2N，且**无法领取失业金**（不符合「非因本人意愿中断就业」） |
| 解除劳动合同通知书（公司出具） | 公司解除，你依法主张 N 或 2N |

**一句话**：**签了「自愿离职」，你就把「公司赔你钱」变成了「你自己走的」。**

### 5.3 HR 常见话术与应对

| 话术 | 应对 |
| --- | --- |
| 「签了自愿离职，我们给你开好看的离职证明」 | 离职证明不得写对你不利的内容（第八十九条）；不需要用补偿换 |
| 「不签就不给办离职手续、不给开证明」 | 开离职证明是公司法定义务（第五十条），不能作为交换条件 |
| 「签了才能拿到这个月工资」 | 工资是劳动报酬，与离职方式无关 |
| 「先签，补偿我们后面打给你」 | 补偿金额与支付时间必须**写进协议** |
| 「你自己提离职，我们给你 N」 | 若真是协商解除且写明补偿，可以考虑；但要注意「谁提出」影响定性 |

【法规】《劳动合同法》第五十条：用人单位应当在解除或者终止劳动合同时出具解除或者终止劳动合同的证明，并在十五日内为劳动者办理档案和社会保险关系转移手续。

【法规】《劳动合同法》第八十九条：用人单位违反本法规定未向劳动者出具解除或者终止劳动合同的书面证明，由劳动行政部门责令改正；给劳动者造成损害的，应当承担赔偿责任。

### 5.4 必须收集的证据清单

**基础证据（立刻保存）**

- [ ] 劳动合同原件
- [ ] 工资流水（银行打印，含近 12 个月）
- [ ] 工资条 / 薪资明细（含奖金、补贴）
- [ ] 社保、公积金缴纳记录
- [ ] 考勤记录、打卡截图
- [ ] 工作沟通记录（企业微信、钉钉、邮件）——**离职前备份到个人设备**
- [ ] 工牌、门禁记录、工作成果（能证明你在此工作的材料）

**解除相关证据（最关键）**

- [ ] **书面的解除通知**（原件/照片）
- [ ] 解除理由的书面表述
- [ ] HR 谈话录音（合法性由仲裁/法院判断，但先保留）
- [ ] 谈话现场的微信/短信记录
- [ ] 同事的证人证言（可后续联系）
- [ ] 公司要求你「主动离职」的任何书面/聊天记录

**注意**：离职前先把自己的工作沟通记录、考勤、工资条导出到个人设备。**公司账号一旦被停用，这些就都拿不到了。**

### 5.5 一个时间上的提醒

【法规】《劳动争议调解仲裁法》第二十七条规定，劳动争议申请仲裁的时效期间为一年，从当事人知道或者应当知道其权利被侵害之日起计算。

**别拖。** 一年看起来很长，但收集证据、找律师、准备材料都要时间。

## 六、维权路径与另外几笔钱

**顺序**：不签不利文件 → 备份证据 → 书面协商 → 12333 投诉（欠薪、未缴社保）→ **劳动仲裁（前置程序，不收费）** → 不服裁决起诉 → 申请强制执行。

仲裁可向**劳动合同履行地或用人单位所在地**的劳动人事争议仲裁委员会申请；事实清楚、证据充分的案件多在仲裁阶段解决。符合条件可申请法律援助。【待核实】简易程序/速裁的适用标准各地不同。

除了 N/N+1/2N，还有几笔常被漏掉：

| 项目 | 说明 |
| --- | --- |
| 未结工资 | 到离职日的工资必须结清 |
| 未休年休假工资 | 未休年假应折算工资（《职工带薪年休假条例》） |
| 加班费 | 有加班未付的可一并主张（需举证） |
| 报销款 | 已垫付未报销的费用 |
| 当月社保公积金 | 确认缴到哪个月 |
| **失业金** | 非因本人意愿中断就业可申领（见 10-04） |

最后一项又是「别签自愿离职」的理由——主动辞职通常不符合「非因本人意愿中断就业」，领不到失业金。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「签了自愿离职也能拿 N」 | 通常拿不到，且影响失业金申领 |
| 「公司说 N 就是 N」 | 要核对：工作年限、月工资口径（含奖金补贴）、是否属违法解除（应 2N） |
| 「N 按基本工资算」 | 按**前 12 个月平均应得工资**，含奖金津贴补贴 |
| 「提前 30 天通知就没有 N」 | 仍要 N；提前通知只是免掉「+1」 |
| 「试用期被辞退没有补偿」 | 若公司无法证明「不符合录用条件」，属违法解除 |
| 「公司裁员只给 N，不能争」 | 若裁员不符合第 41 条法定条件或程序，可能构成违法解除（2N） |
| 「仲裁要花钱请律师」 | 劳动仲裁不收费；符合条件可申请法律援助 |
| 「离职证明可以随便写」 | 第八十九条：违法不出具或造成损害的，公司担责 |
| 「公司不发工资我就没办法」 | 可向劳动保障监察投诉（12333），也可仲裁 |

## 可执行清单

**被通知辞退的当天**

- [ ] **不签任何文件**，先说「我需要时间考虑」
- [ ] 要求公司出具**书面解除通知**，写明解除理由与日期
- [ ] 明确拒绝签《自愿离职申请》
- [ ] 开始录音（如当地允许）或保留文字沟通
- [ ] 把工作沟通记录、考勤、工资条导出到个人设备

**48 小时内**

- [ ] 整理证据清单（第 5.4 节）
- [ ] 计算你的 N：工作年限 × 前 12 个月平均应得工资
- [ ] 判断情形：是第 39 条？第 40 条？第 41 条？还是无理由？
- [ ] 无理由/证据不足 → 主张 2N
- [ ] 打 12333 咨询属地受理口径

**协商阶段**

- [ ] 所有诉求**书面**提出（微信/邮件），留痕
- [ ] 补偿金额与支付时间写进协议才签字
- [ ] 不接受的条款明确书面回复不同意

**协商不成**

- [ ] 向劳动人事争议仲裁委员会申请仲裁（注意一年时效）
- [ ] 咨询当地法律援助中心是否符合援助条件
- [ ] 一并主张：未结工资、未休年假、加班费、报销款

## 一句话记住

**N 看年限和平均工资，+1 是没提前通知的代价，2N 是公司违法解除的惩罚——而这一切的前提是：你千万别签那张「自愿离职申请」。**
