# 职场新人常见错误

> 一句话概括：有些错误会跟着你很久，早一点知道能省很多事。

**适用人群**：刚入职的毕业生；准备实习的学生。

> **核查日期**：2026-11-07

---

## 一、沟通类错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| **越级汇报** | 得罪直属上级，破坏信任 | 先向直属上级汇报 |
| **越权承诺** | 承诺了做不到的事，责任在你 | 说「我需要确认后回复」 |
| **不汇报** | 出问题时无人知晓 | 定期同步进度，有问题早说 |
| **口头代替书面** | 事后扯不清 | 重要事项发邮件或消息确认 |

---

## 二、留痕意识（最重要的习惯）

**职场里「留痕」是自我保护的基础。**

| 场景 | 怎么留痕 |
| --- | --- |
| 口头决定 | 会后补一条消息：「刚才确认的是……」 |
| 任务分配 | 在群里复述一遍确认 |
| 交接工作 | 写清单，双方确认 |
| 加班 | 保留考勤/打卡记录 |
| 被批评 | 记录内容与时间 |

**为什么重要**：出现争议时，「我说过」和「有记录」是完全不同的分量。

---

## 三、权益类错误

| 错误 | 后果 |
| --- | --- |
| 不签劳动合同 | 单位违法，但你也失去凭据 |
| **接受口头承诺的薪资** | 与实际不符时难举证 |
| 不缴社保也接受 | 失去医保、养老、购房资格 |
| 签「自愿放弃社保」 | 条款无效，但你可能被误导 |
| 不保留工资条 | 计算补偿时缺乏依据 |

**详见「劳动合同怎么签」（10-03）。**

---

## 四、边界类错误

| 错误 | 说明 |
| --- | --- |
| 帮同事背锅 | 一次退让会有第二次 |
| 做超出职责的事却无授权 | 出问题责任在你 |
| 过度加班成为常态 | 损害健康，且可能被视为理所当然 |
| 参与办公室政治 | 新人最容易被当棋子 |

---

## 五、离职时的注意事项

| 事项 | 说明 |
| --- | --- |
| 提前通知期 | 按合同约定（试用期与转正后不同） |
| 书面提出 | 保留提交记录 |
| 工作交接 | 写清单，双方签字 |
| **离职证明** | 一定要拿，下家入职需要 |
| 社保转移 | 确认新单位接续 |
| 竞业限制 | 如有约定，确认补偿是否支付 |

---

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「新人就该多干」 | 多干可以，但要留痕、要有授权 |
| 「口头说好就行」 | 争议时无凭据 |
| 「离职证明不重要」 | 下家入职、社保转移都要 |
| 「不签合同对公司不利，与我无关」 | 你也失去维权凭据 |
| 「越级汇报能快速被看见」 | 通常适得其反 |

---

## 六点五、四种「看起来没问题其实很危险」的说法

职场里有些话，说出口时觉得没什么，但会留下隐患。

| 说法 | 问题 | 更好的表达 |
| --- | --- | --- |
| 「没问题，我来」 | 揽下做不了的事 | 「我先确认一下排期，今天下班前回复你」 |
| 「这个不用写邮件了吧」 | 口头约定事后无凭据 | 「我发个消息确认一下刚才说的」 |
| 「我按之前那样做了」 | 之前的做法可能已经变了 | 「按上次的流程做，如果有变化请告诉我」 |
| 「这事不归我管」 | 显得推卸，且可能真的归你 | 「这块我不太熟，我帮你问一下谁负责」 |

**共同点**：把模糊的口头承诺，变成有边界的书面确认。

---

## 七、可执行清单

### 入职第一周

- [ ] 拿到劳动合同并自己保存一份
- [ ] 确认社保开始缴纳
- [ ] 弄清汇报关系（直属上级是谁）
- [ ] 保存工资条

### 日常工作

- [ ] 重要事项邮件/消息确认
- [ ] 任务分配后复述确认
- [ ] 保留考勤记录

### 离职时

- [ ] 书面提出
- [ ] 写交接清单
- [ ] 拿离职证明
- [ ] 确认社保转移

---

## 八、一句话记住

**口头说的都补一条消息。离职一定要拿离职证明。**
