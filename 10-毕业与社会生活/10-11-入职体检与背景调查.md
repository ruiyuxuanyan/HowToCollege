# 入职体检与背景调查

> 一句话概括：体检和背调都有边界，不是公司想查什么就查什么。

**适用人群**：即将入职的毕业生。

> **政策与法律适用范围**
> - 主要依据：《中华人民共和国个人信息保护法》；人社部、卫生部、教育部关于入学就业体检禁止乙肝项目检测的规定
> - 全国统一：入职体检不得检测乙肝项目、背调需本人授权
> - 核查日期：2026-11-05

---

## 一、入职体检的常规项目

| 类别 | 项目 |
| --- | --- |
| 常规 | 身高体重、血压、内外科 |
| 化验 | 血常规、尿常规、肝功能 |
| 影像 | 胸片 |
| 其他 | 视力、听力（视岗位） |

---

## 二、禁止检测的项目

**入职体检不得检测乙肝项目。**

| 明文禁止 | 依据 |
| --- | --- |
| 乙肝表面抗原等乙肝项目 | 人社部、卫生部、教育部相关规定 |

**如果被要求查乙肝**：
1. 可以拒绝
2. 向当地人社部门或卫生部门反映
3. 保留证据

---

## 三、体检结果的隐私边界

| 原则 | 说明 |
| --- | --- |
| 结果属个人隐私 | 公司只能在必要范围知悉 |
| 与岗位无关的信息 | 不应作为录用依据 |
| 具体病种 | 不应被公开传播 |

**「必要范围」的判断**：该健康条件是否与岗位的实际要求相关。

---

## 四、背景调查的合法边界

| 要点 | 说明 |
| --- | --- |
| **需要授权** | 背调应事先取得你的书面同意 |
| 查什么 | 学历、工作经历、离职原因、有无竞业限制 |
| 不能查什么 | 与岗位无关的私人生活、健康状况细节 |
| 第三方背调公司 | 同样受《个人信息保护法》约束 |

---

## 五、背调常见问题

| 问题 | 应对 |
| --- | --- |
| 前公司说了不实评价 | 可要求核实，必要时主张名誉权 |
| 被查了未授权的信息 | 可要求说明并投诉 |
| 学历被质疑 | 提供学信网验证报告 |

---

## 六、遭遇就业歧视怎么办

常见歧视类型：性别、婚育、民族、地域、健康状况（与岗位无关）。

| 步骤 | 动作 |
| --- | --- |
| 1 | 保留证据（录音、聊天记录、招聘要求截图） |
| 2 | 向人社部门投诉 |
| 3 | 必要时提起诉讼 |

详见「面试中的劳动法问题」。

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「入职体检必须查乙肝」 | **明文禁止** |
| 「公司想看什么就给什么」 | 信息提供应限于必要范围 |
| 「背调不用我同意」 | 应取得授权 |
| 「体检不合格就不能入职」 | 取决于是否与岗位要求相关 |
| 「被歧视没办法」 | 可投诉、可诉讼 |

---

## 八、可执行清单

### 体检前

- [ ] 确认体检项目，看有没有乙肝项目
- [ ] 有异议当场提出

### 背调

- [ ] 要求说明背调范围
- [ ] 确认已获你的授权
- [ ] 保留授权文件

### 遇到问题

- [ ] 保留证据
- [ ] 向人社部门反映

---

## 九、一句话记住

**入职体检不能查乙肝。背调必须经你授权，范围限于与岗位相关的信息。**
