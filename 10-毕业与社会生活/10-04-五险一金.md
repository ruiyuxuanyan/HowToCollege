# 五险一金是什么：缴费、个人账户、断缴后果

> 一句话概括：五险里工伤和生育个人不缴，养老和医疗有一部分进你自己的账户，断缴最先影响的是医保。

**适用人群**：第一次入职、第一次看到工资条上「社保公积金」扣款的人；准备跳槽、担心断缴的人；不确定自己交的钱去哪了的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国社会保险法》（2011 年 7 月 1 日起施行）；《住房公积金管理条例》（国务院令，2002 年修订）；《工伤保险条例》《失业保险条例》《企业职工基本养老保险个人账户管理办法》等
> - 全国统一 / 地方执行：**险种设置、个人账户归属、待遇享受条件等框架全国统一；缴费比例、缴费基数上下限、公积金规则、待遇标准全部由地方规定**
> - 核查日期：2026-11-05
> - 已知变化：**各地缴费比例与基数上下限逐年调整**

> ⚠️ **本文不写任何缴费比例数字。** 原因很简单：五险一金的缴费比例和基数上下限由各省市自行规定，且每年调整，任何统一数字都是错的。本文只讲**结构、归属和影响**，比例请查当地社保局与公积金管理中心公布的当年标准。

> ⏳ 易过时：缴费比例、基数上下限、公积金提取规则。

## 一、五险一金分别是哪几个

「五险」是社会保险的五个险种，「一金」是住房公积金。**公积金不是社保**，是独立的住房储金制度。

| 名称 | 类别 | 谁缴 | 钱去哪 | 用途 |
| --- | --- | --- | --- | --- |
| 养老保险 | 五险 | **单位 + 个人** | 单位部分进统筹基金；个人部分进**个人账户** | 退休后按月领养老金 |
| 医疗保险 | 五险 | **单位 + 个人** | 单位部分进统筹；个人部分进**个人账户**（部分地区个人账户划入规则有调整） | 看病报销、药店购药 |
| 失业保险 | 五险 | **单位 + 个人** | 进失业保险基金 | 失业后符合条件可领失业金 |
| 工伤保险 | 五险 | **仅单位** | 进工伤保险基金 | 工伤医疗、伤残待遇 |
| 生育保险 | 五险 | **仅单位** | 进生育保险基金 | 生育医疗费用、生育津贴 |
| 住房公积金 | 一金 | **单位 + 个人** | 全部进**个人公积金账户** | 购房、租房、建房等 |

### 1.1 最重要的一行：谁不缴

**工伤保险、生育保险，个人不缴费。** 这是两个最常见的误解。

如果工资条上出现「工伤险（个人）」「生育险（个人）」的扣款，要么是名目写错了，要么是公司在变相扣钱——**这两种情况都值得问清楚。**

【法规】《社会保险法》第三十三条规定，职工应当参加工伤保险，由用人单位缴纳工伤保险费，职工不缴纳工伤保险费；第五十三条规定，职工应当参加生育保险，由用人单位按照国家规定缴纳生育保险费，职工不缴纳生育保险费。

## 二、哪些钱真的进了「你自己的账户」

这是最实用的一节：很多人交了几年社保，不知道自己名下到底有什么。

| 项目 | 是否进个人账户 | 说明 |
| --- | --- | --- |
| 养老保险 · 个人缴费部分 | **是** | 计入基本养老保险个人账户，可查询、可继承 |
| 养老保险 · 单位缴费部分 | **否** | 进统筹基金，用于当期已退休人员 |
| 医疗保险 · 个人缴费部分 | **是** | 计入医保个人账户（各地划入方式不同） |
| 医疗保险 · 单位缴费部分 | **否** | 进统筹基金，用于住院等报销 |
| 失业保险 | 否 | 进基金，不设个人账户 |
| 工伤保险 | 否 | 进基金，不设个人账户 |
| 生育保险 | 否 | 进基金，不设个人账户 |
| 住房公积金 · 单位和个人部分 | **全部是** | 单位和你的钱都进你的账户，**归你个人所有** |

### 2.1 三个可以直接查的地方

| 查什么 | 去哪查 |
| --- | --- |
| 养老保险个人账户余额、缴费明细 | 国家社会保险公共服务平台（si.12333.gov.cn）、电子社保卡、当地社保 App |
| 医保个人账户余额、消费记录 | 国家医保服务平台 App、当地医保公众号 |
| 公积金账户余额、缴存明细 | 当地住房公积金管理中心官网/App、全国住房公积金小程序 |

**建议**：入职三个月后查一次。如果查不到缴费记录，说明公司可能没缴或没足额缴——这是需要立刻处理的问题。

### 2.2 关于「个人账户」的两个常见误解

| 误解 | 实际 |
| --- | --- |
| 「我交的钱都在我自己账户里」 | 只有养老和医疗的**个人缴费部分**进个人账户；单位缴的大部分进统筹 |
| 「统筹的钱跟我没关系」 | 统筹是现收现付的共济机制。你的住院报销、退休后的基础养老金都来自统筹 |

## 三、五险各自的用途

### 3.1 养老保险

**核心逻辑**：累计缴费满 15 年且达到法定退休年龄，可按月领取基本养老金。

【法规】《社会保险法》第十六条：参加基本养老保险的个人，达到法定退休年龄时累计缴费满十五年的，按月领取基本养老金。

**注意三点**：

| 点 | 说明 |
| --- | --- |
| 「累计」不是「连续」 | 中间断缴不清零，累计计算 |
| 15 年是**最低门槛** | 不是「缴满就够」，缴得越久、基数越高，领得越多 |
| 不够 15 年 | 可延长缴费至满 15 年，或按当地规定处理【待核实】 |

【待核实】法定退休年龄的调整政策正在推进，具体实施时间与方式以国家正式公布的方案为准。

### 3.2 医疗保险

**断缴影响最直接的险种。** 报销范围限于起付线以上、封顶线以下、目录内费用；起付线、封顶线、报销比例**各地不同且按医院级别与参保类型区分**【待核实】。个人账户可用于定点药店购药、门诊自付部分等。

### 3.3 失业保险

**领取需同时满足三个条件**（《社会保险法》第四十五条）：

> 失业人员符合下列条件的，从失业保险基金中领取失业保险金：（一）失业前用人单位和本人已经缴纳失业保险费满一年的；（二）非因本人意愿中断就业的；（三）已经进行失业登记，并有求职要求的。
>
> 【法规】《社会保险法》第四十五条

**关键在「非因本人意愿中断就业」**：主动辞职通常不符合；被辞退、合同到期单位不续签等一般符合（见 10-06）。领取期限与标准与缴费年限挂钩，由地方规定【待核实】。

### 3.4 工伤保险

**个人不缴费，但保障最重。** 认定前提是工作时间、工作场所内因工作原因受到的事故伤害等（《工伤保险条例》第十四条、第十五条）。**单位未参保期间发生工伤，由单位按工伤保险待遇项目和标准支付费用。**

工伤认定有严格时限，出事当天就要报告并留证（诊断证明、事故现场记录），不要「等好了再说」。

《工伤保险条例》第十七条规定的两个时限：

| 谁申请 | 期限 | 起算点 |
| --- | --- | --- |
| **所在单位** | **30 日内** | 事故伤害发生之日，或被诊断、鉴定为职业病之日 |
| **职工本人、其近亲属、工会组织** | **1 年内** | 同上 |

【法规】《工伤保险条例》第十七条

**这条规定的实际意义**：如果单位拖着不申请（有些单位怕影响安全生产考核），**你自己或家人可以在 1 年内直接向用人单位所在地统筹地区社会保险行政部门申请**。不要因为「单位在办」就一直等，等到超过 1 年就麻烦了。

### 3.5 生育保险

**个人不缴费。** 待遇含生育医疗费用与生育津贴两部分；津贴按单位上年度职工月平均工资等口径计发，享受条件通常要求连续缴费满一定月数，**标准各地不同**【待核实】。

近年多地已将生育保险与职工基本医疗保险合并实施（「两险合并」），但**生育保险待遇不变**，只是经办合并。

### 3.6 住房公积金

**最像「自己的钱」的一项。** 单位和个人缴的钱**全部进你的个人账户，归你所有**；可用于购房（提取/贷款）、租房提取、建造翻修自住住房等。公积金贷款利率通常低于商业贷款，**提取规则各地差异极大**【待核实】。

## 四、缴费基数：比比例更值得关注

很多人只关心「比例是多少」，其实**缴费基数**对最终待遇的影响更大。

| 概念 | 含义 |
| --- | --- |
| 缴费基数 | 一般按职工本人上年度月平均工资确定（新入职按首月工资或合同约定工资） |
| 基数上下限 | **各地每年公布**，低于下限按下限、高于上限按上限 |
| 后果 | 公司按最低基数缴，你的养老与公积金积累会明显偏少 |

### 4.1 一个必须知道的权利

**按实际工资缴社保是单位的法定义务。** 如果公司统一按最低基数缴纳，属于未足额缴纳，你可以：

1. 先向 HR 确认缴费基数口径
2. 向当地社保经办机构或劳动保障监察投诉（12333）

**但要注意现实权衡**：按最低基数缴，你当期到手工资更多。这是一个「现在多拿」和「以后多领」的取舍——但**决定权不在公司单方面**，法律要求按实际工资缴。

### 4.2 工资条怎么看

每月对一遍这几项：

- [ ] 养老保险（个人）：有扣款
- [ ] 医疗保险（个人）：有扣款
- [ ] 失业保险（个人）：有扣款
- [ ] **工伤保险：不应有个人扣款**
- [ ] **生育保险：不应有个人扣款**
- [ ] 住房公积金（个人）：有扣款
- [ ] 缴费基数是否与你的工资相符

## 五、断缴的影响：分险种看

「断缴」的后果被说得过于笼统。实际上**每个险种的反应完全不同**。

| 险种 | 断缴影响 | 严重程度 |
| --- | --- | --- |
| **医疗保险** | **影响最快最直接**：断缴后次月起可能无法享受统筹报销（各地规则不同）；重新参保可能有等待期 | 🔴 高 |
| 养老保险 | 累计计算，断缴不清零，但**缴费年限少了，养老金会少** | 🟡 中 |
| 失业保险 | 影响累计缴费年限，进而影响可领取期限 | 🟡 中 |
| 工伤保险 | 断缴期间发生工伤，**由单位按工伤保险待遇标准支付** | 🟡 中（对个人而言单位仍需担责） |
| 生育保险 | 通常要求连续缴费满一定月数，断缴可能影响待遇享受【待核实】 | 🔴 高（计划生育者） |
| 住房公积金 | 断缴影响公积金贷款资格（多要求连续缴存一定月数）【待核实】 | 🟡 中 |

### 5.1 医保断缴：最需要注意的一条

【待核实】各地规则不同，但普遍存在以下机制：

- 断缴后**次月起**停止享受统筹基金支付待遇（个人账户余额一般仍可使用）
- 重新参保后可能有**等待期**，等待期内医疗费用不予报销
- 连续缴费年限可能**重新计算**，影响某些待遇

**做法**：换工作时尽量让社保无缝衔接。多数地区在每月固定日期前缴纳即算当月参保，具体截止日请查当地社保局规定【待核实】。

### 5.2 买房、落户看的是「连续年限」

这是断缴最容易被低估的影响。

| 场景 | 通常要求 |
| --- | --- |
| 部分城市购房资格 | 需**连续**缴纳社保或个税满一定年限（**年限与城市差异极大**）【待核实】 |
| 部分城市落户/积分落户 | 社保连续缴纳年限是重要指标【待核实】 |
| 车牌摇号（部分城市） | 需连续缴纳社保/个税【待核实】 |
| 子女入学（部分地区） | 家长社保连续缴纳记录【待核实】 |

**关键区别**：

> **养老看「累计」，买房落户看「连续」。** 断缴一个月，累计年限还在，但连续年限可能归零重算。

这就是为什么有人「只断了一个月」却要重新等好几年——**具体规则各城市不同，务必查目标城市当年的政策**。

【待核实】上述各类「连续年限」要求均由各城市自行规定，且逐年调整，本文不写任何具体年限数字。

### 5.3 断缴了怎么补

| 情形 | 能否补缴 |
| --- | --- |
| 单位原因导致漏缴 | **可以要求单位补缴**，属单位法定义务 |
| 个人原因中断（如裸辞） | 多数地区**不允许个人补缴**历史中断月份【待核实】 |
| 灵活就业期间 | 可按灵活就业人员身份参保，但通常不能补缴过去月份 |

**最实用的建议**：**尽量不要裸辞，或裸辞前先确认当地的灵活就业参保办法**（详见 10-09）。空窗期可以以灵活就业身份继续缴医保，避免待遇中断。

## 六、换工作时怎么不断缴

| 情形 | 做法 |
| --- | --- |
| 无缝入职 | 确认两家公司的参保月份能接上 |
| 中间有空窗 | 空窗期以**灵活就业人员**身份参加职工医保（各地渠道不同） |
| 跨省换工作 | 通过国家社会保险公共服务平台办社保转移接续；公积金用全国住房公积金小程序办异地转移 |

**关键动作**：离职前问清「社保缴到哪个月」，入职后确认「从哪个月开始缴」，有空档就提前安排。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「工伤和生育个人也要交」 | **个人不缴**，全部由单位缴（《社会保险法》第三十三条、第五十三条） |
| 「我交的社保都在我个人账户里」 | 只有养老、医疗的**个人缴费部分**进个人账户；单位缴的进统筹 |
| 「公积金是公司的钱」 | 单位和个人缴的**全部归你个人所有** |
| 「断缴三个月就清零了」 | 养老保险是**累计**计算，不清零；清零的是部分城市的**连续年限** |
| 「社保缴满 15 年就不用缴了」 | 15 年是**领取的最低门槛**，不是「缴够就行」 |
| 「公积金只能买房用」 | 还可用于租房提取、建造翻修等，规则各地不同 |
| 「按最低基数缴对我更划算」 | 当期到手多，但养老与公积金积累少；且按实际工资缴是单位法定义务 |
| 「主动辞职也能领失业金」 | 需「非因本人意愿中断就业」，主动辞职通常不符合 |
| 「医保断缴只是暂时不能用」 | 重新参保可能有等待期，且连续缴费年限可能重算 |

## 可执行清单

**入职第一个月**

- [ ] 核对工资条：五险一金是否都有，**工伤和生育是否被错误扣了个人部分**
- [ ] 问清缴费基数是多少、按什么口径确定
- [ ] 确认社保从哪个月开始缴

**入职三个月后**

- [ ] 在国家社会保险公共服务平台查养老缴费记录
- [ ] 在国家医保服务平台查医保个人账户
- [ ] 在公积金中心渠道查缴存记录
- [ ] 三项都能查到 → 正常；查不到 → 立即问 HR

**换工作前**

- [ ] 问清现公司社保缴到哪个月
- [ ] 确认新公司从哪个月开始缴
- [ ] 有空窗期的，提前查当地灵活就业参保办法
- [ ] 跨省的，准备社保与公积金转移接续

**长期**

- [ ] 每年查一次缴费基数是否随工资调整
- [ ] 打算在某城市买房/落户的，**提前查该城市对「连续缴纳」的具体要求**，不要等到要用时才发现断了

---

## 一句话记住

**工伤和生育个人不缴，公积金全归你；养老看累计、买房看连续、医保断缴最要命——比例和年限各地不同，查当地当年标准。**
