# 第一次租房：毕业后独立租房的实操清单

> 一句话概括：毕业后租房没有学校兜底，水电燃气要过户、长租公寓有暴雷风险，合同和押金仍是最大的坑。

**适用人群**：刚毕业、第一次完全独立租房的社招新人；跨城市入职、需要先落脚的人；正在纠结长租公寓还是个人房源的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国民法典》第三编第十四章「租赁合同」（第七百零三条至第七百三十四条）；《商品房屋租赁管理办法》（住房和城乡建设部令第 6 号）；《住房租赁条例》（2025 年施行）
> - 全国统一：租赁合同的法定规则、押金与租金的基本约束、出租人义务全国统一
> - 地方执行：租赁备案、群租房认定标准、水电燃气过户流程、租金指导政策均属地方
> - 核查日期：2026-11-05
> - 已知变化：《住房租赁条例》已于 2025 年施行，对住房租赁企业与经纪机构提出更明确的监管要求

> **与 05-06 的边界**：`在校期间租房`（05-06）讲的是学生身份下的租房，有学校、宿舍、家长作为兜底。本文讲**毕业后第一次完全独立租房**——没有兜底，且要处理水电燃气过户、居住证、通勤等一整套新问题。**合同与押金的基础框架请看 05-06，本文不重复，只讲毕业后特有的部分。**

> ⏳ 易过时：地方租赁备案规则、群租房认定标准、水电燃气过户流程。

## 一、毕业租房和在校租房，差在哪

先把差异想清楚，才知道该多准备什么。

| 维度 | 在校租房（05-06） | 毕业后租房（本文） |
| --- | --- | --- |
| 兜底 | 有宿舍可退、有学校可找、有家长支援 | **没有兜底**，退租就要重新找房 |
| 租期 | 常按学期、可按月 | 通常一年起签，押一付三常见 |
| 水电燃气 | 多数由房东代收或已含 | **需要自己过户、自己开户缴费** |
| 居住证/积分 | 一般不涉及 | 涉及居住登记、居住证、积分落户 |
| 通勤成本 | 校园周边，距离短 | 通勤直接决定生活质量，必须算进预算 |
| 中介与平台 | 多为本地中介 | 长租公寓、平台化房源占比高，**有暴雷风险** |
| 收入关系 | 靠生活费 | 房租占收入比例直接决定你的现金流 |

**结论**：毕业后租房的核心矛盾从「别被房东坑」变成了「**别被结构性风险坑**」——长租公寓暴雷、租金贷、押金不退、公司搬迁导致通勤崩盘。

## 二、先算三笔账，再去看房

很多人先看房再算钱，顺序反了。先算清楚，能省掉大量无效看房。

### 2.1 第一笔：房租占收入多少

没有一个全国通用的「合理比例」。但可以用一个判断方法：

| 情形 | 判断 |
| --- | --- |
| 房租 + 水电燃气 + 物业 + 通勤 后，你还能否稳定存下一点钱 | 能 → 可持续 |
| 每月工资发下来，交完房租就见底 | 高风险，一次意外支出就会击穿 |
| 需要靠信用卡/花呗垫付房租 | **不要签**，这是负债螺旋的起点 |

**【经验】一个可用的自我检查**：把「首月总支出」算出来——押金 + 首月租金 + 中介费 + 添置家具家电 + 水电燃气开户 + 通勤卡。这笔钱往往是月租的数倍，很多人只准备了租金。

### 2.2 第二笔：通勤

| 通勤单程 | 实际感受 |
| --- | --- |
| 30 分钟内 | 可长期维持 |
| 30–60 分钟 | 大多数人能接受，但会明显挤压个人时间 |
| 60 分钟以上 | 长期会显著影响状态，且加班后回家困难 |

**关键提醒**：**不要用「地图上的直线距离」判断通勤。** 要按你的实际通勤方式（地铁换乘次数、是否需要公交接驳、早高峰拥挤程度）实测一次。

**最好在工作日的早高峰实地走一遍。** 这一步能筛掉一半看起来便宜的房子。

### 2.3 第三笔：隐形成本

| 项目 | 说明 |
| --- | --- |
| 中介费 | 通常为一个月租金的一定比例，各地惯例不同，**签前问清谁承担** |
| 物业费、取暖费 | 谁承担必须在合同里写明（北方取暖费金额不小） |
| 水电燃气开户/过户 | 部分需要押金或预存 |
| 网络 | 是否已覆盖，需不需要自己装 |
| 家具家电 | 「拎包入住」是否真的齐全，缺什么要自己买 |
| 押金 | 通常押一付三或押一付一，**退还条件必须写清** |

## 三、房源渠道：三种，各有各的坑

### 3.1 个人房东直租

| 优势 | 风险 |
| --- | --- |
| 无中介费、沟通直接 | 合同往往不规范，条款对租客不利 |
| 价格可谈 | 房东可能随时涨价或卖房 |
| — | **要核实对方是不是真房东**（见 3.4） |

### 3.2 中介（经纪机构）

| 优势 | 风险 |
| --- | --- |
| 房源多、流程熟 | 中介费；「二房东」冒充房东；虚假房源引流 |
| 有合同模板 | 口头承诺不写进合同 |

**核实要点**：中介机构应有营业执照并在住建部门备案；经纪人应有从业信息卡。**要求看备案信息，不给看的直接换一家。**

### 3.3 长租公寓 / 平台化房源（风险最高的一类）

这是毕业后最容易踩的坑，也是最需要单独讲的一类。

**模式**：平台从房东处收房，装修后转租给租客，租客向平台付租金。

**结构性风险**：

| 风险 | 机制 |
| --- | --- |
| **平台暴雷** | 平台资金链断裂，房东收不到租金 → 房东要求租客搬走，而租客已付的租金要不回 |
| **租金贷** | 平台引导你签「分期付租」，实际是**贷款合同**。平台跑路，你仍要还贷 |
| **高收低租** | 以高于市场价收房、低于市场价出租，靠时间差套资金，本质不可持续 |

**识别信号**：

- [ ] 要求你**年付/半年付**才能享受「优惠价」
- [ ] 引导你下载第三方 App 签「分期」「月付」协议
- [ ] 合同主体是**金融机构**而不是租赁公司
- [ ] 报价**明显低于**同小区同类房源
- [ ] 催你尽快签约，不给查证时间

**一条铁律**：**任何要求你把「租金」变成「贷款」的操作，立即停止。**（这与 09-03 培训贷的识别逻辑完全一致）

**已经签了怎么办**：

1. 保存合同、付款记录、App 内的借款协议
2. 向 12315、当地住建部门投诉
3. 向放款金融机构书面提出异议
4. 与房东直接沟通，避免被两边夹击
5. 涉及金额较大的，联合其他租客共同维权并咨询律师

### 3.4 怎么确认真房东

**这一步不能省。** 二房东跑路后，你既没有房子也没有押金。

| 核实项 | 怎么做 |
| --- | --- |
| 房产证 | 要求看**不动产权证书**原件，核对产权人姓名 |
| 身份证 | 核对身份证姓名与产权人是否一致 |
| 若为二房东 | 要求看**原房东的书面同意转租证明**（《民法典》第七百一十六条：承租人经出租人同意，可以将租赁物转租给第三人） |
| 若为中介代管 | 要求看**授权委托书** |
| 可疑情况 | 到不动产登记中心或通过当地政务 App 核验权属信息 |

【法规】《民法典》第七百一十六条：承租人经出租人同意，可以将租赁物转租给第三人。承租人转租的，承租人与出租人之间的租赁合同继续有效；第三人造成租赁物损失的，承租人应当赔偿损失。**承租人未经出租人同意转租的，出租人可以解除合同。**

**这条的法律含义**：如果二房东没取得原房东同意，原房东可以解除合同，你就会被清退。所以「同意转租的书面证明」不是形式主义。

## 四、合同：毕业后要额外加进去的条款

基本框架（租金、押金、维修责任、违约责任）请看 05-06。这里只讲**毕业后场景需要额外明确**的部分。

### 4.1 必须在合同里写清的 8 项

- [ ] **水电燃气费用由谁承担、怎么抄表结算**（入住当天的表数拍照留证）
- [ ] **物业费、取暖费由谁承担**
- [ ] **家具家电清单**（逐项列明品牌数量与状态，最好拍照附在合同后）
- [ ] **维修责任划分**（自然损耗 vs 人为损坏；哪些由房东修）
- [ ] **提前退租的条件与违约金**
- [ ] **房东提前收房的补偿**
- [ ] **押金退还的条件与时限**（写明「退房后 X 日内退还」）
- [ ] **能否转租、能否养宠物、能否改动墙面**

### 4.2 三个容易吃亏的点

| 条款 | 问题 | 怎么写 |
| --- | --- | --- |
| 「押金退房时视房屋情况退还」 | 「情况」没定义，等于房东说了算 | 写明退还条件与具体天数 |
| 「房东有权提前 30 日通知收回房屋」 | 你会被动搬家 | 要求约定补偿或删除 |
| 「水电费按人头均摊」 | 合租时容易扯皮 | 写明按表计费或明确分摊方式 |

### 4.3 入住当天必做的取证

**这一步决定了你退租时能不能拿回押金。**

- [ ] 全屋拍照/录像（墙面、地板、家具、家电、卫浴）
- [ ] 水电燃气表读数拍照
- [ ] 有损坏的地方单独拍特写，并当场告知房东（微信留痕）
- [ ] 家具家电清单双方签字确认

**照片要带时间信息**（手机相机默认带），并备份到云端——一年后你才会用到它们。

## 五、水电燃气过户与居住登记

在校时多是房东代收，毕业后你要自己开户。这一步不做，会遇到「无法缴费」「欠费挂在你名下」等问题。

| 项目 | 办理要点 |
| --- | --- |
| 电 | 通过「网上国网」App 或当地供电营业厅办理过户/新装；核对户号 |
| 水 | 当地自来水公司营业厅或线上渠道办理过户 |
| 燃气 | **必须到燃气公司办理**，涉及安全检查；不要私自改动管道 |
| 供暖（北方） | 确认是否已开通，费用承担方在合同中约定 |
| 网络 | 确认楼栋已覆盖的运营商，避免只能选一家高价套餐 |

**关键动作**：

1. 入住当天记录**表底数**并拍照
2. 问清上一个租客是否已结清欠费
3. 办理过户时**把户名改成你自己**，否则欠费可能记在房东名下、你无法查询

【待核实】各地水电燃气的过户渠道与所需材料不同（部分地区支持线上一站式办理），请查询当地供电/供水/燃气公司公布的流程。

---

### 5.1 居住登记与居住证

毕业后租房，还涉及一个在校时不关心的问题。

| 事项 | 说明 |
| --- | --- |
| 居住登记 | 多地要求非本地户籍人员在居住地办理居住登记，通常由本人或房东配合申报 |
| 居住证 | 居住登记满一定期限后可申领，用于子女入学、积分、部分证件办理等 |
| 租赁备案 | 部分城市要求租赁合同备案，备案后可用于居住证、积分、个税专项附加扣除等 |

【待核实】居住登记与居住证的办理条件、所需材料、办理渠道（派出所/社区/线上政务平台）**各城市差异很大**，请查询居住地公安机关或政务服务平台的现行规定。

**提示**：租房合同是办理居住登记的基础材料之一，所以**签合同要签规范合同、留好原件**。这与个税住房租金专项附加扣除也直接相关（见 10-07）。

## 六、退租与押金

| 步骤 | 做法 |
| --- | --- |
| 提前告知 | 按合同约定的提前通知期告知房东（通常提前一个月） |
| 恢复原状 | 清理个人物品、打扫卫生、恢复擅自改动的地方 |
| 共同验收 | **要求房东到场当面验收**，不要直接交钥匙走人 |
| 结清费用 | 水、电、燃气、物业费当场结清并留凭证 |
| 押金退还 | 按合同约定时限要求退还；未按期退还可书面催告 |
| 留证 | 退房当天再拍一次全屋照片/录像 |

**押金不退怎么办**：

1. 书面催告（微信/短信留痕，写明金额与期限）
2. 向当地住建部门或 12345 投诉
3. 金额较大或对方拒不配合的，可向人民法院起诉（小额诉讼程序成本较低）

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「年付更便宜，一次付清省事」 | 年付把风险全押在对方履约上，长租公寓暴雷时损失最大 |
| 「平台说月付就月付，签个协议而已」 | 那份「月付协议」可能是贷款合同 |
| 「二房东也是房东」 | 未经原房东同意的转租，原房东可解除合同，你会被清退 |
| 「押金条丢了就退不了」 | 押金退还应以合同与转账记录为依据；但押金条是重要凭证，务必保存 |
| 「水电费房东代收就行」 | 代收容易产生争议；毕业租房应自己过户并核对表数 |
| 「合同签得简单点，反正都是模板」 | 模板里缺的正是维修、退租、押金条款 |
| 「房子便宜就租，远点没关系」 | 通勤时间会真实消耗你的时间与状态，必须实测 |
| 「口头承诺也算数」 | 没写进合同的口头承诺，举证极难 |

## 可执行清单

**看房前**

- [ ] 算出「首月总支出」（押金+租金+中介费+添置+开户）
- [ ] 确定房租上限（含水电物业通勤后的可持续性）
- [ ] 圈定通勤 60 分钟内的区域
- [ ] 准备好核实材料清单（房产证、身份证、授权文件）

**看房时**

- [ ] 工作日早高峰实测一次通勤
- [ ] 检查水压、下水、电路、门窗、隔音、手机信号
- [ ] 检查有无霉斑、渗水痕迹
- [ ] 确认家具家电清单与实际是否一致
- [ ] 确认水电气表位置与读数

**签约前**

- [ ] 核实房东身份与产权（房产证 + 身份证）
- [ ] 二房东：要有原房东书面同意转租证明
- [ ] 中介：查营业执照与备案信息
- [ ] 合同逐条读，补齐第四节列的 8 项
- [ ] **拒绝任何「租金变贷款」的分期协议**
- [ ] 不签空白合同，不签只有一份的合同（你要留一份原件）

**入住当天**

- [ ] 全屋拍照/录像
- [ ] 水电气表读数拍照
- [ ] 损坏处特写并微信告知房东
- [ ] 家具家电清单签字
- [ ] 办理水电燃气过户，户名改为本人
- [ ] 确认上一租客无欠费

**退租时**

- [ ] 按合同提前通知
- [ ] 打扫并恢复原状
- [ ] 当面验收、结清费用
- [ ] 再拍一次全屋照片
- [ ] 书面催告押金退还

---

## 一句话记住

**毕业后租房，合同和押金的规矩没变，变的是没人兜底——所以先算清首月总支出、实测一次通勤、拒绝任何「租金变贷款」，入住当天把照片拍全。**
