# 档案在哪、有什么用、丢了怎么补

> 一句话概括：这份你看不见的纸质材料，会在十年后决定你能不能考公、退休算几年工龄。

**适用人群**：所有在校生和毕业生，尤其准备考公、进国企、考研的人。

> **政策适用范围**
> - 主要依据：中组部等五部门《关于做好取消普通高等学校毕业生就业报到证有关衔接工作的通知》（2023）；《流动人员人事档案管理服务规定》
> - 全国统一：档案不得个人保管、不得拆封、机要转递
> - 地方执行：接收机构名称与地址各地不同
> - 核查日期：2026-11-05

---

## 一、档案里装了什么

| 类别 | 内容 |
| --- | --- |
| 学籍材料 | 成绩单、毕业生登记表、学籍卡、奖惩记录 |
| 党团材料 | 入党（团）志愿书、申请书 |
| 工作材料 | 劳动合同、转正定级表、职称材料 |
| 其他 | 政审材料、体检表 |

**注意**：档案是**原始纸质材料**，不是电子版。所以才有保管、转递那一套规矩。

---

## 二、档案有什么用

| 用途 | 说明 | 谁受影响 |
| --- | --- | --- |
| **考公政审** | 必须有档案，且内容完整 | 考公考编者 |
| **进国企/事业单位** | 同上 | 相关求职者 |
| **职称评定** | 需要档案中的工作记录 | 教师、工程师等 |
| **退休工龄认定** | 视同缴费年限要看档案 | 所有人（长期） |
| **部分城市落户** | 需要档案转递 | 落户申请者 |
| 考研复试/录取 | 部分学校需要 | 考研者 |

**最容易被忽视的是第四项**：退休时算多少年工龄，取决于档案里有没有相应记录。这个问题可能几十年后才出现，但那时补救极难。

---

## 三、档案应该在哪儿

| 你的身份 | 档案存放地 |
| --- | --- |
| 在校生 | 学校（学生处/档案馆） |
| 国企、机关、事业单位 | 单位人事部门 |
| 民企、外企 | 就业地人才服务中心 或 户籍地人才服务中心 |
| 待业/灵活就业 | **户籍地**人才服务中心或公共就业服务机构 |
| 考研升学 | 录取学校 |
| 出国 | 户籍地人才服务中心（或学校暂存，有期限） |

---

## 四、三件绝对不能做的事

### 4.1 不要自己拿着

个人保管的档案，接收单位**有权拒收**。一旦被拒，就要重新走转递流程，非常麻烦。

### 4.2 不要拆封

**拆封即失效。**

档案袋封口处有密封条和公章，一旦拆开，接收单位无法确认材料真实性，可能拒收。**即使你只是想看看里面有什么，也不行。**

### 4.3 不要长期不管

档案不会自己「找上门」。毕业后不确认，几年后可能查不到在哪。

---

## 五、怎么查档案在哪

按顺序找：

1. **毕业学校**的就业指导中心或档案馆（问最后一次转递记录）
2. **户籍地**的人才服务中心
3. **就业地**的人才服务中心
4. 曾就职的**国企/事业单位**人事部门
5. 全国人才流动中心档案查询服务

**打电话时问三个问题**：
- 我的档案在不在这里？
- 在的话，什么时候转入的？
- 不在的话，能查到转往哪里了吗？

---

## 六、档案怎么转（不能自己送）

**必须走机要通道**，不能快递、不能自己拿。

| 环节 | 谁做 |
| --- | --- |
| 开转递通知单 | 原保管单位 |
| 机要寄送 | 原保管单位 |
| 接收并回执 | 新保管单位 |
| 确认到达 | **你**（打电话问） |

**你要做的只有一件事：确认到达。** 这一步不能省。

---

## 七、档案丢了怎么补

这是最麻烦的情况，但可以补。

### 7.1 补办顺序

| 步骤 | 补什么 | 找谁 |
| --- | --- | --- |
| 1 | 学籍材料（成绩单、毕业生登记表） | 原毕业学校档案馆 |
| 2 | 党团材料 | 原学校党委/团委 |
| 3 | 工作材料（劳动合同、离职证明） | 各单位人事部门 |
| 4 | 重新建档 | 现档案保管单位 |

### 7.2 现实提醒

- 补办可能耗时数月到一年以上
- 有些材料可能永久缺失（如已撤销的学校或单位）
- **补办的档案与原始档案不完全等同**，部分单位会注明「补建」

**所以：比补办更重要的，是别弄丢。**

---

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「档案没用，我进私企」 | 考公、职称、退休工龄都要用 |
| 「放自己手里最保险」 | 会成为「死档」，单位可拒收 |
| 「拆开看看内容」 | 拆封即失效 |
| 「学校会自动寄到正确地方」 | 学校按你填的地址寄，填错就寄错 |
| 「档案走快递快一点」 | 必须机要通道，快递不接收 |
| 「丢了就算了」 | 影响考公、职称、退休待遇 |

## 九、可执行清单

### 在校期间

- [ ] 知道自己的档案现在在哪个部门
- [ ] 如入党入团，确认材料已归档

### 毕业前

- [ ] 确认接收单位的**全称、地址、邮编、联系人电话**
- [ ] 向学校提交档案转递申请

### 毕业后（关键）

- [ ] **1 个月内**：打电话确认是否收到
- [ ] **3 个月内**：如未确认，务必核实
- [ ] 保存好档案转递通知单

### 换工作时

- [ ] 新单位能接收档案的，办转递
- [ ] 不能接收的，转到人才中心，别自己拿
