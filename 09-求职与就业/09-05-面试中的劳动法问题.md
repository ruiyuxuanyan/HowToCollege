# 面试中的劳动法问题：能不能问婚育

> 一句话概括：用人单位可以问「能不能胜任」，不可以问「结没结婚、生不生二胎」。

**适用人群**：正在面试的女学生、已婚未育者；被问过隐私问题不知道怎么答的人；做过 HR 的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国就业促进法》（2015 年修正）第三条、第二十七条、第二十九条、第六十二条；《中华人民共和国妇女权益保障法》（2022 年修订）第四十三条、第四十八条、第七十七条；《中华人民共和国劳动法》第十二条、第十三条
> - 全国统一：**就业歧视的禁止性规定全国统一适用**
> - 地方执行：投诉受理、罚款执行由属地人社部门/法院
> - 核查日期：2026-11-05
> - 已知变化：2022 年《妇女权益保障法》修订，**明确将「询问或调查女职工婚育情况」列为禁止行为**，并新增公益诉讼条款

---

## 一、法律划的线：能问什么，不能问什么

判断标准只有一条：**这个问题与「能不能胜任这份工作」是否直接相关。**

| 能问（与岗位直接相关） | 不能问（与岗位无关） |
| --- | --- |
| 学历、专业、毕业时间 | 婚否、有无男友/女友 |
| 工作/实习经历、项目内容 | 是否计划生育、什么时候生 |
| 技能、证书、外语水平 | 有没有孩子、孩子谁带 |
| 能否接受出差、加班、外派 | 是否在备孕、有无流产史 |
| 能否接受该工作地点 | 月经情况、是否痛经 |
| 期望薪资、到岗时间 | 身高体重（除非岗位有法定要求） |
| 有无竞业限制、是否在服务期 | 宗教信仰、政治面貌（除特定岗位） |
| 是否与其他单位存在劳动关系 | 父母职业、家庭收入 |
| 有无犯罪记录（特定岗位） | 是否单身、有无婚史 |

**灰色地带**：「能否接受出差」「能否接受异地派驻」是合法的，因为直接关系履约能力；但如果对方只问女性、不问男性，就构成差别对待。

## 二、法条原文

### 2.1 《就业促进法》第三条

> 劳动者依法享有平等就业和自主择业的权利。
>
> 劳动者就业，不因民族、种族、性别、宗教信仰等不同而受歧视。
>
> 【法规】《中华人民共和国就业促进法》第三条（2015 年 4 月 24 日修正）

### 2.2 《就业促进法》第二十七条（最关键的一条）

> 国家保障妇女享有与男子平等的劳动权利。
>
> 用人单位招用人员，除国家规定的不适合妇女的工种或者岗位外，不得以性别为由拒绝录用妇女或者提高对妇女的录用标准。
>
> 用人单位录用女职工，不得在劳动合同中规定限制女职工结婚、生育的内容。
>
> 【法规】《中华人民共和国就业促进法》第二十七条

这一条包含两个禁止：

1. **不得以性别为由拒绝录用或提高录用标准**
2. **不得在劳动合同中约定限制结婚、生育**——意味着「入职三年内不得生育」这类条款**本身无效**

### 2.3 《妇女权益保障法》第四十三条（2022 年新增的关键条款）

2022 年 10 月 30 日修订、2023 年 1 月 1 日起施行的《妇女权益保障法》，把这件事写得更明确：

> 用人单位在招录（聘）过程中，除国家另有规定外，不得实施下列行为：
>
> （一）限定为男性或者规定男性优先；
> （二）除个人基本信息外，进一步询问或者调查女性求职者的婚育情况；
> （三）将妊娠测试作为入职体检项目；
> （四）将限制结婚、生育或者婚姻、生育状况作为录用条件；
> （五）其他以性别为由拒绝录用妇女或者差别化地提高对妇女录用标准的行为。
>
> 【法规】《中华人民共和国妇女权益保障法》第四十三条（2022 年 10 月 30 日修订，2023 年 1 月 1 日起施行）

**这一条是本文最重要的依据。** 它把三类行为直接写成了禁止：

| 禁止行为 | 具体表现 |
| --- | --- |
| 询问/调查婚育情况 | 「你结婚了吗」「打算什么时候要孩子」「有没有男朋友」 |
| 妊娠测试作为入职体检 | 入职体检里加验孕项 |
| 婚育状况作为录用条件 | 「我们这岗位希望是已婚已育的」 |

### 2.4 法律责任

> 违反本法规定，侵害妇女合法权益，其他法律、法规规定行政处罚的，从其规定；造成财产损失或者其他损害的，依法承担民事责任；构成犯罪的，依法追究刑事责任。
>
> 【法规】《妇女权益保障法》第七十七条（2022 年修订）

此外，《就业促进法》第六十二条规定：

> 违反本法规定，实施就业歧视的，劳动者可以向人民法院提起诉讼。
>
> 【法规】《就业促进法》第六十二条

**要点**：就业歧视案件**可以直接向法院起诉**，不以劳动仲裁为前置程序（因为此时尚未建立劳动关系）。

【待核实】具体赔偿标准、举证责任分配在各地司法实践中存在差异，需以受理法院的裁判观点为准。建议咨询当地法律援助或执业律师。

## 三、被问了婚育问题，怎么应对

现实中你未必想当场对抗——毕竟你想要这份工作。所以这里给三档策略，从温和到强硬，**按你的处境选**。

### 3.1 策略一：转移焦点（推荐首选）

不正面回答，把话题拉回能力。

> 「我理解公司关心稳定性。我这边的考虑是，未来几年我的重心在职业发展上，这个岗位需要的 XX 能力我已经有 XX 准备。关于到岗时间和投入度，我可以明确说……」

**为什么有效**：既没有正面拒绝（避免当场僵住），也没有提供婚育信息，同时把评估维度拉回岗位胜任力。

### 3.2 策略二：反问边界（较硬）

> 「这个问题和岗位职责的关系是？如果公司担心的是出差或加班安排，我可以直接说明我的可接受范围。」

**效果**：多数 HR 会在此止步——因为继续追问等于书面确认违法。

### 3.3 策略三：明确拒绝（最硬）

> 「婚育情况属于个人隐私，与岗位胜任能力无关，我不方便回答。如果公司在招聘中有性别相关的考虑，我想这会涉及《妇女权益保障法》第四十三条。」

**代价**：可能失去这个机会。**收益**：这种公司往往在产假、晋升上同样有问题，早筛掉未必是坏事。

### 3.4 一个现实的提醒

**不要为了拿 offer 而说谎**（如谎称已绝育、已婚已育）。原因有二：

1. 谎报本身可能被用作后续解除的理由
2. 你会在一个「需要你撒谎才能进」的环境里工作很多年

## 四、这些条款本身就无效

有些公司在合同或入职材料里塞限制性条款。要知道这些条款的效力：

| 条款 | 效力 | 依据 |
| --- | --- | --- |
| 「入职 X 年内不得结婚/生育」 | **无效** | 《就业促进法》第二十七条第三款 |
| 「违反计划生育承诺视为严重违纪」 | 通常**无效** | 同上，且涉及基本权利 |
| 「入职体检须做妊娠测试」 | **违法** | 《妇女权益保障法》第四十三条第三项 |
| 「限男性」/「男性优先」（无法定理由） | **违法** | 《妇女权益保障法》第四十三条第一项 |
| 「已婚已育优先」 | **违法** | 属差别化录用标准 |

【法规】前两项依据《就业促进法》第二十七条第三款：「用人单位录用女职工，不得在劳动合同中规定限制女职工结婚、生育的内容。」

## 五、除了性别，还有哪些歧视被禁止

《就业促进法》第三条列举「民族、种族、性别、宗教信仰」，但实践中被禁止的歧视类型更广。以下区分「有明确法律依据」和「有争议/待明确」：

| 类型 | 法律地位 |
| --- | --- |
| 性别 | 明确禁止【法规】《就业促进法》第三条、第二十七条；《妇女权益保障法》 |
| 民族 | 明确禁止【法规】《就业促进法》第三条 |
| 种族 | 明确禁止【法规】《就业促进法》第三条 |
| 宗教信仰 | 明确禁止【法规】《就业促进法》第三条 |
| 残疾 | 明确禁止【法规】《就业促进法》第二十九条 |
| 传染病病原携带者 | 明确禁止（特定岗位除外）【法规】《就业促进法》第三十条 |
| 户籍 | 多地有规定限制【待核实】依据地方规定，非全国统一 |
| 年龄（35 岁门槛） | 无全国统一的明确禁止条款部分地区、部分岗位有规定 |
| 学历出身（非全日制/第一学历） | 无全国统一的明确禁止条款 |
| 婚育状况 | 对女性求职者明确禁止【法规】《妇女权益保障法》第四十三条 |

> 【法规】《就业促进法》第二十九条：国家保障残疾人的劳动权利。各级人民政府应当为残疾人创造就业条件。
>
> 【法规】《就业促进法》第三十条：用人单位招用人员，不得以是传染病病原携带者为理由拒绝录用。但是，经医学鉴定传染病病原携带者在治愈前或者排除传染嫌疑前，不得从事法律、行政法规和国务院卫生行政部门规定禁止从事的易使传染病扩散的工作。

**注意**：年龄、学历出身这类歧视，目前缺乏全国统一的禁止性条文，更多依赖地方规定和舆论监督。**不要把它们和性别歧视混为一谈**——维权路径不同。

## 六、被歧视了，怎么维权

### 6.1 先固定证据

这是最难的一步，因为歧视往往发生在口头对话中。

| 场景 | 怎么取证 |
| --- | --- |
| 招聘信息写「限男性」 | 截图 + 记录 URL + 时间（最好录屏） |
| 电话沟通被问婚育 | 提前告知录音（或直接录音，实务中可作为证据提交，合法性由法院判断） |
| 微信/邮件被问 | 保留原始聊天记录，不要只截图 |
| 面试现场 | 记录时间、地点、面试官姓名/工号、原话 |
| 入职体检含孕检 | 保留体检单原件 |
| 被拒后 | 保留拒信、要求对方书面说明理由 |

**取证纪律**：不要只截一张图。要能证明「谁、什么时候、在哪、说了什么」。

### 6.2 三条维权路径

| 路径 | 找谁 | 适用 |
| --- | --- | --- |
| 投诉举报 | 当地人力资源和社会保障局（12333） | 招聘环节的歧视 |
| 提起诉讼 | 人民法院（可直接起诉，无需先仲裁） | 要求赔偿、停止侵害 |
| 公益诉讼 | 检察机关（《妇女权益保障法》新增） | 侵害众多女性权益的情形 |

> 【法规】《妇女权益保障法》（2022 年修订）第七十七条明确了侵害妇女权益的民事责任、行政责任与刑事责任衔接，并规定了妇女权益保障公益诉讼制度。

### 6.3 现实的期待管理

说句实话：**单个求职者打赢就业歧视官司，难度不小。** 难点在于：

1. 取证难——歧视多是口头
2. 举证责任——多数情况下仍需你初步证明存在差别对待
3. 时间成本——诉讼周期长，而你已经在找下一份工作

所以更现实的做法是：**把「识别」放在「维权」前面**。面试中被问婚育，本身就是一个关于这家公司的重要信息。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「公司问婚育是关心我」 | 2022 年修订的《妇女权益保障法》第四十三条已明确禁止询问 |
| 「入职体检做孕检是常规」 | 明确违法，属《妇女权益保障法》第四十三条第三项 |
| 「合同里写了不能生育就得遵守」 | 该条款无效（《就业促进法》第二十七条第三款） |
| 「只有女性会被歧视」 | 男性也可能因性别被限制（如「限女性」的岗位），但法律重点保护女性 |
| 「问年龄也违法」 | 年龄歧视目前**缺乏全国统一禁止条款**，与性别歧视不同 |
| 「必须先去仲裁才能起诉」 | 就业歧视可直接向法院起诉（《就业促进法》第六十二条） |
| 「举报了也没用」 | 投诉可推动行政检查；即使个案效果有限，记录本身有价值 |
| 「撒个谎先拿到 offer」 | 谎报可能成为后续解除的理由，且你在为不诚信的环境买单 |

## 可执行清单

**面试前**

- [ ] 想好一句「不回答婚育问题」的转移话术（第三节策略一）
- [ ] 手机准备好录音功能（先确认当地关于录音证据的规则）
- [ ] 查一下这家公司有没有公开的歧视性招聘信息

**面试中**

- [ ] 被问婚育：先用策略一转移；对方追问再用策略二
- [ ] 记住原话、面试官身份、时间
- [ ] 不签署任何含「限制结婚/生育」条款的文件
- [ ] 拒绝入职体检中的妊娠测试项

**面试后**

- [ ] 当天把关键对话写成文字记录（时间、地点、人物、原话）
- [ ] 如果被以婚育为由拒绝，要求对方给出书面理由
- [ ] 招聘信息有「限男性」等表述的，截图留证

**维权时**

- [ ] 证据链完整（谁、何时、何地、说了什么）
- [ ] 先打 12333 咨询属地受理口径
- [ ] 涉及金额或影响较大的，咨询当地法律援助中心

## 一句话记住

**用人单位可以问你「能不能胜任」，不能问你「结没结婚、什么时候生」——后者从 2023 年起是明文禁止的。**
