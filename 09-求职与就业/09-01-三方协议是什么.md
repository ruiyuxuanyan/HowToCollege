# 三方协议是什么

> 一句话概括：它是一份有违约金的民事协议，不是劳动合同，也不是「意向书」。

**适用人群**：签过或准备签三方协议的毕业生；正在纠结要不要毁约的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国劳动合同法》第二十五条；《民法典》合同编；教育部关于高校毕业生就业的相关规定
> - 全国统一：三方协议的性质与违约金规则全国一致
> - 地方执行：各校发放/补发三方的流程不同
> - 核查日期：2026-11-07

---

## 一、三方协议到底是什么

**三方**指：毕业生、用人单位、学校。

**性质**：民事协议（不是劳动合同），受《民法典》调整。

**用途**：确认就业意向、办理户口档案转递、学校统计就业率。

---

## 二、和劳动合同的区别（关键）

| 项目 | 三方协议 | 劳动合同 |
| --- | --- | --- |
| 签约主体 | 学生 + 单位 + 学校 | 劳动者 + 单位 |
| 法律性质 | **民事协议** | **劳动合同** |
| 适用法律 | 《民法典》 | 《劳动合同法》 |
| 违约金 | **可以约定** | 除两种法定情形外**不得约定** |
| 签订时间 | 毕业前 | 入职后（用工起一个月内） |
| 能否替代彼此 | **不能** | **不能** |

### 最重要的一行：违约金

**三方协议可以约定违约金，而且有效。** 这是它和劳动合同最大的区别。

劳动合同里，只有「服务期」和「竞业限制」两种情形可以约定违约金（《劳动合同法》第二十五条）；但三方协议作为民事协议，双方可以自由约定。

**所以：签三方之前，一定要看清违约金那一条。**

---

## 三、常见违约金情况

| 情形 | 通常怎么处理 |
| --- | --- |
| 签了三方后不去 | 按约定付违约金 |
| 单位毁约 | 单位也应承担违约责任（但实践中学生维权较难） |
| 协商解除 | 双方同意可解除，通常不付违约金 |
| 因升学、参军等原因无法履约 | 多数单位会免除，但**要看协议约定** |

**违约金的常见金额**：几千元到一个月工资不等，没有法定上限（但畸高可请求调整）。

---

## 四、毁约怎么办（实操）

如果你已经签了三方，现在想毁约：

### 4.1 处理顺序

1. **先看协议的违约金条款**（多少、什么条件触发）
2. **与原单位协商**（说明原因，请求减免，态度诚恳往往有用）
3. **取得原单位出具的解除证明或同意函**
4. **向学校申请新的三方协议**（多数学校要求先有原单位解约函）
5. 与新单位签约

### 4.2 不要做的事

- **不要直接消失**。有些单位会记录，影响后续背调。
- **不要伪造解约函**。这是伪造文件，可能涉及法律责任。
- **不要以为不签劳动合同就没事**。三方是独立生效的协议。

---

## 五、三方、两方、offer letter 的区别

| 文件 | 性质 | 有违约金吗 |
| --- | --- | --- |
| **三方协议** | 民事协议，学校参与 | 可以约定 |
| **两方协议** | 学生与单位双方的民事协议 | 可以约定 |
| **Offer letter** | 录用通知，性质视内容而定 | 通常无强制约束力，但写明违约条款的除外 |

**注意**：有些公司用 offer letter 代替两方协议，如果不含违约条款，约束力较弱；但一旦你签字接受并造成单位损失，仍可能被追责。

---

## 六、签之前必须确认的六件事

- [ ] 1. 违约金金额是多少，什么情况触发
- [ ] 2. 有没有「服务期」约定（几年内不能离职）
- [ ] 3. 岗位、工作地点、薪资是否与面试时一致
- [ ] 4. 单位是否真的能接收档案和户口
- [ ] 5. 备注栏有没有附加条款（很多人只看正文）
- [ ] 6. 升学、参军等特殊情况能否免责

**特别提醒**：三方协议的「备注」栏经常被忽略，有些单位会在那里加附加条件。

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「三方就是劳动合同」 | 不是。三方是民事协议，入职后还要签劳动合同 |
| 「签了不去也没事」 | 可能要付违约金 |
| 「违约金不合法」 | 三方是民事协议，违约金有效 |
| 「学校会帮我兜底」 | 学校只是见证方，不承担你的违约责任 |
| 「备注栏不重要」 | 附加条款常写在那里 |
| 「毁约影响征信」 | 通常不影响，但可能影响该校后续招聘名额 |

## 八、可执行清单

### 签之前

- [ ] 逐条读完，特别是违约金和备注栏
- [ ] 确认岗位、地点、薪资
- [ ] 想清楚：如果将来毁约，这个金额能接受吗

### 签之后

- [ ] 拍照留存全部页面
- [ ] 记住违约金条款
- [ ] 入职后**务必签劳动合同**（三方不能替代）

### 如果要毁约

- [ ] 先协商，争取减免
- [ ] 拿到书面解除证明
- [ ] 向学校申请补发新三方
- [ ] 不要伪造任何文件

---

## 九、一句话记住

**三方协议的违约金是真的，签之前看清楚；它不是劳动合同，入职后还要另外签。**
