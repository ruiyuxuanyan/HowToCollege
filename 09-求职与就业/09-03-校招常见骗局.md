# 校招常见骗局：收费内推、培训贷、假 offer

> 一句话概括：所有在你入职前要你付钱、签贷款、交证件的机会，先当成骗局。

**适用人群**：正在投校招、实习、内推的在校学生；收到过「付费内推」「保 offer」私信的人；已经交过钱、正在犹豫要不要继续的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国劳动合同法》第九条（禁止收取财物、扣押证件）；《中华人民共和国刑法》第二百六十六条（诈骗罪）、第二百二十四条（合同诈骗罪）；《禁止传销条例》；教育部关于高校毕业生就业权益的相关规定
> - 全国统一：禁止用人单位收取押金、扣押证件，全国统一适用
> - 地方执行：投诉受理渠道、立案标准以属地为准
> - 核查日期：2026-11-07
> - 已知变化：骗局话术持续翻新，本文讲**结构**，不追具体话术

> ⏳ 易过时：具体话术和平台名称会变，识别逻辑不变。

## 一、《劳动合同法》第九条：一条能挡掉一半骗局的规定

原文：

> 用人单位招用劳动者，不得扣押劳动者的居民身份证和其他证件，不得要求劳动者提供担保或者以其他名义向劳动者收取财物。
>
> 【法规】《中华人民共和国劳动合同法》第九条（2012 年 12 月 28 日修正）

这一条包含三层禁止：

| 禁止行为 | 常见变体 |
| --- | --- |
| 扣押证件 | 押身份证、押毕业证、押学位证原件 |
| 要求提供担保 | 要担保人、要押金、「保证金」 |
| 收取财物 | 服装费、培训费、体检费、工牌费、材料费、入职押金 |

**结论很直接：只要入职前要你掏钱或押证件，就违法。**

违反的后果：《劳动合同法》第八十四条规定，由劳动行政部门责令限期退还，并以每人五百元以上二千元以下的标准处以罚款；给劳动者造成损害的，应当承担赔偿责任。【法规】

## 二、五类高发骗局

### 2.1 收费内推 / 付费保 offer

**话术**：「我们有内部名额，X 万元保你进 XX 公司」「付费内推，简历直送 HR」。

**真相**：

- 正规企业的内推**不向候选人收费**。内推奖励由企业发给推荐人，不是向求职者收
- 所谓「内部名额」「保过」在正规招聘流程里不存在——录用决定由用人部门做出，任何中介无权承诺
- 收款后常见结局：失联；或给你一个真实但极难通过的岗位链接，让你「自己投」

**识别**：

| 信号 | 说明 |
| --- | --- |
| 先付款再谈岗位 | 正常流程是先有岗位再谈其他 |
| 承诺「保过」「保录用」 | 无人能保证 |
| 要求把钱转到**个人账户** | 正规机构收款走对公账户且开票 |
| 不肯说清是哪家公司哪个岗位 | 信息不透明是核心特征 |
| 用「名额只剩 X 个」催你 | 制造紧迫感是标准手法 |

### 2.2 培训贷（后果最重的一类）

完整链条：

| 步骤 | 对方做什么 |
| --- | --- |
| 1 | 发布「高薪岗位」，面试极易通过 |
| 2 | 告知「技能不达标，需要先培训」 |
| 3 | 培训费「可以分期」，让你签一份分期合同 |
| 4 | **那份合同实际是贷款合同** |
| 5 | 培训结束后，工作没了 |
| 6 | 你背上债务，且上了征信 |

**唯一可靠的识别点**：**任何要求你在入职前签「分期」「贷款」「金融服务」「先学后付」合同的，立刻停止。**

这一条在这类骗局里几乎是决定性判据。培训本身不是问题，问题是**为了一个没落实的岗位去借钱**。

**已经签了怎么办**（按顺序）：

1. 立刻保存全部合同、聊天记录、转账凭证
2. 报警（涉嫌诈骗）
3. 向 12315（市场监管）、12378（金融消费者投诉）投诉
4. 向放款机构书面提出异议，主张合同存在欺诈
5. 请律师评估主张合同无效或可撤销

> 注意：不要因为「怕影响征信」就继续还款而不做任何动作。**先固定证据，再谈还款**，顺序反了会很被动。

### 2.3 假 offer

**形态**：伪造的录用通知，通常带公司 logo、看起来很像真的。

**目的**有三种，目的不同，危害程度不同：

| 目的 | 手法 | 危害 |
| --- | --- | --- |
| 骗钱 | offer 后要求交「入职保证金」「体检费」 | 直接经济损失 |
| 骗信息 | 要求提前提交身份证、银行卡、学历证书扫描件 | 身份被冒用、被办卡 |
| 骗时间 | 用假 offer 拖住你，让你拒掉其他机会 | 错过整个招聘季 |

**怎么验真**：

- 用**公司官网公布的** HR 邮箱/电话回拨，**不要**用 offer 邮件里给的号码
- 在企业官网或官方招聘公众号核对岗位编号
- 要求走**对公**流程签约；对公账户名必须与公司名一致
- 用「国家企业信用信息公示系统」核对公司是否存在、状态是否正常（见第三节）

### 2.4 假实习

**形态**：以「实习」名义招人，实际做的是无报酬劳动、与专业无关的杂活，或干脆是诈骗的一环（如让你去拉人头）。

**识别**：

| 信号 | 说明 |
| --- | --- |
| 全程无书面实习协议 | 正规实习也会有协议 |
| 不写工作内容，只说「来了就知道」 | 内容不透明 |
| 实习内容与招聘描述完全不符 | 典型挂羊头 |
| 让你去发展下线、拉同学报名 | 这已经接近传销（见 09-08） |
| 以「实习」名义收培训费 | 组合型骗局 |

### 2.5 挂靠社保 / 挂靠证书

**话术**：「帮你挂靠社保，保持连续缴纳记录」「证书挂靠，一年给你 X 万，什么都不用干」。

**问题**：

- **社保挂靠是虚构劳动关系**，属于违法违规行为。所谓「代缴」，本质是伪造参保事实
- 一旦被查，缴费记录可能被认定无效，钱和年限都可能白费
- 挂靠证书（尤其职业资格证）在很多领域被明令禁止，出事故时证书持有人要担责
- 对方用你的身份信息参保，你的身份信息同时被其掌握

**正确做法**：灵活就业人员可以**以个人身份**参加社保，这是合法渠道（详见 10-09）。不需要通过任何「挂靠公司」。

## 三、查一家公司：国家企业信用信息公示系统

这是最实用的一步，而且**免费、官方、5 分钟能做完**。

**地址**：国家市场监督管理总局「国家企业信用信息公示系统」，网址为 `www.gsxt.gov.cn`（官网域名以市场监管总局公布为准）。也可通过「国家企业信用信息公示系统」微信小程序查询。

**查什么**：

| 查这一项 | 要看什么 | 危险信号 |
| --- | --- | --- |
| 企业是否存在 | 名称、统一社会信用代码 | 查无此企业 → 直接放弃 |
| 登记状态 | 存续 / 在业 / 注销 / 吊销 / 经营异常 | 注销、吊销、经营异常 → 放弃 |
| 成立时间 | 注册资本实缴情况 | 刚成立几个月就大规模校招，需警惕 |
| 经营范围 | 是否与招聘岗位相符 | 招「技术岗」但经营范围里没有相关业务 |
| 行政处罚信息 | 有无处罚记录 | 有多次处罚记录需谨慎 |
| 经营异常名录 | 是否被列入 | 被列入 → 放弃 |
| 严重违法失信名单 | 是否被列入 | 被列入 → 放弃 |
| 股东与高管 | 是否与宣称的背景一致 | 宣称「大厂子公司」但股权上毫无关系 |

**补充查询**：

- **中国裁判文书网**：查公司涉诉情况（劳动争议多不多）
- **信用中国**：查失信被执行人、重大税收违法
- **学信网**：核对学历（对方若声称你的学历有问题，你可以自己先确认）

> 【官方】上述系统均为政府主办，数据来源为登记与监管信息。查询结果以系统实时显示为准。

## 四、正规招聘长什么样

反向记住这个清单，比记骗局清单更有效。

| 特征 | 正规 | 可疑 |
| --- | --- | --- |
| 收费 | 全程不收费 | 任何环节要钱 |
| 证件 | 不押原件 | 要押身份证/毕业证 |
| 主体 | 对公账户、能开票 | 个人账户收款 |
| 岗位 | 描述具体，职责清楚 | 含糊、「来了再说」 |
| 流程 | 笔试—面试—HR 谈—发 offer | 面试一次就发 offer |
| 合同 | 入职一个月内签书面劳动合同 | 拖、或以「实习协议」长期替代 |
| 联系方式 | 公司域名邮箱、官网电话 | 个人微信、私人手机号 |
| 承诺 | 不承诺「保过」 | 「保录用」「保过」 |

【法规】其中「入职一个月内签书面劳动合同」见《劳动合同法》第十条；未签的二倍工资责任见第八十二条（详见 10-03）。

## 五、已经中招了怎么办

按损失类型分头处理，**先固定证据，再走程序**。

### 5.1 通用第一步：固定证据

- [ ] 聊天记录完整截图（含对方账号信息、时间）
- [ ] 转账记录（银行流水、支付平台账单）
- [ ] 合同/协议全文拍照或扫描
- [ ] 对方公司名称、地址、联系人、电话
- [ ] 招聘信息原始页面截图（含 URL）

### 5.2 分渠道维权

| 情形 | 找谁 | 依据 |
| --- | --- | --- |
| 被收押金、押证件 | 当地劳动保障监察机构（12333） | 《劳动合同法》第九条、第八十四条 |
| 被骗钱（诈骗） | 报警（110 / 国家反诈中心 App） | 《刑法》第二百六十六条 |
| 被诱导签贷款 | 报警 + 12378 金融消费者投诉 + 贷款机构异议 | 合同欺诈 |
| 招聘平台上的虚假信息 | 平台举报 + 12315 | 平台审核责任 |
| 涉及传销 | 报警 + 12315 | 《禁止传销条例》 |

### 5.3 时间上的两点提醒

1. **越早越好**。资金一旦多层转移，追回难度陡增
2. **不要私下和对方「协商退款」而拖延报警**。对方常用「退你一半，你别报警」来消耗你的时间窗口

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「内推都是要花钱的」 | 正规内推不向候选人收费，奖励由企业发给推荐人 |
| 「签了合同就没办法了」 | 存在欺诈的可主张无效或撤销，需律师协助 |
| 「金额小，报警没用」 | 诈骗立案看总体情节，多人受害可合并；且报警是固定证据的方式 |
| 「怕影响征信所以先还贷款」 | 先固定证据并提异议，再谈还款，顺序不能反 |
| 「挂靠社保能保住连续年限」 | 虚构劳动关系属违规，记录可能被认定无效 |
| 「大公司不会骗人」 | 骗子会冒用大公司名义。**必须回官网核实**，不能看邮件里的联系方式 |
| 「拿到 offer 就安全了」 | 假 offer 的三种目的：骗钱、骗信息、骗时间 |

## 可执行清单

**投递前（每家都做）**

- [ ] 在国家企业信用信息公示系统查这家公司：存在、存续、无经营异常
- [ ] 核对经营范围是否与岗位相符
- [ ] 查一下中国裁判文书网的涉诉记录
- [ ] 确认招聘信息发布在**公司官网或官方公众号**上

**沟通中（守住三条线）**

- [ ] 不付任何费用（押金、培训费、体检费、服装费、内推费）
- [ ] 不押任何证件原件
- [ ] 不签任何「分期 / 贷款 / 金融服务」合同

**收到 offer 后**

- [ ] 用**官网公布的**联系方式回拨核实，不用 offer 邮件里的号码
- [ ] 确认签约主体与面试公司一致（警惕关联公司签）
- [ ] 要求走对公流程，核对账户名与公司名
- [ ] offer 上写清岗位、地点、薪资构成、入职时间

**万一中招**

- [ ] 先固定证据（聊天记录、转账、合同、页面截图）
- [ ] 按 5.2 表格找对应渠道
- [ ] 涉及诈骗立即报警，不要等「协商」

**入职前不收你钱、不押你证件、不让你签贷款——这三条守住，大部分校招骗局就近不了身。**
