# 实习转正与背景调查：简历能不能美化

> 一句话概括：可以优化表述，不能编造事实——背调查的就是「有没有编」。

**适用人群**：正在实习、准备争取转正的人；简历上有空白期或夸大成分的人；即将入职、要过背调的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国劳动合同法》第八条（用人单位有权了解劳动者与劳动合同直接相关的基本情况，劳动者应当如实说明）、第二十六条（以欺诈手段订立的劳动合同无效）、第三十九条（严重违反规章制度、欺诈可解除）
> - 全国统一 / 地方执行：法条框架全国统一；**背调的具体操作无统一规范**，由企业自主
> - 核查日期：2026-11-05
> - 已知变化：背调行业化，第三方机构参与增多；个人信息保护要求趋严

> ⚠️ 本文不教怎么「包装」到能骗过背调。核心结论是：**可优化的与不可编造的，边界很清晰。**

---

## 一、先划清边界：优化 ≠ 编造

这是全文最重要的一张表。

| 维度 | 适度包装（可以） | 编造（不可以） | 法律/后果 |
| --- | --- | --- | --- |
| **经历有无** | 有这段经历，重新组织叙述 | 没有的经历写上去 | 欺诈 |
| **角色** | 参与某项目，说清自己负责哪部分 | 把团队成果写成自己主导 | 欺诈 |
| **时间** | 如实写起止年月 | 拉长在职时间以填补空白 | 欺诈 |
| **职级/头衔** | 如实写岗位，附职责说明 | 把「实习生」写成「主管」 | 欺诈 |
| **学历** | 如实写学校、专业、学位 | 伪造学历、学位、院校 | 欺诈，且可被学信网直接戳穿 |
| **证书** | 写已取得的 | 写「在考」「备考中」当成已取得 | 欺诈 |
| **业绩数字** | 用真实数据，说明统计口径 | 编一个好看的数字 | 欺诈 |
| **技能** | 写「熟练」并确能被问到 | 写「精通」但基本不会 | 面试即暴露 |
| **离职原因** | 如实且简洁 | 伪造理由（如把辞退说成主动离职） | 背调最常查的点 |

**一句话判据**：**「如果面试官打电话给当时的同事，这段描述还成立吗？」** 成立就是包装，不成立就是编造。

## 二、背调到底查什么

背调（背景调查）不是「查你有没有犯罪记录」这么简单，通常分几层。**层级取决于岗位敏感度**，普通岗位往往只做前两层。

| 层级 | 查什么 | 怎么查 | 常见岗位范围 |
| --- | --- | --- | --- |
| 基础核验 | 身份、学历学位、证书真伪 | 学信网、学位网、证书查询系统 | 几乎所有岗位 |
| 履历核验 | 工作/实习经历、在职时间、职位、离职原因 | 联系前雇主 HR 或证明人 | 多数正式岗位 |
| 表现评价 | 工作表现、是否有重大过失、是否可再录用 | 联系直属上级 | 中高级岗位 |
| 合规核查 | 犯罪记录、涉诉、失信、金融违规 | 官方渠道或第三方机构 | 金融、国企、公职、涉密 |
| 竞业/利益冲突 | 是否受竞业限制、是否有关联企业 | 协议核查、工商查询 | 技术、管理、涉密 |

### 2.1 学历：最容易被戳穿的一层

学历核验几乎零成本——**学信网（中国高等教育学生信息网）**可查高等教育学籍学历。这意味着：

- 伪造学历基本没有成功率
- 「野鸡大学」学历在学信网查不到，等同于无效
- 即使入职时蒙混过关，后续任何一次核查都可能翻出来

### 2.2 离职原因：最常出问题的一层

背调里最容易被问出问题的不是能力，是**离职原因**。

常见的不一致：

| 你写的 | 前雇主可能说的 | 风险 |
| --- | --- | --- |
| 主动离职寻求发展 | 因绩效不达标被辞退 | 诚信问题 |
| 合同到期未续 | 违纪解除 | 诚信问题 |
| 公司裁员 | 个人原因离职 | 中等（可能被追问） |

【经验】很多企业的背调问题清单里，「离职原因是否与本人陈述一致」是固定项。这一项的不一致，比能力评价差更容易导致 offer 撤回。

### 2.3 竞业限制：容易被忽略但后果重

如果你上一份工作签过竞业限制协议，新雇主所在业务若构成竞争，可能触发违约。

- 竞业限制**只对高级管理人员、高级技术人员和其他负有保密义务的人员**有效（《劳动合同法》第二十四条）【法规】
- 且**单位需在离职后按月支付补偿**，否则你可主张不受约束【法规】
- 但如果有效且你在限制期内入职竞争对手，可能面临违约金

**做法**：入职前主动看清上一份合同有无竞业条款，必要时如实告知新雇主。隐瞒的后果通常比坦白更重。

## 三、背调的合法边界

背调不是无限的。有两条约束：

### 3.1 只能查「与劳动合同直接相关」的信息

《劳动合同法》第八条：

> 用人单位招用劳动者时，应当如实告知劳动者工作内容、工作条件、工作地点、职业危害、安全生产状况、劳动报酬，以及劳动者要求了解的其他情况；用人单位有权了解劳动者与劳动合同直接相关的基本情况，劳动者应当如实说明。
>
> 【法规】《中华人民共和国劳动合同法》第八条

关键在「**直接相关**」。与岗位无关的隐私（婚育状况、宗教信仰、疾病史中与岗位无关的部分）不属于用人单位有权了解的范围。这一部分在「面试中的劳动法问题」一文详述。

### 3.2 需经你授权

正规背调机构会要求你签署**授权书**，并说明调查范围。你可以：

- 要求看清授权范围再签
- 拒绝超出范围的调查项
- 询问是否会联系现雇主（很多机构允许你标注「不联系现雇主」）

**没有授权就调查，可能构成对个人信息权益的侵害。**

## 四、实习怎么转正

实习转正的机制各公司不同，没有统一规则，但有共同的可操作点。

| 环节 | 你能做的 |
| --- | --- |
| 明确标准 | 入职时就问清楚：转正看什么？有没有名额？谁决定？ |
| 拿到明确的项目 | 争取一个能拿出成果的任务，而不是零散杂活 |
| 让成果可见 | 定期汇报进展，不要闷头做完才说 |
| 找到你的评价人 | 通常是直属上级，要让他清楚你的贡献 |
| 提前问结果 | 实习后期直接问转正意向，不要等最后一天 |
| 留退路 | 实习期间同步投其他岗位，不要把全部希望押在一家 |

【经验】实习转正最大的坑是「一直以为会转，最后没名额」。这不是你能力问题，是信息不对称问题——**入职时就该问清名额和标准**。

### 转正前的书面确认

口头承诺不算数。争取拿到：

- [ ] 转正意向的书面确认（邮件即可）
- [ ] 转正后的岗位、薪资、入职时间
- [ ] 是否需要重新走背调

## 五、如果简历上已经有编造，怎么办

分情况。**核心原则：在对方发现之前主动处理，比被发现后解释代价小得多。**

| 情况 | 建议 |
| --- | --- |
| 还没投递 | 直接改掉。这是成本最低的时刻，改完就没事了 |
| 已投未面 | 更新简历版本；若被问到，按真实情况答 |
| 面试中 | 不要顺着假话往下编。可以说「这里我表述得不准确，实际是……」 |
| 已发 offer、未入职 | 主动向 HR 更正关键信息（学历、经历、离职原因）。多数公司会重新评估而非直接撤回 |
| 已入职后被查出 | 法律风险实体化：《劳动合同法》第二十六条、第三十九条 |

法律后果说明：

> 以欺诈、胁迫的手段或者乘人之危，使对方在违背真实意思的情况下订立或者变更劳动合同的，劳动合同无效。
>
> 【法规】《劳动合同法》第二十六条第一款第（一）项

> 劳动者有下列情形之一的，用人单位可以解除劳动合同：……（五）因本法第二十六条第一款第一项规定的情形致使劳动合同无效的；
>
> 【法规】《劳动合同法》第三十九条第五项

**这意味着**：编造关键事实导致合同无效的，单位可以解除且**无需支付经济补偿**。也就是说，编造经历的代价不只是丢工作，还包括失去本应拿到的补偿。

## 六、空白期怎么处理

简历上的空白期（考研失败、待业、生病、家庭原因）是常见焦虑点。

**可以这样写，都不算编造**：

| 空白期实际内容 | 简历/面试可以怎么说 |
| --- | --- |
| 备考研究生 | 「备考研究生，未参加当年校招」 |
| 自学技能 | 「系统学习 XX，完成 XX 项目」（前提是真做了） |
| 做兼职/自由职业 | 如实写，哪怕不体面 |
| 家庭原因 | 「处理家庭事务」——不必细说 |
| 找工作 | 「求职中」——这本身就是事实 |

**不要做的**：把空白期塞进上一份工作的在职时间里。这是背调最容易查出来的造假，因为起止月份在前雇主那里有记录。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「小公司不会背调」 | 越来越多中小企业也做基础核验；学历核验成本极低 |
| 「入职后就安全了」 | 转正、晋升、调岗都可能再查；学历造假长期风险 |
| 「把实习写成正式工作没关系」 | 社保记录与在职时间会不一致，很容易查 |
| 「离职原因随便写」 | 这是背调固定核查项，最常出问题 |
| 「头衔夸大不算造假」 | 与实际岗位不符即属不实陈述，影响合同效力 |
| 「背调能查我所有隐私」 | 只能查与岗位直接相关且经你授权的信息 |
| 「有竞业协议也没人管」 | 有效协议下入职竞争对手可能触发违约金 |

## 可执行清单

**写简历时**

- [ ] 每条经历都过一遍「同事会怎么说」这个测试
- [ ] 时间线连续，空白期如实处理，不要塞进上一段
- [ ] 数字有口径（「提升 X%」要能说清怎么算的）
- [ ] 技能等级敢被追问（写「精通」就要能扛住深挖）
- [ ] 证书只写已取得的

**面试/背调阶段**

- [ ] 提前准备好离职原因的统一说法（真实且简洁）
- [ ] 主动确认上一份合同有没有竞业限制条款
- [ ] 背调授权书看清范围再签
- [ ] 需要的话，向背调方标注「不联系现雇主」
- [ ] 若简历有不准确之处，尽早主动更正

**实习期间**

- [ ] 入职时就问清转正标准与名额
- [ ] 定期汇报，让贡献可见
- [ ] 实习后期直接问转正意向
- [ ] 同时保留其他求职机会

## 一句话记住

**背调查的不是「你写得漂不漂亮」，是「你说的是不是真的」——优化措辞没人管，编造事实会连补偿一起丢掉。**
