# 求职时的个人信息保护

> 一句话概括：简历投出去之前，先想清楚哪些信息不该给。

**适用人群**：正在求职、投简历的毕业生。

> **政策与法律适用范围**
> - 主要依据：《中华人民共和国个人信息保护法》
> - 全国统一：个人信息处理规则全国统一
> - 核查日期：2026-11-05

---

## 一、三个阶段，给的信息不同

| 阶段 | 该给 | 不该给 |
| --- | --- | --- |
| **投简历** | 姓名、电话、邮箱、教育背景、经历 | **身份证号、银行卡号、家庭详细住址、身份证照片** |
| **面试** | 补充作品、证明能力的信息 | 身份证原件（可出示不可留存）、银行卡 |
| **入职/签合同** | 身份证复印件、银行卡（发工资）、学历证明 | 与岗位无关的家庭隐私 |

**核心原则**：**信息提供应限于「处理目的所必需」的范围。**

---

## 二、高风险信息清单

| 信息 | 风险 |
| --- | --- |
| **身份证号 + 姓名** | 可能被用于注册账号、办卡 |
| **身份证正反面照片** | 风险最高，可被用于开户、贷款 |
| **银行卡号 + 手机号** | 盗刷、盗绑 |
| **人脸/活体认证** | 冒名验证 |
| **家庭详细住址** | 隐私泄露、骚扰 |
| **学历证书原件** | 丢失难补 |

---

## 三、常见索要场景的判断

| 场景 | 是否合理 |
| --- | --- |
| 投简历时要身份证号 | **不合理**，可拒绝 |
| 面试时要身份证原件 | 可出示核验，**不接受留存或拍照** |
| 背景调查要身份证号 | 合理，但应**先获得你的书面授权** |
| 入职要银行卡 | 合理（发工资） |
| 入职要学历证书原件 | 可核验，一般不需要留存原件 |
| 要求提供人脸识别 | 需说明目的，谨慎 |

---

## 四、信息被泄露后怎么办

| 情况 | 处理 |
| --- | --- |
| 收到骚扰电话/短信 | 标记拉黑，必要时举报 |
| 被冒名注册公司 | 向市场监管部门反映，见 11-03 |
| 被冒名贷款 | 报警 + 征信异议 |
| 遭遇精准诈骗 | 见 07-13 |

**详见「个人信息泄露的排查与止损」（11-03）。**

---

## 五、求职平台的使用

| 建议 | 说明 |
| --- | --- |
| 用专门邮箱/手机号求职 | 减少主号被骚扰 |
| 简历不写详细住址 | 写城市即可 |
| 不公开完整身份证号 | 不写 |
| 查公司信息 | 国家企业信用信息公示系统 |

---

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「求职就得全给」 | 信息提供应限于必要范围 |
| 「公司要就得给」 | 可以询问用途并拒绝不合理要求 |
| 「简历上放身份证照片显得正规」 | 没有必要，且风险高 |
| 「背调不用授权」 | 应获得你的授权 |
| 「泄露了也没办法」 | 可报警、可向监管部门投诉 |

---

## 七、可执行清单

### 投简历前

- [ ] 简历不写身份证号、详细住址
- [ ] 用专门邮箱/手机号
- [ ] 查目标公司工商信息

### 面试时

- [ ] 身份证可出示，不接受拍照留存
- [ ] 询问索要信息的目的

### 入职时

- [ ] 确认信息用途限于办理入职
- [ ] 学历证书原件核验后取回

### 泄露后

- [ ] 报警（如被冒用）
- [ ] 查征信、查名下账户（见 11-03）

---

## 八、一句话记住

**投简历不给身份证号。入职才给银行卡，而且只为发工资。**
