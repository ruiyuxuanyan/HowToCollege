# 求职时的个人信息保护

> 一句话概括：投简历之前先想清楚——法律给了你「拒绝过度收集」的权利，但没人会主动告诉你。

**适用人群**：正在投简历、面试、办入职的毕业生。

> **政策与法律适用范围**
> - 主要依据：《中华人民共和国个人信息保护法》（2021-11-01 施行）
> - 全国统一：处理个人信息的**目的限定、最小必要、告知同意**规则全国统一
> - 各企业自定：具体收集哪些信息、背景调查怎么做
> - 核查日期：2026-11-05

> **与相关隐私篇目的分工**：本篇处理「**给之前的判断**」——求职各阶段哪些信息该给、哪些可以依法拒绝。已经泄露了、要排查止损 → 11-03；被挂到网上 → 06-09；偷拍偷窥类侵权 → 08-11。

---

## 一、先记住一条底线条文

很多「求职要给身份证吗」的讨论绕来绕去，其实《个人信息保护法》第六条已经把答案写死了：

> 【法规】第六条：处理个人信息应当具有明确、合理的目的，并应当与处理目的直接相关，采取对个人权益影响最小的方式。
> **收集个人信息，应当限于实现处理目的的最小范围，不得过度收集个人信息。**

这就是「**最小必要**」原则。翻译成求职场景：

- 投简历阶段，目的是「判断你是否合适」→ 需要的是经历和能力，**不需要身份证号**
- 入职阶段，目的是「发工资、缴社保」→ 需要身份证和银行卡，**这才合理**

**同一个信息，在不同阶段是否合理，取决于那个阶段的目的。** 这是本文全篇的判断标准。

---

## 二、三个阶段，给的信息不同

| 阶段 | 处理目的 | 该给 | 不该给 |
| --- | --- | --- | --- |
| **投简历** | 判断是否匹配岗位 | 姓名、电话、邮箱、教育背景、实习经历 | **身份证号、银行卡号、家庭详细住址、身份证照片** |
| **面试** | 核实能力、初步确认身份 | 作品、证明能力的材料；身份证可**出示**核验 | 身份证**留存或拍照**、银行卡 |
| **入职/签合同** | 建立劳动关系、发薪缴保 | 身份证复印件、银行卡（发工资）、学历证明 | 与岗位无关的家庭隐私、婚育情况 |

## 三、法律给了你哪些具体权利

这是本文最有用的部分——不是「建议你别给」，而是「法律上你可以这么说」。

| 权利 | 条文 | 求职场景怎么用 |
| --- | --- | --- |
| **知情权** | 第十七条：处理前应告知处理者名称、**处理目的、方式、种类、保存期限** | 「请问这些信息用来做什么？保存多久？」——对方有法定告知义务 |
| **最小必要** | 第六条：不得过度收集 | 「投简历阶段为什么要身份证号？」——直接指出超出必要范围 |
| **单独同意**（对外提供） | 第二十三条：向他人提供个人信息，须告知接收方名称、目的、方式、种类，并取得**单独同意** | 背景调查委托第三方时，必须单独征得你同意，不能藏在「投递即同意」里 |
| **查阅复制权** | 第四十五条：有权查阅、复制其个人信息 | 可以要求看公司留存了你哪些信息 |
| **更正补充权** | 第四十六条：不准确或不完整，有权请求更正、补充 | 背调报告有误时可要求更正 |
| **删除权** | 第四十七条：处理目的已实现、或你**撤回同意**等情形，应主动删除 | 没应聘上，可以要求删除简历 |
| **要求解释权** | 第四十八条：有权要求对处理规则作解释说明 | 看不懂隐私政策时可以问 |
| **拒绝权** | 第四十四条：有权限制或拒绝他人处理其个人信息 | 拒绝提供非必要信息 |

**特别注意第二十三条**——这是背景调查的法定依据：

> 【法规】第二十三条：个人信息处理者向其他个人信息处理者提供其处理的个人信息的，应当向个人告知接收方的名称或者姓名、联系方式、处理目的、处理方式和个人信息的种类，并**取得个人的单独同意**。

「单独同意」意味着：不能用一个笼统的「我已阅读并同意」打包拿走。**背景调查必须单独授权**，这条是可以当面提出的。

## 四、高风险信息清单

| 信息 | 风险 | 泄露后可被用来做什么 |
| --- | --- | --- |
| **身份证正反面照片** | **最高** | 开户、注册、贷款面签、实名认证 |
| 身份证号 + 姓名 | 高 | 注册账号、办卡、查询部分公开信息 |
| 银行卡号 + 手机号 | 高 | 盗刷、绑定支付、冒充客服诈骗 |
| 人脸 / 活体认证视频 | **极高** | 冒名通过实名验证，且无法更改 |
| 家庭详细住址 | 中 | 上门骚扰、精准诈骗 |
| 学历证书原件 | 中 | 丢失难补（可补办证明书，见下） |

> 【法规】第四十七条还规定：处理目的已实现、无法实现或者为实现处理目的不再必要，或**个人撤回同意**的，处理者应当主动删除；未删除的，个人有权请求删除。
> **用法**：面试没通过后，可以书面要求对方删除你的简历和身份材料。

## 五、常见索要场景，逐条判断

| 场景 | 合理吗 | 依据 / 怎么说 |
| --- | --- | --- |
| 投简历时要身份证号 | **不合理** | 违反第六条最小必要，可拒绝 |
| 面试时要身份证原件 | 可出示核验，**不接受留存或拍照** | 核验身份的目的用「看」就能实现 |
| 背景调查要身份证号 | **合理，但须单独授权** | 第二十三条要求单独同意，并告知接收方 |
| 入职要银行卡 | 合理 | 目的是发工资，符合必要性 |
| 入职要学历证书原件 | 可核验，一般不需留存原件 | 留存复印件即可 |
| 要求提供人脸识别 | 需说明目的，谨慎 | 人脸不可更改，风险最高 |
| 要求填写婚育状况 | **与岗位无关** | 违反最小必要；且《妇女权益保障法》明确禁止询问/调查婚育情况 |
| 要求提供家庭成员信息 | 通常不合理 | 与录用决定无直接关联 |

## 六、证件丢了 / 原件被扣了怎么办

| 情况 | 处理 |
| --- | --- |
| 学历证书原件被扣 | 明确要求返还；不返还的可向劳动监察部门反映 |
| 学历证书遗失 | 【法规】《普通高等学校学生管理规定》第三十八条：经本人申请、学校核实后应出具**证明书，与原证书具有同等效力** |
| 身份证被扣 | 报警。任何单位无权扣押身份证 |
| 被冒名注册公司 | 向市场监管部门申请撤销登记（见 11-03） |
| 被冒名贷款 | 报警 + 向征信机构提异议 |
| 简历信息被倒卖 | 向网信、市场监管部门举报；情节严重的可报案 |

> 【法规】第六十六条给出了处罚力度：违法处理个人信息，拒不改正的处一百万元以下罚款；**情节严重的，处五千万元以下或者上一年度营业额百分之五以下罚款**，并可责令暂停相关业务、吊销营业执照。这是你可以引用的谈判筹码。

## 七、求职平台怎么用

| 建议 | 说明 |
| --- | --- |
| 用专门邮箱 / 手机号求职 | 主号不被骚扰，弃用成本低 |
| 简历不写详细住址 | 写到城市即可，面试再谈 |
| 不写完整身份证号 | 面试阶段完全不需要 |
| 不公开身份证照片 | 简历上放身份证照片毫无必要且风险高 |
| 投递前查公司 | 国家企业信用信息公示系统（gsxt.gov.cn）核工商信息 |
| 保留投递记录 | 出问题时可证明「哪家公司、什么时候、拿到了什么」 |

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「求职就得全给，不给就是不配合」 | 第六条明确禁止过度收集，你有权拒绝非必要信息 |
| 「公司要就得给」 | 可以询问目的，超出必要范围的可以拒绝 |
| 「简历上放身份证照片显得正规」 | 没必要，且是风险最高的一类信息 |
| 「背调不用授权」 | 第二十三条要求**单独同意**，且须告知接收方 |
| 「点了『同意』就没辙了」 | 第四十四条有拒绝权，第四十七条可撤回同意并要求删除 |
| 「泄露了也没办法」 | 可要求删除、可投诉举报、可报案；第六十六条有明确处罚 |
| 「没应聘上，简历留着也无所谓」 | 可依第四十七条要求删除 |

## 九、可执行清单

### 投简历前

- [ ] 简历不写身份证号、不写详细住址、不放证件照
- [ ] 用专门邮箱/手机号
- [ ] 查目标公司的工商信息
- [ ] 看一眼它的隐私政策/个人信息处理规则（第十七条要求它公开）

### 面试时

- [ ] 身份证可出示，**不接受拍照留存**
- [ ] 询问索要信息的目的与保存期限（这是它的法定告知义务）
- [ ] 背调授权单独签，看清楚授权给谁、查什么

### 入职时

- [ ] 确认信息用途限于办理入职、发薪、缴保
- [ ] 学历证书原件核验后取回
- [ ] 留存一份自己提交的材料清单

### 泄露或不再需要后

- [ ] 书面要求删除简历与身份材料（第四十七条）
- [ ] 被冒用：报警 + 查征信 + 查名下企业
- [ ] 情节严重：向网信/市场监管部门举报

## 十、一句话记住

**投简历不给身份证号，入职才给银行卡且只为发工资。法律给了你「最小必要」这条底线，敢问一句「用来做什么、存多久」。**
