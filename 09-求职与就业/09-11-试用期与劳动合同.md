# 试用期与劳动合同：签之前必须确认的 8 件事

> 一句话概括：签合同前的十分钟，决定你未来一年的处境。

**适用人群**：第一次签劳动合同的毕业生。

> **政策与法律适用范围**
> - 主要依据：《中华人民共和国劳动合同法》第十九条、第二十条、第二十五条、第八十二条
> - 全国统一：试用期上限、试用期工资下限、违约金限制全国统一
> - 地方执行：最低工资标准各省不同
> - 核查日期：2026-11-05

> **与「劳动合同怎么签」的分工**：本篇聚焦**试用期**这个最容易出问题的环节；合同全貌与必备条款见 10-03。

---

## 一、签前必须确认的 8 件事

- [ ] **1. 合同期限与试用期是否匹配法定上限**
- [ ] **2. 试用期工资是否合规**
- [ ] **3. 工作内容和地点**（警惕「服从公司安排」无限授权）
- [ ] **4. 工时制度**（标准/综合计算/不定时）
- [ ] **5. 社保何时开始缴、是否缴**
- [ ] **6. 有无违约金条款**（除两种法定情形外无效）
- [ ] **7. 工资构成与发放日**
- [ ] **8. 有无「自愿放弃社保」条款**（无效）

---

## 二、试用期的法定上限

《劳动合同法》第十九条：

| 合同期限 | 试用期上限 |
| --- | --- |
| 3 个月以上不满 1 年 | **1 个月** |
| 1 年以上不满 3 年 | **2 个月** |
| 3 年以上固定期限或无固定期限 | **6 个月** |
| **不满 3 个月** | **不得约定试用期** |

**两个延伸规则**：
- 同一用人单位与同一劳动者**只能约定一次试用期**
- 试用期**包含在劳动合同期限内**（不能单独签「试用期合同」）

---

## 三、试用期工资的下限

《劳动合同法》第二十条：

> 劳动者在试用期的工资不得低于本单位相同岗位最低档工资或者劳动合同约定工资的百分之八十，并不得低于用人单位所在地的最低工资标准。

**两个下限取高的**：
1. 约定工资的 **80%**（或同岗位最低档）
2. **当地最低工资**

---

## 四、三种常见的违法操作

| 操作 | 为什么违法 | 后果 |
| --- | --- | --- |
| 试用期超过法定上限 | 违反第十九条 | 超出部分无效，需按转正工资补差 |
| 只签「试用期合同」 | 视为未签书面合同 | 需支付**二倍工资** |
| 试用期不缴社保 | 违反《社会保险法》 | 违法，须补缴 |

---

## 五、违约金：只有两种情况合法

《劳动合同法》第二十五条：除第二十二条（服务期）、第二十三条（竞业限制）规定的情形外，**用人单位不得与劳动者约定由劳动者承担违约金**。

| 合法情形 | 条件 |
| --- | --- |
| 服务期 | 单位提供了**专项培训费用**并进行了专业技术培训 |
| 竞业限制 | 限于高管、高级技术人员、其他负保密义务人员；离职后单位须按月给补偿 |

**除此之外的违约金条款无效。** 常见无效条款：
- 「未满一年离职赔偿一个月工资」
- 「提前离职赔偿培训费」（无专项培训则不算）
- 「违反制度罚款」

---

## 六、试用期能不能随便辞退

**不能。**

用人单位在试用期解除劳动合同，需要**证明劳动者不符合录用条件**，并说明理由。

| 常见误操作 | 实际 |
| --- | --- |
| 「试用期随时可以让你走」 | 需有法定理由与证据 |
| 「不符合录用条件」但没告知录用条件 | 该理由难以成立 |

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「试用期不用签合同」 | 用工之日起一个月内必须签 |
| 「试用期不用缴社保」 | 必须缴 |
| 「试用期可以随便辞退」 | 需证明不符合录用条件 |
| 「签了违约金就得赔」 | 除两种法定情形外无效 |
| 「先签试用期合同，转正再签正式的」 | 违法，且视为未签书面合同 |

---

## 八、可执行清单

### 签之前

- [ ] 对照第二节核对试用期是否超限
- [ ] 核算试用期工资是否达到双下限
- [ ] 确认社保缴纳起始月
- [ ] 检查有没有违约金条款
- [ ] 检查有没有「自愿放弃社保」

### 签之后

- [ ] 自己保留一份合同原件
- [ ] 保留工资条、考勤记录

### 如果发现问题

- [ ] 试用期超限 → 可主张补差
- [ ] 未签合同 → 可主张二倍工资
- [ ] 未缴社保 → 向社保部门反映

---

## 九、一句话记住

**试用期有法定上限，工资有双下限，社保必须缴，违约金只有两种情况合法。**
