# 求职中的人身安全：传销与境外高薪招聘

> 一句话概括：所有「交钱入门、拉人进来、按层级分钱」的组织都是传销；所有「境外高薪、包吃住、不看学历」的招聘都要先怀疑。

**适用人群**：正在找工作的应届生、毕业生；收到过「境外高薪」「月入数万」私信的人；有同学或家人突然失联、突然要钱的人。

> **政策适用范围**
> - 主要依据：《禁止传销条例》（国务院令第 444 号，2005 年 11 月 1 日起施行）第七条；《中华人民共和国刑法》第二百二十四条之一（组织、领导传销活动罪）、第二百六十六条（诈骗罪）；《中华人民共和国反电信网络诈骗法》；外交部领事保护相关规定
> - 全国统一：传销的认定标准、组织领导的刑事责任全国统一
> - 地方执行：报警受理、属地管辖按各地执行
> - 核查日期：2026-11-07
> - 已知变化：境外电信网络诈骗园区问题近年持续，各部门持续发布预警

> **写在前面的两句话**：这篇文章讲**识别**和**预防**，不描写细节。如果你已经在担心某个具体的人，直接跳到**第五节**，那里有可立即执行的步骤。

---

## 一、传销：法律给了三个特征

判断传销不需要看它叫什么名字（「直销」「连锁经营」「资本运作」「网络营销」「消费返利」都可能）。**法律已经给了可操作的标准。**

《禁止传销条例》第七条：

> 下列行为，属于传销行为：
>
> （一）组织者或者经营者通过发展人员，要求被发展人员发展其他人员加入，对发展的人员以其直接或者间接滚动发展的人员数量为依据计算和给付报酬（包括物质奖励和其他经济利益，下同），牟取非法利益的；
>
> （二）组织者或者经营者通过发展人员，要求被发展人员交纳费用或者以认购商品等方式变相交纳费用，取得加入或者发展其他人员加入的资格，牟取非法利益的；
>
> （三）组织者或者经营者通过发展人员，要求被发展人员发展其他人员加入，形成上下线关系，并以下线的销售业绩为依据计算和给付上线报酬，牟取非法利益的。
>
> 【法规】《禁止传销条例》第七条（国务院令第 444 号，2005 年 11 月 1 日起施行）

### 1.1 把法条翻译成三个特征

| 特征 | 法条对应 | 通俗说法 |
| --- | --- | --- |
| ① **交入门费** | 第七条第（二）项 | 要先交钱、买货、买「资格」才能加入 |
| ② **拉人头** | 第七条第（一）项 | 收入主要来自发展下线的人数 |
| ③ **层级计酬** | 第七条第（三）项 | 报酬按上下线层级、下线业绩计算 |

**三个特征同时具备，就是传销。** 缺一个往往不构成，但实践中会变形规避——比如把「入门费」包装成「购买产品」，把「拉人头」包装成「团队建设」。

### 1.2 组织、领导传销活动罪

达到刑事标准的，适用《刑法》第二百二十四条之一：

> 组织、领导以推销商品、提供服务等经营活动为名，要求参加者以缴纳费用或者购买商品、服务等方式获得加入资格，并按照一定顺序组成层级，直接或者间接以发展人员的数量作为计酬或者返利依据，引诱、胁迫参加者继续发展他人参加，骗取财物，扰乱经济社会秩序的传销活动的，处五年以下有期徒刑或者拘役，并处罚金；情节严重的，处五年以上有期徒刑，并处罚金。
>
> 【法规】《中华人民共和国刑法》第二百二十四条之一（《刑法修正案（七）》增设）

**注意**：这一条处罚的是「组织者、领导者」。**被诱骗加入并发展了下线的人，也可能被认定为组织者**——「我也是受害者」不一定免责。

## 二、传销的话术结构（不是名单，是模式）

传销的组织形式在变，但话术结构高度稳定。记住结构，比记公司名有用。

| 环节 | 常见说法 | 为什么这么说 |
| --- | --- | --- |
| 邀约 | 「有个好机会，见面聊」「帮我看看这个项目」 | 不在电话里说清楚，避免你查证 |
| 建立信任 | 「你看谁谁已经赚到了」「我们是正规公司」 | 用身边人降低你的警惕 |
| 制造稀缺 | 「名额有限」「这期只剩几个」 | 压缩你思考的时间 |
| 隔离信息 | 「先别跟家里说，等赚到钱再说」「别人不懂会打击你」 | **这是最强的危险信号** |
| 门槛 | 「需要先投入/买一套产品/交保证金」 | 特征① |
| 转化 | 「你也要发展人，这是复制成功」 | 特征②③ |
| 绑定 | 「你现在是团队一员，退出要赔偿」 | 制造沉没成本 |

**一行判据**：**凡是要求你「先不要告诉家人」的机会，都要停下来。**

## 三、境外高薪招聘：骗局链条

这一类近年造成的问题最严重，后果也最重。以下讲**识别链**，不写操作细节。

### 3.1 典型宣传特征

| 话术 | 为什么可疑 |
| --- | --- |
| 「月入数万，包吃包住」 | 薪酬远超同类岗位，且不要求对应能力 |
| 「不看学历、不看经验」 | 高薪岗位不会没有门槛 |
| 「工作轻松，就是打字/客服」 | 与实际岗位不符的轻描淡写 |
| 「机票签证我们全包」 | 让你零成本出国，降低阻力 |
| 「先到边境城市集合」 | **关键危险信号**——正常出境不会这样安排 |
| 「到了再说具体工作」 | 信息刻意不透明 |
| 招聘方是**个人微信/QQ**，非企业官方渠道 | 无主体可追溯 |

### 3.2 需要警惕的路径信号

以下情形出现任何一条，都应当立即终止接触：

- 要求你先到**边境地区**（云南、广西等地边境城市）再「统一安排出境」
- 要求**偷越国边境**、走「小路」、不使用正规口岸
- 收走你的**护照、身份证**「统一保管」
- 不告诉你**具体公司在哪、做什么**
- 全程由**个人**联络，无企业主体、无合同
- 催你尽快决定，不给你查证时间

### 3.3 后果的量级

说清楚这一点，比描述细节更有用：**一旦被控制，你可能面临的是人身自由受限、被迫从事违法活动、被转卖，且身处境外时救援难度极高。**

这不是恐吓。外交部与公安部多次就境外电信网络诈骗园区发布提醒，提醒公民警惕「境外高薪招聘」陷阱。【官方】

**同时要理解一个法律现实**：即使是被胁迫参与，在境外从事诈骗活动本身仍可能构成犯罪，回国后要承担法律责任。「我是被骗去的」在司法实践中需要证据支撑。

---

### 3.4 另外两类引流

**假实习 / 假招聘引流**：以实习、招聘为名收集信息，再把候选人引流到其他链条（培训贷、传销、境外招聘）。识别要点见 09-03。

**「高薪兼职」引流到违法活动**：「帮忙取钱」「帮忙转账」「帮忙注册公司」——这类「兼职」实际是为诈骗、洗钱提供帮助，可能构成帮助信息网络犯罪活动罪或掩饰、隐瞒犯罪所得罪，详见「帮信罪离大学生有多近」（03-06）。

**共同点**：报酬与劳动量严重不匹配，且要求你「别问、照做」。

## 四、被控制了怎么办

**前提认知**：被控制时，你的第一目标是**保住人身安全并寻找对外联系的机会**，不是「讲道理」或「据理力争」。

### 4.1 在国内（传销窝点等）

| 做法 | 说明 |
| --- | --- |
| 不要正面冲突 | 不要激烈对抗、不要威胁举报，先降低对方警惕 |
| 记住位置信息 | 门牌、楼栋、周边店铺名、窗外的地标、公交站名 |
| 寻找外出机会 | 外出「上课」、就医、买东西时是最可能的机会 |
| 保留通讯设备 | 尽量不让手机被收走；被收走前设法告知家人位置 |
| 利用一切对外窗口 | 快递员、外卖员、邻居、房东——可以留纸条或低声求助 |
| 找机会报警 | 拨打 110，或用短信报警（部分省份支持 12110 短信报警）【待核实】具体号码与格式以当地公安公布为准 |
| 脱身后立即报警 | 不要因为「怕丢脸」而不报警，你的报案是解救他人的关键 |

### 4.2 在境外

| 做法 | 说明 |
| --- | --- |
| 优先保证人身安全 | 不要激怒控制方，不要试图独自逃跑（尤其在不熟悉的环境） |
| 设法联系家人 | 一条消息、一个定位就有价值 |
| 联系中国驻当地使领馆 | 外交部**全球领事保护与服务应急热线：12308**（24 小时）【官方】 |
| 家人代为报警 | 家人在国内报警，警方可通过国际执法合作渠道处理 |
| 保留证据 | 聊天记录、转账记录、对方的账号与身份信息 |

> **外交部全球领事保护与服务应急热线：12308**（+86-10-12308）。这是外交部设立的 24 小时领事保护应急热线，中国公民在境外遇到紧急情况可拨打。【官方】

## 五、家人发现失联怎么办

这一节写给**在家的人**。时间非常关键。

### 5.1 立即做的四件事（按顺序）

| 顺序 | 动作 | 说明 |
| --- | --- | --- |
| 1 | **报警** | 到户籍地或最后居住地派出所报案。**不需要等 24 小时**——人口失踪可以立即报警，这是常见误解 |
| 2 | 提供完整信息 | 姓名、身份证号、照片、最后联系时间、最后位置、手机号、社交账号、银行卡号 |
| 3 | 查资金流向 | 银行流水、支付记录——异常转账是重要线索 |
| 4 | 联系使领馆/12308 | 若怀疑已出境，拨打 12308，提供姓名、护照号、可能的所在国 |

### 5.2 同时要做的

- [ ] 保留所有聊天记录（**不要删除**，不要只截图，要保留原始记录）
- [ ] 记录对方提到的所有地名、公司名、人名
- [ ] 通知学校（如仍在校）——学校有应急机制
- [ ] 不要自行前往「救人」，也不要向不明身份的人支付「赎金」——这可能既救不了人，又扩大损失
- [ ] 不要相信主动联系你的「能帮忙捞人」的人，先报警核实

### 5.3 一个常见误区

**「失联要等 24 小时才能报警」是错的。** 人口失踪可以立即报警。涉及疑似被拐卖、被控制的，更应当立即报警。

## 六、预防：三条底线

比事后处置更有效的，是三条简单的底线。

| 底线 | 具体做法 |
| --- | --- |
| **① 不为工作付钱、不押证件** | 任何入职前收费、收走护照身份证的，直接终止（《劳动合同法》第九条） |
| **② 不见面不谈、不实地不签** | 面试必须在**正规办公场所**；对方拒绝告知地址的，不去 |
| **③ 出境工作必须走正规渠道** | 通过有**对外劳务合作经营资格**的企业办理，签订正式合同，办工作签证而非旅游签证 |

第 ③ 条展开：合法出境务工需要通过具备对外劳务合作经营资格的企业，并办理相应工作签证。**持旅游签证出境打工本身就是违法的**，也是被控制的重要前兆。

对外劳务合作企业的资质名单可通过商务部「对外投资和经济合作司」相关系统查询，具体查询入口以商务部官网公布为准。

### 6.1 一条给家人的约定

**和家人约定一个「安全词」和一个「定期报平安的机制」。** 遇到被控制、被胁迫时，一句预设的普通话就能传递危险信号。

## 常见误区

| 误区 | 实际 |
| --- | --- |
| 「传销就是卖假货」 | 传销的核心是**交入门费 + 拉人头 + 层级计酬**，卖不卖货不是关键 |
| 「我只是被拉进去的，不算犯罪」 | 《刑法》224 条之一处罚组织者、领导者；发展了下线也可能被认定 |
| 「境外高薪是真的，我朋友去过」 | 「朋友去过」本身常用作话术；务必查证本人是否真实存在、是否真实回来 |
| 「先去看看，不行就回来」 | 到了境外、证件被收，回不回来不由你决定 |
| 「失联要等 24 小时才能报警」 | 可以立即报警 |
| 「报警没用」 | 报警是启动协查、冻结资金、跨境协作的唯一正式入口 |
| 「我自己去把人带回来」 | 高风险，可能双方都陷入危险；应通过警方与使领馆 |
| 「对方说交钱就放人」 | 不轻信、不私自支付，交由警方判断 |

## 可执行清单

**求职期间**

- [ ] 不向任何招聘方支付费用、不交出护照/身份证原件
- [ ] 面试地点必须是可查证的正规办公场所
- [ ] 全程通过企业官方渠道沟通，警惕纯个人微信/QQ 联络
- [ ] 对「境外高薪、包吃住、不看学历」一律先假设是骗局
- [ ] 出国工作只走有对外劳务合作经营资格的企业，办工作签证

**和家人**

- [ ] 约定定期报平安的时间
- [ ] 约定一个只有家人懂的「安全词」
- [ ] 把行程、住宿地址、同行人信息告知家人

**如果怀疑自己被卷入**

- [ ] 先保证人身安全，不激烈对抗
- [ ] 记位置、找对外联系机会
- [ ] 拨打 110（境内）；境外拨 12308
- [ ] 脱身后立即报警

**如果是家人失联**

- [ ] **立刻**到派出所报警（不必等 24 小时）
- [ ] 提供姓名、身份证号、照片、最后联系时间与位置、账号信息
- [ ] 查银行流水与支付记录
- [ ] 怀疑出境：拨 12308
- [ ] 保留全部聊天记录原件，不要删除
- [ ] 不私自支付「赎金」，不轻信「能捞人」的中间人

## 一句话记住

**传销看三个特征（交钱、拉人、层级分钱），境外招聘看一个动作（先到边境再出境）——遇到任何一个，先停下来告诉家人。**
