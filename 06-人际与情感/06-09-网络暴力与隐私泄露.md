# 网络暴力与隐私泄露：被挂人、被造谣怎么办

> 一句话概括：网暴的关键不在「怼回去」，在于把证据固定下来的那几个小时。

**适用人群**：被挂到公共平台、被人肉、被造谣的人；私密照片被威胁传播的人；看到朋友被网暴想帮忙的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国民法典》人格权编（名誉权、隐私权、个人信息保护）；《中华人民共和国治安管理处罚法》（2025 年修订，2026 年 1 月 1 日起施行）；《中华人民共和国刑法》第二百四十六条（侮辱罪、诽谤罪）、第二百五十三条之一（侵犯公民个人信息罪）；《中华人民共和国个人信息保护法》
> - 全国统一：**法律责任全国统一**
> - 核查日期：2026-11-05
> - 条文序号说明：治安管理处罚法 2025 年 6 月 27 日修订、**2026 年 1 月 1 日已施行**。修订后条序有调整：**公然侮辱、捏造事实诽谤、威胁他人人身安全、偷窥偷拍窃听散布他人隐私等，现行均规定在第五十条**（2012 年版为第四十二条），罚款上限由 500 元提高到 1000 元。第五十条共六项：第（一）项威胁人身安全、第（二）项侮辱诽谤、第（四）项对证人打击报复、第（五）项反复发送淫秽侮辱信息或跟踪滋扰、第（六）项偷窥偷拍窃听散布隐私
>
> ⏳ 易过时：各平台的投诉入口与处理时效。

> **与相关隐私篇目的分工**：本篇处理「**正在发生**的网暴与人肉」——从被挂那一刻起的取证、投诉、报案。不是网暴但信息已被泄露（名下多卡、被冒名注册）→ 11-03；偷拍、偷窥、宿舍被翻 → 08-11；求职投简历时该给什么 → 09-10。

## 一、先明白网暴的机制

网暴不是「很多人在网上说你坏话」，它是一个有阶段的过程。理解阶段，才知道在每个阶段该做什么。

| 阶段 | 发生了什么 | 可干预点 |
| --- | --- | --- |
| **① 触发** | 一条帖子/一张图/一段截取视频发出 | **这一阶段最关键**：及时投诉可阻断扩散 |
| **② 扩散** | 转发、搬运、多平台同步 | 记录传播量，这是定损的关键 |
| **③ 人身攻击** | 辱骂、造谣、P 图、编造「黑历史」 | 固定证据，平台投诉 + 报警 |
| **④ 人肉搜索** | 姓名、学校、专业、手机号、家庭住址被公开 | **立即报警**，这是刑事风险区 |
| **⑤ 线下骚扰** | 电话轰炸、寄东西、到校门口 | 报警，通知学校保卫处 |

**核心判断**：越早干预，代价越小。等到第④⑤阶段，你能做的只剩事后追责。

## 二、黄金 6 小时：先做什么

被网暴后的头几个小时，情绪最激烈，最容易做错事。**先按这个顺序做，再处理情绪。**

### 2.1 第一步：固定证据（不要先回复）

| 证据 | 怎么留 | 关键细节 |
| --- | --- | --- |
| **截图** | 带**完整页面**，包括 URL、时间、账号名、点赞转发数 | 不要只截一句话，不要裁掉边栏 |
| **录屏** | 从打开链接开始录，滚动完整内容 | 录屏能证明「内容确实存在于这个页面」 |
| **链接** | 复制原始 URL，存进文档 | 链接可能被删，所以要和截图对应编号 |
| **账号信息** | 截图对方的昵称、ID、主页 | 对方可能改名，所以主页和 ID 都要截 |
| **传播数据** | 转发数、评论数、阅读量、在哪些平台被搬运 | 这是主张损害程度的依据 |

### 2.2 第二步：双重备份

- 本地存一份（手机/电脑）
- 云端存一份（网盘、邮箱发给自己）

**理由**：手机丢失、账号被盗、误删，都会让证据消失。

### 2.3 第三步：不要做的事

| 不要做 | 为什么 |
| --- | --- |
| **不要在评论区对骂** | 会让你的言论也被截取，反过来成为对方材料 |
| **不要删掉自己的账号** | 你删了，自己的历史记录也没了 |
| **不要自己「发一条澄清」** | 澄清往往带来二次传播。是否回应，等冷静后再定 |
| **不要私下联系对方** | 可能被截图断章取义，也可能激化 |
| **不要发对方的隐私作为反击** | 你会从受害者变成侵权者 |

### 2.4 第四步：告诉一个人

网暴最伤人的部分是**孤立感**。找一个信任的人，把情况说清楚，请对方帮你一起记录和判断。**一个人处理这件事很容易做错决定。**

## 三、取证清单（逐项打勾）

```
□ 原始帖子的完整截图（含 URL、时间、账号、互动数据）
□ 从头滚到尾的录屏
□ 原始 URL 列表（按 1、2、3 编号）
□ 发布者的主页截图（昵称 + ID + 头像）
□ 所有转发/搬运的链接与截图
□ 评论区的辱骂内容截图（挑最恶劣的，不要全截）
□ 私信骚扰的截图
□ 被公开的个人信息清单（姓名/学号/手机/住址/家人信息）
□ 每条信息被公开的页面截图与 URL
□ 传播量数据（转发数、阅读量、是否上了热门）
□ 自己因此受到影响的记录（就医、请假、无法上课）
```

**为什么传播量重要**：民事上影响损害赔偿，治安和刑事上影响「情节严重」的认定。

## 四、平台投诉：先止损

平台投诉的目的不是「讨回公道」，是**停止扩散**。

### 4.1 投诉什么

| 内容 | 投诉理由 |
| --- | --- |
| 辱骂、人身攻击 | 人身攻击/辱骂 |
| 编造事实 | 不实信息/造谣 |
| 公开手机号、住址、身份证 | 侵犯隐私/泄露个人信息 |
| 私密照片 | 色情低俗/侵犯隐私（**这类处理通常最快**） |
| P 图丑化 | 侵犯肖像权/人身攻击 |

### 4.2 怎么做

1. 用平台内的「举报」入口，选对应类目
2. 同一内容被多平台搬运，**逐个平台投诉**（不要指望一个平台管所有）
3. 保存投诉记录（投诉编号、时间、结果）
4. 处理慢时，通过平台的「侵权投诉」通道提交**正式通知**，附身份证明和权属证明

> 【经验】各平台处理时效差异很大，涉隐私和涉黄内容通常处理较快，涉及「言论」类争议较慢。各平台入口与规则见其官方帮助中心。具体时效

### 4.3 如果平台不处理

《民法典》第一千一百九十五条规定了「通知—删除」规则：权利人通知网络服务提供者采取删除、屏蔽、断开链接等必要措施，网络服务提供者接到通知后应及时处理；未及时采取必要措施，对损害的扩大部分与该网络用户承担连带责任。

> 【法规】《中华人民共和国民法典》第一千一百九十五条

也就是说：**你正式通知了，平台不管，平台要担责。** 所以书面通知（而不是点个举报按钮）更有分量。

## 五、法律分三档

### 5.1 民事：名誉权、隐私权、个人信息

| 权利 | 被侵害的表现 | 依据 |
| --- | --- | --- |
| **名誉权** | 编造事实贬损你的社会评价 | 《民法典》第一千零二十四条 |
| **隐私权** | 公开你的私密空间、活动、信息 | 《民法典》第一千零三十二条 |
| **个人信息** | 公开姓名、电话、住址、行踪 | 《民法典》第一千零三十四条以下、《个人信息保护法》 |
| **肖像权** | 未经同意使用你的照片、P 图 | 《民法典》第一千零一十九条 |

> 【法规】《民法典》第一千零二十四条：民事主体享有名誉权。任何组织或者个人不得以侮辱、诽谤等方式侵害他人的名誉权。

可以主张：停止侵害、删除、赔礼道歉、赔偿损失（含精神损害）。

### 5.2 治安：行政处罚

| 行为 | 依据（行为内容） |
| --- | --- |
| 公然侮辱他人 | 治安管理处罚法 |
| 捏造事实诽谤他人 | 同上 |
| 偷窥、偷拍、窃听、散布他人隐私 | 同上 |
| 多次发送淫秽、侮辱、恐吓信息干扰他人正常生活 | 同上 |
| 威胁他人人身安全 | 同上 |

> 【法规】《中华人民共和国治安管理处罚法》（2025 年修订，2026 年 1 月 1 日起施行）**第五十条**对上述行为统一规定：处五日以下拘留或者一千元以下罚款；情节较重的，处五日以上十日以下拘留，可以并处一千元以下罚款。分项为——第（一）项写恐吓信或者以其他方法威胁他人人身安全；第（二）项公然侮辱他人或者捏造事实诽谤他人；第（四）项对证人及其近亲属打击报复；第（五）项多次发送淫秽、侮辱、恐吓等信息或者采取滋扰、纠缠、跟踪等方法干扰他人正常生活；第（六）项偷窥、偷拍、窃听、散布他人隐私。（旧法为第四十二条，罚款上限由 500 元提高到 1000 元。）
>
> **这条还有第二款，很多人不知道**：实施第（五）项滋扰、纠缠、跟踪行为的，除处罚外，经公安机关负责人批准，可以**责令其一定期限内禁止接触被侵害人**；违反禁止接触规定的，处五日以上十日以下拘留，可以并处一千元以下罚款。这比「处罚一次」更有用——它是一道可以执行的「别再靠近我」。

**报警要带**：证据材料（打印或 U 盘）、身份证。要求出具**接报案回执**，这张纸一定要拿。

### 5.3 刑事：三个可能涉及的罪名

| 罪名 | 条文 | 门槛 |
| --- | --- | --- |
| **侮辱罪** | 《刑法》第二百四十六条 | 公然侮辱，情节严重 |
| **诽谤罪** | 《刑法》第二百四十六条 | 捏造事实诽谤他人，情节严重 |
| **侵犯公民个人信息罪** | 《刑法》第二百五十三条之一 | 非法获取、出售或提供公民个人信息，情节严重 |

> 第二百四十六条　以暴力或者其他方法公然侮辱他人或者捏造事实诽谤他人，情节严重的，处三年以下有期徒刑、拘役、管制或者剥夺政治权利。
>
> 前款罪，**告诉的才处理**，但是严重危害社会秩序和国家利益的除外。
>
> 【法规】《中华人民共和国刑法》第二百四十六条

**这里有个关键点**：「告诉的才处理」意味着侮辱罪和诽谤罪通常需要**你自己去法院起诉**（自诉），公安机关不一定立案。这是很多人卡住的地方。

但《刑法》第二百五十三条之一（侵犯公民个人信息罪）**不是自诉罪**，人肉搜索、买卖个人信息属于公安立案范围。

> 第二百五十三条之一　违反国家有关规定，向他人出售或者提供公民个人信息，情节严重的，处三年以下有期徒刑或者拘役，并处或者单处罚金；情节特别严重的，处三年以上七年以下有期徒刑，并处罚金。
>
> 【法规】《中华人民共和国刑法》第二百五十三条之一

### 5.4 三档怎么选

| 你的目标 | 走哪条 |
| --- | --- |
| 只想让它消失 | 平台投诉 |
| 想让对方受处罚 | 报警（治安） |
| 想获得赔偿、公开道歉 | 民事诉讼 |
| 情节极其严重（大规模造谣、人肉） | 报警 + 咨询律师（刑事） |

## 六、人肉搜索：最危险的一档

个人信息一旦被公开，风险会从「网上被骂」升级为「现实中被打扰」。

### 6.1 什么算个人信息

| 类型 | 例子 |
| --- | --- |
| 身份信息 | 姓名、身份证号、学号 |
| 联系方式 | 手机号、微信、邮箱 |
| 位置信息 | 学校、宿舍楼、家庭住址、常去的地方 |
| 家庭信息 | 父母姓名、工作单位 |
| 生物识别 | 人脸照片、声纹 |
| 行踪轨迹 | 「他每天几点从哪个门走」 |

### 6.2 立即要做的事

| 顺序 | 动作 |
| --- | --- |
| ① | **报警**，说明「个人信息被公开，担心人身安全」 |
| ② | 通知学校保卫处，说明可能有校外人员来找你 |
| ③ | 关闭社交账号的手机号搜索、允许陌生人查看等设置 |
| ④ | 告知家人、室友、辅导员，让他们知道可能有骚扰电话 |
| ⑤ | 记录所有骚扰电话（号码、时间、内容） |

### 6.3 如果出现线下骚扰

- **不要单独应对**
- 报警，说明具体时间地点
- 学校保卫处可以协助
- 必要时申请变更宿舍

## 七、私密影像被威胁

这一类最需要冷静，因为它涉及「羞耻感」这个最强的杠杆。

| 情况 | 做什么 |
| --- | --- |
| 对方威胁要传播 | **不要付钱，不要妥协**。妥协通常不会终止威胁，只会证明有效 |
| 已经传播 | 报警（涉及传播淫秽物品、侵犯隐私）；同时平台投诉（这类处理最快） |
| 对方是你认识的人 | 保留全部聊天记录，不要删 |
| 涉及未成年人 | **立即报警**，这是另一个量级 |

**关键事实**：传播私密影像的行为，违法的是传播者，不是你。羞耻感被用来控制你，但它不该由你承担。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「先骂回去再说」 | 你的回骂也会被截图，可能反过来成为对方材料 |
| 「删了帖就没事了」 | 删之前先固定证据，否则你连「发生过什么」都证明不了 |
| 「截图就够了」 | 截图容易被质疑伪造，录屏 + URL 更稳 |
| 「报警没用，网上骂人不管」 | 公然侮辱、散布隐私是治安违法行为，可以处罚 |
| 「诽谤罪报警就能立案」 | 侮辱罪、诽谤罪原则上是自诉案件，需要自己去法院起诉 |
| 「人肉搜索没人管」 | 可能构成侵犯公民个人信息罪，属公安立案范围 |
| 「发澄清能挽回」 | 可能带来二次传播。是否回应，冷静后再定 |
| 「只要我不看就没事」 | 不看不等于不存在。证据要留，安全要顾 |
| 「我也公开对方的隐私，扯平」 | 你会从受害者变成侵权者 |

## 九、可执行清单

### 立刻（前 6 小时）

- [ ] **不要回复、不要对骂、不要删账号**
- [ ] 截图（带 URL、时间、账号、互动数据）
- [ ] 录屏（从头滚到尾）
- [ ] 把所有链接抄进一个文档并编号
- [ ] 云端 + 本地双备份
- [ ] 告诉一个信任的人

### 当天

- [ ] 逐平台投诉，记录投诉编号
- [ ] 如果涉及个人信息被公开 → 报警
- [ ] 关闭社交账号的隐私暴露项
- [ ] 通知辅导员与家人（尤其是可能被骚扰的人）

### 3 天内

- [ ] 整理一份完整的时间线（什么时候、哪个平台、什么内容、传播量）
- [ ] 决定是否做正式的平台侵权通知
- [ ] 咨询学校法律援助中心或律师（多数高校有）
- [ ] 预约心理咨询（见 07-03）

### 长期

- [ ] 保留证据至少数年（诉讼时效与追诉期限的考量）
- [ ] 定期搜索自己的名字，看有没有新的传播
- [ ] 不要在情绪激动时做公开回应

## 十、一句话记住

**先留证，再动手——网暴里最不可挽回的错误，是在证据固定之前就回应。**
