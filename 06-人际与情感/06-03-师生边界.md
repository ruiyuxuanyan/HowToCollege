# 师生边界：导师、老师的越界行为与举报路径

> 一句话概括：权力不对等的关系里，边界要提前划，越界要留证。

**适用人群**：跟随导师做科研的研究生；与任课教师、辅导员、教练有单独接触的学生；正在被要求做分外之事但不确定是否合理的人。

> **政策适用范围**
> - 主要依据：教育部《新时代高校教师职业行为十项准则》（教师〔2018〕16 号）；《教育部关于高校教师师德失范行为处理的指导意见》（教师〔2018〕17 号）；《普通高等学校学生管理规定》（教育部令第 41 号）；《中华人民共和国民法典》第一千零一十条
> - 全国统一 / 地方执行：**师德准则与处理指导意见全国统一；各校师德监督举报渠道、调查程序由学校规定**
> - 核查日期：2026-11-07
>
> ⏳ 易过时：各校师德监督举报的具体部门与联系方式。

## 一、问题的核心是权力不对等

师生关系和普通人际关系最大的不同：**老师手里有你需要的东西。**

| 老师掌握的资源 | 具体表现 |
| --- | --- |
| **成绩** | 平时分、期末评定、答辩表决 |
| **毕业** | 开题通过、中期检查、论文送审、答辩资格 |
| **推荐** | 保研推荐信、出国推荐、实习机会、就业推荐 |
| **资源** | 项目经费、实验设备、数据、署名顺序 |
| **话语权** | 在学院、评审组中的评价权 |

这决定了三件事：

1. **「不愿意」很难说出口**——拒绝的成本由你承担
2. **「自愿」需要重新审视**——在有权力差的关系里，表面同意可能不是真正的自愿
3. **越界往往不是一步到位的**——而是逐步试探，看你能接受到哪一步

理解这一点，不是让你敌视所有老师，而是让你知道：**当你感到不舒服却又说不出为什么时，很可能就是权力差在起作用。**

## 二、越界行为的四个等级

不是所有越界都是性骚扰。分级处理，路径不同。

| 等级 | 表现 | 性质 | 找谁 |
| --- | --- | --- | --- |
| **一级：不当言行** | 开不当玩笑、评论外貌、私下频繁约见、过度打听私生活 | 师德问题，尚不构成违法 | 学院、师德监督 |
| **二级：学术压榨** | 长期安排与学业无关的私事、侵占学生成果署名、克扣补助 | 违反师德与学术规范 | 学院、研究生院、学术委员会 |
| **三级：性骚扰** | 言语、文字、图像、肢体方式与性有关且违背意愿 | 民事侵权，可能涉治安/刑事 | 见 06-02 |
| **四级：学术不端** | 强迫学生造假、代写、篡改数据 | 违反学术规范，可能涉违法 | 学术委员会、见 02-10 |

**这四级可以叠加**。一个长期压榨学生的导师，往往同时有一级和二级的问题。

## 三、一级：不当言行，怎么划边界

这一级的难点是**没有明确标准**，容易变成「是不是我想多了」。给几条可操作的判断：

| 情形 | 正常 | 越界信号 |
| --- | --- | --- |
| 单独见面 | 办公室、门开着、有第三人在场 | 要求去酒店、住处、KTV、深夜单独约 |
| 沟通时间 | 工作时间 | 深夜、频繁的私人时段 |
| 话题 | 学业、科研、职业规划 | 恋爱经历、身材、家庭隐私 |
| 联系方式 | 学校邮箱、工作群 | 要求只加私人微信、要求删聊天记录 |
| 礼物 | 集体性的节日小礼物 | 单独送贵重礼物、要求保密 |
| 称呼 | 正常称呼 | 起亲昵外号、要求改口 |

### 3.1 三条自保原则

1. **在公开场合见面**：办公室门开着，或有第三人在场。可以主动说「我叫上 XX 一起去，方便记录」。
2. **留下书面痕迹**：任务安排、时间要求，尽量走邮件或工作群。口头安排后，发一条消息确认：「老师，刚才您说的 XX，我理解是……对吗？」
3. **不接受「保密」要求**：「这件事不要告诉别人」是一个明确的信号。

### 3.2 如果已经发生了不当言行

- **不要当面激烈冲突**（在权力不对等的关系里，正面冲突的成本由你承担）
- **当天写下来**，时间、地点、原话
- **此后避免单独接触**，理由可以是「我最近在赶 XX」，不需要撕破脸

## 四、二级：学术压榨的边界

这一级最常见，也最难界定。什么是「正常的要求」，什么是「压榨」？

### 4.1 对照表

| 情形 | 正常范围 | 越界 |
| --- | --- | --- |
| **工作量** | 有明确的研究任务和进度安排 | 长期无上限、无休息日、以毕业相威胁 |
| **任务内容** | 科研、文献、实验、数据处理 | 接送孩子、代买菜、装修房子、给私人公司干活 |
| **署名** | 按实际贡献排序 | 主要贡献者被排在后面，或成果被直接占用 |
| **补助** | 按学校/项目标准发放 | 长期克扣、以各种理由扣减 |
| **假期** | 协商安排 | 不允许休假、寒暑假全程占用 |
| **人身** | 无 | 辱骂、罚站、体罚、当众羞辱 |

### 4.2 「正常要求」和「压榨」的分界

三个判断问题：

1. **这件事和我的学业有关系吗？** 帮你取快递没有，帮你做实验有。
2. **我拒绝会有什么后果？** 正常的后果是「那我自己做」，越界的后果是「你别想毕业」。
3. **这个要求对所有人都一样吗？** 对所有人都严格，是风格；只针对某几个人，是打压。

### 4.3 留存记录

这一级最重要的证据是**工作记录**：

- 任务安排的聊天记录（尤其是深夜、假期、与学业无关的任务）
- 你的工作日志（做了什么、花了多少时间）
- 论文/项目的贡献记录（谁做了什么）
- 补助发放记录（银行流水）

## 五、证据保留：三个层次

| 层次 | 内容 | 作用 |
| --- | --- | --- |
| **书面痕迹** | 邮件、工作群消息、任务清单、签字文件 | 最有力，因为有第三方可验证 |
| **记录** | 事件日志、工作日志、时间线 | 让「长期性」可见 |
| **旁证** | 同门、同学、其他老师的证言 | 补强 |

**注意**：

- 邮件不要删，学校邮箱通常有归档
- 微信聊天记录定期备份（换手机时尤其要注意）
- **不要用非法手段取证**（如在他人办公室安装录音设备），这可能让你从有理变无理
- 你是对话一方时的录音，一般可作为证据使用【经验】

## 六、举报路径

### 6.1 四个层级

| 层级 | 找谁 | 适合什么 |
| --- | --- | --- |
| **学院** | 学院党委/党总支、分管研究生工作的副院长 | 一级、二级问题，希望内部解决 |
| **学校师德监督** | 党委教师工作部、人事处 | 师德失范，有专门受理渠道 |
| **学校纪委** | 纪检监察机构 | 涉及违纪、滥用职权 |
| **上级** | 省级教育行政部门、12345 | 学校不处理 |

### 6.2 师德失范的专门依据

> 【官方】教育部《新时代高校教师职业行为十项准则》（教师〔2018〕16 号）明确了高校教师的十条行为规范，其中包括「关心爱护学生」「坚持言行雅正」「遵守学术规范」「秉持公平诚信」等要求，并明确「不得与学生发生任何不正当关系，严禁任何形式的猥亵、性骚扰行为」。

> 【官方】《教育部关于高校教师师德失范行为处理的指导意见》（教师〔2018〕17 号）规定了师德失范行为的受理、调查、认定与处理程序，明确对师德失范行为实行「一票否决」。

这两个文件是举报时最应该引用的依据。**它们明确了「学校必须处理」，而不是「可以处理」。**

### 6.3 举报信怎么写

不要写情绪，写事实。结构：

```
一、举报人与被举报人基本信息
二、事实经过（按时间顺序，每条注明时间、地点、在场人）
三、证据清单（编号列出，说明每份证据证明什么）
四、请求事项（依据哪条规定，请求什么处理）
五、关于保密的请求
六、联系方式
```

**关键**：每一条事实都要有对应证据。没有证据的事实写「有 XX 可以作证」。

### 6.4 举报前必须想清楚的三个问题

| 问题 | 为什么重要 |
| --- | --- |
| **我的核心诉求是什么？** | 换导师？道歉？处分对方？还是只想停止？不同诉求对应不同路径 |
| **我能承受多长时间？** | 正式调查通常需要数月，期间关系会更紧张 |
| **我的学业会不会受影响？** | 这是最现实的顾虑，需要提前安排（见 7.2） |

## 七、更换导师：可行性与代价

### 7.1 什么情况下应该换

- 涉及性骚扰（见 06-02）
- 长期压榨且沟通无效
- 研究方向严重不匹配
- 导师即将离职、退休、长期不在岗

### 7.2 流程（各校不同，此为通行框架）

1. **先找学院研究生秘书/分管副院长私下咨询**——不要直接提交申请
2. 了解本校《研究生导师管理办法》中关于更换导师的规定
3. 找到愿意接收的新导师（**这一步最难，通常需要先有接收方**）
4. 提交书面申请，说明理由
5. 学院协调，可能组织谈话

> 各校更换导师的条件与程序差异很大，有的要求双方导师同意，有的由学院直接指派。查本校研究生院规定。

### 7.3 代价与现实

| 代价 | 说明 |
| --- | --- |
| **时间** | 可能延毕半年到一年 |
| **关系** | 与原导师、原课题组彻底决裂 |
| **风评** | 部分老师可能不愿接收「换过导师」的学生 |
| **成果** | 已做的数据、成果归属可能产生争议 |

**这不是劝你忍**，而是让你在信息完整的情况下做决定。如果涉及性骚扰或人身安全，这些都该往后排。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「老师严格是为我好」 | 严格和压榨的区别是：严格指向学业，压榨指向私人利益和人身控制 |
| 「别人都忍了，我也忍」 | 别人忍不忍，不改变行为的性质 |
| 「举报了我就毕不了业」 | 这是最真实的风险，所以要在举报前安排好学业（见 7.2），而不是因此不举报 |
| 「我没有录音，没法举报」 | 邮件、工作群消息、任务记录、同门证言，都是证据 |
| 「他是教授，学校不会处理他」 | 师德失范实行「一票否决」，这是明文规定。但实际执行力度因校而异 |
| 「先忍到毕业再说」 | 可以，但要写下来。毕业后再追究，时效和证据都会更难 |
| 「我要发到网上」 | 可能涉及侵犯名誉权（见 06-09）。走正式渠道更稳 |

## 九、可执行清单

### 现在就做

- [ ] 把过去发生的事按时间顺序写下来（不确定的写「约」）
- [ ] 检查邮件和聊天记录，导出一份备份
- [ ] 记下同门中可能愿意作证的人

### 建立边界

- [ ] 此后所有任务安排尽量走邮件或工作群
- [ ] 单独见面时要求门开着，或主动带第三人
- [ ] 不接受「这件事不要告诉别人」的要求
- [ ] 不深夜单独赴约

### 如果决定举报

- [ ] 查本校「党委教师工作部」或「师德监督」的举报方式
- [ ] 按 6.3 的结构写好材料
- [ ] 先咨询学院研究生秘书，了解程序
- [ ] 同时准备学业上的备选方案（换导师 / 换方向）
- [ ] 保留一份材料副本给信任的人

### 照顾自己

- [ ] 预约心理咨询（免费，见 07-03）
- [ ] 维持课题组之外的朋友关系
- [ ] 不要独自承担——至少告诉一个人

## 十、一句话记住

**权力不对等的关系里，「他对我很好」和「他对我有企图」可以同时成立——重要的不是他的动机，是你的边界有没有被尊重。**
