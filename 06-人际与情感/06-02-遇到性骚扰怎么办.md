# 遇到性骚扰怎么办

> 一句话概括：第一件事是留证据，第二件事是找到会受理你的人。

**适用人群**：正在经历或曾经经历过性骚扰的在校生（不限性别）；被骚扰后不确定「这算不算」的人；想帮朋友但不知道该做什么的人。

> **政策适用范围**
> - 主要依据：《中华人民共和国民法典》第一千零一十条；《中华人民共和国妇女权益保障法》（2022 年修订）；《中华人民共和国治安管理处罚法》（2025 年修订，2026 年 1 月 1 日起施行）；教育部《新时代高校教师职业行为十项准则》
> - 全国统一 / 地方执行：**法律责任全国统一；学校内部受理机构、处理流程由各校规定**
> - 核查日期：2026-11-05
> - 条文序号说明：治安管理处罚法 2025 年修订后条文顺序有调整，本文引用**行为内容**，具体序号标注【待核实】
>
> ⏳ 易过时：各校受理机构名称、师德失范举报的具体流程。

## 一、法律上的性骚扰是什么

《民法典》第一千零一十条是核心条文：

> 违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施性骚扰的，受害人有权依法请求行为人承担民事责任。
>
> 机关、企业、学校等单位应当采取合理的预防、受理投诉、调查处置等措施，防止和制止利用职权、从属关系等实施性骚扰。
>
> 【法规】《中华人民共和国民法典》第一千零一十条（2021 年 1 月 1 日起施行）

拆开看，构成性骚扰需要三个要素：

| 要素 | 含义 | 说明 |
| --- | --- | --- |
| **违背他人意愿** | 你不愿意，或明确表示过不愿意 | 沉默不等于同意；不敢反抗不等于同意 |
| **与性有关** | 言语、文字、图像、肢体行为 | 不要求「触碰」，说、发、拍都算 |
| **指向特定人** | 针对你 | 不是你过度敏感的问题 |

**第二款是很多人忽略的重点**：法律明确要求**学校**采取预防、受理投诉、调查处置措施。也就是说，学校有法定义务，不只是「可以帮你」。

《妇女权益保障法》（2022 年修订）进一步强化了这一点，明确禁止以恋爱、交友为名或者在终止恋爱关系、离婚之后实施纠缠、骚扰，并规定学校应当采取措施预防和制止性骚扰。

> 【法规】《中华人民共和国妇女权益保障法》（2022 年 10 月 30 日修订，2023 年 1 月 1 日起施行）关于人身和人格权益的相关条款。【待核实】具体条项以现行文本为准

## 二、常见场景与「这算不算」的对照

很多人卡在第一步：不确定自己遇到的是不是性骚扰。先看这张表。

| 场景 | 具体行为 | 是否属于性骚扰 |
| --- | --- | --- |
| **语言** | 反复开黄腔、评论身体、追问性经历 | 违背意愿且反复，成立 |
| **文字/图像** | 发色情图片、视频、露骨文字，即使「开玩笑」 | 成立 |
| **肢体** | 不必要的触碰、搂抱、抚摸、故意贴近 | 成立 |
| **凝视/跟踪** | 长时间盯着身体部位、尾随、堵路 | 可构成，尤其伴随言语时 |
| **权力型** | 老师以成绩、推荐、毕业为条件提出性要求 | 成立，且属师德失范，见 06-03 |
| **实习/职场** | 上司、同事的上述行为 | 成立，另可通过劳动监察、工会渠道 |
| **网络** | 陌生人发送露骨内容、偷拍传播 | 成立，可能同时涉治安违法 |
| **单次轻度** | 一次不合时宜的玩笑，你说不要后对方停止 | 通常按人际冲突处理，但**记录下来** |

**一个实用判断**：如果你需要反复说服自己「他可能没那个意思」，那多半不是你敏感。

## 三、立刻做什么（分场景）

### 3.1 当场

| 动作 | 为什么 |
| --- | --- |
| **明确说「不」** | 用最简短的话：「不要这样」「我不喜欢」。不需要解释，不需要客气 |
| **离开现场** | 不必等对话结束。你有权直接走 |
| **找见证人** | 让周围的人注意到发生了什么事 |
| **不要独自去封闭空间「谈清楚」** | 包括办公室、宿舍、车里 |

如果当时**没能反抗**——这非常常见，人在惊吓时会僵住，这是生理反应，不是你的错，也**不影响行为的性质**。

### 3.2 24 小时内

**趁记忆清晰，写下来。** 用文档或纸，写这五项：

```
时间（精确到分钟，越准越好）
地点（具体到房间号、座位、路段）
在场人（姓名，有没有其他人看到）
对方说了什么、做了什么（尽量用原话）
你的反应（说了什么、有没有离开）
```

### 3.3 证据保留

| 证据 | 怎么留 | 注意 |
| --- | --- | --- |
| **聊天记录** | 截图 + 不删原始记录 | 带时间、昵称、完整上下文 |
| **录音** | 你是对话一方时的录音 | 不要剪辑；不要诱导 |
| **监控** | **尽快**向保卫处/物业申请调取 | 监控通常只保存有限天数，**这是最紧急的一件事** |
| **衣物** | 涉及肢体侵犯，不要清洗，装袋保存 | 需要时报警由警方提取 |
| **证人** | 记下姓名和联系方式 | 提前确认对方意愿 |
| **就医记录** | 24 小时内去医院检查，留存病历 | 即使没有明显伤痕也建议去 |

**关于监控**：这是最容易失去的证据。多数校园监控保存期有限（常见为数天到数周），**越早申请越好**【待核实】具体保存期限以本校保卫处为准。

### 3.4 医疗与心理

- **身体检查**：校医院或正规医院妇科/外科，说明情况，要求出具记录
- **紧急避孕与性病预防**：如果发生了性侵，尽快就医，**越早越好**（详见 07-09）
- **心理支持**：校心理咨询中心（多数免费）或 12356（见 07-03）

## 四、举报渠道：可以并行，不必二选一

| 渠道 | 适用情形 | 特点 |
| --- | --- | --- |
| **学校学生工作部门** | 学生之间的骚扰 | 处理快，可要求保密 |
| **学校师德监督/纪检部门** | 涉及教师 | 有专门处理规定，见 06-03 |
| **学校保卫处** | 需要调监控、控制现场 | 有权调取校内监控 |
| **公安（110）** | 涉及肢体侵犯、偷拍传播、威胁 | 会留下正式记录 |
| **妇联 12338** | 妇女权益受侵害，提供咨询与协助 | 不收费，可提供法律指引 |
| **12345** | 学校不作为 | 转教育主管部门督办 |
| **实习单位 HR/工会** | 实习期间 | 另可向劳动监察部门反映 |

### 4.1 向学校举报怎么说

不要写「我要举报性骚扰」这种大词，先陈述事实：

> 「我反映 2026 年 10 月 8 日至 10 月 20 日期间，XX 学院 XX 老师/同学对我实施的以下行为。我有聊天记录、事件记录和一位证人。我请求学校依《民法典》第一千零一十条第二款和本校规定受理，并在调查期间对我的身份保密。」

三个关键词：**具体时间**、**有证据**、**要求书面答复**。

### 4.2 要求保密，以及保密的边界

你可以要求学校在调查期间不公开你的身份。但要注意：

- 调查必然要告知被举报人**具体指控内容**，否则无法申辩
- 完全匿名通常不可能
- 你可以要求**不公开向同学、不写进班级通知**

**保密不是「什么都不说」**，而是「知情范围最小化」。这个预期要提前建立，否则容易觉得被背叛。

### 4.3 学校不处理怎么办

《民法典》第一千零一十条第二款规定学校「应当」采取措施。学校不作为时：

1. 书面向学校提交，要求**书面答复**（这是关键一步，口头沟通无法追责）
2. 向省级教育行政部门反映
3. 拨打 12345
4. 涉及教师且学校不处理，可向纪检监察部门反映

## 五、法律上能追究什么

分三档，可以同时进行：

| 层级 | 依据 | 可能结果 |
| --- | --- | --- |
| **民事** | 《民法典》第一千零一十条、人格权编 | 停止侵害、赔礼道歉、赔偿损失 |
| **治安** | 《治安管理处罚法》关于猥亵他人、偷窥偷拍散布隐私、侮辱的规定 | 拘留、罚款【待核实】具体条项 |
| **刑事** | 强制猥亵、侮辱罪；强奸罪 | 依《刑法》相关条款 |

需要说明：**民事和治安不冲突**。可以一边要求学校处理，一边报警，一边保留起诉的权利。

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「是不是我太敏感了」 | 判断标准是**你的意愿**，不是对方的意图。你觉得被冒犯并表达了，就成立 |
| 「说出去名声不好」 | 名誉受损的是实施者。而且学校有保密义务，你可以要求控制知情范围 |
| 「没有监控就没有证据」 | 聊天记录、录音、证人、事件记录、就医记录，组合起来同样有效 |
| 「我当时没反抗，说明我同意」 | 僵住是应激反应。**沉默和僵住都不是同意** |
| 「私下和解算了，别闹大」 | 可以和解，但要清楚代价：可能失去追责窗口、可能再次发生。和解前建议先咨询 |
| 「他是老师/领导，我告不赢」 | 师德失范有专门处理规定，且权力关系本身是加重情节，不是免责理由 |
| 「过了很久了，没用了」 | 民事索赔有诉讼时效，治安和刑事有追诉期限，但**校内举报通常无严格时效**。先举报，时效问题交给专业判断 |
| 「举报了会被报复」 | 报复行为本身构成新的违纪/违法事实。可要求学校采取保护措施 |

## 七、如果你是朋友，你能做什么

| 该做 | 不该做 |
| --- | --- |
| 相信他/她，第一句话是「这不是你的错」 | 追问细节（「你当时穿什么」「你为什么不跑」） |
| 问「你希望我做什么」，而不是替他决定 | 擅自替他举报或发到网上 |
| 陪他去就医、报警、找辅导员 | 劝他「算了，别影响前途」 |
| 帮他记下时间线（当事人往往记不清） | 承诺「我绝对不告诉任何人」（涉及安全时做不到） |
| 提醒他尽快调监控 | 自己去找对方「理论」 |

**关于「不要替他发到网上」**：公开传播可能让他从受害者变成被围观的对象，也可能涉及侵犯对方名誉权（见 06-09）。是否公开，是当事人的权利。

## 八、可执行清单

### 如果刚刚发生

- [ ] 离开现场，去有人的地方
- [ ] 给一个信任的人打电话
- [ ] **当天**向保卫处申请调取监控
- [ ] 把经过写下来（时间、地点、原话）
- [ ] 截图所有相关聊天记录，不要删原始记录
- [ ] 如果涉及肢体侵犯，就医并保留病历，不要清洗衣物

### 本周

- [ ] 查本校《学生手册》中关于性骚扰/师德失范的受理部门
- [ ] 决定举报范围（学校 / 报警 / 两者并行）
- [ ] 预约心理咨询（免费，见 07-03）
- [ ] 把事件的书面材料整理成一份，备份两份

### 举报时

- [ ] 书面提交，不要只口头说
- [ ] 附证据清单（不用附原件，说明有即可）
- [ ] 明确提出**书面答复**的要求
- [ ] 提出保密范围的要求
- [ ] 记下受理人、受理时间、受理编号

### 长期

- [ ] 保留所有材料的副本至少数年
- [ ] 不要在情绪最激烈时做不可逆的决定（如公开指名）
- [ ] 如果需要，咨询律师或法律援助（多数高校有法律援助中心）

## 九、一句话记住

**先留证据，再谈感受——不是说感受不重要，是只有证据能让你的感受被认真对待。**
