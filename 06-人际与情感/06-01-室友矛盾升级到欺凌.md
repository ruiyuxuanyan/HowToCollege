# 室友矛盾升级到欺凌：什么算、怎么取证、找谁

> 一句话概括：忍让换不来和平，证据和渠道才能。

**适用人群**：正在被室友持续针对、但不确定「这算不算过分」的人；已经被孤立、被损坏东西、被群里嘲笑的人；想帮室友但不知道边界在哪的人。

> **政策适用范围**
> - 主要依据：《普通高等学校学生管理规定》（教育部令第 41 号）、《中华人民共和国民法典》人格权编、《中华人民共和国治安管理处罚法》（2025 年修订，2026 年 1 月 1 日起施行）
> - 全国统一 / 地方执行：**上位法与部门规章全国统一；各校学生管理规定、申诉办法由学校自行制定**
> - 核查日期：2026-11-05
> - 重要差异：**校园欺凌的专门治理文件主要面向中小学**，高校没有对应的专门规章（详见第二节）
> - 条文序号说明：治安管理处罚法 2025 年 6 月 27 日修订、**2026 年 1 月 1 日已施行**。修订后条序有调整：**公然侮辱、捏造事实诽谤、威胁他人人身安全、偷窥偷拍窃听散布他人隐私等，现行均规定在第五十条**（2012 年版为第四十二条），罚款上限由 500 元提高到 1000 元。该条分项较多，引用具体项时请核对官方文本
>
> ⏳ 易过时：各校申诉与举报的具体部门名称、流程。

## 一、先分清：这是「矛盾」还是「欺凌」

室友之间有摩擦是常态。真正需要处理的不是「合不来」，而是**力量不对等下的重复伤害**。

判断欺凌，看四个要件是否同时成立：

| 要件 | 什么意思 | 举例 |
| --- | --- | --- |
| **力量不对等** | 一方在人数、体型、经济、话语权、宿舍话语权上明显占优 | 三个人对付一个人；本地生对本省外新生 |
| **重复性** | 不是一次冲突，而是一段时间内反复发生 | 连续几周每天被起外号 |
| **故意伤害** | 目的是让对方难受，不是「没注意」 | 故意把对方的东西藏起来看笑话 |
| **无法有效反抗** | 对方反抗过但无效，或反抗会招致更严重的报复 | 「你敢说出去试试」 |

四项都齐，就不是「相处不好」，而是欺凌。

反过来，只有一两项、且双方力量大致对等，更像人际冲突——处理方式是沟通、换宿舍，而不是举报。

**这个区分很重要**：把普通摩擦当欺凌举报，会被认为小题大做；把欺凌当摩擦忍让，会持续恶化。

## 二、高校没有「校园欺凌」专门规定，那适用什么

这是本文最需要说清的一点，很多网络文章会误导你。

| 文件 | 适用对象 | 对大学生是否适用 |
| --- | --- | --- |
| 《未成年人学校保护规定》（教育部令第 50 号） | 中小学 | **不适用**（大学生多为成年人） |
| 《加强中小学生欺凌综合治理方案》（教督〔2017〕10 号） | 中小学 | **不适用** |
| 《普通高等学校学生管理规定》（教育部令第 41 号） | 高校 | **适用**（但无「欺凌」专章） |
| 《民法典》人格权编 | 全体民事主体 | **适用** |
| 《治安管理处罚法》（2025 年修订，2026-01-01 施行） | 全体 | **适用**，且**新增了学生欺凌条款** |
| **《治安管理处罚法》第六十条** | **学生欺凌** | **适用** |

## 二点五、一个重要变化：新治安法专设了学生欺凌条款

**2026 年 1 月 1 日起施行的新《治安管理处罚法》第六十条规定**：以殴打、侮辱、恐吓等方式实施学生欺凌，违反治安管理的，公安机关应当依法处理。

> 【法规】《中华人民共和国治安管理处罚法》（2025 年 6 月 27 日修订，2026 年 1 月 1 日起施行）第六十条
>
> 【待核实】该条的具体表述与适用细则，请以官方文本全文为准。

**这一条对大学生意味着什么**：

- 过去说「高校没有欺凌专门规定」，指的是**教育部门的规范性文件**主要面向中小学
- 但**治安管理处罚法层面**，现在有了直接针对「学生欺凌」的条款，且适用于全体学生（不限中小学）
- 所以报警时可以直接指出这一点，不必只笼统说「他欺负我」

**报警时可以这样说**：「我要报案，涉及《治安管理处罚法》第六十条规定的学生欺凌行为，具体表现是……（殴打/侮辱/恐吓）。」

结论：**高校处理这类事件，走的是「学生违纪处分 + 民事侵权 + 治安处罚」三条线**，而治安这条线现在有了更直接的依据。

> 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第五十二条列举了学校可以给予开除学籍处分的情形，其中包括触犯国家法律构成刑事犯罪、侵害其他个人或组织合法权益造成严重后果、屡次违反学校规定受到纪律处分经教育不改等。【待核实】具体条项以本校规定为准

所以你向学校反映时，**不要说「我要举报校园欺凌」**——对方会告诉你没有这个制度。要说：

> 「我反映的是同宿舍同学对我实施的持续侵害行为，涉及人身攻击和财物损坏，请求按学生管理规定处理。」

用词不同，受理路径完全不同。

## 三、欺凌在宿舍里长什么样

不是只有打人才算。以下形式在宿舍场景中最常见：

| 形式 | 具体表现 | 是否属于欺凌 |
| --- | --- | --- |
| **言语** | 起侮辱性外号、当众嘲讽外貌/家境/口音、模仿说话 | 反复且针对同一人时成立 |
| **关系** | 拉群不带他、集体不回应、故意在其面前说悄悄话 | 有组织地孤立时成立 |
| **财物** | 故意损坏、藏东西、往床上倒水、拿走生活用品 | 单次即可构成侵权 |
| **作息侵害** | 深夜故意大声外放、开灯、反复开关门 | 持续且警告无效后成立 |
| **网络** | 在班级群/宿舍群嘲笑、P 图传播、剪辑录音 | 一旦传播即扩大 |
| **肢体** | 推搡、拍打头部、堵门 | 直接涉及治安处罚 |

**注意「作息侵害」这一项**：它最容易被当成「生活习惯不同」，但如果是**针对特定人的、持续性的**，就脱离了生活习惯的范畴。判断标准是：其他人是否也被同样对待。如果只针对你，那不是习惯问题。

## 四、取证：没有证据的举报基本无效

这是全文最实用的一节。**很多人不是没被欺负，是说不清。**

### 4.1 五类要留的证据

| 证据类型 | 怎么留 | 关键点 |
| --- | --- | --- |
| **聊天记录** | 截图 + 原始记录不要删 | 截图要带**时间、昵称/微信号、完整上下文**，不要只截一句话 |
| **群聊信息** | 截图 + 导出聊天记录 | 群名、群成员列表也要截，证明传播范围 |
| **录音** | 手机录音 | 你是对话一方时录音，通常可作为证据使用；**不要剪辑** |
| **病历** | 医院就诊记录、诊断证明、伤情照片 | 身体伤害当天就医，拍照要带日期 |
| **证人** | 愿意作证的同学姓名、联系方式 | 提前问对方是否愿意作证，不要替人做主 |

### 4.2 事件日志（最有用的东西）

拿一个文档，每次事件记一行。格式：

```
日期 | 时间 | 地点 | 在场人 | 发生了什么（原话） | 我的反应 | 有无证据
```

示例：

```
2026-10-12 | 23:40 | 6号楼412 | 全宿舍4人 | 张某把我的洗漱用品从阳台扔到楼下，说"手滑" | 我要求道歉，他说"至于吗" | 有照片、有同宿舍李某可作证
```

**为什么这个最重要**：单次事件看起来都是「小事」，一份连续三周、十几次的记录，性质立刻不同。学校处理时最需要的就是这个。

### 4.3 录音的合法性边界

很多人担心「偷录算不算数」。基本规则是：

- 你是**对话的一方**，为了保留证据而录音，一般可以作为证据使用
- 在他人私密空间**秘密安装设备**（如对方不在时的宿舍装摄像头），可能构成侵权甚至违法
- 不要为了取证去**诱导对方说没做过的事**

> 【经验】以上为通行理解，个案认定以司法机关为准。涉及具体诉讼请咨询律师。

### 4.4 不要做的事

- **不要删聊天记录**：删了就没有原始载体，截图的可信度会降
- **不要公开发到网上**：可能反过来构成侵权（见 06-09）
- **不要私下「谈判」并接受口头承诺**：口头承诺没有留痕

## 五、三级举报渠道，逐级走并留痕

### 5.1 第一级：辅导员

**怎么说**：

> 「老师，我需要向您反映一件事，不是暂时的不愉快，是持续的。我有记录，能不能约个时间我当面给您看？我希望这件事先保密处理。」

三个要点：说明**持续性**、表明**有证据**、提出**保密诉求**。

**留痕**：微信或邮件文字沟通；如果当面谈，事后发一条消息确认「刚才向您反映的 XX 情况，麻烦您跟进」，把时间固定下来。

### 5.2 第二级：学院

辅导员不处理，或者处理后无改善，找**学院分管学生工作的副书记/副院长**。

带上：事件日志、证据清单、与辅导员的沟通记录。

**书面提交**，不要只口头说。一份写了时间线的材料，和一段口头抱怨，得到的结果不一样。

### 5.3 第三级：学校学生工作部（处）/ 学生申诉处理委员会

| 渠道 | 管什么 |
| --- | --- |
| 学生工作部（处） | 违纪处分、宿舍调整 |
| 学生申诉处理委员会 | 对处分决定不服 |
| 保卫处 | 涉及人身安全、财物损坏 |
| 心理健康教育中心 | 心理支持（见 07-03） |

> 【待核实】各校机构名称不同，有的叫「学生事务部」「书院」等。查本校《学生手册》或官网「机构设置」。

### 5.4 每一步都要留的东西

| 步骤 | 留什么 |
| --- | --- |
| 找辅导员 | 沟通时间、对方答复（文字） |
| 找学院 | 书面材料的提交记录、回复 |
| 找学工部 | 受理编号或签收记录 |

## 六、学校处理不力，或者已经违法了

### 6.1 学校不作为

| 途径 | 说明 |
| --- | --- |
| **12345** 政务服务便民热线 | 反映高校学生管理问题，会转教育主管部门 |
| **省级教育行政部门** | 高校的学生管理受省级教育部门指导 |
| **校内申诉** | 对处分决定不服，按规定期限提出申诉 |

注意时效：**校内申诉通常有期限**（多数为收到决定书之日起若干日内），过了就丧失机会。查本校规定。

### 6.2 什么时候直接报警

| 情形 | 报警理由 |
| --- | --- |
| 被打、被推倒受伤 | 殴打他人，涉治安处罚 |
| 被威胁人身安全 | 威胁他人人身安全 |
| 财物被故意损坏，金额较大 | 故意毁坏财物 |
| 被偷拍、私密影像被传播 | 散布他人隐私，可能涉刑事 |
| 被长期跟踪、堵截 | 可能涉寻衅滋事 |

> 【法规】《治安管理处罚法》对「公然侮辱他人或者捏造事实诽谤他人」「写恐吓信或者以其他方法威胁他人人身安全」「偷窥、偷拍、窃听、散布他人隐私」等行为规定了拘留、罚款等处罚。2025 年修订版自 2026 年 1 月 1 日起施行，**具体条文序号【待核实】**

报警时带上：事件日志、证据、身份证。派出所会出具**接报案回执**，这张纸一定要拿。

### 6.3 换宿舍

这是最现实的短期解法。多数学校允许申请调宿，理由写「人身安全与正常学习生活受到持续影响」，附证据。

**注意**：换宿舍解决了你，但没有解决问题本身。是否同时举报，取决于你想要什么——想尽快恢复生活就换，想让对方承担责任就举报，两者可以并行。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「忍忍就毕业了」 | 四年是很长的时间。持续的睡眠剥夺和孤立会实打实影响学业和心理健康 |
| 「告老师会被报复」 | 可以要求保密处理；且一旦进入正式流程，报复行为本身就是新的违纪事实，反而对你有利 |
| 「没有监控就没有证据」 | 监控只是证据之一。聊天记录、事件日志、证人、病历，组合起来同样有效 |
| 「我也还嘴了，是不是我也有错」 | 遭受侵害后的反抗不等于互相欺凌。判断看的是力量对比和谁在持续发起 |
| 「学校说这是宿舍矛盾，让我自己协调」 | 这是常见的推诿。要求对方**书面答复处理意见**，是打破推诿最有效的一招 |
| 「举报了会被记入档案」 | 你举报不会；被处分的是对方 |
| 「我发到网上让舆论压学校」 | 可能让你从受害者变成侵权者，见 06-09 |

## 八、可执行清单

### 今天

- [ ] 建一个文档，把**过去发生过的事**按时间补记下来（记不清的写「约」）
- [ ] 检查聊天记录是否完整，截图时确认带时间和昵称
- [ ] 把重要证据备份到云端或另一个设备

### 本周

- [ ] 找一位愿意作证的同学，私下确认意愿（不要替他做决定）
- [ ] 查本校《学生手册》里关于**违纪处分**和**申诉**的条款，记下受理部门和期限
- [ ] 约辅导员面谈，带上事件日志

### 如果两周内没有改善

- [ ] 向学院提交**书面**材料
- [ ] 同时提出调宿申请
- [ ] 开始记录与学校沟通的每一次时间和答复

### 如果涉及人身伤害或威胁

- [ ] 当天就医，留存病历
- [ ] 报警，拿接报案回执
- [ ] 告诉至少一位家人或朋友

### 关于你自己

- [ ] 预约校心理咨询中心（免费，见 07-03）
- [ ] 保留正常的社交和学习节奏，不要让生活只剩这一件事
