# 恋爱期间转账能不能要回

> 一句话概括：给钱时的性质，决定了分手后能不能要回来。

**适用人群**：恋爱期间有过大额转账、代付、送礼的人；分手后对方要求返还的人；正在考虑要不要给对象一笔钱的人。

> **本文性质**
>
> 本文是法律信息整理，**不构成法律意见**。具体个案请咨询执业律师。同类纠纷在不同法院的裁判结果差异较大，本文只讲判断框架，不预测结果。

> **政策适用范围**
> - 主要依据：《中华人民共和国民法典》第六百五十七条（赠与合同定义）、第六百五十八条（任意撤销权）、第六百六十三条（法定撤销权）；《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释（一）》（法释〔2020〕22 号）第五条；《最高人民法院关于审理涉彩礼纠纷案件适用法律若干问题的规定》（**法释〔2024〕1 号**，2024 年 2 月 1 日起施行）

## 一、先记住三种性质，后果完全不同

分手后能不能要回，**不看金额大小，看这笔钱当时的法律性质**。

| 性质 | 通俗说法 | 能不能要回 | 典型情形 |
| --- | --- | --- | --- |
| **一般赠与** | 「我送你的」 | **不能** | 节日红包、生日礼物、日常吃饭看电影、520/1314 这类特殊金额 |
| **借贷** | 「你先借着」 | **能** | 有借条、有「借」「还」的聊天记录、有还款约定 |
| **附条件赠与（彩礼）** | 「为了结婚给的」 | **有条件返还** | 大额转账、金银首饰、购房款，且以结婚为目的 |

**核心逻辑**：赠与一旦完成，钱就是对方的了。想让钱回来，你必须证明它**不是**赠与，或者属于**可以撤销/返还的**赠与。

---

## 二、一般赠与：给了就是要不回来

### 2.1 法律依据

> 第六百五十七条　赠与合同是赠与人将自己的财产无偿给予受赠人，受赠人表示接受赠与的合同。
>
> 【法规】《中华人民共和国民法典》第六百五十七条

> 第六百五十八条　赠与人在赠与财产的权利转移之前可以撤销赠与。
>
> 具有救灾、扶贫、助残等公益、道德义务性质的赠与合同或者经过公证的赠与合同，不适用前款规定。
>
> 【法规】《中华人民共和国民法典》第六百五十八条

**关键点**：钱一旦转过去（权利已转移），就**不能再任意撤销**。这就是为什么日常转账要不回来。

### 2.2 什么会被认定为一般赠与

| 情形 | 通常认定 |
| --- | --- |
| 春节、情人节、生日、纪念日的红包 | 赠与 |
| 「520」「1314」「999」这类特殊金额 | 赠与（金额本身表达了赠与意思） |
| 日常餐饮、电影、打车、旅游支出 | 赠与（共同消费，见 06-05） |
| 衣服、化妆品、手机等礼物 | 赠与 |
| 备注「爱你」「生日快乐」「拿去买点喜欢的」 | 赠与 |
| 小额的、频繁的转账 | 赠与 |

---

## 三、借贷：能要回，但要证明「借」

### 3.1 关键在举证

主张借贷的人（通常是出钱的一方）要证明**双方有借贷合意**。只有转账记录不够——转账记录只能证明「钱给了」，不能证明「是借的」。

| 证据 | 强度 |
| --- | --- |
| **借条**（写明金额、日期、还款时间、双方签字） | 最强 |
| 聊天记录中有「借」「还」「什么时候还」等表述 | 强 |
| 转账备注写「借款」 | 较强 |
| 只有转账记录，没有任何说明 | 弱，可能被认定为赠与 |
| 对方在聊天中承认「我欠你 XX」 | 强 |

### 3.2 实务中最常见的失败原因

> 「我以为转账记录就够了。」

不够。**这是本篇最需要记住的一句话。**

如果你正在借钱给对象，最低成本的做法是：

- 转账时备注写「借款」
- 或者发一条消息：「这 5000 我先转你，你什么时候方便再还。」对方回复「好」——这就形成了借贷合意的证据

不需要写借条，但一定要留下**「这是借的」的文字记录**。

## 四、附条件赠与（彩礼）：三种情形可以要求返还

### 4.1 法律依据

> 第五条　当事人请求返还按照习俗给付的彩礼的，如果查明属于以下情形，人民法院应当予以支持：
>
> （一）双方未办理结婚登记手续；
> （二）双方办理结婚登记手续但确未共同生活；
> （三）婚前给付并导致给付人生活困难。
>
> 适用前款第二项、第三项的规定，应当以双方离婚为条件。
>
> 【法规】《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释（一）》第五条

### 4.2 三种情形对照

| 情形 | 条件 | 备注 |
| --- | --- | --- |
| **未办结婚登记** | 给了彩礼，但没领证 | 最常见的情形 |
| **领证但未共同生活** | 已登记，但没有实际共同生活 | 需以离婚为条件 |
| **给付导致生活困难** | 给彩礼后，给付方生活陷入困难 | 需以离婚为条件，「生活困难」有严格标准 |

### 4.3 学生场景下的现实问题

多数大学生恋爱期间的钱，**既不是彩礼，也不是借贷，而是赠与**。原因：

- 没有「以结婚为目的」的明确表示
- 金额通常不足以被认定为彩礼
- 没有双方家庭的参与（彩礼通常是两个家庭之间的事）

所以，「分手后要回恋爱期间的钱」在学生场景中成功率不高，**除非能证明是借贷**。

### 4.4 什么可能被认定为彩礼

- 双方已见过家长、有明确的结婚计划（有聊天记录、有订婚仪式）
- 金额明显超出日常消费水平
- 给付方是双方父母，而不是本人
- 给付时明确提到「结婚」「彩礼」「聘礼」

【经验】以上为实践中常见的考量因素，具体认定由法院根据证据判断。

## 五、法官看什么：五个判断要素

同一笔钱，不同法院可能判出不同结果。以下是实践中常被考量的因素：

| 要素 | 怎么看 |
| --- | --- |
| **金额** | 是否明显超出双方的经济能力和日常消费水平 |
| **场景** | 节日、生日、纪念日 vs 普通日子；有无特殊含义 |
| **备注与聊天记录** | 「借」「还」vs「爱你」「给你买」 |
| **双方经济状况** | 学生之间的几千元和上班族之间的几千元，意义不同 |
| **给付目的** | 有无提及结婚、共同生活、未来规划 |
| **是否有对价** | 是否以对方的某种行为为条件 |

**注意**：这不是评分表，不存在「满足几项就赢」。法官做的是整体判断。

## 六、已经发生纠纷怎么办

### 6.1 三步走

| 步骤 | 做什么 | 注意 |
| --- | --- | --- |
| **① 协商** | 明确写出你主张的金额、依据、期限 | 全程留文字记录，不要只打电话 |
| **② 调解** | 学校调解、人民调解委员会、社区调解 | 成本低，不破坏关系 |
| **③ 诉讼** | 向被告住所地或合同履行地法院起诉 | 小额诉讼程序成本较低 |

### 6.2 诉讼的现实门槛

| 项目 | 现实情况 |
| --- | --- |
| **举证责任** | 你主张是借贷，你要证明 |
| **时间** | 数月到一年以上 |
| **成本** | 诉讼费按标的额计算，标的额小的费用低；律师费另计 |
| **关系** | 一旦起诉，关系彻底破裂 |
| **执行** | 赢了官司不等于拿到钱，对方无财产则执行困难 |

**结论**：金额不大时，诉讼往往不划算。这也是为什么「事前留证据」比「事后打官司」重要得多。

### 6.3 反过来：被要求返还怎么办

| 对方主张 | 你可以怎么回应 |
| --- | --- |
| 「这是借的」 | 要求对方出示借条或借款合意的证据 |
| 「这是彩礼」 | 主张不符合彩礼特征（无结婚目的、金额不符、无家庭参与） |
| 「你骗了我的钱」 | 这是刑事指控（诈骗），需要公安机关立案，不是民事纠纷 |
| 威胁公开你的隐私 | 这可能构成违法，见 06-09 |

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「有转账记录就能要回」 | 转账记录只证明钱给了，不证明是借的 |
| 「金额大就一定能要回」 | 金额大只是考量因素之一，性质才是决定性的 |
| 「备注写了『借款』就一定赢」 | 备注是重要证据，但对方可以举反证（如聊天记录显示是赠与） |
| 「送给我的就是我的」 | 大额且以结婚为目的的，可能被认定为彩礼 |
| 「分手了就该还」 | 法律上没有「分手即返还」的规则 |
| 「可以告他诈骗」 | 诈骗需要「以非法占有为目的」且达到刑事立案标准，恋爱纠纷通常不构成 |
| 「520、1314 也能要回」 | 这类特殊金额几乎必然被认定为赠与 |
| 「口头说好就行」 | 口头约定难以举证 |

## 八、可执行清单

### 给钱之前

- [ ] 想清楚：这笔钱是送的，还是借的？
- [ ] 如果是借：转账备注写「借款」，或发消息确认还款
- [ ] 如果是送：接受「要不回来」这个结果，再决定给不给
- [ ] 不要给超出自己承受能力的金额
- [ ] 不要为对方借网贷、办信用卡分期（这是最常见的坑，见 04-03）

### 已经给了

- [ ] 整理所有转账记录（银行流水、微信/支付宝账单）
- [ ] 导出相关聊天记录，不要删
- [ ] 标注每一笔的性质（赠与/借贷/可能彩礼）
- [ ] 如果是借贷且对方未还，尽早以文字方式催告（固定「承认债务」的证据）

### 发生纠纷

- [ ] 先文字协商，不要只打电话
- [ ] 保留所有沟通记录
- [ ] 金额较大时咨询律师（多数高校有法律援助中心）
- [ ] 不要在情绪中做不可逆的事（公开对方信息、发到网上）

## 九、一句话记住

**给钱的那一刻，性质就定了——「借」要留字，「送」别后悔。**
