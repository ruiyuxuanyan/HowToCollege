# 校外租房：五查 + 入住当天拍全屋

> 一句话概括：看房前查五件事，签约前改三个条款，入住当天拍全屋照片——这三件事能救回你的押金。

**适用人群**：准备搬出宿舍租房的学生；已经交了定金还没签合同的人；退租时被扣押金、说不出道理的人。

> **本文性质**
>
> 本文是租赁实务信息整理，**不构成法律意见**。重大金额或复杂纠纷请咨询执业律师或当地住建部门。
>
> **政策适用范围**
> - 主要依据：《中华人民共和国民法典》第三编第十四章「租赁合同」；《商品房屋租赁管理办法》（住建部令第 6 号）；《中华人民共和国治安管理处罚法》关于房屋出租登记的规定；各地《居住证》/居住登记相关规定
> - 全国统一 / 地方执行：**租赁合同的法律规则全国统一；租赁备案、居住登记、群租认定、押金监管的具体规定由各城市制定**
> - 核查日期：2026-11-05
> - 已知变化：多地正在推行住房租赁资金监管与租赁合同网签备案
>
> ⏳ 易过时：各城市居住登记要求、群租房认定标准、租赁备案流程。
>
> **重要前提**：**部分高校规定在校生不得校外住宿，或需办理审批手续。** 违反可能受校纪处分。租房前先查本校规定。

## 一、五查：签约前必须核实的五件事

这一节是本文的核心。**任何一项查不清，都不要签。**

### 1.1 第一查：产权

要确认和你签合同的人是不是这套房的合法权利人。看房产证/不动产权证原件（不是照片），核对与身份证是否一致；确认房屋用途写明「住宅」（商业/办公用途不能作住宅出租）；确认是否有共有人（夫妻共有应让共有人也签字或出具同意出租说明）；要求房东在合同中写明"出租人保证其为合法权利人，如因权属争议导致承租人无法使用，承担全部责任"。

**危险信号**：只给看照片、说"证在老家/在办"。

### 1.2 第二查：二房东

**二房东**指整租后再转租的人。转租不违法，但须经出租人同意：

> 承租人经出租人同意，可以将租赁物转租给第三人……承租人未经出租人同意转租的，出租人可以解除合同。
>
> 【法规】《中华人民共和国民法典》第七百一十六条

**这意味着**：大房东没同意转租，**大房东可解除合同，你可能被清退**。

怎么防：看二房东与原房东的租赁合同（确认租期覆盖你的租期）、看原房东同意转租的书面证明、至少电话联系上原房东确认一次。

**危险信号**：不提供与大房东的合同；说"大房东在国外/联系不上"；租金明显低于同地段市价；要求一次性付很长周期并给折扣。

### 1.3 第三查：能不能办居住登记

这一项对大学生特别重要，但几乎所有人都会漏掉。

**为什么重要**：办居住证通常需要先有居住登记（且需连续一定期限）；部分城市办银行卡、考驾照、考试报名、积分落户都要求居住证明；部分学校也要求校外住宿学生报备地址。

**怎么查**：问当地公安派出所/社区事务受理服务中心，确认该房屋能否登记、需什么材料（通常需房东配合提供房产证明）。

**关键点**：**有些房子"不能登记"**——违建、群租房、商业用房改造、产权不清。这类房房租便宜，但你办不了居住登记，后续一系列事都会被卡住。

**签约前必须问房东**："这套房能不能办居住登记？需要我们一起去派出所吗？" **如果对方含糊其辞，直接放弃。**【经验】

### 1.4 第四查：押金条款

押金纠纷是退租时最常见的争议。合同里要写清四件事：押金金额、退还条件（"何种情况可以扣、扣多少"）、退还时限、扣款标准（如"墙面污损按实际修复费用，需提供票据"）。另注明押金是否可抵租金，转账时备注"XX 房屋押金"。

**常见陷阱**：合同只写"押金若干"不写退还条件；写"房屋有损坏即扣押金"却无标准；退租以"需要打扫"扣清洁费；现金支付无凭证（**一律转账**）。

### 1.5 第五查：违约责任

这一节决定你"想走的时候能不能走"。要看：提前退租要提前多久通知、违约金多少、押金退不退；房东能否提前收房、如何赔偿；租期内能否涨租；维修责任谁承担；能否转租；优先承租权怎么约定。

**两条对你有利的法定规则**（但可被合同约定排除）：

> 租赁期限届满，房屋承租人享有以同等条件优先承租的权利。
>
> 【法规】《民法典》第七百三十四条第二款

> 出租人应当履行租赁物的维修义务，但是当事人另有约定的除外。
>
> 【法规】《民法典》第七百一十二条

**注意"当事人另有约定的除外"**：合同可以把维修责任推给你。**签字前看清楚这一条。**

## 二、入住当天：拍全屋照片（最重要的一步）

### 2.1 为什么必须做

退租时最常见的争议是"这个损坏是你弄的"。房东说是你弄坏的 → 扣押金；你说是原来就有的 → 但你证明不了。**举证不能的一方吃亏，通常是租客。**

### 2.2 怎么拍

**原则**：在房东在场时拍，拍完当场发给房东，形成时间戳。

必拍：入户门与门牌号（证明是这套房）、每个房间四角 + 门口全景、墙面（污渍/裂缝/钉孔/发霉）、地面（划痕/破损）、天花板（水渍）、门窗与锁具、每件家具全貌 + 瑕疵特写、家电外观 + 铭牌 + **通电测试**、厨卫水槽下水马桶瓷砖缝、水电气表读数、逐个测插座、清点钥匙门禁卡。

### 2.3 视频比照片更强，且必须当场发给房东

拍一段完整视频：从进门按固定路线走一圈，边走边口述时间、地点、双方在场，逐处指出已有瑕疵。视频无法事后剪辑替换，且自带时间与语境。

拍完立刻把原图（不压缩）微信发给房东，附一句"这是今天的验房照片和视频，确认房屋现状，有问题现在说"。房东回复"没问题"或"收到"，就是双方确认的书面记录；不回就截图留证。

### 2.5 配套：做一份《房屋交接清单》

```markdown
# 房屋交接清单
地址：________ 交接日期：__年__月__日 出租人：____ 承租人：____
一、水电气读数：水表__ 电表__ 燃气表__
二、钥匙/门禁：入户钥匙__把；单元门禁__张；其他__

三、家电清单与状态
| 物品 | 数量 | 品牌型号 | 状态 | 备注 |
| --- | --- | --- | --- | --- |
| （空调/冰箱/洗衣机/热水器/燃气灶等逐项填） |  |  |  |  |

四、家具与墙面/地面已知瑕疵：__________________
五、其他约定：______________________________

出租人签字：____ 承租人签字：____
（附：验房照片/视频，已于当日通过微信发送并确认）
```

## 三、合同怎么改：三个必改条款

多数中介/房东用模板合同。以下三条，能改就改。

### 3.1 改「维修责任」

**模板常见写法**："房屋内一切设施损坏由承租人负责维修。"

**问题**：热水器老化爆炸、水管爆裂、墙体漏水，都要你赔。

**改成**：

> 房屋主体结构、原有管线、原有家电因自然老化或质量问题发生的故障，由出租人负责维修并承担费用；因承租人使用不当造成的损坏，由承租人负责。出租人应在接到通知后 __ 日内维修，逾期未修的，承租人可自行维修并从租金中扣除费用。

### 3.2 改「押金退还」

**模板常见写法**："退租时视房屋情况退还押金。"

**改成**：

> 租赁期满或合同解除，承租人结清费用并交还房屋后，出租人应在 __ 日内退还押金。除承租人欠缴租金、费用或造成房屋/设施损坏（自然损耗除外）外，出租人不得扣减押金。扣减部分应提供明细及票据。

### 3.3 改「提前退租」

**模板常见写法**："提前退租押金不退。"

**改成**：

> 承租人提前 __ 日书面通知出租人可解除合同，支付相当于 __ 个月租金的违约金；已付未住期间的租金应予退还。

**谈判技巧**：房东最在意的是"房子不要空着"。主动提出"我帮你找下一个租客"，比单纯要求降低违约金更容易谈成。【经验】

## 四、其他必须确认的事项

| 事项 | 要问清 |
| --- | --- |
| 租金支付方式 | 转账给谁？备注写什么？包含哪些费用（物业、取暖、网费）？ |
| 水电燃气单价 | 是民用价还是商用价？（商用贵很多） |
| 合租情况 | 公共区域怎么分摊、室友是谁 |
| 使用限制 | 是否允许做饭、养宠物 |
| 房屋状况 | 能否办居住登记（见 1.3）、是否被抵押查封（见 1.1）、是否群租房 |
| 消防 | 有无烟感、灭火器、逃生通道是否畅通 |
| 学校规定 | **查本校是否允许校外住宿、是否需审批** |

**付款周期**："押 X 付 X"是常见表述，具体金额由市场与协商决定，本文不给数字。首次租房尽量选较短的付款周期，降低"付半年房东跑路"的风险。

## 五、常见误区

| 误区 | 实际 |
| --- | --- |
| 「看了房产证照片就行」 | 要看原件并核对身份证 |
| 「二房东也是房东」 | 未经原房东同意的转租，原房东可解除合同 |
| 「便宜就行，居住登记无所谓」 | 办不了登记会影响居住证、考试报名等 |
| 「押金现金给，房东人很好」 | 一律转账留痕 |
| 「合同是模板，改不了」 | 大部分条款可手写补充并双方签字 |
| 「入住时房子就这样，不用拍」 | 退租时你说不清 |
| 「群租房便宜划算」 | 消防隐患大，可能被清理，且难办登记 |

## 可执行清单

**看房 / 签约**
- [ ] 查本校是否允许校外住宿、需不需要审批
- [ ] 核对房产证原件与房东身份证，确认房屋用途为住宅
- [ ] 如为二房东，看原租赁合同 + 原房东同意转租的证明
- [ ] 问清能否办居住登记、水电燃气是民用价还是商用价
- [ ] 检查烟感、灭火器、逃生通道
- [ ] 逐条读合同，重点改押金、维修、提前退租三条
- [ ] 手写修改处双方签字，索取房东身份证与房产证复印件

**入住当天**
- [ ] 拍全屋照片（每间四角 + 全景）与完整验房视频
- [ ] 拍水电气表读数，测试所有家电并录像
- [ ] 清点钥匙/门禁卡，填写《房屋交接清单》双方签字
- [ ] **当日把照片视频发给房东并让其回复确认**

**租住 / 退租**
- [ ] 每月保存租金转账记录（备注用途），报修留文字记录
- [ ] 不擅自改造房屋结构，按期办理居住登记续期
- [ ] 提前按合同约定通知，退租时同样拍全屋照片视频
- [ ] 结清水电气费用并留凭证，要求书面确认押金退还时间

## 一句话记住

**五查（产权、二房东、居住登记、押金条款、违约责任）+ 入住当天拍全屋发给房东——这两件事做了，90% 的押金纠纷不会发生在你身上。**
