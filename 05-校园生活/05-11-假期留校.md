# 假期留校：审批、住宿、吃饭、安全

> 一句话概括：留校不是"不想回家就不回"，而是一次需要提前申请的住宿变更。

**适用人群**：寒假/暑假需要留校的人（实习、考研、科研、竞赛、打工）；家在外地但假期不想回去的人；第一次留校不知道怎么办的人。

> **政策适用范围**
> - 主要依据：教育部《普通高等学校学生管理规定》（教育部令第 41 号）关于学生住宿管理的规定；各校《学生宿舍管理规定》《假期留校学生管理办法》
> - 全国统一 / 地方执行：**国家层面仅作原则规定；假期是否允许留校、审批条件、集中住宿安排、收费标准完全由各校规定**
> - 核查日期：2026-11-07
> - 已知变化：各校假期管理办法每年可能调整
>
> ⏳ 易过时：本校留校申请时间、集中住宿楼栋、假期食堂开放安排。

---

## 一、先明确：留校需要批准

很多人以为"我交了住宿费，假期当然能住"。**不是这样。**

| 事实 | 说明 |
| --- | --- |
| 假期宿舍楼通常**封闭或合并** | 为节省管理成本，会集中住宿 |
| 留校需要**申请并获批** | 未经批准留宿，可能按违纪处理 |
| 部分学校**原则上不鼓励留校** | 尤其寒假（春节） |
| 留校可能有**额外费用** | 部分学校收取假期住宿费 |

**所以第一件事不是打包行李，是查本校通知。**

---

## 二、什么理由会被批准

各校标准不同，但通过率有明显梯度。

### 2.1 通常容易批准

| 理由 | 需要什么证明 |
| --- | --- |
| 参加学校组织的实习/实践 | 实习证明、指导教师确认 |
| 考研/考公备考 | 部分学校要求报名确认或辅导班证明 |
| 参与科研项目/实验室工作 | 导师签字确认 |
| 参加学科竞赛集训 | 竞赛通知、指导教师确认 |
| 补考/重修/小学期课程 | 教务系统记录 |
| 家在外地且路途遥远、往返成本过高 | 部分学校会考虑（需说明） |
| 家庭特殊困难 | 相关说明材料 |

### 2.2 通常不容易批准

| 理由 | 为什么 |
| --- | --- |
| 「我想在学校玩」 | 不构成理由 |
| 「我在这边打工」 | 部分学校不认，需看具体规定 |
| 「回家没意思」 | 不构成理由 |
| 「我朋友留校」 | 不构成理由 |
| 「我懒得搬行李」 | 不构成理由 |

**注意**：**"打工"这一项各校态度差异很大。** 有的学校认可（视为社会实践），有的学校不认可。**以本校规定为准。**【待核实：本校对"假期打工"作为留校理由的认定，请查学生工作部通知】

### 2.3 提高通过率的做法

| 做法 | 效果 |
| --- | --- |
| 提供书面证明（导师签字、单位盖章） | 显著提高 |
| 说明具体时间段 | 提高 |
| 说明住宿需求（是否需要集中住宿） | 提高 |
| 提前申请（不要卡在截止日期） | 提高 |
| 承诺遵守假期管理规定 | 提高 |

## 三、时间线：什么时候做什么

**核心原则：留校申请通常有明确截止日期，错过就没有补救机会。**

### 3.1 一般时间线（以学期末为参照）

| 时点 | 做什么 |
| --- | --- |
| **放假前 4–6 周** | 关注学生工作部/宿管中心/辅导员通知 |
| **放假前 4 周** | 确认申请条件、准备证明材料 |
| **放假前 3 周** | 提交申请 |
| **放假前 2 周** | 等待审批，跟进进度 |
| **放假前 1 周** | 确认获批、知道集中住宿楼栋 |
| **放假前 3 天** | 搬迁至集中住宿楼栋（如需） |
| **放假当天** | 原宿舍封楼，未获批者须离校 |

**不同学校时间差别很大。必须查本校通知。**【待核实：本校留校申请的具体起止时间】

### 3.2 通知去哪找

| 渠道 | 说明 |
| --- | --- |
| 辅导员/班级群 | 最直接的渠道 |
| 学生工作部（处）网站 | 正式通知 |
| 宿舍管理中心/后勤处 | 住宿安排 |
| 学校官方微信公众号 | 常同步发布 |
| 学院官网/公众号 | 院系层面通知 |

## 四、住宿：集中住宿是常态

### 4.1 常见的三种安排

| 模式 | 说明 |
| --- | --- |
| **集中住宿** | 所有留校学生集中到指定的几栋楼/几层 |
| **原楼封闭、指定楼开放** | 未获批不得进入原楼 |
| **原宿舍保留** | 少数学校，或仅对研究生/特定群体 |

**集中住宿的常见特点**：

- 可能与不认识的人同住
- 需要搬行李
- 热水、网络、空调等条件可能与原宿舍不同
- 门禁时间可能更严格

### 4.2 搬迁注意事项

| 事项 | 建议 |
| --- | --- |
| 贵重物品 | **全部带走或锁好**，不要留在封闭楼栋 |
| 证件 | 随身携带 |
| 电器 | 拔掉插头，收好 |
| 食物 | 清理干净（否则开学有异味/虫） |
| 被褥 | 卷起或装袋防尘 |
| 门窗 | 关好、锁好 |

**重要提醒**：**假期封闭的宿舍楼仍可能有人进入（维修、检查）。贵重物品不要留在原宿舍。**【经验】

### 4.3 假期住宿费

部分学校收取假期住宿费，部分不收取。

**本文不写金额。** 查本校通知或问宿管。【待核实：本校假期住宿是否收费及标准】

## 五、吃饭：这是留校最实际的问题

假期食堂大面积关闭，是留校生活最大的落差。

### 5.1 假期餐饮的常见情况

| 类型 | 情况 |
| --- | --- |
| 学生食堂 | **多数关闭或仅保留 1–2 个窗口** |
| 教工食堂 | 可能开放，但价格不同 |
| 校内便利店/超市 | 通常开放（可能缩短营业时间） |
| 校外餐饮 | 部分店铺假期歇业（尤其春节） |
| 外卖 | 部分骑手返乡，配送变慢或加价 |

### 5.2 应对方案

| 方案 | 说明 |
| --- | --- |
| 提前查假期食堂开放安排 | 学生工作部/后勤处通常提前公告 |
| 确认开放窗口的营业时间 | 可能只有午餐/晚餐 |
| 备一些应急食品 | 泡面、面包、饼干（注意保质期） |
| 确认周边超市营业时间 | 尤其春节前后 |
| 学会用宿舍楼的开水/微波炉 | 部分楼有公共加热设施 |

### 5.3 春节期间的特别提示

如果寒假留校跨春节：

| 问题 | 建议 |
| --- | --- |
| 食堂几乎全关 | 提前储备，或确认学校是否安排年夜饭 |
| 周边店铺歇业 | 提前采购 |
| 快递停运 | 提前买好东西 |
| 宿舍楼人很少 | 安全问题更需注意 |
| 情绪低落 | 这很常见，主动联系家人朋友 |

**部分学校会为留校学生安排除夕活动或发放慰问品。** 关注学校通知，也可以主动问辅导员。【经验】

## 六、安全：人少的时候风险更高

留校期间宿舍楼人少、管理力量减弱，安全风险结构会变化。

### 6.1 主要风险

| 风险 | 说明 |
| --- | --- |
| **盗窃** | 人少、楼内陌生面孔易辨识但难核实 |
| **消防** | 违规用电（冬季取暖需求大）、电动车电池 |
| **人身安全** | 独自在楼、夜间出行 |
| **心理** | 孤独、与家人分离、备考压力 |
| **诈骗** | 假期兼职骗局、冒充学校通知 |

### 6.2 具体做法

| 场景 | 做法 |
| --- | --- |
| 住宿 | 只住获批的集中楼栋，不留宿他人，不留宿校外人员 |
| 用电 | 严格遵守宿舍用电规定（见 05-04、05-05）；**冬季尤其不要用违规取暖设备** |
| 门禁 | 遵守假期门禁时间，晚归提前报备 |
| 外出 | 告知室友/家人行程，夜间不单独去偏僻处 |
| 陌生人 | 不轻易让陌生人进楼；发现可疑人员报告宿管/保卫处 |
| 财物 | 贵重物品随身或锁好 |
| 快递 | 及时取，不要长时间堆在门口 |

### 6.3 紧急联系

| 情况 | 联系 |
| --- | --- |
| 火警 | 119 |
| 报警 | 110 |
| 急救 | 120 |
| 校内安全 | 保卫处值班电话（**提前存到手机**） |
| 宿舍问题 | 宿管值班室 |
| 心理支持 | 学校心理咨询中心（假期可能有值班安排，需提前确认） |

**建议**：留校第一件事，把保卫处、宿管、辅导员、校医院电话存进手机。**人少的时候，找到人是关键。**【经验】

### 6.4 心理上的准备

留校容易出现的状况：

| 状况 | 应对 |
| --- | --- |
| 孤独（尤其春节） | 主动约同样留校的同学；定期与家人视频 |
| 作息紊乱 | 保持固定作息，别把假期过成"熬夜—补觉"循环 |
| 备考焦虑 | 制定可执行的日计划；不要用"每天学 12 小时"自我惩罚 |
| 想放弃 | 联系心理咨询中心或朋友 |

**如果你感到持续的低落、失眠、无意义感，这不是"意志力问题"。** 见「心理危机求助」（07-03）。

## 七、假期在校的其他实务

### 7.1 图书馆与自习室

| 情况 | 说明 |
| --- | --- |
| 开放时间缩短 | 常见 |
| 只开部分楼层/区域 | 常见 |
| 可能需要预约 | 部分学校 |
| 网络与数据库 | 校园网可能正常，校外访问需 VPN |

**备考的人必须提前确认自习地点。** 宿舍不是好的学习环境。【经验】

### 7.2 校园网与水电

| 项目 | 可能的变化 |
| --- | --- |
| 校园网 | 可能正常，也可能因楼栋封闭断网 |
| 热水供应 | 可能限时或停止 |
| 空调/暖气 | 视学校与地区 |
| 洗衣房 | 部分关闭 |

### 7.3 快递与外卖

| 情况 | 说明 |
| --- | --- |
| 快递点 | 可能缩短营业时间或关闭部分网点 |
| 外卖配送 | 可能变慢、起送价提高 |
| 大件快递 | 提前确认能否送达 |

### 7.4 校内办事

| 事项 | 说明 |
| --- | --- |
| 教务处/学生处 | 假期通常有值班，但业务受限 |
| 证明开具 | 尽量在放假前办完 |
| 档案/证明类 | 假期办理周期更长 |

**原则**：**能在放假前办的事，不要留到假期办。**【经验】

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「交了住宿费就能住假期」 | 需申请获批，且常需集中住宿 |
| 「不申请也没人查」 | 假期有查寝，未获批可能按违纪处理 |
| 「留校可以住原宿舍」 | 多数学校要求搬至集中楼栋 |
| 「食堂总有开着的」 | 假期可能只保留极少数窗口 |
| 「留校很自由」 | 门禁、用电、住宿管理往往更严格 |
| 「东西放宿舍没事」 | 封闭楼栋仍可能有人进入 |
| 「春节留校没人管」 | 部分学校有慰问安排，主动问 |
| 「留校就是学习」 | 孤独与作息紊乱是真实挑战 |

## 可执行清单

### 申请前（放假前 4-6 周）

- [ ] 查本校假期留校管理办法与申请通知
- [ ] 确认自己的理由是否在受理范围
- [ ] 准备证明材料（导师签字/单位盖章/报名确认）
- [ ] 确认是否需要缴纳假期住宿费
- [ ] 确认集中住宿的楼栋与搬迁时间

### 申请

- [ ] 在截止日期前提交
- [ ] 主动跟进审批进度
- [ ] 拿到书面/系统内的获批记录

### 搬迁前

- [ ] 贵重物品全部带走或锁好
- [ ] 清理食物、拔掉电器插头
- [ ] 关好门窗
- [ ] 记录水电气表读数（如涉及）

### 留校期间

- [ ] 存好保卫处、宿管、辅导员、校医院电话
- [ ] 确认食堂开放窗口与时间
- [ ] 确认自习地点
- [ ] 遵守门禁与用电规定
- [ ] 告知家人/室友行程
- [ ] 保持固定作息
- [ ] 主动联系同样留校的同学

### 返校前

- [ ] 确认原宿舍开放时间
- [ ] 搬回原宿舍
- [ ] 检查物品有无丢失

## 一句话记住

**假期留校要先申请获批、多数要搬到集中楼栋、食堂会关掉大半；放假前把能办的事办完，贵重物品别留在封闭的楼里。**
