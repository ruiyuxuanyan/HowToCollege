# 校园里的「担保」：帮同学贷款、做担保人

> 一句话概括：签字的那一刻，你的钱就不是你的钱了。

**适用人群**：被同学、学长、亲戚请去「签个字」的大学生；准备帮人做网贷担保的人；在借条上签过名、不确定自己签了什么的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国民法典》第三编合同编第十三章「保证合同」（第六百八十一条至第七百零二条）
> - 全国统一：民法典在全国范围内统一适用
> - 核查日期：2026-11-05
> - 已知变化：**《民法典》对保证方式的推定规则与旧《担保法》相反**。旧法推定「连带责任保证」，民法典推定为「一般保证」。这一点是本篇的核心，见第三节
>
> ⏳ 易过时：无（民法典短期内不会修改此部分）；但各地法院对「保证意思表示是否成立」的认定有差异。

## 一、先把三个词分开

日常说话混着用，法律上是三件完全不同的事。

| 身份 | 你承诺了什么 | 对方不还钱时 |
| --- | --- | --- |
| **见证人** | 我证明这份合同是他们签的 | **你不用还钱** |
| **保证人（担保人）** | 他不还，我负责 | **你要还钱** |
| **共同借款人** | 我和你一起借这笔钱 | **你本来就是债务人** |

**这三个身份的差别不是「程度」，是「性质」。**

- 见证人：只是证人
- 保证人：从债务人（第二责任人）
- 共同借款人：主债务人（第一责任人）

**最危险的误签**：本意是当见证人，签在了「保证人」栏。或者是本意当保证人，却签在了「借款人」栏——后者更重。

## 二、什么是保证合同

> 第六百八十一条　保证合同是为保障债权的实现，保证人和债权人约定，当债务人不履行到期债务或者发生当事人约定的情形时，保证人履行债务或者承担责任的合同。
>
> 【法规】《中华人民共和国民法典》第六百八十一条

拆开看：

| 要素 | 意思 |
| --- | --- |
| 三方 | 债权人（出借人）、债务人（借款人）、保证人（你） |
| 你向谁承诺 | **向债权人**承诺，不是向借款人 |
| 你承诺什么 | 债务人不履行时，你履行 |
| 你的地位 | 从债务人 |

**最关键的一句话：你签保证合同，是跟「出借人」签的，不是跟「同学」签的。**

这意味着：同学说「放心，我肯定还」——这句话对出借人没有任何约束力。你对他做的承诺，和你对债权人的法律责任，是两回事。

## 三、核心：两种保证方式，差别巨大

这是本文最重要的一节。**也是《民法典》相对旧法变化最大的地方。**

### 3.1 法条

> 第六百八十六条　保证的方式包括一般保证和连带责任保证。
>
> 当事人在保证合同中对保证方式没有约定或者约定不明确的，按照一般保证承担保证责任。
>
> 【法规】《中华人民共和国民法典》第六百八十六条

### 3.2 一般保证

> 第六百八十七条　当事人在保证合同中约定，债务人不能履行债务时，由保证人承担保证责任的，为一般保证。
>
> 一般保证的保证人在主合同纠纷未经审判或者仲裁，并就债务人财产依法强制执行仍不能履行债务前，有权拒绝向债权人承担保证责任，但是有下列情形之一的除外：
>
> （一）债务人下落不明，且无财产可供执行；
> （二）人民法院已经受理债务人破产案件；
> （三）债权人有证据证明债务人的财产不足以履行全部债务或者丧失履行债务能力；
> （四）保证人书面表示放弃本款规定的权利。
>
> 【法规】《中华人民共和国民法典》第六百八十七条

**「先诉抗辩权」是什么**：债权人必须**先**去起诉/仲裁债务人，**并且**申请强制执行，**执行不到**，才能来找你。

这对保证人是重要的保护：你不是第一顺位。

### 3.3 连带责任保证

> 第六百八十八条　当事人在保证合同中约定保证人和债务人对债务承担连带责任的，为连带责任保证。
>
> 连带责任保证的债务人不履行到期债务或者发生当事人约定的情形时，债权人可以请求债务人履行债务，也可以请求保证人在其保证范围内承担保证责任。
>
> 【法规】《中华人民共和国民法典》第六百八十八条

**注意第二款**：「可以请求债务人履行，**也可以**请求保证人承担」。

也就是说：**债权人可以不找借款人，直接找你。**

### 3.4 一张表看清差别

| | 一般保证 | 连带责任保证 |
| --- | --- | --- |
| 债权人能否直接找你 | **不能**（要先诉债务人并执行） | **能**，随时 |
| 你有没有先诉抗辩权 | **有** | 没有 |
| 诉讼中的地位 | 通常列为共同被告，但责任有先后 | 可直接单独起诉你 |
| 实际风险 | 较低（前面有一道程序） | **高** |
| 推定规则（无约定时） | **民法典推定为一般保证** | 需明确约定 |

### 3.5 民法典的变化，必须写清楚

这一点很容易搞错，因为很多旧资料还在用旧规则：

| | 旧《担保法》（1995 年） | 现行《民法典》（2021 年施行） |
| --- | --- | --- |
| 没有约定或约定不明时 | 推定为**连带责任保证** | 推定为**一般保证** |

**依据**：《民法典》第六百八十六条第二款。旧《担保法》第十九条规定的是「按照连带责任保证承担保证责任」，民法典改了方向。

**这个变化的意义**：

- 好消息：如果你签的合同没写清楚是哪种保证，按**一般保证**处理，你多了一道「先诉抗辩权」
- 但不能依赖它：实务中，债权人拟的合同几乎都会明确写「连带责任保证」
- 而且：这个推定只解决「约定不明」的情况，解决不了「你到底是不是保证人」的问题

**所以不要因为「反正推定为一般保证」就随便签。**正确的态度是：**看清楚合同里到底写了什么。**

> **【待核实】** 对 2021 年 1 月 1 日之前成立的保证合同，适用当时的《担保法》；之后的适用《民法典》。这个时间界限涉及法律适用的溯及力问题，具体案件需律师判断。

## 四、担保属于哪一类责任

这一篇几乎全部是**民事**问题。但三种责任要分清，因为你会听到各种说法。

| 层次 | 是否涉及 | 具体表现 |
| --- | --- | --- |
| **民事** | **本篇主线** | 代为清偿、被起诉、财产被执行、追偿 |
| **行政** | 通常不涉及 | 担保本身不产生行政处罚 |
| **刑事** | 一般场景不涉及 | 但围绕担保的欺诈行为例外，见下表 |

**可能触及刑事的，不是「担保」本身，而是围绕担保的欺诈行为：**

| 行为 | 大致方向 |
| --- | --- |
| 伪造他人签名做担保 | 可能涉及伪造私文书、合同诈骗 |
| 用虚假材料骗取贷款并让他人担保 | 骗取贷款类犯罪 |
| 以「担保为名」收取保证金、手续费后失联 | 诈骗类犯罪 |
| 明知无力偿还仍举债并诱使他人担保 | 可能涉及合同诈骗 |

> 第二百二十四条　有下列情形之一，以非法占有为目的，在签订、履行合同过程中，骗取对方当事人财物，数额较大的，处三年以下有期徒刑或者拘役，并处或者单处罚金；数额巨大或者有其他严重情节的，处三年以上十年以下有期徒刑，并处罚金；数额特别巨大或者有其他特别严重情节的，处十年以上有期徒刑或者无期徒刑，并处罚金或者没收财产：
>
> （一）以虚构的单位或者冒用他人名义签订合同的；
> ……
>
> 【法规】《中华人民共和国刑法》第二百二十四条（合同诈骗罪）

**这一节的实际意义**：如果有人用「担保是民事问题，不犯法」来劝你签，这句话本身没错——**但对你不利的部分恰恰全在民事里**。担保的风险不需要构成犯罪，就足以让你赔光。

## 五、担保人要承担什么

不是「帮忙说句话」，是实实在在的财产责任。

| 后果 | 具体表现 |
| --- | --- |
| **代为清偿** | 借款人不还，你要还。包括本金、利息、违约金、实现债权的费用 |
| 被起诉 | 债权人可以直接起诉你（连带责任保证下） |
| 财产被执行 | 判决生效后，你的存款、工资、财产可能被强制执行 |
| **上失信名单** | 不履行生效判决，可能被限制高消费、列入失信被执行人名单 |
| 影响征信 | 部分情形下，担保记录会体现在征信报告中 |
| 影响就业 | 失信记录、被执行记录会影响考公、参军、部分行业入职 |
| 诉讼成本 | 你要自己花钱请律师应诉 |

**关于「实现债权的费用」**：很多保证合同会写「保证范围包括主债权、利息、违约金、损害赔偿金和实现债权的费用」。这意味着对方请律师的钱也可能算在你头上。

**关于「影响征信」这一点要谨慎表述**：担保信息是否上征信、如何体现，取决于具体的信贷类型和征信规则，属于【待核实】事项。但「被判决承担保证责任后不履行会被执行」这一点是确定的。

## 六、校园里的四种典型场景

### 场景一：同学网贷，让你做担保人

**对方会说**：「就是走个流程，我肯定按时还，不会连累你。」

**实际是什么**：

- 网贷平台的合同通常是**格式合同**，保证条款写得对平台极有利
- 多数会明确写成「连带责任保证」
- 平台在你同学逾期后，可能**直接找你**，甚至直接联系你的家人、学校
- 金额往往不小（几千到几万），对学生是重大负担

**判断要点**：

| 问题 | 为什么关键 |
| --- | --- |
| 合同里写的是「一般保证」还是「连带责任保证」？ | 决定对方能不能直接找你 |
| 保证范围包含什么？ | 可能远超你以为的「本金」 |
| 保证期间是多长？ | 决定你要担心多久 |
| 平台有没有放贷资质？ | 非法放贷的合同效力可能有问题 |

### 场景二：亲戚借钱，让你签字

**这一类的特点是**：拒绝的心理成本极高。

**但要注意**：亲戚关系不影响法律责任。你签了字，就是保证人；亲戚还不上，债权人（可能是银行、可能是其他亲戚）照样可以起诉你。

**这一类最常见的坑**：

| 坑 | 说明 |
| --- | --- |
| 「就是签个见证」 | 但你签的是「保证人」栏 |
| 「用你的名义走个流程」 | 这可能让你变成**借款人**，而不是保证人 |
| 「银行要求的，必须有个人签字」 | 银行要求的是担保人，不是见证人 |
| 「房子抵押了，轮不到你」 | 抵押物不足值时，差额部分仍可能找你 |

**第三行最危险**：如果实际是「用你的名义贷款，钱给亲戚用」，那你是**借款人**，不是保证人。亲戚不还，银行只找你。这在法律上叫「名义借款」，实务中争议极大，通常按合同相对性处理。

### 场景三：签「见证人」却签成了「担保人」

这是最容易补救、也最容易出错的一种。

**怎么区分**（这是本节的核心）：

| 看什么 | 见证人 | 保证人 |
| --- | --- | --- |
| 签字栏的名称 | 「见证人」「证明人」 | 「保证人」「担保人」 |
| 合同里有没有「保证」条款 | 没有 | 有 |
| 有没有「承担保证责任」「代为清偿」字样 | 没有 | 有 |
| 有没有约定保证方式、保证范围、保证期间 | 没有 | 通常有 |
| 签在哪里 | 正文之后的见证栏 | 合同末尾的保证人栏，或单独的保证合同 |

**判断方法：不看你在哪签字，看文件里怎么定义你的身份。**

即使你签在「见证人」三个字下面，如果合同正文写着「丙方为乙方债务提供连带责任保证」，那你仍然是保证人。

### 场景四：帮同学「走个流水」「做个证明」

| 对方要求 | 法律上可能是什么 |
| --- | --- |
| 「帮我签个借款确认书」 | 可能构成债务承认或共同借款 |
| 「在借条上签个名，证明我借了钱」 | 视签字位置，可能被认定为保证人或共同借款人 |
| 「帮我做个收入证明」 | 可能构成骗贷的协助（见 03-06） |
| 「用你的名义借，我来还」 | **你是借款人**，风险最高 |

**这一类的共同点**：文件看起来「只是形式」，实际每一份都是在创设或确认法律义务。

## 七、签字前必须确认的五件事

如果你已经被要求签字，先问清这五件事。**答不上来的，不签。**

| 序号 | 要确认什么 | 为什么 |
| --- | --- | --- |
| 1 | **我在合同里是什么身份** | 保证人 / 借款人 / 见证人，三者责任天差地别 |
| 2 | **保证方式是哪一种** | 一般保证还是连带责任保证 |
| 3 | **保证范围有多大** | 只保本金？还是含利息、违约金、律师费 |
| 4 | **保证期间多长** | 你要担心多久 |
| 5 | **债务人的还款能力** | 你有没有能力替他兜底 |

### 6.1 关于「保证期间」

保证期间是一个重要的保护机制：

> 第六百九十二条　保证期间是确定保证人承担保证责任的期间。债权人与保证人可以约定保证期间，但是约定的保证期间早于主债务履行期限或者与主债务履行期限同时届满的，视为没有约定。
>
> 债权人与保证人未约定保证期间的，保证期间为主债务履行期限届满之日起六个月。
>
> 【法规】《中华人民共和国民法典》第六百九十二条

> 第六百九十三条　一般保证的债权人未在保证期间对债务人提起诉讼或者申请仲裁的，保证人不再承担保证责任。
>
> 连带责任保证的债权人未在保证期间请求保证人承担保证责任的，保证人不再承担保证责任。
>
> 【法规】《中华人民共和国民法典》第六百九十三条

**通俗解释**：

- 保证期间是「债权人必须在这段时间内主张权利」的期限
- 过了这个期间，你就不用再负责
- 没有约定时，是主债务到期后**六个月**

**实务含义**：不是「一辈子背着这个责任」。但你也不该指望它——因为债权人通常会在期间内主张。

### 6.2 一个必要的提醒

如果对方催你「今天必须签」「来不及了」「你先签我回头给你看」——**这就是不该签的信号**。

任何正当的担保，都不需要你在一小时内决定。

## 八、已经签了怎么办

分三种情况。

### 7.1 情况一：还没发生债务违约

这个阶段最重要的事是**收集和固定材料**：

| 固定什么 | 为什么 |
| --- | --- |
| 完整的合同原件（或清晰照片、每一页） | 你需要知道保证方式、范围、期间 |
| 你的签字页 | 确认你签的位置和栏位名称 |
| 与债务人、债权人的沟通记录 | 证明你当时是怎么被说服的 |
| 债务人目前的还款情况 | 判断风险何时爆发 |

**然后做两件事**：

1. **搞清楚「保证期间」的起算和截止日**，记在日历上
2. 和债务人**书面**确认：他希望你怎么配合，他打算怎么还

### 7.2 情况二：债务已经违约，债权人找你了

**不要做的事**：

- 不要口头承诺「我会还」
- 不要先转一笔钱「表示诚意」（可能被视为承认保证责任）
- 不要躲（躲不掉，而且可能加速对方起诉）

**要做的事**：

- 立即找律师
- 核对自己的保证方式：如果是一般保证，你有**先诉抗辩权**
- 核对保证期间是否已过

**先诉抗辩权怎么用**：如果是一般保证，债权人还没起诉债务人、还没执行，你可以拒绝承担保证责任。这是法定的抗辩，但**要在诉讼中提出**，不是自动生效的。

### 7.3 情况三：你已经被起诉了

**必须应诉，不能缺席。**

缺席的后果是法院可能缺席判决，你连抗辩的机会都没有。

抗辩的方向（需要律师判断）：

| 抗辩点 | 依据 |
| --- | --- |
| 我是见证人不是保证人 | 合同文本、签字栏位 |
| 我是一般保证，享有先诉抗辩权 | 第六百八十七条 |
| 保证期间已过 | 第六百九十二条、六百九十三条 |
| 主合同无效，保证合同也无效 | 从属性 |
| 保证范围超出约定 | 合同条款 |
| 签字不是我本人 | 笔迹鉴定（谨慎使用，且需真实） |
| 我是被欺诈、胁迫签的 | 需举证，难度大 |

**关于「被欺诈、胁迫」**：这一条听起来好用，实际上举证极难。要有明确证据（录音、聊天记录、证人），不能只是「他说会还我」。

### 7.4 承担了保证责任之后

> 第七百条　保证人承担保证责任后，除当事人另有约定外，有权在其承担保证责任的范围内向债务人追偿，享有债权人对债务人的权利，但是不得损害债权人的利益。
>
> 【法规】《中华人民共和国民法典》第七百条

**你有追偿权。** 你替他还了钱，你可以向他追。

**但现实是**：他连债权人都还不上，通常也还不上你。所以追偿权很多时候是「纸面上的权利」。

**这就是为什么担保的风险是真实的**——法律给你追偿权，但不保证你能拿到钱。

## 九、常见误区

| 误区 | 实际 |
| --- | --- |
| 「只是签个字，不会真让我还」 | 签字就是承诺。债权人可以直接向你主张 |
| 「他不还我也不用还」 | 这正是保证的定义：他不还，你还 |
| 「我签的是见证人」 | 看合同正文怎么定义你的身份，不只看签字栏 |
| 「没有约定保证方式就按连带责任」 | **民法典改了**：没有约定或约定不明，按**一般保证** |
| 「担保只保本金」 | 通常包含利息、违约金、实现债权的费用，看合同约定 |
| 「过几年就自动失效」 | 有保证期间，但通常会在期间内被主张。且诉讼时效另有规则 |
| 「我跟他是好朋友，他不会坑我」 | 他可能不是故意坑你，他只是还不上 |
| 「他家里有钱，会替他还」 | 他家人没有法律义务替他还 |
| 「我签了但没拿钱，所以不算」 | 保证人不拿钱，但承担责任 |
| 「先还一点表示诚意，对方就不会追究」 | 可能被视为承认保证责任，反而对自己不利 |

## 十、可执行清单

### 被要求签字时的五问

- [ ] 这份文件里，我是什么身份？（逐字找「保证人」「担保人」「借款人」「见证人」）
- [ ] 保证方式是一般保证还是连带责任保证？
- [ ] 保证范围包括哪些？（本金 / 利息 / 违约金 / 律师费）
- [ ] 保证期间是多长？
- [ ] 如果对方还不上，我有能力全额承担吗？（诚实回答）

**任何一问答不上来，就不要签。**

### 如果决定不签，怎么说

> 「我不做担保，家里有规矩，谁的忙都不帮，不是针对你。」

**不要解释理由，不要给「下次吧」的余地。** 真正正当的请求，不会因为你说「不做担保」就变成绝交。

### 已经签了的

- [ ] 找到合同原件，拍照存档每一页
- [ ] 确认保证方式、保证范围、保证期间
- [ ] 算出保证期间的截止日，记在日历上
- [ ] 保留当时沟通的记录（谁怎么说的）
- [ ] 关注债务人的还款情况
- [ ] 一旦对方逾期，立即找律师

### 长期

- [ ] 把「不担保、不代持、不借名」写成自己的原则
- [ ] 记住：担保不是人情，是负债
