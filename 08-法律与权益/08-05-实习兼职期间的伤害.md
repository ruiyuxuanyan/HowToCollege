# 实习、兼职期间的伤害：不算工伤，不等于没得赔

> 一句话概括：在校生兼职不走工伤认定，走人身损害赔偿。

**适用人群**：正在做兼职、实习的大学生；在实习单位受了伤不知道怎么索赔的人；准备签实习协议的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国民法典》侵权责任编（第一千一百六十五条起、第一千一百七十九条）；《工伤保险条例》；《中华人民共和国劳动法》《中华人民共和国劳动合同法》关于劳动关系认定的规定
> - 全国统一：民法典与《工伤保险条例》全国适用；**各地法院对「在校生实习是否构成劳动关系」的裁判口径存在差异**，见第四节
> - 核查日期：2026-11-05
> - 已知变化：《工伤保险条例》现行版本为 2010 年修订；各地对实习伤害的赔偿标准（城镇居民人均可支配收入等）按年度调整
>
> ⏳ 易过时：赔偿标准的具体数额每年变化；各校实习管理规定不同。

## 一、先定性：你是哪一种身份，决定走哪条路

受伤之后第一件事不是算钱，是搞清楚**你和用工方是什么关系**。关系不同，索赔的法律依据、责任划分方式、赔偿项目全都不一样。

| 你的身份 | 法律关系的性质 | 受伤后走什么 | 谁赔 |
| --- | --- | --- | --- |
| 在校生**课余兼职**（家教、发传单、送外卖） | 通常认定为**劳务关系** | 人身损害赔偿 | 用工方按过错赔 |
| 在校生**实习**（学校安排或自行联系） | 通常认定为**劳务关系**，不是劳动关系 | 人身损害赔偿 | 实习单位 / 学校 / 你自己，按过错分担 |
| 已毕业、签了劳动合同 | **劳动关系** | 工伤认定 | 工伤保险基金 + 单位 |
| 学校组织的**教学实习**（有学分、纳入培养方案） | 复杂，可能是教育管理关系 + 劳务关系 | 人身损害赔偿，学校可能担责 | 单位 + 学校按过错 |
| 与单位**事实劳动关系**（长期固定、受管理、领固定工资） | 可能被认定为**劳动关系** | 可能走工伤 | 见第四节 |

**注意第四行和第五行**，这是两个例外。

### 1.1 为什么在校生通常不构成劳动关系

《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》（劳部发〔1995〕309 号）第十二条有一句关键表述（大意）：

> 在校生利用业余时间勤工助学，不视为就业，未建立劳动关系，可以不签订劳动合同。

【法规】原劳动部《关于贯彻执行〈中华人民共和国劳动法〉若干问题的意见》（劳部发〔1995〕309 号）第十二条

**这句话的实务含义**：你的兼职不被当作「就业」，所以《劳动法》《劳动合同法》《工伤保险条例》那一整套保护不适用。

**不适用意味着失去哪些保护：**

| 失去了什么 | 具体表现 |
| --- | --- |
| 工伤认定 | 不能申请工伤，拿不到工伤保险待遇 |
| 最低工资标准 | 严格说不受最低工资约束（但仍受公平原则约束） |
| 加班费 | 没有法定加班费 |
| 经济补偿金 | 被辞退没有 N+1 |
| 书面劳动合同 | 单位不需要和你签劳动合同 |
| 劳动仲裁 | 不能走劳动仲裁，直接去法院起诉 |

**这就是为什么很多学生兼职出事后发现「没人管」——不是法律不管，是你走错了门。**

## 二、那走什么？人身损害赔偿

不走工伤，走的是《民法典》侵权责任编。

### 2.1 法条

> 第一千一百六十五条　行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
>
> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。
>
> 【法规】《中华人民共和国民法典》第一千一百六十五条

> 第一千一百七十九条　侵害他人造成人身损害的，应当赔偿医疗费、护理费、交通费、营养费、住院伙食补助费等为治疗和康复支出的合理费用，以及因误工减少的收入。造成残疾的，还应当赔偿辅助器具费和残疾赔偿金；造成死亡的，还应当赔偿丧葬费和死亡赔偿金。
>
> 【法规】《中华人民共和国民法典》第一千一百七十九条

**这两条是整套索赔的地基。** 第一千一百七十九条列出的项目，就是你能要的钱的清单。

### 2.2 能要哪些钱

| 项目 | 对应什么 | 怎么证明 |
| --- | --- | --- |
| 医疗费 | 挂号、检查、治疗、药费、手术 | 医院票据、病历 |
| 护理费 | 需要人照顾的费用 | 护理人员收入证明，或当地护工标准 |
| 交通费 | 就医往返 | 车票、打车记录 |
| 营养费 | 加强营养的支出 | 医嘱（要有医生写明） |
| 住院伙食补助费 | 住院期间伙食 | 住院记录 |
| **误工费** | 因伤不能工作的收入损失 | 见 2.3，这一点对学生很关键 |
| 残疾赔偿金 | 构成伤残等级 | 司法鉴定意见 |
| 残疾辅助器具费 | 假肢、轮椅等 | 票据 + 医嘱 |
| 精神损害抚慰金 | 严重伤害造成的精神痛苦 | 伤残等级、后果严重程度 |
| 后续治疗费 | 二次手术、康复 | 医嘱或鉴定意见 |

### 2.3 「误工费」对学生是个坑

这是最容易出问题的一项。

**法律规定**：误工费按「因误工减少的收入」计算。

**问题在于**：如果你没有固定收入，「减少的收入」怎么算？

实务中的大致处理：

| 你的情况 | 误工费通常怎么算 |
| --- | --- |
| 有固定兼职收入，有工资流水 | 按实际减少的收入算 |
| 有兼职但没流水、发现金 | 举证困难，法院可能按当地相近行业平均工资或酌情认定 |
| 纯学生，没有收入 | **通常不支持误工费**，或只支持很少 |
| 但因伤耽误了实习/求职，造成明确损失 | 可以主张，但需要证明「损失是确定的」 |

**所以，一份兼职的工资流水，受伤后的价值不只是那点钱，是误工费的依据。** 尽量走银行转账，不要收现金。

### 2.4 责任怎么分

人身损害赔偿的核心是**过错**。不是「谁受伤谁有理」，是「谁有过错谁担责」。

| 责任方 | 可能的过错 |
| --- | --- |
| 用工方 / 实习单位 | 未提供安全培训、未提供防护设备、安排危险作业、设备有隐患、未及时救助 |
| 学校 | 未审查实习单位资质、未进行安全教育、未跟踪管理（学校组织实习时） |
| 你自己 | 违反操作规程、不听劝阻、擅自操作、隐瞒身体条件 |
| 第三方 | 如设备供应商、场地提供方 |

**可能的结果**：

- 单位全责 → 全赔
- 单位主责、你次责 → 按比例（如 7:3）
- 你主责 → 你自己承担大部分
- 混合过错 → 按各自过错比例分担

法条依据：

> 第一千一百七十三条　被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。
>
> 【法规】《中华人民共和国民法典》第一千一百七十三条

**这就是为什么「你自己有没有违规」会成为争议焦点。** 单位一定会查你有没有违反操作规程。

## 三、学校的责任在哪

学校组织的实习出事，学校不是旁观者。

### 3.1 学校的义务

《民法典》第一千二百条（限制民事行为能力人在教育机构受害）与第一千一百九十九条、第一千二百零一条针对的是未成年学生。大学生是**完全民事行为能力人**，适用的是过错责任原则（第一千一百六十五条），不适用教育机构的过错推定。

所以对大学生来说，学校的责任要看**学校有没有过错**：

| 学校做了什么 | 是否有过错 |
| --- | --- |
| 组织实习但没审查单位资质、安全条件 | 可能有过错 |
| 未进行实习前的安全教育 | 可能有过错 |
| 实习协议中未约定安全责任 | 可能有过错 |
| 学生反映问题后未处理 | 可能有过错 |
| 学生自行找的兼职，学校不知情 | 通常无过错 |

### 3.2 一个实际的做法

出事后，向学校**书面**报告（不是口头说一声），要求学校介入协调。理由：

1. 学校有管理职责，书面报告能固定「学校已知情」
2. 学校出面协调，单位通常更配合
3. 如果最后要起诉，书面报告是证明学校是否尽责的材料

## 四、例外：什么时候可能被认定为劳动关系

虽然在校生兼职通常不构成劳动关系，但**不是绝对的**。

司法实践中，法院判断是否存在劳动关系，看的是**实质**，不是身份。参考的要素包括：

| 要素 | 说明 |
| --- | --- |
| 人格从属性 | 你是否受单位管理、考勤、遵守其规章制度 |
| 经济从属性 | 你是否主要靠这份收入生活 |
| 组织从属性 | 你是否被纳入单位的组织体系 |
| 持续性 | 是否长期、固定、全职 |
| 报酬 | 是否按月固定发放 |

**可能出现劳动关系的情形**：

- 已经毕业（或即将毕业、已完成学业）的学生，全职工作
- 长期固定在某单位工作，接受完整管理，按月领薪
- 学校安排的「顶岗实习」中，学生完全按单位员工方式管理（各地裁判不一）

> **【待核实】各地口径差异**：关于「在校生实习是否构成劳动关系」，各地法院裁判标准不统一。部分法院认为在校生不具备建立劳动关系的主体资格；部分法院在满足实质要件时予以认定。**这一点必须按你所在地区、具体案情判断，不能一概而论。**
>
> 建议：如果伤情严重、金额较大，**咨询当地劳动法律师**，评估是否有主张劳动关系的空间。因为一旦认定劳动关系，就能走工伤，赔偿标准通常更高且更稳定。

### 4.1 工伤和人身损害赔偿，差在哪

| | 工伤 | 人身损害赔偿 |
| --- | --- | --- |
| 是否看过错 | **不看**（无过错责任） | 看过错，按比例 |
| 谁出钱 | 工伤保险基金 + 单位 | 侵权人 |
| 伤残标准 | 《劳动能力鉴定》标准 | 人身损害伤残标准 |
| 赔偿项目 | 法定，较固定 | 法定项目 + 酌定 |
| 程序 | 工伤认定 → 劳动能力鉴定 → 待遇 | 协商 / 起诉 |
| 举证难度 | 相对低（不需证明对方过错） | 需证明过错和因果关系 |

**最关键的区别是第一行**：工伤不看谁有过错。哪怕是你自己操作失误受伤，只要是工伤，照样赔。人身损害赔偿则要按过错分担。

## 五、《工伤保险条例》为什么不适用

很多人会问：「单位给我交了工伤保险，为什么不能报？」

> 第二条　中华人民共和国境内的企业、事业单位、社会团体、民办非企业单位、基金会、律师事务所、会计师事务所等组织和有雇工的个体工商户（以下称用人单位）应当依照本条例规定参加工伤保险，为本单位全部职工或者雇工（以下称职工）缴纳工伤保险费。
>
> 【法规】《工伤保险条例》第二条

**关键词是「职工」。** 工伤保险覆盖的是**建立劳动关系的职工**。

在校生兼职不构成劳动关系 → 不是「职工」 → 不在覆盖范围 → 不能申请工伤认定。

**还有一层**：工伤认定需要用人单位或职工本人向社保行政部门提出申请。如果不存在劳动关系，这个申请的前提就不成立。

**所以「单位说有保险」这句话要问清楚**：是**工伤保险**（社保五险之一），还是**商业意外险**（单位自己买的）？

| 险种 | 能不能用 |
| --- | --- |
| 工伤保险 | 在校生兼职通常不能用 |
| 商业意外险（单位为员工投保） | **可能能用**，看保单的保障对象和条款 |
| 学校给学生买的校方责任险 | 可能能用，看条款 |
| 学平险 / 城乡居民医保 | 可以报销部分医疗费 |

**这一条很实际**：很多单位给兼职学生买的是商业意外险。出事后先问清楚保的是什么险、能不能理赔、怎么理赔。这往往是最快拿到钱的方式。

## 六、受伤之后，按顺序做

### 第 0 步：先治伤

**任何时候，治伤优先于取证。** 但可以在就医时顺手做几件事：

- 告诉医生受伤的**真实经过**（工作原因、时间、地点）——病历上的记录是关键证据
- 保留所有票据原件
- 不要用「自己不小心摔的」这种说法，除非事实如此

### 第一步：24 小时内固定四类证据

| 证据 | 具体是什么 | 为什么重要 |
| --- | --- | --- |
| **工作关系证据** | 排班表、打卡记录、工作群聊天、任务派发记录、工资转账 | 证明你在为谁工作 |
| **事故证据** | 现场照片、监控位置、在场同事的姓名和联系方式 | 证明事故怎么发生的 |
| **伤情证据** | 病历、诊断证明、影像资料、票据 | 证明伤到什么程度 |
| **沟通证据** | 与单位沟通的微信/短信，尤其是对方承认「是在我们这受的伤」 | 证明对方认可 |

**特别注意**：如果在工作群里，**不要退群**。群聊记录是最有力的证据之一。

### 第二步：书面通知单位

用微信或短信（可留痕），内容包含：

- 哪天、几点、在什么地方
- 在做什么工作时受伤
- 伤到什么程度、在哪家医院
- 明确要求：请单位协助处理

**不要打电话说。** 电话没有记录。

### 第三步：判断走哪条路

| 情况 | 怎么做 |
| --- | --- |
| 伤情轻、费用小 | 与单位协商，签书面协议 |
| 伤情中等、单位配合 | 协商 + 保险理赔 |
| 伤情重、可能构成伤残 | **立即找律师**，评估是否做伤残鉴定 |
| 单位推诿、否认关系 | 找律师，准备起诉；同时向学校、劳动监察反映 |

### 第四步：考虑伤残鉴定

如果伤情可能留下后遗症（骨折、关节损伤、视力听力损害、疤痕），**要做伤残鉴定**。

- 时机：治疗终结后（一般是伤情稳定后）
- 机构：有资质的司法鉴定机构
- 作用：残疾赔偿金的计算依据，也是谈判的核心筹码

**注意**：人身损害的伤残鉴定标准和工伤的劳动能力鉴定标准**不是同一套**，等级可能不同。这也是为什么「能不能认定劳动关系」很关键。

### 第五步：协商或起诉

**协商时的三个要点**：

1. 一次性了结的协议，必须写清「包含全部项目」——否则后续治疗费可能要不回来
2. 不要签「放弃一切权利」的空白协议
3. 签字前让律师看一眼（金额大的话，这笔钱值得花）

**诉讼**：人身损害赔偿的诉讼时效是**三年**（《民法典》第一百八十八条），从知道或应当知道权利受损之日起算。不要拖。

## 七、「签了免责协议就白受伤」吗

这是实习协议里最常见、也最容易被误解的一条。

**结论：不一定有效。**

依据：

> 第四百九十七条　有下列情形之一的，该格式条款无效：
>
> （一）具有本法第一编第六章第三节和本法第五百零六条规定的无效情形；
> （二）提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利；
> （三）提供格式条款一方排除对方主要权利。
>
> 【法规】《中华人民共和国民法典》第四百九十七条

> 第五百零六条　合同中的下列免责条款无效：
>
> （一）造成对方人身损害的；
> （二）因故意或者重大过失造成对方财产损失的。
>
> 【法规】《中华人民共和国民法典》第五百零六条

**第五百零六条第（一）项是关键**：**造成对方人身损害的免责条款，无效。**

也就是说，实习协议里写「实习期间发生任何人身伤害，本单位概不负责」，这一条**在法律上是无效的**。

**但仍要注意两点**：

1. 「无效」需要你主张。单位不会主动说这条无效，很多人因为看到这条就放弃了
2. 协议里其他条款仍可能有效（比如约定争议解决方式、保密义务）

**所以看到免责条款不要慌，也不要因此就觉得「签了也没用」。** 该签的协议还是要签（不签可能失去实习机会），但出事时要知道这一条站不住。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「不是工伤就没人管」 | 走人身损害赔偿，照样能索赔，且赔偿项目相当完整 |
| 「单位给交了保险就是工伤」 | 可能是商业意外险，不是工伤保险。在校生兼职通常不在工伤保险覆盖范围 |
| 「签了免责协议就只能认」 | 造成人身损害的免责条款无效（《民法典》第五百零六条） |
| 「我自己操作失误，就全是我责任」 | 单位的安全保障义务、培训义务是独立的；可能混合过错，按比例分担 |
| 「没签合同就没法维权」 | 劳务关系不要求书面合同，用排班表、聊天记录、转账记录也能证明 |
| 「误工费能按我未来工资算」 | 误工费按「实际减少的收入」算。没有收入通常不支持 |
| 「先私了拿点钱算了」 | 伤情可能之后恶化。重伤不要急着一次性了结 |
| 「学校安排的实习，学校必须赔」 | 学校按过错担责，不是必然担责 |
| 「伤好了就没事了」 | 后遗症、伤残要在治疗终结后做鉴定，别过早签了结协议 |
| 「口头答应赔就行」 | 没有书面协议，对方随时反悔 |

## 九、可执行清单

### 受伤当场

- [ ] 停止工作，先处理伤口
- [ ] 让在场同事留下姓名和联系方式
- [ ] 拍现场照片（设备、环境、地面、你的伤处）
- [ ] 确认监控位置（哪个摄像头、朝向哪里）
- [ ] 立刻告知单位负责人（用微信，不要打电话）

### 就医时

- [ ] 如实告诉医生：工作时受的伤
- [ ] 要求病历上写明受伤原因和时间
- [ ] 保留全部票据原件（不要交出去）
- [ ] 拿到诊断证明（盖章）
- [ ] 需要休假就开病假条

### 24 小时内

- [ ] 书面通知单位（微信/短信，写明时间地点经过）
- [ ] 保存工作群、排班表、打卡记录（**不要退群**）
- [ ] 截图保存所有与单位的沟通
- [ ] 告诉家人

### 一周内

- [ ] 向学校书面报告（如果是学校组织的实习）
- [ ] 问清单位买的什么保险、怎么理赔
- [ ] 整理证据清单（时间线 + 材料目录）
- [ ] 伤情较重就咨询律师

### 谈判/起诉前

- [ ] 治疗终结后再谈一次性了结
- [ ] 需要就做伤残鉴定
- [ ] 不签空白协议、不签「放弃一切权利」
- [ ] 注意三年诉讼时效
