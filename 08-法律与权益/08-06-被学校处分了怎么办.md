# 被学校处分了怎么办：程序、申诉、能不能撤销

> 一句话概括：处分的程序是学校必须走完的，走漏一步就是你申诉的理由。

**适用人群**：收到处分告知书或处分决定的学生；正在被调查、还没出结果的学生；帮同学处理这类事的学生干部。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。个案也可向本校学生申诉处理委员会咨询。
>
> **政策与法律适用范围**
> - 主要依据：《普通高等学校学生管理规定》（教育部令第 41 号，2017 年 2 月 4 日发布，2017 年 9 月 1 日施行）；《中华人民共和国教育法》；《中华人民共和国行政复议法》
> - 全国统一：教育部令第 41 号对全国普通高校统一适用；**各校的实施细则、申诉办法、具体时限由学校自定，差异很大**
> - 核查日期：2026-11-05
> - 已知变化：教育部令第 41 号是现行主要依据；该校令此前为教育部令第 21 号（2005 年），41 号令施行后取代
>
> ⏳ 易过时：各校申诉时限、申诉委员会组成、听证规则。

---

## 一、处分的五种，严重程度完全不同

教育部令第 41 号第五十一条规定了五种处分：

> 第五十一条　学校对学生的处分，应当做到证据充分、依据明确、定性准确、程序正当、处分适当。
>
> 对有违反法律法规、本规定以及学校纪律行为的学生，学校应当给予批评教育，并可视情节轻重，给予如下纪律处分：
>
> （一）警告；
> （二）严重警告；
> （三）记过；
> （四）留校察看；
> （五）开除学籍。
>
> 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第五十一条

| 处分 | 严重程度 | 关键后果 |
| --- | --- | --- |
| 警告 | 最轻 | 通常有考察期，表现好可解除 |
| 严重警告 | 轻 | 同上 |
| 记过 | 中 | 进档案；影响评奖评优、入党、保研 |
| 留校察看 | 重 | 察看期通常一年；期内再违纪可能升级为开除 |
| **开除学籍** | 最重 | **失去学籍，无法继续在本校就读** |

**最关键的区别：前四种是「校内的」，开除学籍是「身份性的」。**

开除学籍不是「罚一下」，它是让你不再是这个学校的学生。所以法律对它的程序要求最严。

## 二、处分必须走的程序（本篇核心）

这一节是本文最有用的部分。**学校如果漏掉任何一环，就是你申诉的理由。**

### 2.1 法定要求

> 第五十五条　学校在对学生作出处分或者其他不利决定之前，应当告知学生作出决定的事实、理由及依据，并告知学生享有陈述和申辩的权利，听取学生的陈述和申辩。
>
> 处理、处分决定以及处分告知书等，应当直接送达学生本人，学生拒绝签收的，可以以留置方式送达；已离校的，可以采取邮寄方式送达；难于联系的，可以利用学校网站、新闻媒体等以公告方式送达。
>
> 【法规】同上，第五十五条

把这一条拆成动作，就是下面的检查表。

### 2.2 五个必经环节

| 环节 | 学校要做什么 | 你要确认什么 |
| --- | --- | --- |
| ① 调查取证 | 查清事实，收集证据 | 学校有没有给你看过证据？证据是否完整？ |
| ② **事先告知** | 告知**拟**处分的事实、理由、依据 | 是不是在你被处分**之前**告知的？ |
| ③ **听取陈述申辩** | 给你机会说明情况，并且**听取** | 有没有给你这个机会？有没有记录？ |
| ④ 作出决定 | 按权限和程序作出书面决定 | 决定书有没有写明事实、理由、依据、期限？ |
| ⑤ **送达 + 告知申诉途径** | 送达本人，并告知申诉的权利、途径、期限 | 有没有明确告诉你「不服可以怎么申诉、多少天内」？ |

**第②③⑤环是最容易出问题的地方**，也是申诉时最有力的切入点。

### 2.3 常见程序瑕疵（申诉时逐条对照）

| 瑕疵 | 具体表现 | 是否构成申诉理由 |
| --- | --- | --- |
| 未事先告知 | 直接给处分决定，之前没通知过 | **是**，程序违法 |
| 未听取陈述申辩 | 没问过你，或问了但不记录 | **是** |
| 未告知申诉途径 | 决定书里没写怎么申诉、多少天内 | **是** |
| 未送达本人 | 只在班会上口头说，没给书面文件 | **是** |
| 证据未质证 | 只写「经查」，不说明依据什么 | 可以作为事实认定不清的理由 |
| 决定主体越权 | 开除学籍没有经过规定的会议研究 | **是**，重大程序违法 |
| 超期作出 | 学校规定的处理期限已过 | 可作为理由，但效力因校而异 |

**注意最后一行**：超期是否影响处分效力，各校规定不同，属于【待核实】范围。

### 2.4 开除学籍的特别程序

这是最重的一档，法律对它的决定主体有额外要求。

> 第五十七条　学校对学生作出开除学籍处分决定，应当由校长办公会或者校长授权的专门会议研究决定，并应当事先告知学生有要求举行听证的权利。
>
> 【法规】同上，第五十七条

两个要点：

1. **决定主体**：必须是**校长办公会**或**校长授权的专门会议**。不是学院、不是学工部、不是某个处长
2. **听证权利**：必须**事先告知**学生有权要求听证

**这两点是最硬的申诉武器。** 如果开除决定是学院直接作出的，或者没有告知你听证权利，程序上就有明显问题。

## 三、申诉：两条路，先校内后校外

### 3.1 校内申诉是必经程序

> 第五十九条　学校应当成立学生申诉处理委员会，负责受理学生对处理或者处分决定不服提起的申诉。
>
> 学生申诉处理委员会应当由学校相关负责人、职能部门负责人、教师代表、学生代表、负责法律事务的相关机构负责人等组成，可以聘请校外法律、教育等方面专家参加。
>
> 【法规】同上，第五十九条

**关键：校内申诉是向教育行政部门申诉的前置程序。** 跳过校内直接去省教育厅，通常会被要求先走校内。

### 3.2 时限——这是最容易错过的东西

> 第六十条　学生对学校的处理或者处分决定有异议的，可以在接到学校处理或者处分决定书之日起十日内，向学校学生申诉处理委员会提出书面申诉。
>
> 【法规】同上，第六十条

**十日。** 从**接到决定书之日**起算。

这个时限的几个细节：

| 问题 | 说明 |
| --- | --- |
| 从哪天算 | 「接到」之日，不是决定作出之日 |
| 十天是自然日还是工作日 | 该条未明确，实务中通常按自然日理解，**保守起来按自然日算** |
| 能不能延长 | 该条未规定延长。**视为不能** |
| 学校会不会另有规定 | 可能。有的学校写得更长，有的更短。**以本校申诉办法为准，取更有利的那个** |

**所以第一件事：拿到处分决定书，当天就看清楚申诉期限，并且马上开始准备。**

### 3.3 学校的答复时限

> 第六十一条　学生申诉处理委员会对学生提出的申诉进行复查，并在接到书面申诉之日起十五日内作出复查结论并告知申诉人。情况复杂不能在规定限期内作出结论的，经学校负责人批准，可延长十五日。学生申诉处理委员会认为必要的，可以建议学校暂缓执行有关决定。
>
> 【法规】同上，第六十一条

**注意最后一句**：「可以建议学校暂缓执行」。这意味着申诉期间，处分**可能仍在执行**。如果你要主张暂缓（尤其是开除学籍），要主动提出。

### 3.4 向教育行政部门申诉

> 第六十二条　学生对复查决定有异议的，在接到学校复查决定书之日起十五日内，可以向学校所在地省级教育行政部门提出书面申诉。
>
> 省级教育行政部门在接到学生书面申诉之日起三十日内，应当对申诉人的问题给予处理并答复。
>
> 【法规】同上，第六十二条

所以完整的救济链条是：

```
处分决定书（送达）
   │ 10 日内
   ▼
校内申诉（学生申诉处理委员会）
   │ 15 日内答复（可延长 15 日）
   ▼
不服 → 15 日内向省级教育行政部门申诉
   │ 30 日内处理答复
   ▼
仍不服 → 可以依法申请行政复议或提起行政诉讼
```

**最后一步的依据**：学校作出的处分决定，在开除学籍这类直接影响受教育权的重大事项上，司法实践中通常被认为属于可诉的行为。**这条路径的具体可行性、管辖法院、起诉期限，属于需要律师判断的问题**，本文不给结论。

## 四、什么理由的申诉容易成功

不是「我觉得处分太重」就能成功。有效的理由是这几类：

### 4.1 程序违法（最容易成功）

| 理由 | 具体主张 |
| --- | --- |
| 未事先告知 | 学校未在作出决定前告知拟处分的事实、理由、依据 |
| 未听取申辩 | 未给你陈述和申辩的机会，或听取了但未记录 |
| 未送达 | 处分决定未依法送达本人 |
| 未告知申诉途径 | 决定书未写明申诉权利、途径、期限 |
| 决定主体越权 | 开除学籍未经校长办公会或校长授权的专门会议研究 |
| 未告知听证权利 | 开除学籍前未告知有要求听证的权利 |

**为什么程序违法最容易成功**：因为它不涉及「事实到底成不成立」的争议，是客观可查的。学校有没有做过某个动作，看文件就能判断。

### 4.2 事实认定错误

| 理由 | 怎么主张 |
| --- | --- |
| 关键事实无证据 | 处分依据的事实，学校拿不出证据 |
| 证据不足 | 只有一方的说法，没有客观证据 |
| 事实与证据不符 | 证据能证明 A，学校认定成 B |
| 遗漏有利事实 | 你有能证明自己无过错/情节较轻的材料，学校没采纳 |

### 4.3 依据不当

| 理由 | 怎么主张 |
| --- | --- |
| 适用条款错误 | 你的行为不符合所引条款的构成 |
| 引用的校规本身与上位规定冲突 | 校规不能违反教育部令第 41 号 |
| 校规未经合法程序制定/未公示 | 学生手册没有这一条，或没有向你公示过 |

### 4.4 处分畸重

| 理由 | 怎么主张 |
| --- | --- |
| 同类行为处分不一致 | 同样的事，别人是警告，你是记过（需举证，较难） |
| 未考虑从轻情节 | 初犯、主动改正、赔偿损失、取得谅解、配合调查 |
| 未区分主次 | 你是次要参与者，却被按主要责任人处理 |

**这一类最难成功**，因为「适当与否」的判断权在学校。但如果前四类有一条成立，配合这一条效果更好。

## 五、申诉书怎么写

不要写成情绪宣泄。按这个结构写，一页半到两页。

### 5.1 结构

```
标题：关于撤销〔处分决定文号〕处分决定的申诉书

一、申诉人基本信息
    姓名、学号、学院、专业、年级、联系电话

二、申诉请求
    1. 撤销〔文号〕《关于给予XXX处分的决定》；
    2. 〔如有〕重新调查并作出处理；
    3. 〔如已执行〕暂缓执行。

三、事实与理由
    （一）程序方面
         1. 学校未在作出处分决定前告知拟处分的事实、理由和依据，
            违反《普通高等学校学生管理规定》第五十五条……
         2. ……
    （二）事实认定方面
         1. 处分决定认定「……」，但该事实缺乏证据支持。现有证据显示……
    （三）依据方面 / （四）处分适当性方面

四、证据清单
    1. 处分决定书复印件
    2. 微信聊天记录截图（X 页）
    3. 证人 XXX 的书面证言
    4. ……

五、结语
    恳请学生申诉处理委员会依法复查。

申诉人：（签名）
日期：
```

### 5.2 写作要点

| 要做 | 不要做 |
| --- | --- |
| 每一段都指向具体条款 | 不要写「这太不公平了」 |
| 只说事实和时间点 | 不要评价老师的为人 |
| 程序问题放最前面 | 不要把最激烈的情绪放开头 |
| 请求写具体（撤销/重新处理/暂缓） | 不要只写「希望学校重新考虑」 |
| 附证据清单并编号 | 不要只口头说「有证人」 |
| 用「据……第 X 条规定」的句式 | 不要用「我认为」「我觉得」 |

### 5.3 一个常见错误

很多人把申诉书写成**「我确实做错了，但处分太重」**。这在策略上是不利的——你等于承认了事实和定性，只剩下「轻重」这一个很难赢的争点。

**更有效的写法**：先主张程序问题（客观、可查），再主张事实问题，最后才谈轻重。**顺序很重要。**

## 六、听证：什么情况下可以要求

### 6.1 法定的听证情形

教育部令第 41 号第五十七条明确：**开除学籍**处分决定前，应当事先告知学生有要求举行听证的权利。

也就是说：

- 开除学籍 → **你有权要求听证**
- 其他处分 → 该规定未强制要求听证，但**部分学校的校规规定了更广的听证范围**

**所以第二件事（第一件是看时限）：查本校学生手册里的听证条款。** 有的学校规定留校察看也可以要求听证。

### 6.2 听证要准备什么

| 准备 | 说明 |
| --- | --- |
| 书面申请 | 在告知的期限内提交，逾期视为放弃 |
| 陈述提纲 | 3–5 分钟能讲完，重点讲程序问题和事实争议 |
| 证据原件 | 带原件，提交复印件 |
| 证人 | 提前联系，确认能到场 |
| 是否请律师 | 部分学校允许代理人参加，查本校规定 |

**听证的价值**：它是一个**留下记录**的正式程序。你在听证上说的话、提交的材料，会成为后续申诉的基础。即使听证结果不理想，记录本身也有用。

## 七、处分之后，还有几件事要做

### 7.1 关于「处分能不能撤销」

| 处分类型 | 通常的消除方式 |
| --- | --- |
| 警告、严重警告、记过、留校察看 | 多数学校规定考察期满、表现良好可申请**解除**（不是「撤销」，是「解除」） |
| 开除学籍 | 只能通过申诉、行政复议、诉讼改变 |

**「解除」和「撤销」的区别很重要**：

- **撤销** = 处分自始不存在（通过申诉等程序实现）
- **解除** = 处分曾经存在，但效力终止（通过考察期表现实现）

**解除后档案里还有没有记录？** 各校做法不同，属于【待核实】。有的学校解除后不入档案，有的仍保留。**这一条要直接问学校，并且要书面答复。**

### 7.2 处分对后续的影响

| 影响 | 说明 |
| --- | --- |
| 奖学金、评优 | 通常规定「受处分期间不得参评」 |
| 入党 | 有影响，具体看党组织规定 |
| 保研 | 通常直接失去资格（各校规定不同） |
| 学生干部 | 通常要免职 |
| 毕业、学位 | 一般不影响（除非开除学籍），但有的学校规定「留校察看期间不授予学位」 |
| 就业政审 | 公务员、事业单位、参军政审会查；一般企业通常不查校内处分 |

**最后一行要区分清楚**：校内处分**不是**违法犯罪记录，一般不会出现在「无犯罪记录证明」里。但考公、参军的政审可能通过学校了解在校表现。

### 7.3 不要做的事

| 不要 | 原因 |
| --- | --- |
| 错过申诉期限 | 期限是硬性的，过了就没有校内救济 |
| 只口头申诉 | 必须书面，且要留提交凭证（收件回执、邮件回执） |
| 在社交平台曝光 | 可能被追加处理，也会影响后续协商 |
| 找人说情 | 可能被视为不当影响，且不留记录 |
| 拒绝签收决定书 | 拒收可以留置送达，拒收本身不产生任何有利效果，反而失去申诉时间 |

**倒数第一条特别说明**：很多人以为「我不签收就等于没收到」。法律上不是这样——第五十五条明确规定了留置送达、邮寄送达、公告送达。拒收只会让你错过期限。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「申诉没用，学校自己查自己」 | 程序违法是客观问题，很多申诉成功就靠这个 |
| 「错过了期限还能补」 | 十日是法定期限，逾期通常不再受理 |
| 「不签收决定书就不算送达」 | 可以留置送达、邮寄送达、公告送达 |
| 「学院通知我就是处分了」 | 开除学籍必须经校长办公会或校长授权的专门会议研究决定 |
| 「开除学籍跟退学差不多」 | 性质完全不同：一个是处分（影响档案），一个是学籍处理 |
| 「处分过一段时间自动消失」 | 需要申请解除；能否入档要问学校 |
| 「申诉就是跟学校对着干」 | 申诉是制度设计的权利，行使权利不等于对抗 |
| 「找关系比走程序有用」 | 程序留痕，关系不留痕；而且程序问题一旦成立，结果更稳 |
| 「先认错态度好，处分会轻」 | 认错和申诉不冲突，但不要在申诉书里先承认全部事实 |
