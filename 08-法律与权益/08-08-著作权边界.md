# 著作权边界：搬运、汉化、网盘分享的界限

> 一句话概括：侵权不以营利为前提，但后果分轻重。

**适用人群**：做自媒体、搬运视频、汉化字幕的大学生；在网盘分享资源、做「资源号」的人；写论文、做课程作业引用他人作品的人；经营社团公众号的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国著作权法》（2020 年 11 月 11 日修正，2021 年 6 月 1 日施行）；《中华人民共和国刑法》第二百一十七条；最高人民法院、最高人民检察院关于办理侵犯知识产权刑事案件的司法解释
> - 全国统一：著作权法与刑法全国统一适用
> - 核查日期：2026-11-07
> - 已知变化：现行《著作权法》为 2020 年修正版，条文序号与 2010 年版有变化，**引用时注意版本**
>
> ⏳ 易过时：侵犯著作权罪的入罪数额标准由司法解释规定，可能调整。

## 一、最容易误解的一件事：侵权不看钱

先说结论：

> **著作权侵权不以「营利」为前提。**

这是本文最需要纠正的认知。很多人的逻辑是：「我又没卖钱，不算侵权吧？」

**法律上不成立。**

依据：

> 第五十二条　有下列侵权行为的，应当根据情况，承担停止侵害、消除影响、赔礼道歉、赔偿损失等民事责任：
>
> （一）未经著作权人许可，发表其作品的；
> ……
> （五）未经著作权人许可，……通过信息网络向公众传播其作品的，本法另有规定的除外；
> ……
>
> 【法规】《中华人民共和国著作权法》（2020 年修正）第五十二条

这一条列举的侵权行为，**没有一条以「营利」为构成要件**。只要未经许可 + 使用了作品 + 不属于合理使用，就构成侵权。

### 1.1 但营利确实影响后果

| | 不营利 | 营利 |
| --- | --- | --- |
| 是否构成侵权 | **可能构成** | 可能构成 |
| 赔偿数额 | 通常较低（按实际损失或法定赔偿） | 通常较高 |
| 是否可能刑事 | 一般不会 | **可能**（侵犯著作权罪要求「以营利为目的」） |
| 平台处罚 | 可能被下架 | 更严 |

**关键区别在最后两行**：刑事犯罪要求「以营利为目的」，民事侵权不要求。

所以：

- **不赚钱** ≠ 不违法，只是停在民事责任
- **赚钱** = 民事 + 可能刑事，风险高一个量级

## 二、行为风险分级

这是本文最实用的一张表。按「你自己做 → 给别人看 → 拿去赚钱」的顺序排列。

| 行为 | 是否侵权 | 民事风险 | 刑事风险 | 说明 |
| --- | --- | --- | --- | --- |
| **自己下载、自己看** | 通常是（复制行为），但实际极少被追究 | 极低 | 无 | 处于「合理使用」与「私人使用」的灰色地带，实务中不追 |
| 看盗版电影、听盗版音乐 | 使用行为本身一般不单独追责 | 极低 | 无 | 但**上传/分享的人**责任完全不同 |
| 下载后**自己收藏、不外传** | 同上 | 极低 | 无 | 关键在「不外传」 |
| **搬运**（把别人的视频/文章原样转到自己账号） | **侵权** | 中—高 | 一般无（除非营利） | 最常见的学生风险 |
| **二次剪辑/混剪** | 可能侵权（改编权、信息网络传播权） | 中 | 低 | 看使用比例和是否「转换性使用」 |
| **汉化、字幕组** | **侵权**（翻译权、信息网络传播权） | 中—高 | 一般无（除非营利） | 「不收费」不免责 |
| **网盘分享资源**（影视、电子书、课程） | **侵权** | **高** | **可能**（情节严重时） | 最大风险区 |
| 建「资源号」靠资源引流 | **侵权** + 可能不正当竞争 | 高 | **可能** | 引流本身可被视为「间接获利」 |
| **商用**（挂广告、卖会员、卖资源） | **侵权** | 高 | **高** | 直接落入刑事构成要件 |
| 论文/作业引用他人内容 | 可能侵权，但通常属合理使用 | 低 | 无 | 看引用比例和是否注明 |
| 社团活动放映电影 | 可能侵权（放映权） | 中 | 无 | 「非营利」不等于合理使用 |

**读这张表的方法**：不看「是否赚钱」，看「是否让作品到达了原本不会到达的人」。

## 三、合理使用：边界比你想的窄

「合理使用」是唯一的合法出口。但它的条件很严格。

> 第二十四条　在下列情况下使用作品，可以不经著作权人许可，不向其支付报酬，但应当指明作者姓名或者名称、作品名称，并且不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益：
>
> （一）为个人学习、研究或者欣赏，使用他人已经发表的作品；
> （二）为介绍、评论某一作品或者说明某一问题，在作品中适当引用他人已经发表的作品；
> （三）为报道新闻，在报纸、期刊、广播电台、电视台等媒体中不可避免地再现或者引用已经发表的作品；
> ……
> （六）为学校课堂教学或者科学研究，翻译、改编、汇编、播放或者少量复制已经发表的作品，供教学或者科研人员使用，但不得出版发行；
> ……
>
> 【法规】《中华人民共和国著作权法》（2020 年修正）第二十四条

### 3.1 三个必须同时满足的条件

法条开头有一句总纲，很多人忽略：

> 「但应当**指明作者姓名或者名称、作品名称**，并且**不得影响该作品的正常使用**，也**不得不合理地损害著作权人的合法权益**」

这是「三步检验法」，三个条件**同时**满足才算合理使用。

| 条件 | 意思 | 学生常踩的坑 |
| --- | --- | --- |
| 指明作者和作品名 | 要标注出处 | 搬运时不标来源 |
| 不影响正常使用 | 不能替代原作品的市场 | 上传全集资源，别人就不用买了 |
| 不损害合法权益 | 不能造成实质损害 | 「免费分享」也会损害 |

**第二、三条是「网盘分享」的致命处**：你把一部电影传到网盘公开分享，即使不收费，也已经「影响了该作品的正常使用」——因为想看的不用再买会员了。

### 3.2 逐项对照学生场景

| 场景 | 是否合理使用 | 为什么 |
| --- | --- | --- |
| 为写论文下载几篇文献 | **是**（第（一）项，个人学习研究） | 已发表作品，个人使用 |
| 论文里引用他人观点并注明 | **是**（第（二）项，适当引用） | 指明出处，引用适度 |
| 论文里大段照搬不注明 | **不是** | 超出「适当引用」，且构成抄袭 |
| 课程作业里用他人图片 | **通常是**（第（一）项） | 内部使用，不公开传播 |
| 把课程作业发到网上 | **可能不是** | 变成向公众传播了 |
| 老师课堂播放电影片段 | **通常是**（第（六）项） | 课堂教学，少量 |
| 社团活动公开放映整部电影 | **通常不是** | 超出课堂教学，且是「放映」 |
| 在公众号写影评并配海报 | **通常是**（第（二）项） | 介绍评论，适当引用 |
| 在公众号发完整影片 | **不是** | 不是「适当引用」 |
| 汉化组翻译漫画并发布 | **不是** | 涉及翻译权和信息网络传播权，且面向公众 |
| 做字幕给已购影片自己看 | **较可能是** | 个人使用，不传播 |
| 做字幕并发布到字幕站 | **不是** | 向公众传播 |
| 毕设做的动画用了别人的 BGM | **看情况** | 校内展示通常可；公开发布/参赛则可能不行 |
| 用 AI 生成的图片做推文 | 另有规则 | AI 生成物的著作权归属本身有争议，见第 3.4 节 |

### 3.3 「个人学习」不等于「可以随便传」

这是「合理使用」被误用最多的一项。

第（一）项写的是「**为个人**学习、研究或者欣赏，**使用**他人已经发表的作品」。

拆开：

- **为个人** = 使用范围限于你自己
- **使用** = 使用行为，不是「传播行为」

**所以：**
「我下载是为了学习」→ 可能成立
「我下载后传到网盘给大家学习」→ **不成立**。这已经不是「个人使用」，是「向公众提供」。

### 3.4 关于 AI 生成内容

AI 生成内容的著作权归属，目前法律和司法实践仍在发展中。以下只作提示，不给结论：

| 问题 | 目前状况 |
| --- | --- |
| AI 生成的图有没有著作权 | 有争议。多数观点认为需体现人的独创性投入才可能受保护 |
| 用 AI 图商用会不会侵权 | 可能侵犯他人权利（如训练数据来源、风格模仿） |
| 用 AI 仿某画师风格 | 法律上不明确，但平台规则和行业惯例通常禁止 |

**这一领域变化快**，涉及具体纠纷时应咨询专业律师，不要依赖网上的说法。

## 四、民事与刑事的分界

### 4.1 刑事：侵犯著作权罪

> 第二百一十七条　以营利为目的，有下列侵犯著作权或者与著作权有关的权利的情形之一，违法所得数额较大或者有其他严重情节的，处三年以下有期徒刑，并处或者单处罚金；违法所得数额巨大或者有其他特别严重情节的，处三年以上十年以下有期徒刑，并处罚金：
>
> （一）未经著作权人许可，复制发行、通过信息网络向公众传播其文字作品、音乐、美术、视听作品、计算机软件及法律、行政法规规定的其他作品的；
> ……
>
> 【法规】《中华人民共和国刑法》第二百一十七条（2020 年《刑法修正案（十一）》修改）

### 4.2 构成要件的四个关键词

| 要件 | 意思 | 关键点 |
| --- | --- | --- |
| **以营利为目的** | 为了赚钱 | **这是与民事侵权的分水岭** |
| 未经许可 | 没得到授权 | 绝大多数学生场景都满足 |
| 复制发行 / 通过信息网络传播 | 上传、分享、提供下载 | 「网盘分享」正好落在这里 |
| **违法所得数额较大** 或 **其他严重情节** | 达到司法解释规定的门槛 | 具体数额见 4.3 |

### 4.3 具体门槛

「违法所得数额较大」「其他严重情节」的具体标准由司法解释规定。

> **现行司法解释**：最高人民法院、最高人民检察院《关于办理侵犯知识产权刑事案件适用法律若干问题的解释》（**法释〔2025〕5 号**，2025 年 4 月 26 日起施行）。
>
> 该解释取代了此前的多个版本，对「违法所得数额较大」「非法经营数额」「复制品数量」、以及网络传播中的「作品数量、下载次数、点击量」等设定了具体标准。
>
> **本文不逐一列举具体数字**，理由：(1) 数额标准按作品类型（文字、音乐、影视、软件）分档，条件复杂；(2) 读者真正需要知道的是「有没有踩线」，而精准判断需要律师；(3) 引用具体数字容易脱离上下文被误用。
>
> 各作品类型对应的具体数额门槛，请查阅法释〔2025〕5 号原文。
>
> **正确表述**：「达到司法解释规定的『违法所得数额较大』或『其他严重情节』标准」。
>
> **如需具体数字**：查阅现行司法解释原文，或咨询律师。

### 4.4 特别注意「以营利为目的」的认定

「营利」不一定是「直接收费」。司法解释和实践中，以下情形可能被认定为「以营利为目的」：

| 情形 | 是否可能被认定 |
| --- | --- |
| 直接卖资源、卖会员 | 是 |
| 挂广告、靠流量分成 | **可能**（间接获利） |
| 用免费资源引流到付费业务 | **可能** |
| 用资源涨粉后接商单 | **可能** |
| 纯分享，不挂任何广告，不引流 | 通常不构成 |
| 收「打赏」 | **可能** |

**「资源号」为什么危险**：它的商业模式就是「用免费资源换流量，用流量变现」。这个链条在法律上就是「以营利为目的」。

## 五、学生最容易踩的四个场景

### 5.1 搬运：把别人的内容原样转到自己账号

**这是最普遍、也最容易被追究的一种。**

| 你的想法 | 法律的看法 |
| --- | --- |
| 「我注明了出处」 | 注明出处不等于获得许可。第（二）项的「适当引用」要求是「介绍、评论、说明问题」，不是「完整搬运」 |
| 「我是帮原作者传播」 | 未经许可的传播就是侵权，动机不影响 |
| 「原视频没写禁止转载」 | 没有「禁止转载」声明 ≠ 授权转载 |
| 「我是学生，不算商业」 | 学生身份不是免责事由 |

**判断标准**：你转的是「一小段用于评论」，还是「整个作品」？前者可能是合理使用，后者几乎一定不是。

### 5.2 汉化、字幕组

**这一类的法律问题最清楚**：

| 行为 | 涉及的权利 |
| --- | --- |
| 翻译外文作品 | **翻译权**（属于著作财产权） |
| 制作字幕 | 涉及翻译权、改编权 |
| 发布到网上 | **信息网络传播权** |
| 压制、封装 | 复制权 |

**「我们不收费」为什么不构成合理使用**：

因为第（一）项要求「为**个人**使用」。一个汉化组把作品发布给几万人下载，无论如何不是「个人使用」。第（二）项要求「适当引用」，而完整翻译不是引用。

**实务上的现实**：汉化组被追究刑事责任的案例相对少见（因为多数不直接收费），但**民事侵权风险明确存在**，权利人发律师函、要求下架是常见做法。

### 5.3 网盘分享资源

**这是风险最高的一类**，因为它同时满足：

| 要素 | 你的情况 |
| --- | --- |
| 未经许可 | 是 |
| 通过信息网络传播 | 是（网盘链接） |
| 影响作品正常使用 | 是（别人不用买了） |
| 可能被认定营利 | 看是否引流/挂广告 |

**几个常见的自我安慰，逐条回应：**

| 说法 | 实际 |
| --- | --- |
| 「我只是分享，不是卖」 | 侵权不以营利为前提 |
| 「链接是私密的，只有群里的人能看到」 | 「特定范围」也可能构成「公众」。几百人的群不是私人范围 |
| 「分享完就删了」 | 传播已经发生 |
| 「网盘平台没管，应该没事」 | 平台不管不等于合法；平台接到通知后会删，并且会提供你的信息 |
| 「资源是别人传的，我只是转链接」 | 转链接也可能构成帮助侵权或直接侵权 |

**另外要注意**：网盘平台会配合权利人投诉，并在必要时提供上传者信息。所谓「匿名」是相对的。

### 5.4 商用：风险最高的一档

| 行为 | 风险 |
| --- | --- |
| 自媒体挂广告用他人素材 | 高。广告收入 = 营利 |
| 卖「资源合集」 | 高。直接营利 |
| 用他人图片做商品/周边 | 高。涉及复制、发行 |
| 用他人音乐做视频 BGM 并开通收益 | 高 |
| 接单帮人做设计，用了未授权素材 | 高。你是交付方，责任在你 |

**「商用素材哪里找」是正确的问题**，而不是「怎么用才不被发现」。可用的来源包括：CC0/公共领域素材、明确授权的免费图库、购买授权、自己拍摄。

## 六、被投诉了怎么办

按顺序处理，**不要拖，也不要硬扛**。

### 第一步：立即停止并下架

不管你认为自己有没有侵权，**先下架**。

理由很实际：

- 侵权损害在持续扩大，下架能止损
- 平台的处理逻辑是「先处理，后申诉」；不下架可能被封号
- 后续协商时，「已及时删除」是有利情节

### 第二步：判断对方是谁、要什么

| 对方 | 常见诉求 |
| --- | --- |
| 平台（通知你违规） | 下架、扣分、封号 |
| 权利人（律师函） | 停止侵权 + 赔偿 + 道歉 |
| 权利人（平台投诉） | 下架 |
| 权利人（起诉） | 赔偿 + 诉讼费 |

**律师函不等于起诉。** 很多律师函的目的是促成和解。但**不要无视**——无视会导致对方直接起诉。

### 第三步：不要自己回复律师函

**这是最重要的一条。** 你自己回复的内容可能成为对你不利的证据（比如承认了侵权事实、承认了获利金额）。

正确做法：把律师函给律师看，由律师回复。

### 第四步：评估自己的处境

| 你的情况 | 大致处境 |
| --- | --- |
| 个人使用，未传播 | 风险很低 |
| 少量搬运，无营利，已删除 | 通常是民事，赔偿额不高，可能和解 |
| 大量搬运，有广告收入 | 赔偿额可能较高，需认真对待 |
| 卖资源、规模化 | 可能涉刑事，**必须找律师** |

### 第五步：和解的注意事项

如果要和解：

- 书面协议，写清「赔偿金额」「停止侵权行为」「双方权利义务终结」
- 不要签「承认犯罪」类表述
- 保留付款凭证
- **金额较大的和解，必须让律师看协议**

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「不赚钱就不算侵权」 | 侵权不以营利为前提。营利影响的是刑事风险和赔偿额 |
| 「注明了出处就没事」 | 注明出处是合理使用的条件之一，不是全部；完整搬运仍侵权 |
| 「原作者没写禁止转载」 | 没写禁止 ≠ 授权 |
| 「我删了就没事了」 | 删了能止损，但已发生的侵权责任不消失 |
| 「网盘私密链接不算公开传播」 | 群里几百人分享，通常已构成向公众传播 |
| 「汉化不收费是做好事」 | 涉及翻译权和信息网络传播权，动机不影响定性 |
| 「学生身份会从轻」 | 可能影响赔偿额，不免责 |
| 「社团活动非营利就能放电影」 | 超出「课堂教学」范围，可能侵犯放映权 |
| 「平台没删就是合法的」 | 平台未发现不等于合法 |
| 「截图/录屏就不算复制」 | 截图也是复制 |
