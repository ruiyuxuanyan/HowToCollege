# 合同基本常识：签字前该看哪几条

> 一句话概括：不用懂法律，但要会找那五个要命的条款。

**适用人群**：第一次租房、签实习协议、办健身卡、签培训合同的大学生；任何需要「看都没看就签字」的场合。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国民法典》合同编（第四百六十四条起、第四百六十九条、第四百九十六条、第四百九十七条、第五百八十五条、第五百八十六条至第五百八十八条、第五百六十二条至第五百六十三条、第五百零六条）
> - 全国统一：民法典全国适用
> - 核查日期：2026-11-05
> - 已知变化：民法典自 2021 年 1 月 1 日施行，取代原《合同法》
>
> ⏳ 易过时：无（合同法基本规则稳定）。本文被 05-06 租房、10-03 劳动合同、04-05 实习协议引用。

## 一、签字前必看的五处

这是本文的核心。**记不住法条没关系，记住这五个位置。**

| 序号 | 看什么 | 找什么 | 危险信号 |
| --- | --- | --- | --- |
| 1 | **金额与支付方式** | 总价、单价、付款时间、付款方式、有没有其他费用 | 只写「另计」不写金额；有多项附加费用；要求一次性付清长期费用 |
| 2 | **期限** | 起止日期、续期规则、**自动续费** | 自动续期条款；续期需提前很久通知；长期合同（如三年健身卡） |
| 3 | **违约责任** | 违约金比例、谁对谁违约、赔偿范围 | 只约定你的违约责任，不约定对方的；违约金畸高 |
| 4 | **解除条件** | 能不能退、怎么退、退多少、要多久 | 只写「经双方协商一致可解除」；退费按「原价」折算；无解除权 |
| 5 | **争议解决** | 去哪起诉、仲裁还是诉讼、适用什么法律 | 约定在对方所在地法院；约定仲裁（成本高于诉讼）；约定不明的「提交相应主管部门」 |

### 1.1 为什么是这五处

因为**纠纷几乎总是发生在这五处**。

| 纠纷 | 对应条款 |
| --- | --- |
| 「说好 2000，怎么变成 3500」 | 金额与支付方式 |
| 「我不想续了，怎么又扣钱了」 | 期限/自动续费 |
| 「我不想租了，押金不退」 | 解除条件 |
| 「我违约要赔三个月房租，他违约什么都不赔」 | 违约责任 |
| 「要去他所在的城市打官司，成本比争议金额还高」 | 争议解决 |

**签之前，用手机拍下这五处。**事后争议时，这是最直接的依据。

## 二、合同成立的要素

法律上，一个合同要包含什么？

> 第四百七十条　合同的内容由当事人约定，一般包括下列条款：
>
> （一）当事人的姓名或者名称和住所；
> （二）标的；
> （三）数量；
> （四）质量；
> （五）价款或者报酬；
> （六）履行期限、地点和方式；
> （七）违约责任；
> （八）解决争议的方法。
>
> 【法规】《中华人民共和国民法典》第四百七十条

**注意「一般包括」这四个字**：这些不是强制要件。缺了某几项，合同仍然可能成立。

### 2.1 合同什么时候成立

> 第四百六十九条　当事人订立合同，可以采用书面形式、口头形式或者其他形式。
>
> 书面形式是合同书、信件、电报、电传、传真等可以有形地表现所载内容的形式。
>
> 以电子数据交换、电子邮件等方式能够有形地表现所载内容，并可以随时调取查用的数据电文，视为书面形式。
>
> 【法规】《中华人民共和国民法典》第四百六十九条

**关键：口头合同也有效。**

| 形式 | 是否有效 | 问题在哪 |
| --- | --- | --- |
| 书面合同 | 有效 | 最清楚 |
| 微信聊天达成的一致 | **有效**（数据电文视为书面） | 需要保存完整记录 |
| 口头约定 | **有效** | **举证极难** |
| 没有约定（只有行为） | 可能成立（事实合同） | 条款不明，全靠法律补充 |

**所以「我们只是口头说好」不代表没有合同，只代表出了事你很难证明说好的是什么。**

## 三、格式条款：最需要警惕的一类

### 3.1 什么是格式条款

> 第四百九十六条　格式条款是当事人为了重复使用而预先拟定，并在订立合同时未与对方协商的条款。
>
> 采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则确定当事人之间的权利和义务，并采取合理的方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款，按照对方的要求，对该条款予以说明。提供格式条款的一方未履行提示或者说明义务，致使对方没有注意或者理解与其有重大利害关系的条款的，对方可以主张该条款不成为合同的内容。
>
> 【法规】《中华人民共和国民法典》第四百九十六条

### 3.2 你的三项权利

| 权利 | 依据 | 意思 |
| --- | --- | --- |
| 要求**提示** | 第四百九十六条第二款 | 对方必须用合理方式提醒你注意重要条款（加粗、单独签字确认等） |
| 要求**说明** | 同上 | 你可以要求对方解释 |
| 主张条款**不成为合同内容** | 同上 | 对方没提示没说清，你可以主张那一条对你无效 |

**第三项是最有力的**：不是「条款无效」，是「这条根本没进合同」。效果一样，但主张路径更简单。

### 3.3 格式条款无效的三种情形

> 第四百九十七条　有下列情形之一的，该格式条款无效：
>
> （一）具有本法第一编第六章第三节和本法第五百零六条规定的无效情形；
> （二）提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利；
> （三）提供格式条款一方排除对方主要权利。
>
> 【法规】《中华人民共和国民法典》第四百九十七条

逐项对照常见合同：

| 你看到的条款 | 违反哪一项 |
| --- | --- |
| 「本店对服务过程中发生的任何人身伤害概不负责」 | 第（一）项 + 第五百零六条（造成人身损害的免责条款无效） |
| 「本公司对任何损失不承担赔偿责任」 | 第（二）项，不合理免除自己责任 |
| 「一经售出，概不退换」 | 第（二）项/第（三）项，限制/排除主要权利 |
| 「最终解释权归本公司所有」 | 第（二）项，单方解释权 |
| 「如有争议，以本公司记录为准」 | 第（三）项，排除对方举证权利 |
| 「学员不得以任何理由要求退费」 | 第（三）项，排除解除权 |

**「最终解释权归本公司」这句话，在法律上是无效的。** 但它在合同里出现了几十年，因为绝大多数人不知道。

### 3.4 一个必须知道的限制

格式条款无效需要**你主张**。法院不会主动替你发现。

也就是说：

- 合同里有无效条款，不代表合同自动作废
- 你要在纠纷中明确提出「这一条无效」
- 如果你不提，可能就被按那条执行了

## 四、定金与订金：一字之差

这是最经典、也最容易吃亏的一组。

### 4.1 定金（有法律效力）

> 第五百八十六条　当事人可以约定一方向对方给付定金作为债权的担保。定金合同自实际交付定金时成立。
>
> 定金的数额由当事人约定，但是不得超过主合同标的额的百分之二十，超过部分不产生定金的效力。实际交付的定金数额多于或者少于约定数额的，视为变更约定的定金数额。
>
> 【法规】《中华人民共和国民法典》第五百八十六条

> 第五百八十七条　债务人履行债务的，定金应当抵作价款或者收回。给付定金的一方不履行债务或者履行债务不符合约定，致使不能实现合同目的的，无权请求返还定金；收受定金的一方不履行债务或者履行债务不符合约定，致使不能实现合同目的的，应当双倍返还定金。
>
> 【法规】《中华人民共和国民法典》第五百八十七条

**「定金罚则」：**

| 谁违约 | 后果 |
| --- | --- |
| 付定金的一方（你）违约 | **定金不退** |
| 收定金的一方（对方）违约 | **双倍返还** |

**两个限制**：

1. 定金不得超过主合同标的额的 **20%**，超过部分不产生定金效力
2. 定金合同自**实际交付**时成立（没交钱，定金条款不生效）

### 4.2 订金（没有定金效力）

**「订金」不是法律术语**，法律上没有规定它的效力。

实务中通常被理解为**预付款**：

| 情况 | 通常处理 |
| --- | --- |
| 你不想买了 | 可以要求返还（不是「罚没」） |
| 对方不卖了 | 返还订金，但**不双倍** |

### 4.3 对比表

| | 定金 | 订金 |
| --- | --- | --- |
| 法律依据 | 民法典第五百八十六、五百八十七条 | 无专门规定 |
| 是否适用「罚则」 | **是**（不退 / 双倍返还） | 否 |
| 你违约 | 定金不退 | 通常可退 |
| 对方违约 | 双倍返还 | 通常只返还本金 |
| 上限 | 主合同标的额的 20% | 无 |
| 是否需实际交付 | 是 | 通常也是 |

**这一节的实用价值**：签合同付钱时，**看清单子上写的是哪个字**。

- 你交了「定金」，又反悔 → 钱可能要不回来
- 你交了「订金」，又反悔 → 通常能要回来

**如果对方写的是「定金」而你想保留退路**：要求改成「订金」或「预付款」，或者把退款条件写进合同。

## 五、违约金：能调，但别指望

### 5.1 法条

> 第五百八十五条　当事人可以约定一方违约时应当根据违约情况向对方支付一定数额的违约金，也可以约定因违约产生的损失赔偿额的计算方法。
>
> 约定的违约金低于造成的损失的，人民法院或者仲裁机构可以根据当事人的请求予以增加；约定的违约金过分高于造成的损失的，人民法院或者仲裁机构可以根据当事人的请求予以适当减少。
>
> 【法规】《中华人民共和国民法典》第五百八十五条

### 5.2 「过分高于」怎么理解

**法律没有给一个固定比例。**实务中通常参照「违约金是否明显超过实际损失」来判断。

**这属于需要个案判断的问题，本文不给具体倍数。** 正确的做法是：如果你认为违约金过高，可以请求法院或仲裁机构减少，但要举证证明「实际损失远低于违约金」。

### 5.3 学生最常见的违约金场景

| 场景 | 常见约定 | 要注意什么 |
| --- | --- | --- |
| 租房提前退租 | 押金不退 + 一个月租金 | 「押金」和「违约金」是否重复计算 |
| 培训课程退费 | 按「原价」扣除已上课时 | 原价与折后价，差别很大 |
| 健身卡退卡 | 扣手续费 30%–50% | 是否属于「不合理加重对方责任」 |
| 实习协议提前离职 | 赔「招聘成本」 | 需要对方举证实际损失 |
| 三方协议违约 | 违约金（见 09-01） | 金额是否合理、是否有实际损失 |

## 六、解除：能不能退，怎么退

### 6.1 两种解除

| 类型 | 依据 | 意思 |
| --- | --- | --- |
| **协商解除** | 第五百六十二条 | 双方谈成就能解除 |
| **法定解除** | 第五百六十三条 | 满足法定情形，单方就能解除 |

> 第五百六十三条　有下列情形之一的，当事人可以解除合同：
>
> （一）因不可抗力致使不能实现合同目的；
> （二）在履行期限届满前，当事人一方明确表示或者以自己的行为表明不履行主要债务；
> （三）当事人一方迟延履行主要债务，经催告后在合理期限内仍未履行；
> （四）当事人一方迟延履行债务或者有其他违约行为致使不能实现合同目的；
> （五）法律规定的其他情形。
>
> 【法规】《中华人民共和国民法典》第五百六十三条

### 6.2 学生最需要的一条

第（四）项：「**当事人一方迟延履行债务或者有其他违约行为致使不能实现合同目的**」。

这一条是很多退费争议的依据。举例：

- 报了培训班，机构停课、换老师、大幅缩减课时 → 可能致使合同目的不能实现
- 租的房子无法居住（漏水、断电、被查封）→ 同上
- 健身房搬迁到很远的地方 → 可能同上

**但「我不想学了」不属于法定解除事由。** 这只能走协商解除，或按合同约定的解除条款。

### 6.3 解除后怎么算钱

> 第五百六十六条　合同解除后，尚未履行的，终止履行；已经履行的，根据履行情况和合同性质，当事人可以请求恢复原状或者采取其他补救措施，并有权请求赔偿损失。
>
> 【法规】《中华人民共和国民法典》第五百六十六条

通俗说：**没消费的部分应该退，已消费的部分按实际情况结算。**

这就是为什么「按原价折算」的退费条款常常被质疑——它把已消费部分按高于实际成交价的标准计算，实质上多扣了钱。

## 七、合同纠纷属于哪一类责任

签合同出问题，绝大多数是**民事**。但要知道边界在哪。

| 层次 | 是否常见 | 表现 |
| --- | --- | --- |
| **民事** | **绝大多数** | 违约、赔偿、解除、退费。走协商、起诉、仲裁 |
| **行政** | 少数情形 | 消费类可向市场监管部门投诉（12315）；特定行业有行政处罚 |
| **刑事** | 少数情形 | 不是「不履行合同」，而是「一开始就打算骗」 |

**区分民事违约与刑事诈骗的关键**：

| | 民事违约 | 合同诈骗 |
| --- | --- | --- |
| 签订时的心态 | 想履行，但履行不了 | **一开始就没打算履行** |
| 典型表现 | 拖欠、质量不符、单方涨价 | 虚构主体、收钱跑路、根本没打算提供服务 |
| 后果 | 赔钱、解除合同 | 可能构成犯罪 |

**这一节的实际意义**：「他违约了，能不能报警抓他」——通常不能。违约是民事纠纷，报警后警方一般会引导你走诉讼或调解。**只有当对方从一开始就是骗，才可能进入刑事程序。** 这也是为什么签合同前要核对对方身份（见第九节）。

## 八、不要签空白合同

这一条单独拿出来说，因为它造成的损失往往最大。

### 8.1 什么是空白合同

| 形式 | 例子 |
| --- | --- |
| 金额栏空白 | 「金额回头填」 |
| 期限栏空白 | 「日期先空着」 |
| 附件缺失 | 「附件后面补给你」 |
| 只签一页，其余页未填 | 「先签，内容我们统一打印」 |
| 电子合同只让你点「同意」不给看全文 | 隐藏在链接里 |

### 8.2 为什么危险

因为**举证责任在你**。

合同上有你的签字，法律上推定你认可全部内容。你要主张「签字时这里是空的」，需要举证——而这个举证极难。

### 8.3 三条硬规则

1. **不签任何有空白的合同**。空白处要么划掉，要么填上
2. **每一页都签字或按手印**（防止换页）
3. **签字后当场拿到一份原件或完整副本**

**第三条经常被忽略**：「合同我们收着，你需要再要」——这句话意味着你手里没有任何证据。

### 8.4 关于电子合同

电子合同同样有效（第四百六十九条）。要注意：

- 完整阅读，不要直接滑到底点同意
- 保存完整截图（含条款正文，不只是签署页）
- 保存签署时间和对方的确认通知
- 保存邮件/短信中的合同链接和附件

## 九、签字前的通用动作

### 9.1 五个动作

| 动作 | 为什么 |
| --- | --- |
| **逐页拍照** | 防止事后被换页、篡改 |
| **要求给副本** | 没有副本等于没有证据 |
| **核对对方身份** | 公司名与营业执照是否一致；个人要身份证 |
| **在空白处划线** | 防止事后添加内容 |
| **不当天决定** | 任何催你「今天必须签」的，都值得警惕 |

### 9.2 关于「核对对方身份」

| 对方 | 怎么核 |
| --- | --- |
| 公司 | 国家企业信用信息公示系统（`www.gsxt.gov.cn`）查营业执照、经营范围、是否存续 |
| 个人（房东） | 要求看身份证 + 房产证（名字要一致） |
| 中介 | 查备案；确认是「居间」还是「代理」 |
| 培训机构 | 查办学许可证 |

**最容易踩的坑**：签约主体和收款主体不是同一个。比如合同和 A 公司签，钱打给 B 个人账户。这种情况下，出事后你很难向 A 主张。

**规则：钱打给谁，就和谁签合同。**

## 十、常见误区

| 误区 | 实际 |
| --- | --- |
| 「口头说好就行，不用写」 | 口头合同有效，但举证极难。写下来是保护自己 |
| 「签了字就一定要照做」 | 无效条款、可撤销情形、法定解除权都可能改变结果 |
| 「格式条款都是有效的」 | 第四百九十七条列举了三类无效情形 |
| 「『最终解释权归本店』有效」 | 属于排除对方主要权利，通常无效 |
| 「定金和订金一样」 | 定金适用罚则，订金通常只是预付款 |
| 「违约金写多少就要赔多少」 | 过分高于损失可以请求减少（第五百八十五条） |
| 「签了合同就不能退」 | 有协商解除和法定解除两条路 |
| 「空白处对方会按说好的填」 | 举证责任在你，不要签空白 |
| 「合同我不用拿，对方有就行」 | 你没有任何证据 |
| 「电子合同不算合同」 | 数据电文视为书面形式（第四百六十九条） |
| 「对方是大公司，不会坑我」 | 格式条款正是大公司拟的 |

## 十一、可执行清单

### 签字前（照着做）

- [ ] 找到并读懂五处：金额 / 期限 / 违约责任 / 解除条件 / 争议解决
- [ ] 检查有没有**自动续费**条款
- [ ] 检查退费/退款条款（能不能退、怎么算）
- [ ] 检查违约金比例是否畸高
- [ ] 检查争议解决地是否在对方所在地
- [ ] 检查所有空白处：要么填上，要么划掉
- [ ] 核对签约主体与收款主体是否一致
- [ ] 拍照（每一页）
- [ ] 要求当场给一份原件或完整副本

### 签字时

- [ ] 每一页签字/按手印
- [ ] 在金额、期限等关键处按手印（部分场景）
- [ ] 不要在空白纸上签字（包括「签到表」以外的任何空白纸）
- [ ] 不要在未填完的合同上签字

### 签字后

- [ ] 保存合同原件 + 电子扫描件
- [ ] 保存付款凭证（转账记录、收据、发票）
- [ ] 保存所有沟通记录（微信、邮件、通话录音）
- [ ] 记下关键日期（起止日、续费日、退费申请截止日）

### 遇到不合理条款时

- [ ] 先问：「这一条是什么意思？」（要求说明）
- [ ] 要求书面修改或补充协议
- [ ] 不改就不签（口头承诺不算修改）
- [ ] 已签的，保留当时「未被提示」的证据（如合同未加粗该条款）
