# 打架与寻衅滋事：从口角到刑事的距离

> 一句话概括：法律上的「轻伤」并不轻，一拳可能就是三年。

**适用人群**：宿舍矛盾、球场冲突、酒桌上容易上头的大学生；被人打了想「打回去」的人；已经动过手、正在担心后果的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国刑法》第二百三十四条、第二百九十三条、第二十条；《中华人民共和国治安管理处罚法》；《人体损伤程度鉴定标准》（司法部等五部门联合发布，2014 年 1 月 1 日施行）
> - 全国统一：刑法与《人体损伤程度鉴定标准》全国统一适用；治安处罚的具体裁量各地有差异
> - 核查日期：2026-11-05
> - 已知变化：该法曾多次修改，**本文所引条款序号以 2012 年修正版为准，现行版本序号是否变化未能核实**，引用前请查阅现行文本
>
> ⏳ 易过时：治安管理处罚法的条款序号、各地对「情节恶劣」的认定口径。

## 一、三种后果，先分清在哪一层

打架的法律后果不是「一个」，是三条完全不同的轨道。走哪条，取决于**对方伤到什么程度**。

| 对方伤情 | 性质 | 依据 | 后果 |
| --- | --- | --- | --- |
| 没有伤，或很轻微 | 治安违法 | 《治安管理处罚法》关于殴打他人的规定 | 拘留、罚款 |
| **轻微伤** | 治安违法 | 同上 | 拘留、罚款（可能顶格） |
| **轻伤**（一级/二级） | **刑事** | 《刑法》第二百三十四条 | 三年以下有期徒刑、拘役或者管制 |
| **重伤**（一级/二级） | 刑事，加重 | 同上第二款 | 三年以上十年以下 |
| 死亡，或以特别残忍手段致重伤造成严重残疾 | 刑事，最重 | 同上第二款 | 十年以上、无期或死刑 |

**这张表最需要记住的是第三行**：

> 轻伤 = 刑事 = 留下犯罪记录。

不是「赔钱就完事」，不是「学校处理一下就过去」。轻伤是刑事案件，进了刑事程序，后面所有事都跟着变。

## 二、「轻伤」在法律上到底有多重

这是本文最重要的一节。绝大多数人对「轻伤」的理解完全错误。

### 2.1 日常语义与法律语义

| 日常说法 | 法律上的对应 |
| --- | --- |
| 「就是擦破点皮」 | 一般不构成伤情等级，或属轻微伤 |
| 「流了点血，不严重」 | 可能是轻微伤，也可能已达轻伤 |
| 「养几天就好了」 | **完全可能是轻伤** |
| 「没住院，不算伤吧」 | **伤情等级与是否住院无关** |
| 「骨头没断就没事」 | 部分骨折只是轻微伤，但没有骨折也可能达轻伤 |

**关键：伤情等级由《人体损伤程度鉴定标准》按具体损伤情形对照认定，不看你主观感觉，也不看恢复快慢。**

### 2.2 大致的感觉

《人体损伤程度鉴定标准》把伤情分为**重伤一级、重伤二级、轻伤一级、轻伤二级、轻微伤**五级。损伤程度从重到轻排列。

从实际鉴定结果看，以下情形常被认定为轻伤（**具体以鉴定机构对照标准作出的结论为准**）：

- 多数需要复位或固定的骨折
- 牙齿脱落达到标准规定枚数
- 面部创口达到标准规定长度，或遗留明显瘢痕
- 听力、视力的一定程度损害
- 鼻骨粉碎性骨折、双侧鼻骨骨折等

而以下情形常属轻微伤：

- 软组织挫伤、擦伤
- 单个鼻骨骨折
- 口腔黏膜破损

**注意这个落差**：一次推搡，对方倒地时用手撑地造成手腕骨折，鉴定可能就是轻伤二级。你的主观意图是「推一下」，法律后果是「故意伤害罪」。

**法律看的是结果，不是你的意图有多轻。** 意图影响量刑，不影响定罪。

### 2.3 谁来做鉴定

伤情鉴定由**有资质的司法鉴定机构**作出，通常在案件进入公安或司法程序后由办案机关委托。

这意味着两件事：

- 你自己去医院开的诊断书**不等于**伤情鉴定意见
- 「我觉得没那么严重」在法律上没有意义，要等鉴定结论

**这也意味着：一旦报警并进入程序，伤情等级不由双方协商决定。**

## 三、寻衅滋事：比你以为的宽

很多人以为「寻衅滋事」是「无事生非、街头斗殴」才构成。实际上它的适用范围比想象中宽，而且**校园场景完全可能落入**。

> 第二百九十三条　有下列寻衅滋事行为之一，破坏社会秩序的，处五年以下有期徒刑、拘役或者管制：
>
> （一）随意殴打他人，情节恶劣的；
> （二）追逐、拦截、辱骂、恐吓他人，情节恶劣的；
> （三）强拿硬要或者任意损毁、占用公私财物，情节严重的；
> （四）在公共场所起哄闹事，造成公共场所秩序严重混乱的。
>
> 纠集他人多次实施前款行为，严重破坏社会秩序的，处五年以上十年以下有期徒刑，可以并处罚金。
>
> 【法规】《中华人民共和国刑法》第二百九十三条

逐项对照校园场景：

| 法条项 | 校园里的样子 |
| --- | --- |
| （一）随意殴打他人 | 因为「看他不顺眼」「他多看了我一眼」动手；帮朋友「撑场面」去打人 |
| （二）追逐、拦截、辱骂、恐吓 | 堵在宿舍门口不让走；群里长期辱骂恐吓；跟踪纠缠 |
| （三）强拿硬要、任意损毁占用 | 强行「借」同学的东西不还；砸宿舍门、砸车、毁坏他人物品 |
| （四）公共场所起哄闹事 | 食堂、操场、校门口聚众闹事造成秩序混乱 |

### 3.1 「随意」这两个字是关键

第（一）项写的是「**随意**殴打他人」。这个「随意」是寻衅滋事与故意伤害的核心区别：

| | 故意伤害（234 条） | 寻衅滋事（293 条） |
| --- | --- | --- |
| 起因 | 有具体矛盾（欠钱、口角、感情纠纷） | 无事生非，或极小的事由 |
| 对象 | 特定的人 | 可能不特定，或针对「看不顺眼」的人 |
| 核心 | 伤害结果 | 破坏社会秩序 |
| 入罪门槛 | **达到轻伤** | **情节恶劣**（不要求轻伤） |

**最需要注意的一点**：寻衅滋事**不要求造成轻伤**。「情节恶劣」就可以构成，比如多次随意殴打、持凶器、在公共场所殴打、造成恶劣社会影响等。

也就是说：**打了人但对方只是轻微伤，仍可能构成寻衅滋事罪。**

### 3.2 一个行为可能同时触犯两条

如果随意殴打他人致轻伤，可能同时符合 234 条和 293 条。这种情况按处罚较重的规定定罪。

**实务提示**：寻衅滋事的量刑起点往往高于故意伤害（293 条第一档是「五年以下」，234 条第一档是「三年以下」）。所以「我只是打了一拳」在某些情形下，定性为寻衅滋事反而更重。

## 四、正当防卫：限度比你想的窄

「对方先动手，我还手就是正当防卫」——这是最普遍、也最危险的误解。

> 第二十条　为了使国家、公共利益、本人或者他人的人身、财产和其他权利免受正在进行的不法侵害，而采取的制止不法侵害的行为，对不法侵害人造成损害的，属于正当防卫，不负刑事责任。
>
> 正当防卫明显超过必要限度造成重大损害的，应当负刑事责任，但是应当减轻或者免除处罚。
>
> 对正在进行行凶、杀人、抢劫、强奸、绑架以及其他严重危及人身安全的暴力犯罪，采取防卫行为，造成不法侵害人伤亡的，不属于防卫过当，不负刑事责任。
>
> 【法规】《中华人民共和国刑法》第二十条

### 4.1 正当防卫的五个条件

| 条件 | 意思 | 学生常踩的坑 |
| --- | --- | --- |
| 起因 | 存在**不法侵害** | 对方只是骂你，不构成「侵害」 |
| 时间 | 侵害**正在进行** | 对方已经停手、跑了，你还追打 → 不是防卫 |
| 对象 | 只能针对**侵害人本人** | 打对方的朋友 → 不是防卫 |
| 意图 | 为了**制止**侵害 | 为了泄愤、报复 → 不是防卫 |
| 限度 | 不能**明显超过必要限度** | 对方空手推你，你拿凳子砸头 → 过当 |

**最容易失败的是「时间」这一条。**

对方打了你一拳，然后转身走了，你追上去把他打倒——这**不是正当防卫**，是新的一次故意伤害。实务中大量「互殴」认定就出在这里。

### 4.2 「互殴」和「防卫」怎么分

两高一部《关于依法适用正当防卫制度的指导意见》（2020 年 9 月）明确了一个核心判断方法：**看谁先动手、看是否有防卫意图、看力量对比是否悬殊**。

通俗化的判断：

| 情形 | 通常认定 |
| --- | --- |
| 对方先动手，你只格挡、后退、挣脱 | 正当防卫 |
| 对方先动手，你还手一拳后停手 | 可能认定防卫，也可能认定互殴（看具体情节） |
| 对方先动手，你和他对打多个回合 | **通常认定互殴** |
| 对方停手后你继续打 | 故意伤害 |
| 你叫人来一起打 | 故意伤害，且可能构成聚众斗殴 |
| 对方只是推搡，你持械反击 | 很可能防卫过当 |

**「互殴」的后果**：双方都要为对方的伤负责，各自按伤情承担相应责任。不存在「他先动手所以他全责」。

### 4.3 关于「特殊防卫」

第二十条第三款规定的「特殊防卫」（针对行凶、杀人、抢劫、强奸、绑架等严重危及人身安全的暴力犯罪，造成伤亡也不负刑责），**门槛很高**。

它适用于你面临严重人身危险的情形，不适用于「同学推了我一把」「他踹了我一脚」这类冲突。

**不要用「特殊防卫」给自己的还手找依据。**

## 五、校园里最容易出事的地方

按风险从高到低：

| 场景 | 为什么危险 |
| --- | --- |
| **酒桌** | 判断力下降；「不喝就是不给面子」的群体压力；同行者可能被认定为共犯或未尽救助义务 |
| **篮球场、足球场** | 身体对抗被误读为挑衅；围观人多，容易升级成群架 |
| **宿舍矛盾** | 长期积累；封闭空间无处退让；随手可及的物品成为凶器 |
| **感情纠纷** | 「帮你出气」叫朋友一起去 —— 叫来的人在法律上不是旁观者 |
| **路见不平** | 出发点正当，但介入方式容易变成参与斗殴 |
| **网络争执线下约架** | 有预谋，几乎不可能认定正当防卫 |

**关于酒桌，多说一句**：如果同桌的人喝醉了闹事，你没有参与但也没有阻止，一般不负刑事责任。但如果有人因醉酒处于危险状态（如倒在路边、呕吐窒息）而你明知却不救助，可能涉及不作为的责任。这个边界因案而异，属于需要个案判断的领域。

## 六、动手之后，按顺序做

### 第一步：立刻停手，离开现场

不是「打完这一下就走」，是从这一刻起不再有任何肢体接触。**任何继续的动作都会把「防卫」变成「互殴」或「报复」。**

### 第二步：不要删、不要发

- 不要删聊天记录（对方的挑衅记录是重要证据）
- **不要发朋友圈、不要在群里说这件事**（可能被对方作为你「有伤害故意」的证据）
- 不要在网上「挂人」

### 第三步：就医并保留记录

如果你也受伤了：

- 去正规医院，**如实描述受伤经过**（不要隐瞒是打架造成的，也不要夸大）
- 保留全部病历、诊断证明、影像资料、缴费凭证
- 在 24 小时内考虑去公安机关做伤情鉴定（越早越好，因为伤情会变化）

### 第四步：判断是否必须报警

| 情况 | 建议 |
| --- | --- |
| 你是被打的一方，对方受伤更重 | **尽快报警**，说明你被先打的事实，固定当时情形 |
| 双方都受伤 | 报警，让程序来认定，而不是私下「比谁伤得重」 |
| 你是主要施暴方 | **先找律师**，再决定如何应对 |
| 只是轻微推搡、没人受伤 | 可以不报警，但要把和解写清楚 |

### 第五步：关于「私了」

**这一点必须说清楚，因为最容易搞错：**

| 民事赔偿部分 | 刑事部分 |
| --- | --- |
| **可以私了**。赔钱、道歉、签和解协议，是有效的 | **不能私了**。是否追究刑事责任由司法机关决定 |

也就是说：

- 赔钱达成谅解，可以影响量刑（从轻）、影响是否起诉（相对不起诉）
- **但赔了钱，案件照样可能继续走**，不会因为对方说「不追究了」就自动撤销

如果对方说「你赔我两万，我就不报警」——这是**敲诈陷阱**的高发形态。正确做法是：谈赔偿可以，但要在有第三方（学校、调解组织）在场的情况下谈，并写入书面协议，写清「赔偿范围」和「不再就此事主张民事权利」。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「对方先动手，我还手就是正当防卫」 | 还手对打通常被认定为互殴；防卫要求针对正在进行的不法侵害且不超过必要限度 |
| 「没打伤就没事」 | 寻衅滋事不要求轻伤，「情节恶劣」即可构成 |
| 「轻伤就是轻伤，很快就好」 | 法律上的轻伤对应刑事犯罪，三年以下 |
| 「赔钱私了就不追究了」 | 民事赔偿可以私了，刑事责任不能私了 |
| 「我只是推了他一下」 | 法律看结果。倒地造成的骨折也可能是轻伤 |
| 「他骂我，我打他不算我先动手」 | 骂人不构成「不法侵害」，你先动手就是你先动手 |
| 「我朋友叫我去，我没动手」 | 事前有共同故意、现场起助威作用的，可能被认定为共犯 |
| 「打了架学校处理一下就完了」 | 学校处分和法律责任是两条线，会同时发生 |
| 「被人打了不能还手，还手就理亏」 | 可以防卫，但要克制在「制止侵害」的范围内，并及时脱离 |

## 八、可执行清单

### 冲突正在发生时

- [ ] 后退、拉开距离、把双手放在可见位置
- [ ] 大声说「我不想打架」，让周围人听见（这句话以后是证据）
- [ ] 找人、找在场见证者，或直接离开
- [ ] **不还手，除非无法脱离且面临持续侵害**
- [ ] 全程不要拿任何物品

### 事后 24 小时内

- [ ] 拍照记录自己的伤情（有日期水印）
- [ ] 保存现场监控位置的线索（哪天、哪个摄像头、大概时间）
- [ ] 记下在场人员的名字
- [ ] 就医，如实陈述
- [ ] 决定是否报警（对方伤重，你更应主动）

### 事后一周内

- [ ] 找学校辅导员/保卫处报备（先报备的人，在后续叙述中通常更主动）
- [ ] 咨询律师（如果对方伤情可能达轻伤）
- [ ] 不要在任何社交平台谈论此事
- [ ] 不要私下转账「封口费」

### 长期

- [ ] 记住：任何一次动手都可能改变你的学籍、档案和就业

## 九、一句话记住

**打完这一拳，对方是轻微伤还是轻伤，不由你决定——但责任由你承担。**
