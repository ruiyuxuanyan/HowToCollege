# 报警之后会发生什么

> 一句话概括：报警不是「报完就完了」——你还需要知道流程和你的权利。

**适用人群**：准备报警或已经报警的人；被侵害后不知道该怎么办的人。

> **本文性质**
>
> 本文为程序性信息整理，**不构成法律意见**。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国刑事诉讼法》关于立案的规定；《公安机关办理刑事案件程序规定》；《中华人民共和国治安管理处罚法》
> - 全国统一：立案程序、救济途径全国统一
> - 核查日期：2026-11-05

---

## 一、报警的方式

| 方式 | 适用 |
| --- | --- |
| **110** | 紧急情况、正在发生的违法犯罪 |
| 到派出所报案 | 一般情况，需做笔录 |
| 12110 短信报警 | 不便通话时（如被控制、听力障碍） |

---

## 二、报警后警方做什么

```
接警 → 受案 → 审查（是否属于管辖、是否构成案件）
              ├─ 立案 → 侦查
              └─ 不予立案 → 出具《不予立案通知书》
```

| 概念 | 说明 |
| --- | --- |
| **受案** | 警方受理并登记，这是第一步 |
| **立案** | 确认构成案件，正式启动侦查 |
| 不予立案 | 认为不构成犯罪或不属于管辖 |

---

## 三、受案回执：一定要拿

**这是本文最重要的一条建议。**

报警后，你有权索取**受案回执**（或受案登记表回执）。

| 为什么重要 | 说明 |
| --- | --- |
| 证明你报过案 | 后续跟进的凭据 |
| 查询进度 | 凭回执编号可查询 |
| 申请立案监督 | 不予立案时需要用 |
| 保险理赔 | 部分保险需要报警记录 |

**怎么做**：做笔录后主动说「请给我一份受案回执」。

---

## 四、不予立案怎么办（救济路径）

这是很多人不知道的权利。

| 步骤 | 做什么 |
| --- | --- |
| 1 | 要求公安机关出具**《不予立案通知书》**（书面） |
| 2 | 收到后，可向作出决定的公安机关申请**复议** |
| 3 | 对复议结果不服，可向上一级公安机关申请**复核** |
| 4 | 也可以向**人民检察院**申请**立案监督** |

**关键**：**一定要拿到书面的《不予立案通知书》**，口头告知无法作为后续救济的依据。

---

## 五、三类案件的区别

| 类型 | 举例 | 谁处理 |
| --- | --- | --- |
| **刑事案件** | 盗窃、诈骗、故意伤害 | 公安立案侦查 |
| **治安案件** | 打架未致轻伤、扰乱秩序 | 公安治安处罚 |
| **民事纠纷** | 欠钱不还、合同纠纷 | **法院**，公安一般不管 |

**常见误解**：经济纠纷报警，警方通常告知「属于民事纠纷，请向法院起诉」——这不是不作为，是管辖分工。

---

## 六、报警时的注意事项

| 做法 | 说明 |
| --- | --- |
| **如实陈述** | 夸大或隐瞒可能影响案件处理 |
| 提供证据 | 聊天记录、转账凭证、照片 |
| 记下信息 | 接警编号、办案民警姓名与联系方式 |
| 不要在电话里说太多细节 | 先报案，细节到派出所做笔录时说 |

---

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「报警没用」 | 止付、立案侦查都依赖报警 |
| 「金额小警察不管」 | 仍应报案，累计案件有助侦破 |
| 「报了警就一定能破案」 | 立案≠破案，但报案是必要的 |
| 「口头说不用回执」 | 一定要拿书面回执 |
| 「民事纠纷也要报警」 | 公安一般引导走法院 |
| 「不立案就没辙了」 | 可复议、复核、申请检察立案监督 |

## 八、可执行清单

### 报警时

- [ ] 拨打 110 或到派出所
- [ ] 如实陈述事实
- [ ] 提供证据材料

### 做完笔录后

- [ ] **索取受案回执**
- [ ] 记下办案民警姓名与联系方式
- [ ] 记下案件编号

### 如果被拒

- [ ] 要求出具《不予立案通知书》
- [ ] 申请复议 → 复核 → 检察立案监督

---

## 九、一句话记住

**报警后一定要拿受案回执。不立案就要书面通知，然后复议、复核、申请检察监督。**
