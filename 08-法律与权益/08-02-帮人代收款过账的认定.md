# 帮人「代收款」「过账」的认定：从日常场景看边界

> 一句话概括：三个问题问完，你就知道这笔钱该不该过你的账户。

**适用人群**：被人问过「帮我收个款」「借你的码走一下流水」的大学生；已经在帮人过账、心里有点不踏实的人；想搞清楚「到底哪一步开始违法」的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国刑法》第二百八十七条之二、第三百一十二条、第二百六十六条；最高人民法院、最高人民检察院《关于办理非法利用信息网络、帮助信息网络犯罪活动等刑事案件适用法律若干问题的解释》（法释〔2019〕15 号）
> - 全国统一：刑法与上述司法解释在全国范围内统一适用
> - 核查日期：2026-11-05
> - 已知变化：本罪名与司法解释目前有效；具体量刑与罪名适用以法院裁判为准
>
> ⏳ 易过时：司法解释的补充规定、各地检察机关的从宽处理口径可能调整。

## 一、三种可能的定性，先分清轻重

同样是「帮人收钱」，法律上可能是三种完全不同的东西。刑期差好几倍。

| 定性 | 法条 | 核心区别 | 刑罚幅度 |
| --- | --- | --- | --- |
| 诈骗罪共犯 | 《刑法》第二百六十六条 | 你和对方**一起**骗人，有共同故意 | 依诈骗数额定，最高可至无期徒刑 |
| 帮助信息网络犯罪活动罪（帮信罪） | 《刑法》第二百八十七条之二 | 你知道对方在犯罪，你提供支付等帮助 | 三年以下有期徒刑或者拘役，并处或单处罚金 |
| 掩饰、隐瞒犯罪所得罪（掩隐罪） | 《刑法》第三百一十二条 | 钱已经是**犯罪所得**了，你帮着藏、帮着转 | 三年以下；情节严重的，三年以上七年以下 |

**怎么理解这张表：**

- **最轻的是帮信罪**，最高三年。很多人以为「帮信罪很重」，其实它是这三个里最轻的
- **掩隐罪更重**，因为它的行为发生时，犯罪已经完成，你是在处理赃款
- **诈骗共犯最重**，因为你本身就是骗局的一部分

法条原文（掩隐罪部分）：

> 第三百一十二条　明知是犯罪所得及其产生的收益而予以窝藏、转移、收购、代为销售或者以其他方法掩饰、隐瞒的，处三年以下有期徒刑、拘役或者管制，并处或者单处罚金；情节严重的，处三年以上七年以下有期徒刑，并处罚金。
>
> 【法规】《中华人民共和国刑法》第三百一十二条

**实务上要注意的一点**：同一个行为可能同时符合两个罪名，最后按「处罚较重的规定」定罪。所以辩护空间往往在「定性」上，而不在「有没有做」。

## 二、判断树：三个问题

这是本文的核心。遇到任何「帮人收款」的请求，按顺序问自己三句话。

```
对方要你做的事
   │
   ├─ 问题一：这笔钱从哪来？
   │     ├─ 说不清楚 / 「你别管」/ 「客户的钱」
   │     │        → 停。不需要再问下去
   │     └─ 说得清、能对上具体交易
   │              → 继续问问题二
   │
   ├─ 问题二：为什么非要用你的账户？
   │     ├─ 因为他自己的不能用（被冻结、被限额、怕留痕、不是本人）
   │     │        → 停。这是最强的危险信号
   │     ├─ 因为方便（就这一次、他不在本地）  → 慎。要能说清为什么
   │     └─ 因为业务本身要求（如代收货款、有合同）
   │              → 继续问问题三
   │
   └─ 问题三：你有没有因此拿到好处？
         ├─ 有佣金、有提成、按流水比例给钱
         │        → 停。正常代收不会按流水付费
         ├─ 有「人情」（同学帮忙、亲戚开口）  → 慎。人情不改变客观性质
         └─ 完全没有，纯帮忙且金额合理
                  → 风险较低，但仍需保留证据
```

**为什么是这三个问题，而不是「你知不知道」：**

因为法律不要求证明你「心里怎么想」。司法解释允许从客观情形**推定**你明知。而这三个问题问的，正是司法机关会看的那些客观情形。

具体到司法解释列举的推定情形，其中与你最相关的是这一项：

> 第十一条　为他人实施犯罪提供技术支持或者帮助，具有下列情形之一的，可以认定行为人明知他人利用信息网络实施犯罪，但是有相反证据的除外：
>
> （三）交易价格或者方式明显异常的；
>
> 【法规】最高人民法院、最高人民检察院《关于办理非法利用信息网络、帮助信息网络犯罪活动等刑事案件适用法律若干问题的解释》（法释〔2019〕15 号）第十一条

**「交易价格或者方式明显异常」——这八个字，就是判断树的法律依据。**上面三个问题，全都在检测「异常」。

司法解释第十一条的完整七项列举，已在 03-06 中逐条引过，这里不重复。

## 三、四个真实场景，逐个过判断树

下面四种情形，是学生最常遇到的。每种都走一遍判断树。

### 场景一：同学说「我卡被限额了，帮收一笔学费」

**这是最容易被误判的一种**，因为它听起来完全正常。

| 判断树 | 回答 | 结论 |
| --- | --- | --- |
| 钱从哪来 | 对方家长转的学费，能对上 | 通过 |
| 为什么用你的账户 | 他自己的卡当日限额 | 通过（有合理解释） |
| 有没有好处 | 没有 | 通过 |

**结论：这个场景本身不构成犯罪。**

**但仍要做三件事**，因为「现在正常」不等于「以后能证明正常」：

1. 让对方在微信里**用文字说清楚**这是什么钱、为什么用你的账户（不要只听语音）
2. 转账时**备注用途**
3. 收到后**尽快原路转出**给应缴的账户，不要在自己账上停留

**危险变体**：如果这位同学说「你先取现给我，我转给我朋友」，或者「别备注，备注会被限额」——判断树立刻转向「停」。要求你消除痕迹，本身就是异常。

### 场景二：网上兼职「代收款，按流水 2% 提成」

| 判断树 | 回答 | 结论 |
| --- | --- | --- |
| 钱从哪来 | 「平台客户的钱」，说不清 | **停** |
| 为什么用你的账户 | 对方是「公司」，却要用个人账户 | **停** |
| 有没有好处 | 按流水比例提成 | **停** |

三项全中。这是典型的「跑分」，是帮信罪最常见的形态。

**为什么这一条几乎没有辩护空间**：正规企业收款走对公账户，这是税务和支付合规的基本要求。一个号称有业务的公司，却需要借用陌生学生的个人账户收款，只有一个解释——它的钱不能见光。

### 场景三：亲戚说「帮我收笔货款，我在外地不方便」

| 判断树 | 回答 | 结论 |
| --- | --- | --- |
| 钱从哪来 | 亲戚的生意往来，能说清 | 通过 |
| 为什么用你的账户 | 人在外地、走账不便 | 通过（但要核实） |
| 有没有好处 | 没有 | 通过 |

**结论：风险较低，但不是零。**

「亲戚」这个身份在司法实践中**不构成免责理由**。真实案例里，亲属关系反而常被认为是「应当知道」的背景——因为你更了解对方在做什么。

具体可以做两件事降低风险：

- 让亲戚提供**对应的合同、订单或发票**
- 钱到账后，转出的对象是**亲戚本人的账户或其公司账户**，不是第三方陌生人

**关键分界线**：钱最终流向谁的账户。流向本人 = 代收；流向不明第三方 = 过账。这两件事的法律性质不一样。

### 场景四：陌生人高价「租你的收款码」

| 判断树 | 回答 | 结论 |
| --- | --- | --- |
| 钱从哪来 | 不知道 | **停** |
| 为什么用你的账户 | 陌生人，无任何关系 | **停** |
| 有没有好处 | 一天给几百 | **停** |

这一条不需要分析。**一个陌生人愿意为一个收款码付钱，说明这个码在他手里比我手里值钱得多**——多出来的价值只能来自违法用途。

《反电信网络诈骗法》第三十一条对此有直接禁止：

> 任何单位和个人不得非法买卖、出租、出借电话卡、物联网卡、电信线路、短信端口、银行账户、支付账户、互联网账号等，不得提供实名核验帮助。
>
> 【法规】《中华人民共和国反电信网络诈骗法》第三十一条

注意这一条禁止的是**出租、出借本身**，不以对方是否犯罪为前提。也就是说，即使对方最后没构成犯罪，出租收款码这个行为本身也已经违法。

## 四、「我只是帮忙，没拿钱」能免责吗

不能，但**影响很大**。这两件事要分开看。

### 4.1 不拿钱，不影响「是否构成犯罪」

帮信罪的构成要件里，没有「必须获利」这一项。法条写的是「提供……支付结算等帮助，情节严重的」。

司法解释规定的「情节严重」七项标准中，只有第（四）项是「违法所得一万元以上」。其余六项都与获利无关——比如「为三个以上对象提供帮助」，纯帮忙也满足。

所以：**免费帮忙，照样可能构成犯罪。**

### 4.2 但「没拿钱」是重要的从轻情节

这一点很实际。是否获利会影响：

- 检察机关是否作出**相对不起诉**
- 法院量刑时的**从轻幅度**
- 能否争取**缓刑**
- 被害人的损失能否**退赔**

法释〔2019〕15 号第十五条留了一个出口：

> 综合考虑社会危害程度、认罪悔罪态度等情节，认为犯罪情节轻微的，可以不起诉或者免予刑事处罚；情节显著轻微危害不大的，不以犯罪论处。
>
> 【法规】同上司法解释第十五条

**这句话的实际含义是**：「我纯粹是帮忙、没拿一分钱、事后主动配合、还赔了钱」这一整套事实，在实务中确实能显著影响结果。但它影响的是**处理结果**，不是**是否违法**。

一句话：**不拿钱不能免责，但可能是你唯一能拿出来的东西。**

## 五、「不知情」的边界在哪

这是所有人最想问的。前面说过，法律允许推定。但「推定」不是「一律认定」，它有边界。

### 5.1 什么情况下的「不知道」站得住

| 情形 | 是否可能站得住 | 原因 |
| --- | --- | --- |
| 对方提供了完整的合同、发票、订单 | 较可能 | 你尽到了合理的核实义务 |
| 金额、频率与正常生活场景匹配 | 较可能 | 不构成「明显异常」 |
| 你主动询问过，对方给出了具体解释 | 较可能 | 你有询问记录 |
| 你在发现异常后立即停止并报案 | 最可能 | 有明确的转折点证据 |
| 对方是陌生人，但你「没多想」 | 很难 | 陌生人 + 给钱 = 明显异常 |
| 对方明确说「别问」 | 几乎不可能 | 刻意回避本身就是信号 |

### 5.2 「我不知道」的证据长什么样

法律上，你的主观状态要靠**客观材料**证明。所以真正有用的不是你的陈述，而是：

- 你和对方的**完整聊天记录**（尤其是你提问、对方解释的部分）
- 转账的**备注**和**用途说明**
- 你**主动核实**的痕迹（查过对方公司、要过合同）
- 你**发现异常后停止**的时间点（这个时间点越早越好）

**反过来说，以下行为会摧毁「不知情」的辩护**：

- 删除聊天记录
- 使用别人的账户收钱
- 按对方指示拆分金额、避开限额
- 收到钱后立即取现（而不是转账，因为取现不留对方账户信息）

这几件事的共同点：**它们都只有在你认为这件事不能见光时才会做。**

## 六、已经做了，现在怎么办

如果你已经在帮人过账，按这个顺序处理。**不要自己判断严重程度，也不要等「看看会不会有事」。**

### 第一步：今天停止，但不惊动对方

不要把对方拉黑，不要质问，不要说「我怀疑你是骗子」。**保持联系，正常对话，但不再收任何款。**

理由是：你的聊天记录是证明你主观状态的最重要证据，一旦对方警觉删除记录，你就失去了它。

### 第二步：完整固定证据

| 要固定什么 | 怎么固定 |
| --- | --- |
| 聊天记录 | 截图 + 录屏（含对方账号主页），不要只截片段 |
| 转账记录 | 银行 App 导出流水、支付平台账单 |
| 对方的身份信息 | 微信号、手机号、姓名、收款账户 |
| 时间线 | 自己写一份，从第一次接触到现在，按日期列 |

**不要删任何东西。**删记录在实务中可能被认定为对抗调查，反而加重。

### 第三步：搞清楚自己处在什么位置

对照第一节的表格，判断自己更接近哪一种定性。这一步**不要自己下结论**，只是为了让律师快速了解情况。

同时自查名下账户状态（具体方法见 03-06 第七节，不重复）。

### 第四步：找律师，再决定是否主动说明

这是最关键、也最容易被跳过的一步。

**为什么必须先找律师**：主动投案、如实供述在法律上是法定从轻情节，但「什么时候说、说到什么程度、要不要先退赔」是策略问题。说早了可能扩大调查范围，说晚了可能失去从轻机会。这个判断需要看你的具体材料。

**网上那些「帮信罪没事，退赔就行」的说法，不要照搬。**各地检察机关的处理口径差异很大。

### 第五步：告诉一个能帮你的人

家人、导师、或者你信得过的长辈。理由很实际：如果事情进入程序，你需要有人帮你找律师、帮你周转退赔款、帮你跟学校沟通。独自扛到最后才说，通常已经错过最好的时点。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「我没拿钱，就是帮忙」 | 帮信罪不以获利为构成要件。免费帮忙也可能构罪 |
| 「钱没在我账上过夜，我马上转走了」 | 关键在于「流过」，不在于「停留」。资金流水会完整记录 |
| 「我只是提供了一个收款码，没碰钱」 | 提供支付账户、收款码属于法条明列的「支付结算」帮助 |
| 「对方说是正常生意」 | 对方说什么不重要，客观上是否异常才重要 |
| 「我同学也在做，他都没事」 | 没被追究不等于合法；也可能只是还没查到 |
| 「金额小，达不到门槛」 | 「为三个以上对象提供帮助」不看金额，见 03-06 第四节 |
| 「删了记录就查不到」 | 银行流水、平台数据都能调取；删记录本身可能被认定对抗调查 |
| 「退赔了就没事了」 | 退赔是从轻情节，不是免罪事由。是否不起诉由检察机关决定 |

### 以后遇到时的标准回答

> 「我账户不外借，家里有规矩，不好意思。」

**不需要解释，不需要给理由，也不需要说「下次吧」。**真正正当的请求，不会因为你说「不外借」就办不成；坚持要你账户的，正是最该拒绝的那种。

### 拒绝之后

如果对方开始施压——说你不够朋友、说这是最后一次、说「就这一次」、说「你不帮我我就完了」——**这些施压本身就是答案**。真正正当的事，不需要用感情逼你。
