# 网络言论的边界：造谣、辱骂、转发的法律后果

> 一句话概括：转发就是传播，法律不看你是不是原创。

**适用人群**：经常在群里、朋友圈、微博、小红书发言的大学生；被造谣或被人挂过的人；习惯「先转了再说」的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国刑法》第二百四十六条、第二百九十一条之一；《中华人民共和国治安管理处罚法》；《中华人民共和国民法典》人格权编（第九百九十条起、第一千零二十四条名誉权、第一千零三十二条隐私权）；最高人民法院、最高人民检察院《关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》（法释〔2013〕21 号）
> - 全国统一：刑法、民法典与上述司法解释在全国范围内统一适用；治安处罚的具体裁量各地有差异
> - 核查日期：2026-11-05
> - 已知变化：该法曾多次修改，**本文所引条款序号以 2012 年修正版为准，现行版本是否另有修改未能核实**
>
> ⏳ 易过时：治安管理处罚法的条款序号；网络诽谤「情节严重」的具体数量标准（司法解释另定，见 3.3 与 3.4 节）。

## 一、一句话讲清三种行为的区别

日常说的「说话惹事」，法律上分成三件不同的事。混在一起就没法判断。

| 行为 | 你做了什么 | 核心特征 |
| --- | --- | --- |
| **侮辱** | 骂人、羞辱、贬损人格 | 内容是**价值判断**（「他是个人渣」），不要求是事实 |
| **诽谤** | 编造或散布**虚假事实** | 内容必须是**可以被证明真假的具体事实**（「他偷过东西」） |
| **造谣** | 编造并传播虚假的**公共信息** | 内容涉及公共领域（灾情、疫情、警情等） |

**这个区分为什么重要**：

- 侮辱可以针对个人，不需要「假事实」
- 诽谤必须是「假事实」，纯骂人一般不构成诽谤
- 造谣的重点不在某个人，在公共秩序

三条路的后果完全不同，下面分开讲。

## 二、民事、行政、刑事：三层后果

同一个发言，可能同时触发三种责任。这不是「三选一」，是可能同时承担。

| 层次 | 依据 | 后果 | 谁来找你 |
| --- | --- | --- | --- |
| **民事** | 《民法典》人格权编 | 停止侵害、删帖、赔礼道歉、赔偿损失（含精神损害抚慰金） | 被侵权人起诉你 |
| **行政** | 《治安管理处罚法》 | 拘留、罚款 | 公安机关 |
| **刑事** | 《刑法》 | 有期徒刑、拘役、管制或剥夺政治权利 | 检察院起诉 / 被害人自诉 |

**最需要理解的一点**：

民事和行政的门槛都**很低**。也就是说，绝大多数「说话惹事」停在民事或行政层面，不走刑事。但这不代表没事——民事赔偿要钱，行政拘留要留记录。

## 三、侮辱与诽谤：刑事的门槛在哪

### 3.1 法条

> 第二百四十六条　以暴力或者其他方法公然侮辱他人或者捏造事实诽谤他人，情节严重的，处三年以下有期徒刑、拘役、管制或者剥夺政治权利。
>
> 前款罪，除严重危害社会秩序和国家利益的以外，告诉的才处理。
>
> 【法规】《中华人民共和国刑法》第二百四十六条

拆开看，两个罪共用一个条文，但构成要件不同：

| | 侮辱罪 | 诽谤罪 |
| --- | --- | --- |
| 行为 | 以暴力或其他方法**公然**侮辱他人 | **捏造事实**诽谤他人 |
| 是否需要「假事实」 | 不需要 | **必须**是捏造的虚假事实 |
| 是否需要「公然」 | **需要**（能让不特定人知悉） | 法条未写「公然」，但传播是常态 |
| 门槛 | 情节严重 | 情节严重 |

### 3.2 侮辱罪的关键是「公然」

「公然」不是「当着你的面」，而是**让不特定人或多数人可能知悉**。

对照一下：

| 情形 | 是否「公然」 |
| --- | --- |
| 在班级群里骂人（几十人） | 是 |
| 在朋友圈发辱骂内容（好友可见） | 是 |
| 在微博、贴吧公开发布 | 是 |
| 私聊里骂对方 | **通常不是**（但这不排除民事侵权） |
| 当面对骂，旁边有人 | 是 |

**所以「私聊骂人」和「群里骂人」在法律上是两件事。** 前者一般不构成侮辱罪，但仍可能构成民事侵权。

### 3.3 「情节严重」怎么算

《刑法》第二百四十六条只写了「情节严重」，具体标准在司法解释里。

两高《关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》（法释〔2013〕21 号）对网络诽谤的「情节严重」作了规定，大致包括：

- 同一诽谤信息被**实际点击、浏览次数**达到一定数量
- 同一诽谤信息被**转发次数**达到一定数量
- 造成被害人精神失常、自残、自杀等严重后果
- 二年内曾因诽谤受过行政处罚，又诽谤他人

> **【待核实】具体数量门槛**：该司法解释规定的是「五千次」「五百次」这一量级的标准。**本文不写具体数字**，因为：(1) 条文数量标准需逐字核对原文；(2) 该解释 2013 年施行，此后是否被修改未能核实。**引用前请查阅法释〔2013〕21 号现行文本，或咨询律师。**
>
> 一般表述请用：「达到司法解释规定的点击、浏览、转发数量门槛」。

### 3.4 诽谤罪多为自诉案件——这一点极其重要

《刑法》第二百四十六条第二款：

> 前款罪，**除严重危害社会秩序和国家利益的以外，告诉的才处理**。

「告诉的才处理」= 自诉案件 = **被害人自己去法院起诉，公安机关不主动立案**。

这意味着：

| 情况 | 走哪条路 |
| --- | --- |
| 一般网络诽谤 | 被害人向法院提起**自诉** |
| 严重危害社会秩序和国家利益 | 公安机关立案，检察院**公诉** |

**实务含义**：

- 你被诽谤了，报警可能被告知「这是自诉案件，去法院起诉」
- 反过来，如果你诽谤了别人，对方需要自己去起诉你，程序成本较高
- **但这不代表安全**：自诉案件照样能判刑，而且民事赔偿更容易实现

关于「严重危害社会秩序和国家利益」的具体情形，法释〔2013〕21 号有列举（如引发群体性事件、公共秩序混乱、民族宗教冲突等）。**具体情形未逐条核实，标注。**

## 四、编造、传播虚假信息：另一种罪

这条针对的是**公共信息**，不是针对某个人。

> 第二百九十一条之一　编造虚假的险情、疫情、灾情、警情，在信息网络或者其他媒体上传播，或者明知是上述虚假信息，故意在信息网络或者其他媒体上传播，严重扰乱社会秩序的，处三年以下有期徒刑、拘役或者管制；造成严重后果的，处三年以上七年以下有期徒刑。
>
> 【法规】《中华人民共和国刑法》第二百九十一条之一（《刑法修正案（九）》增设）

注意这条的**限定范围**：只针对**险情、疫情、灾情、警情**四类。

| 你编造/转发的 | 是否落入 291 条之一 |
| --- | --- |
| 「某地发生重大交通事故，死了十几人」（假的） | 是（警情/灾情） |
| 「某医院出现新型传染病，已经封院」（假的） | 是（疫情） |
| 「某小区发生持刀伤人」（假的） | 是（警情） |
| 「某明星离婚了」（假的） | 一般不是（不属四类），但可能有民事问题 |
| 「学校食堂用过期食材」（未经核实） | 不属四类，但可能构成诽谤或治安违法 |

**关键点**：「明知是上述虚假信息，故意传播」——**转发也在条文里**。

条文写得很清楚：「或者**明知是上述虚假信息，故意在信息网络或者其他媒体上传播**」。

所以，编造的人和传播的人，法条上是并列的两种行为。

## 五、核心：转发即传播

这是本文最重要的一节。

### 5.1 法条怎么写的

回到 291 条之一：「**明知是上述虚假信息，故意在信息网络或者其他媒体上传播**」。

再看 246 条：「捏造事实诽谤他人」——司法解释把「散布」「转发」都纳入了「诽谤他人」的行为方式。

也就是说：

> **法律评价的是「信息因为你而到达了更多人」这件事，不是「这句话是谁先说的」。**

### 5.2 转发者的责任边界

转发者的责任不是无限的。关键在两个点：

| 判断点 | 说明 |
| --- | --- |
| **是否明知或应知是虚假的** | 你的责任来源于「知道还传」，不是「不小心传了」 |
| **是否造成后果** | 传播范围、对被害人的实际影响 |

**「我以为是真的」在什么情况下站得住？**

| 情形 | 你的处境 |
| --- | --- |
| 转了权威媒体（新华社、央视）的报道 | 一般不承担责任 |
| 转了政府部门、学校的官方通知 | 一般不承担责任 |
| 转了「某博主说」「群里有人发」的截图 | **很难站住**。这就是「应知」的领域 |
| 转了明显违背常识的内容（「喝醋能杀新冠」） | 很难站住 |
| 转的时候自己加了「不知道真假，大家看看」 | **不能免责**。这句话恰恰证明你知道可能不实 |
| 转的时候加了评论「太可怕了大家快看」 | 可能加重责任（有推动传播的故意） |

**注意倒数第三行**：「不知道真假，大家看看」这句话，在实务中经常被作为「明知可能不实仍传播」的依据。它看起来是免责声明，实际是自认。

### 5.3 一个具体场景

以下是一个**虚构的示例**，仅用于演示判断方法，不对应任何真实事件：

假设群里有人发了一条消息：「某某大学有学生在宿舍跳楼，学校在压热搜」，配了一张模糊的照片。

按法律拆开看：

| 要素 | 分析 |
| --- | --- |
| 内容类型 | 涉及警情/人身安全 → 可能落入 291 条之一 |
| 如果是假的 | 编造者可能构罪；转发者「明知虚假仍传播」也可能 |
| 如果只是未经核实 | 不构成 291 条之一，但仍可能构成治安违法或民事侵权 |
| 你的最佳做法 | **不转**。如果担心，直接打学校值班电话核实 |

**「不转」的成本是零，「转了」的成本是不可控的。**

## 六、治安处罚：门槛最低的那一层

刑事门槛高，但治安处罚门槛低。绝大多数「说话惹事」实际停在治安层面。

《治安管理处罚法》对以下行为规定了拘留、罚款：

- 散布谣言，谎报险情、疫情、警情或者以其他方法故意扰乱公共秩序
- 公然侮辱他人或者捏造事实诽谤他人
- 偷窥、偷拍、窃听、散布他人隐私
- 多次发送淫秽、侮辱、恐吓或者其他信息，干扰他人正常生活

> 【法规】《中华人民共和国治安管理处罚法》
>
> **2025 年 6 月 27 日修订，2026 年 1 月 1 日起施行**。修订后条文序号有调整：现行版本中，**公然侮辱他人或者捏造事实诽谤他人的，规定在第五十条**（原 2012 年版为第四十二条）。
>
> 第五十条的处罚幅度：处**五日以下拘留或者一千元以下罚款**；情节较重的，处**五日以上十日以下拘留**，可以并处一千元以下罚款。
>
> **现行条号对照**（2026 年 1 月 1 日起施行）：
>
> | 行为 | 现行条号 | 旧法条号 |
> | --- | --- | --- |
> | 公然侮辱他人、捏造事实诽谤他人 | **第五十条** | 第四十二条 |
> | 写恐吓信或以其他方法威胁他人人身安全 | **第五十条第一款第一项** | 第四十二条第一项 |
> | 偷窥、偷拍、窃听、散布他人隐私 | **第五十条第六项** | 第四十二条第六项 |
> | 殴打他人、故意伤害他人身体 | **第五十一条** | 第四十三条 |
>
> 罚款上限也一并调整：侮辱诽谤类由 500 元提到 **1000 元**；殴打他人由二百至五百元提到 **五百至一千元**。
>
> 上表按公开报道与官方普法核对，第五十条分项较多，引用具体项时请以官方文本全文为准。

**治安处罚的特点**：

| 特点 | 含义 |
| --- | --- |
| 不需要「情节严重」 | 门槛远低于刑事 |
| 公安机关主动处理 | 不需要被害人自己起诉 |
| 会留下违法记录 | 影响政审、部分岗位入职 |
| 可以同时民事索赔 | 拘留之后对方还能告你赔钱 |

**很多人以为「没到刑事就没事」，实际上治安处罚是最常见的后果，而且已经足够影响前途。**

## 七、民事：最容易被忽略，但最容易发生

《民法典》人格权编的保护范围比刑法宽得多。

| 权利 | 条款 | 对应行为 |
| --- | --- | --- |
| 名誉权 | 第一千零二十四条 | 侮辱、诽谤、贬损社会评价 |
| 隐私权 | 第一千零三十二条 | 公开他人私密信息 |
| 个人信息 | 第一千零三十四条起 | 公开他人姓名、身份证号、住址、联系方式 |
| 肖像权 | 第一千零一十九条 | 未经同意使用他人照片（含「挂人」配图） |

**民事责任的三个特点：**

1. **门槛极低**。不需要「情节严重」，只要有损害事实、行为、因果关系、过错
2. **举证相对容易**。截图、公证就能用
3. **后果实际**。要删帖、要道歉、要赔钱

**「挂人」为什么风险极高**：一条「挂人」微博通常同时涉及名誉权（贬损评价）、隐私权（公开私人信息）、肖像权（配照片）、个人信息（姓名学号院系）。四项可以一起告。

### 7.1 被网暴的人可以主张什么

- 停止侵害（删帖、断开链接）
- 赔礼道歉（可能要求公开发布）
- 赔偿损失（含为维权支出的合理费用）
- 精神损害赔偿（造成严重精神损害的）

### 7.2 平台的责任

《民法典》第一千一百九十五条、第一千一百九十六条规定了「通知—删除」规则：

- 权利人通知平台，平台应及时采取删除、屏蔽等措施
- 平台未及时处理，对损害扩大部分承担连带责任

**实务含义**：被侵权时，向平台发正式通知（不是普通举报）是有效手段，且能固定平台的责任。

## 八、「我只是随口一说」为什么不管用

法律上的表达自由有边界，这个边界不是「你说得对不对」，而是**你的话对别人造成了什么**。

| 你的想法 | 法律的看法 |
| --- | --- |
| 「就我们群里说说」 | 群有几十人，已是「公然」 |
| 「我又没指名道姓」 | 结合上下文能指向特定人即可 |
| 「我说的是事实」 | 事实需要你举证；举不出就是捏造 |
| 「我就是转了一下」 | 转发即传播 |
| 「我删了」 | 已传播的部分不会消失；删帖不消除既成责任 |
| 「对方也骂我了」 | 不构成免责，可能双方都担责 |
| 「网上都这么说」 | 「网上」不是免责主体，你是 |
| 「我是为他好/为了正义」 | 动机不改变行为性质，可能影响裁量 |

**最后一行值得多说一句**：「为了正义」「为了提醒大家」是最常见的自我说服。但法律上，你的动机不影响「你传播了一条可能虚假的、损害他人的信息」这个客观事实。它最多在量罚时被考虑。

## 九、如果你被造谣/被网暴了

顺序很重要。

### 第一步：不要立刻回应

公开对骂会让你从「受害人」变成「互殴型言论」的一方。而且你的回应会被截图，成为对方的材料。

### 第二步：完整取证

| 取什么 | 怎么取 |
| --- | --- |
| 原始页面 | 不要只截图，用**录屏**从打开 App 到看到内容到点开对方主页，一次录完 |
| 传播数据 | 转发数、评论数、点赞数、阅读量（这些决定是否达到「情节严重」） |
| 时间 | 精确到分钟，包含系统时间 |
| 对方身份 | 账号 ID、昵称、主页链接、可能的真实身份线索 |
| 影响证据 | 你因此受到的损失（就医记录、请假记录、工作受影响的证明） |

**有条件的话做「证据保全公证」**。网络内容随时可能被删，公证的证据效力最高。费用通常几百元。

### 第三步：向平台投诉

用平台的侵权投诉通道（不是普通举报），要求删除。保留投诉记录和平台回复。

### 第四步：分情况选择路径

| 情况 | 路径 |
| --- | --- |
| 内容涉隐私、个人信息 | 报警（治安违法），同时要求平台删除 |
| 一般诽谤、侮辱 | 民事起诉（要求删帖、道歉、赔偿） |
| 达到司法解释的数量门槛、后果严重 | 刑事**自诉**（自己去法院），或报警要求按公诉处理 |
| 涉及险情疫情灾情警情的假消息 | 报警（可能构成 291 条之一） |

### 第五步：不要做的事

- 不要人肉对方（你可能构成侵犯公民个人信息）
- 不要组织「反向网暴」
- 不要私下威胁（可能构成敲诈或威胁恐吓）

## 十、常见误区

| 误区 | 实际 |
| --- | --- |
| 「我只是转发，不是我写的」 | 转发即传播，法条把传播和编造并列 |
| 「我加了『不知道真假』就免责了」 | 这句话反而证明你知道可能不实 |
| 「私下说说没人管」 | 群聊是「公然」；私聊也可能构成民事侵权 |
| 「没指名道姓就没事」 | 结合上下文能指向特定人即可 |
| 「删了就没事了」 | 已传播部分不会消失；删帖只是止损，不消除责任 |
| 「对方先骂我的」 | 不构成免责，可能双方都担责 |
| 「网上说话警察不管」 | 治安处罚是最常见的后果，且门槛很低 |
| 「诽谤是公诉，报警就行」 | 诽谤罪原则上是自诉案件，除严重危害社会秩序和国家利益 |
| 「我是为了正义/提醒大家」 | 动机不影响行为定性 |
| 「没赚钱就不算事」 | 言论类责任的构成不以营利为前提 |

## 十一、可执行清单

### 发之前的三秒检查

- [ ] 这条信息我能说出**具体来源**吗？（不是「群里看到的」）
- [ ] 如果它是假的，我承担得起后果吗？
- [ ] 里面有没有**具体的人**？有的话，我说的每一句都能举证吗？
- [ ] 我是在陈述**事实**，还是在表达**评价**？（前者要能举证，后者要能接受反驳）
- [ ] 我加了「不确定」「据说」吗？加了就说明我不该发

### 已经发了，发现可能有问题

- [ ] 立即删除（止损，但不免责）
- [ ] 保存自己发布时的完整上下文（证明没有恶意）
- [ ] 如果是误传，公开更正（这是减轻责任的有效动作）
- [ ] 不要继续辩解、不要和对方对骂

### 被侵权时

- [ ] 录屏取证（不是截图）
- [ ] 记录传播数据
- [ ] 向平台发正式侵权通知
- [ ] 考虑证据保全公证
- [ ] 根据内容类型选择报警 / 起诉

### 长期习惯

- [ ] 只转有明确出处的信息
- [ ] 不在群里评价具体的人
- [ ] 不参与「挂人」
- [ ] 遇到「求扩散」的信息，先查证再决定
