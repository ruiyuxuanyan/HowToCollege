# 大学生最常踩的法律红线总览

> 一句话概括：一篇文章看完全部高危行为——你的「不知道」，比「故意」代价更大。

**适用人群**：全体在校大学生。

> **本文性质**
>
> 本文是法律信息索引，**不构成法律意见**。每个条目都指向详细篇目，具体问题请咨询执业律师。
>
> **核查日期**：2026-11-07

---

## 一、为什么学生容易踩线

| 原因 | 表现 |
| --- | --- |
| 信息差 | 根本不知道这件事违法 |
| 从众 | 「大家都在做」 |
| 被利用 | 有人专门找学生做「工具人」 |
| 轻视后果 | 以为最多被批评、被罚钱 |

**最关键的一点**：法律不看你「以为什么」，看你的行为客观上是什么。

---

## 二、四类高危行为（完整清单）

### 第一类：用自己的身份替别人办事

| 行为 | 可能触犯 | 详细 |
| --- | --- | --- |
| 出借/出售银行卡、支付账户 | 帮助信息网络犯罪活动罪（《刑法》287 之二） | 03-06 |
| 帮人「代收款」「过账」赚佣金 | 同上；情节更重时构成掩饰、隐瞒犯罪所得罪（312 条） | 08-02 |
| 出租微信号、收款码 | 同上 | 03-05 |
| 用自己身份证帮人注册公司、开对公账户 | 同上 + 民事债务风险 | 03-05 |
| 帮同学贷款做担保人 | 民事：承担还款责任 | 08-09 |

**共同特征**：对方需要「你的身份」，因为他的身份已被监控。

**记住一句话**：正常的事，不需要借用别人的身份。

### 第二类：网络上的言论与信息

| 行为 | 可能触犯 | 详细 |
| --- | --- | --- |
| 编造并传播谣言 | 编造、故意传播虚假信息罪（291 条之一）；治安处罚 | 08-04 |
| 捏造事实诽谤他人 | 诽谤罪（246 条）；名誉权侵权 | 08-04 |
| 公开辱骂、人身攻击 | 侮辱罪（246 条）；治安处罚 | 08-04 |
| 「挂人」、曝光他人隐私 | 侵犯隐私权；侵犯公民个人信息罪（253 条之一） | 06-09 |
| 人肉搜索 | 侵犯公民个人信息罪 | 06-09 |

**关键**：**转发也算传播。** 法律不看你是不是原创。

### 第三类：财产与财物

| 行为 | 可能触犯 | 详细 |
| --- | --- | --- |
| 偷外卖、拿室友东西 | 盗窃罪（264 条）——**多次盗窃不看金额** | 08-14 |
| 顺手拿走他人物品 | 同上 | 08-14 |
| 捡到东西拒不归还 | 可能构成侵占 | 08-14 |
| 私自翻查他人财物 | 治安处罚；隐私侵权 | 08-11 |

**最容易被忽视的**：**「多次盗窃」不受金额限制**。今天拿一次外卖、下周再拿一次，第三次就可能构罪。

### 第四类：冲突与暴力

| 行为 | 可能触犯 | 详细 |
| --- | --- | --- |
| 打架致人轻伤 | 故意伤害罪（234 条） | 08-03 |
| 随意殴打、起哄闹事 | 寻衅滋事罪（293 条） | 08-03 |
| 「打回去」超出必要限度 | 防卫过当仍可能担责 | 08-03 |

**注意**：法律上的「轻伤」并不轻——骨折、牙齿脱落都可能构成。

## 四、三条通用自保原则

### 原则一：不用自己的身份替别人办事

**具体包括**：银行卡、支付账户、微信号、身份证、公司注册、贷款担保。

**为什么**：一旦对方违法犯罪，你的身份就是链条上的一环。

### 原则二：不传播不确定的信息

**具体包括**：未经核实的「新闻」、涉他人的隐私内容、群里的「爆料」。

**为什么**：转发即传播，且很难证明你「不知情」。

### 原则三：不参与「来钱太容易」的事

**判断标准**：这件事的报酬与付出是否明显不成比例？

| 情形 | 判断 |
| --- | --- |
| 借张卡一天给 300 | 不成比例 → 拒绝 |
| 代收款按流水给 1% 提成 | 不成比例 → 拒绝 |
| 帮注册公司给 2000 | 不成比例 → 拒绝 |

## 五、涉事了怎么办

| 步骤 | 做什么 |
| --- | --- |
| 1 | **立即停止**，不要继续 |
| 2 | **保留证据**——不要删聊天记录、不要注销账号 |
| 3 | **咨询律师**，再决定是否主动说明 |
| 4 | 告诉家人 |
| 5 | 配合调查，如实陈述 |

**关于第 2 步的反直觉之处**：很多人第一反应是删记录，但**毁灭证据可能被认定为对抗调查，反而加重**。保留证据在某些情形下反而有利于证明你的主观状态。

**关于第 3 步**：主动投案、如实供述在量刑上是法定从轻情节，但具体怎么做属于法律策略，各地标准不同，**必须找执业律师，不要照搬网上说法**。

## 六、常见误区

| 误区 | 实际 |
| --- | --- |
| 「我只是帮忙，又没参与」 | 提供帮助本身即可构成犯罪 |
| 「我不知道啊」 | 法律允许推定「明知」 |
| 「金额小没事」 | 多次盗窃、3 个以上帮助对象都不看金额 |
| 「只是转发」 | 转发即传播 |
| 「删了记录就查不到」 | 平台数据可调取，删记录可能加重 |
| 「学生身份会从轻」 | 可能从轻，但不免责 |

## 七、可执行清单（红线清单）

**存下来，遇到时对照：**

- [ ] 不出借银行卡、支付账户、微信号、收款码
- [ ] 不帮人「代收款」赚佣金
- [ ] 不用自己身份证帮人注册公司
- [ ] 不帮同学贷款做担保
- [ ] 不签任何「入职前分期/贷款」合同
- [ ] 不转发未经核实的爆料、涉他人隐私的内容
- [ ] 不参与刷单、跑分
- [ ] 不写外挂、破解、抓取非公开数据的代码
- [ ] 动手前先想清楚：轻伤就构罪
- [ ] 不替人考试、不买卖答案
