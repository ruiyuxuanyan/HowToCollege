# 顺手牵羊与盗窃：多少金额会构成犯罪

> 一句话概括：「就拿一次」也可能变成刑事记录。

**适用人群**：全体在校生。

> **本文性质**
>
> 本文为法律信息整理，**不构成法律意见**。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国刑法》第二百六十四条；两高关于办理盗窃刑事案件的司法解释
> - 全国统一：盗窃罪的构成与「多次盗窃」等情形全国统一
> - **地方执行：盗窃「数额较大」的具体标准由各省确定，各省不同**
> - 核查日期：2026-11-05

---

## 一、盗窃罪的构成

《刑法》第二百六十四条规定，盗窃公私财物，**数额较大的**，或者**多次盗窃、入户盗窃、携带凶器盗窃、扒窃的**，构成盗窃罪。

**注意这里有个「或者」**——这是全文最关键的地方。

---

## 二、两种入罪路径

| 路径 | 是否看金额 |
| --- | --- |
| ① 数额较大 | **看金额**，标准各省不同 |
| ② **多次盗窃** | **不看金额** |
| ③ 入户盗窃 | 不看金额 |
| ④ 携带凶器盗窃 | 不看金额 |
| ⑤ 扒窃 | 不看金额 |

### 「多次盗窃」的定义

司法解释规定，「多次盗窃」通常指**二年内盗窃三次以上**。

**这就是最容易被忽视的陷阱**：

> 拿一次外卖 → 没到数额标准，可能只是治安处罚
> 再拿一次 → 仍可能只是治安处罚
> **第三次 → 可能构成盗窃罪**

**三次小额，加起来可能只有几百块，但已经构罪。**

---

## 三、数额标准为什么不能给数字

「数额较大」的具体金额**由各省、自治区、直辖市根据本地情况确定**，因此各地不同。

**不要记住某个数字**（网上常见的「1000 元」「2000 元」是某些地区的标准，不是全国统一）。

**正确做法**：查你所在省份的高级人民法院、人民检察院发布的盗窃罪数额标准。

---

## 四、校园里的常见场景

| 场景 | 法律定性 |
| --- | --- |
| 拿室友的东西（未告知） | 可能构成盗窃 |
| **偷外卖** | 单次看金额；多次则可能构罪 |
| 图书馆顺走他人物品 | 同上 |
| 借了不还（有归还意思） | 一般属民事纠纷，但拒不归还可能构成侵占 |
| 捡到东西不还 | 可能构成侵占罪 |

**「借用」与「盗窃」的界限**：是否有归还的意思、是否告知对方、是否使用后放回。

---

## 五、治安处罚与刑事处罚的分界

| 情况 | 处理 |
| --- | --- |
| 未达数额标准，且非多次/入户/扒窃 | 治安处罚（拘留、罚款） |
| 达数额标准，或属多次/入户/扒窃等 | 刑事（盗窃罪） |

**即使是治安处罚，也会留记录**，影响考公政审、部分就业。

---

## 六、被偷了怎么办

| 步骤 | 动作 |
| --- | --- |
| 1 | 保留现场，不要破坏 |
| 2 | 查看监控（通过保卫处或报警） |
| 3 | **报警**（不要自己去找对方理论） |
| 4 | 索取受案回执 |

**不要做的事**：不要在群里公开指认（可能构成名誉侵权）、不要私自搜查他人。

## 八、常见误区

| 误区 | 实际 |
| --- | --- |
| 「金额小不算偷」 | **多次盗窃不看金额** |
| 「还回去就没事」 | 可能已构成既遂 |
| 「室友的东西借一下不算」 | 未告知拿走可能构成盗窃 |
| 「偷外卖没人管」 | 累计可能构罪 |
| 「有监控就一定查得到」 | 仍应报警留案 |

## 九、可执行清单

### 自己

- [ ] 不拿走不属于自己的东西，包括「借一下」
- [ ] 捡到他人物品交给失物招领

### 被偷

- [ ] 保护现场
- [ ] 通过保卫处或报警调监控
- [ ] 报警并索取受案回执

### 被指控

- [ ] 保留清白证据
- [ ] 必要时咨询律师
