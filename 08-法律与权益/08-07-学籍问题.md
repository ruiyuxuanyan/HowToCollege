# 学籍问题：休学、退学、转学、开除的区别

> 一句话概括：休学可逆，退学不可逆，开除是处分——三者性质完全不同。

**适用人群**：考虑休学或退学的大学生；因学业、健康、家庭原因需要中断学业的人；已经被通知退学或开除的人；想转学的学生。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。个案也可向本校教务处（学籍管理科）核实。
>
> **政策与法律适用范围**
> - 主要依据：《普通高等学校学生管理规定》（教育部令第 41 号，2017 年 9 月 1 日施行）；《中华人民共和国高等教育法》
> - 全国统一：教育部令第 41 号对全国普通高校统一适用；**具体休学年限、退学条件、转学条件由学校规定或由省级教育行政部门规定，差异很大**
> - 核查日期：2026-11-05
> - 已知变化：教育部令第 41 号取代了 2005 年的教育部令第 21 号
>
> ⏳ 易过时：各校学籍管理细则；转学的省级政策。

## 一、四种状态，一张表看清

这是本文最重要的一张表。**做完任何决定前，先在这张表上找到自己的位置。**

| | 休学 | 保留学籍 | 退学（主动） | 开除学籍（处分） |
| --- | --- | --- | --- | --- |
| **性质** | 学籍状态变更 | 学籍状态变更 | 学籍终止 | **纪律处分** |
| **谁提出** | 学生申请，学校批准 | 学生申请，学校批准 | 学生申请，学校批准 | **学校单方作出** |
| **可逆性** | **可逆**（在期限内复学） | 可逆 | **不可逆** | 只能通过申诉改变 |
| **学籍是否在校** | 在校（休学状态） | 在校 | **注销** | **注销** |
| **能否拿到毕业证** | 复学后可以 | 复学后可以 | 不可以 | 不可以 |
| **是否进档案** | 一般不进（属正常学籍变动） | 一般不进 | 有退学记录 | **有处分记录** |
| **对后续升学** | 无影响 | 无影响 | 需重新高考或成人教育 | 需重新高考或成人教育，且处分有影响 |
| **典型原因** | 疾病、参军、创业、出国 | 参军、创业、出国 | 个人选择、学业不达标 | 严重违纪 |

**最容易混淆的两个**：退学和开除学籍。

- 结果看起来相似（都不能继续读）
- 但**性质天差地别**：退学是「你自己不读了」，开除是「学校不要你了」
- 档案记录不同，对后续就业政审的影响也不同

## 二、休学：唯一可逆的选择

### 2.1 什么情况可以休学

> 第二十五条　学生可以分阶段完成学业。学生在校最长年限（含休学和保留学籍）由学校规定。
>
> 学生申请休学或者学校认为应当休学的，经学校批准，可以休学。休学次数和期限由学校规定。
>
> 【法规】《普通高等学校学生管理规定》（教育部令第 41 号）第二十五条

**注意这一条的两个「由学校规定」**：

1. **最长年限**由学校规定（常见是标准学制加若干年，各校不同）
2. **休学次数和期限**由学校规定（常见是每次一年、累计不超过两年，各校不同）

所以：**休学能休多久，必须查本校规定，不能听学长的经验。**

### 2.2 常见的休学理由

| 理由 | 通常需要什么材料 |
| --- | --- |
| 疾病 | 二级甲等以上医院的诊断证明、病历（部分学校要求指定医院复查） |
| 参军入伍 | 入伍通知书 |
| 创业 | 营业执照等（部分学校有此政策） |
| 出国交流 | 录取通知、项目文件 |
| 家庭重大变故 | 相关证明 |
| 其他正当理由 | 学校认定 |

> 各校对「其他正当理由」的认定尺度差异很大。有的学校很宽松，有的很严。**必须问本校教务处。**

### 2.3 休学期间的关键事项

| 事项 | 说明 |
| --- | --- |
| 学费 | 通常不需缴纳（复学后按复学年级标准） |
| 住宿 | 需退宿，行李自行处理 |
| 医保 | **要问清楚**。学生医保通常随学籍状态变化，需确认是否仍可参保 |
| 兵役 | 男生需注意兵役登记与缓征的相关规定 |
| 助学贷款 | 需与贷款银行/资助中心沟通还款安排（休学期间可能影响贴息） |
| 复学 | **必须在期限届满前申请**，逾期可能被视为退学 |

**复学是最容易出问题的一环。** 很多人以为「到时候回来就行」，实际上需要提前申请、提交材料（如康复证明），并且有截止时间。

### 2.4 休学的成本

不要低估休学的时间成本：

| 成本 | 说明 |
| --- | --- |
| 时间 | 至少一年。同期同学毕业时你还在读 |
| 心理 | 与同龄人「脱节」的感受，回校后班级关系重建 |
| 经济 | 少一年收入；如果复学后住宿、生活成本变化 |
| 政策 | 部分政策（如应届生身份）与毕业年份挂钩 |

**关于「应届生身份」**：休学会改变你的毕业年份，从而影响应届生身份的起算时间。这一点在求职时很关键，详见 09-06。

## 三、退学：不可逆的那一步

### 3.1 两种退学：主动退学与被退学

| | 主动退学 | 因学业原因被退学 |
| --- | --- | --- |
| 谁提出 | 学生本人申请 | 学校作出处理 |
| 常见原因 | 个人规划、经济、健康、转行 | 学分不达标、超过最长学习年限、休学期满未复学 |
| 是否需要本人同意 | 是 | 否，但需履行告知程序 |
| 结果 | 学籍注销 | 学籍注销 |

**很多人不知道「被退学」的存在**，以为退学都是自己申请的。实际上学业不达标也会被退学。

法条依据：

> 第三十条　学生有下列情形之一，学校可予退学处理：
>
> （一）学业成绩未达到学校要求或者在学校规定的学习年限内未完成学业的；
> （二）休学、保留学籍期满，在学校规定期限内未提出复学申请或者申请复学经复查不合格的；
> （三）根据学校指定医院诊断，患有疾病或者意外伤残不能继续在校学习的；
> （四）未经批准连续两周未参加学校规定的教学活动的；
> （五）超过学校规定期限未注册而又未履行暂缓注册手续的；
> （六）学校规定的不能完成学业、应予退学的其他情形。
>
> 【法规】同上，第三十条

### 3.2 逐项对照：这些都可能让你被退学

| 情形 | 学生常踩的坑 |
| --- | --- |
| 学分不达标 | 以为「补考能过」，结果累计到触发线 |
| 超过最长学习年限 | 不知道学校有「最长年限」这个规定 |
| 休学期满未复学 | **忘记申请复学，或错过截止日期** |
| 连续两周不参加教学活动 | 长期旷课、长期请假未批、在外实习未报备 |
| 逾期未注册 | 忘记注册、故意不注册以为能「拖着」 |
| 疾病或伤残 | 学校指定医院诊断不能继续学习 |

**第（二）项和第（五）项是「程序性踩坑」**，跟学业能力无关，纯粹是忘了办手续。

**特别提醒**：第（四）项的「连续两周」是一个很短的期限。长期不请假、在外地实习没报备、因病在家休养但没办休学手续——都可能落入这一项。

### 3.3 退学的后果（必须清楚）

| 后果 | 说明 |
| --- | --- |
| 学历 | **拿不到毕业证，也拿不到肄业证以外的任何学历证明** |
| 学籍 | 注销，学信网可查状态变更 |
| 再读书 | 只能**重新参加高考**，或走成人教育（自考、成考、开放大学） |
| 档案 | 退回生源地或户籍地（具体见 10-02） |
| 应届生身份 | 失去 |
| 已缴费用 | 按学校规定退费，通常按学期折算 |
| 已修学分 | **一般不能转入其他高校**（学分互认极少） |

**「一般不能转学分」这一条最伤。** 读了两年退学，这两年在本科学历上等于没有。重新高考要重新读四年。

### 3.4 退学前的最后一道检查

在你提交退学申请之前，务必逐个确认：

- [ ] 我是否可以先**休学**一年，再决定？（休学可逆，退学不可逆）
- [ ] 我的问题（经济/健康/心理）是否有其他解决途径？（助学贷款、医保、心理咨询）
- [ ] 我是否了解重新入学的实际难度？
- [ ] 家里人是否知情？
- [ ] 我是否已经和辅导员、学院谈过？
- [ ] 退学后我的档案会去哪里？怎么取？

**第一条是本文最想传达的建议**：如果只是「暂时读不下去」，休学几乎总是优于退学。代价是多花一年，但保留了退路。

## 四、转学：限制极严，不要抱太大期望

### 4.1 法律怎么规定

> 第二十二条　学生一般应当在被录取学校完成学业。因患病或者有特殊困难、特别需要，无法继续在本校学习或者不适应本校学习要求的，可以申请转学。有下列情形之一，不得转学：
>
> （一）入学未满一学期或者毕业前一年的；
> （二）由低学历层次转为高学历层次的；
> （三）以定向就业招生录取的；
> （四）研究生拟转入学校、专业的录取控制标准高于其所在学校、专业的；
> （五）无正当转学理由的。
>
> 【法规】同上，第二十二条

### 4.2 拆开看这几个限制

| 限制 | 意思 |
| --- | --- |
| 入学未满一学期 | 刚入学不能转 |
| 毕业前一年 | 最后一年不能转 |
| 低学历转高学历 | 专科不能转本科，二本不能转一本 |
| 定向就业招生 | 定向生（如免费师范生、定向医学生）不能转 |
| 无正当理由 | 这是最主要的口子，也是最难的 |

**「由低学历层次转为高学历层次」**这一条，实际上封死了「二本转一本」的路。这是最多人误解的地方。

### 4.3 转学的现实

| 需要什么 | 难度 |
| --- | --- |
| 转出学校同意 | 中 |
| 转入学校同意 | **极高**（转入学校要有空额，且愿意接收） |
| 省级教育行政部门备案/批准 | 高 |
| 正当理由（患病、特殊困难） | 高（需要硬材料） |
| 专业相近 | 通常要求 |
| 同批次/同层次 | 通常要求 |

**实务判断**：转学的成功率非常低。绝大多数人问「能不能转学」，实际上想要的是「换一个更好的学校」——这恰恰是法律明确不允许的方向。

**如果你的诉求是「换专业」**，那不是转学，是校内转专业，走的是学校的转专业办法。两条完全不同的路。

**如果你的诉求是「这个学校读不下去」**，更现实的选择通常是：休学一年想清楚，或者读完再考研换学校。

## 五、开除学籍：是处分，不是学籍处理

### 5.1 性质和依据

> 第五十二条　学生有下列情形之一，学校可以给予开除学籍处分：
>
> （一）违反宪法，反对四项基本原则、破坏安定团结、扰乱社会秩序的；
> （二）触犯国家法律，构成刑事犯罪的；
> （三）受到治安管理处罚，情节严重、性质恶劣的；
> （四）代替他人或者让他人代替自己参加考试、组织作弊、使用通讯设备或其他器材作弊、向他人出售考试试题或答案牟取利益，以及其他严重作弊或扰乱考试秩序行为的；
> （五）学位论文、公开发表的研究成果存在抄袭、篡改、伪造等学术不端行为，情节严重的，或者代写论文、买卖论文的；
> （六）违反本规定和学校规定，严重影响学校教育教学秩序、生活秩序以及公共场所管理秩序的；
> （七）侵害其他个人、组织合法权益，造成严重后果的；
> （八）屡次违反学校规定受到纪律处分，经教育不改的。
>
> 【法规】同上，第五十二条

### 5.2 八种情形，学生最容易踩的三种

| 项 | 情形 | 学生最常见的触发方式 |
| --- | --- | --- |
| （二） | 触犯国家法律，构成刑事犯罪 | 帮信、打架致轻伤、盗窃等（见 08-01） |
| （四） | 严重作弊 | 替考、组织作弊、用手机作弊、卖题 |
| （五） | 学术不端情节严重 | 代写论文、买卖论文、大面积抄袭 |

**需要特别注意第（四）项**：「代替他人或者让他人代替自己参加考试」是**直接列举**的，不是「情节严重才处理」。这是最没有辩护空间的一类。

### 5.3 开除学籍必须走的程序

这是本文与 08-06 的衔接点。开除学籍有额外的程序要求：

| 要求 | 依据 |
| --- | --- |
| 由**校长办公会**或**校长授权的专门会议**研究决定 | 教育部令第 41 号第五十七条 |
| 事先告知学生有**要求举行听证**的权利 | 同上 |
| 事先告知事实、理由、依据 | 第五十五条 |
| 听取陈述和申辩 | 第五十五条 |
| 送达决定书 | 第五十五条 |
| 告知申诉途径和期限 | 第五十五条 |

**缺任何一项，都是申诉的理由。** 详细程序和申诉流程见 08-06。

### 5.4 开除学籍与主动退学：三个关键差异

| | 开除学籍 | 主动退学 |
| --- | --- | --- |
| 性质 | 纪律处分（负面评价） | 学籍处理（中性） |
| 处分记录 | **进档案** | 无处分记录，只有退学记录 |
| 能否申诉 | **能**（10 日内校内申诉） | 一般不能（是你自己申请的） |
| 对就业政审 | 有影响 | 影响较小 |
| 后续升学 | 可重新高考，但处分记录可能被问及 | 可重新高考 |

**核心差异是「负面评价」**。开除学籍意味着学校认定你有严重过错。这个认定会跟着档案走。

## 六、如果你已经被通知退学或开除

顺序很重要，不要慌。

### 第一步：确认文件性质

先搞清楚你收到的是什么：

| 收到的文件 | 什么意思 |
| --- | --- |
| **退学处理决定** | 学籍处理，不是处分 |
| **开除学籍处分决定** | 纪律处分 |
| **拟退学/拟处分告知书** | **还没最终决定**，你还有陈述申辩机会 |
| 只是口头通知、辅导员谈话 | 还没有正式文件，程序还没走到 |

**第三行最关键**：如果是「拟」什么，说明你还在程序中间，**必须立刻提交书面陈述申辩**。

### 第二步：核对程序（针对处分）

对照第五节的六项要求，逐项看学校做了没有。缺项就是申诉理由。

### 第三步：核对事实与依据

- 学校认定的事实，有没有证据？
- 引用的条款，和你的行为对得上吗？
- 有没有对你有利的事实被遗漏？

### 第四步：在期限内行动

| 情形 | 期限 |
| --- | --- |
| 收到处分决定 | **10 日内**向校内学生申诉处理委员会申诉 |
| 收到「拟处分」告知 | 按告知书写的期限提交陈述申辩（通常很短） |
| 收到退学处理决定 | 该规定未统一设申诉期限，但**部分学校规定可申诉**，需查本校办法 |

**注意第四行**：教育部令第 41 号第五十九条至第六十二条的申诉程序，条文表述是「对学校的处理或者处分决定有异议」——「处理」也包括退学处理。**所以退学处理通常也可以申诉**，但具体以本校办法为准。**【待核实】**

### 第五步：找专业帮助

| 找谁 | 能帮什么 |
| --- | --- |
| 学校法律援助中心 / 法学院老师 | 免费，懂程序 |
| 执业律师 | 正式申诉、复议、诉讼 |
| 省级教育行政部门 | 申诉的上一级 |
| 家人 | 经济与情绪支持 |

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「休学和退学差不多，都是不读了」 | 休学可逆，退学不可逆 |
| 「退学后还能回原来学校」 | 不能。需重新高考或成人教育 |
| 「退学的学分以后能转」 | 一般不能。学分互认极少 |
| 「转学就是换个学校」 | 限制极严，低层次不能转高层次，毕业前一年不能转 |
| 「二本可以转到一本」 | 法律明确禁止「由低学历层次转为高学历层次」 |
| 「被退学一定是成绩差」 | 还可能是休学期满未复学、逾期未注册、连续两周不参加教学活动 |
| 「开除学籍跟退学一样」 | 开除是处分，进档案；退学是学籍处理 |
| 「不签收退学通知就无效」 | 可以留置、邮寄、公告送达 |
| 「休学期间什么都不用管」 | 复学要申请、有截止日期；医保、贷款、兵役都要处理 |
| 「休学多久都行」 | 由学校规定，有累计上限和最长学习年限 |

## 八、可执行清单

### 想做决定之前（休学/退学）

- [ ] 查本校《学籍管理规定》，找到：最长学习年限、休学次数与期限、复学流程
- [ ] 问清「休学一年」的具体手续和截止时间
- [ ] 问清休学期间的医保、住宿、贷款怎么处理
- [ ] 算一笔账：休学一年的时间成本、经济成本
- [ ] 和家人谈一次
- [ ] 先问：我的问题能不能用休学解决，而不是退学？

### 如果是学业不达标

- [ ] 查自己的学分缺口，还剩几门
- [ ] 查学校规定的「降级/试读」政策（部分学校有缓冲机制）
- [ ] 找辅导员谈，问有没有补救路径
- [ ] 不要拖到最后一年才发现

### 如果是休学中

- [ ] 在日历上标记**复学申请截止日**（提前一个月设提醒）
- [ ] 保留好康复证明/相关材料
- [ ] 确认医保、住宿、贷款状态

### 如果收到退学/开除通知

- [ ] 确认文件性质（「拟」还是「决定」）
- [ ] 复印/扫描存档
- [ ] 核对程序（开除看六项）
- [ ] 在 10 日内提交申诉（处分）或按告知期限提交申辩
- [ ] 书面留痕，不要只口头沟通
- [ ] 找律师或学校法律援助

### 无论哪种情况

- [ ] 确认档案去向（见 10-02）
- [ ] 保留所有书面文件原件
- [ ] 不要在任何文件上签「无异议」

**休学是「我先停一下」，退学是「我不读了」，开除是「学校不要你了」——只有第一个能回头。**
