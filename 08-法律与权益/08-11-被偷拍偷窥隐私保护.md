# 被偷拍、被偷窥、宿舍被翻：隐私权保护

> 一句话概括：先取证，再声张——很多人输在打草惊蛇。

**适用人群**：宿舍、浴室、更衣室被偷拍的人；发现自己东西被翻、手机被动过的人；私密影像被传播或威胁的人；同宿舍有过这类怀疑的人。

> **本文性质**
>
> 本文为一般性说明，**不构成法律意见**，具体问题请咨询执业律师。
>
> **政策与法律适用范围**
> - 主要依据：《中华人民共和国民法典》人格权编（第九百九十条、第一千零三十二条、第一千零三十三条、第一千零三十四条起）；《中华人民共和国治安管理处罚法》；《中华人民共和国刑法》（第二百五十三条之一、第三百六十三条、第三百六十四条）
> - 全国统一：民法典与刑法全国适用；治安处罚的具体裁量各地有差异
> - 核查日期：2026-11-05
> - 已知变化：该法曾多次修改，**本文所引条款序号以 2012 年修正版为准，现行版本是否另有修改未能核实**
>
> ⏳ 易过时：治安管理处罚法的条款序号；各地对「情节严重」的认定。

## 一、这件事同时可能触发三种责任

隐私被侵犯不是一个「违法」或「不违法」的判断，而是可能同时触发三条线。

| 层次 | 依据 | 后果 |
| --- | --- | --- |
| **民事** | 《民法典》人格权编 | 停止侵害、删除、赔礼道歉、赔偿损失（含精神损害） |
| **行政（治安）** | 《治安管理处罚法》 | 拘留、罚款 |
| **刑事** | 《刑法》 | 有期徒刑、拘役、管制 |

**三条线可以同时走。**报警处理（治安）和民事索赔并不冲突。

## 二、民法典怎么保护：隐私权的两条核心

### 2.1 隐私权是什么

> 第一千零三十二条　自然人享有隐私权。任何组织或者个人不得以刺探、侵扰、泄露、公开等方式侵害他人的隐私权。
>
> 隐私是自然人的私人生活安宁和不愿为他人知晓的私密空间、私密活动、私密信息。
>
> 【法规】《中华人民共和国民法典》第一千零三十二条

这里的三个关键词，正好覆盖校园里的三类情形：

| 关键词 | 对应场景 |
| --- | --- |
| **私密空间** | 宿舍、浴室、更衣室、卫生间、你的床铺和柜子 |
| **私密活动** | 换衣服、洗澡、睡觉、私人谈话 |
| **私密信息** | 手机内容、聊天记录、身体状况、恋爱关系 |

### 2.2 具体的禁止行为

> 第一千零三十三条　除法律另有规定或者权利人明确同意外，任何组织或者个人不得实施下列行为：
>
> （一）以电话、短信、即时通讯工具、电子邮件、传单等方式侵扰他人的私人生活安宁；
>
> （二）进入、拍摄、窥视他人的住宅、宾馆房间等私密空间；
>
> （三）拍摄、窥视、窃听、公开他人的私密活动；
>
> （四）拍摄、窥视他人身体的私密部位；
>
> （五）处理他人的私密信息；
>
> （六）以其他方式侵害他人的隐私权。
>
> 【法规】《中华人民共和国民法典》第一千零三十三条

**这一条是本文最核心的法律依据。**逐项对照校园场景：

| 法条项 | 校园里的样子 |
| --- | --- |
| （二）进入、拍摄、窥视私密空间 | 在宿舍、浴室装摄像头；偷配钥匙进室友房间；透过门缝/缝隙窥视 |
| （三）拍摄、窥视、公开私密活动 | 偷拍室友换衣服、洗澡；偷录私人谈话 |
| （四）拍摄身体私密部位 | 裙底偷拍、浴室偷拍、更衣室偷拍 |
| （五）处理私密信息 | 偷看手机、翻聊天记录、翻看日记、把私密照片发给别人 |

**注意第（二）项的「进入」**：不只是拍摄和窥视，**擅自进入**私密空间本身就已经落入这一条。宿舍属于「私密空间」这一点，在司法实践中通常成立（尤其是个人床铺、柜子所在的区域）。

**但要注意一个现实边界**：宿舍是多人共享的，公共区域（如共用的桌面、走道）的隐私期待低于个人床铺和柜子。具体到「室友翻我抽屉」这类情形，法律上通常认定为侵犯隐私，但举证和认定会有细节争议。**【待核实】这一点在不同案件中认定标准不完全一致。**

### 2.3 个人信息也受保护

> 第一千零三十四条　自然人的个人信息受法律保护。
>
> 个人信息是以电子或者其他方式记录的能够单独或者与其他信息结合识别特定自然人的各种信息，包括自然人的姓名、出生日期、身份证件号码、生物识别信息、住址、电话号码、电子邮箱、健康信息、行踪信息等。
>
> 【法规】《中华人民共和国民法典》第一千零三十四条

**偷看别人手机为什么不仅是「隐私」问题**：手机里有姓名、身份证号、住址、位置、聊天记录、照片——这些都是个人信息。

## 三、治安处罚：最常见的实际后果

绝大多数偷拍、偷窥行为，实际处理结果停在治安处罚。

《治安管理处罚法》对以下行为规定了拘留、罚款：

- 偷窥、偷拍、窃听、散布他人隐私
- 偷看、偷拍、窃听、散布他人隐私（条文表述以现行文本为准）

> 【法规】《中华人民共和国治安管理处罚法》（2025 年 6 月 27 日修订，**2026 年 1 月 1 日起施行**）
>
> **偷窥、偷拍、窃听、散布他人隐私的，规定在现行第五十条第六项**（2012 年版为第四十二条）。
>
> 处罚幅度：处**五日以下拘留或者一千元以下罚款**；情节较重的，处**五日以上十日以下拘留**，可以并处一千元以下罚款。
>
> 【待核实】该条其余各项的具体序号未逐一核实，引用其他行为类型时请核对官方文本。

**治安处罚的实务特点：**

| 特点 | 含义 |
| --- | --- |
| 门槛低 | 不需要「情节严重」 |
| 可拘留 | 通常为几日到十几日 |
| 有违法记录 | 影响政审、部分岗位入职 |
| 可以同时要求民事赔偿 | 治安处罚不免除民事责任 |
| 需要证据 | 警方也要看证据，这就是为什么取证是关键 |

## 四、刑事：三种可能的罪名

### 4.1 侵犯公民个人信息罪

> 第二百五十三条之一　违反国家有关规定，向他人出售或者提供公民个人信息，情节严重的，处三年以下有期徒刑或者拘役，并处或者单处罚金；情节特别严重的，处三年以上七年以下有期徒刑，并处罚金。
>
> 【法规】《中华人民共和国刑法》第二百五十三条之一

**触发场景**：把偷拍到的内容、他人的身份信息、联系方式**出售或提供给他人**。注意是「提供」，不要求收费。

### 4.2 传播淫秽物品罪 / 传播淫秽物品牟利罪

> 第三百六十四条　传播淫秽的书刊、影片、音像、图片或者其他淫秽物品，情节严重的，处二年以下有期徒刑、拘役或者管制。
>
> 【法规】《中华人民共和国刑法》第三百六十四条

> 第三百六十三条　以牟利为目的，制作、复制、出版、贩卖、传播淫秽物品的，处三年以下有期徒刑、拘役或者管制，并处罚金；情节严重的，处三年以上十年以下有期徒刑，并处罚金；情节特别严重的，处十年以上有期徒刑或者无期徒刑，并处罚金或者没收财产。
>
> 【法规】《中华人民共和国刑法》第三百六十三条

**两个罪的区别就在「以牟利为目的」：**

| | 传播淫秽物品罪（364 条） | 传播淫秽物品牟利罪（363 条） |
| --- | --- | --- |
| 是否要求营利 | **不要求** | **要求** |
| 刑罚 | 二年以下 | 三年以下起，最高可至无期 |
| 学生常见触发 | 在群里转发他人私密影像 | 卖「资源」、收费进群 |

**这一节的要点**：把偷拍到的私密影像发到群里，即使一分钱不收，也可能构成第三百六十四条。

### 4.3 强制猥亵、侮辱罪

如果偷拍过程中伴随身体接触、胁迫，可能涉及更重的罪名。这一部分不属于本文范围，属于需要律师判断的情形。

**【说明】** 本文不对这类情形给结论，只提示：如果伴随身体接触、胁迫、威胁，性质会显著加重，应直接报警并咨询律师。

## 五、核心：先取证，再声张

这是本文最重要的一节。**顺序错了，后面全废。**

### 5.1 为什么不能先声张

| 先声张会发生什么 | 后果 |
| --- | --- |
| 对方删掉设备里的内容 | 最直接的证据消失 |
| 对方格式化手机、电脑 | 传播链条断掉 |
| 对方先找人说情、施压 | 你可能被孤立，甚至被反指「误会」 |
| 对方倒打一耙说你「诬陷」 | 你反而要举证 |
| 宿舍其他人被惊动，现场被破坏 | 设备位置、痕迹消失 |

**这不是让你忍气吞声，是让你在证据安全之后再行动。**

### 5.2 取证要取什么

| 证据 | 具体做法 |
| --- | --- |
| **偷拍设备本身** | **不要拆、不要动、不要拔卡**。拍照记录位置、外观、朝向、连线 |
| 设备里的内容 | 不要自己查看、不要复制、不要转发（这一步交给警方） |
| 现场环境 | 拍下设备所在位置与你的私密空间的关系（比如正对床/浴室） |
| 时间地点 | 精确记录发现时间和位置 |
| 你的第一反应记录 | 当时在场的人、你告诉了谁、几点告诉的 |
| 通讯记录 | 对方如果有过威胁、暗示、试探性的消息，全部保留 |
| 异常痕迹 | 门锁被动过、柜子被动过、手机被动过的迹象 |

**最重要的一条：不要自己动手拆设备、不要自己翻看内容、不要截图转发。**

理由：私自查看和转发可能让你自己也陷入「处理他人私密信息」或者「传播」的问题；而且会破坏证据的完整性。

### 5.3 正确的处置顺序

```
发现异常
   │
   ├─ ① 不要动现场，先拍照/录像（记录设备位置、外观）
   │
   ├─ ② 立刻离开该空间，保护自己
   │
   ├─ ③ 打电话报警（110），说明「宿舍/浴室发现偷拍设备」
   │      → 涉及偷拍设备，警方可以到场固定证据
   │
   ├─ ④ 同时告诉可信任的人（室友、辅导员、家人）
   │      → 目的：有人证，避免单独面对
   │
   ├─ ⑤ 报警后索取【受案回执】
   │      → 这是后续跟进的凭据（见 08-12）
   │
   └─ ⑥ 配合警方，不要自行与对方接触
```

**第③步是关键**：偷拍设备属于警方可以现场固定的物证。自行处理（拆下来、扔掉、拿去给辅导员看）会让证据的证明力大打折扣。

### 5.4 如果对方是室友

这是最棘手的情形。原则不变，但有几点要注意：

| 要做 | 不要做 |
| --- | --- |
| 报警（这是最重要的一步） | 不要在宿舍群里公开质问 |
| 告诉辅导员，要求调整住宿 | 不要私自搜查对方物品（可能反而违法） |
| 保留自己的证据 | 不要私下「谈判」换取道歉 |
| 考虑临时搬到别处住 | 不要单独和对方对峙 |

**关于「私自搜查对方物品」**：即使是你的室友、即使你有合理怀疑，私自翻查对方的东西也可能构成侵权。这件事要交给警方或学校保卫部门。

### 5.5 关于「我已经看到了内容」

如果你不小心看到了，或者对方已经给你看过：

| 要做 | 不要做 |
| --- | --- |
| 记住你看到了什么（时间、内容性质） | 不要截图、不要保存、不要转发 |
| 告诉警方 | 不要发给任何人「作证」 |
| 必要时在警方指导下提供 | 不要自己发到群里求认同 |

**为什么**：一旦你转发了，你可能从「受害人」变成「传播者」。

## 六、被传播私密影像：这是最危险的情形

这一类要单独讲，因为后果最严重、处理最需要谨慎。

### 6.1 法律后果（针对传播者）

| 行为 | 可能涉及 |
| --- | --- |
| 在群里/网上发布他人私密影像 | 传播淫秽物品罪（364 条）；治安处罚；民事侵权 |
| 以影像要挟索要钱财 | 敲诈勒索罪 |
| 以影像要挟维持关系 | 可能涉及强制猥亵、侮辱罪等，需律师判断 |
| 出售影像 | 传播淫秽物品牟利罪（363 条） |

**关于「敲诈勒索」**：用私密影像威胁要钱，这是独立的罪名，且量刑不轻。这一条要说清楚，因为很多人以为「只是要回自己的钱」。

### 6.2 如果你是受害者

**顺序：**

1. **不要付钱、不要答应任何条件**。付钱通常不会让对方停止，只会证明你怕
2. **保存证据**：对方的账号、聊天记录（含威胁内容）、发布时间、链接
3. **立即报警**。传播淫秽物品、敲诈勒索都是公诉案件，警方会处理
4. **同时向平台投诉**，要求删除（保留投诉记录）
5. **不要自己去找对方谈判**
6. **告诉一个可信任的成年人**（家人、辅导员、律师）

**关于「平台删除」**：主流平台都有紧急处理通道。用「侵权投诉」而不是普通举报，说明涉及私密影像、要求紧急删除。

### 6.3 不要做的事

| 不要 | 为什么 |
| --- | --- |
| 不要付钱 | 会变成持续勒索 |
| 不要自己发声明澄清 | 可能扩大传播 |
| 不要去找对方「讲道理」 | 危险，且无效果 |
| 不要删除自己手机里的证据 | 那是唯一的证据 |
| 不要因为羞耻而不报警 | 这是对方最希望的结果 |

**最后一条要说重一点**：这类案件的受害者常常因为羞耻而选择沉默。但**传播私密影像是犯罪行为，责任在传播者，不在被拍的人。**

## 七、民事索赔：可以要什么

| 请求 | 依据 | 说明 |
| --- | --- | --- |
| 停止侵害 | 第一千一百六十七条 | 要求删除、停止传播 |
| 排除妨碍、消除危险 | 同上 | 比如拆除设备 |
| 赔礼道歉 | 第九百九十五条 | 可以要求在一定范围内公开 |
| 赔偿损失 | 第一千一百八十二条、一千一百八十三条 | 含为维权支出的合理费用 |
| **精神损害赔偿** | 第一千一百八十三条 | 侵害人身权益造成严重精神损害的可以主张 |

> 第一千一百八十三条　侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿。
>
> 【法规】《中华人民共和国民法典》第一千一百八十三条

**关于精神损害赔偿的数额**：法律没有固定标准，由法院根据侵权情节、后果、当地生活水平等酌定。**【待核实】**具体数额无法给出，需按个案判断。

**关于诉讼时效**：三年（《民法典》第一百八十八条），从知道或应当知道权利受损及义务人之日起算。

## 八、学校层面的处理

学校不是执法机关，但有管理和处分权。

| 你可以要求学校做什么 | 依据/理由 |
| --- | --- |
| 调整宿舍 | 学校有保障学生安全与正常生活的管理职责 |
| 启动纪律处分程序 | 依据本校学生违纪处分规定 |
| 提供心理支持 | 学生心理健康服务 |
| 出具情况说明 | 便于后续维权 |

**要注意的一点**：学校的处理**不能替代报警**。

很多学生只找学校，结果学校为了「内部消化」而轻处理，最后证据也散了、时间也过了。

**正确做法：报警 + 告知学校，两条线同时走。** 报警是固定证据、确认违法事实的最有效方式；学校的处分是另一条线。

**关于学校「劝你别报警」**：如果学校以「影响学校声誉」「内部处理更好」为由劝你不要报警，你要清楚：**是否报警是你的权利，不是学校能决定的。** 你可以礼貌地表示「我已经决定了」，并坚持索取受案回执。

## 九、常见误区

| 误区 | 实际 |
| --- | --- |
| 「先找对方谈谈」 | 会给对方销毁证据的时间 |
| 「先告诉辅导员，让学校处理」 | 学校处理不能替代报警，且可能拖延 |
| 「把设备拆下来当证据」 | 破坏现场，证据效力下降。应报警由警方固定 |
| 「我自己先看看里面有什么」 | 可能让你自己陷入「处理私密信息」的问题，且破坏证据 |
| 「发到群里让大家评理」 | 你可能变成传播者 |
| 「只是偷看手机，不算什么」 | 落入第一千零三十三条第（五）项，侵犯私密信息 |
| 「宿舍是公共空间，不算隐私」 | 个人床铺、柜子所在的区域通常有隐私期待 |
| 「没拍到什么就不算」 | 「窥视」「进入」本身就已落入第一千零三十三条 |
| 「他删了就没事了」 | 传播已经发生；删了只是止损 |
| 「这事太丢人，不想让别人知道」 | 沉默是对方最希望的结果。责任在侵权人 |
| 「报警也没用」 | 报警能固定证据、留下受案回执，是后续所有维权的基础 |

## 十、可执行清单

### 发现偷拍设备/被偷窥的当下

- [ ] 不要碰设备，不要拆、不要拔卡
- [ ] 拍照/录像记录设备位置、外观、朝向（用手机，带时间）
- [ ] 拍下设备与你私密空间的位置关系
- [ ] 立刻离开该空间
- [ ] 打 110 报警，说明「发现偷拍设备」
- [ ] 同时告诉一个可信任的人

### 报警时

- [ ] 说清：时间、地点、发现了什么、设备在哪
- [ ] 要求警方到场固定证据
- [ ] **索取受案回执**（一定要要，见 08-12）
- [ ] 记录办案民警的联系方式

### 24 小时内

- [ ] 记录完整时间线（发现时间、报警时间、告知了谁）
- [ ] 保存所有相关沟通记录
- [ ] 如果是室友：向辅导员书面申请调整宿舍
- [ ] 告诉家人
- [ ] 不要与对方单独接触

### 后续

- [ ] 跟进案件进展（凭受案回执）
- [ ] 评估是否提起民事诉讼（精神损害赔偿）
- [ ] 保留维权支出的票据（公证费、律师费、交通费）
- [ ] 需要时寻求心理支持

### 如果是私密影像被传播

- [ ] 不付钱、不答应条件
- [ ] 保存对方账号、威胁内容、发布链接
- [ ] 立即报警
- [ ] 向平台投诉要求紧急删除（用侵权投诉通道）
- [ ] 告诉可信任的成年人
- [ ] 不要自己发声明、不要去找对方
