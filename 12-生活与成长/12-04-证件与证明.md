# 证件与证明：在读证明、成绩单、户籍证明、无犯罪记录

> 一句话概括：证明不是「开不出来」，是「该谁开、按什么口径开」没搞清。

**适用人群**：要办实习、考证、出国、政审、落户、贷款，被要求「提供某某证明」却不知道去哪开的人；跑了两趟派出所、三趟教务处还没办成的人。

> **核查日期**：2026-11-05
> ⏳ 易过时：各校自助打印机的开放时间、各省线上办理入口；派出所出具证明的范围以 2016 年文件为框架，地方执行细节会变。

---

## 一、先分清三类，别跑错门

同一个「证明」，可能由三个完全不同的机构出。跑错门是最大的时间浪费。

| 类别 | 谁出 | 典型例子 |
| --- | --- | --- |
| **校内证明** | 学校教务处、学工部、档案馆、学院 | 在读证明、成绩单、应届毕业生证明、无处分证明 |
| **政府证明** | 派出所、出入境管理部门、民政、公证处 | 户籍证明、无犯罪记录证明、身份证、护照、亲属关系公证 |
| **第三方验证** | 学信网等官方平台 | 学籍在线验证报告、学历证书电子注册备案表 |

**判断方法**：看要求方写的是「学校盖章」还是「公安机关出具」，还是「可在学信网核验」。三个字眼指向三个地方。

---

## 二、学校能开的：多开几份，一次办完

| 证明 | 通常在哪办 | 要点 |
| --- | --- | --- |
| 在读证明 | 教务处 / 学院教务办 / 自助打印机 | 问清要不要求**校级公章**（学院章有时不被接受） |
| 成绩单 | 教务处 / 自助打印机 | 出国、保研、部分实习要**中英文对照版**并盖章 |
| 应届毕业生证明 | 学院 / 就业指导中心 | 实习、考公、落户常用，注明毕业年月 |
| 无处分证明 | 学工部 / 学院 | 部分政审、入党材料需要 |

> 【经验】自助打印机能打的，优先用自助机：不用排队、随时可打、通常自带章。但**自助机打出来的成绩单有时不带教务处红章**，出国申请这类用途要另行确认。

三条省时间的习惯：

1. **一次多打几份**（3—5 份）。补打的成本远高于多打的成本。
2. **当场扫描成 PDF 存云盘**。纸质件会丢，电子件不会。
3. **看清章**。校级公章、教务处章、学院章，在不同场合效力不同，办之前问一句「要哪种章」。

## 三、学信网：免费的官方验证，很多人不知道

这是最被低估的一项。学历、学籍类材料，**官方的电子验证报告往往比纸质盖章件更被认可**，因为对方能自己上网核验真伪。

| 你要证明的 | 用什么 | 说明 |
| --- | --- | --- |
| 我是在校生 | 《教育部学籍在线验证报告》 | 学信网可申请，含在线验证码与有效期 |
| 我已毕业 | 《教育部学历证书电子注册备案表》 | 用人单位可凭验证码在线核验 |
| 我的学位 | 学位证书查询（学位网） | 与学历是两套系统，别混 |

三个实操点：

- **验证有效期可自行设置**，投简历、办入职时按对方要求延长，别让它过期。
- **验证码是公开信息**，只发给需要核验的机构，不要发到群里或挂到公开页面。
- **免费**。任何声称「代办学信网认证、收费加急」的中介，都不必要。

## 四、派出所：哪些开、哪些不开

这块有全国统一的框架文件，值得记住，能省掉很多白跑。

> 【法规】公安部等 12 部门《关于改进和规范公安派出所出具证明工作的意见》（公通字〔2016〕21 号），**2016 年 9 月 1 日起施行**。

文件把事项分成三组：

**第一组：身份证件能证明的，派出所不再出具（9 类）**

姓名、曾用名、性别、身份号码（含 15 位升 18 位）、民族成份、出生日期、出生地、籍贯、户籍所在地住址。

**第二组：户口簿能证明的，派出所不再出具（5 类）**

户口迁移情况、住址变动情况、户口登记项目变更更正情况、注销户口情况、同户人员与户主间的亲属关系。

**第三组：派出所应当出具的（9 类，节选）**

| 证明 | 什么情况下开 |
| --- | --- |
| 户口登记项目变更更正证明 | 改过姓名、性别、民族、出生日期、身份号码，或户口迁移后户口簿无法证明 |
| 注销户口证明 | 因死亡、服现役、出国定居、被判刑等注销户口 |
| 亲属关系证明 | 曾经同户人员之间的亲属关系，户籍档案能反映的 |
| 临时身份证明 | 丢失/忘带身份证，急需登机、乘车、住旅馆、参加国家考试 |
| **无犯罪记录证明** | 见下 |

**「无犯罪记录证明」的准确口径**——这是被误解最多的一条：

- 文件原文：**「公民因办理出国（境）事务需要，可以申请查询本人有无犯罪记录。」**
- 也就是说，**个人可以查本人**，最常见的正当用途是出国（境）。
- 因**政审、参军、重要岗位录用**需要查询的，通常由**需要该证明的单位**持有效证件与介绍信向公安机关查询，而不是让个人自己去开。
- 注意区分两个词：**「犯罪记录」**指刑事犯罪；**「违法犯罪记录」**范围更宽，可能包含治安处罚。用人单位要的到底是哪个，必须问清。

> 【待核实】各省「无犯罪记录证明」的线上办理入口不同（部分省份可在本地政务 App、公安一网通办上申请，也有地方仍需到户籍地或居住地派出所办理）。办理前先搜「省份 + 无犯罪记录证明 + 线上办理」，或直接打派出所电话确认，别默认全国一个流程。

## 五、身份证丢了或过期

| 情形 | 怎么办 |
| --- | --- |
| 在校内丢失 | 先挂失（派出所或线上），再申请补办；急用可办临时身份证 |
| 户籍在学校集体户 | 通常在学校所在地派出所办理，具体看学校户籍管理安排 |
| 户籍在老家、人在学校 | 【官方】公安部已推行居民身份证**异地受理**，可在居住地公安机关申请换领、补领 |
| 考试/乘车前丢失 | 派出所可开**临时身份证明**（见上表），火车站、机场也有相应服务 |

> 【经验】异地办证的受理范围与所需材料各省略有差别（常见是居住证、学生证或在读证明之一）。**先打电话问清三样：能不能办、带什么、多久出证**，再跑一趟。

## 六、办事的四个通用原则

1. **先打电话，别先跑腿。** 问三句：办这个要带什么、哪个窗口、什么时间人少。
2. **材料带双份。** 身份证复印件、照片、学生证，永远多带。
3. **当场扫描存档。** 办完立刻拍/扫，命名成「2026-11 无犯罪记录证明.pdf」这种可搜索的名字。
4. **留办理回执。** 有回执才有查询依据，尤其是需要等待或邮寄的事项。

## 七、常见误区

| 误区 | 实际 |
| --- | --- |
| 「所有证明学校都能开」 | 户籍、无犯罪记录这类只能公安机关出 |
| 「成绩单随时能补」 | 毕业离校后再补，流程会长很多，还可能要档案馆调档 |
| 「学信网报告没人认」 | 恰恰相反，可在线核验的报告通常比纸质件更被认可 |
| 「政审我自己去开无犯罪记录就行」 | 多数政审由单位发函/持介绍信查询，个人开的不一定被接受 |
| 「无犯罪记录＝没有违法记录」 | 两个概念范围不同，问清要求方要哪个 |
| 「电子版不正式」 | 带验证码的电子验证报告就是官方的正式形式 |

## 八、可执行清单

### 现在（20 分钟）

- [ ] 登录学信网，申请一份《学籍在线验证报告》，存 PDF
- [ ] 把已有证件全部扫描，按「证件名-日期」命名存云盘
- [ ] 存好三个电话：教务处、学校户籍管理/保卫处、户籍地派出所

### 要办某个证明之前

- [ ] 问要求方三个问题：**要哪种章、有没有模板、有效期多久**
- [ ] 按第一节判断属于校内／政府／第三方验证
- [ ] 打电话确认材料清单与办理时间

### 长期

- [ ] 每年更新一次在读证明与成绩单的电子版
- [ ] 验证报告快过期前延长有效期，别等到投简历时才发现失效
