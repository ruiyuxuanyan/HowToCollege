## 分类说明

本分类处理「课本不教、但每天都要用」的事：**日常消费里的规则、生活事务的流程、证件的办理、时间的安排、表达的技巧**。

它与其余 11 个分类的边界：

| 容易混的地方 | 放在哪 |
| --- | --- |
| 预付费卡跑路、网购退款被拒 | 08-13 消费维权（维权路径与证据） |
| 订阅扣费、分期手续费与征信 | **本分类**（规则与算法，不重复维权流程） |
| 校园贷、套路贷、帮信罪 | 03 金钱管理（金融风险，量级更大） |
| 宿舍关系与室友矛盾 | 01-08 / 06-01（人际关系，不是事务流程） |
| 兼职被欠薪 | 04 兼职与赚钱（劳动与维权） |
| 考研、考公、秋招的具体流程 | 02 / 09（本分类只给时间轴，不重复流程细节） |

判断一个选题是否属于这里，看它的核心矛盾是不是「**没人教过，但规则是确定的**」。如果核心是「对方违法了，怎么追责」，去 08；如果是「这件事的标准做法是什么」，留在这里。

## 关于来源标注

本分类偏重「规则 + 流程」，因此：

- **有全国统一规定的**（自动续费的提醒义务、派出所出具证明的范围、七日无理由退货），给法规文号与原文
- **各地各校不同的**（水电额度、线上办证入口、自助打印规则），标【待核实】并写明「怎么自己查」
- **方法类内容**（表达、时间轴），全文标【经验】，不伪装成研究结论

## 怎么贡献这个分类

1. 先看 [内容选题清单](../docs/02-内容选题清单.md) 与 [内容质量审核标准](../docs/03-内容质量审核标准.md)
2. 开 issue 说明要写哪一篇、核心矛盾是什么
3. 文件名格式：`{编号}-{短标题}.md`
4. 每篇必须含：一句话概括、适用人群、可执行清单、一句话记住、参考资料、核查日期、核查说明

**这个分类最需要的贡献**：各校的实际流程（报修系统、水电计费、自助打印、证件办理）。这类信息我们查不到，只能靠本地读者补。
